# Overcoming the Weakest-Link Effect in LLM-Driven Program Optimization via Heterogeneous Edit Recombination

- arXiv: https://arxiv.org/abs/2607.28947v1
- arXiv ID: 2607.28947

---

🔍 **核心问题**：现有基于大语言模型（LLM）的程序优化方法依赖显式“文本梯度”指导搜索，但该梯度在程序-分数映射复杂时可靠性下降，限制了优化效果。

🛠 **方法**：提出HERO优化器，采用零阶优化策略，让LLM直接生成多样且互不重叠的原子编辑，再基于评估分数系统性地选择和组合这些编辑，避免整批接受/拒绝导致的“最弱环节效应”。

✨ **主要贡献**：在算法问题、策略游戏、LLM智能体设计和机器人路径规划等多个领域，HERO均能发现更高分数的程序，收敛速度显著快于现有方法，且消耗更少token。

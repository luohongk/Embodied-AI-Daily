# InstantMimic: A High Performance System for Learning Physics-based Skills in Seconds

- arXiv: https://arxiv.org/abs/2609.09821v1
- arXiv ID: 2609.09821

---

🔍 **核心问题**：基于物理的角色控制训练（如DeepMimic等模仿学习方法）虽然效果出色，但训练计算效率低下，GPU加速仿真因物理求解器之外的碎片化内核和CPU内存访问开销而未被充分利用。

🛠 **方法**：提出InstantMimic系统，基于GPU原生物理后端，将仿真、环境计算、策略推理和策略更新整合到单一执行流中，实现整个训练循环的GPU原生化。

✨ **主要贡献**：将多种基于物理的技能训练时间缩短至几秒，并使LLM智能体驱动的超参数搜索变得切实可行。

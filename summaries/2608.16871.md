# Biophysics-informed deep operator learning for inverse problems with application to electrophysiological source reconstruction

- arXiv: https://arxiv.org/abs/2608.16871v1
- arXiv ID: 2608.16871

---

🔍 **核心问题**：从间接且带噪声的脑电测量中重建神经源信号（逆问题），该问题不适定且对噪声敏感，传统方法难以高效适应个体差异。

🛠 **方法**：提出DeepOp-Informed框架，将生物物理感知过程嵌入为可微分层，结合几何深度算子学习，使模型能适应个体脑解剖和传感器位置的差异。

✨ **主要贡献**：在真实脑磁图模拟中，模型对未见受试者的前向模型具有良好泛化性，重建误差低于多种神经网络和经典基线；应用于青少年听觉诱发数据时，重建结果解剖学合理且定位到听觉皮层。框架具有通用性，可扩展至其他成像模态。

# FlowCorrect: Efficient Interactive Correction of Generative Flow Policies for Robotic Manipulation

- arXiv: https://arxiv.org/abs/2602.22056v3
- arXiv ID: 2602.22056

---

🔍 **核心问题**：生成式操作策略在部署时因分布偏移可能失败，但许多失败接近成功，仅需微小修正即可完成，现有方法无法在部署时高效利用人类稀疏修正。

🛠 **方法**：提出FlowCorrect，一种模块化交互式模仿学习方法，通过轻量VR界面接收人类稀疏的相对位姿修正，在推理时局部调整流匹配策略的动作，无需重新训练骨干网络。

✨ **主要贡献**：在真实机器人四个桌面任务（抓放、倒水、杯子扶正、插入）上，FlowCorrect以低修正预算在先前失败案例上达到80%成功率，同时保持已解决场景的性能，展示了部署时高效、样本经济的人机协同策略修正能力。

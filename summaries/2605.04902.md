# AegisTS: An Agent-Driven Hierarchical Reinforcement Learning System for Multivariate Time Series Data Cleaning

- arXiv: https://arxiv.org/abs/2605.04902v5
- arXiv ID: 2605.04902

---

🔍 **核心问题**：多变量时间序列（MTS）中常同时存在缺失值、异常值和约束违反等多种数据质量问题，现有清洗方法仅能处理有限类型的问题，且依赖真实标签或领域规则，难以应对实际场景。

🛠 **方法**：提出AegisTS，一个基于强化学习的智能体系统，将清洗过程建模为联合优化问题，同时处理质量问题处理顺序和清洗模型选择。采用分层智能体架构，高层智能体决定质量问题处理顺序，低层智能体选择具体清洗方法，并通过双阶段奖励机制耦合清洗与下游任务性能，无需真实标签。

✨ **主要贡献**：AegisTS在无需真实数据或规则的情况下，实现多质量问题联合清洗，实验表明其清洗质量提升高达96%，下游任务性能提升27%，显著优于现有方法。

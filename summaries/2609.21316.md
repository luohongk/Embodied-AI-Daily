# NaViRrator: Robot Navigation from Human-Readable Maps through a Learned Visual Route

- arXiv: https://arxiv.org/abs/2609.21316v1
- arXiv ID: 2609.21316

---

🔍 **核心问题**：如何将人类可读地图上指定的起点和终点，转化为预训练视觉-语言导航（VLN）策略可执行的导航指令，从而弥合示意性地图几何与机器人第一视角观测之间的鸿沟。

🛠 **方法**：提出 NaViRrator 框架，其核心 RouteScribe 方法将路径推理与语言表达分离——先用起点-终点线条件流匹配（SGL-CFM）在图像坐标中生成显式路径骨架，再由预训练视觉-语言模型（VLM）将其转化为导航指令，执行时 VLN 策略仅接收指令和第一视角观测。

✨ **主要贡献**：通过"路径骨架"作为模块化接口，实现了地图到语言模块与执行器的解耦（更换执行器无需重训练）；真实世界实验表明其成功率和 SPL 均优于直接地图生成指令、A* 骨架及高斯源条件流匹配等基线，并生成更清晰的显著转向和更准确的机动序列。

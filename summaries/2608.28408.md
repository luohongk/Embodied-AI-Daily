# SymboLLM-FE: LLM-Accelerated Symbolic Regression for Automated Feature Engineering on Tabular Data

- arXiv: https://arxiv.org/abs/2608.28408v1
- arXiv ID: 2608.28408

---

🔍 **核心问题**：表格数据特征信息不足导致模型性能受限，现有AutoFE方法存在特征可解释性差（盲目数学变换）或需多轮迭代且易产生偏差/幻觉（LLM方法）的问题。

🛠 **方法**：提出SymboLLM-FE框架，先用符号回归提取与目标强相关且数学表达清晰的公式特征，再利用LLM基于统计先验进行单次精炼，确保特征可解释性并减少迭代次数。

✨ **主要贡献**：在6个真实数据集和4个Kaggle竞赛上超越现有AutoFE方法；通过统计先验引导的LLM精炼机制和极少量LLM调用（个位数），同时解决可解释性差和迭代成本高的双重挑战。

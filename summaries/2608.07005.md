# Real-time Whole-Body Motion Planning for Mobile Manipulators Carrying Arbitrarily Shaped Payloads via Kinematically-Coupled SVSDF

- arXiv: https://arxiv.org/abs/2608.07005v1
- arXiv ID: 2608.07005

---

🔍 **核心问题**：移动机械臂在杂乱环境中搬运大型非凸载荷时，现有规划器要么简化载荷几何，要么忽略机械臂连杆间的运动耦合，导致可行空间丢失或优化停滞。

🛠 **方法**：提出实时全身运动规划框架，前端采用链分解核基碰撞检测保留真实几何；中端预处理将路径转为平滑可行轨迹并直接执行；后端基于运动耦合SVSDF（KC-SVSDF）进行轨迹优化，沿运动链传播避障梯度。

✨ **主要贡献**：通过KC-SVSDF实现全身一致避障方向，在差分驱动移动机械臂上验证了可靠穿越狭窄通道和杂乱环境的能力，消融实验和对比基准均优于现有方法。

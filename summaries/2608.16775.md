# Topological Attribution Distance (TAD): Revealing Segment-Level RAG Influence on LLM Output Geometry for Incident Log Analysis

- arXiv: https://arxiv.org/abs/2608.16775v1
- arXiv ID: 2608.16775

---

🔍 **核心问题**：在网络安全运营中，LLM生成结果的可信度与证据溯源不足，现有方法难以区分复杂且高度相似的证据源（如网络事件日志），无法有效验证检索证据与生成响应之间的整体几何关系。

🛠 **方法**：提出拓扑归因距离（TAD），基于拓扑学思想，通过段级消融归因分析，量化每个检索日志对LLM输出在嵌入空间中全局几何形状的影响，从而识别关键证据源。

✨ **主要贡献**：TAD能自适应地找出对LLM输出影响最大的日志段，提供基于隐藏状态的可解释、可信溯源，适用于网络安全和Agentic-AI工作流中的证据验证，弥补了现有方法在几何关系捕捉上的不足。

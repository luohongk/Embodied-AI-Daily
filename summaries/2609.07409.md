# RAFM-SER++: A Lightweight Multimodal Emotion Recognition Framework for Real-Time Behavioral Monitoring in Surveillance Systems

- arXiv: https://arxiv.org/abs/2609.07409v1
- arXiv ID: 2609.07409

---

🔍 **核心问题**：多模态语音情感识别系统因依赖高计算量的跨模态交互Transformer，难以部署在资源受限、对延迟敏感的实时监控系统中。

🛠 **方法**：提出RAFM_SER++轻量级框架，采用非对称残差注意力融合机制（RAFM），通过单向残差注意力路径将情感语音特征注入语义文本表示，并结合BYOL启发的跨模态对齐目标和注意力引导池化。

✨ **主要贡献**：在IEMOCAP和ESD基准上，RAFM_SER++相比HuBERT-Base基线持续提升性能，且比SOTA方法MemoCMT减少60%以上可训练参数，推理速度达79.60 it/s，BACC分别达81.10%和95.39%，证明轻量级非对称融合是交互密集型跨模态Transformer在实时监控中的有效替代方案。

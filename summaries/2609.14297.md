# Multi-Task Visual Perception Network with LLM Conditioning for Autonomous Navigation

- arXiv: https://arxiv.org/abs/2609.14297v1
- arXiv ID: 2609.14297

---

🔍 **核心问题**：服务机器人长期导航中，里程计漂移和传感器误差会逐渐累积，导致2D地图退化，使传统路径规划算法（如A*、RRT*、DiPPer、ViT-A*）随时间失效。

🛠 **方法**：提出一种用户友好的交互式框架，将视觉感知与大语言模型（LLM）结合，通过文本或语音解析用户指令，基于局部视觉线索和以自我为中心的几何指令生成序列动作计划，并采用相对即时目标重置定位的最小漂移累积策略，摆脱对全局一致地图的依赖。

✨ **主要贡献**：无需维护全局地图即可实现准确、高效、无碰撞的导航，支持已知和未知环境，在真实世界和仿真实验中显著优于其他方法，源代码已公开。

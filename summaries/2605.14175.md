# Grounded Continuation: A Linear-Time Runtime Verifier for LLM Conversations

- arXiv: https://arxiv.org/abs/2605.14175v2
- arXiv ID: 2605.14175

---

🔍 **核心问题**：长对话中LLM可能基于已被废弃的前提生成看似合理的续写，而现有运行时检查无法将其输出与对话已确立的内容绑定，这一缺口被上下文操纵攻击所利用。

🛠 **方法**：提出运行时验证器，由LLM Interpreter将每句话分类为八种认知操作，符号引擎将其应用于依赖图（记录每个断言所依赖的前提及其是否仍成立）；续写是否有据可依归结为对图的线性遍历，无需调用LLM，撤回操作也沿同一图传播并保证无冲突。

✨ **主要贡献**：在ReviseQA和MemoryAgentBench上超越预算匹配的检索基线，将单跳准确率从0.46–0.95提升至0.93–0.98，使7B模型超过未辅助的GPT-4o；用GPT-4o从原始文本提取更新时准确率无统计差异，且每查询成本随对话长度保持恒定（提示约0.8k token，2000轮时撤回查询低于1微秒）。

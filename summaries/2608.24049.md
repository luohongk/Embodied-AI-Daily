# Physics-Integrated Operator Learning via Gaussian Splatting Representations

- arXiv: https://arxiv.org/abs/2608.24049v1
- arXiv ID: 2608.24049

---

🔍 **核心问题**：纯数据驱动的神经算子模型在长时间自回归预测中误差累积严重，且难以有效利用已知的偏微分方程（PDE）结构信息。

🛠 **方法**：提出一种表示层面的物理融合方法，使用前馈高斯溅射（FFGS）表示将离散解场重构为连续高斯场，其闭式空间导数可直接嵌入学习到的演化映射中，无需引入物理残差损失。

✨ **主要贡献**：在2D和3D多种PDE系统（平流、扩散、非线性自平流、反应动力学）上，相比最强纯数据基线，长时程预测相对ℓ2误差降低1.5–2.2倍，并持续提升谱保真度；在方程部分已知时仍保持鲁棒性，证明连续场表示可作为通用神经算子代理融合物理结构的实用接口。

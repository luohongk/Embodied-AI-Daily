# Multi-Representation Geometric Hierarchy Fusion: An Implicit-Submap Driven Framework for Resilient 3D Place Recognition

- arXiv: https://arxiv.org/abs/2506.14243v4
- arXiv ID: 2506.14243

---

🔍 **核心问题**：解决LiDAR在无GPS环境下进行3D地点识别时，因点云密度变化和单一几何表征导致的描述子不稳定与表示脆弱问题。

🛠 **方法**：提出一种多表征几何层次融合框架，引入隐式弹性神经点表示以降低输入密度影响，并从中提取占据栅格和法向量，融合鸟瞰宏观布局与3D簇微观表面几何构建描述子。

✨ **主要贡献**：在KITTI、KITTI-360、MulRan和NCLT等数据集上验证，该方法在识别精度、运行效率和内存占用间取得良好平衡，并在密度变化和视角变化下表现出更强的鲁棒性，优于多种手工和基于学习的基线方法。

# HuMemSLAM: Efficient Human-Inspired Semantic Place Recognition for Robust Visual SLAM

- arXiv: https://arxiv.org/abs/2609.17168v1
- arXiv ID: 2609.17168

---

🔍 **核心问题**：传统几何视觉SLAM依赖低层特征，易受感知歧义（不同地点外观相似）和感知变化（同一地点外观不同）影响，而现有语义SLAM与学习式VPR方法虽提升鲁棒性，却难以兼顾高检索精度与低延迟的实时部署需求。

🛠 **方法**：受人类记忆与感知启发，提出HuMem-VPR，利用自下而上的感知证据与自上而下的上下文推理之间的双向关系实现高层地点理解，并将其与ORB-SLAM3集成形成HuMemSLAM。

✨ **主要贡献**：HuMem-VPR在真实图像基准上取得最高综合检索精度，在CARLA基准上具竞争力，延迟比所评估的SOTA VPR方法低约2-3倍；HuMemSLAM在多个数据集和在线实验中显著提升集成Recall@1，同时减少提交给几何后端的候选数量。

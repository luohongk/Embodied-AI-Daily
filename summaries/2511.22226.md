# Embedded Universal Predictive Intelligence: a coherent framework for multi-agent learning

- arXiv: https://arxiv.org/abs/2511.22226v3
- arXiv ID: 2511.22226

---

🔍 **核心问题**：传统无模型强化学习假设环境静态且智能体与环境解耦，在多智能体场景中无法应对其他智能体学习导致的非平稳性，也缺乏对自身作为环境一部分的建模。

🛠 **方法**：基于通用人工智能（AIXI）理论，提出一个以自预测为核心的贝叶斯强化学习框架，智能体同时预测未来感知输入和自身动作，并利用Solomonoff先验处理关于自身的认知不确定性。

✨ **主要贡献**：首次将嵌入式智能体与自预测结合，证明该框架能使智能体推理其他智能体运行相似算法，实现无限阶心智理论和新型合作，为嵌入式多智能体学习设立了理论基准。

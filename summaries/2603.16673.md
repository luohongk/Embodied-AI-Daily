# When Should a Robot Think? Resource-Aware Reasoning via Reinforcement Learning for Embodied Robotic Decision-Making

- arXiv: https://arxiv.org/abs/2603.16673v5
- arXiv ID: 2603.16673

---

🔍 **核心问题**：具身智能体在决策时面临“何时推理、何时行动”的困境——过度推理会延迟动作执行，而推理不足则导致决策错误和任务失败。

🛠 **方法**：提出RARRL（基于强化学习的资源感知推理）框架，学习一个高层编排策略，在决策层动态决定是否调用推理、选择推理角色以及分配计算预算，而非学习底层控制策略。

✨ **主要贡献**：在ALFRED基准上结合真实延迟配置的实验表明，RARRL相比固定或启发式推理策略，能持续提升任务成功率、降低执行延迟并增强鲁棒性，证明自适应推理控制对构建可靠高效的具身智能体至关重要。

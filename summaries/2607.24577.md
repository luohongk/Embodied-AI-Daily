# Evaluating Fuzz Testing for Reinforcement Learning Agents

- arXiv: https://arxiv.org/abs/2607.24577v1
- arXiv ID: 2607.24577

---

🔍 **核心问题**：现有强化学习模糊测试方法缺乏统一评估框架，难以比较其有效性和实用性。  
🛠 **方法**：在三个复杂度递增的环境（MountainCar、BipedalWalker、CARLA）中，对五种先进模糊测试方法与随机测试进行统一配置下的系统性对比评估。  
✨ **主要贡献**：揭示了不同方法在崩溃发现效率、行为多样性、鲁棒性提升及安全监控中的互补优势，并提出了结合多策略与多层级多样性分析的实践指南。

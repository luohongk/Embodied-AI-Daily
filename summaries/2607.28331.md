# Structural Validation of LLM-Generated Microservice Decompositions Using Source-Code Dependencies

- arXiv: https://arxiv.org/abs/2607.28331v1
- arXiv ID: 2607.28331

---

🔍 **核心问题**：评估LLM生成的微服务拆分方案是否真正保留了源代码中的结构依赖关系，而非仅凭语义合理性。

🛠 **方法**：提出基于静态依赖分析的自动化验证流水线，对OpenAI o3生成的PetClinic和Bookstore系统拆分方案进行结构一致性评估，并对比零样本与少样本提示策略，同时通过鲁棒性分析控制类到服务映射覆盖率的差异。

✨ **主要贡献**：发现归一化后两种提示策略的结构一致性相当（TPD分别为68.0%和83.3%），并证明结构评估必须显式控制映射覆盖率，否则提示策略间的表观差异可能源于方法偏差而非真实架构质量。

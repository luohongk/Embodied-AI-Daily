# CORF-GS: Real-Time Wireless Radiance Field Reconstruction via Coupled Optical-RF Gaussian Splatting

- arXiv: https://arxiv.org/abs/2607.25569v1
- arXiv ID: 2607.25569

---

🔍 **核心问题**：现有无线辐射场（WRF）重建方法依赖预采集数据和离线优化，无法实现实时信道知识更新。

🛠 **方法**：提出CORF-GS框架，通过耦合光学与射频（RF）高斯溅射，利用光学图像提供结构先验，并结合光学引导采样与联合优化，实时处理顺序关键帧。

✨ **主要贡献**：实现了实时WRF重建，RF频谱合成质量达到最优，且重建时间比现有方法减少6.4倍。

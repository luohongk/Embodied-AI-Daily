# FillGS: Filling Observation Gaps in 4D Gaussian Splatting via Viewpoint-Time Selection and Generative Refinement

- arXiv: https://arxiv.org/abs/2607.29284v1
- arXiv ID: 2607.29284

---

🔍 **核心问题**：4D高斯泼溅（4DGS）在视角覆盖有限时，动态场景中部分时空区域观测稀疏，导致渲染出现伪影，尤其在运动较大的场景中。

🛠 **方法**：提出一种主动选择时空虚拟视角的流程，基于渲染敏感性和运动感知的观测密度挑选虚拟视角，利用生成模型增强这些视角的渲染结果，并过滤与真实观测冲突或可能含生成伪影的区域，仅用可靠区域微调4DGS。

✨ **主要贡献**：在多个多视角视频基准上，通过新划分的训练/测试集验证，该方法在定性和定量评估中均优于先前的视角选择策略和微调方法，有效减少伪影并提升动态场景重建质量。

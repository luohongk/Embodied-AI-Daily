# Length-Controlled Margin-Based Preference Optimization without Reference Model

- arXiv: https://arxiv.org/abs/2502.14643v3
- arXiv ID: 2502.14643

---

🔍 **核心问题**：Direct Preference Optimization (DPO) 在基于人类反馈的强化学习中存在长度偏差、内存效率低和概率退化等问题，限制了其训练效果和稳定性。

🛠 **方法**：提出 Length-Controlled Margin-Based Preference Optimization (LMPO)，引入统一参考模型作为 DPO 损失的上界，采用平均对数概率优化策略，并设计基于 Bradley-Terry 框架的长度控制边际损失函数，以同时调节响应长度和扩大偏好差距。

✨ **主要贡献**：LMPO 有效控制响应长度、减少概率退化，并在 Mistral 和 LLaMA3 两个开源大语言模型的六个条件基准上优于现有偏好优化方法，代码已开源。

# Scene Parameter Saliency via Differentiable Light Transport

- arXiv: https://arxiv.org/abs/2607.21562v1
- arXiv ID: 2607.21562

---

🔍 **核心问题**：如何通过可微渲染技术，识别场景中哪些参数对特定图像指标（如亮度、感知分数）影响最大，从而解释场景属性与视觉结果之间的因果关系。

🛠 **方法**：利用可微渲染器对渲染图像上的任意标量指标进行反向传播，计算每个场景参数的梯度，生成“度量显著性图”，将参数重要性从神经网络权重传播扩展到物理光传输过程。

✨ **主要贡献**：首次将可微渲染的梯度视为场景参数显著性工具，证明不同指标（如眩光指数、平均亮度、神经感知分数）会产生截然不同的显著性排序，且显著性依赖于指标而非场景固有属性，为场景理解和可解释性提供了新视角。

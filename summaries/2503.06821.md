# HierDAMap: Towards Universal Domain Adaptive BEV Mapping via Hierarchical Perspective Priors

- arXiv: https://arxiv.org/abs/2503.06821v2
- arXiv ID: 2503.06821

---

🔍 **核心问题**：针对BEV（鸟瞰图）映射模型在无标注真实世界场景中因域差异导致的性能下降问题，现有无监督域适应研究仅关注图像级学习，无法普适地支持所有BEV映射任务。

🛠 **方法**：提出HierDAMap框架，从全局、稀疏和实例三个层级利用透视先验知识，包含三个核心组件：语义引导的伪监督（SGPS）通过视觉基础模型生成2D伪标签约束特征分布；动态感知一致性学习（DACL）利用不确定性感知的预测深度生成动态BEV标签；跨域视锥混合（CDFM）通过视锥掩码混合双域多视角图像，引导跨域视图变换学习。同时引入域内特征交换数据增强。

✨ **主要贡献**：首次提出通用且整体的BEV域适应框架，从三个层级系统性地利用透视先验，有效缓解空间变化导致的特征分布差异，提升跨域BEV映射性能。代码将开源。

# FormuEvo: LLM-Guided Evolution for Discovering Solver-Efficient Mixed-Integer Programming Formulations

- arXiv: https://arxiv.org/abs/2608.23353v1
- arXiv ID: 2608.23353

---

🔍 **核心问题**：混合整数规划（MIP）在运筹优化中至关重要，但现有LLM自动建模仅关注语义正确性，忽视公式强度，导致下游求解器效率低下。

🛠 **方法**：提出FormuEvo框架，将MIP公式设计视为符号空间上的进化优化，通过LLM驱动的交叉、变异和修复操作迭代生成、评估和选择更强候选公式，并引入求解器统计信息作为“语言梯度”进行定向改进，同时用结构化记忆积累可复用策略。

✨ **主要贡献**：在多种线性和非线性问题上，FormuEvo发现的公式比专家设计和现有LLM方法显著更优，求解器加速最高达5.5倍，且蒸馏知识可跨问题和小模型零样本迁移，展示了LLM引导进化的强大潜力。

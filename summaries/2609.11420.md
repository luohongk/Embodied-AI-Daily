# Deep Learning-based Bug Triage System

- arXiv: https://arxiv.org/abs/2609.11420v1
- arXiv ID: 2609.11420

---

🔍 **核心问题**：如何自动化地对软件缺陷报告进行准确分类与分配，以提升软件开发流程的效率。

🛠 **方法**：基于预训练的RoBERTa-base Transformer架构，利用深度上下文表示对缺陷报告进行自动分类。

✨ **主要贡献**：所提系统仅需5个训练轮次即达到0.90的缺陷识别准确率，验证了微调Transformer模型在软件工程自动化中的高效性与高性能。

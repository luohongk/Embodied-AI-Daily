# Can LLMs Design Video Coding Tools? A Case Study on Planar Mode

- arXiv: https://arxiv.org/abs/2609.01535v1
- arXiv ID: 2609.01535

---

🔍 **核心问题**：探索大语言模型（LLMs）能否自主设计视频编码工具，以Planar模式为案例验证其可行性。

🛠 **方法**：采用“生成-评估”循环，LLM生成Planar预测器，编码器测试性能，再根据反馈迭代优化；在VVenC和ECM两种编码器上分别测试直接替换与新增模式两种集成策略。

✨ **主要贡献**：首次实证表明LLM生成的Planar模式在VVenC上可节省0.18%码率且仅增加0.4%复杂度；在ECM上两种集成策略在低分辨率下均能获得编码增益，为LLM辅助编码工具设计提供了初步证据与实践洞见。

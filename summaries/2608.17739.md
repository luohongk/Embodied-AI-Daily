# Offline Multi-Agent Reinforcement Learning with a Physics-Informed World Model for Cooperative Mixed Traffic Control

- arXiv: https://arxiv.org/abs/2608.17739v1
- arXiv ID: 2608.17739

---

🔍 **核心问题**：在部分可观测的混合交通高速公路瓶颈场景中，如何在不依赖完整全局交通状态或在线试错的情况下，实现联网自动驾驶车辆（CAVs）的协同控制以缓解拥堵。

🛠 **方法**：提出一种基于物理信息世界模型的离线多智能体强化学习框架，从局部CAV观测-动作历史重建物理可解释的全局交通状态，利用宏观-微观耦合交通动力学提供物理监督；采用概率集成世界模型学习状态转移与奖励，并通过模型分歧量化认知不确定性，结合悲观奖励与不确定性截断的多步想象轨迹进行离线策略学习。

✨ **主要贡献**：在SUMO仿真匝道瓶颈场景中，使用约100万条离线转移数据验证了物理监督能显著提升状态重建精度与世界模型预测准确性，为混合交通下的离线协同控制提供了可行方案。

# REFINE-DP: Diffusion Policy Fine-tuning for Humanoid Loco-manipulation via Reinforcement Learning

- arXiv: https://arxiv.org/abs/2603.13707v3
- arXiv ID: 2603.13707

---

🔍 **核心问题**：人形机器人 locomotion-manipulation 任务中，离线训练的扩散策略（DP）运动规划器与操作控制器解耦，导致命令跟踪差、分布偏移和任务失败，且扩大演示数据成本过高。

🛠 **方法**：提出 REFINE-DP 分层框架，联合优化 DP 运动规划器和基于强化学习（RL）的操作控制器。DP 通过 PPO 扩散策略梯度微调以提升任务成功率，控制器同步更新以准确跟踪规划器演化的命令分布，减少分布不匹配。

✨ **主要贡献**：在仿真中实现超 90% 成功率（含预训练未见分布外场景），并支持无特权状态信息的真实世界执行；显著优于预训练 DP 基线，证明 RL 微调是人形机器人可靠操作的关键。

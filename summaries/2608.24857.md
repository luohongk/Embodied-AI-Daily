# Prompt Structure Redistributes, Not Reduces: An Empirical Analysis of Security-Weaknesses in LLM-Generated Python Code

- arXiv: https://arxiv.org/abs/2608.24857v1
- arXiv ID: 2608.24857

---

🔍 **核心问题**：探究结构化与安全导向的提示词（prompt）对LLM生成Python代码安全性的实际影响，尤其是其是否真正减少安全弱点，而非仅改变弱点分布。

🛠 **方法**：使用GPT-4o和LLaMA 3.1-8B，在424个安全敏感Python任务上，采用5种逐步增加结构与安全指导的提示词变体生成代码，并用Bandit和CodeQL评估生成合规性及弱点普遍性、严重性和CWE分布。

✨ **主要贡献**：发现结构化提示显著减少模型拒绝输出（GPT-4o无效输出从338/424降至37-52），但安全导向提示并未一致降低弱点总数；对GPT-4o，更强提示主要将高风险弱点转移为低风险（高风险从20.8%降至13.6%，低风险从32%升至43.5%），并引发安全驱动的语义漂移（静默移除或改写不安全构造），表明提示工程无法替代稳健的安全控制。

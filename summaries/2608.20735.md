# ForeTime-VLA: Causal Future-Token Distillation from a World Action Model for Conveyor-Belt Manipulation

- arXiv: https://arxiv.org/abs/2608.20735v1
- arXiv ID: 2608.20735

---

🔍 **核心问题**：解决视觉-语言-动作（VLA）策略在传送带动态物体操控中缺乏未来感知能力的问题，现有方法仅依赖当前观测，难以预测接触事件。

🛠 **方法**：提出ForeTime-VLA，从冻结的Fast-WAM世界动作模型中蒸馏出未来感知的动作等价表征，通过压缩未来视频潜变量为64维目标，结合历史编码器预测未来token和相位信息，并加入多种训练目标（余弦、关系几何、相位、时间转换等）。

✨ **主要贡献**：在传送带数据集上测试MAE降低2.63%、L2降低3.02%，真实机器人抓取成功率在静止和慢速场景分别达81.1%和58.9%，比次优方法高12.2和22.2个百分点；快速场景抓取数从2/30提升至11/30，验证了因果未来token蒸馏在不部署世界模型的情况下有效提升动态操控性能。

# CSI Prediction Using Diffusion Models

- arXiv: https://arxiv.org/abs/2510.11214v2
- arXiv ID: 2510.11214

---

🔍 **核心问题**：无线通信中信道状态信息（CSI）的获取面临导频开销高和信道老化问题，现有深度学习方法仅学习确定性映射，难以捕捉无线信道的随机性和多模态特性。

🛠 **方法**：提出基于扩散模型的CSI预测概率框架，将任务分解为时间编码器（提取信道动态）和扩散生成器（生成未来CSI），并探索自回归、序列到序列两种推理方案及U-Net、Transformer等扩散骨干网络。

✨ **主要贡献**：首次将扩散模型用于CSI预测，支持灵活集成多种预测方案，通过DDIM调度降低模型复杂度，实验表明该方法显著优于现有最先进基线。

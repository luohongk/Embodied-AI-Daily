# Lightweight 3D Object Detection via Mamba-Based Knowledge Distillation

- arXiv: https://arxiv.org/abs/2608.03490v1
- arXiv ID: 2608.03490

---

🔍 **核心问题**：针对LiDAR三维目标检测在嵌入式设备上计算开销大、精度与效率难以平衡的问题，提出一种轻量化方案。

🛠 **方法**：采用基于Mamba的知识蒸馏框架，通过多分支Mamba教师网络提取体素特征，并利用盒感知特征传递机制，在体素空间中对齐教师与学生网络的特征，实现轻量学生模型的高效训练。

✨ **主要贡献**：显著降低计算负载，同时在公开数据集和真实数据上保持与最先进方法相当的检测精度，验证了Mamba在三维检测蒸馏中的有效性。

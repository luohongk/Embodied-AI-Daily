# Beyond Zooming: Learning Multi-Tool Visual Reasoning for Ultra-High-Resolution Remote Sensing

- arXiv: https://arxiv.org/abs/2607.25993v1
- arXiv ID: 2607.25993

---

🔍 **核心问题**：超高分辨率遥感图像中，任务相关证据稀疏、局部且分散，现有多模态大模型仅依赖“缩放”工具难以处理需要全局搜索、多区域比较或路径规划等复杂推理任务。

🛠 **方法**：提出GeoMTVR数据集（含1.3万超高分辨率VQA样本及多工具推理轨迹），并设计基于工具注意力的强化学习算法，优化工具调用时机、选择、应用区域及输出解读，最终训练出多工具视觉推理模型GeoLens。

✨ **主要贡献**：构建首个大规模多工具视觉推理遥感数据集，提出结合监督微调与工具注意力强化学习的训练框架，GeoLens在精度、证据定位和工具使用效率上均优于直接推理和单工具缩放基线。

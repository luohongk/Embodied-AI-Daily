# Latent Cluster Analysis for Vision-Language-Action Models

- arXiv: https://arxiv.org/abs/2609.02634v1
- arXiv ID: 2609.02634

---

🔍 **核心问题**：视觉-语言-动作（VLA）模型在机器人控制中表现优异，但其内部表征机制尚不明确，缺乏系统性的可解释性分析。

🛠 **方法**：提出LAVLA框架，对GR00T N1.5模型进行逐层潜在聚类分析，并引入基于交叉注意力的嵌入加权方法，以增强动作扩散过程中的关键特征、抑制无关信息。

✨ **主要贡献**：加权聚类显著优于基线，且聚类结果可映射为人类可理解的概念；发现潜在表征在中间层逐步解耦时空与运动学特征，并向输出层趋于稳定，推进了语言驱动机器人系统的可解释性研究。

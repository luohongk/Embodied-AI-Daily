# ReForce: Learning Force-aware Retargeting for Dexterous Manipulation

- arXiv: https://arxiv.org/abs/2608.15560v1
- arXiv ID: 2608.15560

---

🔍 **核心问题**：解决人形演示到机器人灵巧操作迁移中的“具身差异”问题，现有重定向方法仅关注运动学而忽略力信息，导致接触交互不准确。

🛠 **方法**：提出ReForce，一种力感知重定向方法，在运动学重定向动作上预测残差以匹配目标力，利用大规模仿真交互训练的通用力跟踪器，支持在线力感知遥操作和离线数据转换。

✨ **主要贡献**：在接触密集任务（如纸杯抓取和镊子操作）中，ReForce在仿真和真实硬件上均实现更低的力跟踪误差和更强的多指接触参与度，验证了力信息在灵巧操作重定向中的关键作用。

# Cognitive World Model for Progressive BDI/E Trajectory Evaluation of Conversational Agents

- arXiv: https://arxiv.org/abs/2606.29495v2
- arXiv ID: 2606.29495

---

🔍 **核心问题**：现有对话智能体评估仅关注表面回答或最终结果，缺乏对用户内部认知状态（信念、欲望、意图、情绪，即BDI/E）演变的建模，难以诊断智能体成败原因并优化交互策略。

🛠 **方法**：提出认知世界模型（CogWM），一种基于LLM的认知用户模拟器，联合建模用户的BDI/E状态与对应回复，实现显式认知轨迹追踪；使用Qwen3-14B在15万用户轮次样本上训练。

✨ **主要贡献**：CogWM在回复保真度和认知状态理解上优于现有用户模拟基线；与六个先进LLM的交互实验表明，它能通过认知轨迹对智能体进行渐进式比较，揭示不同智能体的行为模式及认知演变与行为结果之间的互补关系。

# CSV-Decode: Certifiable Sub-Vocabulary Decoding for Efficient Large Language Model Inference

- arXiv: https://arxiv.org/abs/2511.21702v2
- arXiv ID: 2511.21702

---

🔍 **核心问题**：大语言模型推理时，因输出层需计算整个词汇表（通常数万词）而导致显著的计算瓶颈。

🛠 **方法**：提出CSV-Decode方法，通过几何上界（质心加半径）离线聚类词汇嵌入，在每步解码时动态构建小型子词汇表，仅对候选词进行稀疏计算，并配合稀疏GEMV内核、多GPU分片和CUDA图优化实现高效推理。

✨ **主要贡献**：在保证双重正确性（精确top-k认证和ε-认证的softmax近似）的前提下，显著加速推理速度，同时保持极低的回退率，并提供完整开源实现。

# LabelMate: An LLM-Driven Framework for Refined Issue Report Labeling

- arXiv: https://arxiv.org/abs/2609.04055v1
- arXiv ID: 2609.04055

---

🔍 **核心问题**：软件问题报告（issue report）常因人工标注成本高而缺乏标签，现有自动化标注方法依赖预标注数据、标签过于通用且需大量人工干预。

🛠 **方法**：提出LabelMate框架，利用大型语言模型（LLM）从历史问题报告中自动推导项目专属标签集，并自动为新报告分配标签，无需任何预标注训练数据。

✨ **主要贡献**：在30个GitHub仓库的16,500份问题报告上，生成275个连贯标签，平均标注准确率达89.84%，显著优于现有通用标签方法，展示了高效且领域自适应的解决方案。

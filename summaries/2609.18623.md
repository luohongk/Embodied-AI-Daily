# FIVE-VLA: Fast and EffectIVE Autonomous Driving with Recurrent Action Memory

- arXiv: https://arxiv.org/abs/2609.18623v1
- arXiv ID: 2609.18623

---

🔍 **核心问题**：现有自动驾驶VLA模型参数过多、高分辨率图像处理效率低，且缺乏时序记忆能力。

🛠 **方法**：采用高效视觉编码器（448×896图像仅生成98个token，跳过文本生成直接预测轨迹），并提出循环动作记忆（RAM）模块，基于历史动作token提供时序上下文。

✨ **主要贡献**：仅641M参数即在Bench2Drive闭环基准上无违规完成路线数提升约10%，开环仿真碰撞率优于SimLingo，并在A100/T4上实现8-30倍推理加速。

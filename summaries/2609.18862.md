# CASHEWS: Source Preprocessor for LLM-based Malicious Package Detection

- arXiv: https://arxiv.org/abs/2609.18862v1
- arXiv ID: 2609.18862

---

🔍 **核心问题**：恶意npm包检测工具依赖LLM分析源代码，但攻击者利用代码混淆、高token密度以及与良性代码捆绑等手段，使LLM因上下文窗口受限而跳过大型文件或漏检恶意行为，形成检测规避面。

🛠 **方法**：CASHEWS是一个JavaScript预处理器，通过迭代解码去混淆、提取捆绑模块与动态执行代码、识别恶意sink并计算反向切片，同时对长字面量和标识符进行缩写，生成紧凑的代码表示供检测器分析。

✨ **主要贡献**：在512个大型包文件、两种扫描器和三种LLM上，CASHEWS将分析覆盖率从69.1–85.7%提升至98.8–100%，假阴性率最多降低18.6个百分点，中位预处理时间仅30秒，净分析成本降低34.6%，使全注册表规模的LLM恶意包检测更实用。

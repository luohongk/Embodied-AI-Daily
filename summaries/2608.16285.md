# Audio-Visual Segmentation via Depth-Guided Collaborative Modeling

- arXiv: https://arxiv.org/abs/2608.16285v1
- arXiv ID: 2608.16285

---

🔍 **核心问题**：现有音视频分割（AVS）方法未显式建模深度等几何线索（如相对距离和遮挡），导致跨模态对齐鲁棒性不足，难以准确分割发声物体。

🛠 **方法**：提出三模态框架DGCM-AVS，引入估计深度作为空间结构线索；设计深度感知动态调制器（Depth-Aware Dynamic Modulator）以区分邻近物体并保持物体内部一致性，并采用深度引导渐进融合（Depth-Guided Progressive Fusion）将深度作为桥梁逐步对齐音频与视觉特征。

✨ **主要贡献**：首次将深度作为显式模态用于AVS，在AVSS数据集上相对最优方法，M_J提升10.2%，M_F提升8.7%，验证了深度作为AVS中未充分探索模态的潜力。

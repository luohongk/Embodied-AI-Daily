# AppDeltaWorld: Transition-Grounded Delta Code World Model for Mobile GUI Agents

- arXiv: https://arxiv.org/abs/2608.05891v1
- arXiv ID: 2608.05891

---

🔍 **核心问题**：移动GUI智能体在真实应用中难以获取敏感场景的交互轨迹，而现有模拟环境扩展成本高，GUI世界模型存在生成不稳定、模态覆盖有限和动作-转换逻辑不一致的问题。

🛠 **方法**：提出AppDeltaWorld，一种基于转换约束的增量代码世界模型。它检索应用特定的Level-1 HTML参考，在动作-转换约束下生成Level-2可执行HTML，并将生成的视觉资产插入图像槽位后通过浏览器渲染，从而将下一GUI预测为可达的代码更新而非无约束的图像或文本。

✨ **主要贡献**：在CMGUIBench-500上取得最高保真度，结构布局和UI元素重建显著优于仅图像和仅代码基线；作为训练环境，支持过滤的闭环SFT数据构建，使AppDeltaAgent在AndroidLens上达到SOTA性能，并在MobileGym和MobileWorld上持续提升；基于世界模型的测试时强化学习无需真实应用交互即可实现策略自适应和进一步改进。

# Natural Language Access to Domain-Specific Metadata: A Reusable Framework for LLM Query Generation

- arXiv: https://arxiv.org/abs/2607.18029v2
- arXiv ID: 2607.18029

---

🔍 **核心问题**：研究者需要查询领域特定档案的元数据，但往往缺乏编写结构化查询（如SPARQL）的专业知识，难以进行即席提问。

🛠 **方法**：提出NLKGQ框架，先用OWL本体捕获领域词汇与语义，再通过领域无关的LLM组件将自然语言问题翻译为SPARQL并在知识图谱上执行，无需微调、检索增强或多智能体编排。

✨ **主要贡献**：在神经影像档案元数据上验证，最佳配置在21题测试集上达到100%准确率；消融实验表明可读实体名和语义标注是准确率的主导因素（比模型选择和提示工程更重要），且OWL结构相比SQL DDL对LLM查询生成有显著优势。

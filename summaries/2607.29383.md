# Exploring Block Anomaly Detection In HDFS Log Data Analysis

- arXiv: https://arxiv.org/abs/2607.29383v1
- arXiv ID: 2607.29383

---

🔍 **核心问题**：针对HDFS分布式文件系统日志量大、非结构化且人工排查异常效率低的问题，提出自动化检测日志块异常的方法。

🛠 **方法**：结合自然语言处理与机器学习技术，构建LLM-BiLSTM混合深度学习模型，并基于Kafka搭建流式日志处理管道，利用并行计算处理历史日志。

✨ **主要贡献**：提出了一套完整的流式HDFS日志块异常检测工作流，能够实时、准确地定位系统异常，显著提升运维人员故障排查效率。

# AuthorMix: Modular Authorship Style Transfer via Layer-wise Adapter Mixing

- arXiv: https://arxiv.org/abs/2603.23069v4
- arXiv ID: 2603.23069

---

🔍 **核心问题**：作者风格迁移需在改写文本以匹配目标作者风格的同时保留原意，而现有方法用单一模型一次性建模所有风格，成本高、灵活性差，且常以牺牲语义为代价换取风格迁移。

🛠 **方法**：AuthorMix 先在高资源作者上分别训练风格专属的 LoRA 适配器，再通过强化学习进行逐层适配器混合，仅需少量目标风格样本即可快速适配新作者。

✨ **主要贡献**：提出轻量、模块化、可解释的风格迁移框架，在风格-语义综合得分上超越包括 GPT-5.1 在内的所有基线，显著提升语义保留，且在人工评估中各维度均达到最优或并列最优。

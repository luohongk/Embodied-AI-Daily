# VLC Fusion: Vision-Language Conditioned Sensor Fusion for Robust Object Detection

- arXiv: https://arxiv.org/abs/2505.12715v2
- arXiv ID: 2505.12715

---

🔍 **核心问题**：现有传感器融合方法在环境变化（如黑暗、雨天、相机模糊）下难以自适应调整各模态权重，导致目标检测性能下降。

🛠 **方法**：提出VLC Fusion框架，利用视觉-语言模型（VLM）提取高层环境语义线索，据此动态调节图像、LIDAR和红外等模态的融合权重。

✨ **主要贡献**：在真实自动驾驶和军事目标检测数据集上，VLC Fusion在已知和未知场景下均优于传统融合基线，显著提升检测精度，并展现出对环境变化的强鲁棒性。

# LogitScope: A Framework for Analyzing LLM Uncertainty Through Information Metrics

- arXiv: https://arxiv.org/abs/2603.24929v2
- arXiv ID: 2603.24929

---

🔍 **核心问题**：大语言模型（LLM）在生成过程中，传统评估方法难以量化每个token位置上的模型置信度，导致无法有效识别不确定性高的决策点和潜在幻觉。

🛠 **方法**：提出LogitScope框架，通过从概率分布中计算逐token的信息度量（如熵和方差熵），在生成每一步实时分析模型不确定性，无需标注数据或语义解释。

✨ **主要贡献**：该框架是模型无关的，采用惰性计算实现高效运行，兼容所有HuggingFace模型，可应用于不确定性量化、模型行为分析和生产监控，为研究人员和从业者提供了推理时检查LLM行为的轻量工具。

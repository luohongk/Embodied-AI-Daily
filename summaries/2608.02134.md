# Messages, Not Tokens: Grounded Coresets for Faithful VLM Compression

- arXiv: https://arxiv.org/abs/2608.02134v1
- arXiv ID: 2608.02134

---

🔍 **核心问题**：视觉语言模型（VLM）将高分辨率图像转换为长序列视觉token，导致推理成本高昂。现有Top-K剪枝方法独立评估每个token，忽略了文本查询依赖的集体、带符号的注意力消息，可能重复覆盖同一显著区域、遗漏互补证据并丢失被移除token的信息。

🛠 **方法**：提出无训练的**Grounded Message Coreset Pruning (GMC)**，将视觉压缩视为构建解码器消息的紧凑核心集。GMC联合分配查询锚定、外观和坐标感知证据的支持度，将丢弃状态传输到选定的代表token（保留原始多模态位置），随后进行物理压缩并恢复原生注意力。压缩分解为两个耦合部分：选择覆盖所需消息模式的载体，以及在载体上实现带符号的群体消息。

✨ **主要贡献**：推导了载体选择与消息实现误差到带符号消息失真、视觉创新和候选边际稳定性的理论界。在多个VLM家族和基准上验证，GMC-H2在Qwen2.5-VL-7B上仅用80.2%的视觉token保留97.78%的完整相对平均能力，GMC-L16达到100.36%。消融实验证明集体支持与群体实现共同驱动性能提升。

# The Model Proposes, the Code Disposes: A Pre-Registered Ablation of a Verifier-and-Acceptance Stage in an LLM-Orchestrated Offensive-Security Agent

- arXiv: https://arxiv.org/abs/2609.15887v1
- arXiv ID: 2609.15887

---

🔍 **核心问题**：在LLM驱动的攻防安全智能体中，加入一个由确定性代码强制执行裁决的"验证器-验收"阶段，是否会改变系统最终报告的内容。

🛠 **方法**：开展三项实验——15次探索性试点、20次预注册验证性消融、以及40次预注册2×2析因研究，均在两个故意留有漏洞的实验靶标上进行，并配有金丝雀监控与人工盲审。

✨ **主要贡献**：验证器阶段显著抑制了报告前的误报（中位数2 vs 0，p=0.00003）并提升了盲审精确率（0.471 vs 0.353，p=0.0087），析因分析将抑制效应归因于模型验证器而非确定性规则；但未达到预注册的非劣性标准，召回率无显著差异，结论仅限于"验证器改变系统输出、代码提供执行与可审计性"，不主张优于其他智能体或可泛化到实验室外。

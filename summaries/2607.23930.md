# Bridging Reinforcement Learning and Optimal Control via Feasible Action Mapping

- arXiv: https://arxiv.org/abs/2607.23930v1
- arXiv ID: 2607.23930

---

🔍 **核心问题**：如何在确保动态系统递归可行性和安全约束的前提下，高效解决复杂控制任务，同时避免传统强化学习（RL）与最优控制（OC）结合时的可行性妥协问题。

🛠 **方法**：提出FAOC框架，通过一个计算高效的优化映射算法，将RL智能体的抽象动作转化为状态依赖的最优控制问题（OCP）可行参数集，从而严格满足系统约束。

✨ **主要贡献**：首次实现RL与OC的无缝融合，无需专家设计抽象动作空间，且不牺牲OCP的完整性；在机器人乒乓球实时运动规划中，FAOC在样本效率和闭环性能上均超越现有基线方法。

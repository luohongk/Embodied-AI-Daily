# Imagine-then-Plan: Agent Learning from Adaptive Lookahead with World Models

- arXiv: https://arxiv.org/abs/2601.08955v3
- arXiv ID: 2601.08955

---

🔍 **核心问题**：现有基于世界模型的智能体方法多采用单步或固定步长的推演，未能充分利用多步想象来支持复杂任务的规划与决策。

🛠 **方法**：提出 **Imagine-then-Plan (ITP)** 框架，让策略模型与学习到的世界模型交互，生成多步“想象轨迹”，并通过自适应前瞻机制（根据任务目标与当前进度动态调整想象步长），将想象结果与当前观测融合，构建部分可观测且可想象的马尔可夫决策过程来指导策略学习。

✨ **主要贡献**：首次提出统一的自适应前瞻想象框架，支持免训练与强化训练两种实现；在多个智能体基准任务上显著优于现有基线，并验证了自适应前瞻能有效增强智能体的推理与复杂任务处理能力。

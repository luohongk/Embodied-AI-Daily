# Task and Skill Planning: Hierarchical Robot Planning with Black-Box Skills

- arXiv: https://arxiv.org/abs/2504.17901v3
- arXiv ID: 2504.17901

---

🔍 **核心问题**：解决长时域机器人规划中，如何将异构的、黑箱式技能（如学习型、力控型策略）与任务与运动规划（TAMP）框架有效整合，同时保持对象级故障推理能力。

🛠 **方法**：提出任务与技能规划（TASP）方法，利用可组合交互基元（CIPs）合成连接前后技能的头尾运动规划，支持规划时优化和执行时调整，并集成预存的异构技能到分层规划器中。

✨ **主要贡献**：通过双臂移动机器人和单臂移动机器人的真实实验验证，证明CIPs能使不同机器人组合异构技能，解决复杂长时域任务（如多房间非单调任务），且保留TAMP的故障推理优势。

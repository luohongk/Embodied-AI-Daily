# VLAConf: Calibrated Task-Success Confidence for Vision-Language-Action Models

- arXiv: https://arxiv.org/abs/2605.29605v2
- arXiv ID: 2605.29605

---

🔍 **核心问题**：现有VLA模型的任务成功置信度估计依赖动作token概率，但流匹配策略不提供此类概率，限制了其在主流VLA模型中的应用。

🛠 **方法**：提出VLAConf，一个两阶段表示级置信度框架，基于冻结的预训练VLA表示。首先用步骤条件硬币翻转网络从成功演示中学习未校准的逆成功支持分数，再用低容量校准器在带结果标签的成功/失败轨迹上拟合，将聚合分数映射为任务成功概率。

✨ **主要贡献**：在LIBERO基准上，VLAConf优于现有在线任务成功置信度估计方法；在选择性专家辅助中，置信度触发的交接可提升任务成功率；并在真实机器人实验中验证了其适用性。

# Selective Knowledge Control for Continual GUI Agent Learning over Application Streams

- arXiv: https://arxiv.org/abs/2609.06530v1
- arXiv ID: 2609.06530

---

🔍 **核心问题**：GUI代理在连续学习多个应用时，需在适应新应用的同时避免遗忘旧应用知识，尤其要区分新旧应用间的共享知识与特有知识，防止干扰。

🛠 **方法**：提出基于激活条件的选择性知识控制方法，通过神经元级梯度操控实现知识保留。具体为维护历史知识状态，对新应用的前向激活进行分类：未激活神经元（含特有知识）截断梯度，激活神经元（含共享知识）正交投影梯度，并在每阶段后合并新关键神经元。

✨ **主要贡献**：在多应用序列基准上验证，该方法能有效缓解灾难性遗忘，同时保持对新应用的适应能力，且为轻量级方案，无需额外存储大量数据。

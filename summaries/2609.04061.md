# When Models Edit Too Much: On the Fidelity of Minimal Code Edits

- arXiv: https://arxiv.org/abs/2609.04061v1
- arXiv ID: 2609.04061

---

🔍 **核心问题**：大型语言模型在代码修复中常过度编辑，即重写超出修复所需范围的代码，影响修复的可审查性和对原始实现的忠实度。

🛠 **方法**：基于400个BigCodeBench问题，通过注入受控的AST级损坏构建评估框架，每个任务有已知的最小补丁；随后测试提示指令、监督微调（SFT）和强化学习（RL）对减少过度编辑的效果。

✨ **主要贡献**：发现过度编辑在强模型中普遍存在（如GPT-5.5），但“保留原始实现”指令可显著降低编辑量（平均额外Levenshtein距离从0.195降至0.131），减少26.6%的认知复杂度并提升Pass@1达2.3个百分点；RL在域外编辑保真度和性能保持上优于SFT，确立了编辑保真度作为代码修复质量的独立衡量维度。

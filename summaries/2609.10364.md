# OmniMed-FL: A Robust Multimodal Federated Learning Framework for Clinical Diagnosis

- arXiv: https://arxiv.org/abs/2609.10364v1
- arXiv ID: 2609.10364

---

🔍 **核心问题**：临床诊断常需同时分析医学影像与病历文本，但标准机器学习无法融合这两类数据，且HIPAA/GDPR合规要求限制了敏感数据的集中聚合，导致跨网络的多模态安全融合存在空白。

🛠 **方法**：提出OmniMed-FL多模态联邦学习框架，将3,000张公开胸片与3,000条按类别（非患者级）匹配的合成病历配对，在非IID Dirichlet划分下（3–20个医院客户端）基准测试8种融合策略、3种初始化、4种缺失文本填补规则及联邦基线。

✨ **主要贡献**：在K=5、α=0.1的严重偏斜下，FedProx达0.737±0.085的macro-F1，优于FedAvg（0.662）和本地训练（0.297）；多模态融合在两个语料上均领先（合成语料0.956 vs 文本0.934、图像0.664），并揭示标签偏斜代价（最高0.27 F1）远大于客户端数量增加（≤0.10）。

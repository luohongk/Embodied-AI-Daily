# S2A2: Audio-Visual Imitation Learning for Manipulation Tasks Using Acoustic Spatial Information

- arXiv: https://arxiv.org/abs/2607.26047v1
- arXiv ID: 2607.26047

---

🔍 **核心问题**：解决机器人在操作任务中如何利用听觉信息（如声音位置和音色）来定位和识别目标，实现声学感知的模仿学习。

🛠 **方法**：提出多模态模仿学习框架S2A2，融合视觉特征与声学空间及信号信息，并集成ACT、扩散策略、VQ-BeT和π₀等策略。

✨ **主要贡献**：首次引入声学感知操作任务集，仿真实验证明该方法在需要位置和音色信息的任务中最有效，真实机器人实验验证了其实际应用可行性。

# Scene2Demo: Self-Evolving Embodied Data Generation via Object-Action Graph

- arXiv: https://arxiv.org/abs/2602.12065v2
- arXiv ID: 2602.12065

---

🔍 **核心问题**：如何从单张真实世界RGB图像和用户查询出发，自动生成可交互的仿真场景、可执行任务及离线机器人学习数据，以解决具身智能中数据获取成本高、多样性不足的问题。

🛠 **方法**：提出Scene2Demo框架，采用结构化多模块流程，通过“对象-动作图”表示任务生成（对象中心配置与动作转换），并利用反馈代理检查视觉执行结果，通过序列修改或参数调整迭代优化失败或不完整的执行，实现自进化式数据生成。

✨ **主要贡献**：在102个自动生成的场景-任务对中实现71.6%执行成功率；在四个长时程任务上，自进化显著提升任务成功率和子任务执行质量，优于RoboGen和GenSim2；行为克隆策略在两个代表任务上分别达到96.0%和92.0%成功率，验证了生成数据对下游策略学习的有效性。

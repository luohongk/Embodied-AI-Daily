# A Note on the Point-Clothoid Distance Algorithm

- arXiv: https://arxiv.org/abs/2609.10179v1
- arXiv ID: 2609.10179

---

🔍 **核心问题**：计算回旋曲线上距查询点最近的点时，Frego与Bertolazzi的高效算法假设每个搜索区间至多存在一个局部极小值，本文质疑该假设是否完备。

🛠 **方法**：利用回旋曲线渐屈线的几何性质，分析平方距离函数的驻点数量与分布，并结合数值实验验证。

✨ **主要贡献**：证明对于切角变化不超过2π的无拐点平面回旋线段，平方距离函数至多有三个驻点，且若全为局部极值则呈min-max-min顺序，从而证实原候选选择逻辑的完备性，并指出可省略不必要的区间中点搜索，减少迭代次数与计算时间。

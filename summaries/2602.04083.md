# Structure-Informed Estimation for Pilot-Limited MIMO Channels via Tensor Decomposition

- arXiv: https://arxiv.org/abs/2602.04083v3
- arXiv ID: 2602.04083

---

🔍 **核心问题**：在宽带MIMO系统中，导频开销限制了信道状态信息的准确性，尤其在6G带宽扩展下，如何在极少量导频观测下实现高精度信道估计成为挑战。

🛠 **方法**：提出一种结构信息混合估计器，将导频受限的MIMO信道估计建模为低秩张量补全问题，对比CP与Tucker分解，并引入轻量级3D U-Net学习低秩结构之外的残差分量，以补偿漫散射和硬件非理想性。

✨ **主要贡献**：在合成镜面信道上，Tucker补全在10%导频密度下比最小二乘和正交匹配追踪分别提升10.88 dB和7.83 dB NMSE；CP在SNR=20 dB时优于Tucker 13.11 dB。在DeepMIMO信道上，混合张量-神经网络估计器在极低导频密度（ρ=2%）下Tucker稳定而CP发散，ρ≥4%时CP引导变体最优，达到-16.44 dB（ρ=8%）和-20.34 dB（ρ=20%）。实证表明样本复杂度取决于信道内在维度而非张量规模。

# R2S-Eval: Robot Evaluation with Real-to-Sim Calibration via Vision-Language Models

- arXiv: https://arxiv.org/abs/2609.03276v1
- arXiv ID: 2609.03276

---

🔍 **核心问题**：传统机器人操作策略评估依赖重复硬件试验和成功率指标，成本高、不稳定且无法反映执行质量，缺乏自动化、质量感知的评估方法。

🛠 **方法**：提出R2S-Eval流水线，结合真实到仿真（real-to-sim）校准与视觉语言模型（VLM）偏好评估——先在仿真器中生成校准后的rollout视频，再由VLM对视频进行成对偏好比较，最终聚合成策略排名。

✨ **主要贡献**：实验表明R2S-Eval能产生可靠稳定的策略结论，与人类偏好一致，大幅减少重复硬件操作，并揭示二值成功率无法捕捉的行为质量差异，推动机器人评估从人工计数转向自动化、统计稳定且质量感知的范式。

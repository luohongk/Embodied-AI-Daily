# Can Vision-Language-Action Models Learn from Real-World Data Continually without Forgetting?

- arXiv: https://arxiv.org/abs/2605.26820v2
- arXiv ID: 2605.26820

---

🔍 **核心问题**：研究视觉-语言-动作（VLA）模型在真实机器人部署中，如何在不遗忘已有技能的前提下持续学习新技能，解决灾难性遗忘问题。

🛠 **方法**：构建了一个包含10个连续操作任务的真实世界持续学习基准，采用经验回放（Experience Replay, ER）策略，通过存储和重放过往任务数据来缓解遗忘。

✨ **主要贡献**：实验表明，精心配置的经验回放方法能有效克服灾难性遗忘，在同等计算预算下甚至优于联合多任务训练，并在10个异构任务流中实现了稳定的持续学习，为部署长期鲁棒的机器人策略提供了实用见解。

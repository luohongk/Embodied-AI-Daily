# Embedding Surgery: Localized Updates for Adaptive Ranking Correction in Dense Retrieval

- arXiv: https://arxiv.org/abs/2609.05110v1
- arXiv ID: 2609.05110

---

🔍 **核心问题**：密集检索系统因文档嵌入离线计算并存储于静态索引，难以根据用户反馈或搜索意图变化进行自适应调整。

🛠 **方法**：提出“嵌入手术”（embedding surgery），在查询时对选定文档嵌入施加局部最小更新，通过凸优化强制满足排序约束，并可直接覆盖近似最近邻索引。

✨ **主要贡献**：在多个基准上显著提升排序性能（如DL-Hard上nDCG@10相对提升+60.64%），对噪声反馈鲁棒，计算开销低，不破坏嵌入空间全局结构，且能与查询适应方法（如CoRocchio）互补。

# ULOHA: An Underwater Bimanual Robot System for Robot Learning

- arXiv: https://arxiv.org/abs/2609.19200v1
- arXiv ID: 2609.19200

---

🔍 **核心问题**：水下视觉运动策略学习此前主要局限于单机械臂，而双臂模仿学习多在空气中研究，缺乏统一的水下双臂机器人学习平台。

🛠 **方法**：提出 ULOHA 平台，结合定制的主从（leader-follower）硬件与 LeRobot 软件扩展，集成遥操作、多视角感知、示教采集、策略训练与自主部署，并在真实机器人上评估 ACT、Diffusion Policy 和 VLA 模型 SmolVLA。

✨ **主要贡献**：实现了双臂间传递、共享物体操作、浮力驱动拦截等协调行为，系统考察了气泡干扰、浮力运动、动作执行时域与实时分块的影响，并通过单臂实验证明跨空气与水的示教可支持两种介质中的执行，为水下双臂机器人学习提供了统一实验平台。

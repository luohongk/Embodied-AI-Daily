# WALoMA: A Multitask Wireless Foundation Model via Adaptive Low-Rank Masked Autoencoders

- arXiv: https://arxiv.org/abs/2607.25763v1
- arXiv ID: 2607.25763

---

🔍 **核心问题**：解决6G无线物理层中专用深度学习模型泛化能力差、标注数据稀缺的问题，提出统一的多任务基础模型。

🛠 **方法**：采用掩码自编码器（MAE）范式，利用无标注信道状态信息（CSI）进行自监督预训练；引入2D位置编码保留天线与子载波的空间-频率关系，并通过低秩适配（LoRA）实现参数高效微调。

✨ **主要贡献**：在5个下游任务（如信道估计、波束预测等）上取得平均87.80%的综合得分，显著超越基线模型（59.90%），且仅需训练14.68%的参数，在极少量标注数据下仍保持强性能。

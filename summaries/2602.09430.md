# AtomBridge: Agentic VLA Inference Plugin for Long-Horizon Tasks in Scientific Experiments

- arXiv: https://arxiv.org/abs/2602.09430v2
- arXiv ID: 2602.09430

---

🔍 **核心问题**：科学实验中，VLA模型在组合多个原子任务时存在技能链断裂问题，原因是前一个技能的末端机器人状态可能超出下一个技能的初始状态分布，导致长时序任务执行失败。

🛠 **方法**：提出AtomBridge，一种推理时即插即用插件，附加在已微调于原子任务的VLA策略上，保持其权重不变；在每个任务边界，利用LLM进行过渡推理并生成机器人动作代码，插入过渡动作以弥合状态不匹配。

✨ **主要贡献**：无需额外微调或长序列演示即可缓解技能链断裂；在仿真和真实实验环境中，8步组合任务的全序列成功率提升10%~25%，显著改善执行连续性和原子任务成功率。

# Persistent Robot World Models: Stabilizing Multi-Step Rollouts via Reinforcement Learning

- arXiv: https://arxiv.org/abs/2603.25685v2
- arXiv ID: 2603.25685

---

🔍 **核心问题**：动作条件下的机器人世界模型在自回归多步预测时，误差累积导致生成视频质量快速退化，无法用于长期任务模拟。

🛠 **方法**：提出一种基于强化学习的后训练方案，让世界模型在自己的自回归轨迹上训练（而非真实历史），并设计多候选未来片段比较协议，结合跨视角的视觉保真度奖励进行优化。

✨ **主要贡献**：在DROID数据集上达到最先进的多步预测效果，LPIPS降低14%（外部相机）、SSIM提升9.1%（腕部相机），在98%的成对比较中胜出，盲人研究中获得80%偏好率。

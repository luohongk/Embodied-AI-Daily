# E-S2Feat:Semantic-Guided Spiking Local Feature Detection and Description for Event Cameras

- arXiv: https://arxiv.org/abs/2608.14027v1
- arXiv ID: 2608.14027

---

🔍 **核心问题**：事件相机在稀疏、噪声和纹理有限条件下，局部特征学习鲁棒性不足，且部署在资源受限平台（如无人机）上需兼顾精度与能效。

🛠 **方法**：提出E-S2Feat，一种基于脉冲神经网络（SNN）的框架，包含模块特定脉冲激活机制（保留细粒度结构信息、低比特高效推理）和语义引导特征调制机制（利用语义先验优化关键点分布与描述子判别力）。

✨ **主要贡献**：在ECD和EDS数据集上显著优于SuperEvent等基线，姿态估计精度与ANN方法相当，但理论计算能效提升约4.8倍；在TUM-VIE上的视觉惯性里程计实验验证了其在完整SLAM系统中的实际应用潜力。

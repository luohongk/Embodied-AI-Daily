# X-WBC: A Cross-Embodiment Foundation Model for Humanoid Whole-Body Control

- arXiv: https://arxiv.org/abs/2609.15213v1
- arXiv ID: 2609.15213

---

🔍 **核心问题**：现有的人形机器人全身控制方法通常为每个机器人单独训练策略，导致运动经验在不同本体间彼此孤立，难以实现通用化部署。

🛠 **方法**：提出跨本体基础框架 X-WBC，将共享的人类运动语义与本体特定的物理执行分离；以人为中心的命令 token 对齐人类运动、机器人参考运动和稀疏 VR 观测，用因果 Transformer 从多机器人混合数据中学习可复用时间结构，再由轻量级机器人专属模块映射到各自的本体感知与动作空间。

✨ **主要贡献**：在九种仿真本体、外部运动和四台真实机器人上验证，联合训练提升了跟踪性能，对齐表示支持跨命令源的一致控制，且策略在训练语料之外仍具竞争力，确立了跨本体联合训练作为全身控制基础模型的可行路径。

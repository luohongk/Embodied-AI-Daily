# Learning When to Think: Adaptive Reasoning for Test-Time Compute Allocation

- arXiv: https://arxiv.org/abs/2608.20256v1
- arXiv ID: 2608.20256

---

🔍 **核心问题**：推理语言模型在固定token预算下运行，无法根据问题难度自适应分配推理计算量，导致简单问题过度计算、困难问题计算不足。

🛠 **方法**：在GRPO强化学习框架中，让模型在响应首token自主选择三种推理模式（NoThink/Short/Long），通过形状化奖励和每模式硬性token上限来区分模式，无需独立路由器。

✨ **主要贡献**：在MATH数据集上训练的1.5B模型成功涌现三种模式且未坍缩，平均响应长度减少41%而精度几乎不变（0.782 vs 0.796），并零样本迁移至其他基准，在GSM8K上节省76%token且精度更高。

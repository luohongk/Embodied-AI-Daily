# Robust Scene Transfer for PointGoal Navigation via Privileged Sensor Guided Contrastive Learning

- arXiv: https://arxiv.org/abs/2606.05506v2
- arXiv ID: 2606.05506

---

🔍 **核心问题**：解决PointGoal导航中视觉表征对场景外观过拟合、跨环境泛化能力差的问题。

🛠 **方法**：提出传感器引导的自适应对比学习框架，利用特权LiDAR传感信息通过几何感知相似度度量和自适应温度缩放指导视觉表征学习，并将表征学习与策略优化解耦，同时引入跨阶段域不匹配抑制环境特定捷径。

✨ **主要贡献**：显著提升策略级跨场景迁移能力，在室内外高保真仿真中优于大型预训练视觉模型和标准对比学习基线，部署时仅需单目RGB和任务输入，无需LiDAR等特权传感器，并发布了多模态数据集。

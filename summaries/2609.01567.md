# Selective Agent Guidance via Entropy: Learning Autonomous Policies from Imperfect VLM Teachers

- arXiv: https://arxiv.org/abs/2609.01567v1
- arXiv ID: 2609.01567

---

🔍 **核心问题**：如何利用昂贵但不完美的视觉语言模型（VLM）作为教师，训练一个廉价的自主策略，同时避免直接使用VLM作为固定策略所带来的高成本和系统性错误。

🛠 **方法**：提出SAGE框架，仅在学习者不确定时查询VLM，执行其建议动作，并通过环境回报加权的知识蒸馏，将教师指导融入轻量级强化学习策略中。

✨ **主要贡献**：SAGE在稀疏奖励的视觉推理和导航任务中，无需VLM即可运行，且性能优于无引导的RL，甚至在某些环境中超越VLM教师；同时大幅减少VLM调用次数，证明VLM可作为临时、不完美的指导来源，其价值通过交互被验证和内化。

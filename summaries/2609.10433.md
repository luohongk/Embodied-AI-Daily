# Multi-Agent Reinforcement Learning for Autonomous UAV Exploration in Wildfire Response

- arXiv: https://arxiv.org/abs/2609.10433v1
- arXiv ID: 2609.10433

---

🔍 **核心问题**：如何让无人机在野火场景中自主导航与监测，实现无需人工干预的火灾监控。

🛠 **方法**：采用深度强化学习框架训练多无人机智能体，在模拟野火环境中学习导航与监测策略。

✨ **主要贡献**：智能体随时间学习到稳定有效的行为（损失收敛、奖励提升、能持续跟踪火边界），表明DRL无人机系统在自主野火监测方面具有潜力，且环境结构与奖励设计会影响策略效果。

# Learning Holistic Whole-Body Loco-Manipulation with a Bipedal Mobile Manipulator

- arXiv: https://arxiv.org/abs/2609.18930v1
- arXiv ID: 2609.18930

---

🔍 **核心问题**：如何让双足移动操作机器人在保持平衡的同时，协调手臂与腿部运动，以完成超出其手臂常规工作空间的操作任务。

🛠 **方法**：采用强化学习训练统一的全身控制器，直接将6自由度末端执行器目标映射为双足底座与机械臂的协调动作；结合奖励门控策略平衡末端跟踪、移动与平衡，并用融合Transformer窗口编码、GRU循环记忆和辅助动力学预测的时序上下文估计器提取动态信息。

✨ **主要贡献**：提出无需显式底座速度或脚步指令、仅凭末端目标即可自主协调伸手、姿态调整与迈步的全身控制器，并在真实机器人上通过VR遥操作、扩散策略和脚本轨迹验证了其作为通用末端接口支持多种操作任务的能力。

# Catastrophic Forgetting in Continual Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.08673v1
- arXiv ID: 2608.08673

---

🔍 **核心问题**：研究持续强化学习中任务相似性与灾难性遗忘之间的关系，探究新任务的相似度是否影响旧任务性能的保持。

🛠 **方法**：采用可解释的Q-learning强化学习算法，在基于图的任务上训练，以最小化到达目标的步数为目标，通过改变新任务的相对复杂度来测试对先前任务性能的影响。

✨ **主要贡献**：实验发现任务相似性与遗忘之间存在复杂动态，遗忘程度随相似度和复杂度显著波动，但未发现任务相似性独立影响遗忘的统计显著性证据，表明遗忘可能受相似性与复杂度交互作用影响，需进一步研究。

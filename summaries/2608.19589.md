# OrthoSkillVLA: Continual Skill Learning via Gradient-Informed Skill Subspace Adaptation

- arXiv: https://arxiv.org/abs/2608.19589v1
- arXiv ID: 2608.19589

---

🔍 **核心问题**：预训练视觉-语言-动作（VLA）模型在连续学习多种技能时，会因参数更新干扰先前技能的表征和速度映射，导致灾难性遗忘。

🛠 **方法**：提出OrthoSkillVLA框架，对VLM和ActionHead分别施加正交子空间约束以保护语义与局部速度模式；对输出层引入轻量级特征感知MoE解码器，为每个技能分配独立专家，并通过免训练路由器按特征相似度选择专家。

✨ **主要贡献**：首次针对VLA内部组件异质性设计分离约束，避免统一约束导致的容量耗尽或速度映射扰动；MoE解码器在不增加推理负担下解决输出层冻结/更新的两难；仿真与真实实验证明其能更好保留旧技能同时高效习得新技能。

# GLAM-SLAM: Real-time Gaussian Large-scale Mapping via Flow Densification and Spatial Decomposition

- arXiv: https://arxiv.org/abs/2607.21416v1
- arXiv ID: 2607.21416

---

🔍 **核心问题**：现有基于高斯泼溅的单目SLAM系统难以在长时间、大规模户外场景中实现实时运行，且存在GPU内存消耗过高的问题。

🛠 **方法**：提出GLAM-SLAM系统，采用解耦架构，前端使用基于特征的轻量跟踪，后端采用结构化稀疏锚点网格表示；引入基于几何的流致密化锚定策略（利用对极约束）满足3DGS初始化需求，并通过场景分区策略结合MLP初始化引入空间归纳偏置。

✨ **主要贡献**：在KITTI等长序列数据集上，重建质量比第二名提升15%，同时保持实时性能和可扩展性，代码已开源。

# Reinforcement Learning for Code Optimization

- arXiv: https://arxiv.org/abs/2607.25970v1
- arXiv ID: 2607.25970

---

🔍 **核心问题**：将强化学习从代码正确性扩展到代码优化时，执行时间作为奖励信号会因测量噪声、奖励稀疏和GRPO不稳定导致优化失败，生成代码速度提升有限且易出错。

🛠 **方法**：提出三阶段框架：构建DMC-Optim基准测试和校准沙箱；在RL环境中组合正确性与速度奖励，并用离线模拟器预测最优配置；调整GRPO和评估策略以适应稀疏、有噪声的定时执行场景。

✨ **主要贡献**：在DMC-Optim上，优化感知配置将Qwen 2.5 7B的top-50% pass@1从18.0%提升至31.3%，CWM 32B从30.7%提升至50.4%；在更严格的top-30%标准下，CWM 32B相对提升125%，同时保持纯正确性分数；在沙箱降级时，鲁棒优化RL比标准RLVR提升100%-200%；CWM 32B在LCB上中位数速度比较中胜率达83%，并达到人类复杂度改进速率的一半（14% vs. 28%）。

# Role-Conditioned Sub-Token Routing for Efficient Vision-Language-Action Policies

- arXiv: https://arxiv.org/abs/2608.18410v1
- arXiv ID: 2608.18410

---

🔍 **核心问题**：视觉-语言-动作（VLA）模型处理长多模态token序列时推理成本高，现有token剪枝方法在激进压缩下会丢失完整表示，导致性能脆弱。

🛠 **方法**：提出RoleSub（角色条件子token路由），在保留token的基础上压缩其值表示的宽度。将每个值表示在正交空间中分组，用轻量路由器根据token表示、潜在角色表示和语言上下文决定保留哪些组，并同样应用于语言值。

✨ **主要贡献**：在OpenVLA-OFT-7B的LIBERO基准上，匹配视觉KV预算时，RoleSub在36个设置中33个优于仅token剪枝的基线，激进压缩下增益最大。结合视觉与语言压缩可将总KV降至原始的9.2–11.3%，同时保持多数任务的控制性能，证明子token压缩是token剪枝的有效补充。

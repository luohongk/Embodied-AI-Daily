# Drop the Act: Probe-Filtered RL for Faithful Chain-of-Thought Reasoning

- arXiv: https://arxiv.org/abs/2605.11467v2
- arXiv ID: 2605.11467

---

🔍 **核心问题**：推理模型在内部已确定答案后，会生成“推理剧场”——看似深思熟虑但对正确性无贡献的步骤，浪费推理token、污染可解释性并掩盖真实计算过程。

🛠 **方法**：提出ProFIL（Probe-Filtered RL），在冻结基座模型上训练一次多头注意力探针，利用内部激活检测“承诺后”步骤；在GRPO强化学习过程中，对探针得分超阈值的rollout将优势置零，从而抑制推理剧场。

✨ **主要贡献**：在四个推理领域（GSM8K、LiveCodeBench、ToolUse、MMLU-Redux）和两种架构（Llama-8B、Qwen-7B）上，ProFIL将剧场步骤减少11–100%，忠实推理比例提升（如LiveCodeBench上+24pp），链长缩短4–19%，同时保持或提升任务准确率；且优于匹配的长度惩罚GRPO基线，证明增益源于语义承诺检测而非简单压缩。

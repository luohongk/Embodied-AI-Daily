# Vision Transformers for End-to-End Quark-Gluon Jet Classification from Calorimeter Images

- arXiv: https://arxiv.org/abs/2506.14934v2
- arXiv ID: 2506.14934

---

🔍 **核心问题**：区分夸克与胶子引发的喷注是高能物理中的关键挑战，本文旨在探索视觉Transformer（ViT）在量热器图像喷注分类中的潜力，以超越传统CNN方法。

🛠 **方法**：基于2012年CMS开放数据，构建包含电磁量热器（ECAL）、强子量热器（HCAL）和重建径迹的多通道喷注图像，系统评估纯ViT及ViT-CNN混合模型（如ViT+MaxViT、ViT+ConvNeXt）进行端到端分类。

✨ **主要贡献**：首次系统验证ViT架构在量热器图像喷注分类中的优势，ViT混合模型在F1分数、ROC-AUC和准确率上均稳定超越CNN基线，并提供了公开可用的结构化数据集和性能基准，为后续深度学习研究奠定基础。

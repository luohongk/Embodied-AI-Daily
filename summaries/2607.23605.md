# Hybrid Advantage Estimation with Unified Critic for VLM Agentic Reinforcement Learning

- arXiv: https://arxiv.org/abs/2607.23605v1
- arXiv ID: 2607.23605

---

🔍 **核心问题**：大型视觉语言模型（VLM）在交互式环境中作为智能体时，需要跨回合进行连贯推理和决策，但现有强化学习方法要么在token级别优化，要么在回合级别优化，无法同时兼顾两种粒度的信用分配。

🛠 **方法**：提出HyGAE框架，通过理论推导建立回合级和token级优化的统一公式，设计混合优势函数（Hybrid Advantage），并证明使用统一评论家（Unified Critic）模型可同时估计两种粒度的价值，实现联合优化。

✨ **主要贡献**：在五个多回合决策环境中，HyGAE平均成功率达91%，比其他方法提升10%；理论证明混合优势与回报的精确解析形式对优化至关重要，并开源项目代码。

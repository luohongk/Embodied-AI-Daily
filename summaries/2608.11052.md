# Efficient Hypergradient Descent for Inverse Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.11052v1
- arXiv ID: 2608.11052

---

🔍 **核心问题**：逆向强化学习（IRL）中，将奖励函数恢复建模为双层优化问题时，外层更新需要计算涉及内层目标函数逆Hessian-向量积的超梯度，导致计算成本过高。

🛠 **方法**：本文证明在内层最优解处，内层目标的Hessian与策略的Fisher信息矩阵成正比，从而得到基于Fisher结构的超梯度（类似自然超梯度下降）；为处理大规模Fisher矩阵，采用流式谱草图（streaming spectral sketch）近似逆Fisher-向量积，避免显式构造Fisher矩阵。

✨ **主要贡献**：在离散和连续控制环境中，与一阶随机双层基线相比，该方法在策略性能和奖励排序质量上均表现优异；Fisher草图显著降低了曲率存储复杂度，并相比显式Fisher求解器提升了计算效率。

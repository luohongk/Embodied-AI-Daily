# 4DHumanDiff: Direct Text-to-4DGS Generation for Consistent 360-Degree Dynamic Humans

- arXiv: https://arxiv.org/abs/2607.27634v1
- arXiv ID: 2607.27634

---

🔍 **核心问题**：从文本提示直接生成高质量、360度视角一致且时间连贯的动态人体资产，现有方法依赖先合成视频再拟合4D表示，成本高且易导致几何不完整或视角不一致。

🛠 **方法**：提出4DHumanDiff，一个端到端扩散框架，直接生成由4D高斯泼溅（4DGS）表示的动态人体；采用3D U-Net骨干加时间注意力机制，并构建6万对文本-4DGS数据集，引入2D正则化和免训练4D插值以提升渲染质量与运动平滑度。

✨ **主要贡献**：实现一分钟内生成一致的360度动态人体，显著提升时间与多视角一致性，推理速度比现有方法快10倍以上，并首次提供大规模文本到4DGS动态人体数据集。

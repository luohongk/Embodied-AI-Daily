# When Trivia Is Not Trivial: Everyday Knowledge Failures in Multilingual LLMs

- arXiv: https://arxiv.org/abs/2607.21445v1
- arXiv ID: 2607.21445

---

🔍 **核心问题**：探究大型语言模型（LLMs）在常识性、文化性及长尾知识上的表现，尤其是在多语言环境下对日常流行文化知识的掌握程度。  
🛠 **方法**：构建多语言基准数据集TriviaRoomQA，包含3300道平行选择题（覆盖6种欧洲语言）和5340道法语题目，评估30个开源LLM（7B-70B参数）在288个主题上的知识能力。  
✨ **主要贡献**：发现LLMs在历史、地理等知识密集型主题上表现优异，但在名人、音乐、电影等日常流行文化主题上显著薄弱；且模型对同一问题的回答能力随语言变化，表明事实知识访问并非语言无关。该研究揭示了现有学术基准未覆盖的重要知识缺口。

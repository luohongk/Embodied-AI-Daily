# rl-triton: High-Performance Triton GPU Kernels for Reinforcement Learning Credit Assignment

- arXiv: https://arxiv.org/abs/2608.17641v1
- arXiv ID: 2608.17641

---

🔍 **核心问题**：强化学习信用分配中多种估计算法（如GAE、V-Trace等）在GPU上计算效率低，现有实现难以充分利用并行硬件。

🛠 **方法**：提出统一关联扫描框架，将七种RL估计算法转化为一阶线性递推，使用Triton实现融合GPU内核，在芯片上构造递推系数，并以O(log T)并行步骤求解。

✨ **主要贡献**：开源库rl-triton，在数千环境、短轨迹场景下比torch.compile基线快1.6-5.70倍，且长序列下加速比更高；同时明确处理了终止与截断轨迹，并验证了算子代数正确性。

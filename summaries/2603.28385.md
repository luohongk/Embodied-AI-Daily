# Critic-Free Deep Reinforcement Learning for Maritime Coverage Path Planning on Irregular Hexagonal Grids

- arXiv: https://arxiv.org/abs/2603.28385v2
- arXiv ID: 2603.28385

---

🔍 **核心问题**：解决不规则海域（如曲折海岸线、岛屿和禁航区）中的覆盖路径规划（CPP）问题，传统分解方法难以处理复杂几何形状且需逐实例重规划。

🛠 **方法**：提出基于深度强化学习（DRL）的框架，将CPP建模为神经组合优化任务，使用Transformer指针策略自回归生成覆盖路径，并采用无评论家的组相对策略优化（GRPO）算法，通过实例内轨迹比较估计优势，避免长时域价值估计的不稳定性。

✨ **主要贡献**：在1000个未见过的合成海域环境中，训练策略的哈密顿路径成功率高达99.1%（远超最优启发式的46.0%），路径长度缩短7%，航向变化减少24.1%；三种推理模式均在50毫秒内完成，验证了实时机载部署的可行性。

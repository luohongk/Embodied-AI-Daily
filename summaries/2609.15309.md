# When Agents Slow Down: Understanding LLM Agents' Test-Time Strategies via Elo-per-token Analysis

- arXiv: https://arxiv.org/abs/2609.15309v1
- arXiv ID: 2609.15309

---

🔍 **核心问题**：LLM智能体在测试时自适应分配计算资源（修改答案、调用工具、探索备选、决定停止），导致其性能随计算量扩展的规律难以衡量。

🛠 **方法**：提出“每token Elo”分析，追踪各token预算下找到的最优解，并用Bradley-Terry模型将任务内排序聚合为跨任务的Elo评分；在四个通用智能体、四个开放式基准（单会话达1亿token）及三个反馈驱动优化框架上验证，并以独立采样作为理论参照。

✨ **主要贡献**：发现智能体初期将token转化为Elo的效率高于独立采样，但边际收益递减并最终低于参照；而人类顶尖选手在AtCoder启发式竞赛中呈超线性提升，显示智能体放缓后仍有巨大提升空间；据此定义“扩展拐点”作为单会话预算，将1亿token拆分到并行会话，在Polyomino Packing任务上比单长会话提升+264 Elo、比十个短会话提升+355 Elo。

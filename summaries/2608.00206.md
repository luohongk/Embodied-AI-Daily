# Motion Planning for Mobile Manipulators Navigating Doorways via Model Predictive Control

- arXiv: https://arxiv.org/abs/2608.00206v1
- arXiv ID: 2608.00206

---

🔍 **核心问题**：解决移动机械臂在人类环境中自主穿越推门和拉门时，需要协调移动底盘与机械臂运动以生成动态可行且无碰撞轨迹的问题。

🛠 **方法**：提出一种基于非线性模型预测控制（MPC）的运动规划框架，将机器人与门建模为耦合动力学系统，并通过惩罚约束确保操作可行性，避免在规划器中显式建模机械臂运动学。

✨ **主要贡献**：通过仿真和硬件实验验证，该方法能成功规划穿越门洞的可行轨迹，无需复杂臂运动学建模，提升了规划效率与实用性。

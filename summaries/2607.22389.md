# HiKV: Hierarchical Importance-Aware KV Cache with Hardware Acceleration for LLM Decoding

- arXiv: https://arxiv.org/abs/2607.22389v1
- arXiv ID: 2607.22389

---

🔍 **核心问题**：解决长上下文大语言模型解码过程中KV缓存持续增长导致的显存瓶颈问题。  
🛠 **方法**：提出算法-硬件协同设计HiKV，通过两级重要性感知压缩：第一阶段在固定预算内淘汰不重要令牌，第二阶段进一步筛选保留令牌中的显著元素；并设计可重构重要性排序器硬件加速两阶段处理。  
✨ **主要贡献**：在注意力计算中实现最高7.95倍加速和90%能耗降低，仅损失1%精度；在同等精度下，相比现有方法额外减少1.82~4.87倍外部内存访问，硬件面积开销仅增加8%。

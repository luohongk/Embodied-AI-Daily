# ViLoMan: Learning Visual-Proprioceptive Whole-Body Loco-Manipulation Skills for Humanoid Robots

- arXiv: https://arxiv.org/abs/2609.19340v1
- arXiv ID: 2609.19340

---

🔍 **核心问题**：人形机器人的全身移动-操作（loco-manipulation）难以实现自主化，主要受限于缺乏多样且物理可执行的机器人-物体交互数据，以及难以仅凭机载观测学习统一的全身控制策略。

🛠 **方法**：ViLoMan 先将人类-物体交互的部分运动学演示转化为完整、物理可执行的机器人轨迹，再通过教师-学生蒸馏框架学习统一策略，将第一视角深度观测与本体感知直接映射为关节级全身动作。

✨ **主要贡献**：提出可扩展的自主人形移动-操作框架，部署时无需参考动作或中间指令；在仿真与真实世界的关门任务中，单一策略使 Unitree G1 仅凭机载深度感知和本体感知即可完成全任务，并具备良好的泛化性与仿真到现实的迁移能力。

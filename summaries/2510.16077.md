# Continual Knowledge Consolidation LORA for Domain Incremental Learning

- arXiv: https://arxiv.org/abs/2510.16077v2
- arXiv ID: 2510.16077

---

🔍 **核心问题**：解决领域增量学习（DIL）中任务特定LoRA忽略共享知识、推理时选择不准确导致准确率下降，以及线性或原型分类器泛化能力不足的问题。

🛠 **方法**：提出CONEC-LoRA，结合任务共享LoRA提取通用知识与任务特定LoRA融入领域知识，采用参数从分布中采样的随机分类器增强分类正确性，并利用辅助网络预测任务特定LoRA，结合不同深度网络结构、局部分类器、球生成器损失与变换模块处理合成样本偏差。

✨ **主要贡献**：在4个主流基准问题上以超过5%的准确率优势超越现有方法，实现了领域增量学习中知识巩固与高效推理的突破。

# HIERA: Workload-Aware Planning Across Implementation Spaces for GPU Kernel Optimization

- arXiv: https://arxiv.org/abs/2608.21157v1
- arXiv ID: 2608.21157

---

🔍 **核心问题**：现有基于LLM的GPU内核优化方法受限于固定实现空间，难以兼顾优化灵活性与搜索效率。

🛠 **方法**：提出HIERA框架，通过构建契约增强的任务规范，在PyTorch算子、CUDA库和自定义CUDA内核间动态选择实现空间，并利用性能剖析反馈与专家知识进行结构化迭代优化。

✨ **主要贡献**：在KernelBench多个负载级别和基础LLM上，HIERA相比现有免训练方法在实现有效性、样本效率和优化性能上更优，且无需额外训练即可媲美基于训练的CUDA-L1；在科学计算stencil算子案例中实现1.53倍于cuDNN的加速，展示出超越标准ML负载的通用性。

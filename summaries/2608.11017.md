# R4DSG: Relative 4D Scene Graph Memory for Object-Centric Question Answering in Long Egocentric Video

- arXiv: https://arxiv.org/abs/2608.11017v1
- arXiv ID: 2608.11017

---

🔍 **核心问题**：长时程第一视角视频中的物体中心问答（如物体被移动到哪里、何时改变状态、为何被重新放置）难以实现，因为现有基于字幕或文本的记忆方法无法保持物体身份一致性和结构化空间变化信息。

🛠 **方法**：提出R4DSG，一种相对4D场景图记忆系统，将视频转换为按时间、地点、持久物体、锚点相对变化和局部交互上下文索引的紧凑可查询记忆条目，利用RGB-only的提示视频分割、时间传播和相对3D提升技术，分离稳定锚点与动态物体，并通过锚点相对转换表示物体状态。

✨ **主要贡献**：在EgoLifeQA的255个物体相关问题上，相比EgoRAG-Text整体提升6.7分，在“何时”类问题上提升12.5分，验证了时间组织的物体记忆的价值，为可穿戴助手、AR系统和具身多媒体智能体提供了实用的记忆基础。

# iARCS: Iterative Agentic RL for Controllable 3D Scene Generation

- arXiv: https://arxiv.org/abs/2608.06161v1
- arXiv ID: 2608.06161

---

🔍 **核心问题**：现有3D场景生成器虽能生成逼真图像，但常忽略任务关键的功能约束（如可达性、可通行性、空间规则），导致合成数据难以用于下游具身AI训练。

🛠 **方法**：提出iARCS框架，采用两阶段策略——先用通用奖励预训练提升物理合理性与布局质量，再用LLM生成的奖励程序进行任务特定微调，并通过训练反馈迭代优化奖励程序。

✨ **主要贡献**：在可通行性、可达性和净空等任务上显著提升约束满足度，同时保持场景多样性；生成的合成数据还能改进基础生成器，证明其作为实用数据生成工具的价值。

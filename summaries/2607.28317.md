# One Human, $N$ Agents: Audit-Budget Allocation for LLM Agent Fleets under Miscalibrated, Correlated Confidence

- arXiv: https://arxiv.org/abs/2607.28317v1
- arXiv ID: 2607.28317

---

🔍 **核心问题**：单个人类审计者需在有限预算下（每轮仅能审计 $B \ll N$ 个）监督 $N$ 个LLM智能体，但智能体自报的置信度可能被对抗性错误校准且错误相互关联，导致审计策略失效。

🛠 **方法**：将问题建模为基于两级高斯copula的预算受限噪声检查，分析置信度排序审计与随机审计的性能对比，并推导出错误校准阈值 $\delta^*$；同时用五个开源LLM和一个专有模型进行实证验证。

✨ **主要贡献**：发现两个反直觉结论——预算越紧 $\delta^*$ 越高（排序审计更稳健），且跨模型相关性低并非优势（共享难度主导）；开源模型置信度近乎恒定（无操作价值），专有模型则有效；提出量化“空洞监督”的标准，并通过轨迹回放验证策略排序。

# Doc-V*:Coarse-to-Fine Interactive Visual Reasoning for Multi-Page Document VQA

- arXiv: https://arxiv.org/abs/2604.13731v2
- arXiv ID: 2604.13731

---

🔍 **核心问题**：多页文档视觉问答（DocVQA）需要在长且视觉密集的文档中推理语义、布局和视觉元素，现有OCR-free方法在容量与精度之间存在权衡，端到端模型难以扩展，检索式流程则脆弱且被动。

🛠 **方法**：提出Doc-V*，一个OCR-free的智能体框架，将多页DocVQA建模为顺序证据聚合过程。它先通过缩略图概览，再基于语义检索和定向页面获取主动导航，并在结构化工作记忆中聚合证据；训练上采用专家轨迹的模仿学习，并结合Group Relative Policy Optimization优化。

✨ **主要贡献**：Doc-V*在五个基准上超越开源基线，逼近专有模型，跨域性能较RAG基线提升最高47.9%；同时证明其通过选择性注意力实现高效证据聚合，而非依赖增加输入页面数量。

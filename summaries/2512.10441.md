# Decoding Student Minds: Leveraging Conversational Agents for Psychological and Learning Analysis

- arXiv: https://arxiv.org/abs/2512.10441v2
- arXiv ID: 2512.10441

---

🔍 **核心问题**：现有教育对话系统仅能提供单一辅导或情感支持，无法同时实时分析学生的认知与情感状态，以兼顾学习表现和心理健康。

🛠 **方法**：提出一种心理感知对话代理，融合大语言模型（LLM）、知识图谱增强的BERT（KG-BERT）和带注意力的双向LSTM网络，利用文本语义、语音韵律特征和时序行为趋势进行多模态实时分类。

✨ **主要贡献**：在45名大学生的试点研究中，系统相比单模态基线显著提升学习动机、降低压力并带来适度学业增益；同时报告了效应量、评分者信度及消融分析，验证了知识图谱和多模态融合的各自贡献，并明确讨论了小样本探索性研究的局限性。

# LiLa-WAM: Lightweight Latent Reasoning World-Action Model for Robotic Manipulation

- arXiv: https://arxiv.org/abs/2608.03701v1
- arXiv ID: 2608.03701

---

🔍 **核心问题**：现有世界-动作模型（WAM）在机器人控制中计算开销大，像素空间方法浪费算力于无关视觉细节，潜在空间方法需多阶段训练，难以在有限计算预算下高效训练。

🛠 **方法**：提出LiLa-WAM，在紧凑潜在空间中进行未来推理，通过联合未来状态预测和动作生成构建轻量推理空间，支持端到端训练（单张24GB GPU）；并引入语言无关的任务表示——视觉转移令牌（VTT），将任务编码为视觉特征空间中的方向。

✨ **主要贡献**：实现轻量级世界-动作模型，显著降低训练成本；在RoboTwin 2.0（50任务）、LIBERO及真实机器人任务上验证有效性，RoboTwin平均成功率90.48%，且仅需单GPU训练。

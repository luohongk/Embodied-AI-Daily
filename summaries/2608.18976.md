# Catastrophic Learning: A New Attack Vector on Continual Learning Networks

- arXiv: https://arxiv.org/abs/2608.18976v1
- arXiv ID: 2608.18976

---

🔍 **核心问题**：本文发现持续学习（CL）模型存在一种新型安全漏洞——攻击者可通过操纵数据降低当前或未来迭代的“可学习性”，而非仅触发灾难性遗忘，从而破坏模型的塑性（plasticity）。

🛠 **方法**：作者形式化了该攻击场景并定义威胁模型，提出六种攻击策略：Label-Exchange、Tensor-Exchange、Attraction-Coincident、Attraction-Preceding、Repulsion-Coincident和Repulsion-Preceding。这些策略通过最小化或最大化中毒样本与受害者迭代标签间的损失，在特征空间中拉近或推远表示，以干扰学习过程。

✨ **主要贡献**：首次提出“学习阻断器”（learning blockers）和“灾难性学习”（catastrophic learning）概念，并在MNIST和Split-CIFAR10上针对DER、ER-ACE和iCaRL三种CL策略进行了超过4,480次模拟实验，证明攻击者能选择性抑制新知识获取并加剧旧知识遗忘，揭示了CL模型对这类攻击的显著脆弱性。

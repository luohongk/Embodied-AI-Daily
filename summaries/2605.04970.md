# Skill Neologisms: Towards Skill-based Continual Learning

- arXiv: https://arxiv.org/abs/2605.04970v3
- arXiv ID: 2605.04970

---

🔍 **核心问题**：如何在不更新模型权重的前提下，让大语言模型（LLM）持续学习新技能，同时避免灾难性遗忘并突破上下文长度的表达限制。

🛠 **方法**：提出“技能新词”（skill neologisms）——在模型词表中加入可训练的软token，每个token针对特定技能进行优化，通过组合这些token实现技能获取与复用。

✨ **主要贡献**：实验表明，预训练LLM已存在与程序性知识相关的token；在合成任务中，技能新词可提升特定技能表现，并能与分布外技能组合，且独立训练的新词可零样本组合；在Skill-Mix基准的自然语言任务中验证了零样本组合的有效性，为基于技能的持续学习提供了可扩展路径。

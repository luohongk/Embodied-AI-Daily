# Stabilizing Temporal Difference Learning via Implicit Stochastic Recursion

- arXiv: https://arxiv.org/abs/2505.01361v3
- arXiv ID: 2505.01361

---

🔍 **核心问题**：传统时序差分（TD）学习算法对步长（学习率）选择高度敏感，步长设置不当会导致方差增大和收敛变慢，而现有调参方法依赖试错，效率低下。

🛠 **方法**：提出隐式TD算法，将标准TD更新重构为不动点方程，通过隐式随机递归求解，从而在不增加计算开销的前提下提升更新稳定性。

✨ **主要贡献**：证明了隐式TD算法在更广步长范围内几乎必然收敛，并给出了带投影步骤的有限时间误差界；实验表明其在on-policy和off-policy任务中均显著优于传统TD，对步长鲁棒性强，为策略评估提供了稳健通用的框架。

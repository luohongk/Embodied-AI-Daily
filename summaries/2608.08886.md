# Estimation of Spacecraft Inertia Tensor Using Attitude-Only Data from Torque-Free Motion

- arXiv: https://arxiv.org/abs/2608.08886v1
- arXiv ID: 2608.08886

---

🔍 **核心问题**：在无陀螺仪和已知控制力矩的情况下，仅利用姿态数据估计航天器在无外力矩运动下的归一化惯性张量。

🛠 **方法**：提出一种姿态-only框架，先用Karush-Kuhn-Tucker（KKT）公式进行快速线性初始化，再通过基于Euler方程精确Jacobi-elliptic解和Magnus展开四元数映射的非线性打靶法进行精化；支持单弧段或多短弧段联合估计。

✨ **主要贡献**：相比扩展卡尔曼滤波（EKF），在单弧段（500秒）下惯性张量误差降低约一个数量级，计算量减少近两个数量级；多弧段（3×100秒）精度相当且仍快一个数量级以上。在逼真近距操作仿真中，2000秒单弧段达到亚千分之一中位误差，并能支持10小时姿态预测（中位误差仅个位数度）；多弧段（30-300秒/段）也一致优于EKF精化。

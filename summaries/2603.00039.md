# CARE: Confounder-Aware Aggregation for Reliable LLM Evaluation

- arXiv: https://arxiv.org/abs/2603.00039v2
- arXiv ID: 2603.00039

---

🔍 **核心问题**：现有LLM-as-a-judge集成评估方法假设各评判模型独立估计真实质量，但实际中它们因共享潜在混杂因素（如冗长偏好、风格倾向等）产生相关误差，导致多数投票或平均等聚合方式增益有限甚至放大系统性错误。

🛠 **方法**：提出CARE框架，显式将LLM评判分数建模为“潜在真实质量信号”与“共享混杂因素”的联合作用，在无真实标签条件下分离质量与混杂因素，并提供可辨识性与有限样本恢复的理论保证。

✨ **主要贡献**：首次从理论上量化了忽略混杂因素时聚合模型的系统性偏差；在12个公开基准（涵盖连续评分、二分类和成对偏好）上，CARE将聚合误差最高降低26.8%，代码已开源。

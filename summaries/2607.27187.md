# A Photonic-CXL Memory Appliance for Scalable KV Cache Management in LLM Inference

- arXiv: https://arxiv.org/abs/2607.27187v1
- arXiv ID: 2607.27187

---

🔍 **核心问题**：大语言模型推理时，KV缓存面临内存墙问题——现有内存层级无法同时满足数十TB容量和数百GB/s带宽的需求，导致长上下文用户并发数受限。

🛠 **方法**：提出Marvell光子结构内存设备，采用光子-CXL混合架构，用无源光纤交换替代电交换，通过无交换机的全交叉拓扑在16个主机间共享32TB内存。

✨ **主要贡献**：相比电CXL池，延迟降低超50%；模拟显示在多轮对话场景中，首令牌生成时间提升6.6倍，消除了缓存驱逐导致的性能悬崖。

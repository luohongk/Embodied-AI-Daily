# SLIM: Saturation-Aware Lightweight Performance Modeling for LLM Serving

- arXiv: https://arxiv.org/abs/2607.29575v1
- arXiv ID: 2607.29575

---

🔍 **核心问题**：LLM服务中增大批处理规模虽能提升吞吐量，但性能会达到平台期，此前研究将其归因于内存带宽限制，却缺乏底层硬件层面的详细验证。

🛠 **方法**：通过GPU硬件剖析技术，定位吞吐量饱和源于解码阶段注意力核的DRAM带宽饱和，并据此提出半解析性能模型SLIM和批处理配置推荐器BCA。

✨ **主要贡献**：首次从硬件层面揭示注意力核算术强度随上下文长度增加而近恒定是带宽饱和的关键；SLIM在预测吞吐和延迟上优于现有基线，BCA可在满足延迟约束下选出最高吞吐配置，并避免高达55GB的GPU内存分配。

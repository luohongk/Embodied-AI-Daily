# SkillMemo: Expert-guided Skill Memory Framework for Compositional Embodied Manipulation

- arXiv: https://arxiv.org/abs/2608.05970v1
- arXiv ID: 2608.05970

---

🔍 **核心问题**：现有具身操作模型（如Diffusion Policy和VLA）因大规模轨迹数据稀缺，在分布外场景下组合泛化能力不足，难以捕捉可复用的技能结构。

🛠 **方法**：提出SkillMemo框架，基于Mixture-of-Experts（MoE）架构隐式分割长程演示为潜在原子技能，并构建技能级情景记忆库（以键值对存储技能表示），推理时检索最相关技能并与当前门控分布融合，以增强动作预测。

✨ **主要贡献**：在仿真基准和真实操作任务上，SkillMemo一致提升DP和VLA骨干模型性能，达到最先进水平并超越π₀.₅，展现出对未见任务配置的强组合泛化能力。

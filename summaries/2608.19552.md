# An end-to-end differentiable transient vapor-compression framework for automated machine sizing and unified optimal control

- arXiv: https://arxiv.org/abs/2608.19552v1
- arXiv ID: 2608.19552

---

🔍 **核心问题**：传统蒸汽压缩热泵系统在设备选型、动态仿真与最优控制之间相互割裂，缺乏统一的可微框架，难以支持自动化设计与电网响应式运行。

🛠 **方法**：提出一个基于JAX的端到端可微有限体积框架，利用预计算的(p,h)双线性流形替代运行时求根，并通过TR-BDF2刚性积分与隐式欧拉MPC共享同一编译物理内核，实现设备选型与动态控制的统一。

✨ **主要贡献**：实现了从热负荷直接自动选型（压缩机排量、膨胀阀面积、换热器管数）与统一预测控制的无缝衔接，实验验证冷却能力MAPE为7.37%，动态误差控制在1.19%–1.62%，为硬件-控制协同设计提供了开源可微基础。

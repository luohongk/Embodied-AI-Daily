# HBF Sucks? A Full-Stack Characterization of High-Bandwidth Flash for KV-Centric LLM Serving

- arXiv: https://arxiv.org/abs/2608.11668v4
- arXiv ID: 2608.11668

---

🔍 **核心问题**：将高带宽闪存（HBF）作为 SSD 式 KV 卸载层的直接替代品，是否真能加速以 KV 缓存为中心的 LLM 推理服务。

🛠 **方法**：构建了基于 HBF 的 Mooncake 式 KV 卸载系统，使用扩展的 TokenSim、四条两小时 Qwen-Bailian 生产轨迹、五种稠密与 MoE 模型，以及 H100/B200 配置进行全栈实测，并辅以成本收益模型和 3D-ICE 热模型分析。

✨ **主要贡献**：发现"更快的设备反而更慢"——端到端延迟上升 2–5.5 倍、SLO 有效吞吐下降 1.1–2.7 倍；揭示瞬态 KV 违反"读为瓶颈、读多于写、带宽可持续"三条件，且写主导导致热限制与 TLC 磨损加剧；指出 HBF 需配合复用感知放置、写预算和热协调才能发挥价值。

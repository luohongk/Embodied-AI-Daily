# NVIDIA Cosmos-H-Dreams: Real-Time Generative Physics Simulation for Surgical Robotics

- arXiv: https://arxiv.org/abs/2608.24199v1
- arXiv ID: 2608.24199

---

🔍 **核心问题**：手术机器人领域的生成式仿真缺乏实时交互能力，传统模拟器难以兼顾逼真外观与软组织动态，且物理实验成本高、难复现。

🛠 **方法**：提出Cosmos-H-Dreams系统，结合动作条件生成模型、教师-学生蒸馏流程（Self Forcing技术）及NVIDIA FlashDreams流式推理库，将预训练手术视频世界模型微调并蒸馏为因果少步学生模型，实现单GPU上约160 FPS的实时流式仿真。

✨ **主要贡献**：首次实现支持人类操作者与学习策略实时控制的手术世界模型，控制器无关（兼容键盘、VR头显、手术机器人控制台等），并开源作为手术教育、合成数据生成及术中决策支持的通用平台。

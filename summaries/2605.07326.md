# GEM: Generating LiDAR World Model via Deformable Mamba

- arXiv: https://arxiv.org/abs/2605.07326v2
- arXiv ID: 2605.07326

---

🔍 **核心问题**：针对基于LiDAR的世界模型发展滞后于相机或占用网格方法的问题，主要挑战在于LiDAR点云的无序性以及难以区分动态物体与静态结构。

🛠 **方法**：提出GEM模型，利用可变形Mamba架构，先通过自定义LiDAR场景分词器将扫描数据压缩为紧凑表示，再经动态-静态分离器进行无监督解耦，最后用三路径可变形Mamba进行选择性扫描与自适应门控融合，以增强时空理解。

✨ **主要贡献**：GEM在多个基准和评估设置下达到最先进性能，显著提升LiDAR世界模型的保真度和想象力；可选集成规划器与BEV布局控制器，支持自主推演和“假设”场景生成，展示了模型的广泛适用性。

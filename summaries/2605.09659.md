# SACK : Safe Active Continual Koopman Learning for Uncertain Systems with Contractive Guarantees

- arXiv: https://arxiv.org/abs/2605.09659v2
- arXiv ID: 2605.09659

---

🔍 **核心问题**：Koopman模型在非线性系统控制中常因模型不确定性和训练与部署间的分布偏移而性能退化，且现有在线自适应方法缺乏安全保证和计算效率。

🛠 **方法**：提出SACK框架，结合离线预训练与在线收缩自适应律，并集成主动学习策略以高效采集数据；控制问题被建模为非凸优化，融入安全约束，并采用鲁棒MPC及基于共形预测的安全裕度校准机制。

✨ **主要贡献**：首次实现带形式化收敛与安全保证的连续自适应Koopman学习，理论推导了模型近似误差界并集成到MPC中，仿真与实验验证了其在不确定系统中的高效性和安全性。

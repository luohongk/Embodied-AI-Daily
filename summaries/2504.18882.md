# SPD Matrix Learning for Neuroimaging Analysis: Perspectives, Methods, and Challenges

- arXiv: https://arxiv.org/abs/2504.18882v3
- arXiv ID: 2504.18882

---

🔍 **核心问题**：神经影像分析中，如何利用对称正定（SPD）矩阵表示脑活动、结构和连接性，并在非欧几里得空间中实现有效的统计推断与机器学习。

🛠 **方法**：系统梳理了从模态特定表示到几何浅层与深度学习范式的演进，将SPD矩阵学习与黎曼几何相结合，统一了经典几何统计与现代AI方法。

✨ **主要贡献**：提出了一个连接神经影像与脑机接口应用的SPD矩阵学习框架，强调其在保持底层结构约束的同时，推动现代AI在脑科学中的扩展。

# Bridging MARL to SARL: An Order-Independent Multi-Agent Transformer via Latent Consensus

- arXiv: https://arxiv.org/abs/2604.13472v2
- arXiv ID: 2604.13472

---

🔍 **核心问题**：解决多智能体强化学习（MARL）中因智能体分解导致的非平稳性、训练不稳定、协调性弱及理论保证不足等问题。

🛠 **方法**：提出共识多智能体Transformer（CMAT），将MARL转化为层次化单智能体强化学习（SARL）框架，使用Transformer编码器处理联合观测空间，并通过解码器自回归生成潜在共识向量，使所有智能体基于该共识同时生成动作，实现顺序无关的联合决策。

✨ **主要贡献**：通过潜在共识机制实现智能体间高效协调，支持单智能体PPO优化联合策略，在星际争霸II、多智能体MuJoCo和谷歌足球等基准任务中，性能优于现有集中式、序列式及传统MARL方法。

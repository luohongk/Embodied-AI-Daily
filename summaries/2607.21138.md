# DTIF: Robust Loop Closure Detection via Delaunay Triangle Topology in Complex Forests

- arXiv: https://arxiv.org/abs/2607.21138v1
- arXiv ID: 2607.21138

---

🔍 **核心问题**：在GNSS信号缺失的复杂森林环境中，低成本激光雷达点云稀疏且噪声大，树干布局重复导致感知混淆，难以实现无初始化回环检测与全局配准。

🛠 **方法**：提出DTIF框架，先提取树干作为稳定地标，用Delaunay三角拓扑编码紧凑场景；再通过边长与半径统计筛选候选子图，结合边-半径一致性验证与强弱顶点支持聚合构建加权对应；最后利用拓扑可靠性权重，在重力对齐下解耦估计偏航、水平与高程平移。

✨ **主要贡献**：在模拟与真实森林数据集上，DTIF实现了高精度配准与低计算开销，在资源受限边缘平台上兼顾了鲁棒性、效率与可部署性。

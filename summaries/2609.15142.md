# C$^2$Nav: Compare Before You Commit for Zero-Shot Vision-and-Language Navigation

- arXiv: https://arxiv.org/abs/2609.15142v1
- arXiv ID: 2609.15142

---

🔍 **核心问题**：在连续环境零样本视觉语言导航（VLN-CE）中，现有系统让VLM直接输出路点、像素、朝向等基数型结果，将生成式回答与几何量或不可逆决策绑定，导致决策脆弱、难以纠错。

🛠 **方法**：提出C²Nav免训练框架，让VLM只做"比较"而非"生成"——由控制器构造候选方案，VLM负责比较选择，几何、阈值与执行留在物理侧；框架包含三个协同模块：Seeing（对物理校验过的候选视角进行序数式注视选举）、Remembering（维护紧凑路线草图并比较相邻指令段假设）、Arriving（结合犹豫阶梯、回看比较与可撤销回退实现可靠停止）。

✨ **主要贡献**：在OpenNav R2R-CE 100协议上，C²Nav搭配Qwen3-VL-8B-Instruct取得41.0% OSR、31.0% SR、16.7% SPL，搭配GPT-5.5达54.0% OSR、44.0% SR、29.0% SPL；消融显示去掉Seeing/Remembering/Arriving后SR分别降至14.0%/25.0%/29.0%，而将比较式回答替换为基数/绝对式提问后SR在空间、过渡、终止环节分别降至12.0%/28.0%/21.0%，表明受限决策接口与更强VLM推理能力是互补而非可互换的。

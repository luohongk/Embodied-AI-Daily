# Lightweight LiDAR-Based Cone Detection Framework Using Random Forest for Formula Student Driverless

- arXiv: https://arxiv.org/abs/2609.11527v1
- arXiv ID: 2609.11527

---

🔍 **核心问题**：Formula Student Driverless 车辆需要可靠、低延迟的感知能力，但现有方案多依赖深度学习与多传感器融合，通常需要 GPU 加速，难以在资源受限平台上运行。

🛠 **方法**：提出一种仅用 LiDAR、面向 CPU 执行的轻量级感知流程，结合地面去除、基于 IMU 的运动补偿、DBSCAN 聚类和基于几何特征的随机森林分类，并通过特征重要性分析将输入特征从 12 个精简至 7 个。

✨ **主要贡献**：在 2,371 个真实 FSD 赛事标注聚类上取得 98.33% 的 F1 分数，CPU 端到端运行时间仅 3.13 ms，并公开数据集、标注工具和训练模型，为资源受限的自动驾驶赛车队提供了可复现的实用基线。

# SpatialCrafter: Single Image World Modeling with Generative 3D Proxies

- arXiv: https://arxiv.org/abs/2608.27073v1
- arXiv ID: 2608.27073

---

🔍 **核心问题**：现有基于视频扩散模型的图像到场景生成方法依赖不完整的条件信号（如稀疏点云或2D全景），导致随机幻觉、长期漂移和3D一致性不佳。

🛠 **方法**：提出两阶段框架SpatialCrafter，先通过Point-anchored Sparse Structure (PaSS) Flow模块生成全局3D代理，再将视频扩散模型重构为生成式延迟细化器，在代理定义的几何上合成高频逼真细节，并引入并行几何注入和代理感知损坏训练策略。

✨ **主要贡献**：构建了首个大规模混合图像到场景数据集（115K场景），在合成和真实数据集上超越现有方法，有效缓解长期漂移，并在快速相机运动和极端视角变化下保持鲁棒性和一致性。

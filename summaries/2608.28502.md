# Recognition Without Enforcement: Configuration-Dependent Failures in LLM Agent Instruction Arbitration and External Control

- arXiv: https://arxiv.org/abs/2608.28502v1
- arXiv ID: 2608.28502

---

🔍 **核心问题**：LLM智能体在指令仲裁中无法可靠执行信任边界，存在“识别-执行差距”——模型能识别伪造来源却仍可能执行冲突工具调用，导致安全漏洞。

🛠 **方法**：通过跨模型、跨配置的大规模实验（46-48个模型端点）系统量化该差距，并设计外部参考监视器，结合认证来源路由与能力门控工具执行，强制拦截伪造/篡改/重放/未签名请求。

✨ **主要贡献**：证明该差距非模型权重固有属性，可通过策略与提示消除；外部强制机制可确定性阻止所有测试攻击（仅发现一个已修补的时钟偏差缺陷），而提示层防御无法跨模型泛化，确立“外部执行优于内部识别”的安全原则。

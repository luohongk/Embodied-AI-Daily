# Unified Embodied VLM Reasoning with Robotic Action via Autoregressive Discretized Pre-training

- arXiv: https://arxiv.org/abs/2512.24125v3
- arXiv ID: 2512.24125

---

🔍 **核心问题**：现有视觉-语言-动作（VLA）模型在开放世界机器人操作中难以同时实现广泛的语义泛化与高精度动作执行，存在推理与精度之间的权衡瓶颈。

🛠 **方法**：提出ERIQ基准（含6K+问答对，覆盖四个推理维度）用于解耦评估机器人具身推理能力；提出FACT动作分词器，基于流匹配将连续控制信号离散化为高保真序列；构建GenieReasoner模型，在统一空间中联合优化推理与动作。

✨ **主要贡献**：揭示了具身推理能力与端到端VLA泛化之间的强正相关性；FACT在保持轨迹重建精度的同时实现了动作离散化；GenieReasoner在真实任务中优于连续动作与先前离散动作基线，为克服推理-精度权衡提供了系统框架。

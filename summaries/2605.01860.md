# Optimizing Trajectory-Trees in Belief Space: An Application from Model Predictive Control to Task and Motion Planning

- arXiv: https://arxiv.org/abs/2605.01860v2
- arXiv ID: 2605.01860

---

🔍 **核心问题**：针对部分可观测机器人规划问题，传统顺序轨迹无法有效应对观测带来的不确定性，导致控制成本高且任务规划受限。

🛠 **方法**：提出在置信空间中优化轨迹树（trajectory-trees），分别用于模型预测控制（PO-MPC）和任务与运动规划（PO-LGP）；开发分布式增广拉格朗日算法（D-AuLa）加速树优化，并利用逻辑几何规划框架扩展至部分可观测场景。

✨ **主要贡献**：通过单分支轨迹树显著降低控制成本，D-AuLa算法满足实时性要求；PO-LGP在小规模置信状态问题上有效，并通过探索性策略扩展到更大问题，验证了轨迹树在不确定环境中的优越性。

# Can LLM Annotations Replace User Clicks for Learning to Rank?

- arXiv: https://arxiv.org/abs/2511.06635v2
- arXiv ID: 2511.06635

---

🔍 **核心问题**：探究大语言模型（LLM）生成的标注能否替代用户点击数据用于学习排序（LTR）模型训练，并分析两者在不同场景下的优劣。

🛠 **方法**：在公开数据集TianGong-ST和工业数据集Baidu-Click上，对点击监督模型与LLM标注监督模型进行多维度对比；随后提出两种融合策略——数据调度（data scheduling）和频率感知多目标学习（frequency-aware multi-objective learning），以整合两类监督信号。

✨ **主要贡献**：发现点击监督模型擅长高频查询及文档权威性信号，LLM标注模型擅长中低频查询及语义匹配；两种融合策略均能提升各频率查询的排序性能，其中频率感知多目标学习效果更优，并开源了代码。

# Towards Grounded GI Endoscopy VQA via Multi-Task Learning on Small VLMs

- arXiv: https://arxiv.org/abs/2607.27122v1
- arXiv ID: 2607.27122

---

🔍 **核心问题**：在胃肠道内窥镜图像视觉问答（VQA）中，模型不仅需要准确回答临床问题，还需确保其内部表征能反映答案背后的视觉证据，以促进临床采纳。

🛠 **方法**：提出一种多任务微调方案，利用现有VQA数据集中的专家标注息肉掩膜和基于Grad-CAM的弱监督定位，构建辅助的定位与描述任务，并通过低秩适配对三个小型视觉语言模型进行微调。

✨ **主要贡献**：在Kvasir-VQA-x1数据集上，多任务微调相比纯VQA微调，在分布内和分布外数据上均一致提升了答案准确率，并改善了答案词与相关图像区域的隐式对齐。

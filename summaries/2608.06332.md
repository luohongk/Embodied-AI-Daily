# GeniWorld: A Generalizable Interactive World Model for Robotic Manipulation via Visual Actions

- arXiv: https://arxiv.org/abs/2608.06332v1
- arXiv ID: 2608.06332

---

🔍 **核心问题**：现有动作条件世界模型在机器人操作中面临动作可控性差和对未见环境泛化能力不足的问题。

🛠 **方法**：基于预训练视频生成模型，利用URDF渲染将数值动作转化为视觉动作表示，显式解耦机器人运动学与环境动态，并构建自回归视频预测模型与高频运动控制集成，实现闭环控制。

✨ **主要贡献**：在仅用有限固定场景数据训练时，GeniWorld在域内表现优异，并能零样本泛化到高度随机的新环境；作为策略评估器在扰动下保持可靠，且能生成多样化操作轨迹以提升下游策略在复杂环境中的性能。

# A Computational Pipeline for Patient-Specific Modeling of Thoracic Aortic Aneurysm: From Medical Image to Finite Element Analysis

- arXiv: https://arxiv.org/abs/2509.12596v2
- arXiv ID: 2509.12596

---

🔍 **核心问题**：针对胸主动脉瘤（TAA）破裂风险评估中缺乏患者特异性生物力学建模的问题，提出从医学影像到有限元分析的完整计算流程。

🛠 **方法**：采用深度学习图像分割从3D CT中提取主动脉区域，将体素分割掩膜转换为结构化六面体网格，并基于患者解剖数据构建有限元模型进行应力分析。

✨ **主要贡献**：建立了患者特异性的TAA生物力学建模流程，结合深度学习分割与六面体网格的有限元模拟，为个体化破裂风险预测和精准治疗提供了可靠的技术框架。

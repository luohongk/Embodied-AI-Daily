# Characterizing CPU-Induced Slowdowns in Multi-GPU LLM Inference

- arXiv: https://arxiv.org/abs/2603.22774v3
- arXiv ID: 2603.22774

---

🔍 **核心问题**：多GPU大语言模型推理性能常受CPU瓶颈限制，而非GPU饱和，导致GPU利用率严重不足，尤其在智能体LLM服务中更为突出。

🛠 **方法**：通过详细实验分析现代LLM服务负载，系统研究CPU资源分配对多GPU推理的影响，并对比不同配置下的性能表现。

✨ **主要贡献**：揭示CPU资源不足导致内核启动延迟、通信停滞和分词延迟等瓶颈；证明增加CPU核数（成本远低于GPU）可显著提升性能，在中等负载下将TTFT延迟降低1.47-7.11倍，且无需额外GPU。

# Towards Automated Domain Model Extraction from Source Code using Heuristics and Open-Source LLMs

- arXiv: https://arxiv.org/abs/2608.12228v1
- arXiv ID: 2608.12228

---

🔍 **核心问题**：在隐私敏感工业环境中，无法使用专有大型语言模型（LLM）进行源码逆向工程，而本地可部署的开源LLM受限于上下文窗口，难以直接处理大型代码库以提取领域模型。

🛠 **方法**：提出一种自动化方法，结合结构性和语义性启发式规则与迭代式LLM推理，通过逐步分析排序后的代码元素子集，克服上下文限制，无需完整系统上下文即可识别领域概念并细化领域边界。

✨ **主要贡献**：在十个项目的数据集上实现了高F1分数，且方法完全可在本地部署的轻量级LLM上运行，特别适用于隐私敏感的工业逆向工程场景，为开源LLM在代码理解中的应用提供了可行方案。

# Generalizing HVAC Control With Domain Randomized Reinforcement Learning

- arXiv: https://arxiv.org/abs/2609.05822v1
- arXiv ID: 2609.05822

---

🔍 **核心问题**：大规模部署暖通空调（HVAC）控制器时，性能常依赖精确的建筑模型或逐站点调参，导致泛化困难。

🛠 **方法**：提出NOMAD-RL，一种基于域随机化强化学习的通用控制器，通过循环策略实现部分可观测下的在线自适应，并采用物理信息归一化流进行自适应域随机化，以建模热区参数的关联与多模态分布。

✨ **主要贡献**：该方法在单区和多区场景中均优于PID和无随机化RL基线，性能接近调优的MPC，尤其在多区场景中表现突出，展示了物理信息自适应域随机化对鲁棒、可迁移HVAC控制的潜力。

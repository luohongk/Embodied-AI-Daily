# Traj-LeWM: Path-Aware World-Model Planning via Latent Trajectory Cost

- arXiv: https://arxiv.org/abs/2608.14125v1
- arXiv ID: 2608.14125

---

🔍 **核心问题**：LeWM视觉世界模型在规划时仅依赖预测终点与目标的距离，忽略了完整轨迹信息，导致候选动作排序可能不准确。

🛠 **方法**：提出Traj-LeWM，在保留LeWM局部动态学习和终点评分的基础上，引入目标条件化的潜在轨迹代价（LTC），在训练时用轨迹级偏好监督补充下一帧预测，在规划时将LTC与终点距离联合排序。

✨ **主要贡献**：在Push-T、OGBench-Cube、Reacher和Two-Room任务上分别提升3、14、7、7个百分点，并通过消融实验验证了轨迹级表征塑造与路径感知排序的互补作用。

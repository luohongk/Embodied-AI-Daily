# Automatic Pronunciation Error Detection and Correction of the Holy Quran's Learners Using Deep Learning

- arXiv: https://arxiv.org/abs/2509.00094v2
- arXiv ID: 2509.00094

---

🔍 **核心问题**：针对《古兰经》学习者发音错误检测与纠正任务，解决高质量标注数据稀缺和发音评估量化困难的问题。

🛠 **方法**：构建98%自动化的数据处理流水线（含基于微调wav2vec2-BERT的停顿点切分、转录及Tasmeea算法验证），提出自定义Quran Phonetic Script（QPS）编码体系（11级音素/属性编码），并设计多级CTC模型进行发音错误检测。

✨ **主要贡献**：发布848小时音频（286K标注话语）、qdat_bench基准（159个真实错误样本），多级CTC模型在测试集和基准上分别达到0.21%和1.94%的平均音素错误率（PER），Tajweed规则F1分数达75.8%，全部代码已开源。

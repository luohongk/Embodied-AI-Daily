# S2-HWM: Sparse Event-Structured Hierarchical World Model for Long-Horizon Surgical Robot Manipulation

- arXiv: https://arxiv.org/abs/2608.13103v1
- arXiv ID: 2608.13103

---

🔍 **核心问题**：长时程手术机器人操作中任务奖励稀疏，且有意义的交互变化间隔不规则，现有世界模型难以捕捉可变时长的任务进展。

🛠 **方法**：提出S2-HWM，一种稀疏事件结构化的分层世界模型，从原始潜轨迹中学习稀疏事件证据，协调事件级管理器与原始步工作器；事件证据调度管理器目标更新，并形成事件转移模型（ETM）预测下一边界状态、段时长和累积奖励，实现可变时长的事件级预测。

✨ **主要贡献**：在SurRoL PegTransfer任务上达到98.7%成功率，比扁平GAS DreamerV3基线提升22.7个百分点，验证了事件级分层建模对长时程稀疏奖励任务的有效性。

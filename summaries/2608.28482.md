# How Proper Scoring Rules Shape LLM Forecasting

- arXiv: https://arxiv.org/abs/2608.28482v1
- arXiv ID: 2608.28482

---

🔍 **核心问题**：本文探讨在大型语言模型（LLM）进行二分类事件预测时，不同“适当评分规则”（proper scoring rules）作为训练目标，是否会导致模型性能和行为上的显著差异。

🛠 **方法**：作者将五种适当的评分规则（如Brier分数、对数分数等）分别作为训练目标，对LLM进行训练，并评估其在真实世界已解决事件上的预测校准度、概率使用情况，以及偏差、信息量和噪声等特征。

✨ **主要贡献**：研究发现，尽管这些评分规则理论上都鼓励真实概率报告，但训练出的模型在校准度、概率使用和误差结构上存在明显差异；例如，Brier训练的模型在Brier分数和AUC-ROC上最优，而对数训练的模型在对数分数和校准误差上最优。这表明评分规则的选择不仅影响预测准确性，还影响误差的组成方式，且部分差异可能源于训练随机性。

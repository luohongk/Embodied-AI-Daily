# Parameter Exploration for RLVR via Variational Learning

- arXiv: https://arxiv.org/abs/2608.09805v1
- arXiv ID: 2608.09805

---

🔍 **核心问题**：现有LLM强化学习（RLVR）中的探索主要局限于动作空间（如温度缩放），无法重新排序token，导致探索受限、训练发散或停滞。

🛠 **方法**：提出参数空间探索方法——扰动参数策略优化（3PO），通过从后验分布中采样不同策略生成rollout，并采用多种采样策略和rollout分组方式估计奖励。

✨ **主要贡献**：在OLMo-3-1025-7B和Qwen2.5-Math-7B上，3PO在数学推理和代码生成任务中一致优于标准GRPO，且计算成本相近；同时显著减少零优势组和畸形rollout，证明参数空间探索能有效提升LLM强化学习性能。

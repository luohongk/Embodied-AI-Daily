# A Comparative Evaluation of Deep Learning Object Detection Models on a Real-World Multi-Plant Dataset from Africa

- arXiv: https://arxiv.org/abs/2608.11053v1
- arXiv ID: 2608.11053

---

🔍 **核心问题**：现有农业目标检测模型多在受控数据集上评估，无法真实反映非洲等地区的田间复杂条件，缺乏对实际农场环境下模型性能的系统比较。

🛠 **方法**：使用从尼日利亚农场采集的真实多作物数据集AgriAISeg（含3,382张芝麻、卷心菜和番茄图像），在光照变化、遮挡和视角差异等条件下，训练并比较YOLOv5、YOLOv8、YOLO11、YOLO26、Faster R-CNN和RT-DETR六种检测模型，以精确率、召回率、mAP@0.5和mAP@0.5:0.95为评估指标。

✨ **主要贡献**：RT-DETR表现最佳（精确率0.768，mAP@0.5:0.95为0.624），YOLOv8和YOLO11性能稳定；Faster R-CNN精度显著较低（mAP@0.5仅0.466），且YOLO系列训练效率更高。研究证明单阶段和基于Transformer的检测器在真实农业环境中更可靠高效，为非洲精准农业提供了实用模型选择依据。

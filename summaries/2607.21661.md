# GRACE: Gradient-Free Robot Action Generation via Combined Diffusion-MPPI Posterior Mean Estimation

- arXiv: https://arxiv.org/abs/2607.21661v1
- arXiv ID: 2607.21661

---

🔍 **核心问题**：现有扩散策略在机器人动作生成中依赖可微分的引导成本，无法处理非可微分的实际安全约束（如碰撞检测、关节限制等）。

🛠 **方法**：提出GRACE框架，结合扩散模型与模型预测路径积分（MPPI）控制，仅通过正向成本评估来引导预训练扩散策略，在每一步反向过程中用单次MPPI更新估计条件后验均值。

✨ **主要贡献**：在可微分成本下可恢复传统梯度引导效果，在仿真中成功率高于现有基线方法；在真实7自由度机械臂上，成功避免未引导策略每次都会碰撞的障碍物。

# Persona-Execution Separation: An Architecture Pattern for Evolving LLM Agents under Execution Audit

- arXiv: https://arxiv.org/abs/2608.27427v1
- arXiv ID: 2608.27427

---

🔍 **核心问题**：在受治理的组织中，LLM智能体需要让“人设”（指令、语气、自我呈现）自由演化，同时保持“执行”（有状态、可审计的工作）可追踪，但单一信任域难以同时低成本满足这两个需求。

🛠 **方法**：提出Persona-Execution Separation（PES）架构模式，将人设与执行置于不同信任域，通过受治理的契约桥连接；人设可漂移，执行匿名且可审计，并辅以审批矩阵、数据防泄漏（DLP）和审计机制来强制跨域交互。

✨ **主要贡献**：从三个目标（自由漂移、执行可追踪、解耦）推导出PES的必要性，证明在LLM表征不可区分性下，任何单域机制都需重建PES但耦合成本更高；通过受监管数字员工平台的开发/试点案例（五个月决策）和机制检查验证了PES的有效性，并发现预分离构建中执行路径因疏忽而非构造性解耦，而PES将其变为可审计的架构规则。

# Security Tests as Executable Specifications for LLM Code Generation: Benefits, Trade-offs, and Coverage Limits

- arXiv: https://arxiv.org/abs/2608.09740v1
- arXiv ID: 2608.09740

---

🔍 **核心问题**：大型语言模型生成的代码功能正确但存在安全漏洞，而安全干预可能破坏功能行为。本文研究安全测试作为可执行规范，能否在代码生成前和迭代修复中同时提升功能与安全性。

🛠 **方法**：提出SecTDD框架，分离三个因素——测试是否预先展示、失败执行是否触发修订、失败如何选择与表示。使用行为划分的可见/隐藏测试和字节相同的初始候选，在2,705条轨迹、31个任务、3个安全基准、16个CWE类别和2个模型家族上评估。

✨ **主要贡献**：预先展示所有可见测试使功能与安全联合成功率平均提升19.3个百分点，但仅改善9个条件中的7个，损害2个；结构化反馈修复80个候选无回归，原始反馈修复83个但有3个回归；所有常见机制下，通过全部可见测试的候选仍会失败于隐藏行为族。结果表明可执行反馈能修复安全代码生成，但效果依赖模型、任务、反馈入口和测试覆盖。

# An Omitted Mode Is a Rare Rule: The Sampling-Verification Danger Law in Continuous Code World Models

- arXiv: https://arxiv.org/abs/2608.17956v1
- arXiv ID: 2608.17956

---

🔍 **核心问题**：在连续控制任务中，LLM合成的代码世界模型仅通过采样验证被接受时，这种接受究竟能保证什么？论文揭示了“遗漏模式”这一罕见规则如何导致模型被利用，并造成巨大性能损失。

🛠 **方法**：将验证流程的危险性形式化为期望风险，精确推导出漏检概率为(1-r)^N；提出边界点上的局部化预算定理，并利用版本空间证书分析模型可辨识性；通过真实LLM合成实验和重评分验证，系统检验采样验证的局限性。

✨ **主要贡献**：证明采样验证仅能保证样本一致性，无法覆盖被利用的规划器查询（约2%）；在混合仪器上，模式盲模型被利用导致几乎全部可达回报的遗憾；发现可辨识性是仪器的可测属性，且存在与所有样本一致但无害的入口规则类；GPT-5.x在1D修复中表现良好（105/111），但2D区域完全失败（0/156），表明规则定位与归纳存在本质困难。

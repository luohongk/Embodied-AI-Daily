# LEGO: Leveled Language Gaussian Splatting

- arXiv: https://arxiv.org/abs/2608.10057v1
- arXiv ID: 2608.10057

---

🔍 **核心问题**：现有3D场景理解方法难以捕捉场景中固有的语义层级结构（如“花盆→花束→花苞→花瓣”），且多粒度2D分割缺乏跨视角一致性。

🛠 **方法**：提出LEGO框架，将多视角SAM产生的易变粒度自适应重分级为统一的3D一致层级，并用CLIP嵌入对各层级片段进行语义标注，同时结合空间关系构建层级语言场景图。

✨ **主要贡献**：实现了3D场景的多层级、开放词汇分割与上下文感知空间推理，在可提示和开放词汇3D分割基准上均达到最先进性能，显著提升层级分解与复杂空间理解能力。

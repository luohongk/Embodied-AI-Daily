# Dynamic UAV-based search operations using probabilistic diffusion modeling of Man Overboard incident victims

- arXiv: https://arxiv.org/abs/2608.02093v1
- arXiv ID: 2608.02093

---

🔍 **核心问题**：解决邮轮人员落水（Man Overboard）后，如何快速预测落水者可能位置并利用无人机高效搜索，以提升搜救成功率的问题。

🛠 **方法**：采用扩展卡尔曼滤波（EKF）结合Leeway漂移模型预测落水者动态位置，并设计五种无人机搜索策略（Zigzag、Boustrophedon、Spiral、Probability Informed Search及改进的IPIS），在仿真环境中评估其性能。

✨ **主要贡献**：提出改进的概率知情搜索（IPIS）方法，在落水后20分钟启动搜索且检测成功率仅30%的条件下，平均找到落水者的成功率超过80%；同时公开了全部仿真代码，便于复现和进一步研究。

# UniMPA: A Unified Memory-Prediction-Action Model via Action-Grounded Transition Modeling

- arXiv: https://arxiv.org/abs/2609.11875v1
- arXiv ID: 2609.11875

---

🔍 **核心问题**：现有VLA模型在观察→动作学习中存在“转换可实现性鸿沟”，表现为转换歧义（相似观察对应不同操作阶段）、预测-执行不匹配（视觉合理的预测未必物理可实现）、经验-实现不匹配（历史可行动作未必适应当前场景）三个耦合问题。

🛠 **方法**：提出UniMPA统一记忆-预测-动作模型，通过共享的“动作锚定转换接口”解决上述问题：用持续-选择性未来预测（持续潜流跟踪任务进度+关键像素流解析细粒度交互）消除转换歧义；用时间视觉-动作记忆库检索历史可实现的视觉-动作经验以验证预测的物理可执行性；用动作-视觉记忆库检索视觉锚定的动作原型，并通过原型偏置流将流源推向历史支持的动作流形以实现上下文自适应。

✨ **主要贡献**：构建了统一的记忆-预测-动作框架，以动作锚定的转换建模为核心，将未来预测、物理可执行性验证与上下文自适应动作细化整合于共享接口，缓解了观察→动作学习中的转换可实现性鸿沟。

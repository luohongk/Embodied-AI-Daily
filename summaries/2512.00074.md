# Bootstrap Dynamic-Aware 3D Visual Representation for Scalable Robot Learning

- arXiv: https://arxiv.org/abs/2512.00074v4
- arXiv ID: 2512.00074

---

🔍 **核心问题**：现有3D视觉预训练方法在识别和分割任务上表现优异，但在机器人操作任务中效果不佳，原因是缺乏状态-动作-状态的动态建模，且显式几何重建存在不必要的冗余。

🛠 **方法**：提出AFRO框架，一种自监督方法，无需动作或重建监督即可学习动态感知的3D表示。它将状态预测建模为生成式扩散过程，在共享潜空间联合建模前向和逆动态，并通过特征差分和逆一致性监督防止动作学习中的特征泄漏。

✨ **主要贡献**：AFRO在16个模拟和4个真实世界任务中显著提升操作成功率，优于现有预训练方法，且随数据量和任务复杂度扩展良好。定性可视化表明其学习到语义丰富、判别性强的特征，为机器人3D表示学习提供了有效预训练方案。

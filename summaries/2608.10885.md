# ConfTriage: A Calibration-Aware LLM Triage Framework for Pulmonary Nodule Malignancy with Selective Specialist Deferral

- arXiv: https://arxiv.org/abs/2608.10885v1
- arXiv ID: 2608.10885

---

🔍 **核心问题**：肺结节恶性预测通常依赖需要大量标注影像数据和任务特定训练的专业深度学习模型，本文探讨通用大语言模型（LLM）仅基于结节属性的自然语言描述，能否作为校准的分诊层。

🛠 **方法**：提出ConfTriage框架，以语言为模态、校准为安全机制，对低置信度病例选择性转诊至专业深度学习模型；并证明有限样本组合误差界和过风险受LLM概率L1校准误差控制的理论保证。

✨ **主要贡献**：在LIDC-IDRI上对五个前沿LLM进行七路输入消融，显示自然语言描述主导诊断信号，而低层图像统计几乎无诊断价值；ConfTriage实现F1 88.22%、AUC 0.92，仅用零样本LLM推理解决76.5%病例，仅将不确定病例转诊至专业模型，为通用LLM与专业AI结合提供实用路径。

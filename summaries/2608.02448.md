# UAV-Based Environmental Monitoring of Rip-Current Indicators Using Wavelet-Derived Texture Features

- arXiv: https://arxiv.org/abs/2608.02448v1
- arXiv ID: 2608.02448

---

🔍 **核心问题**：针对无人机RGB影像中离岸流（裂流）视觉特征微弱、易受光照和海况干扰，难以可靠监测的问题，提出一种基于物理信息的自动检测方法。

🛠 **方法**：将离散小波变换（DWT）提取的空间-频率纹理特征与深度学习结合，设计了多种融合策略（如通道替换、双流注意力融合），并分别用CNN进行图像级分类、用YOLOv8进行目标级定位。

✨ **主要贡献**：在评估数据集上，小波纹理特征显著优于纯RGB模型；双流架构分类准确率超95%，通道替换策略使YOLOv8定位mAP@50达94%；可解释性分析证实模型关注与离岸流相关的波浪缺口区域，为无人机海滩安全决策支持提供了可行方案。

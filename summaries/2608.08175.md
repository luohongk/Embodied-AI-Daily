# AOC-CBS: Anytime-Optimal Continuous-time Conflict-Based Search for Generalised Multi-Agent Path Finding

- arXiv: https://arxiv.org/abs/2608.08175v1
- arXiv ID: 2608.08175

---

🔍 **核心问题**：传统多智能体路径规划（MAPF）假设离散时间、圆形智能体、单一目标等，无法处理异构车队、非几何冲突、任务序列等复杂场景。本文旨在解决这些限制下的广义MAPF问题。

🛠 **方法**：提出AOC-CBS算法，一种任意时间最优的连续时间冲突搜索方法，结合修复函数组合（含新提出的Tier-Prioritized Safe Interval Path Planning）和多核并行处理，支持非凸智能体沿光滑运动学可行轨迹移动。

✨ **主要贡献**：AOC-CBS保证最终返回最优解，并全程提供已知最优性差距上界；在标准基准测试中，与精确求解器OC-CBS相比，在最优解质量上相当，但可扩展性从数十个智能体提升至数百个（当接受有界最优性差距时）。

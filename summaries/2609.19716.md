# GAPrompt++: Multi-Granular Geometry-Aware Point Cloud Prompt for 3D Vision Model

- arXiv: https://arxiv.org/abs/2609.19716v1
- arXiv ID: 2609.19716

---

🔍 **核心问题**：现有基于提示的3D点云参数高效微调方法忽略了点云固有的几何结构，无法同时编码细粒度几何线索与粗粒度结构语义，也难以在模型层级中有效传播这些信息，限制了适配能力。

🛠 **方法**：提出GAPrompt++多粒度几何感知提示方法，包含三个组件——Point Shift Prompter（跨尺度提取多粒度几何特征）、Keypoint Prompter（自适应生成点级提示以突出局部几何显著性和细粒度结构细节）、Prompt Propagation机制（将多粒度几何线索注入整个特征提取层级）。

✨ **主要贡献**：在多个基准上达到基于提示的PEFT方法中的最优性能，甚至超越全量微调，且可训练参数不足2%；同时构建了基于3D高斯泼溅和多视图立体重建的两个更具挑战性的新基准，以缓解现有评测数据集饱和问题。

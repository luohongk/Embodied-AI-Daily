# EnvACE: Internalizing Environment Dynamics via World Rehearsal for Agentic Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.06197v1
- arXiv ID: 2608.06197

---

🔍 **核心问题**：训练大语言模型智能体进行长程工具使用时，依赖真实或合成可执行环境及外部模拟器，其构建和验证成本高昂且难以落地。

🛠 **方法**：提出EnvACE，一种智能体强化学习方法，用“世界排演”替代训练中的外部环境交互——策略交替生成工具调用和扮演环境产生响应，并基于排演响应做后续决策，两角色联合端到端优化。

✨ **主要贡献**：策略通过排演将动作-环境响应关系内化到参数中，形成支持决策的智能体世界模型；在BFCL-v4、tau²-Bench、VitaBench和FinMCP-Bench上表现优异，超越环境扩展基线，且测试时可进行私有排演提升性能，无需额外外部交互。

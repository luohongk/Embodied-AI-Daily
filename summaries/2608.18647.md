# Progressive Experience Fusion for Multi-Task World Model Control in Endovascular Navigation

- arXiv: https://arxiv.org/abs/2608.18647v1
- arXiv ID: 2608.18647

---

🔍 **核心问题**：解决自主血管内导航中，控制器需在多变血管解剖结构上完成长距离、多阶段路径规划的挑战。

🛠 **方法**：提出渐进式经验融合（PEF）训练多任务TD-MPC2控制器，并结合基于残差动作序列离散度的自适应模型预测路径积分规划视界，以及患者特定模拟中的微调。

✨ **主要贡献**：PEF在已知解剖训练集上平均成功率74%，显著优于SAC（37%）；在30个血管训练后，对10个未见血管成功率90%；在体外卒中患者血管荧光镜环境下，经微调后路径比从63%提升至80%，验证了多血管训练与患者特定适应的可行性。

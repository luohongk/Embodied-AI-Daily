# Efficient LLM-Generated Shuttling Compilers for Complex Trapped-Ion Architectures

- arXiv: https://arxiv.org/abs/2607.24714v1
- arXiv ID: 2607.24714

---

🔍 **核心问题**：针对复杂离子阱量子计算架构，如何高效自动生成离子穿梭编译器，以替代传统数月的人工开发过程。

🛠 **方法**：使用单一前沿大语言模型（Claude Opus 4.7）从文字规范出发，生成并迭代优化完整的Python穿梭编译器代码，从线性分段陷阱逐步扩展到带结的陷阱及通用连接图架构。

✨ **主要贡献**：首次证明未经修改的大语言模型可生成正确且具有竞争力的穿梭编译器，在基准测试中穿梭时间步数最多减少76%（线性架构）和39%（带结架构），并将新架构的开发时间从数月缩短至数天。

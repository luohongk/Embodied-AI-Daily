# FibVLA: An Efficient Temporal Vision-Language-Action Model with Fibonacci Sampling

- arXiv: https://arxiv.org/abs/2607.29596v1
- arXiv ID: 2607.29596

---

🔍 **核心问题**：现有视觉-语言-动作模型（VLA）在捕捉长时序信息时推理效率下降，难以兼顾时序感知与实时响应。

🛠 **方法**：提出FibVLA框架，采用对数回溯采样（Fibonacci采样）处理本体感知状态和视觉帧，以低冗余捕捉长期时序依赖；动作专家使用流匹配生成动作分布，并引入Fibonacci循环推理策略，基于闭环反馈生成长期规划步骤。

✨ **主要贡献**：在不重训大规模视觉编码器的情况下，显著提升动作平滑度和成功率；实际评估中相比基于视频的基线方法，实时响应性更优，验证了时序感知与推理效率的平衡可行性。

# Silent Failures in Quantized LLM Reasoning: A Taxonomy-Based Analysis of Hollow Convergence and Failure Mode Shifts

- arXiv: https://arxiv.org/abs/2607.09999v2
- arXiv ID: 2607.09999

---

🔍 **核心问题**：揭示量化后的大语言模型在保持任务准确率的同时，可能隐藏推理过程的质量退化，特别是“空心收敛”等无法被标准评估发现的失败模式。

🛠 **方法**：提出六类推理失败分类体系（Cohen’s κ=0.906），对5个指令微调模型（3B-14B参数）在3种量化精度下生成3万条思维链输出进行人工标注与统计分析。

✨ **主要贡献**：发现NF4量化导致小模型“空心收敛”显著下降、错误模式从“信心滚雪球”转向“捷径崩溃”，且该现象无法通过表层文本特征可靠检测（F1=0.53），揭示了量化部署中隐藏的推理质量风险。

# RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning

- arXiv: https://arxiv.org/abs/2609.20784v1
- arXiv ID: 2609.20784

---

🔍 **核心问题**：多轮智能体强化学习仅能获得轨迹级的稀疏标量奖励，现有自蒸馏方法依赖特权信息构建教师，但特权信息未必可靠，且教师监督的收益随训练阶段变化。

🛠 **方法**：提出 RetireOPD，先用以环境奖励优化的、解耦的技能条件教师，再通过 RL 与在线策略蒸馏（OPD）联合训练无技能学生；采用自适应退役机制，当师生差距不再缩小且学生达到教师成功率的设定比例时，自动放弃教师，转为纯 RL 训练。

✨ **主要贡献**：在 Qwen2.5 1.5B–7B 模型上，ALFWorld 成功率较 RL 基线提升 14.1%–18.8%，WebShop 准确率提升 11.8%–19.0%，并在所有设置下超越其技能条件教师。

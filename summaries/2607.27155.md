# OmegaUse-OfficeVal: Benchmarking LLM Agents on Long-Horizon Office-Suite Tasks with Economic Grounding

- arXiv: https://arxiv.org/abs/2607.27155v1
- arXiv ID: 2607.27155

---

🔍 **核心问题**：现有基准测试难以评估LLM代理在办公套件长周期任务中的经济可行性，缺乏对人类成本与模型推理成本的直接对比。

🛠 **方法**：构建包含100个隐私保护型办公任务的OmegaUse-OfficeVal基准，为每个任务标注人类工时和任务价格代理两种经济信号，并开发基于细粒度评分规则的代码验证器。

✨ **主要贡献**：首次实现任务级经济性评估，揭示当前LLM虽成本更低、速度更快，但交付质量尚未达到人类水平；开源代码与数据集，提供经济加权评估新范式。

# Runtime Uncertainty Monitoring for LLM-Based Multi-Agent Systems Using Bayesian Networks

- arXiv: https://arxiv.org/abs/2607.25877v1
- arXiv ID: 2607.25877

---

🔍 **核心问题**：如何量化并监控基于大语言模型的多智能体系统在精算建模等高风险决策场景中的运行时不确定性，以避免错误风险评估和不公平定价。

🛠 **方法**：提出一个多智能体框架，由中心枢纽协调数据准备、建模、审核和解释等专业智能体，利用令牌级对数概率经长度归一化后转换为校准的任务级置信度，再通过贝叶斯网络传播不确定性。

✨ **主要贡献**：创新性地将对数概率转化为校准置信度并集成到贝叶斯网络中，实现了对工作流稳定性和运行时不确定性的实时监控，同时保持基线精算性能。

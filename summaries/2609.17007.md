# Search-Based Metamorphic Testing of Vision-Language Models in Autonomous Underwater Robotic Software

- arXiv: https://arxiv.org/abs/2609.17007v1
- arXiv ID: 2609.17007

---

🔍 **核心问题**：如何评估视觉语言模型（VLM）在自主水下机器人（AUR）软件中的质量与可靠性，以支持其集成与改进。

🛠 **方法**：提出基于搜索的蜕变测试方法 MetaVLM，利用 NSGA-II 多目标搜索算法，寻找对水下图像的最小变换集合，以诱发 VLM 的错误预测，并与随机搜索基线进行对比。

✨ **主要贡献**：在开源 VLM（BLIP 和 CLIP）上验证了 MetaVLM 的有效性，揭示了各模型在 AUR 场景下的优势与局限，并为 VLM 软件系统的质量保障提供了实践启示。

# The Robot Data Factory

- arXiv: https://arxiv.org/abs/2609.16705v1
- arXiv ID: 2609.16705

---

🔍 **核心问题**：Physical AI 的发展不能仅依赖大规模原始机器人数据集，而需要保留“感知-行动-后果”闭环的物理交互经验，如何持续生成、验证和复用这种经验是核心挑战。

🛠 **方法**：提出 Robot Data Factory（RDF），一套任务驱动的基础设施与方法论，通过可复现任务、技能课程、多模态同步感知、外部真值、智能体机器人网络和数据流水线，实现“部署-测量-学习-重复”的闭环循环。

✨ **主要贡献**：形式化了机器人经验及其质量，提出任务-技能-片段-数据集-基准-能力层级，推导了连接机器人规模、传感速率、存储、训练算力与具身智能集群需求的量化扩展规律，并在家庭、环境、能源三大物理训练场中实例化，将机器人数据生成重构为持续的科学生产过程。

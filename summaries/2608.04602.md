# Adaptive Intrusion Detection System using Transformer-Based Neural Networks and Continual Learning Approach with Adversarial Investigation

- arXiv: https://arxiv.org/abs/2608.04602v1
- arXiv ID: 2608.04602

---

🔍 **核心问题**：网络入侵检测系统（IDS）在部署后因威胁分布变化而性能衰退，现有持续学习方法存在灾难性遗忘，且回放缓冲区可能成为新的攻击面。

🛠 **方法**：提出自适应IDS框架，结合表格Transformer编码器与类别平衡的经验回放缓冲区，在每次更新时回放良性流量以稳定决策边界；引入类别-实例增量（CII）场景，并测试标签翻转和后门投毒攻击对缓冲区的威胁。

✨ **主要贡献**：在CICIDS2017上，传统类增量设置下准确率达0.9994，CII下为0.9989，遗忘可忽略，远超微调、EWC、LwF和iCaRL基线；但发现缓冲区易受攻击——1%标签翻转使模型崩溃（准确率0.0053），后门攻击在保持0.97准确率的同时使触发流攻击成功率达95%，表明缓冲区完整性是严格的操作要求。

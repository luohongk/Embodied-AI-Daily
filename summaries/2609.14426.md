# Learning-Based Dynamic Obstacle Avoidance for a UAV Using Only Three Range Sensors

- arXiv: https://arxiv.org/abs/2609.14426v1
- arXiv ID: 2609.14426

---

🔍 **核心问题**：在未知动态环境中，仅依靠三个低成本测距传感器、且无人机仅有偏航单自由度的强部分可观测条件下，实现实时静态与动态障碍物规避及目标到达。

🛠 **方法**：将行为栅格地图（behavior grid map）表示与深度强化学习相结合，采用PPO算法进行连续控制策略学习，通过状态表示与控制策略的协同设计，将稀疏测距数据聚合为结构化局部表示以支持实时决策。

✨ **主要贡献**：仅用三个测距传感器即可实现可靠导航，仿真中成功率显著优于PPO变体和MPC（小规模高拥堵场景94% vs. 79–90%，大规模高拥堵场景83% vs. 62–71%），并在四个真实场景实验中验证了无碰撞到达目标的可行性。

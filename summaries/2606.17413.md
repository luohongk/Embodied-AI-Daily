# Amortized Probabilistic Retrieval of Atmospheric CO2 from OCO-2 Spectra Using Deep Learning with Laplace Approximations and Normalizing Flows

- arXiv: https://arxiv.org/abs/2606.17413v2
- arXiv ID: 2606.17413

---

🔍 **核心问题**：OCO-2卫星反演大气CO₂（XCO₂）的传统全物理方法计算昂贵，且对后验分布施加了严格的高斯假设，难以刻画真实的非对称不确定性。

🛠 **方法**：提出深度学习框架，对每个光谱波段单独编码，结合拉普拉斯近似与条件归一化流进行摊销式概率推断，在高保真OCO-2模拟集合（含前向模型误差）上训练，并与v10 ACOS全物理反演对比。

✨ **主要贡献**：推理速度从分钟级降至毫秒级，XCO₂精度优于业务算法，归一化流能刻画高斯无法表示的非对称后验，其预测密度优势在精度优势消失时依然保持；主要局限在于稀疏观测条件下校准退化，源于模拟场景多样性而非方法本身。

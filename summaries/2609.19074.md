# RLLBC-Lib: An Educational Code Library for Reinforcement Learning and Learning-Based Control

- arXiv: https://arxiv.org/abs/2609.19074v1
- arXiv ID: 2609.19074

---

🔍 **核心问题**：强化学习涉及多个对象之间复杂的多周期交互，其动态过程难以理解，学生和学习者入门门槛较高。

🛠 **方法**：开发了RLLBC-Lib代码库，以表格型RL方法为核心构建完整库以夯实理论基础，并采用相同设计原则实现深度RL库，同时提供对比RL与其他基于学习的控制方法的实现示例。

✨ **主要贡献**：通过清晰的实现降低了RL入门门槛，揭示了表格型与深度RL方法之间的平行关系，并为创建带自动评分的编程作业提供了理想基础。

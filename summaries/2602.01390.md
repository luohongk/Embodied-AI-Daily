# Toward Scalable Audio Description Quality Control: A Workflow for Evaluating Human and VLM Raters

- arXiv: https://arxiv.org/abs/2602.01390v3
- arXiv ID: 2602.01390

---

🔍 **核心问题**：音频描述（AD）的质量控制缺乏系统性方法，现有评估依赖NLP指标和短视频片段，难以规模化评估长视频AD质量。

🛠 **方法**：提出一种基于项目反应理论（IRT）的工作流，利用专家建立的地面真值，对VLM（视觉语言模型）和人类评分者的评估能力进行量化比较，并采用六维评估框架（源自专业指南及盲人顾问反馈）。

✨ **主要贡献**：发现顶级VLM在评分上可接近人类水平，但其推理过程不如人类可靠和可操作；提出混合评估系统（VLM+人工监督）的可行性，为规模化AD质量控制提供了新路径。

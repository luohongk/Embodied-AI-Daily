# Vision-based Goal-Reaching Control for Mobile Robots Using a Hierarchical Learning Framework

- arXiv: https://arxiv.org/abs/2601.00610v2
- arXiv ID: 2601.00610

---

🔍 **核心问题**：面向大型移动机器人的视觉目标到达控制，解决强化学习探索式训练难以安全部署的问题。

🛠 **方法**：提出分层框架，包括立体视觉位姿估计、带约束的RL运动规划、基于SCG训练的DNN前馈映射与对数障碍自适应鲁棒控制，以及安全监督与返回逻辑。

✨ **主要贡献**：在6000 kg机器人上实现3–4 cm终点RMSE，优于两种RAC基线，并成功实现故障注入后的自主恢复，验证了分层框架的鲁棒性与实用性。

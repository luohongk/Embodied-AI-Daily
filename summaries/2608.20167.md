# BreakGuard: Towards Detecting Dependency Breaking Changes with LLM-Generated Tests

- arXiv: https://arxiv.org/abs/2608.20167v1
- arXiv ID: 2608.20167

---

🔍 **核心问题**：开源库版本更新时可能引入破坏性变更（BCs），导致客户端应用崩溃或行为异常，而现有客户端测试套件因库覆盖不足难以检测这些变更。

🛠 **方法**：提出BreakGuard方法，静态提取客户端中调用目标库方法的所有焦点方法，并利用大语言模型（如GPT-4o、Qwen3-coder-480B等）为每个焦点方法生成针对性测试用例，通过对比变更前后版本的测试通过情况来检测BCs。

✨ **主要贡献**：在89个真实BCs上评估，最佳配置下检测率达30.3%（27/89），平均每个检测到的BC成本约0.90美元；该方法能检测多种库类别的BCs，但对崩溃型变更的检测可靠性高于行为型变更。

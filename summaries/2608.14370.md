# A Hybrid LLM-Based Framework for Automated Security Annotation Generation in Business Process Models

- arXiv: https://arxiv.org/abs/2608.14370v1
- arXiv ID: 2608.14370

---

🔍 **核心问题**：从自然语言安全需求文档中为BPMN业务流程模型生成准确、完整的安全标注（SecBPMN2）目前依赖人工专家，耗时且易出错。

🛠 **方法**：提出混合框架，结合大语言模型（LLM）进行语义提取、模式约束映射、规则归一化和确定性验证，以BPMN模型和安全需求文档为输入，自动生成符合SecBPMN2规范的安全标注。

✨ **主要贡献**：在27个跨领域流程模型数据集上，框架生成的标注结构有效且模式完整性高；与人类分析师相比，精确率显著提升（0.58 vs 0.29），召回率相当（0.52 vs 0.50），错误标注减少近50%，且生成速度远快于人工，为安全优先的BPM建模提供了可扩展的自动化基础。

# MVFA: A Multi-View Text-Guided Multimodal Fusion LLM Adapter for Sentiment Analysis and Emotion Recognition

- arXiv: https://arxiv.org/abs/2609.06188v1
- arXiv ID: 2609.06188

---

🔍 **核心问题**：多模态情感分析与情绪识别中，将大语言模型（LLM）适配到文本、音频、视觉异构模态时，全量微调计算成本过高，而现有轻量适配器在跨模态融合中易丢失文本语义信息。

🛠 **方法**：提出多视角文本引导的多模态融合适配器（MVFA），通过最大池化、均值池化和注意力池化构建互补文本视图，引导音频与视觉特征的跨模态交互；融合表示经增强Q-Former模块压缩为可学习的伪令牌，仅微调少量参数即可增强冻结LLM的多模态推理能力。

✨ **主要贡献**：在CH-SIMS V2.0、MELD和CHERMA三个数据集上取得SOTA性能（如CH-SIMS V2.0上Acc2达84.62%、F1达84.59%），并在ChatGLM3-6B、LLaMA2-7B和Qwen3-8B多个冻结骨干上验证了可移植性，确立了多视角文本引导融合作为参数高效多模态LLM适配的有效范式。

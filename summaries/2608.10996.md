# ConRub-Med: Reinforcement Learning with Consensus Rubrics for Open-Ended Medical Question Answering

- arXiv: https://arxiv.org/abs/2608.10996v1
- arXiv ID: 2608.10996

---

🔍 **核心问题**：开放式医学问答缺乏自动验证答案正确性的低成本方法，现有强化学习难以处理部分正确、不完整或含临床错误的长文本回答。

🛠 **方法**：提出ConRub-Med框架，利用三个异构语言模型生成原子评分标准，经独立模型审查保留共识项；采用三态评分区分正确、缺失和错误信息，错误给予负分；在GRPO组内奖励相同时，用成对裁判提供序列优势而不改变标量奖励。

✨ **主要贡献**：盲审显示其输出比单生成器更符合临床相关性；在9个基准中6个排名第一，医学和泛化平均分最高；在HealthBench-Hard上达38.98±1.04，优于InfiMed-ORBIT的33.60（8,000样本）和37.30（28,000样本）。

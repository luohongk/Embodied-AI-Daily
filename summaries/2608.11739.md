# G0.5: One Autoregressive Stream for Robot Reasoning and Action

- arXiv: https://arxiv.org/abs/2608.11739v1
- arXiv ID: 2608.11739

---

🔍 **核心问题**：现有视觉-语言-动作（VLA）模型将预训练VLM与单独训练的动作专家分离，使VLM仅作为上下文编码器而非决策者，限制了其推理与行动能力的统一。

🛠 **方法**：提出G0.5，一个单一Transformer解码器在统一目标下同时生成推理与动作token的预训练自回归VLA，包含可学习的跨具身动作分词器、原生思维链流（交织任务分解、目标定位与动作提示）以及视觉记忆模块（注入多秒历史信息）。

✨ **主要贡献**：推理与动作共享权重，使预训练VLM能力直接迁移至物理行为，无需额外训练即可通过提示控制动作粒度与任务范围；在7个独立基准上超越SOTA，如真实机器人微调（76.7% vs π0.5的53.3%）、BEHAVIOR挑战（31.4%）、零样本迁移（82.5%）及LIBERO（98.9%）等。

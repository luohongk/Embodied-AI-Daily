# Music-JEPA: Learning a World Model of Sound from Action

- arXiv: https://arxiv.org/abs/2607.22000v1
- arXiv ID: 2607.22000

---

🔍 **核心问题**：如何利用联合嵌入预测架构（JEPA）学习音乐声音的世界模型，使模型能够理解音乐动作与声音结果之间的因果关系。

🛠 **方法**：将音乐建模为动作条件系统，以音频为状态、钢琴卷帘为动作，通过JEPA预测给定当前音频状态和动作后的未来音频状态，并在离线环境下使用配对音频-钢琴卷帘数据训练。

✨ **主要贡献**：模型成功捕捉了音乐动作与声音的关联，学到的表征支持节拍跟踪、作曲家识别、调性估计等下游任务，并能通过规划搜索最优动作实现钢琴转录。

# Counterfactual Stress Testing for Image Classification Models

- arXiv: https://arxiv.org/abs/2605.10894v2
- arXiv ID: 2605.10894

---

🔍 **核心问题**：医学影像模型在临床部署时因分布偏移（如人群、设备差异）常出现性能下降，而现有压力测试方法仅使用简单扰动，无法反映真实临床变化，导致鲁棒性评估不准确。

🛠 **方法**：提出基于因果生成模型的反事实压力测试框架，通过干预属性（如扫描仪类型、记录性别）生成保留解剖身份的“what-if”图像，实现受控且语义明确的分布偏移评估。

✨ **主要贡献**：在胸部X光和乳腺摄影两种模态、三种模型架构及多种偏移场景下，反事实测试比经典扰动更准确预测真实分布外性能，能捕捉性能变化方向与相对幅度，并显著提升排名一致性，为部署前鲁棒性评估提供有效工具。

# StairMaster: Learning to Conquer Risky Hollow Stairs for Agile Quadrupedal Robots

- arXiv: https://arxiv.org/abs/2606.25765v2
- arXiv ID: 2606.25765

---

🔍 **核心问题**：四足机器人在攀爬空心楼梯时面临腿部卡陷、深度信息稀疏和高频噪声等挑战，现有方法难以实现稳定运动。

🛠 **方法**：提出StairMaster框架，采用三阶段强化学习，集成交叉注意力机制提取深度结构特征，结合空间感知循环单元（SRU）维持鲁棒时空记忆，并设计高保真深度传感器模拟管道、3D路径点引导主动感知奖励及空心间隙与楼梯边缘惩罚。

✨ **主要贡献**：首次实现基于强化学习的四足机器人零样本迁移攀爬55°陡峭空心楼梯，在Unitree Go2机器人上成功验证，填补了极端不连续地形运动控制的空白。

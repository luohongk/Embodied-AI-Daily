# The Router Within: Eliciting Native Skill Routing from a Frozen LLM

- arXiv: https://arxiv.org/abs/2609.15982v1
- arXiv ID: 2609.15982

---

🔍 **核心问题**：LLM智能体需要从技能库中选出正确技能，但现有方案要么把所有技能元数据塞进上下文（分散注意力、限制库规模），要么用外部检索管线（把选择移出智能体自身能力）。

🛠 **方法**：提出Gavel，利用冻结LLM自身前向传播中已蕴含的路由信号，仅训练两个线性映射。先"一瞥"（glance）将任务与各技能的中层状态投影打分，快速筛选候选；再"裁决"（verdict）恢复候选技能的完整前向传播，读取模型自身的似然与yes/no判断，以专家乘积方式与glance融合。

✨ **主要贡献**：证明冻结LLM自带路由信号且两个线性映射即可读出，无需在上下文中放入技能文本；训练一次即可零样本迁移到三个公开基准及新基准SkillTraj（372条模拟轨迹），在Qwen3-32B上比增加1.2B–16B外部参数的渐进披露与检索重排管线最高提升13.4分（写作任务）和21.9分（中途触发技能），且路由精度随基座模型增强而提升，在bash-agent环境中触发正确技能频率超过Codex中更大的前沿模型。

# LLM-Guided Graph Generation for Structure-Based Local Improvement Methods

- arXiv: https://arxiv.org/abs/2608.13333v1
- arXiv ID: 2608.13333

---

🔍 **核心问题**：解决大规模邻域搜索中变量选择策略依赖人工设计、难以跨问题泛化的问题。

🛠 **方法**：构建一个问题无关的自动流水线，利用LLM根据语义指导生成图生成器，将任意MiniZinc格式的问题实例映射为统一加权图，并基于图特征指导结构化的局部改进框架（SLIM）进行变量选择和配置选择。

✨ **主要贡献**：在20个MiniZinc竞赛问题上，算法选择平均胜率达39.5%，超过最佳单一配置（19.3%）两倍以上；通过配置和特征消融进一步提升至44.0%，验证了LLM语义生成在自动结构提取和特征提取上的有效性。

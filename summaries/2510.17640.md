# RESample: A Robust Data Augmentation Framework via Exploratory Sampling for Robotic Manipulation

- arXiv: https://arxiv.org/abs/2510.17640v4
- arXiv ID: 2510.17640

---

🔍 **核心问题**：VLA模型在机器人操作中因训练数据仅含成功轨迹，缺乏失败恢复数据，导致部署时遇到执行偏差无法自我纠正，策略容易陷入失败状态。

🛠 **方法**：提出RESample框架，通过训练保守覆盖函数识别数据分布内但缺失于成功演示的失败模式，并基于覆盖差异进行探索性采样，主动生成失败恢复轨迹以扩充训练数据。

✨ **主要贡献**：在LIBERO基准和真实机器人任务上，RESample以不超过20%的额外样本将策略成功率提升最高12%绝对值，有效增强策略的失败恢复能力。

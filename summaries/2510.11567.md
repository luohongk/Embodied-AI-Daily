# A Framework for Low-Effort Training Data Generation for Urban Semantic Segmentation

- arXiv: https://arxiv.org/abs/2510.11567v2
- arXiv ID: 2510.11567

---

🔍 **核心问题**：合成数据集与真实城市场景（如Cityscapes）之间存在显著域差距，导致语义分割模型在目标域上性能受限，而通过精细3D建模缩小差距成本过高。

🛠 **方法**：提出一个框架，利用现成的扩散模型和仅含不完美伪标签的目标域数据，将合成语义图转换为高保真、目标对齐的真实风格图像，并过滤劣质生成、修正标签错位、统一语义标准。

✨ **主要贡献**：在5个合成数据集和2个真实数据集上，分割mIoU较最先进翻译方法提升最高+8.0%pt，使快速构建的低成本合成数据达到与耗时手工设计数据集相当的效果，展示了生成模型与快速语义原型结合的高效数据生成范式。

# Wonder: Video World Model Done Better

- arXiv: https://arxiv.org/abs/2607.26037v1
- arXiv ID: 2607.26037

---

🔍 **核心问题**：解决现有视频世界模型无法实现实时、可交互的相机控制与长时域探索的问题，支持用户自由导航并保持场景一致性。

🛠 **方法**：提出系统级协同设计，包括基于密集坐标场的相机控制方法、稀疏注意力记忆机制（支持高效长上下文检索），以及改进的自蒸馏训练流程（增强控制信号响应、保持生成多样性与长期记忆）。

✨ **主要贡献**：实现16 FPS的分钟级视频生成，支持实时相机控制、未见区域探索与历史区域重访，同时保持几何、外观与动态的长期一致性，并自然扩展至视频条件生成（实时重拍动态场景）。

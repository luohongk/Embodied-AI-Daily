# SPRInG: Continual LLM Personalization via Selective Parametric Adaptation and Retrieval-Interpolated Generation

- arXiv: https://arxiv.org/abs/2601.09974v2
- arXiv ID: 2601.09974

---

🔍 **核心问题**：解决大语言模型在持续个性化场景中，用户兴趣动态漂移时难以适应新偏好且易发生灾难性遗忘的问题。

🛠 **方法**：提出半参数框架SPRInG，训练时通过似然评分函数识别高新颖性交互，选择性更新用户适配器并将难学残差存入回放缓冲区；推理时采用严格相关性门控，通过logit插值融合参数知识与检索历史。

✨ **主要贡献**：在长文本个性化生成基准上显著优于现有基线，验证了其对真实世界持续个性化场景的鲁棒性，有效区分真实偏好漂移与瞬时上下文噪声。

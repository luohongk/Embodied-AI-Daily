# Explainable Reinforcement Learning via Physics-Aware Policy Distillation

- arXiv: https://arxiv.org/abs/2607.24672v1
- arXiv ID: 2607.24672

---

🔍 **核心问题**：解决深度强化学习在安全关键领域（如机器人、汽车工程）中因黑箱特性导致的缺乏可解释性问题，以提升监管合规性和人机信任。

🛠 **方法**：采用策略蒸馏框架，将高性能连续控制TD3教师模型的知识蒸馏为基于浅层决策树的解释性学生模型，并利用物理感知特征和“噪声专家回放”生成数据集。

✨ **主要贡献**：实现了与专家教师模型性能等效的可解释学生模型，揭示了从连续控制转向离散规则控制会引发高频Bang-Bang驱动和稳定双峰极限环的权衡，同时通过BIBO稳定性分析验证了全局与局部可解释性。

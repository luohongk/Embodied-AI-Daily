# Rotational Equivariance in Machine Learning: A Comprehensive Tutorial

- arXiv: https://arxiv.org/abs/2608.31045v1
- arXiv ID: 2608.31045

---

🔍 **核心问题**：解决机器学习中3D数据预测对坐标框架选择的依赖性问题，确保模型输出随输入旋转而相应变换。

🛠 **方法**：系统介绍旋转等变性的数学基础（群论、表示论、球谐函数、Wigner矩阵等），并综述三类实现策略：群卷积、内部张量表示和基于规范化（canonicalization）的方法。

✨ **主要贡献**：提供从物理直觉到现代架构的完整教程，统一不同形式语言下的等变思想，并通过权衡分析帮助实践者选择合适方法，降低该领域的学习门槛。

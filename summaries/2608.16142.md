# Graph Neural Assisted Actor-Critic for Latency-Efficient Edge Vision System

- arXiv: https://arxiv.org/abs/2608.16142v2
- arXiv ID: 2608.16142

---

🔍 **核心问题**：无人机视觉系统将视频传输至地面服务器时存在显著延迟，影响操作员辅助活动的实时性和有效性。

🛠 **方法**：提出GCN辅助的A2C深度强化学习模型，结合图卷积网络探索像素相关区域的隐藏表示，并利用拉格朗日对偶形式与梯度下降防止收敛失败及约束违反，仅传输可疑目标的子组像素相关区域而非整帧视频。

✨ **主要贡献**：GCN辅助A2C在降低视频帧传输延迟的同时减少了误检率，性能优于其他DRL方法及现有最优模型。

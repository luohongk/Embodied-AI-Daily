# Integrated Multimodal AI System for Retrieval-Augmented Reasoning, Object Sensing, and Damage Analysis

- arXiv: https://arxiv.org/abs/2608.08935v1
- arXiv ID: 2608.08935

---

🔍 **核心问题**：在复杂环境（如光照不足、天气恶劣）下，如何实现高准确率、可解释的物体损伤评估，并减少大模型推理中的幻觉问题。

🛠 **方法**：构建统一多模态AI系统，集成检索增强生成（RAG，含向量与知识图谱两种变体）、红外/热成像感知、视觉基础模型流水线，以及无线信号传感；通过动态检索增强本地语言模型的文档 grounding，并利用多模态融合提升检测与分割鲁棒性。

✨ **主要贡献**：证明图式RAG在跨文档推理任务上优于向量RAG和静态提示；红外与可见光融合克服了单一模态的失效模式；视觉语言模型可高精度生成合成损伤图像并分类严重度；无线传感补充了EO/IR失效场景下的环境感知能力。

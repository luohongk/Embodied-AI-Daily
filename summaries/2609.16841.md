# StackTok: Accelerating VLMs Inference with Budget-Adaptive Visual Token Selection

- arXiv: https://arxiv.org/abs/2609.16841v1
- arXiv ID: 2609.16841

---

🔍 **核心问题**：高分辨率图像在视觉语言模型（VLM）中产生超长视觉token序列，导致推理成本大幅上升，而现有免训练选择方法采用固定的相关性-覆盖度权衡，无法适应不同查询和token预算。

🛠 **方法**：提出StackTok，一种免训练选择器，以查询相关性为目标、视觉覆盖度为预算校准支撑；通过覆盖度贪心序列构建尺寸索引的覆盖参考，利用查询-视觉亲和熵调整支撑目标，并采用参考门控的交错选择策略在相关性与覆盖度之间动态切换；对高分辨率输入按局部提名token的边际增益跨裁剪块分配共享预算。

✨ **主要贡献**：在5个VLM和10个图像理解基准上，StackTok在所有免训练选择器中均排名第一；在LLaVA-NeXT-7B高分辨率场景下，仅用2880个视觉token中的160个（5.6%）即保留95.26%的完整token性能。

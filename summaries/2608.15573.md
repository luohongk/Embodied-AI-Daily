# Not All History Helps: Velocity-Aware Selective Memory for Long-Horizon End-to-End Autonomous Driving

- arXiv: https://arxiv.org/abs/2608.15573v1
- arXiv ID: 2608.15573

---

🔍 **核心问题**：端到端自动驾驶在长时程规划中，历史自预测状态可能过时或与当前运动阶段冲突，导致不可靠的时序先验，影响规划的安全性和一致性。

🛠 **方法**：提出StableDrive框架，包含两个核心组件：选择性动量记忆（SMM）利用Mamba选择性状态空间算子控制历史规划状态对当前周期的影响；运动阶段训练脚手架（MSTS）通过运动阶段、长时程轨迹和纵向运动监督引导阶段感知的未来运动学习，推理时移除。通过两个架构对齐端点的固定参数中点，得到单一可部署的SMM规划器，无需模型集成或额外推理计算。

✨ **主要贡献**：在nuScenes MomAD评估协议下，所有1-6秒规划指标均达SOTA，平均碰撞率降低23.3%，TPC降低30.9%，L2误差降低11.8%；在LT-nuScenes和NAVSIM v1/v2上也取得最优性能，其中NAVSIM v2 navhard的EPDMS提升5.7分。

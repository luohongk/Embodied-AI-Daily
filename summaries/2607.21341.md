# Grasp, Handover, Rotate: Bimanual Object Reorientation via Compositional Diffusion and Energy-Based Optimization

- arXiv: https://arxiv.org/abs/2607.21341v1
- arXiv ID: 2607.21341

---

🔍 **核心问题**：解决双臂机器人在物体重定向任务中，因碰撞、运动学约束或初始抓取姿态不佳导致无法直接放置的问题，需在多重竞争目标下联合优化抓取、交接、重抓取和运动规划。

🛠 **方法**：提出BiCompoDiff框架，结合预训练的抓取扩散模型与双臂规划能量模型（EBMs），在逆向扩散过程中注入梯度引导，以强制执行碰撞避免、轨迹平滑（通过可微逆运动学）、交接可行性和重抓取安全性，并采用退火MCMC采样优化复合能量景观中的抓取姿态。

✨ **主要贡献**：在多样化模拟家居重定向任务中，BiCompoDiff相比强基线方法成功率提升超20%，轨迹平滑度（以关节位移衡量）提升高达37%；真实世界验证表明其具备有效的仿真到现实迁移能力及鲁棒性能。

# 3D MRI-Based Alzheimer's Disease Classification Using Multi-Modal 3D CNN with Leakage-Aware Subject-Level Evaluation

- arXiv: https://arxiv.org/abs/2603.17304v2
- arXiv ID: 2603.17304

---

🔍 **核心问题**：现有基于MRI的阿尔茨海默病（AD）分类研究多采用二维切片分析，忽略了大脑三维结构中的空间关系，且评估协议常存在数据泄漏问题。

🛠 **方法**：提出一种多模态3D卷积神经网络，结合原始T1 MRI与FSL FAST分割得到的灰质、白质、脑脊液概率图，并在OASIS 1数据集上采用5折受试者级交叉验证进行评估。

✨ **主要贡献**：在受试者级评估下取得72.34%的平均准确率和0.7781的ROC AUC，GradCAM可视化显示模型关注内侧颞叶和脑室等与AD相关的解剖区域；同时通过切片级与受试者级协议的对比实验，揭示了数据表示和评估策略对性能报告的影响，建立了可复现的受试者级基准。

# Learning to Optimize UAV Path Planning for Data Sensing in Wireless Sensor Networks

- arXiv: https://arxiv.org/abs/2609.16629v1
- arXiv ID: 2609.16629

---

🔍 **核心问题**：无人机在无线传感器网络中执行数据采集任务时，现有路径规划方法存在手工设计偏差导致泛化能力差，以及简化仿真环境导致实际部署性能不佳两大局限。

🛠 **方法**：提出景观感知元差分进化框架（LAMDE），采用双层学习优化架构——元层通过可训练算法配置策略元学习自适应规划策略，低层使用差分进化算法求解，并引入景观感知自动增强方案和变长编码策略。

✨ **主要贡献**：重新形式化了含复杂约束的无人机路径规划问题，通过元学习与自动数据增强解决训练数据稀缺和分布偏移问题，变长编码可动态剪枝冗余悬停点并同时优化连续飞行参数，实验证明LAMDE在复杂WSN数据采集场景中达到最优性能。

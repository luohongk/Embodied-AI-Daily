# PENDA: An Efficient Processing Element via Norm-of-Difference for Deep Learning Accelerators

- arXiv: https://arxiv.org/abs/2609.08424v1
- arXiv ID: 2609.08424

---

🔍 **核心问题**：深度学习加速器中内积计算占主导成本，现有加速方法多依赖近似计算，可能损害模型精度，需在不损失精度的前提下提升硬件效率。

🛠 **方法**：提出PENDA处理单元，利用余弦定理将乘法运算重构为平方差操作，从而用范数差单元替代传统乘累加单元，实现精确计算。

✨ **主要贡献**：在深度学习加速器的PE阵列中，PENDA分别减少面积11–36%、能耗5–48%、时钟周期11–19%，同时保持计算完全精确，无需精度折衷。

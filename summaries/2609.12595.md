# A Hierarchical Coverage Path Planning Algorithm for Unknown Environments

- arXiv: https://arxiv.org/abs/2609.12595v1
- arXiv ID: 2609.12595

---

🔍 **核心问题**：如何在未知环境中实现高效的在线覆盖路径规划，使机器人能在探索过程中逐步适应环境并减少重复覆盖。

🛠 **方法**：通过将未知区域逐步分解为子区域并构建增量式分解树，维护全局覆盖路径，结合局部规划器在各子区域内生成覆盖运动，实现轨迹的在线自适应调整。

✨ **主要贡献**：提出了一种基于层次分解树的在线覆盖规划算法，在高保真仿真中相比三种基线算法在路径长度和重叠率方面均取得了更优的覆盖效率。

# Compact Bellman-Grounded Cognitive Maps for Cost-Aware Navigation

- arXiv: https://arxiv.org/abs/2609.05104v1
- arXiv ID: 2609.05104

---

🔍 **核心问题**：现有认知地图模型在导航中未显式考虑可加性异构路径成本，且随环境规模扩大存在存储效率低下的问题。

🛠 **方法**：提出BCM模型，通过自监督的Bellman接地目标将局部边成本写入紧凑的坐标编码中，支持动态目标查询而无需逐目标重训练。

✨ **主要贡献**：在加权网格上（N=1600）保持100%成功率，平均Gap仅5%（对比谱基线约45%）；存储随图规模（N=400→3600）亚线性增长，兼顾生物灵活性与最优路径规划。

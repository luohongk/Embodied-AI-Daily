# Shifting from Injection to Interaction: Rethinking Web Security in the Age of LLMs and Beyond

- arXiv: https://arxiv.org/abs/2609.03999v1
- arXiv ID: 2609.03999

---

🔍 **核心问题**：传统Web安全威胁（如XSS）在LLM时代被放大，同时LLM特有的提示注入等攻击可在Web应用中传播，现有研究将Web与LLM安全割裂，缺乏统一分析。

🛠 **方法**：对LLM在客户端、服务端及流水线层如何放大Web漏洞进行统一分析，评估现有防御及其局限，并扩展NIST与ISO/IEC AI安全框架至LLM赋能的Web环境，提出LLM感知的监控与控制框架（含语义输入验证、提示完整性保护、输出隔离、代理治理与运行时监控）。

✨ **主要贡献**：首次统一分析传统与LLM特有威胁的交互影响，识别出对抗性自然语言指令、自主代理安全及部署后持续监控三大未解挑战，为安全AI赋能的Web系统指明未来方向。

# FutureRTC: Real-Time Robot Execution with Anticipatory-Conditioned Action Chunking

- arXiv: https://arxiv.org/abs/2607.24008v1
- arXiv ID: 2607.24008

---

🔍 **核心问题**：解决视觉-语言-动作（VLA）策略在异步执行时，因预测与执行时间错位导致的动作块间不连续问题。

🛠 **方法**：提出FutureRTC框架，包含状态修正模块（补偿执行时本体感知状态偏差）和观测预测模块（利用机器人运动作为物理先验，通过运动感知特征传输与重建预测视觉表征），并引入策略一致性损失对齐预测与执行时的动作块。

✨ **主要贡献**：无需修改底层策略即可实现即插即用的异步VLA控制，在仿真和真实环境中显著提升对推理延迟的鲁棒性，获得更平滑的轨迹、更快的执行速度和更高的任务成功率。

# In-Context Robot Learning with VLM Agents

- arXiv: https://arxiv.org/abs/2609.19138v1
- arXiv ID: 2609.19138

---

🔍 **核心问题**：如何让机器人在部署时无需梯度更新或参数修改，就能像人类一样从上下文（演示、示例、交互反馈）中学习并适应陌生环境与任务。

🛠 **方法**：提出 GPT-Policy 通用智能体框架，集成上下文编译器（保留任务相关视觉转换）、VLM（生成机器人工具动作）和约束控制器（验证并执行动作、反馈结果），实现从新初始状态生成可执行、可验证的机器人行为。

✨ **主要贡献**：验证了商业 VLM 可在无梯度更新下完成上下文机器人学习；真实机器人实验中，人类视频演示即使无动作标签也能提升任务完成率，对齐的动作参考在接触敏感任务上进一步增益，为 VLM 通用能力转化为物理行为提供了实证基础。

# Diff-DDoS: Realistic Cyber-Physical Attack Synthesis and Robust Detection for 5G-Enabled CPS Using Tabular Diffusion Models

- arXiv: https://arxiv.org/abs/2608.17796v1
- arXiv ID: 2608.17796

---

🔍 **核心问题**：5G赋能的网络物理系统（CPS）中，基于深度学习的DDoS检测器面临标注攻击数据稀缺和合成样本不真实的问题，导致在面对逼真、分布保持的攻击样本时性能严重下降（F1分数下降约47%至100%）。

🛠 **方法**：提出Diff-DDoS框架，包含三个阶段：第一阶段训练基线CNN检测器处理CDR时空网格；第二阶段使用表格去噪扩散概率模型（TabDDPM）在正常CDR聚合数据上生成逼真攻击；第三阶段引入对抗扩散训练（ADT），通过逆分类器引导生成困难但分布保持的样本，直至检测器收敛。

✨ **主要贡献**：在米兰CDR数据集上，ResNet50结合ADT在静默呼叫、互联网信令和混合场景中分别恢复F1分数至79.62%、100%和92.79%；经阈值校准后，ADT在SMS洪泛场景达到100% F1（对比CTGAN仅47.3%），并匹配最强梯度对抗训练基线。实验证明表格扩散模型能有效用于数据稀缺的5G CPS入侵检测器的压力测试与加固。

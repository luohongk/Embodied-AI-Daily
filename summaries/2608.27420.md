# Boosting LLM Exploration via Weak-Model Guidance in RLVR

- arXiv: https://arxiv.org/abs/2608.27420v1
- arXiv ID: 2608.27420

---

🔍 **核心问题**：RLVR训练中策略熵下降导致推理覆盖范围缩小，使pass@k（k较大时）性能退化。

🛠 **方法**：利用更小、更弱的语言模型生成部分推理轨迹，强制目标模型基于这些不熟悉的前缀继续生成答案，从而破坏过度自信并促进探索不同推理路径。

✨ **主要贡献**：在多个数学基准上一致优于vanilla RLVR，且k增大时性能提升更显著；无需额外SFT、复杂奖励设计或提示工程即可有效缓解熵坍缩，扩展推理覆盖范围。

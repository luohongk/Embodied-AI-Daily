# DeicticVLA: Unifying Instruction Modes Based on Language and Deictic Gestures in a Single VLA

- arXiv: https://arxiv.org/abs/2608.28108v1
- arXiv ID: 2608.28108

---

🔍 **核心问题**：现有视觉-语言-动作模型（VLA）依赖自然语言指令，但在区分同类别或外观相似的物体时，语言描述往往不够精确，导致任务指定困难。

🛠 **方法**：提出DeicticVLA，将语言指令（LI）、视觉-语言指令（VLI）和视觉指令（VI）统一为“文本提示+指示性掩码”的形式，通过文本提示补全和指示性手势接地，使单个预训练VLA支持三种指令模式。

✨ **主要贡献**：在仿真和真实任务中验证了统一三模式接口的有效性；两阶段训练策略显著提升指示性掩码在未见布局中的泛化能力；在真实场景中，VLI和VI在未见类别上达到100%成功率，远超仅用LI的16.7%，同时保留LI数据可缓解遗忘且不损害其他模式性能。

# PlantC2USeg: Cross-Scale Consistent Pre-Training for Few-Shot Unified Plant Point Cloud Segmentation

- arXiv: https://arxiv.org/abs/2609.02860v1
- arXiv ID: 2609.02860

---

🔍 **核心问题**：植物点云分割（PPCS）依赖大量密集标注数据，且在不同物种和传感条件下存在分布偏移，导致少样本统一分割的适应能力不足。

🛠 **方法**：提出PlantC2USeg深度迁移学习框架，采用跨尺度一致性学习对齐空间尺度特征，并引入信息受限解码策略防止重建捷径，从而增强鲁棒适应；通过继承阈值实现统一微调，降低适应开销。

✨ **主要贡献**：在Soybean3D全监督下达到91.91%语义IoU和94.62%实例mWCov；仅用10个样本仍保持83.23% mWCov。跨物种迁移（烟草、番茄、高粱）10-shot平均IoU达78.41%，玉米22-shot IoU达92.75%；在ShapeNet Part上mIoU达85.0%，证明跨领域泛化能力，显著减少分布偏移下的适应成本。

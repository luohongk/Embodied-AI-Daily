# SubSplat: High-Resolution Pixel-aligned 3DGS via Sub-pixel Gaussian Reparameterization

- arXiv: https://arxiv.org/abs/2607.20813v1
- arXiv ID: 2607.20813

---

🔍 **核心问题**：像素对齐的高斯泼溅在高分辨率渲染时，输入分辨率提升会带来网络计算成本二次增长，而低分辨率输入则导致高斯密度不足和伪影。

🛠 **方法**：提出SubSplat框架，通过子像素高斯重参数化器（SPGR）将主高斯细分为更精细的基元，直接从低分辨率特征恢复结构密度，并利用多视图特征聚合增强高频细节。

✨ **主要贡献**：在RealEstate10K和ACID数据集上验证，SubSplat在保持高效计算的同时实现了高保真渲染，成功解决了像素对齐高斯泼溅中重参数化保真度与网络计算成本之间的权衡。

# Replacing Tunable Parameters in Weather and Climate Models with State-Dependent Functions using Reinforcement Learning

- arXiv: https://arxiv.org/abs/2601.04268v3
- arXiv ID: 2601.04268

---

🔍 **核心问题**：传统天气与气候模型中的参数化方案依赖固定系数，离线调参难以适应动态物理过程，导致持续偏差。

🛠 **方法**：提出基于强化学习（RL）的在线学习框架，将可调参数替换为随模型状态变化的函数，并在单智能体与联邦多智能体设置下，于简单气候偏差校正、辐射对流平衡和纬向平均能量平衡模型（EBM）等理想化测试平台中评估九种RL算法。

✨ **主要贡献**：TQC、DDPG和TD3算法表现最优，单智能体RL在EBM中优于静态调参，六智能体DDPG联邦配置在热带和中纬度区域取得最低面积加权RMSE；学习到的参数修正具有物理意义，能减少经向偏差、调整垂直温度廓线并稳定加热增量，为数值模型中的在线学习提供了可扩展路径。

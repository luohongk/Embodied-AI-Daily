# WaymoQA: A Multi-View Visual Question Answering Dataset for Safety-Critical Reasoning in Autonomous Driving

- arXiv: https://arxiv.org/abs/2511.20022v3
- arXiv ID: 2511.20022

---

🔍 **核心问题**：现有多模态大模型在自动驾驶安全关键场景中缺乏多视角推理能力，难以处理“规避一个风险却引发另一个风险”的复杂情况。

🛠 **方法**：提出Safety-Critical Reasoning任务，将推理分为“解决即时风险”和“缓解决策引发的下游风险”两阶段，并构建WaymoQA数据集（35,000对人工标注问答），涵盖多视角图像与视频，支持多项选择和开放问答。

✨ **主要贡献**：实验表明现有MLLM在安全关键场景下表现不佳，但用WaymoQA微调后推理能力显著提升，验证了该数据集对开发更安全、更具推理能力的驾驶智能体的有效性。

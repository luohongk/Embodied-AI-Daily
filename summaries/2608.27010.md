# A Multi-Modal AI Framework for Real-Time Queue Prediction, Management and Optimisation in Intelligent Border Control Systems

- arXiv: https://arxiv.org/abs/2608.27010v1
- arXiv ID: 2608.27010

---

🔍 **核心问题**：传统边境检查站的排队管理系统依赖静态数据，难以应对动态交通变化，导致排队预测不准、等待时间长和资源利用效率低。

🛠 **方法**：提出一个多模态AI框架，融合异构数据源，利用LSTM网络进行实时排队预测，并结合模型预测控制（MPC）与调度优化生成控制策略，供边境官员执行。

✨ **主要贡献**：相比ARIMA和基于规则的方法，排队预测误差降低35%，平均等待时间减少30%，吞吐量提升约20%，验证了AI与优化技术结合在自适应边境交通管理中的高效性。

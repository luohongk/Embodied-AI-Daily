# A Two-Stage Framework for Ego-Centric Key Object Identification via Object State Prediction

- arXiv: https://arxiv.org/abs/2609.07125v1
- arXiv ID: 2609.07125

---

🔍 **核心问题**：现有自动驾驶中的关键物体识别方法未显式考虑自车视角，导致对物体重要性的判断不够准确。

🛠 **方法**：提出两阶段框架，引入虚拟自车表示和模块化物体状态预测器，结合时空推理，基于物体状态与相对空间信息进行关键物体识别。

✨ **主要贡献**：在真实驾驶数据集上验证了方法的有效性，相比仅依赖视觉关系的方法，能更准确地在复杂交通环境中识别关键物体。

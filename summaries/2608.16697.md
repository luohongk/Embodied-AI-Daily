# FabriMAE I Trust Myself? Self-Evaluating VLA Action Generation with Markov Attention Entropy

- arXiv: https://arxiv.org/abs/2608.16697v1
- arXiv ID: 2608.16697

---

🔍 **核心问题**：视觉-语言-动作模型（VLA）在无外部监督下难以自我评估动作生成的可靠性，现有方法依赖专家标注或仅从输出统计估计不确定性，忽略了内部信号。

🛠 **方法**：提出MAE（马尔可夫注意力熵）框架，将VLA内部注意力信号转化为架构感知的可靠性分数，并基于条件生成马尔可夫链建模VLA的潜在动作生成过程；同时构建LIBERO-Reflect基准（含4000个标准与挑战性场景片段）。

✨ **主要贡献**：MAE在AUPR、AUROC和FPR@95指标上持续优于现有基线；实例化FabriMAE用于无验证器的测试时动作选择，在LIBERO-Plus上以较小运行时开销提升PI系列鲁棒性，验证了跨异构VLA架构的通用性。

# Learning-Based Collaborative MEC for LLM Inference with Soft-Deadline Awareness via Transformer-Enhanced PPO

- arXiv: https://arxiv.org/abs/2608.02031v1
- arXiv ID: 2608.02031

---

🔍 **核心问题**：在软截止时间约束下，如何通过移动边缘计算（MEC）服务器协作高效完成大语言模型（LLM）推理任务，同时最小化截止时间延长的使用，并应对任务间的依赖关系。

🛠 **方法**：提出一种基于Transformer增强的近端策略优化（PPO）框架，通过捕捉任务时间依赖和跨服务器交互，优化任务迁移决策，实现MEC服务器间的协同调度。

✨ **主要贡献**：设计了一种带约束灵活性的扩展截止时间机制，并验证了所提方法在任务完成率和系统效率上显著优于传统PPO及启发式方法。

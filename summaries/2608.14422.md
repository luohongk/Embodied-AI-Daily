# UMPIRE-Net: Unrolled Magnitude-Phase Regularization Network for Accelerated MRI

- arXiv: https://arxiv.org/abs/2608.14422v1
- arXiv ID: 2608.14422

---

🔍 **核心问题**：加速MRI重建中，现有物理驱动深度学习方法直接重建复数图像，隐含耦合了幅度和相位信息，在部分傅里叶成像等需要精确相位建模的场景下表现欠佳。

🛠 **方法**：提出UMPIRE-Net，将图像分解为幅度和相位两个分量，分别设计独立的可学习正则化器，并引入新的数据一致性公式以强化测量约束。

✨ **主要贡献**：在不同数据集和加速因子下，相比传统复数域PD-DL基线，该方法显著提升重建质量，生成更清晰的图像并减少伪影，代码已开源。

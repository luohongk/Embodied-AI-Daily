# Face and Voice Cross-modal Association with Learning Convex Feature Embedding

- arXiv: https://arxiv.org/abs/2607.28129v1
- arXiv ID: 2607.28129

---

🔍 **核心问题**：人脸与语音跨模态关联任务中，音频和视频特征间的异质性未被充分处理，导致大量误报（false positives）和漏报（false negatives）。

🛠 **方法**：提出一种学习凸特征嵌入的跨模态关联方法，通过引入中间特征使同一人的语音和人脸特征嵌入凸包内，并结合跨模态注意力机制以最小化类间差异。

✨ **主要贡献**：在VoxCeleb数据集上的跨模态验证、匹配和检索任务中，该方法显著优于现有最先进方法，有效降低了误报和漏报。

# READ: Learning Risk-Informed Fields for End-to-End Autonomous Driving

- arXiv: https://arxiv.org/abs/2609.12371v1
- arXiv ID: 2609.12371

---

🔍 **核心问题**：现有学习型自动驾驶规划器中，环境因素与候选动作之间的关系往往是隐式的，难以检查、诊断或优化场景上下文对轨迹安全性的影响；而经典安全场虽显式但风险形状与权重固定，无法适应不同场景。

🛠 **方法**：提出 READ 框架，从几何与行为约束中学习显式、与规划对齐的风险表示，并将其实例化为连续时空场，支持沿候选轨迹的可微查询，从而引导预测轨迹趋向低风险区域，同时保留可微的轨迹评估与优化接口。

✨ **主要贡献**：实现了可学习、可适应的空间风险表示，可同时集成到端到端规划器和视觉-语言-动作（VLA）模型中；在 NAVSIM 上跨匹配的端到端骨干网络取得一致提升，在 VLA 设置下表现强劲，并在 NAVSIM v2 上取得有竞争力的结果。

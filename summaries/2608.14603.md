# HMS-SCP: Task-Oriented Multi-Scale Semantic Communication for V2X Cooperative Perception

- arXiv: https://arxiv.org/abs/2608.14603v2
- arXiv ID: 2608.14603

---

🔍 **核心问题**：在V2X协同感知中，密集城市环境下的累积带宽需求可能压倒网络容量，威胁安全关键的C-ITS功能，现有中间融合方法在带宽效率和噪声鲁棒性上存在不足。

🛠 **方法**：提出HMS-SCP框架，采用空间重要性预测器识别各尺度的任务相关网格元素，直接映射为复值符号进行联合源信道编码（JSCC），利用跨尺度的结构语义冗余增强抗噪性，同时保持超低符号率。

✨ **主要贡献**：在OPV2V和DAIR-V2X数据集上验证，HMS-SCP在严重瑞利衰落和极端压缩比下防止性能崩溃，保持高置信度远场检测，实时延迟低于16ms，满足动态V2X环境的安全临界阈值，显著降低带宽消耗并缓解网络拥塞。

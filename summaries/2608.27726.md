# Coordinated Motion Planning for Multi-Arm Systems via Iterative LQ Games

- arXiv: https://arxiv.org/abs/2608.27726v1
- arXiv ID: 2608.27726

---

🔍 **核心问题**：高自由度多机械臂在共享工作空间中的运动规划面临可扩展性差、鲁棒性和安全性不足的挑战。

🛠 **方法**：提出迭代线性二次（LQ）博弈框架，将每个机械臂建模为独立智能体，通过线性化动力学和近似代价函数求解局部LQ博弈，并利用Riccati反向递推获得反馈Nash策略，同时引入可微惩罚项处理自碰撞和臂间碰撞。

✨ **主要贡献**：实现了高维场景下平滑、安全且高效的多臂协调轨迹生成，实验表明该方法优于传统集中式或分散式规划方法，验证了微分博弈在多机器人操作中的有效性。

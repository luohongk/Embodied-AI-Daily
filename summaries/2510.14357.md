# SUM-AgriVLN: Spatial Understanding Memory for Agricultural Vision-and-Language Navigation

- arXiv: https://arxiv.org/abs/2510.14357v2
- arXiv ID: 2510.14357

---

🔍 **核心问题**：农业机器人在实际场景中常收到重复性自然语言指令，但现有AgriVLN方法将每次指令视为独立任务，未利用过往空间记忆辅助当前导航决策。

🛠 **方法**：提出SUM模块，通过3D重建执行空间理解，并将历史场景以2D表征形式保存为空间记忆，在导航时调用这些记忆辅助决策器，集成到AgriVLN骨干中形成SUM-AgriVLN。

✨ **主要贡献**：在A2A基准上，SR从0.47提升至0.54，NE仅从2.91m微增至2.93m，达到农业VLN领域最先进性能，验证了空间记忆对重复指令场景的有效性。

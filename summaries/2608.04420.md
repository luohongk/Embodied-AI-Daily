# SCOPE: Field-of-View-Aware Path Planning in Unknown 3D Environments via Safety-Volume Certification

- arXiv: https://arxiv.org/abs/2608.04420v1
- arXiv ID: 2608.04420

---

🔍 **核心问题**：在未知3D环境中，使用有限视场传感器进行安全导航时，如何确保机器人膨胀体积在运动前被完全观测并验证为无障碍，以避免进入未认证空间。

🛠 **方法**：提出SCOPE框架，通过在线安全体积认证构建认证图，将乐观路径上的首个未认证点转为显式观测任务，结合目标中心视点搜索、认证预览机制和观测感知轨迹优化，实现规划与执行解耦。

✨ **主要贡献**：证明了条件完备规划性（在理想感知和穷举搜索下可达目标），在60个随机任务中100%到达目标且几乎零进入未认证空间，预览机制减少27%平均任务时间，并通过真实机器人实验验证系统有效性。

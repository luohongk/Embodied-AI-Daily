# CanonNav: Disentangling Navigation Behavior from Camera Geometry in Cross-Platform Visual Navigation

- arXiv: https://arxiv.org/abs/2608.30242v1
- arXiv ID: 2608.30242

---

🔍 **核心问题**：跨平台视觉导航中，直接从图像-轨迹对学习会混淆导航行为与平台相关的相机几何，导致策略需隐式推断相机几何这一不适定问题；同时模仿学习仅捕捉专家动作，未显式建模中间决策。

🛠 **方法**：提出CanonNav框架，通过相机几何规范化将视觉观测和轨迹转换到相机一致的表示空间，并利用离线可通行性估计器生成的伪标签，引入安全监督（惩罚不安全轨迹）和局部进展监督（指导前进方向），在推理时仅使用RGB输入。

✨ **主要贡献**：在多种相机配置和环境中，CanonNav一致优于RGB基线，并在挑战性场景中超越RGB-D方法，证明其有效解耦导航行为与相机几何，并提升跨平台泛化能力。

# Empowering Local Agriculture: A Deep Learning-Powered Web System for Identifying Bangladeshi Mango Varieties

- arXiv: https://arxiv.org/abs/2608.28161v1
- arXiv ID: 2608.28161

---

🔍 **核心问题**：孟加拉国芒果品种识别困难，因相近品种视觉特征相似且实际拍摄条件多变。

🛠 **方法**：构建包含9类共2,013张高分辨率芒果图像的数据库，微调ResNet18、ResNet50和EfficientNetB0三种预训练CNN模型，并将最优模型集成到Streamlit网页应用中。

✨ **主要贡献**：EfficientNetB0取得最佳性能（测试准确率97.36%，F1分数0.93–0.99），模型仅约400万参数适合轻量部署；开发了用户可上传图片并获取品种预测的实用Web系统，为孟加拉农业提供便捷工具。

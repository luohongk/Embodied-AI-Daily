# Skills in Weights, Memory in Code: Hybrid Learning for Memory-Dependent Robot Manipulation

- arXiv: https://arxiv.org/abs/2608.09410v1
- arXiv ID: 2608.09410

---

🔍 **核心问题**：现实中的机器人操作任务往往是非马尔可夫的，需要从长时间交互历史中保留和推理任务相关信息，而现有VLA策略通常只基于当前观测或短固定长度历史生成动作，难以处理记忆依赖型操作。

🛠 **方法**：提出HyMeS混合学习框架，将低层运动技能通过梯度模仿学习训练马尔可夫VLA策略，同时用编码智能体通过启发式学习迭代更新可执行启发式系统来管理高层记忆策略，并利用多模态阶段完成验证（本体感觉信号+多帧VLM判断）闭环连接控制与执行。

✨ **主要贡献**：相比端到端记忆增强VLA，HyMeS仅需可复用运动技能的演示数据，无需覆盖所有历史依赖任务配置，实现数据高效组合泛化；在RoboMemArena上，累计成功率从52.5%提升至66.2%，任务成功率从41.3%提升至60.1%，分别超越pi0.5和PrediMem基线。

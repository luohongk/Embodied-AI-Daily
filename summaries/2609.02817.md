# Cliff: Learning Process Rewards from the First Mistake

- arXiv: https://arxiv.org/abs/2609.02817v1
- arXiv ID: 2609.02817

---

🔍 **核心问题**：在基于可验证奖励的强化学习（RLVR）中，仅使用结果奖励无法为中间推理过程提供细粒度指导，导致模型训练效率受限。

🛠 **方法**：提出Cliff奖励塑形策略，利用现成的LLM作为教师，识别每次推理轨迹中的首个错误，将轨迹划分为正确前缀和错误后缀，并据此分配token级正负优势信号。

✨ **主要贡献**：在12个场景中，Cliff一致提升推理性能，相比on-policy蒸馏提升15%、标准GRPO提升7%，且不依赖专用奖励模型或师生同构假设，是一种简单、通用且有效的细粒度监督方法。

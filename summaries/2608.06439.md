# A Low-Latency ASIC Architecture for Real-Time Line Segment Detection

- arXiv: https://arxiv.org/abs/2608.06439v1
- arXiv ID: 2608.06439

---

🔍 **核心问题**：针对嵌入式视觉应用中线段检测的实时性需求，现有深度学习方法资源开销大，经典算法延迟不确定，难以在资源受限平台上实现低延迟实时处理。

🛠 **方法**：提出一种基于步长算法的全流水线ASIC架构，采用寄存器行缓冲与数据复用、无乘法器MCM滤波、8类角度量化、CAM式关联存储实现单周期匹配，以及优化的重复线段去除机制，每时钟周期处理一个像素且延迟确定。

✨ **主要贡献**：在45nm CMOS工艺下，VGA分辨率达325 FPS（125 MHz下406 FPS），全高清48 FPS，功耗25.54 mW，面积0.412 mm²；相比90nm Line Hough Transform实现，功耗降低49%，帧率提升1.6倍以上，适合边缘计算场景。

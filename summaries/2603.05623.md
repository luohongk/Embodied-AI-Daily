# Post Fusion Bird's Eye View Feature Stabilization for Robust Multimodal 3D Detection

- arXiv: https://arxiv.org/abs/2603.05623v2
- arXiv ID: 2603.05623

---

🔍 **核心问题**：多模态3D检测中，相机-激光雷达融合在域偏移或传感器故障下性能显著下降，而现有鲁棒性方法需修改融合架构或重新训练，难以部署到已有系统。

🛠 **方法**：提出后融合稳定器（PFS），一个轻量模块，直接作用于现有检测器的BEV中间特征，通过稳定特征统计、抑制退化区域并自适应残差修正，生成精炼特征供原检测头使用。

✨ **主要贡献**：PFS作为近恒等变换，在保持原有性能的同时提升鲁棒性，在nuScenes上相机缺失鲁棒性提升+1.2% mAP，低光场景提升+4.4% mAP，且仅需3.3M参数，易于集成到现有系统。

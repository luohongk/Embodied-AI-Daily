# RIPE++: Reinforced Keypoint Learning from Positive Pairs Only

- arXiv: https://arxiv.org/abs/2608.19693v1
- arXiv ID: 2608.19693

---

🔍 **核心问题**：现有稀疏关键点提取与匹配方法通常依赖相机位姿或深度监督，在真实场景中难以获取；而基于强化学习的现有方法（如RIPE）依赖粗糙的二元奖励和精心构造的负样本对，导致训练不稳定且描述子判别性不足。

🛠 **方法**：提出RIPE++，设计一种仅从单一正样本对中同时提取奖励和惩罚的强化学习目标，充分利用几何一致性信号，无需负样本对比；并将该目标扩展到匹配阶段，通过适配LightGlue实现弱监督的完整稀疏匹配流程训练。

✨ **主要贡献**：在MegaDepth1500上将AUC@5从56.58提升至59.65；在标准基准上达到与全监督方法相当的性能；能在无相机位姿的低纹理医学视频序列上训练，而传统SfM流程在此类场景常失败。

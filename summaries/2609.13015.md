# Global Path Planner with Multi-Model Switching

- arXiv: https://arxiv.org/abs/2609.13015v1
- arXiv ID: 2609.13015

---

🔍 **核心问题**：如何在多样化地形下保持全局路径规划的路径保真度与跟踪性能。

🛠 **方法**：结合可通行性图进行地形分析、Heading-Aware A* 算法生成可行路径，以及多模型 Pure Pursuit 控制器实现动态跟踪，并基于地形特征与机器人状态实时切换运动学模型。

✨ **主要贡献**：提出自适应运动学建模与多模型切换机制，在 Artaban 四足机器人和 X3 四旋翼无人机仿真中验证了路径效率、鲁棒性和适应性的提升。

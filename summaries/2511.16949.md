# MobileOcc: A Human-Aware Semantic Occupancy Dataset for Mobile Robots

- arXiv: https://arxiv.org/abs/2511.16949v2
- arXiv ID: 2511.16949

---

🔍 **核心问题**：面向移动机器人在人群密集环境中的稠密3D语义占用感知研究不足，缺乏专门的数据集和基准。

🛠 **方法**：构建MobileOcc数据集，采用静态物体占用标注管道和针对人体建模的网格优化框架，从2D图像重建可变形人体几何，并用LiDAR点云进行细化优化；同时建立占用预测和行人速度预测两个任务的基准。

✨ **主要贡献**：首次提出面向移动机器人人群环境的语义占用数据集，验证了标注方法在3D人体姿态估计数据集上的鲁棒性，并开源代码和数据集以促进可复现研究。

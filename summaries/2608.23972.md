# Safety-aware Model Predictive Path Integral Control with Signal Temporal Logic

- arXiv: https://arxiv.org/abs/2608.23972v1
- arXiv ID: 2608.23972

---

🔍 **核心问题**：在机器人运动规划中，当任务具有时间紧迫性且需满足复杂时序规范（如信号时序逻辑STL）时，如何实现安全且高效的运动规划。

🛠 **方法**：提出一种基于采样的滚动时域规划框架，将离散时间STL公式编码为时变控制屏障函数（CBF），并将其集成到模型预测路径积分（MPPI）控制器中，利用并行采样实现低计算成本。

✨ **主要贡献**：该方法在四个火星车规划案例中相比多种MPPI基线，持续实现更高的安全性和效率；并在NVIDIA Isaac Lab中完成四旋翼飞行器规划实验验证，展示了其在复杂环境下的实用性和鲁棒性。

# ViHaTeleop: A Low-Cost, Lightweight Visual-Haptic Teleoperation System for Dexterous Manipulation Learning

- arXiv: https://arxiv.org/abs/2608.16572v1
- arXiv ID: 2608.16572

---

🔍 **核心问题**：低成本遥操作系统难以采集接触关键型灵巧操作演示数据，导致模仿学习效果受限。

🛠 **方法**：提出ViHaTeleop系统，结合SLAM腕部追踪、相机手部追踪和基于线性谐振执行器的指间振动触觉反馈，并引入LED照明、鱼眼手部相机和触觉感知重定向约束等设计，部署于Franka+LEAP Hand+9DTact平台。

✨ **主要贡献**：在六项接触关键任务中，触觉反馈使成功率提升2.2至15.6个百分点，主观评分显著改善；集成Isaac Sim深度相机触觉代理，实现从多模态演示采集到视觉-触觉策略训练的完整流程，初步验证触觉线索在插销任务中比纯视觉提升17个百分点。

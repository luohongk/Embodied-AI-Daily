# Collaborative Memory for Multi-Agent VLM Systems

- arXiv: https://arxiv.org/abs/2609.17921v1
- arXiv ID: 2609.17921

---

🔍 **核心问题**：在多智能体VLM系统中，不同智能体分别感知不同图像区域、视频帧或视觉表示，如何实现分布式感知下的共享视觉上下文、协调不同解读并更新依赖推理。

🛠 **方法**：提出以记忆层次、跨智能体共享和一致性机制为核心的协作记忆框架，不仅保存图像或文本摘要，还保留观察、智能体解读与后续推理之间的依赖关系。

✨ **主要贡献**：构建了面向VLM智能体团队的共享视觉记忆框架，支持智能体复用他人贡献、恢复缺失视觉上下文并随新证据协调分歧，为构建可靠且资源高效的智能体团队奠定基础。

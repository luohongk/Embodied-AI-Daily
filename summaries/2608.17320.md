# Robust Brachiation on a Life-Sized Dual-Arm Robot Using Waypoint-Guided Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.17320v1
- arXiv ID: 2608.17320

---

🔍 **核心问题**：在无立足点的环境中，如何让真实尺寸双臂机器人实现稳健的摆荡运动（brachiation），这需要全身协调和精确的抓握/释放时序控制。

🛠 **方法**：提出Waypoint-Guided Reinforcement Learning（WGRL），通过稀疏指定末端执行器路径点引导行为学习，结合任务成功与机械能奖励，并在Sim-to-Real迁移环境中训练。

✨ **主要贡献**：在真实尺寸双臂机器人上实现了稳健摆荡，包括失败恢复行为；通过Sim-to-Sim和硬件实验验证了方法在几何变化环境下的有效性，为基于手臂的机器人运动提供了学习设计指南。

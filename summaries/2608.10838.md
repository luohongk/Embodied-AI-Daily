# PolyLayout: Hierarchical VLM-Guided Layout Generation Beyond Rectangular Rooms

- arXiv: https://arxiv.org/abs/2608.10838v1
- arXiv ID: 2608.10838

---

🔍 **核心问题**：现有3D室内布局生成研究主要针对矩形房间和简单家具摆放，忽略了真实住宅中常见的非矩形几何结构和严格的门窗约束，难以直接应用于家居零售场景。

🛠 **方法**：提出一个混合式分层框架，将布局生成分为三个阶段：功能家具聚类与区内细粒度摆放、基于视觉语言模型（VLM）的宏观路由以在多样多边形边界内锚定区域和独立家具、以及基于规则的优化实现无碰撞且符合建筑约束的微观排列。

✨ **主要贡献**：在量产级目录和真实不规则户型上验证，该方法在感知合理性上达到最优，同时保持良好几何合规性和较低延迟，并能支持现有方法无法处理的非矩形边界，填补了学术研究与实际应用之间的空白。

# Vision Transformer-Based Multi-Level Feature Fusion for Multi-Label Sewer Defect Classification

- arXiv: https://arxiv.org/abs/2609.11375v1
- arXiv ID: 2609.11375

---

🔍 **核心问题**：大规模多标签场景下，下水道缺陷自动分类难以兼顾分类精度与计算复杂度。

🛠 **方法**：提出分层视觉Transformer模型Sewer-Transformer-ML（含多级特征融合），并设计两种轻量架构Sewer-MobileNet-ML与Sewer-Mobile-TransNet以适配资源受限场景。

✨ **主要贡献**：Sewer-Transformer-ML-Base在Sewer-ML测试集上以F2_CIW 65.68%登顶公开榜单，领先第二名7.6个百分点；Sewer-MobileNet-ML仅用17M参数即达65.73%的F2_CIW（参数减少约95%）；消融实验揭示了Transformer特征适合直接拼接、多尺度CNN特征更适合注意力融合的规律。

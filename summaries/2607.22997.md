# Real2Sim2Real for Vision-Language-Action Manipulation: An AMD ROCm-Based Pipeline

- arXiv: https://arxiv.org/abs/2607.22997v1
- arXiv ID: 2607.22997

---

🔍 **核心问题**：解决在非CUDA生态（AMD硬件）下，实现视觉-语言-动作（VLA）模型驱动的具身智能操作任务，证明无需依赖CUDA锁定的技术栈。

🛠 **方法**：基于AMD ROCm开源软件栈，整合数据中心训练芯片、Radeon PRO仿真/渲染GPU及Ryzen AI边缘计算，构建端到端加速管道，并融合3D高斯泼溅（3DGS）重建与Genesis物理引擎生成合成数据。

✨ **主要贡献**：提出首个完全AMD加速的VLA操作技术栈，包含四项渐进式演示（Sim-to-Real训练、语义目标选择、Real2Sim合成数据生成、大规模强化学习），所有管道在RDNA4/RDNA3.5硬件上原生运行，并可通过免费Radeon云平台复现。

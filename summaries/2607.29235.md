# FBFM: A Training-Free Asynchronous Feedback Mechanism for Flow-Matching in World-Action Models Execution

- arXiv: https://arxiv.org/abs/2607.29235v1
- arXiv ID: 2607.29235

---

🔍 **核心问题**：现有世界-动作模型（WAM）在长时程机器人控制中，仅在分块边界处用真实观测进行反馈校正，时间粒度较粗，无法在单个时间步级别修正预测误差，导致长期任务中误差累积和漂移。

🛠 **方法**：提出FBFM（反馈流匹配），一种无需训练的推理机制，在流匹配生成过程中将反馈嵌入当前生成块内部。它通过掩码伪逆修正条件速度场，利用前一个动作块指导下一个动作块生成，并用执行前一块后观测到的图像指导下一帧预测，形成跨块异步闭环校正。

✨ **主要贡献**：FBFM实现了细粒度的在线校正，无需额外训练即可提升对突发事件的响应能力并抑制长期漂移。在LIBERO和RoboTwin2.0任务中，成功率提升超过5%，真实机器人观测预测诊断显示跟踪精度显著改善，为开放环流生成与闭环动态之间架起新桥梁。

# Stochastic Dynamics on Persistence Diagram Space via Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.06276v1
- arXiv ID: 2608.06276

---

🔍 **核心问题**：现有持久性图（PD）统计方法多将其视为静态对象，缺乏对PD空间上随机演化与概率建模的框架。

🛠 **方法**：提出基于强化学习的随机动力学框架，通过拓扑感知的局部编辑操作定义PD上的受控马尔可夫过程，并设计奖励函数以平衡分布匹配、拓扑保真与复杂度压缩。

✨ **主要贡献**：证明了该马尔可夫链的不可约性、非周期性与几何遍历性，确保PD空间上唯一平稳分布的存在；实验表明该方法能在简化PD复杂度的同时保留主导拓扑结构，适用于合成数据与神经影像数据。

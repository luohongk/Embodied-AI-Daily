# An Integrated Vision-and-Language Pretraining (VLP) and Visual Question Answering (VQA) model to Automate Nondestructive Evaluation Image Analysis

- arXiv: https://arxiv.org/abs/2608.29408v2
- arXiv ID: 2608.29408

---

🔍 **核心问题**：自动化无损检测（NDE）图像的分析与解读，减少人工依赖和人为误差，提升检测流程效率。

🛠 **方法**：提出ChatNDE Figure to Caption系统，结合ResNet50提取图像特征与GPT2生成自然语言描述，并引入视觉问答（VQA）模型以支持针对图像的交互式提问。

✨ **主要贡献**：构建了大型NDE图像数据集并采用视觉-语言预训练（VLP）策略，使模型能生成包含关键缺陷特征的描述；尽管BLEU评分不高，但生成的描述已能捕捉专家关注的重要细节，且VQA功能增强了现场检测的交互性与实用性。

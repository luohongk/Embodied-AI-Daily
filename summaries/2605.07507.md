# TCMIIES: A Browser-Based LLM-Powered Intelligent Information Extraction System for Academic Literature

- arXiv: https://arxiv.org/abs/2605.07507v2
- arXiv ID: 2605.07507

---

🔍 **核心问题**：学术文献数量激增，现有信息抽取工具依赖编程技能或专用模型，限制了领域研究者（如中医药学者）的使用。

🛠 **方法**：构建基于浏览器的零安装平台TCMIIES，利用商业LLM API，通过模式引导提示框架和自动系统提示生成，实现图形化自定义抽取模式，无需编程；纯前端架构本地处理数据，支持多LLM提供商和并发批处理。

✨ **主要贡献**：提供灵活、隐私保护且成本效益高的文献结构化抽取方案，在中医药场景中结构化输出合规率超94%，抽取准确率接近专家水平（参考κ=0.82），并支持CNKI等中文数据库的智能字段映射。

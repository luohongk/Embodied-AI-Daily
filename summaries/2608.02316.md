# Residual-Based Adaptive Kalman Filtering for Legged Robot State Estimation

- arXiv: https://arxiv.org/abs/2608.02316v1
- arXiv ID: 2608.02316

---

🔍 **核心问题**：腿式机器人状态估计中，卡尔曼滤波器的噪声参数（Q和R）难以手动调整，且固定参数无法适应不同步态和环境变化。

🛠 **方法**：提出一种基于滤波残差和新息的自适应协方差调整策略，在不变扩展卡尔曼滤波器（InEKF）中在线更新过程噪声Q和测量噪声R，融合IMU与腿部运动学数据。

✨ **主要贡献**：实验表明，仅自适应调整R即可将小跑步态下的估计精度提升25%（相比固定调参的InEKF），且无需足底力传感器或额外参数调整，性能与基于足力的方法相当。

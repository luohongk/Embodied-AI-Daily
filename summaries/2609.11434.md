# Hologram Representation via Quadratic Phase Gaussian Splatting

- arXiv: https://arxiv.org/abs/2609.11434v1
- arXiv ID: 2609.11434

---

🔍 **核心问题**：如何更高效、高质量地表示全息图，以提升全息重建的视觉质量。

🛠 **方法**：提出复值二次相位高斯（CVQPG），用2D二次相位函数替代2D高斯溅射中的标准2D高斯表示，并引入额外可学习参数控制基函数的曲率。

✨ **主要贡献**：在全息重建中平均超越现有最优方法 +0.19 dB（RGB）和 +0.33 dB（灰度），证明调制基元波前是一种轻量有效的增强手段，且成功保留了自然图像的中高频信息。

# Rake-Compress Riccati Recursions for Parallel Scenario-Tree Model Predictive Control

- arXiv: https://arxiv.org/abs/2608.01332v1
- arXiv ID: 2608.01332

---

🔍 **核心问题**：解决场景树模型预测控制（MPC）中，标准树Riccati递归因依赖链随树高线性增长而难以并行化的问题。

🛠 **方法**：提出基于rake-compress树收缩的代数精确并行求解器，通过叶消除（rake）和单节点压缩（compress）两种操作，将任意有根树收缩至根节点，再反向恢复所有Riccati系数、状态、控制及乘子。

✨ **主要贡献**：实现$O(N)$算术复杂度与存储、$O(\log N)$跨度（与树高、平衡性及最大出度无关），支持半正定对偶正则化（含无正则情形），并证明收缩恒等式及与KKT系统的等价性；附带三个MIT许可的JAX实现包。

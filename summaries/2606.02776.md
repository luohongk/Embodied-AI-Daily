# Topics as Proxies for Sociodemographics: How Conversational Context Affects LLM Answers

- arXiv: https://arxiv.org/abs/2606.02776v4
- arXiv ID: 2606.02776

---

🔍 **核心问题**：在大语言模型用于法律、医疗、金融等高风险场景时，对话历史是否会导致不同用户群体间的结果差异，以及这种差异的主要驱动因素是什么。

🛠 **方法**：通过实验评估LLM从单次对话历史中推断用户社会人口学特征的能力，并比较社会人口学特征与对话主题、情绪、可读性等（心理）语言学特征对LLM生成建议的影响。

✨ **主要贡献**：发现LLM难以从单次对话中准确推断用户社会人口学特征，且群体间差异幅度很小；对话主题是影响LLM建议的最主要因素，其在一定程度上充当社会人口学群体的代理，且影响方式常不可预测，凸显了高风险场景下对话上下文对LLM输出的潜在风险。

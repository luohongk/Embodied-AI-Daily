# AppendiGrade: An XAI-Enhanced Deep Learning Framework for Grading Appendicitis in Ultrasound with Gaussian Blur and Grad-CAM

- arXiv: https://arxiv.org/abs/2608.17923v1
- arXiv ID: 2608.17923

---

🔍 **核心问题**：解决超声图像中复杂阑尾炎（如穿孔、脓肿）与单纯性阑尾炎的自动区分难题，提升诊断准确性与效率。

🛠 **方法**：采用四种预训练深度学习模型（DenseNet201、InceptionV3、ConvNextTiny、VGG19）进行分类，结合图像预处理、超参数调优、模型微调、图像锐化等优化技术，并利用Grad-CAM生成热力图解释模型决策。

✨ **主要贡献**：在4679张五类超声图像数据集上，将InceptionV3的准确率从69.21%提升至95.58%，并通过Grad-CAM可视化感染区域，便于专家交叉验证，提高了模型的可解释性和临床实用性。

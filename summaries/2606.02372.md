# CoMAP: Co-Evolving World Models and Agent Policies for LLM Agents

- arXiv: https://arxiv.org/abs/2606.02372v2
- arXiv ID: 2606.02372

---

🔍 **核心问题**：现有语言智能体的文本世界模型在训练后固定不变，无法适应智能体策略演化带来的状态-动作分布变化，且智能体改进常依赖外部奖励或验证器，限制了其在真实交互环境中的应用。

🛠 **方法**：提出CoMAP框架，通过闭环交互协同演化世界模型与智能体策略。每步决策时，世界模型预测候选动作的未来反馈，智能体基于反馈可靠性进行前瞻性反思并调整动作；随后用产生的on-policy轨迹通过自蒸馏更新世界模型，使其匹配智能体不断演化的交互分布。

✨ **主要贡献**：在具身任务规划、Web导航和工具使用基准上，CoMAP持续优于强基线（如Qwen3-4B相对提升+16.75%）；分析表明协同演化循环随时间提升世界模型预测精度，并增强长程决策有效性。代码已开源。

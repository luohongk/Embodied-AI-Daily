# RoboBRIDGE: A Modular Framework for Bridging Policies to Robust Real-World Robotic Agents

- arXiv: https://arxiv.org/abs/2607.27881v1
- arXiv ID: 2607.27881

---

🔍 **核心问题**：预训练的视觉-语言-动作（VLA）模型在部署为真实机器人智能体时，缺乏失败恢复机制、长程任务执行不一致，且对观测、任务或本体变化鲁棒性不足。

🛠 **方法**：提出RoboBRIDGE模块化框架，通过五个协调模块（Monitor、Perceptor、Planner、Controller、Robot Interface）对现成组件（包括预训练VLA）进行编排，实现快速失败检测与分层恢复、异步场景更新与重规划，以及基于LoRA适配器的原始技能微调。

✨ **主要贡献**：在LIBERO、RoboCasa及多平台真实世界案例中，RoboBRIDGE一致优于独立策略和现有增强VLA部署，证明可靠的机器人智能体不仅依赖扩展动作预测器，更需围绕其进行结构化编排。

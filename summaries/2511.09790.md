# A Robust Task-Level Control Architecture for Learned Dynamical Systems

- arXiv: https://arxiv.org/abs/2511.09790v2
- arXiv ID: 2511.09790

---

🔍 **核心问题**：基于动态系统（DS）的示教学习（LfD）在机器人任务空间生成运动规划时，常因未建模动态、持续扰动和系统延迟导致“任务执行不匹配”，使机器人状态偏离期望状态。

🛠 **方法**：提出L1增强动态系统（L1-DS）架构，在任意DS-based LfD模型上叠加标称稳定控制器和L1自适应控制器，并引入基于窗口动态时间规整（DTW）的目标选择器以处理时间错位，实现相位一致跟踪。

✨ **主要贡献**：首次在任务层面显式处理DS生成运动计划的执行不匹配问题，通过L1自适应控制增强鲁棒性，并在LASA和IROS手写数据集上验证了方法的有效性，显著提升跟踪精度与相位一致性。

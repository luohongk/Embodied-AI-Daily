# MSA-DCNN: A Data-Efficient Multi-Scale Attention Deformable CNN for Medical Image Classification

- arXiv: https://arxiv.org/abs/2607.06083v2
- arXiv ID: 2607.06083

---

🔍 **核心问题**：现有深度学习方法在医学图像分类中难以同时应对多尺度形态变化和标注数据稀缺的问题，且缺乏统一的解决方案。

🛠 **方法**：提出MSA-DCNN框架，整合自适应多尺度可变形采样、尺度内显著性细化、可学习的跨尺度融合，以及辅助自蒸馏机制，在统一优化方案中联合建模。

✨ **主要贡献**：在三个公开基准和一个外部白血病测试集上，MSA-DCNN在分布偏移和标签稀缺条件下，以更少参数在准确率、F1和AUC上达到与ViT、CNN及MICCAI半监督基线相当或更优的性能；消融实验验证了各组件的互补贡献。

# From Prior-Guided Heuristics to Deployable Agents: Accelerating Demonstration-Driven Reinforcement Learning for Deadline-Constrained Network Control

- arXiv: https://arxiv.org/abs/2609.03590v1
- arXiv ID: 2609.03590

---

🔍 **核心问题**：在动态异构网络中，为延迟敏感信息提供严格的端到端峰值延迟保证仍具挑战；现有基于流量的路由指标未考虑流量紧迫性，且从头训练的深度强化学习控制器存在样本效率低、训练时间长和早期探索波动等问题。

🛠 **方法**：提出部署导向的网络控制框架，包含两个部分：一是引入延迟感知的Effective Congestion (EC)指标族和Uniform Path Grouping (UPG)分布启发式，并嵌入混合架构MADRL EC ($p^*$)（分布式调度器+集中式RL路由器）；二是提出统一训练目标，泛化行为克隆、离线RL、在线RL及离线到在线方案，并据此推导Model-Guided Annealed Reinforcement Learning (MGA-RL)协议，基于DDPG骨干实现演示驱动的训练方法。

✨ **主要贡献**：提出EC指标族以按数据包紧迫性量化接口拥塞并主动过滤不可行流量，UPG启发式促进鲁棒负载均衡；MGA-RL协议泛化传统O2O方案，通过统一训练目标结合实时奖励、预收集奖励和策略模仿项，显著提升训练效率和部署可行性，为截止时间约束下的网络控制提供了实用解决方案。

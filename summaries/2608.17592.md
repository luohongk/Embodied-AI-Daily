# Communication Reduction via Semantic-Based Encoding in DMPC Using LSTMs

- arXiv: https://arxiv.org/abs/2608.17592v1
- arXiv ID: 2608.17592

---

🔍 **核心问题**：分布式模型预测控制（DMPC）中，智能体间频繁交换大量信息，导致通信负担过重，甚至超出先进无线通信技术的承载能力。

🛠 **方法**：采用基于长短期记忆（LSTM）网络的编码器-解码器结构，在分布式优化算法中实现语义通信压缩——发送端发布消息的降维表示，接收端重建原始消息。

✨ **主要贡献**：在移动机器人编队测试中，训练后的网络在通信受限条件下仍保持良好性能，且能应对全通信过载场景；LSTM不仅实现了高精度消息重建，还支持不同预测时域长度而无需重新训练。

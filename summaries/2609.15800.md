# Navigating Sparse Evidence: Agentic Visual RAG via Explicit Context Selection and Consolidation

- arXiv: https://arxiv.org/abs/2609.15800v1
- arXiv ID: 2609.15800

---

🔍 **核心问题**：视觉检索增强生成（VRAG）中，答案相关证据往往稀疏且分散，而现有智能体方法基于原始探索轨迹或压缩文本记忆生成答案，易受探索噪声干扰，且缺乏显式组织的支撑图像，导致推理依据不清晰。

🛠 **方法**：提出 SCoRE 统一智能体循环，探索阶段仅在文本账本中保留查询相关观察及其源指针以约束视觉上下文，终止时重新加载引用图像并按逻辑顺序整合为视觉证据用于作答；训练上结合过滤冷启动轨迹蒸馏与证据感知强化学习（奖励覆盖度、整合紧凑性与答案正确性）。

✨ **主要贡献**：将最终推理与探索试错解耦，通过索引化的声明-图像链接确保严格视觉接地，并实现端到端优化，提升了稀疏证据场景下 VRAG 的证据组织能力与答案可靠性。

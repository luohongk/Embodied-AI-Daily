# SceneGTMM: A Conformal Mapping-based Scene-Aware Transferable GNN-Transformer Dual-Graph Interaction Framework for Map Matching

- arXiv: https://arxiv.org/abs/2608.19298v1
- arXiv ID: 2608.19298

---

🔍 **核心问题**：解决地图匹配中噪声鲁棒性差、跨区域迁移能力弱以及模型可解释性不足的问题，尤其是在定位误差较大（16-50米）的多源轨迹场景下。

🛠 **方法**：提出SceneGTMM框架，包含三个核心组件：1）基于共形映射的场景相对策略，构建以轨迹为中心的局部坐标系以支持跨区域迁移；2）GNN-Transformer双图交互架构，GNN建模道路图捕捉局部拓扑约束，Transformer建模轨迹图捕捉全局时间依赖，并通过跨图注意力实现噪声抑制与语义对齐；3）CRF增强的结构化预测，结合Transformer全局上下文与CRF拓扑转移约束提升路径连通性。

✨ **主要贡献**：在多源轨迹上实现超过80%的匹配准确率，较HMM提升5.3%；在跨城市迁移场景中优于MTrajRec、GraphMM和TMM等现有方法；通过注意力机制和相对坐标可视化增强了模型可解释性，为实时交通感知和自动驾驶路径规划提供了高精度、可迁移的地图匹配新范式。

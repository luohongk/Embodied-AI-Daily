# Path Planning of Cleaning Robot with Reinforcement Learning

- arXiv: https://arxiv.org/abs/2208.08211v2
- arXiv ID: 2208.08211

---

🔍 **核心问题**：清洁机器人在不同环境中进行全覆盖路径规划时，传统强化学习模型需针对每个新环境重新训练，缺乏泛化能力，且现有方法多局限于简单路径段而非全局清扫。

🛠 **方法**：提出将近端策略优化（PPO）算法与迁移学习（TL）、最近已清洁瓷砖检测、奖励塑形及精英集构建相结合，实现跨多种清洁环境的高效路径规划。

✨ **主要贡献**：通过消融实验和与随机、Z字形等传统方法的对比，验证了该方法在训练性能和收敛速度上优于原始PPO，且整体清扫效率显著高于传统方法，具备更强的环境适应性。

# NebulaVLA: A Dual-Frequency Vision-Language-Action Model With Guide Action for Robotic Manipulation

- arXiv: https://arxiv.org/abs/2608.16503v1
- arXiv ID: 2608.16503

---

🔍 **核心问题**：解决视觉-语言-动作（VLA）模型在真实机器人部署中面临的效率与性能权衡、跨本体泛化能力不足以及执行平滑性差的问题。

🛠 **方法**：提出异步双频架构NebulaVLA，将高层语义推理与低层动作控制解耦；引入统一语言接地动作表示GESTURE-7以桥接异构机器人语义差异；设计Guide Action算法，通过掩码平滑约束保证运动学连续性。

✨ **主要贡献**：在LIBERO-Plus基准上达到85.5%的平均成功率，动作生成速度提升约2.7倍，显著优于同步基线，实现了高效且响应灵敏的机器人控制。

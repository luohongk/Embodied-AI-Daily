# Parameter Sensitivity Analysis for Aerial LiDAR-Inertial Odometries in low-altitude flights

- arXiv: https://arxiv.org/abs/2609.12837v1
- arXiv ID: 2609.12837

---

🔍 **核心问题**：LiDAR-惯性里程计（LIO）算法性能高度依赖场景、LiDAR类型和机器人运动特性，通常需要大量调参才能达到理想效果，本文旨在分析各参数对性能的影响以简化调参过程。

🛠 **方法**：在低至中空飞行采集的多环境LiDAR SLAM数据集上，对FAST-LIO2和Cartographer的LIO模块进行穷举网格搜索，利用Pearson相关性和随机森林置换重要性分析各参数与绝对轨迹误差（ATE）的关系。

✨ **主要贡献**：识别出对性能影响较大的关键参数，提出简化调参流程和调参建议；采用所提建议后，两种算法在94%的测试案例中ATE与网格搜索最优性能的差距在5 cm以内。

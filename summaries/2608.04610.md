# HiSC: Hierarchical Spatial Clustering Token Compression for Efficient 3D Scene Understanding

- arXiv: https://arxiv.org/abs/2608.04610v1
- arXiv ID: 2608.04610

---

🔍 **核心问题**：3D视觉-语言模型（3D VLMs）在多视角场景理解中因重复观测和大量无信息区域导致视觉token冗余，计算成本高昂，现有2D token压缩方法无法有效处理3D场景的结构化特性。

🛠 **方法**：提出HiSC，一种无需训练的层次化空间聚类token压缩框架。首先通过空间图合并（SGraM）策略利用几何与语义线索将冗余token聚为空间簇，再在LLM推理中通过空间聚类剪枝（SCluP）范式进行簇间与簇内层次化压缩，保留对象完整性与重要细节。

✨ **主要贡献**：在多种3D推理基准上验证了有效性，尤其在高压缩率下表现优异；实现超过90%的token缩减且性能损失极小，代码已开源。

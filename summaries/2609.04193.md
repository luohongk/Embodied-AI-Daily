# GIFT: Guided Intermediate Feature Training via Action-Oriented Structural Supervision for Robotic Manipulation

- arXiv: https://arxiv.org/abs/2609.04193v1
- arXiv ID: 2609.04193

---

🔍 **核心问题**：视觉-语言预训练和世界模型为机器人策略提供了丰富的视觉特征，但原生训练目标可能忽略控制相关的物理与任务结构，同时保留无关视觉冗余，导致“动作充分性差距”（action-sufficiency gap）。

🛠 **方法**：提出GIFT（Guided Intermediate Feature Training）框架，通过几何对齐、可供性预测和目标区域重建三种结构约束，将控制相关的几何、可供性和目标信息转化为训练时监督，引导中间特征学习，且不改变各模型原有的动作输出形式。

✨ **主要贡献**：在VLA策略和两种世界动作模型（WAM）上实例化GIFT，零样本迁移至LIBERO-Plus和RoboCasa均显著超越基线（最高提升12.6点），尤其在铰接物体任务和真实世界高精度操作中表现突出，证明学习功能结构化中间特征是一种跨模型动作公式的可复用原则。

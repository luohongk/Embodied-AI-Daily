# Realistic Continual Learning Approach using Pre-trained Models

- arXiv: https://arxiv.org/abs/2404.07729v2
- arXiv ID: 2404.07729

---

🔍 **核心问题**：持续学习中的灾难性遗忘问题，且现有实验设置多依赖理想化的类增量场景，忽略了真实环境中任务类别分布的随机性。

🛠 **方法**：提出RealCL（真实持续学习）范式，任务间类别分布随机；并设计CLARE方法，基于预训练模型整合新知识同时保留旧知识。

✨ **主要贡献**：首次将RealCL定义为传统持续学习设置的泛化形式，提出适应RealCL任务的CLARE方法，实验证明其在多种RealCL场景下优于现有模型，展现出在不可预测学习环境中的通用性。

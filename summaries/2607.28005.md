# Deep learning-based hierarchical insect classification using camera trap imagery

- arXiv: https://arxiv.org/abs/2607.28005v1
- arXiv ID: 2607.28005

---

🔍 **核心问题**：昆虫种群下降使生物多样性监测愈发紧迫，但传统人工鉴定耗时费力且缺乏标准化数据，深度学习图像分类在昆虫监测中面临数据标注难、类别不均衡和层级泛化等挑战。

🛠 **方法**：构建了一个包含约100万张昆虫图像、五级34类层级标注的长尾数据集，并设计了一种基于深度学习的层级分类模型，采用类平衡加权和置信度阈值（T=0.6）机制，在不确定时回退到更粗粒度的分类层级。

✨ **主要贡献**：模型利用生物分类学提取粒度特定的视觉特征，在五个层级上实现了80-99%的测试准确率，相比非层级分类器显著提升了层级一致性和预测可靠性，为大规模自动化昆虫监测提供了可行方案。

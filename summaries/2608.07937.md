# FlexSplat: Flexible Feed-Forward 3D Gaussian Splatting without Point Cloud Correspondence

- arXiv: https://arxiv.org/abs/2608.07937v1
- arXiv ID: 2608.07937

---

🔍 **核心问题**：现有基于查询的3D高斯泼溅前馈重建方法依赖已知相机位姿，本文旨在实现无需相机标定和点云对应的新视角合成。

🛠 **方法**：提出FlexSplat框架，联合训练几何Transformer与高斯解码器，前者预测每张图像的相机参数和深度，后者利用深度引导的高斯参数化及多视角可变形交叉注意力聚合所有视图信息，并通过不确定性加权的深度一致性损失优化几何估计。

✨ **主要贡献**：在ShapeNet-SRN和GSO数据集上，无需相机位姿和真值深度即可达到与有标定方法相当的性能（PSNR差距≤0.7 dB），且感知质量（LPIPS）最优；高斯数量与输入分辨率解耦，不随视图数增长，实现紧凑高效的表示。

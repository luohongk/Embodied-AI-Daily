# Exposing the Long-tail in Embodied Urban Navigation via Scalable Learning from In-the-Wild Videos

- arXiv: https://arxiv.org/abs/2608.16476v1
- arXiv ID: 2608.16476

---

🔍 **核心问题**：从真实世界数据学习城市导航策略受限于任务数据采集成本高，以及罕见但安全关键场景覆盖不足（即长尾问题）。

🛠 **方法**：提出一个可扩展框架，自动从网络规模的非结构化第一视角视频中标注度量轨迹和结构化导航语义，并训练视觉-语言-动作策略进行可解释的导航规划；同时基于模型性能和感知-运动模式分布刻画长尾，用反思式分析诊断重复失败模式。

✨ **主要贡献**：证明了从无约束视频到真实城市导航任务的有效知识迁移，并揭示了超越总体导航性能的连贯长尾结构，为系统暴露和应对安全关键场景提供了新途径。

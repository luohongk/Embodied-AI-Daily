# $\texttt{DisMorph}$: learning to disentangle technical distortions from true biological change

- arXiv: https://arxiv.org/abs/2608.08173v1
- arXiv ID: 2608.08173

---

🔍 **核心问题**：纵向MRI中，可变形配准估计的形变场混合了真实生物学变化与扫描仪引入的几何畸变（如梯度非线性），导致形态测量结果产生偏差。

🛠 **方法**：提出DisMorph框架，基于纯合成数据训练，显式将纵向形变分解为技术畸变场和生物学变化场；训练时用生成模型分别合成两类效应以提供解耦监督，并通过域随机化增强跨协议泛化能力。

✨ **主要贡献**：在模拟数据上比传统配准更准确、稳定地检测解剖变化；在仅含畸变的真实图像对上能将几何变化正确归因于畸变场；在阿尔茨海默病纵向数据中能检测脑区解剖变化并识别标准校正后残留的畸变，为临床中难以保持采集一致性的场景提供更精确的纵向形态测量。

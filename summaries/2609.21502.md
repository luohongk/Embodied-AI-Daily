# Adaptive World Memory 3D Foundation Model for Scalable 3D Mapping, Localization, and Rendering

- arXiv: https://arxiv.org/abs/2609.21502v1
- arXiv ID: 2609.21502

---

🔍 **核心问题**：现有3D基础模型虽能从RGB图像进行几何推理，但在持久记忆、可扩展性和可渲染场景建模方面存在不足，难以支撑大规模机器人定位与建图。

🛠 **方法**：提出以记忆为核心的3D基础模型，采用自适应世界记忆机制（基于Transformer的门控更新结合测试时时空调节），并通过局部子图组织、渐进式建图与跟踪、回环检测及SL(4)全局优化实现大规模建图，最后用高斯重建头解码记忆增强特征以统一位姿估计、点云重建与渲染。

✨ **主要贡献**：实现了单一模型内相机位姿估计、稠密点云重建与逼真渲染的统一，在公开基准和自采数据集上提升了轨迹精度、重建完整性和渲染质量，验证了自适应记忆作为持久机器人世界建模基础的有效性。

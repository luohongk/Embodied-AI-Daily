# Continual Distillation Learning for Rehearsal-Free Class-Incremental Learning via Decoupled Prompting

- arXiv: https://arxiv.org/abs/2407.13911v5
- arXiv ID: 2407.13911

---

🔍 **核心问题**：在无回放的基于提示的类增量学习中，如何将大规模ViT骨干的持续学习能力有效迁移到小规模模型，以提升其性能。

🛠 **方法**：提出Decoupled Continual Distillation Learning (D-CDL)，引入持久的知识蒸馏提示（KD-prompts）和专用KD分支，将蒸馏知识与任务适应解耦，KD-prompts跨任务传播以全局传递教师知识，原始提示继续负责持续学习。

✨ **主要贡献**：首次定义CDL蒸馏设置，D-CDL可通用集成到多种提示式持续学习方法中，在Split CIFAR-100和Split ImageNet-R上显著优于现有蒸馏基线，并在多种师生配置下稳定提升学生模型性能。

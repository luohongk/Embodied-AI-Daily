# Learning Multi-Agent Task Assignment and Navigation in the Factory: from Simulation to Real Robots

- arXiv: https://arxiv.org/abs/2609.14567v1
- arXiv ID: 2609.14567

---

🔍 **核心问题**：如何在工业环境中将去中心化多智能体强化学习（MARL）真正部署到多机器人系统上，实现多机器人对多机器的安全任务分配与导航。

🛠 **方法**：提出FMAPPO（特征融合多智能体PPO），将2D LiDAR测量与任务特定状态信息融合，并通过高保真仿真与ROS2构建完整的仿真到现实（sim-to-real）流水线，部署在物理移动操作平台上验证。

✨ **主要贡献**：在仿真中FMAPPO显著超越MAPPO和SMAPPO等基线（零件配送提升106%/21%，零件收集提升48%/11%，机器利用率提升31/10个百分点，碰撞减少18%/15%，安全分提升14/6个百分点），并在真实机器人实验中验证了去中心化策略能在真实传感与控制约束下安全协调多机器人服务多台机器。

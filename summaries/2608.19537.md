# Multimodal Trajectory Planning for Surface Vehicles using Turning Circle-based Control Barrier Functions

- arXiv: https://arxiv.org/abs/2608.19537v1
- arXiv ID: 2608.19537

---

🔍 **核心问题**：针对自主水面船在动态环境中的轨迹规划，解决传统基于欧氏距离的安全约束无法体现非完整运动学限制，以及单模态MPC易陷入局部极小值和死锁的问题。

🛠 **方法**：提出一种无需引导路径的多模态轨迹规划框架，将模型预测控制（MPC）与基于回转圆的控制障碍函数（TC-CBF）相结合，通过几何构造左转和右转两种避碰模式，并将避碰方向直接嵌入安全约束中。

✨ **主要贡献**：TC-CBF能根据船舶实际回转能力生成拓扑不同的可行轨迹，避免依赖全局引导路径，同时缓解局部极小和死锁问题。仿真实验表明，在多种交通密度下，该方法相比单模态基线具有更高的成功率、更少的安全违规次数和更小的残余违规量。

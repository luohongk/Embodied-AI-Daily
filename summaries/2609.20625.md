# Chronicle: Cut-Point Replay for Regression Testing of LLM Agents

- arXiv: https://arxiv.org/abs/2609.20625v1
- arXiv ID: 2609.20625

---

🔍 **核心问题**：LLM Agent 的失败难以复现，因为模型推理非确定性、工具读取的状态不断变化、多步轨迹难以重演，而现有记录工具只用于追踪或评分，无法针对代码变更做回归测试。

🛠 **方法**：提出 Chronicle，在 Agent 运行的非确定性边界处记录不可变"信封"并支持重放；其核心操作"切点重放"（cut-point replay）从记录中提供选定边界的响应，其余边界用新代码实时执行，从而把历史故障转化为可在 CI 中运行的回归测试。

✨ **主要贡献**：在 6 个记录故障的基准上，记录开销仅每次跨越 23 μs（约为 300 ms 模型调用的 0.008%），完整重放零模型调用且 20 次重复比特稳定；切点测试能对错误代码失败、对受保护及良性改动通过，并在变异研究中捕获所有放行不安全动作的变异体，而全桩基线一个都抓不到。

# 360CityArena: A Realistic Virtual Urban Navigation Benchmark for Embodied Agents

- arXiv: https://arxiv.org/abs/2608.08814v1
- arXiv ID: 2608.08814

---

🔍 **核心问题**：现有户外具身智能导航基准缺乏真实感或复杂度，难以反映真实城市环境中的导航与推理挑战。

🛠 **方法**：基于日本秋叶原地区602段360度视频构建逼真3D环境，设计175个手工任务，涵盖环境理解、路径推理和空间推理三类能力，并用LMM智能体进行评测。

✨ **主要贡献**：提出首个高真实感的城市级导航基准360CityArena；评测显示最强模型Gemini 2.5 Flash仅达17.1%准确率，远低于人类77.3%，揭示城市级具身导航仍存在巨大挑战。

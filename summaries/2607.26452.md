# CG-World: A Large-Scale World-State Dataset and Protocol for World Models

- arXiv: https://arxiv.org/abs/2607.26452v1
- arXiv ID: 2607.26452

---

🔍 **核心问题**：现有视频、机器人和仿真数据集通常只捕捉状态、动作、事件和观测的部分结构，缺乏支持世界模型联合动力学学习的完整数据。

🛠 **方法**：从工业计算机图形学管线中提取大规模世界状态数据集CG-World，明确记录中间状态（如多模态语义、空间结构、骨骼与控制器状态、物理缓存、接触事件等），并定义分支谱系（包括事实轨迹、观测干预、动作干预、机制干预和严格反事实分支）。

✨ **主要贡献**：构建了约85万个时间对齐片段的数据集，提供可复用的结构化监督，在几何条件视频生成、动作预测和闭环视觉-语言-动作策略迁移中验证了有效性，为世界模型、物理AI和具身智能奠定共享数据基础设施。

# Two-Token Features and Small-Large Ensembles for VLM Hallucination Detection

- arXiv: https://arxiv.org/abs/2609.10244v1
- arXiv ID: 2609.10244

---

🔍 **核心问题**：针对 SHROOM-Visions 2026 共享任务，检测视觉语言模型（VLM）在字符级别的幻觉输出。

🛠 **方法**：微调一个 4B 参数的小型 VLM 作为逐 token 分类器，从其自身隐藏状态中读取双 token 特征，并在预测时与约 400B 参数的零样本大型 VLM 评判器集成；两者均使用现成 OCR 读取图像中可见文本，并利用大模型生成的合成幻觉数据增强集成多样性。

✨ **主要贡献**：提出双 token 特征与小-大模型集成方案，在隐藏测试集上取得 Cor 0.487 / Cor-lbl 0.387，主指标 Cor-lbl 在英、法、意、中四种语言上分别排名 6/28、6/21、8/21、7/22。

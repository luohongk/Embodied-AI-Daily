# GenSplatCodec: Feed-Forward Gaussian Splatting Compression via One-Step Diffusion

- arXiv: https://arxiv.org/abs/2607.24403v1
- arXiv ID: 2607.24403

---

🔍 **核心问题**：现有前馈式3D高斯泼溅压缩方法在低码率下因丢弃高频纹理和视角相关外观信息，导致解码质量下降，而生成式后处理模型又缺乏跨视角一致性。

🛠 **方法**：提出GenSplatCodec统一编解码框架，采用双流编码方案（紧凑高斯结构流+轻量参考外观流），并通过几何引导的一步生成式解码，联合利用结构和外貌线索实现高保真、视角一致的新视图重建。

✨ **主要贡献**：首次将低码率高斯压缩重构为几何引导的生成式解码问题，提出三阶段优化策略稳定学习过程，在多个数据集上取得优于现有方法的率失真性能。

# Calibrated Partial Resets: Preventing Policy Collapse in Continual Reinforcement Learning

- arXiv: https://arxiv.org/abs/2607.24996v1
- arXiv ID: 2607.24996

---

🔍 **核心问题**：在持续强化学习中，神经网络因训练过程中产生大量休眠神经元而丧失可塑性，导致策略崩溃和性能下降。

🛠 **方法**：提出校准部分重置（CPR）优化器，周期性地将低效用神经元向初始化方向拉动，拉动强度根据每个神经元的效用值进行缩放，避免完全重置带来的不稳定性。

✨ **主要贡献**：CPR在SlipperyAnt任务中经过4亿步训练仍能避免策略崩溃，并在Continual MetaWorld和Continual MinAtar基准上优于现有重置和衰减方法，揭示了效用缩放重置在持续学习中平衡可塑性与峰值性能的潜力。

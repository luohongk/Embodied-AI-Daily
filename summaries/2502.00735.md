# `From Prompt to Perturbation': An Adaptive Framework for Voice-Based Jailbreaks on Audio LLMs

- arXiv: https://arxiv.org/abs/2502.00735v4
- arXiv ID: 2502.00735

---

🔍 **核心问题**：现有音频大模型（Audio LLMs）的安全研究通常只关注单一架构（级联流水线或端到端LALM），缺乏对两种架构在统一条件下系统性的对抗攻击评估。

🛠 **方法**：提出一种自适应越狱攻击框架，通过反馈引导的变异引擎自动生成并优化攻击候选，同时覆盖文本提示和音频扰动，从而扩展攻击的多样性与覆盖面。

✨ **主要贡献**：在六个代表性音频系统上验证了两种架构均存在显著漏洞；与现有最优方法相比，该框架在多种音频LLM系统上实现了更高的攻击成功率。

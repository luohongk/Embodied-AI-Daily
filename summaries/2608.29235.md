# Uncertainty-Aware Multimodal Anti-UAV Detection via Evidential Fusion and Conflict-Discounted Belief Aggregation

- arXiv: https://arxiv.org/abs/2608.29235v1
- arXiv ID: 2608.29235

---

🔍 **核心问题**：现有反无人机多模态感知系统在RGB与热成像融合时未建模预测不确定性，且无法表达模态间冲突时的怀疑，导致传感器退化或失效时可靠性不足。

🛠 **方法**：将EDTC框架扩展至RGB-热成像多模态感知，提出折扣信念融合（DBF），将模态间冲突转化为不确定性质量后再聚合意见，并通过选择低不确定性模态确定边界框。

✨ **主要贡献**：多模态融合在Anti-UAV基准上优于单模态（测试准确率0.670 vs 0.604/0.598），实时速度≥38 FPS；但DBF与无折扣平均效果无显著差异，因基准中模态间冲突近乎为零，融合不确定性校准良好（ECE 0.057）但作为定位失败检测器弱于空间方差（AUROC 0.626 vs 0.739），揭示冲突感知融合仅在特定数据分布下才有增益。

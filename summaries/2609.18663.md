# VLA-ULAP: Interleaving Cloud VLA Calls with Ultra-Lightweight Local Action Prediction at the Edge

- arXiv: https://arxiv.org/abs/2609.18663v1
- arXiv ID: 2609.18663

---

🔍 **核心问题**：十亿参数级VLA策略推理耗能高、远程调用通信延迟大，难以满足边缘端实时响应需求。

🛠 **方法**：提出VLA-ULAP，将远程VLA调用与超轻量本地动作预测器（ULAP，约7.4M参数）交错执行；ULAP融合当前视图、本体感知与已执行动作历史，单次前向预测动作块，独立训练，无需VLA隐状态或在线验证。

✨ **主要贡献**：在Jetson Orin Nano上单次推理仅19.9ms/0.183J（对比GR00T的284.3ms/50.55J）；仿真中减少48.8–76.7%的VLA调用并保留95.0–97.5%成功率，物理实验保留95.2–100%成功率且推理时间与能耗大幅降低，动态任务成功率亦优于π₀.₅。

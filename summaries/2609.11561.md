# Memory as Plans: World-Action Modeling with Memory-Grounded Planning

- arXiv: https://arxiv.org/abs/2609.11561v1
- arXiv ID: 2609.11561

---

🔍 **核心问题**：主流机器人策略多采用马尔可夫假设，但许多真实操作任务本质上是非马尔可夫的，需要超越当前观测的长时程记忆；现有记忆机制依赖语言摘要或不断增长的视觉窗口，容易丢失细粒度视觉证据，或在历史覆盖与执行效率间难以兼顾。

🛠 **方法**：提出 MaP-WAM（Memory-as-Plans）框架，将依赖记忆的世界-动作建模分解为“记忆驱动的规划”与“规划条件下的执行”，把长期多模态情景上下文作为规划阶段的证据而非反复输入执行器；通过 World-Action-Progress（WAP）模型在推理时联合预测动作块与执行进度，并借助规划-观测对齐校准进度，实现自适应分段切换与闭环上下文更新。

✨ **主要贡献**：以“记忆即计划”的方式将情景记忆压缩为分段级语言计划与视觉引导，使执行器上下文长度保持固定并支持键值缓存；在 RMBench 上取得 83.3% 成功率的最优表现，真实机器人任务达 78.0%，且执行推理延迟随任务历史增长近似恒定。

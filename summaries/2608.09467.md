# RecoverFly: A Failure-Aware Reinforcement Learning Post-Training Framework for Aerial Vision-Language Navigation

- arXiv: https://arxiv.org/abs/2608.09467v1
- arXiv ID: 2608.09467

---

🔍 **核心问题**：无人机视觉-语言导航（UAV-VLN）中的端到端策略因行为克隆目标缺乏交互式闭环执行的纠正监督，导致在复杂环境中导航性能受限。

🛠 **方法**：提出RecoverFly框架，采用失败感知的强化学习后训练方法，包括token级RL稳定优化语法约束的自回归动作、重访未解决失败案例以强化纠正学习，以及结合两阶段长尾场景课程与参考策略正则化提升场景适应性。

✨ **主要贡献**：在TravelUAV基准上，RecoverFly在未见地图和未见物体场景中均取得最佳性能；相比AerialVLA初始化，在仅使用约30%训练集大小的rollout预算下，成功率提升3.12至8.37个百分点，验证了其有效性、鲁棒性和泛化能力。

# SARTM: Segment Any RGB Thermal Model with Language aided Distillation

- arXiv: https://arxiv.org/abs/2505.01950v2
- arXiv ID: 2505.01950

---

🔍 **核心问题**：解决SAM模型仅基于RGB数据训练、无法直接应用于RGB-热红外（RGB-T）语义分割的问题，尤其是在低光、过曝等恶劣视觉条件下的场景理解。

🛠 **方法**：提出SARTM框架，通过添加LoRA层微调SAM以保留其分割能力，引入语言信息作为训练指导，并设计跨模态知识蒸馏（CMKD）模块来缩小模态差异，同时调整分割头并加入辅助语义分割头以融合多尺度特征。

✨ **主要贡献**：在MFNET、PST900和FMB三个基准上显著优于现有方法，实现了任意模态组合下的鲁棒分割，并公开代码与预训练权重。

# DynamicMCPBench: A Trace-Grounded, Effect-Scored Benchmark for LLM Agents over Live MCP Servers

- arXiv: https://arxiv.org/abs/2607.20531v2
- arXiv ID: 2607.20531

---

🔍 **核心问题**：现有LLM智能体基准测试依赖固定答案或工具列表，在动态、有状态的MCP服务器环境下评估失效，无法真实反映智能体处理实时任务的能力。

🛠 **方法**：提出DynamicMCPBench框架，通过自动生成任务、实时执行记录成功轨迹、提取与路径无关的效果检查点，并以“pass^3”（三次独立尝试全部成功）标准评分，而非比较最终答案。

✨ **主要贡献**：在121个服务器、750个任务上评估24个模型，发现最强智能体仅解决约50%任务，31%任务无模型可解，且任务链越长准确率从39%降至13%；人工验证表明自动评分可靠（一致性0.76），揭示了当前智能体在多步复杂任务上的系统性短板。

# Coverage Path Planning for Holonomic UAVs via Uniaxial-Feasible, Gap-Severity Guided Decomposition

- arXiv: https://arxiv.org/abs/2505.08060v3
- arXiv ID: 2505.08060

---

🔍 **核心问题**：针对全向无人机在应急响应中覆盖高度不规则多边形区域（如不对称形状、密集凹坑簇、多内部孔洞）时，现有分解策略过度碎片化导致路径长度和完成时间增加的问题。

🛠 **方法**：提出一种基于递归双轴单调性准则的分解策略，通过累积间隙严重性指标引导切割，将凹坑簇均匀分布至子区域，生成最小可并行扫描分区集，并结合全局优化器联合选择扫描路径与区间过渡，最小化总路径长度、过渡开销和转弯次数。

✨ **主要贡献**：在15种覆盖路径规划方法中，本方法实现了最低的平均路径长度和完成时间开销，显著提升了轨迹质量与效率。

# High-Fidelity Digital Twin Data Models by Randomized Dynamic Mode Decomposition and Deep Learning with Applications in Fluid Dynamics

- arXiv: https://arxiv.org/abs/2609.17101v1
- arXiv ID: 2609.17101

---

🔍 **核心问题**：如何从数值模拟输出中非侵入式地构建高保真数字孪生数据模型（DTM），以低计算成本准确复现复杂流体动力学过程。

🛠 **方法**：结合随机动态模态分解（randomized DMD）与深度学习人工智能，构建降阶数据模型，无需对控制方程进行Galerkin投影。

✨ **主要贡献**：提出了一种高效DTM新框架，在三个复杂度递增的激波现象数值模拟中验证了其数值精度与计算效率，输出结果与原始数据一致且复杂度显著降低。

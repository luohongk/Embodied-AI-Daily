# Exact Action Values Are Not Enough: Rollout-Verified Reinforcement Fine-Tuning of a Reasoning Model for Multi-Zone VAV Control

- arXiv: https://arxiv.org/abs/2607.27914v1
- arXiv ID: 2607.27914

---

🔍 **核心问题**：多区域VAV（变风量）空调控制需在热舒适、室内空气质量和电力消耗间平衡，但现有MPC和RL方法依赖建筑特定建模或训练，难以规模化部署。

🛠 **方法**：先测试前沿推理模型（GPT-5）能否无需建筑特定训练实现竞争性控制，再尝试用TD3引导的强化微调（RFT）将控制知识迁移到本地可部署的开源权重模型，并引入确定性rollout验证器审计critic。

✨ **主要贡献**：TD3在物理仿真中比基线降低4.5%电力且提升温控和CO₂合规；GPT-5降电6.2%但牺牲通风裕度；发现critic的跨时间相关性近乎完美（r=0.9998）却无法可靠排序同状态动作，rollout验证仅10个状态中5个选对最优；200步RFT无持续改进，开源模型预测误差未改善，建议先进行面向转移误差的监督微调再价值型RFT。

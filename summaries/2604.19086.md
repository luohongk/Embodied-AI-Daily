# MUCOCO: Automated Consistency Testing of Code LLMs

- arXiv: https://arxiv.org/abs/2604.19086v2
- arXiv ID: 2604.19086

---

🔍 **核心问题**：代码大语言模型（Code LLMs）常表现出不一致的程序行为，而现有基准测试多为手工构造、静态且不针对一致性属性，因此需要自动化方法发现其不一致行为。

🛠 **方法**：提出MUCOCO方法，采用语义保持的变异分析，将给定编程查询的程序自动转换为语义等价的变异体，并通过比较变异体与原始程序的输出或测试结果来检测不一致性。

✨ **主要贡献**：在4个编码任务和7个LLM上评估，MUCOCO能有效暴露不一致性，优于最接近的基线（TURBULENCE），约15%的生成输入触发不一致，凸显了测试Code LLMs一致性属性的必要性。

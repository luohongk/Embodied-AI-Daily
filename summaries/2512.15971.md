# From Words to Wavelengths: VLMs for Few-Shot Multispectral Object Detection

- arXiv: https://arxiv.org/abs/2512.15971v2
- arXiv ID: 2512.15971

---

🔍 **核心问题**：多光谱目标检测在自动驾驶、监控等安全场景中至关重要，但标注数据稀缺严重制约了深度检测器的训练。

🛠 **方法**：将两种代表性VLM检测器（Grounding DINO和YOLO-World）适配到多光谱输入，并提出一种有效机制来融合文本、视觉和热成像三种模态信息。

✨ **主要贡献**：在FLIR和M3FD两个基准上验证，VLM检测器在小样本场景下显著优于同等数据训练的专用多光谱模型，在全监督设置下也达到竞争性或更优的结果，表明大规模VLM学到的语义先验可有效迁移到未见光谱模态，为数据高效的多光谱感知提供了新路径。

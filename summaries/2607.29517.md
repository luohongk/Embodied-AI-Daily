# STAGE: STyle-controllable Action GEneration for personalized autonomous driving

- arXiv: https://arxiv.org/abs/2607.29517v1
- arXiv ID: 2607.29517

---

🔍 **核心问题**：解决自动驾驶系统无法个性化匹配用户驾驶风格的问题，使系统生成的驾驶行为能贴近用户自身习惯。

🛠 **方法**：提出STAGE方法，基于模仿学习训练，融合风格值和潜在动作模态编码；通过偏好学习将用户风格映射为连续单调值，并设计规则降低人工标注成本；推理时用户输入风格值控制动作生成。

✨ **主要贡献**：实现驾驶动作的风格可控生成，验证了在多种典型场景下与人类期望高度一致；相比其他方法，STAGE在风格可控性、连续性、驾驶风格对齐能力及安全性上具有独特优势。

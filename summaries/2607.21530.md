# From Resource Flow to Executable Tests: Petri-Net-Guided LLM Test Generation for Concurrent Stateful Rust APIs

- arXiv: https://arxiv.org/abs/2607.21530v1
- arXiv ID: 2607.21530

---

🔍 **核心问题**：大型语言模型生成的并发有状态Rust API测试常违反前置条件、缺乏深度或丢失并发语义，而传统模型方法需大量手工代码将抽象场景转为可执行测试。

🛠 **方法**：提出基于Petri网引导的测试生成方法，用有色令牌和变迁表示API资源、生命周期及因果依赖，推导合法深状态、近合法及偏序并发场景，并作为约束中间表示指导LLM代码合成，辅以局部忠实性契约、结构修复循环及Petri网调度优化。

✨ **主要贡献**：首次将Petri网形式化建模与LLM代码生成结合，实现从资源流到可执行测试的自动化转化，通过分层语义预言机区分合成失败与API行为违规，有效提升并发测试的深度和语义保真度。

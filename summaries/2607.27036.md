# Mitigating Compounding Error via Video Representation Regularization

- arXiv: https://arxiv.org/abs/2607.27036v1
- arXiv ID: 2607.27036

---

🔍 **核心问题**：视频扩散世界模型在自回归生成长视频时，因误差累积导致帧质量随时间严重下降，而误差累积的机制及如何实现稳定长程生成尚未明确。

🛠 **方法**：提出视频表示正则化（Video Representation Regularization），一种轻量级训练约束，通过稳定潜在表示并抑制迭代误差累积，同时引入有效秩（erank）作为误差累积的量化指标。

✨ **主要贡献**：首次建立自回归视频漂移与模型内部表示之间的联系，发现表示维度塌陷是误差累积的关键原因，揭示数据规模扩展无法抵抗误差漂移的反直觉现象，并在VBench的Aesthetic Quality和Imaging Quality指标上分别从38.65提升至55.56、从44.37提升至72.08。

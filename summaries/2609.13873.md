# PriMobiBench: Characterizing Visual Privacy Leakage in VLM-Driven Mobile GUI Agents

- arXiv: https://arxiv.org/abs/2609.13873v1
- arXiv ID: 2609.13873

---

🔍 **核心问题**：VLM驱动的移动GUI智能体在解析屏幕截图流时存在敏感信息直接泄露和用户画像推断的隐私风险，而缺乏标准化基准来量化这些风险。

🛠 **方法**：提出PriMobiBench基准，提供数据生成、智能体轨迹构建和多模型评估的统一流程，并构建MobiLeak数据集（16个应用、25种隐私属性、2960个隐私实例），同时提出在云端处理前遮蔽隐私敏感但任务无关UI元素的缓解方案。

✨ **主要贡献**：首次系统评估移动GUI智能体的视觉隐私风险，揭示VLM直接提取敏感信息成功率高达82.5%、用户画像推断成功率约70%，且所提缓解方案在仅损失约8%性能的情况下将画像成功率降低最多58%。

# Learning Agent-based Model Predictive Control for Holistic Vehicle Performance

- arXiv: https://arxiv.org/abs/2609.11871v1
- arXiv ID: 2609.11871

---

🔍 **核心问题**：传统基于智能体的模型预测控制（AMPC）依赖所有智能体贡献的精确预测，实际中难以实现，导致其最优性受限。

🛠 **方法**：提出学习型智能体MPC（LAMPC），融合基于模型的AMPC与数据驱动学习，采用高斯过程回归（GPR）结合在线数据管理预测未知贡献，并通过多步预测机制和基于预测方差的软机会约束随机框架保障控制安全与可行性。

✨ **主要贡献**：LAMPC在已学习场景中跟踪性能优于传统AMPC，在未充分学习场景中仍能保证约束满足，且具备实时实现效率和适应任意控制智能体拓扑的灵活性。

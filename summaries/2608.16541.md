# Automating Learner Assessment: Benchmarking Machine Learning and Deep Learning Models for EEG-Based Familiarity Prediction

- arXiv: https://arxiv.org/abs/2608.16541v2
- arXiv ID: 2608.16541

---

🔍 **核心问题**：解决教育中学习效果客观评估难的问题，具体是预测学习者对知识（人脸事实知识和数学概念知识）的认知熟悉度。

🛠 **方法**：采集23名参与者的连续EEG数据，提取六个频段的功率谱密度特征，并对比15种机器学习与深度学习模型（如CNN），采用标准分层交叉验证和严格的试次独立验证（Group K-Fold）两种评估策略。

✨ **主要贡献**：揭示标准交叉验证因时间泄漏导致性能虚高（CNN F1=0.9853），而试次独立验证下峰值降至0.6038但仍显著高于随机水平；通过SHAP分析发现额叶和颞叶的Gamma与Beta振荡是熟悉度的关键生物标志物，为教育技术中的EEG认知监测提供了现实基准。

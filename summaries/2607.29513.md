# Homotopy-Aware Corridor Generation without Predefined Reference Paths

- arXiv: https://arxiv.org/abs/2607.29513v1
- arXiv ID: 2607.29513

---

🔍 **核心问题**：现有安全走廊生成方法依赖预定义参考路径，导致走廊几何形状受限，且无法充分探索不同的同伦类别，影响机器人运动规划的灵活性与安全性。

🛠 **方法**：提出一种无需参考路径的走廊生成框架，基于凸集图（GCS），直接生成凸集序列作为走廊；扩展基于可见性的变形方法以比较和融合走廊；并开发自适应多尺度GCS，结合采样细尺度图与可见性粗尺度图，支持局部更新与全局探索。

✨ **主要贡献**：实现了无偏见的走廊结构生成，能保留多种同伦路径；自适应多尺度机制在环境变化时无需重建全图；数值实验显示高效建图、稳定轨迹性能及更短时长的同伦感知轨迹；地面与空中机器人硬件实验验证了其在未知障碍物下的实用性。

# A Physics-Informed Neural Network Approach for UAV Path Planning in Dynamic Environments

- arXiv: https://arxiv.org/abs/2510.21874v2
- arXiv ID: 2510.21874

---

🔍 **核心问题**：无人机在动态风场中规划安全、节能且满足物理约束的轨迹时，传统方法（如A*和Kino-RRT*）因离散化和采样限制，常产生次优或非平滑路径。

🛠 **方法**：提出一种物理信息神经网络（PINN）框架，将无人机动力学、风扰动和避障约束直接嵌入学习过程，通过最小化物理残差和风险感知目标，无需监督数据即可生成动态可行且无碰撞的轨迹。

✨ **主要贡献**：在控制能量、平滑度和安全裕度上优于A*和Kino-RRT*，同时保持相近飞行效率；展示了物理信息学习统一模型驱动与数据驱动规划的潜力，为无人机轨迹优化提供可扩展且物理一致的框架。

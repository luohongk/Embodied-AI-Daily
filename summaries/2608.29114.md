# CGFM-Nav: Cognitive Graph-Field Memory for Semantic-Guided Lifelong Multimodal Embodied Navigation

- arXiv: https://arxiv.org/abs/2608.29114v1
- arXiv ID: 2608.29114

---

🔍 **核心问题**：视觉语言导航（VLN）中，现有环境表示难以同时支持显式语义记忆和连续探索引导，导致智能体在长期导航中推理与探索效率不足。

🛠 **方法**：提出认知图-场记忆（CGFM），将对象、空间关系和视觉观测组织为多模态场景图，用于目标检索和长程推理；当目标不明确时，将图证据投影为语义前沿场以引导探索，并集成子图选择、VLM推理和验证反馈形成闭环决策框架CGFM-Nav。

✨ **主要贡献**：在GOAT-Bench上，基于Qwen3-VL-8B，CGFM-Nav将成功率从53.2%提升至63.0%，SPL从30.0%提升至39.6%，验证了显式语义记忆与语义引导探索结合的有效性。

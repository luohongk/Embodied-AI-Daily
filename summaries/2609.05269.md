# CONTINUITY: Security-Context Contracts for Composable LLM Agent Controls

- arXiv: https://arxiv.org/abs/2609.05269v1
- arXiv ID: 2609.05269

---

🔍 **核心问题**：LLM智能体系统中，单独正确的安全机制在跨组件组合时可能失效，导致安全上下文（如授权、溯源、策略）在指令到效果的传递链中被丢失、篡改或错误绑定，形成“安全上下文不连续”问题。

🛠 **方法**：提出CONTINUITY框架，为每个组件定义assume-guarantee契约，并通过签名根授权、溯源承诺、角色绑定转换收据、有界类型释放、转换见证及效果绑定执行许可等机制，携带经认证的安全上下文跨组件传递，最终以形式化“后果完整性”验证所有外部效果均有有效授权见证。

✨ **主要贡献**：实现了参考验证器与跨层故障注入套件，覆盖4个应用域、32类故障，在2,560个参数化攻击实例（128个故障域类）中，完整配置未产生任何有害外部效果，同时完成全部700个良性任务并升级处理200个歧义案例，证明智能体安全需显式跨层契约而非仅靠单点机制。

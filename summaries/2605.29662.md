# SAFE-Pruner: Semantic Attention-Guided Future-Aware Token Pruning for Efficient Vision-Language-Action Manipulation

- arXiv: https://arxiv.org/abs/2605.29662v2
- arXiv ID: 2605.29662

---

🔍 **核心问题**：视觉-语言-动作（VLA）模型在机器人控制中实时推理速度慢，现有视觉令牌剪枝方法多依赖浅层线索，可能误删深层所需的关键视觉信息。

🛠 **方法**：提出SAFE-Pruner框架，利用语义注意力一致性（模型在控制时间步中注意力集中于相同语义实体）预测深层令牌重要性，并引入参考时间步刷新策略，在注意力偏移时更新预测。

✨ **主要贡献**：实现最高1.89倍加速，成功率下降低于1.5%，且比现有最优方法性能提升达1.9%。

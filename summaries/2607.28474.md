# TEA-AgriVLN: Traversability Estimation Alarm for Agricultural Vision-and-Language Navigation

- arXiv: https://arxiv.org/abs/2607.28474v1
- arXiv ID: 2607.28474

---

🔍 **核心问题**：在农业场景的视觉-语言导航（VLN-CE）中，地面可通行性判断存在模糊性（如未成熟玉米地对机器狗可通行但对人类不可通行），导致导航决策不准确。

🛠 **方法**：提出TEA模块，通过估计相机图像的可通行性生成可通行性地图，当预测动作与地图不一致时向决策器发出警报，促使重新思考；该模块集成到AgriVLN骨干网络中形成TEA-AgriVLN方法。

✨ **主要贡献**：在A2A基准上将成功率（SR）从0.47提升至0.54，导航误差（NE）从2.91米降至2.70米，达到农业VLN-CE领域最先进性能；并通过消融研究和案例研究分析了TEA在不同地面类别和场景下的有效性与局限性。

# Visual Prompting for Robotic Manipulation with Annotation-Guided Pick-and-Place Using ACT

- arXiv: https://arxiv.org/abs/2508.08748v2
- arXiv ID: 2508.08748

---

🔍 **核心问题**：便利店场景中机器人抓取-放置任务面临物体密集堆叠、遮挡以及颜色、形状、尺寸和纹理等属性差异，导致轨迹规划与抓取困难。

🛠 **方法**：提出一种感知-动作流水线，利用标注引导的视觉提示（边界框标注可抓取物体与放置位置）提供结构化空间引导，并采用基于Transformer的动作分块（ACT）模仿学习算法，从人类演示中预测分块动作序列，实现平滑自适应的抓取-放置操作。

✨ **主要贡献**：在零售环境中通过成功率与抓取行为视觉分析验证了系统性能，显著提升了抓取精度与适应性，为密集场景下的机器人操作提供了数据驱动的有效方案。

# Surgical WAM: A World-Action Model for Data-Efficient Surgical Robot Learning

- arXiv: https://arxiv.org/abs/2608.11204v1
- arXiv ID: 2608.11204

---

🔍 **核心问题**：在动作标注数据（如dVRK遥操作轨迹）稀缺的情况下，如何利用丰富的无动作内窥镜视频提升手术机器人的闭环操控能力。

🛠 **方法**：提出Surgical WAM模型，基于Cosmos Policy构建统一生成模型，先通过无动作视频预训练学习手术场景的视觉动态，再在固定动作标注预算下微调，部署时作为滚动时域闭环控制器执行预测动作块并重规划。

✨ **主要贡献**：在四个模拟手术任务中，视频预训练将平均成功率从63.5%提升至77.8%（PegTransfer任务绝对提升20个百分点），尤其在接触密集和双臂协调任务上增益显著，证明无动作视频可提供可迁移的视觉动态先验，为数据高效的手术机器人学习提供了实用路径。

# BRIDGE: An Open-Source Humanoid Platform via Morphology-Control Co-Design for Physical AI

- arXiv: https://arxiv.org/abs/2609.03497v1
- arXiv ID: 2609.03497

---

🔍 **核心问题**：传统人形机器人开发将硬件设计与全身控制分离，导致系统难以实现类人运动的流畅性和敏捷性，无法有效利用人类行为数据。

🛠 **方法**：提出数据驱动的形态-控制协同设计框架，引入新指标同时衡量运动学重定向保真度与动态跟踪性能，优化机器人形态以匹配人类运动，并基于此设计开源平台Bridge。

✨ **主要贡献**：在多项指标上超越基线人形机器人（Bumi、K1、Toddlerbot），实现SOTA性能；发布88cm高开源平台Bridge及其控制策略，在基础行走、鲁棒平衡和高度动态动作中展现卓越表现，并提供开源材料。

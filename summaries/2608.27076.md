# Tabular Deep Learning for Algorithmic Trading: Cross-Regime Bayesian Optimisation for Equity Signal Generation

- arXiv: https://arxiv.org/abs/2608.27076v1
- arXiv ID: 2608.27076

---

🔍 **核心问题**：在算法交易的股票信号生成中，现有模型评估未明确针对市场制度（regime）变化进行超参数优化，导致模型在不同市场条件下的鲁棒性不足。

🛠 **方法**：对约300只美国大盘股11年的日度数据，训练五类模型（含表格深度学习），使用贝叶斯优化，目标函数针对三种统计上不同的市场制度下的交易表现进行超参数选择。

✨ **主要贡献**：提出跨制度鲁棒的超参数选择方法，显著提升样本外泛化能力；构建XGBoost与TabNet的混合集成模型，年化收益51.26%、夏普比率2.44、CAPM alpha显著为正（0.423，p=0.011），且近零beta表明收益源于选股而非市场暴露；另发现另类数据在技术面和基本面特征之后作用有限，且空头贡献强于多头。

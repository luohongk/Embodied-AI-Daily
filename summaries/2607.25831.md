# WarmTuner: Program-Specific Warm Starts for Compiler Autotuning via Offline-to-Online Reinforcement Learning

- arXiv: https://arxiv.org/abs/2607.25831v1
- arXiv ID: 2607.25831

---

🔍 **核心问题**：编译器自动调优中，现有方法依赖冻结的历史知识，导致在线搜索时若先验与目标程序不匹配，会浪费有限预算，难以快速找到最优编译标志组合。

🛠 **方法**：提出WarmTuner，一种离线到在线强化学习框架。离线阶段从历史数据学习程序条件化策略，覆盖全部标志空间；在线阶段利用真实编译运行反馈，通过组相对策略优化（GRPO）持续更新策略，使其由实测加速驱动而非仅依赖历史数据。

✨ **主要贡献**：在GCC 15.2.0的cBench和PolyBench上，WarmTuner平均加速达1.732倍（对比-O3），并在30个程序中14个取得最优结果，显著优于现有技术。

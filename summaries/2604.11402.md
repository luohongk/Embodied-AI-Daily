# SCD4VPR: Multi-modal Scene Change Detection for Long-term Visual Place Recognition Database Update

- arXiv: https://arxiv.org/abs/2604.11402v2
- arXiv ID: 2604.11402

---

🔍 **核心问题**：长期视觉位置识别（VPR）中，环境随时间变化（如季节更替）导致地图数据库失效，而现有场景变化检测（SCD）方法无法区分真实结构变化与视角差异，影响数据库更新决策。

🛠 **方法**：提出SCD4VPR，融合视觉语言模型（VLM）生成的语义描述与视觉特征，通过跨模态注意力机制，并结合几何-语义匹配，输出多类变化掩码，分别识别物体变化、外观变化和视角变化。

✨ **主要贡献**：构建了首个真实街景SCD基准（NYC-CD，含8122对像素级多类标注图像），在四个SCD基准上验证了方法对多种骨干网络的提升；在NYU-VPR数据库更新实验中，SCD4VPR引导的更新在最大时间间隔下恢复R@1达+30.1，且数据库更紧凑。

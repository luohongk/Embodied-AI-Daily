# Towards Tighter Convex Relaxation of Mixed-Integer Programs: Leveraging Logic Network Flow for Task and Motion Planning

- arXiv: https://arxiv.org/abs/2509.24235v2
- arXiv ID: 2509.24235

---

🔍 **核心问题**：传统混合整数规划在任务与运动规划中，因逻辑树约束导致凸松弛松弛度差、计算开销大，难以满足实时性要求。

🛠 **方法**：提出“逻辑网络流”（Logic Network Flow）框架，将时间逻辑谓词编码为网络流模型中的多面体边约束，并利用基于网络流的Fourier-Motzkin消元法消除连续流变量，在保持凸松弛紧度的同时减少约束数量。

✨ **主要贡献**：相比逻辑树方法，该框架在理论上证明凸松弛更紧、约束更少；实验显示在车辆路由、多机器人协调及动力学控制等任务中计算速度提升数个数量级，内存消耗降低，并在四足机器人上验证了动态环境下的实时重规划能力。

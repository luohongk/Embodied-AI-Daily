# Designing Reinforcement Learning for Diffusion Models: A Unified Path-Space View

- arXiv: https://arxiv.org/abs/2608.14430v1
- arXiv ID: 2608.14430

---

🔍 **核心问题**：当前扩散模型的强化学习（RL）后训练算法（如反向轨迹法和前向匹配法）在形式上碎片化，缺乏统一的理论框架，且性能差异的原因不明。

🛠 **方法**：从正则化扩散RL目标出发，利用采样SDE间的重要性采样推导出轨迹空间上的显式策略梯度估计器，并进一步推导出等价的方差缩减值梯度形式，从而统一两类算法；在此基础上提出多样本KDE值梯度估计器和尺度有界权重族。

✨ **主要贡献**：揭示了现有算法差异本质上是方差缩减效应而非RL原理不同，构建了统一的设计空间，并在SD3.5-M和Qwen-Image模型上验证了该解释，且新方法优于现有扩散RL基线。

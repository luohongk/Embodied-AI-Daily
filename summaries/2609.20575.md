# Accelerating Visual Policy Learning with Sampling-Based Model Predictive Control

- arXiv: https://arxiv.org/abs/2609.20575v1
- arXiv ID: 2609.20575

---

🔍 **核心问题**：视觉策略学习（如机器人运动与操作）需协调环境接触，计算和GPU显存开销大；一阶策略梯度虽借助可微仿真降低训练成本，但局部优化易收敛到非预期的接触模式。

🛠 **方法**：提出采样引导策略搜索（SGPS），将基于采样的模型预测控制（MPC）与一阶策略优化交替结合——先用行为克隆从采样动作初始化策略，再在扰动初始状态和随机动力学下交替进行采样细化与短时域FoPG更新，并采用解耦FoPG公式将渲染排除在计算图外，直接从深度观测学习。

✨ **主要贡献**：在单GPU上为Unitree Go2和G1机器人学习了运动、越障、推箱和双臂搬运等策略，证明细化过程优于单纯初始化与跟踪；蒸馏后的策略可零样本迁移到真实Go2，利用机载深度自主实现小跑、爬行、跨栏及行为切换。

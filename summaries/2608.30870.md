# VCAR: Training-Free 3DGS Segmentation via View Completeness and Axis-Aware Boundary Refinement

- arXiv: https://arxiv.org/abs/2608.30870v1
- arXiv ID: 2608.30870

---

🔍 **核心问题**：现有3D高斯泼溅（3DGS）语义分割方法依赖特征蒸馏，训练开销大且分割边界模糊，主要源于视角覆盖不足和各向异性高斯原语的边界溢出。

🛠 **方法**：提出VCAR，一种免训练的由粗到细分割策略。粗阶段用基于可见性的加权多视角投票快速定位目标；细阶段通过球面螺旋采样生成补充视角，在增强视图上多视角投票精化边界，并引入轴感知边界细化（ABR）沿主导轴压缩各向异性高斯原语以消除边界伪影。

✨ **主要贡献**：在NVOS和LERF数据集上达到最先进的无需训练的分割精度和效率，显著降低计算开销，代码已开源。

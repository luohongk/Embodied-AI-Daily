# Two-Timescale Hierarchical Reinforcement Learning for Resilient Operations

- arXiv: https://arxiv.org/abs/2607.23434v1
- arXiv ID: 2607.23434

---

🔍 **核心问题**：全球运营中突发冲击频发，需要能适应市场与运营条件变化的决策规则，尤其针对具有层级结构（长期与短期决策共享目标）的系统，如何联合优化这些相互依赖的规则以增强运营韧性。

🛠 **方法**：提出一种双时间尺度层级强化学习框架，分别在长期与短期时间尺度上自适应调整策略，并通过同步更新耦合策略，首次证明了此类耦合双时间尺度学习的收敛性。

✨ **主要贡献**：在理论层面，证明了策略对与最优策略对的平均差距为 \(O(T^{-1/2})\)，在决策失误导致明显利润损失时可改进至 \(O(\log T/T)\)；在二手车案例中，该框架在联合供需冲击下平均利润提升9.2%，在长期冲击情景下提升11.8%，且利润轨迹更稳定，无需改变现有层级决策结构即可增强运营韧性。

# LLM-Advisor: An LLM Advisor for Cost-efficient Path Planning across Multiple Terrains

- arXiv: https://arxiv.org/abs/2503.01236v3
- arXiv ID: 2503.01236

---

🔍 **核心问题**：在固定图路径规划中，全局规划器受限于预定义路线空间，可能错失原生分辨率地图中成本更低的地形走廊，导致路径成本非最优。

🛠 **方法**：提出LLM-Advisor框架，利用多模态语义地形上下文生成备选路线，结合地图分离的参考示例增强（REA）和确定性验证回退机制，仅部署可行且成本严格低于基线的路线。

✨ **主要贡献**：引入MultiTerraPath基准（2000张地图，含Easy/Hard子集），在粗格点A*（步长r=50）基线下，LLM-Advisor（GPT-5.5）在Easy和Hard上分别提升52.00%和45.00%的FIR，验证回退保证100%有效性，且在r=100时恢复49.16%（Easy）和29.98%（Hard）的粗-最优间隙。

# A Generalizable Feature Extractor for Alzheimer's-Related Brain MRI Tasks

- arXiv: https://arxiv.org/abs/2609.05400v1
- arXiv ID: 2609.05400

---

🔍 **核心问题**：在神经影像数据标注不足的情况下，预训练模型能否作为可复用的基础模型，用于阿尔茨海默病相关的多种下游任务，且无需针对每个任务重新训练。

🛠 **方法**：冻结一个先前用于脑龄预测的3D CNN（718万参数），通过低秩适配（LoRA）仅引入约1%的可训练参数，将其适配到不同任务，并在六个实验中评估其泛化能力。

✨ **主要贡献**：该模型在ADNI上区分正常与痴呆的AUC达0.964，直接迁移到OASIS-3（不重训练）AUC为0.871；还能预测淀粉样阳性（AUC 0.804）及估计海马体积（R²=0.80）和白质高信号体积（R²=0.91），证明脑龄模型可作为阿尔茨海默病任务的有效基础模型，尤其适合数据受限场景。

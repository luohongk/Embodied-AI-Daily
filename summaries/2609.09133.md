# ExecCritic: Learn to Test, Test to Improve for Coding Agents

- arXiv: https://arxiv.org/abs/2609.09133v1
- arXiv ID: 2609.09133

---

🔍 **核心问题**：编码智能体在仓库修复中依赖自身生成的测试，但测试可能不完整或错误，导致虚假信心和修复效果不佳。

🛠 **方法**：提出ExecCritic框架，采用“测试-验证-修订”流程，将测试生成与代码修复分离：Test智能体独立生成测试，Repair智能体基于执行反馈修改代码，两者分别用角色特定强化学习训练。

✨ **主要贡献**：角色分离和强化学习显著提升测试质量与修复率，Qwen Test智能体的Base-to-Gold成功率从22.2%升至62.2%，组合后修复率达72.6%，比无测试基线提升11.4个百分点，且无需更强模型或Oracle反馈。

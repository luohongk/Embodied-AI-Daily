# Surprised by Attention: Predictable Query Dynamics for Time Series Anomaly Detection

- arXiv: https://arxiv.org/abs/2603.12916v4
- arXiv ID: 2603.12916

---

🔍 **核心问题**：多元时间序列中的异常常表现为跨通道依赖关系的结构性偏移（如自动驾驶中转向指令与横向加速度解耦），而传统基于重构残差的检测器在灵活序列模型仍能合理重构信号时容易漏检。

🛠 **方法**：提出 AxonAD，将多头注意力中 query 的演化视为短时程可预测过程，用仅依赖历史的预测器预测未来 query 向量，配合梯度更新的重构路径，并以掩码预测-目标目标函数对 EMA 目标编码器进行训练；推理时结合重构误差与尾部聚合的 query 失配分数（预测与目标 query 的余弦偏差）。

✨ **主要贡献**：通过 query 预测与重构误差的双重评分，同时捕捉结构性依赖偏移和幅度级异常；在专有车载遥测数据及 TSB-AD 多元基准（17 数据集、180 序列）上，排序质量与时间定位均优于强基线，消融实验证实 query 预测与组合评分是性能提升的主要来源。

# Paint What You See: Benchmarking Dexterous Visual Tool Use in Multimodal Agents

- arXiv: https://arxiv.org/abs/2608.25417v1
- arXiv ID: 2608.25417

---

🔍 **核心问题**：现有基准测试主要覆盖网页导航、GUI操作和软件工程，缺乏对“灵巧视觉工具使用”（即从视觉证据推断参数并精确控制最终结果）这一能力的评估。

🛠 **方法**：提出EASEL基准，以参考图像引导的视觉重建为主要代理任务（智能体逐步绘制画布匹配参考图），并包含区域标注、手写和路径规划等语义任务；同时提供EASEL-Data（44万样本的两阶段课程数据集）和EASEL-9B模型用于训练与效果验证。

✨ **主要贡献**：对25个模型的评估显示现有多模态智能体在EASEL上普遍表现不佳（重建相似度仅0.40-0.54），且存在严重的闭环不稳定性；EASEL-9B在训练后相对基础模型提升6.3%，在所有模型中排名第三，揭示了该能力的显著短板与改进潜力。

# Beacon: LLM Multi-Agent Driven Hardware Design Space Exploration for Heterogeneous Multi-Chiplet Deep Learning Accelerators

- arXiv: https://arxiv.org/abs/2608.30932v1
- arXiv ID: 2608.30932

---

🔍 **核心问题**：异构多芯粒深度学习加速器的硬件设计空间探索（HW-DSE）因仿真评估昂贵、迭代预算有限，传统数据驱动方法难以高效优化设计参数。

🛠 **方法**：提出Beacon框架，利用大语言模型（LLM）多智能体协作，结合评估器生成的详细报告（如执行时间线、资源利用率等）进行瓶颈定位、根因诊断和候选硬件生成，并集成分析工具箱与RAG记忆实现闭环搜索。

✨ **主要贡献**：在有限迭代预算下，Beacon相比随机搜索、贝叶斯优化和强化学习，将复合延迟-能耗-成本目标降低25.1%–93.5%，显著提升异构多芯粒设计探索效率。

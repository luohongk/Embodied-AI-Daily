# Learning Mamba as a Continual Learner: Meta-Learning Selective State Space Models for Continual Learning

- arXiv: https://arxiv.org/abs/2412.00776v5
- arXiv ID: 2412.00776

---

🔍 **核心问题**：传统元持续学习（MCL）依赖Transformer作为序列模型，但其键值缓存随样本线性增长，违背了持续学习不存储全部样本的初衷；而现有常数状态模型（如线性注意力、状态空间模型）虽符合要求，但难以有效进行元学习。

🛠 **方法**：提出MambaCL，将选择性状态空间模型（Mamba）应用于元持续学习，并引入选择性正则化（selectivity regularization）来监督压缩状态中的隐式关联，使常数状态模型在MCL中可训练且有效。

✨ **主要贡献**：系统验证了Mamba及其他常数状态模型在多种MCL场景下的有效性、泛化性和模型设计差异，展示了常数状态学习器在高效持续学习中的潜力，性能优异且泛化能力强。

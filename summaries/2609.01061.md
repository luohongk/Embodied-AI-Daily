# Accelerating Reinforcement Learning via MPC Solver-Gradient Guidance for Weights-varying MPC

- arXiv: https://arxiv.org/abs/2609.01061v1
- arXiv ID: 2609.01061

---

🔍 **核心问题**：在模型预测控制（MPC）中，固定代价函数权重在环境变化时性能不佳，而基于强化学习（RL）的在线权重自适应虽能优化真实闭环回报，但样本效率低；基于梯度的策略学习（GB-PL）虽利用可微MPC求解器梯度提高效率，却可能因模型失配产生偏差。

🛠 **方法**：提出SG-RL（Solver-Gradient Guided Reinforcement Learning），以采样闭环回报为目标，用有界的求解器梯度作为辅助引导，结合PPO算法，通过四种模块化方式（actor更新缩放、策略损失、优势估计、价值函数学习）注入梯度信息，实现MPC权重在线自适应。

✨ **主要贡献**：在两个全尺寸自动驾驶平台上，SG-RL在存在模型失配时，以最多减少70.6%的样本达到PPO最优闭环回报，比GB-PL基线至少提升54%的回报，并能零样本泛化到未见环境。

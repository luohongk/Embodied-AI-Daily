# REPLICANT: Learning Policies for Evading and Hardening Malware Detectors

- arXiv: https://arxiv.org/abs/2608.28499v1
- arXiv ID: 2608.28499

---

🔍 **核心问题**：评估机器学习恶意软件检测器在现实对抗环境下的鲁棒性，现有攻击方法常假设攻击者能访问训练数据、特征空间或置信度分数等特权信息，不符合实际威胁模型。

🛠 **方法**：提出Replicant，一种基于深度强化学习的框架，在严格的标签-only黑盒威胁模型下学习可迁移的规避策略，同时优化样本修改方式与查询时机，并跨样本、检测器和特征空间复用。

✨ **主要贡献**：在七个Android恶意软件检测器和三个特征空间上，Replicant平均攻击成功率达78.8%，相对最优基线提升20.9%-39.2%，且查询效率更高；用于对抗训练时，生成的检测器具有更强的泛化鲁棒性，证明学习规避任务既能提升攻击性能，也能为加固检测器提供更优信号。

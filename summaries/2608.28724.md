# MANTLE: A Framework for Adaptive In-Situ Planetary Perception Using a Modular Uplink Principle

- arXiv: https://arxiv.org/abs/2608.28724v1
- arXiv ID: 2608.28724

---

🔍 **核心问题**：火星表面探测任务中，机器人需要自主感知复杂地形以确保安全导航和科学分析，但现有感知模型难以在任务中持续更新和扩展能力。

🛠 **方法**：提出MANTLE多任务自适应网络，采用共享的DINOv2骨干网络提取特征，搭配两个任务专用头——用于地形分类的分类头和用于巨石分割的分割头，分别基于HiRISE轨道影像和MSL地表影像训练。

✨ **主要贡献**：分类头在7类火星地形上达到92.56%的测试准确率，分割头在验证集上IoU达0.753，并在未见过的行驶路径上表现出强跨日泛化能力。其核心创新是“模块化上行链路原则”——仅需在星上保留共享冻结骨干，新感知能力可在地球训练为轻量任务头后上行更新，无需重训全模型，使探测器能在任务期间持续学习进化。

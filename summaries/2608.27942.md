# CASTANET: Causality-Aware Spatio-Temporal Adversarial Network Using Traffic Incident Effects

- arXiv: https://arxiv.org/abs/2608.27942v1
- arXiv ID: 2608.27942

---

🔍 **核心问题**：预测由突发事件（如事故、道路损坏）引起的非周期性交通拥堵，这类事件稀疏、时空分布不均且影响异质，传统深度学习方法难以有效预测。

🛠 **方法**：提出CASTANET模型，融合时空图神经网络与因果处理效应估计，显式利用事故记录并缓解事件数据的选择偏差。

✨ **主要贡献**：在东京真实交通与事故数据上，整体RMSE较最优基线降低4.0%，事件条件下降低10.1%，严重拥堵场景下提升达14.55%。

# RetroDFM-R: Reasoning-Driven Retrosynthesis Prediction with Large Language Models via Reinforcement Learning

- arXiv: https://arxiv.org/abs/2507.17448v2
- arXiv ID: 2507.17448

---

🔍 **核心问题**：现有AI逆合成预测方法依赖模式匹配而非可迁移的化学推理，导致泛化性和可解释性不足，难以获得化学家信任。

🛠 **方法**：提出RetroDFM-R，一种基于大语言模型（LLM）的逆合成预测模型，通过大规模强化学习训练，使其生成透明、逐步的化学推理过程，而非仅输出黑箱预测结果。

✨ **主要贡献**：在USPTO-50K基准上达到60.4%（无增强）和66.1%（全推理设置）的准确率，超越此前最优基线；双盲专家评估证实其合成路径的化学合理性和实用性；能重构真实药物及自组装单层材料的多步合成路线，兼具高准确率与人类可解释性，推动自动化逆合成规划的实际部署。

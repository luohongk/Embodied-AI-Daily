# US-VLA: An Ultrasound Vision-Language-Action Model for Embodied Abdomina

- arXiv: https://arxiv.org/abs/2608.16074v1
- arXiv ID: 2608.16074

---

🔍 **核心问题**：现有AI辅助超声扫描方法依赖精心设计的奖励函数或大量交互数据，泛化能力差，难以适应不同设备、患者和复杂临床场景。

🛠 **方法**：提出超声视觉-语言-动作模型（US-VLA），显式编码临床语义目标，在实时超声反馈下生成序列化探头操作动作；设计超声感知专家融合模块，联合整合超声观测与辅助上下文信息。

✨ **主要贡献**：构建了包含肝脏和肾脏检查的US-VLA-Data真实数据集（5个临床标准切面、320条专家扫描轨迹、约8万同步时间步）；实验证明US-VLA在探头操控任务中表现优异，验证了其在腹部超声场景中的有效性和泛化潜力。

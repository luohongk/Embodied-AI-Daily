# LLM-Assisted Dynamic Threat Analysis for Attacker-Reachable Software Weaknesses in Autonomous Vehicles

- arXiv: https://arxiv.org/abs/2608.13450v1
- arXiv ID: 2608.13450

---

🔍 **核心问题**：自动驾驶软件栈中，从对抗性输入可达的软件弱点难以动态验证其可利用性，手动构建可执行测试工件成本极高。

🛠 **方法**：对Autoware的185个包进行编译器精确静态分析，识别弱点并采样740个可达站点；使用两个本地开源LLM（推理模型和代码专用模型）生成测试工件，通过编译器反馈修复，并对可执行部分进行模糊测试。

✨ **主要贡献**：构建了构建集成失败分类法，发现80%的首次编译失败源于依赖连接而非程序逻辑；推理模型首次编译成功率（64%）远超代码专用模型（6%），但修复后仍因桩代码导致崩溃，未能在预算内动态确认任何弱点，表明构建集成是LLM辅助动态分析的主要瓶颈。

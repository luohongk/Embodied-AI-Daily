# Anomalous Frame Detection Using VLM-Based Description Comparison for Extracting Expert-Specific Actions and Contextual Decision-Making Scenes with Intra-Video Self-Similarity

- arXiv: https://arxiv.org/abs/2607.11957v2
- arXiv ID: 2607.11957

---

🔍 **核心问题**：如何从专家与普通工人的任务视频中自动提取包含专家特有动作和情境决策的候选场景，以传承专家经验。

🛠 **方法**：利用视觉语言模型（VLM）逐帧生成视频描述，通过帧间描述比较提取专家特有动作，并基于视频内描述的自相似性分析片段相似度，提取情境决策场景。

✨ **主要贡献**：在27个模拟配电盘维护任务中，动作候选提取率达65%（传统方法59%），决策场景候选提取率达61%（传统方法33%），显著提升了专家知识候选场景的发现效果。

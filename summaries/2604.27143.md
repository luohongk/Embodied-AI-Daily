# Enhancing Linux Privilege Escalation Attack Capabilities of Local LLM Agents

- arXiv: https://arxiv.org/abs/2604.27143v2
- arXiv ID: 2604.27143

---

🔍 **核心问题**：本地小型开源大语言模型在Linux权限提升攻击任务中成功率远低于云端前沿模型（仅8-16%），且缺乏系统性分析其失败原因与改进方法。

🛠 **方法**：基于hackingBuddyGPT框架，对两个小型模型（Llama3.1 8B、Qwen2.5 7B）进行实证研究，从执行轨迹中归纳六类失败模式，并评估五种增强技术（链式思考提示、检索增强生成、结构化提示、历史压缩、反思分析）的独立与组合效果。

✨ **主要贡献**：通过全因子消融实验，将小型模型成功率从8%提升至67%（匹配引导的GPT-4o），70B模型达83%；发现反思分析贡献最大，且漏洞发现（而非利用）是本地模型的主要瓶颈，为构建可靠本地攻击代理及防御方提供了可迁移经验。

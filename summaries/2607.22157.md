# Learning on the Job: Continual Learning from Deployment Feedback for Frozen-Weights Agents

- arXiv: https://arxiv.org/abs/2607.22157v1
- arXiv ID: 2607.22157

---

🔍 **核心问题**：AI智能体在部署后模型参数被冻结，无法从每次运行中积累经验，导致重复遇到相同困难任务时仍需从零开始。

🛠 **方法**：提出一种持续学习框架，将冻结模型与外部记忆模块结合，把每次运行的结果（如成功/失败判定或事后修正）蒸馏为可检索的自然语言规则，实现从部署反馈中持续学习。

✨ **主要贡献**：在τ-bench银行领域，仅利用单比特结果反馈即可将单次任务成功率提升至基线1.6倍，利用修正反馈提升至2.6倍，并解决了基线无法完成的84个任务中的22个；该方法在Mistral Large和Claude Sonnet 5上均有效，且积累的记忆可在不同模型间迁移。

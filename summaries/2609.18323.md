# Can MiniMax-H3 Reason About the Physical World? An Evaluation of Omni-Modal Generative Model

- arXiv: https://arxiv.org/abs/2609.18323v1
- arXiv ID: 2609.18323

---

🔍 **核心问题**：全模态生成模型（如MiniMax-H3）能否借助多模态对齐提升对物理世界的推理能力，以及全模态输入能带来哪些新的评估范式。

🛠 **方法**：构建了一个围绕物理世界推理四个维度的评估框架，设计了四类需跨模态整合互补信息的新任务（隐式提示+多帧、音频-图像、前缀视频、音频-视频），共517个评估实例。

✨ **主要贡献**：首次系统评估全模态生成模型的物理世界推理能力，MiniMax-H3总体成功率为41.97%（视频决策推理最高56.00%，音频消歧推理最低27.40%），表明有效的多模态整合仍是充分发挥多模态输入优势的关键。

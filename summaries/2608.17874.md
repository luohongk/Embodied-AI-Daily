# Jetson-ORB-SLAM3: Accuracy-Preserving GPU Implementation for Edge Computing Devices

- arXiv: https://arxiv.org/abs/2608.17874v1
- arXiv ID: 2608.17874

---

🔍 **核心问题**：在低功耗边缘设备上运行视觉惯性SLAM时，密集特征提取和回环检测计算成本高，现有GPU移植常以牺牲精度换取速度。

🛠 **方法**：提出一种精度保持的GPU实现，将ORB特征提取前端卸载到NVIDIA Jetson Orin Nano的GPU上，算法复现CPU参考检测器（关键点一致率94.7%，描述子位一致率99.9%）；回环检测通过原生TensorRT加速CNN模型，后端建图与优化仍留在CPU。

✨ **主要贡献**：在EuRoC、TUM-VI和KITTI数据集上验证，GPU管线与CPU参考的轨迹误差差异小于0.10cm，证明加速不损失精度；CosPlace回环检测推理延迟降至2.2ms（180倍加速），单目惯性模式在EuRoC上平均32FPS，且系统可在7W功耗设备上实时运行。

# SuppreSensing: Expert-Guided Feature Recalibration and Discrepancy Augmentation for Multimodal Object Detection

- arXiv: https://arxiv.org/abs/2608.20944v1
- arXiv ID: 2608.20944

---

🔍 **核心问题**：多模态目标检测中，遥感图像面临语义异质性和模态特定噪声干扰，导致融合效果不佳。

🛠 **方法**：提出SuppreSensing框架，包含专家驱动的多模态特征重校准模块（EMFR）和专家驱动的定制特征净化模块（ECFP），并采用模态特定属性增强策略建模双向差异模式。

✨ **主要贡献**：在DroneVehicle和VEDAI数据集上达到最先进检测性能，并在FLIR和LLVIP自然场景数据集上验证了跨域鲁棒性和泛化能力。

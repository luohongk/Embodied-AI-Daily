# Bi-Level Routing and Sparse Spatial Attention based Multi-View BEV 3D Object Detection for Autonomous Driving

- arXiv: https://arxiv.org/abs/2609.14185v1
- arXiv ID: 2609.14185

---

🔍 **核心问题**：基于BEV的多视角3D目标检测面临计算复杂度高、多尺度特征提取困难以及密集2D到BEV视角转换效率低等问题。

🛠 **方法**：提出Sparse-BEVNet算法，在图像特征提取网络中引入双层路由注意力（BRA）降低主干计算负担，在特征融合模块采用级联组注意力（CGA）增强跨层级特征交互，并用稀疏空间交叉注意力机制替代传统密集视角投影流程。

✨ **主要贡献**：在nuScenes数据集上达到45.2% mAP和54.5% NDS，相较基线模型分别提升3.6%和2.8%，在降低计算开销的同时提升了检测精度。

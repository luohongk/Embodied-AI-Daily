# PyFLI: A Python Library for Simulation, Parameter Estimation, and Benchmarking in Fluorescence Lifetime Imaging

- arXiv: https://arxiv.org/abs/2609.11994v2
- arXiv ID: 2609.11994

---

🔍 **核心问题**：荧光寿命成像（FLI）因采集设备（ICCD、SPAD、TCSPC）和寿命估计方法各异，缺乏统一的数据模拟、参数估计与基准测试工具，尤其难以为深度学习提供带真实标签的训练数据。

🛠 **方法**：PyFLI 是一个开源 Python 框架，支持从多种采集系统导入数据、在可配置的采集与噪声条件下模拟带标签数据，并集成非线性最小二乘拟合、最大似然估计、相量分析、RLD、Laguerre 估计以及可选的贝叶斯和深度学习推断，支持 CPU/GPU 图像级处理。

✨ **主要贡献**：提供了 FLI 处理与标准化数据模拟的统一平台，涵盖重建、可视化、统计分析和跨软件比较，并包含用于单像素高光谱 FLI 的压缩感知重建，便于方法评估与公平基准测试。

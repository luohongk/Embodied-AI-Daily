# Generating Medical Image Counterfactuals using Causal Explanations

- arXiv: https://arxiv.org/abs/2609.02697v1
- arXiv ID: 2609.02697

---

🔍 **核心问题**：现有医学图像反事实解释方法依赖生成模型（如GAN或扩散模型），导致用另一个黑盒模型解释分类器，难以区分分类器决策与生成器偏差。

🛠 **方法**：提出无需生成模型的反事实生成框架，直接从分类器提取的因果证据构建反事实图像，支持用户指定区域的可控编辑，且无需额外训练。

✨ **主要贡献**：该方法确定性高、透明性强，在真实医学数据集上能有效改变分类预测，同时保持图像与原始输入更接近，优于生成式基线，更直接揭示分类器的决策边界。

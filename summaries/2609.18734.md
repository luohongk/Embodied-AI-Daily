# Conditionally linear, matrix normal state space models

- arXiv: https://arxiv.org/abs/2609.18734v1
- arXiv ID: 2609.18734

---

🔍 **核心问题**：如何对矩阵值时间序列数据建立线性状态空间模型，并在统一框架下处理混合频率、异方差和异常值等问题。

🛠 **方法**：提出状态为潜矩阵正态过程的线性状态空间模型，推导矩阵版本的卡尔曼滤波、对数似然和平滑算法，并给出贝叶斯推断中从潜状态矩阵联合后验分布抽样的算法。

✨ **主要贡献**：将经典状态空间模型推广到矩阵值情形，应用于美国50州宏观经济面板数据，发现少量潜因子即可捕捉跨州跨变量的联合动态，为高维宏观系统提供简约且可扩展的建模方法。

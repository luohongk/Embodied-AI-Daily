# LG-VLN: A Zero-Shot Vision-and-Language Navigation Framework with LangGraph State Orchestration

- arXiv: https://arxiv.org/abs/2609.15098v1
- arXiv ID: 2609.15098

---

🔍 **核心问题**：连续环境下的视觉语言导航（VLN-CE）需在未知3D环境中理解自然语言指令并执行连续动作，而现有方法依赖LiDAR、全景相机等额外传感器，且几何建图与语义导航使用分离的视觉表示，易导致长轨迹中的空间-语义不一致。

🛠 **方法**：提出LG-VLN单目零样本框架，采用共享视觉特征与基于LangGraph的状态编排。在线前馈3D重建网络预测深度、相机位姿和稠密点云用于位姿估计与全局地图融合；几何与导航共享稠密CleanDIFT特征，结合语义一致性过滤、目标实例约束、BLIP-2图文相关性构建语义价值图；LangGraph将指令解析、几何感知、语义更新、路径规划、动作执行与失败恢复建模为带条件转移的有向状态图。

✨ **主要贡献**：在R2R-CE val-unseen的550回合子集上实现21.3%成功率和12.1% SPL，消融实验证明共享语义特征可提升导航性能，且视觉相似度与图文相关性的结合进一步增强效果，确立了共享视觉表示与显式状态编排在纯单目RGB零样本VLN-CE中的有效性。

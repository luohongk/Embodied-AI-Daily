# Embodied Agents Take Control: Minimal-Interface Zero-Shot Agents Rival Industrial-Scale Policies in Vision-and-Language Navigation

- arXiv: https://arxiv.org/abs/2607.26148v1
- arXiv ID: 2607.26148

---

🔍 **核心问题**：研究通用型智能体能否在仅依赖单目RGB摄像头和离散动作的极简接口下，自主完成零样本视觉语言导航任务，并与工业级专用策略竞争。

🛠 **方法**：采用三种软件工程智能体框架（agent harnesses），在零样本导航测试中仅提供单目RGB图像和离散动作，并引入可选的训练航点工具作为混合能力，对比不同模型与接口配置的效果。

✨ **主要贡献**：发现默认配置下通用智能体（如opus-5）可达70.7%成功率，混合智能体（fable-5）在默认努力下以更少步骤和更短时间达到76.7%成功率，且性能主要受模型选择驱动；但长时任务中性能显著下降，延迟和上下文增长限制持续运行。

# CoVeR: Coverage-Based Token Pruning for Multi-View 3D Reasoning in VLMs

- arXiv: https://arxiv.org/abs/2609.08345v1
- arXiv ID: 2609.08345

---

🔍 **核心问题**：多视角3D场景推理中，视觉token数量庞大且存在空间冗余，现有剪枝方法要么保留近重复token导致场景覆盖不全，要么无法精确控制token预算并因3D重叠而饱和。

🛠 **方法**：提出CoVeR，一种无需训练、确定性的token选择器，仅利用token坐标信息，通过选择能共同覆盖场景所有区域的token，实现精确的逐场景预算控制，同时避免学习型方法的近重复选择和体素化的饱和问题。

✨ **主要贡献**：CoVeR在三个3D推理基准上全面超越现有SOTA方法，仅用约8%的视觉token即可保留93.5%的完整性能，平均提升3.9个百分点，并作为即插即用模块在四种VLM上验证了泛化能力。

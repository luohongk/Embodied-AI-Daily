# Rollplex: Cross-Phase GPU Spatial Sharing for Vision Language Model Post-Training

- arXiv: https://arxiv.org/abs/2608.14498v1
- arXiv ID: 2608.14498

---

🔍 **核心问题**：视觉语言模型（VLM）的强化学习后训练中，现有运行时将rollout、参考评分和actor训练严格串行执行，导致GPU计算资源在密集视频和前缀处理阶段利用率不足。

🛠 **方法**：提出Rollplex运行时，将参考和训练阶段分解，把前缀计算移入rollout解码窗口，并采用两机制：阶段感知内存管理控制HBM驻留，并行感知权重共享在不同张量并行度间复用物理存储。

✨ **主要贡献**：在32块H800 GPU上，Rollplex相比串行共置加速1.23–1.30倍，相比分离部署加速1.57–2.24倍，同时保持同步RL更新语义，显著提升VLM后训练效率。

# REFACTOR-VLA: Unsupervised Library Learning of Typed Motor Programs

- arXiv: https://arxiv.org/abs/2609.01215v1
- arXiv ID: 2609.01215

---

🔍 **核心问题**：现有视觉-语言-动作（VLA）模型是“单体式”的，直接输出原始动作，缺乏可复用的行为抽象，导致长时程任务性能下降且难以解释；同时，已有技能发现方法未解决“何时两个动作序列行为等价”这一核心问题。

🛠 **方法**：提出REFACTOR-VLA，一种“醒/睡”两阶段系统。睡眠阶段利用学习到的潜在世界模型计算“行为等价核”（BEK），对动作片段进行聚类；清醒阶段基于Hindley-Milner风格词汇表生成带类型的lambda表达式，并由库条件化的整流流动作解码器执行。抽象仅通过最小描述长度和返回保持门控后才会被采纳。

✨ **主要贡献**：在LIBERO基准上发现，单纯扩大世界模型容量（188M→430M）反而使4套任务性能全面下降；而训练目标更为关键——加入辅助监督对比（InfoNCE）损失显著提升聚类质量，NMI在4套任务上分别达0.462、0.867、0.915和0.754，平均超越最强基线+0.184。此外，睡眠阶段首次生成真实LIBERO任务语言库，解码器使用3个抽象中的2个并重写全部256条演示。

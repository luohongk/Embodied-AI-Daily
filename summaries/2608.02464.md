# Real-Time Detection and Repair of LLM Agent Failures

- arXiv: https://arxiv.org/abs/2608.02464v1
- arXiv ID: 2608.02464

---

🔍 **核心问题**：LLM智能体在任务执行中常出现循环、工具错误、目标偏离等失败，而用第二个LLM逐步评判的修复成本过高，需探索低成本、高效的失败检测方法。

🛠 **方法**：仅基于可观测的步骤遥测数据，使用仅需微秒级计算、且只在健康运行上训练的一类回声状态网络集成（结合CUSUM告警）进行检测；另加一层确定性验证，通过重算工具结果与调用记录来捕捉失败。

✨ **主要贡献**：在2823个真实智能体会话中，检测器在5%误报预算下召回0.71（AUROC 0.872），且能预测自身失效区域；确定性验证以零误报捕获60%失败（含覆盖率检查达96%），两者结合将任务成功率从52%提升至73%，每步开销约200微秒，比LLM评判低三个数量级。

# Beyond Action Imitation: Learning a Decision-Aware User Simulator for Online Advertising

- arXiv: https://arxiv.org/abs/2607.26893v1
- arXiv ID: 2607.26893

---

🔍 **核心问题**：现有基于LLM的用户模拟器仅从单领域交互历史推断偏好并预测点击等动作，导致偏好捕捉不完整、模型易走捷径，模拟的保真度和诊断价值有限。

🛠 **方法**：提出DASH模拟器，通过上下文工程将跨领域异构历史转化为决策相关上下文，并利用强LLM蒸馏思维轨迹进行监督微调，再结合基于规则的奖励模型（评估思维轨迹的形式、内容和逻辑）与动作奖励进行强化学习训练。

✨ **主要贡献**：在腾讯真实广告数据（覆盖5个异构内容领域）上验证了DASH在有效性、效率、保真度和诊断价值上的优势，实现了联合生成思维轨迹与预测行为动作的决策感知模拟。

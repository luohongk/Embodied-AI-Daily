# AtlasPatch: Scalable Foundation Model-based Tissue Detection and Patch Extraction for Computational Pathology

- arXiv: https://arxiv.org/abs/2602.03998v3
- arXiv ID: 2602.03998

---

🔍 **核心问题**：全切片图像（WSI）预处理中的组织检测与图像块提取是计算病理学的关键步骤，但现有方法在染色差异、组织碎片和伪影下鲁棒性不足，且计算成本高，成为大规模工作流的瓶颈。

🛠 **方法**：提出AtlasPatch，基于SAM2基础模型构建组织检测器，仅微调层归一化参数（占模型权重的0.076%），在缩略图分辨率上单次前向传播生成组织掩膜，并通过金字塔感知的轮廓映射直接生成目标放大倍率下的图像块坐标，实现并行化高通量提取。

✨ **主要贡献**：构建了包含30,000对缩略图-掩膜的多队列数据集，覆盖多器官、扫描仪和伪影；检测精度达0.986，对切片变异鲁棒；相比现有深度学习方法提速达16倍，同时保持六个切片级分类任务的下游多实例学习性能，为大规模计算病理学提供高效预处理方案。

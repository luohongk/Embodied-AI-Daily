# ARIES-Mission2: A Zero-Shot Vision-Language-Action Framework for Fast Large-Scale Aerial Mission Generation

- arXiv: https://arxiv.org/abs/2608.12763v1
- arXiv ID: 2608.12763

---

🔍 **核心问题**：多模态大语言模型在低空无人机任务生成中缺乏空间优化能力，导致路径规划效率低下。

🛠 **方法**：提出零样本VLA框架ARIES-Mission2，将视觉语义感知与物理路径优化解耦，使用DeepSeek-V3解析任务、Molmo-7B进行目标定位，并通过地理插值将像素坐标转为GPS航点；后端将多目标遍历建模为TSP问题，比较原始VLM顺序及PSO、GPSO、IPSO三种优化路线，选取最短闭环路径。

✨ **主要贡献**：在UAV-VLPA-nano-30基准上，总飞行距离62.43 km，较未优化VLA基线缩短21.6%，较人工规划缩短9.5%；每任务平均耗时19.18 s，比专家快约3.6倍；TSP求解仅需0.16 s/任务，且计算时间随目标数增长缓慢，具备良好可扩展性。

# Compact Feed-Forward 3D Gaussians via Saliency-Guided Primitive Merging

- arXiv: https://arxiv.org/abs/2608.10712v1
- arXiv ID: 2608.10712

---

🔍 **核心问题**：前馈式3D高斯泼溅方法从稀疏视图重建场景时，会生成大量逐像素高斯原语，导致表示冗余且渲染效率低下。

🛠 **方法**：提出一种结构感知的合并流水线，通过显著性引导的自适应超像素分割将空间相邻、外观相似的高斯聚类，再用学习式编码器压缩为潜在表示，跨视图匹配合并，最后通过细节层次解码器生成可控分辨率的高斯集。

✨ **主要贡献**：将高斯数量压缩至逐像素方法的1/20，同时保持视觉质量；作为与骨干网络无关的后处理模块，能灵活调节质量与效率的权衡，在减少原语数量方面优于现有方法。

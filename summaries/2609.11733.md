# Reflex-Informed Neuromuscular Reinforcement Learning for Muscle-Driven Locomotion

- arXiv: https://arxiv.org/abs/2609.11733v1
- arXiv ID: 2609.11733

---

🔍 **核心问题**：肌肉驱动的人体运动生成难以同时兼顾生理合理性与对肌肉能力变化及外部扰动的适应性。

🛠 **方法**：提出“反射信息引导的神经肌肉强化学习”框架，以固定的相位依赖反射控制器为底层机制，由强化学习策略输出四个具有生物力学意义的残差参数，动态调节髋摆动、膝支撑和踝推进相关的反射增益与阈值。

✨ **主要贡献**：生成的运动在生理合理性、运动学精度、动态一致性、双侧对称性和步态稳定性上均有提升，且学习到的策略在肌肉无力和外部扰动下无需重新训练即可保持鲁棒。

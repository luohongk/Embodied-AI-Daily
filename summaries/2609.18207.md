# Reinforcement Learning for Real-Time Vision-Language-Action Policies

- arXiv: https://arxiv.org/abs/2609.18207v1
- arXiv ID: 2609.18207

---

🔍 **核心问题**：大型VLA模型推理延迟高，导致执行时观测已过时，产生分布偏移，严重降低机器人操作的可靠性与性能；现有异步执行方法多基于模仿学习，无法超越训练分布。

🛠 **方法**：基于EXPO-FT框架，将慢速但表达能力强的动作生成与快速反应式动作编辑解耦——大型预训练VLA提出动作块，轻量编辑策略根据最新观测快速编辑动作，实现满足实时控制需求的RL微调（Real-Time EXPO-FT）。

✨ **主要贡献**：在Kinetix基准的10/10环境中，延迟策略取得最优性能；在四项真实动态任务（传物、平衡球、桌上足球、动态抓取）中，仅用10分钟在线数据即将平均性能从42%提升至97%，无需人工干预，展现了快速、样本高效的真实世界动态适应能力。

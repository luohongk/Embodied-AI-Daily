# Adaptive Learned State Estimation based on KalmanNet

- arXiv: https://arxiv.org/abs/2604.02441v2
- arXiv ID: 2604.02441

---

🔍 **核心问题**：现有基于学习的混合状态估计器（如KalmanNet）在模拟数据上表现良好，但在真实汽车多传感器数据（雷达、激光雷达、摄像头）中性能不足，难以适应复杂交通场景和传感器噪声特性。

🛠 **方法**：提出自适应多模态KalmanNet（AM-KNet），为每个传感器设计独立的测量模块以学习其噪声特性；引入超网络通过上下文调制（目标类型、运动状态、相对位姿）实现滤波器自适应；并基于Joseph形式构建协方差估计分支，通过负对数似然损失监督估计误差和新息。

✨ **主要贡献**：在nuScenes和View-of-Delft数据集上，AM-KNet相比基础KalmanNet显著提升了估计精度和跟踪稳定性，缩小了与经典贝叶斯滤波器在真实汽车数据上的性能差距。

# ManiCM: Real-time 3D Diffusion Policy via Consistency Model for Robotic Manipulation

- arXiv: https://arxiv.org/abs/2406.01586v4
- arXiv ID: 2406.01586

---

🔍 **核心问题**：现有基于扩散模型的3D机器人操作策略因多步去噪导致推理速度慢，难以满足实时控制需求。

🛠 **方法**：提出ManiCM模型，将一致性约束引入扩散过程，在点云条件下于动作空间构建一致性扩散，并通过一致性蒸馏技术直接预测动作样本（而非噪声），实现单步推理生成动作。

✨ **主要贡献**：在Adroit和Metaworld的31个任务上，ManiCM将最先进方法的平均推理速度提升10倍，同时保持具有竞争力的平均成功率，验证了实时性与性能的平衡。

# ActFER: Agentic Facial Expression Recognition via Active Tool-Augmented Visual Reasoning

- arXiv: https://arxiv.org/abs/2604.08990v2
- arXiv ID: 2604.08990

---

🔍 **核心问题**：现有基于多模态大语言模型（MLLM）的面部表情识别（FER）方法采用被动范式，依赖外部预处理的面部输入，仅对固定视觉证据进行单次推理，缺乏主动感知能力。

🛠 **方法**：提出ActFER智能体框架，将FER重构为主动视觉证据获取与多模态推理过程，动态调用人脸检测与对齐工具，选择性放大局部区域，并通过视觉思维链推理面部动作单元（AUs）和情绪。同时开发UC-GRPO强化学习算法，利用AU多级可验证奖励、查询条件对比效用估计和情绪感知EMA校准实现动态信用分配。

✨ **主要贡献**：ActFER在多个基准上持续优于被动MLLM-based FER基线，显著提升AU预测精度，实现了对局部检查时机和证据推理策略的联合学习。

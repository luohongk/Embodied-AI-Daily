# MeClear: Cooperative Game-Theoretic Attribution and Risk-Aware Memory Clearance for Long-Horizon LLM Agents

- arXiv: https://arxiv.org/abs/2609.09115v1
- arXiv ID: 2609.09115

---

🔍 **核心问题**：长时程LLM智能体依赖外部记忆系统，但传统检索机制只优化语义匹配，忽略下游效用，常将过时、误导或冲突的记忆引入上下文，损害任务表现。

🛠 **方法**：提出MeClear框架，结合Leave-One-Out筛选与采样合作Shapley归因，评估记忆间的交互效用，识别并抑制负面记忆；通过查询范围的嵌套过滤执行最小清除策略，在不永久改动记忆库的前提下验证任务恢复。

✨ **主要贡献**：在十个长对话记忆池上，MeClear达到85.9%的目标召回率和82.3%的整体任务恢复率，较LOO基线提升25.5个百分点，有效解决冗余冲突遮蔽问题。

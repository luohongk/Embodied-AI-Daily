# Beyond Static Costs: Learning-Dynamics Aware Loss Functions for Long-Tailed Classification

- arXiv: https://arxiv.org/abs/2607.25830v1
- arXiv ID: 2607.25830

---

🔍 **核心问题**：解决长尾分布数据集中，传统重加权损失函数仅依赖静态类别频率，忽略模型动态学习过程，导致尾部类别性能差的问题。

🛠 **方法**：提出学习动态感知损失函数（LDAL），通过三类动态指标连续调整类别权重：特征表示强度（语义尺度）、基于预测熵的类别学习难度、以及跨epoch预测变化正则项，以稳定训练并避免局部最优。

✨ **主要贡献**：首次将损失函数从静态样本计数转向动态学习进度，在多个基准数据集上显著超越现有重加权方法，实现精度与泛化性的最优平衡，且计算开销可忽略。

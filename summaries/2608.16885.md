# $τ_0$-VLA: a Hierarchical Robot Foundation Model with World-Model-Guided Test-Time Computation

- arXiv: https://arxiv.org/abs/2608.16885v1
- arXiv ID: 2608.16885

---

🔍 **核心问题**：长时程机器人操作中，分层视觉-语言-动作（VLA）模型每次决策仅通过单次前向传播完成，无法为困难或关键选择分配额外计算资源。

🛠 **方法**：提出$τ_0$-VLA，一种分层机器人基础模型，将高层子任务生成建模为可扩展计算量的推理问题，通过世界模型引导的测试时计算，在必要时搜索替代子任务，并由低层策略跨多机器人执行。

✨ **主要贡献**：在40,115小时异构真实数据上训练，采用多模态协同训练；实验表明，增加测试时计算显著提升子任务预测准确率，并在长时程操作任务中带来更高的闭环成功率，适用于域内和分布偏移场景。

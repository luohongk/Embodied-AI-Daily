# WoundAIssist: Development and Evaluation of an AI-Based Mobile Application for Remote Chronic Wound Care in Elderly Patients

- arXiv: https://arxiv.org/abs/2506.06104v2
- arXiv ID: 2506.06104

---

🔍 **核心问题**：老年人群中慢性伤口护理需求日益增长，传统护理需频繁面诊，耗费大量医疗资源，加重患者与医护人员负担。

🛠 **方法**：开发了以患者为中心的AI移动应用WoundAIssist，支持患者在家拍照记录伤口并填写问卷，医生通过远程监控和视频问诊参与诊疗；集成轻量级深度学习模型实现设备端伤口分割，并结合患者报告数据与服务器端AI分析持续监测愈合进程。

✨ **主要贡献**：一是开发了WoundAIssist这一易用且功能全面的远程伤口护理方案，二是通过患者与皮肤科医生的可用性研究验证了其出色的易用性、良好的应用质量及对AI伤口识别的积极评价，并总结了三年多跨学科研究得出的远程患者监测应用设计经验。

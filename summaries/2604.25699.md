# NVLLM: A 3D NAND-Centric Architecture Enabling Edge on-Device LLM Inference

- arXiv: https://arxiv.org/abs/2604.25699v2
- arXiv ID: 2604.25699

---

🔍 **核心问题**：解决边缘设备上大语言模型（LLM）推理受限于内存带宽和存储访问粒度的问题，尤其是单批解码时的内存瓶颈。

🛠 **方法**：提出NVLLM架构，将前馈网络（FFN）计算卸载到3D NAND闪存中，注意力机制在轻量CMOS逻辑和外部DRAM上执行；通过晶圆堆叠集成多平面NAND与计算流水线，将GEMM/GEMV分解为点积原语，直接在原始NAND读取上执行并集成ECC，同时用KV缓存感知调度器维持吞吐量。

✨ **主要贡献**：在OPT和LLaMA模型（最高30B参数）上，相比A800外核推理实现16.7×–37.9×加速，比SSD类设计快4.7×，且CMOS面积开销仅2.7%。

# CR-VLA-Force: Learning Control-aware Compliance VLA Model for Robust Contact-rich Robotic Manipulation

- arXiv: https://arxiv.org/abs/2609.05832v1
- arXiv ID: 2609.05832

---

🔍 **核心问题**：现有力觉感知的视觉-语言-动作（VLA）模型在接触丰富的机器人操作中，难以实现精确的力跟踪和快速连续调整，导致任务失败和安全风险。

🛠 **方法**：提出控制感知的柔顺VLA框架（CC-VLA），采用多模态混合专家（MoE）编码力信号与视觉-语言融合特征，结合多阶段训练策略，并设计VLA引导的自适应柔顺控制器，同时引入对抗式共享遥操作策略采集高精度力/力矩数据。

✨ **主要贡献**：在真实实验中显著提升了挑战性力感知任务的成功率和力控制精度，并在部分分布外位姿偏移场景下展现出多层次的安全性与鲁棒性。

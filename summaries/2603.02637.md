# StitchCUDA: An Automated Multi-Agents End-to-End GPU Programing Framework with Rubric-based Agentic Reinforcement Learning

- arXiv: https://arxiv.org/abs/2603.02637v2
- arXiv ID: 2603.02637

---

🔍 **核心问题**：现有基于LLM的GPU编程方法仅关注单个内核优化，无法处理端到端GPU程序生成，限制了实际部署。

🛠 **方法**：提出StitchCUDA多智能体框架，包含三个专用智能体（Planner、Coder、Verifier），并集成基于评分标准的智能体强化学习，结合真实执行的评分奖励和规则奖励，训练Coder掌握任务到代码生成和反馈驱动优化两种原子技能。

✨ **主要贡献**：在KernelBench上实现近100%的端到端GPU编程成功率，比多智能体基线快1.72倍，比RL模型基线快2.73倍；有效防止奖励黑客行为（如复制PyTorch代码或硬编码输出），代码已开源。

# CLAM: Continuous Latent Action Models for Robot Learning from Unlabeled Demonstrations

- arXiv: https://arxiv.org/abs/2505.04999v2
- arXiv ID: 2505.04999

---

🔍 **核心问题**：在机器人学习场景中，专家演示通常只包含观测序列而无动作标签，传统行为克隆依赖昂贵的遥操作标注数据，本文旨在从无标签演示中学习有效控制策略。

🛠 **方法**：提出连续潜在动作模型（CLAM），通过自监督动力学预测推断连续潜在动作，并利用少量任务无关的play数据联合训练动作解码器，将潜在动作映射为可执行电机指令。

✨ **主要贡献**：在DMControl、MetaWorld及真实WidowX机器人任务中，CLAM相比先前潜在动作基线将平均任务成功率提升2-3倍，性能接近使用特权动作标签的行为克隆，证明无需专家动作标注即可在真实硬件上部署有效策略。

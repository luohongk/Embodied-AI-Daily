# Short-Term-to-Long-Term Memory Transfer for Knowledge Graphs under Partial Observability

- arXiv: https://arxiv.org/abs/2605.22142v3
- arXiv ID: 2605.22142

---

🔍 **核心问题**：在部分可观测环境下，如何让知识图谱的强化学习智能体有效决定短期记忆中的符号观测信息是否应转移至长期记忆，以应对记忆容量限制。

🛠 **方法**：提出一种神经符号价值决策方法，将短期到长期记忆转移建模为逐项Q学习问题，使用共享参数处理可变大小的短期缓冲区，并通过跨时间步的匹配项进行时序差分更新。

✨ **主要贡献**：在RoomKG基准上，学习到的转移策略在长期记忆容量128下优于符号和神经基线（包括带时间标注的符号基线和LSTM/Transformer基线），且轻量级局部短期变体表现最佳，能显式保留导航和查询相关事实，丢弃低价值候选事实，实现可解释的记忆管理。

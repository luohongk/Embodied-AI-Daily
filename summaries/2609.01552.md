# Can LLMs Discover Scientific Laws in Real and Parallel Worlds?

- arXiv: https://arxiv.org/abs/2609.01552v1
- arXiv ID: 2609.01552

---

🔍 **核心问题**：现有评估无法判断LLM能否真正发现科学定律，因为测试多基于合成数据或模型可能已见过的公开公式。

🛠 **方法**：构建SCILAWS-BENCH基准，包含118个来自381篇论文的真实科学问题，每个问题在两种设置下测试——SCILAWS-REAL（从固定观测数据提出定律）和SCILAWS-PARALLEL（主动查询校准世界以恢复合成隐藏定律）。

✨ **主要贡献**：发现预测拟合度与科学有效性可能脱节，记忆效应影响模型是复现还是超越已有公式，并揭示最佳N选择中的瓶颈；提供了基于论文的基准和评估AI科学发现的新视角。

# Beyond Screenshots: Evaluating VLMs' Understanding of UI Animations

- arXiv: https://arxiv.org/abs/2604.26148v2
- arXiv ID: 2604.26148

---

🔍 **核心问题**：现有视觉语言模型（VLM）在UI理解上主要基于静态截图，缺乏对动态UI动画的理解能力，本文旨在评估VLM在UI动画感知、目的识别和意义解读上的表现。

🛠 **方法**：构建了AniMINT数据集，包含300个密集标注的UI动画视频，并系统评估了多个先进VLM在动画效果感知、动画目的识别和动画意义解释上的能力，同时引入Motion、Context和Perceptual Cues（MCPC）因素分析性能瓶颈。

✨ **主要贡献**：发现VLM能可靠检测基础运动，但在高层动画理解上表现不稳定，与人类水平存在显著差距；通过MCPC分析揭示了影响VLM性能的关键因素，为未来UI动画理解研究指明了改进方向。

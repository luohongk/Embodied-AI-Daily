# Multi-AUV Ad-hoc network-based Target Tracking: A Value Gradient Guidance Multi-Agent Diffusion Reinforcement Learning Approach

- arXiv: https://arxiv.org/abs/2608.12436v1
- arXiv ID: 2608.12436

---

🔍 **核心问题**：针对多AUV自组网协同跟踪中，现有MARL方法因高维状态-动作建模和噪声敏感策略导致训练不稳定、跟踪性能下降的问题。

🛠 **方法**：提出VGG-MADiffRL算法，将值梯度引入扩散策略的反向去噪过程以引导动作生成，并设计MDCA三层闭环控制架构（全局智能控制、本地在线训练、物理执行），结合双价值网络联合优化与软目标更新。

✨ **主要贡献**：在动态水下环境中实现更快收敛、更高跟踪精度和更平滑的训练动态，验证了算法的有效性和工程实用性，为多AUV协同跟踪提供了新范式。

# DreamQAS: Learning a Decision-Useful World Model for VQE-Efficient Quantum Architecture Search

- arXiv: https://arxiv.org/abs/2607.29491v1
- arXiv ID: 2607.29491

---

🔍 **核心问题**：传统基于强化学习的量子架构搜索（RL-QAS）在每次扩展电路后都需重复优化变分量子本征求解器（VQE），导致计算成本高昂，尽管电路构建和动作合法性是确定且已知的。

🛠 **方法**：提出DreamQAS，一种基于模型的强化学习框架，保留精确的电路动力学，仅学习昂贵的VQE后反馈。它使用循环随机先验集成预测无Oracle分数，支持多步想象策略学习，并结合排序激活、不确定性感知悲观截断和选择性真实VQE验证。

✨ **主要贡献**：在15,000集预算下，DreamQAS在五个分子任务中的四个上取得最低平均冻结策略能量误差，且达到相同精度时减少1.6至10.6倍的真实VQE调用。反事实动作排序效用平均提升0.346（95%置信区间[0.185, 0.507]），且集成不确定性优于随机拒绝的风险覆盖，证明其价值在于决策有用的反馈而非精确能量预测。

# Pareto-Aware Hierarchical Reinforcement Learning for Online Resource Allocation in RIS-assisted Large-Scale IoT Systems

- arXiv: https://arxiv.org/abs/2608.13032v1
- arXiv ID: 2608.13032

---

🔍 **核心问题**：在RIS辅助的大规模物联网系统中，高维物理层变量和非凸Pareto最优速率集导致实时资源分配面临严峻的计算挑战。

🛠 **方法**：提出一种降维的分层强化学习框架PAAERL，先用低维权向量替代高维RIS波束赋形变量以严格表征Pareto最优前沿，再集成自编码器进行二次数据驱动压缩，将优先级空间映射为紧凑的连续潜在动作空间。

✨ **主要贡献**：在凸与非凸速率区域均理论上避免几何信息损失，显著缩短离线训练时间、加速在线策略收敛并降低网络总成本，在包括多用户移动边缘计算在内的实际场景中优于现有基准方法，展现出卓越的可扩展性和实用价值。

# Scores Are Not Decisions: Cost-Aware Stopping for Tool Acquisition in LLM Agents

- arXiv: https://arxiv.org/abs/2607.27083v1
- arXiv ID: 2607.27083

---

🔍 **核心问题**：LLM代理在调用外部工具时，面临在异构成本下如何决定“获取多少工具”的决策问题——获取太少会导致信息不足，获取太多则增加成本、上下文负担和隐私风险。

🛠 **方法**：提出成本感知的边际决策停止方法（CAM-DF）及其轻量可解释变体CAM-DF-lite，通过直接训练“当前停止”与“最优继续”之间的离线差距，以符号标记决策方向、以差距大小加权错误代价，实现成本感知的停止决策。

✨ **主要贡献**：证明该目标与停止目标贝叶斯对齐，且仅依赖分数的规则在异构成本下非最优；在五个工具使用领域的1343个任务上，CAM-DF在τ-bench零售场景中取得最高收益，且在所有排名源和两种成本设置下均优于预测-阈值基线；在实时执行中，相比完全访问，CAM-DF减少37%的工具暴露，同时保持任务成功率。

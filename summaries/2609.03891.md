# A hybrid pipeline for dynamic ontology-based semantic mapping

- arXiv: https://arxiv.org/abs/2609.03891v1
- arXiv ID: 2609.03891

---

🔍 **核心问题**：解决机器人在复杂动态环境中构建语义地图时，缺乏上下文理解和实时更新能力的问题。

🛠 **方法**：提出一种混合语义映射流水线，结合外部标定相机的单应性投影进行几何建图与定位，融合目标检测、持续目标跟踪及本体驱动的语义更新，并利用线性回归校正真实世界坐标。

✨ **主要贡献**：构建了动态语义世界模型，能实时更新对象实例、空间属性和语义关系；采用本体作为知识表示，利用其层次结构和语义表达能力增强环境理解，提升语义映射的准确性与适应性。

# PRIME: Perception Feedback with Situational Memory Embeddings in VLA Models

- arXiv: https://arxiv.org/abs/2609.22040v1
- arXiv ID: 2609.22040

---

🔍 **核心问题**：现有自动驾驶VLA模型中，早期感知模块无法感知下游推理与导航目标，只能被动处理视觉输入，缺乏由意图驱动的注意力机制。

🛠 **方法**：提出PRIME，通过交叉注意力聚合过去L步窗口内的感知、推理、导航目标与预测行为的潜在表示，构建“情境记忆”，以此对VLA感知查询进行反馈调节，仅增加最多29.7M参数（占7.3B基础模型的0.41%）。

✨ **主要贡献**：在Bench2Drive闭环基准上取得最优驾驶得分82.47（较ORION提升4.73）和60.00%成功率（提升5.38个百分点），是Think2Drive演示训练下已发表VLA中的最高驾驶得分。

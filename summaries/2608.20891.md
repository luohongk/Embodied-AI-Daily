# IMU-Free Body-Frame State Estimation with Sparse Scene Flow for Quadcopters

- arXiv: https://arxiv.org/abs/2608.20891v1
- arXiv ID: 2608.20891

---

🔍 **核心问题**：针对无IMU的四旋翼无人机，如何在无GPS和惯性传感器的情况下，仅凭视觉和电机推力命令实现机体坐标系下的状态估计。

🛠 **方法**：采用连续-离散扩展卡尔曼滤波器（EKF）在复合流形状态空间上估计位姿、速度、角速度、重力和扰动，利用静止场景点作为惯性参考；结合FAST/Shi-Tomasi特征检测、Lucas-Kanade跟踪和NCC立体匹配，通过卡方门控筛选静止点，并利用4视图光束平差生成稀疏场景流和点云。

✨ **主要贡献**：提出了一种完全无IMU的视觉状态估计系统，在机体坐标系下运行，输出位姿变化和稀疏场景流，可作为下游世界模型的测量源，且架构支持未来集成GPS/IMU，点云密度可依据关注点自适应调整。

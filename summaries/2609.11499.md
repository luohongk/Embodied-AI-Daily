# Recursive Code World Models: Building Complex Worlds through Recursive Scene Programs

- arXiv: https://arxiv.org/abs/2609.11499v1
- arXiv ID: 2609.11499

---

🔍 **核心问题**：如何从单张参考图像出发，用可执行代码重建具有复杂细粒度结构的三维世界，而仅靠代码世界模型的表示本身无法确定构建方式。

🛠 **方法**：提出递归代码世界模型（RCWM），将递归场景程序（RSP）表示与递归调用自身的构建求解器结合，每次调用遵循“整体—递归重建未解部分—回归整体精修”的全局-局部-全局流程，并借助视觉-语言编码智能体对比参考图与渲染图来指导精修与递归。

✨ **主要贡献**：提出递归构建原则，在复杂场景重建上超越现有基于代码的图像到场景方法，消融实验验证了递归构建的有效性，并表明更深层递归可提升细尺度重建质量。

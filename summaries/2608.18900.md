# \textsc{TestifAI}: Tomography-Based Testing for Deep Learning Systems

- arXiv: https://arxiv.org/abs/2608.18900v1
- arXiv ID: 2608.18900

---

🔍 **核心问题**：深度学习模型在安全关键场景中需进行鲁棒性测试，但现有框架无法高效、系统地探索多种输入扰动组合（如模糊、亮度、缩放）下的模型行为，且组合测试数量呈指数增长。

🛠 **方法**：提出TestifAI框架，引入“部分模型断层扫描”技术，仅通过低阶（1-2种）扰动组合的测试结果，训练辅助模型来预测高阶（3-4种）扰动组合的鲁棒性，避免执行指数级数量的测试。

✨ **主要贡献**：在5个图像和语言分类任务上，TestifAI能以低于7%的聚合鲁棒性估计误差预测高阶扰动结果，同时减少60-80%的推理次数，显著提升测试效率与准确性。

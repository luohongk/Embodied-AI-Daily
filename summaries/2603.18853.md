# Learn for Variation: Efficient AAV Trajectory Learning through a Differentiable Wireless World Model

- arXiv: https://arxiv.org/abs/2603.18853v3
- arXiv ID: 2603.18853

---

🔍 **核心问题**：针对第六代物联网中自主飞行器（AAV）数据采集任务，解决轨迹规划中非线性无线速率与长时程服务进度耦合导致的优化难题。

🛠 **方法**：提出L4V框架，将AAV运动学、信道状态和用户队列演化建模为可微分的世界模型，用累积队列替代不连续完成时间目标，通过离散伴随递归反向传播路径灵敏度，并采用重参数化阴影和莱斯衰落学习共享OFDMA分配。

✨ **主要贡献**：证明结构化伴随随水平线至多多项式增长，并建立全梯度下降的驻点收敛率；分布预训练实现对新布局的前向部署。相比遗传算法、DQN、A2C、DDPG和可微分MPC，任务时间减少高达65%，默认任务仅需53毫秒，预训练后60项冻结策略测试全部通过。

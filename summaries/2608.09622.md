# Adaptive Sequential Test Planning for Multi-Mechanism Reliability Qualification via Bayesian Monte Carlo Tree Search

- arXiv: https://arxiv.org/abs/2608.09622v1
- arXiv ID: 2608.09622

---

🔍 **核心问题**：先进半导体器件可靠性鉴定中，传统静态测试计划无法适应器件个体差异和实时退化观测，难以在多竞争失效机制下平衡表征目标与失效约束。

🛠 **方法**：将可靠性鉴定建模为部分可观测的序贯决策问题，采用蒙特卡洛树搜索（MCTS-SA）结合扩展卡尔曼滤波（EKF）信念状态估计，实现闭环自适应测试规划，并针对BTI、EM和TDDB三种失效机制建模随机个体差异。

✨ **主要贡献**：首次将树搜索自适应测试规划应用于多机制可靠性鉴定，在5000次规划迭代中将表征良率从20%提升至54%以上，累计成功率39%，且最优测试序列的EM和TDDB损伤分数均远低于安全阈值，显著优于非自适应策略。

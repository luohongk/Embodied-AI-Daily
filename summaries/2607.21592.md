# Unified Video Dense Prediction from Disjoint Data

- arXiv: https://arxiv.org/abs/2607.21592v1
- arXiv ID: 2607.21592

---

🔍 **核心问题**：现有视频场景理解任务（如深度、语义分割等）依赖碎片化且领域不兼容的数据集，缺乏统一模型能同时从分散数据中学习多种密集预测属性。

🛠 **方法**：提出UniD模型，利用预训练扩散模型的强视觉先验，通过轻量级任务投影器让各任务专家监督统一骨干网络，无需标注重叠或伪标签，直接从分散数据联合学习八种场景属性。

✨ **主要贡献**：首次实现从不相交数据中联合预测深度、法线、语义等八种密集属性，性能媲美单任务专家，且具备跨任务一致性与强分布外泛化能力。

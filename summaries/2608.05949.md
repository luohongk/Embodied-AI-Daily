# VLMs for Videogame Data Annotation

- arXiv: https://arxiv.org/abs/2608.05949v1
- arXiv ID: 2608.05949

---

🔍 **核心问题**：探索视觉语言模型（VLM）在视频游戏帧序列中标注奖励信号的有效性，解决合成场景多变且不符合真实物理规律带来的标注困难。

🛠 **方法**：使用VLM对赛车类（及其他类型）视频游戏帧序列进行问答式标注，并测试输入序列长度、分辨率、问题批处理等参数的影响，同时采用输出混合和提示优化等策略提升标注质量。

✨ **主要贡献**：发现VLM在回答视频游戏基础问题时表现不佳（跨游戏类型普遍存在），但通过参数调整和提示优化可改善标注质量；量化了序列长度、分辨率与批处理对标注效果及token消耗的权衡关系。

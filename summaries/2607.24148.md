# A Motion-Aware Vector Quantization Framework with Centroid Reuse for Efficient VLA Inference

- arXiv: https://arxiv.org/abs/2607.24148v1
- arXiv ID: 2607.24148

---

🔍 **核心问题**：VLA模型在GPU上推理延迟高，难以满足实时部署需求，现有加速器未充分利用权重相似性和执行动态性带来的冗余。

🛠 **方法**：提出VQVLA算法-硬件协同设计框架，包含MotionVQ运动感知向量量化方案（根据机器人执行状态动态调整精度）和合并质心向量化GEMM范式（通过空间聚合与时间复用消除冗余乘法）。

✨ **主要贡献**：相比A100 GPU、Dadu-Corki等方案实现1.9x-6.5x加速，且精度损失可忽略，首次将运动感知量化与质心复用结合用于VLA推理加速。

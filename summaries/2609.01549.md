# NashDreamer: Model-Based Reinforcement Learning for Zero-Sum Imperfect-Information Games

- arXiv: https://arxiv.org/abs/2609.01549v1
- arXiv ID: 2609.01549

---

🔍 **核心问题**：将基于模型的强化学习（MBRL）扩展到双人零和、信息不完美博弈（IIGs）中，解决多智能体环境下对手引起的非平稳性和模型学习的可辨识性难题。

🛠 **方法**：提出NashDreamer框架，采用集中式多智能体循环状态空间模型（MARSSM），将环境动态与玩家策略对个体观测的影响解耦，并兼容任意策略梯度算法。

✨ **主要贡献**：理论上论证了集中式模型学习的数学必要性，实验表明NashDreamer在四个基准博弈中显著提升样本效率，并首次揭示Dreamer类算法在随机环境中存在后验崩溃的优化脆弱性。

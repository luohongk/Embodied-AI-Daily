# Texture Image Classification Using DWT AlexNet Feature Fusion and Deep Neural Networks

- arXiv: https://arxiv.org/abs/2608.28524v1
- arXiv ID: 2608.28524

---

🔍 **核心问题**：纹理图像分类中，手工特征难以表达复杂视觉模式，而深度模型未能充分利用纹理图像固有的多尺度空间-频率信息。

🛠 **方法**：提出混合特征融合框架DWT_AlexNet_DNN，将离散小波变换（DWT）提取的多尺度特征与AlexNet深度特征相结合，并输入深度神经网络进行分类。

✨ **主要贡献**：通过融合DWT与AlexNet特征，兼顾了局部纹理细节与高层语义表示，提升了纹理分类的准确性与鲁棒性，验证了混合特征融合在纹理识别任务中的有效性。

# Visual Relocalization from Sparse Views in Aliased and Low-Texture Environments via Novel View Synthesis

- arXiv: https://arxiv.org/abs/2607.22147v1
- arXiv ID: 2607.22147

---

🔍 **核心问题**：在低纹理、视觉混淆、光照恶劣且视角稀疏的行星类似环境中，传统视觉定位方法性能严重下降，难以实现鲁棒的单图像6自由度位姿估计。

🛠 **方法**：提出一种基于3D高斯泼溅（3DGS）的可微地图表示方法，直接估计相机位姿；并采用结合光度损失与几何损失的几何感知训练策略，其中几何监督首次通过多视图立体（MVS）与LiDAR深度联合提供。

✨ **主要贡献**：联合优化使3DGS模型更好地拟合场景几何，提升光度与几何一致性，在行星模拟环境数据上验证了该方法在挑战性条件下定位精度的显著提升。

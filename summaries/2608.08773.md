# PEEL: Parallel Extraction for Long-Horizon Disassembly Planning via Scale-Invariant Sampling

- arXiv: https://arxiv.org/abs/2608.08773v1
- arXiv ID: 2608.08773

---

🔍 **核心问题**：解决长时程多部件物体拆解中，机器人在狭窄、紧凑的逃逸通道下计算无碰撞移除序列的难题。

🛠 **方法**：提出PEEL算法，采用尺度不变采样方案（先通过预热阶段估计物体尺度，再利用方向性采样器），并集成到多臂老虎机快速探索随机树（MAB-RRT）规划器中，通过奖励信号动态切换采样器，并行运行多个规划器以生成有序拆解图。

✨ **主要贡献**：MAB-RRT在76个装配体上实现100%的单部件拆解成功率，且对参数鲁棒；PEEL成功解决4个包含10至17个部件的长时程拆解任务，并在Fetch机械臂上完成实际执行验证。

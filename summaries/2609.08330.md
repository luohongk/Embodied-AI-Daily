# EMBLEM: Enhancing Multi-script Table Detection through Masking

- arXiv: https://arxiv.org/abs/2609.08330v1
- arXiv ID: 2609.08330

---

🔍 **核心问题**：现有表格检测模型在英文和中文文档上表现良好，但在多语言、多脚本文档上因脚本多样性和标注数据稀缺而性能不佳。

🛠 **方法**：提出EMBLEM范式，通过生成掩盖脚本和字体细节的掩码图像，使预训练于英文文档的模型聚焦于与脚本无关的页面布局；同时构建了包含18种语言、15种脚本的MANDALA数据集。

✨ **主要贡献**：EMBLEM在MANDALA上仅用英文掩码图像微调即取得20.8%的绝对F1提升，且优于强基线，在五个英文基准上保持竞争力；发布了MANDALA数据集及代码模型。

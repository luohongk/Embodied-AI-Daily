# GST-Bench: Can VLMs Develop Global Spatial Awareness from Video?

- arXiv: https://arxiv.org/abs/2608.05747v1
- arXiv ID: 2608.05747

---

🔍 **核心问题**：现有视觉语言模型（VLMs）在视频理解中缺乏全局空间感知能力，无法从连续长时程视觉流中推断新视角或构建全局场景表示。

🛠 **方法**：提出GST-Bench基准，基于6,790分钟合成视频构建VQA任务，要求模型从未见过的视角进行空间推理，并将第一人称观察映射到全局俯视图；同时构建GST-Bench-Local用于诊断局部与全局能力差异，并提供GST-Train训练数据集。

✨ **主要贡献**：评估22个SOTA VLMs，最强零样本模型仅得42.68分，远低于人类79.08分，揭示模型虽具备局部空间理解但无法整合长时程观测为全局一致表示，为未来全局空间推理研究提供基准与数据资源。

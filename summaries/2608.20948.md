# Neural-Primitive: An Efficient End-to-end Local Planner with Primitive-based Imitation Learning for Autonomous Flight

- arXiv: https://arxiv.org/abs/2608.20948v1
- arXiv ID: 2608.20948

---

🔍 **核心问题**：在未知杂乱环境中，无人机自主飞行面临机载轨迹生成的计算-质量-内存三难问题。

🛠 **方法**：提出一种基于模仿学习的端到端局部规划器，通过离线基元数据集收集框架生成安全轨迹基元，并用轻量神经网络将传感器输入直接映射为多项式系数，无需后端求解。

✨ **主要贡献**：实现超快计算（桌面端<1ms，机载平均3.68ms）和低内存占用（<1.5MiB），在仿真中优于现有方法，并通过零样本部署验证了鲁棒的仿真到现实迁移能力。

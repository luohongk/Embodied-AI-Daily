# SatEdit: Mask-Conditioned Image Editing via VLM-Guided Segment Annotation

- arXiv: https://arxiv.org/abs/2607.29367v1
- arXiv ID: 2607.29367

---

🔍 **核心问题**：卫星图像编辑需要精确的物体级空间控制，但缺乏带掩码、语义标签和配对编辑的大规模监督数据集，导致训练成本高昂。

🛠 **方法**：提出SatEdit框架，利用分割基础模型生成物体掩码，通过视觉语言模型（VLM）为采样片段分配语义标签，经轻量人工验证后，用掩码引导的修复生成配对增删样本，并基于LoRA微调高分辨率编辑骨干网络。

✨ **主要贡献**：在SODA-A数据集上构建了含1,014张图像、852个验证标注（覆盖91类）的训练集；与开源及专有编辑模型相比，SatEdit在掩码区域语义对齐上取得最高CLIP分数（0.6322）和CLIP增量（0.0726），同时保持场景完整性，验证了VLM辅助标注是数据高效、空间可控卫星图像编辑的实用路径。

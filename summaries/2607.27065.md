# ScratchSim: A Procedural Synthetic Data Pipeline for Surface Scratch Detection

- arXiv: https://arxiv.org/abs/2607.27065v1
- arXiv ID: 2607.27065

---

🔍 **核心问题**：工业质检中表面划痕检测面临标注数据稀缺的挑战，导致自动化缺陷检测困难。

🛠 **方法**：提出基于BlenderProc的程序化渲染管线ScratchSim，通过可配置材质、相机模式和域随机化生成大规模合成数据，并自动输出COCO格式标注；结合三种轻量级检测器（YOLOX、YOLO26、LW-DETR）评估四种训练策略。

✨ **主要贡献**：证明从合成权重微调始终优于纯真实数据训练，混合训练在真实数据稀缺时有效恢复性能；方法无需大量真实标注数据即可实现可扩展的缺陷检测，适用于边缘设备工业检测。

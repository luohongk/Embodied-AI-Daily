# One Policy, Many Embodiments: Unified Camera-Centric Action Geometry Pre-training for Heterogeneous Embodied Manipulation

- arXiv: https://arxiv.org/abs/2608.26058v1
- arXiv ID: 2608.26058

---

🔍 **核心问题**：解决异构具身数据（不同机器人形态、相机配置和动作空间）难以联合训练统一视觉-语言-动作（VLA）策略的瓶颈问题。

🛠 **方法**：提出UCAG-P，一种以相机为中心的统一定义动作几何预训练方法。它将异构数据对齐到共享的几何动作空间（图像和相机坐标系中的锚点运动），并通过几何条件动作翻译器结合目标形态运动学生成可执行控制，实现共享策略与形态特定控制的解耦。

✨ **主要贡献**：首次实现单一检查点在多个异构基准（LIBERO、RoboTwin、RoboCasa等）上无需微调即达到高成功率（如LIBERO 98.3%、RoboTwin Easy 88.7%），并支持零样本泛化，验证了跨形态学习可迁移操作几何的可行性。

# Pangram 4 Technical Report

- arXiv: https://arxiv.org/abs/2607.27183v1
- arXiv ID: 2607.27183

---

🔍 **核心问题**：提升AI生成文本检测的准确性与鲁棒性，并解决细粒度编辑、人机混合文本的识别难题。  
🛠 **方法**：基于深度学习构建AI文本分类模型Pangram 4，通过优化训练策略增强分布外泛化与对抗攻击防御能力。  
✨ **主要贡献**：AUROC达0.9916，假阳性率仅0.0041%，假阴性率0.3396%；在边界检测、混合文本识别任务上显著优于前代，并在多个标准基准上达到最先进性能。

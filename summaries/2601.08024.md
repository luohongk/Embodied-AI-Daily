# A Highly Efficient Diversity-based Input Selection for DNN Improvement Using VLMs

- arXiv: https://arxiv.org/abs/2601.08024v2
- arXiv ID: 2601.08024

---

🔍 **核心问题**：深度神经网络微调需要标注新收集的数据，成本高且耗时，现有基于多样性的输入选择方法计算开销大、难以扩展到大规模数据集。

🛠 **方法**：提出基于概念多样性（CBD）的输入选择指标，利用视觉语言模型（VLMs）高效计算图像多样性，并设计结合CBD与Margin不确定性的混合选择策略。

✨ **主要贡献**：CBD与几何多样性（GD）高度相关但计算时间大幅降低；基于CBD的选择方法在多个DNN模型、数据集和预算下优于六种现有基线，且效率接近简单不确定性方法，具备良好的可扩展性。

# CoNav-UAV: Cooperative Dual-Altitude Aerial Navigation via Stackelberg Learning

- arXiv: https://arxiv.org/abs/2608.01802v1
- arXiv ID: 2608.01802

---

🔍 **核心问题**：针对空中平台的目标导向视觉语言导航（VLN）任务，现有方法难以在同一智能体中兼顾全局探索与近距离无碰撞接近，且双无人机系统依赖特权信息且缺乏协同适应。

🛠 **方法**：提出CoNav-UAV，将任务建模为高空领导者与低空跟随者之间的Stackelberg博弈，仅依赖机载视觉和语言输入；通过迭代Stackelberg学习，领导者利用基于记忆的上下文学习优化视觉语言推理，跟随者通过DAgger式专家蒸馏更新运动控制，交替训练直至达到Stackelberg均衡。

✨ **主要贡献**：在AerialVLN基准的三个高保真城市场景中，CoNav-UAV一致优于单/双智能体基线，学习场景成功率提升最高30.8点，跨场景迁移提升9.0点，且适应数据减少约3倍；进一步分析验证了领导者与跟随者更新的互补增益，并揭示了不同VLM骨干下的稳健性能与差异化的学习动态。

# Deformable 2D Gaussian Splatting for Efficient 4K Video Compression

- arXiv: https://arxiv.org/abs/2609.14129v1
- arXiv ID: 2609.14129

---

🔍 **核心问题**：超高清（UHD）视频的高效存储与实时解码面临挑战，现有神经视频压缩和隐式神经表示方法虽性能优异，但解码延迟高、内存占用大。

🛠 **方法**：提出一种实时视频压缩框架，使用粗到细的多尺度2D高斯泼溅（2DGS）结构表示并压缩图像组（GOP），并耦合一个轻量级形变网络。

✨ **主要贡献**：在LPIPS率失真性能上超越H.265及其他先进学习方法，首次展示了高斯泼溅作为高效高分辨率视频压缩实用方案的潜力。

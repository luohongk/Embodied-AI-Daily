# CoRe-GS: Coarse-to-Refined Gaussian Splatting with Semantic Object Focus

- arXiv: https://arxiv.org/abs/2509.04859v4
- arXiv ID: 2509.04859

---

🔍 **核心问题**：现有语义高斯泼溅（GS）方法在三维重建中均匀优化整个场景，忽视了机器人实时感知中对特定兴趣点（POI）快速、高质量重建的需求，且常因浮点伪影和不完整重建影响对象提取效果。

🛠 **方法**：提出CoRe-GS，一种由粗到细的任务驱动方法。先通过轻量级后期语义精炼构建可分割的GS表示，再仅选择性优化与POI相关的视图和高斯点，并利用基于颜色的过滤策略抑制分割引起的浮点伪影。

✨ **主要贡献**：在LERF-Mask上以6-8倍更少的优化步骤达到竞争性mIoU；在NeRDS 360和SCRREAM上，相比全场景语义GS，POI获取时间减少91-95%，同时提升重建质量并减少浮点；在所有基准上比后优化对象提取快44-76%，验证了任务感知精炼对实时机器人感知的高效性。

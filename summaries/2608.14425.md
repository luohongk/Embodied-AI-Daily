# Knowing When to Stop: Bayesian Optimal Stopping for LLM Evaluations

- arXiv: https://arxiv.org/abs/2608.14425v1
- arXiv ID: 2608.14425

---

🔍 **核心问题**：LLM评估通常使用固定采样预算，对所有测试项重复相同次数，即使某些估计已足够精确，导致计算资源浪费。

🛠 **方法**：提出optstop框架，将评估视为序贯测量问题，基于分层贝叶斯推断，支持二值、有序和连续结果，根据不确定性动态决定继续采样或停止，并包含针对低性能场景的保守采样保护机制。

✨ **主要贡献**：在200项、10轮评估中，optstop在9种验证设置下减少了57%-97%的计划试验，同时保持与完整运行等效的结论，证明评估计算可按不确定性分配而非固定重复次数，节省幅度取决于评估设计。

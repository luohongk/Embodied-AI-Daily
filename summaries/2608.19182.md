# ADEPT: Accelerating Dexterity via Pre-Training and Post-Training using Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.19182v1
- arXiv ID: 2608.19182

---

🔍 **核心问题**：解决高自由度多指机器人从原始视觉-触觉感知中学习长时程灵巧操作任务时，从零训练困难且难以跨任务复用技能的问题。

🛠 **方法**：提出ADEPT框架，先通过大规模强化学习在通用物体重定位任务上预训练灵巧策略，再将其作为先验用于下游任务的后续训练；结合行为克隆蒸馏、评论家预热和保守策略更新实现稳定迁移，并引入关节空间几何织构（Geometric Fabric）安全协调策略与机器人。

✨ **主要贡献**：预训练策略可零样本完成下游任务的重定位阶段，且后续训练避免重复学习基础技能；在23自由度Kuka-Allegro和29自由度Flexiv-Sharpa两个平台上实现从仿真到真实的零样本迁移，能解决挑战性初始状态下的长时程任务，速度达到人类水平。

# GigaBrain-WBC-0.5: A Behavior World Model for Robust Whole-Body Control with Environment Interaction

- arXiv: https://arxiv.org/abs/2608.18234v1
- arXiv ID: 2608.18234

---

🔍 **核心问题**：现有的人形机器人全身运动跟踪策略仅在平坦地面上有效，无法应对复杂地形和物体交互，且面对不合理指令时缺乏鲁棒性。

🛠 **方法**：提出GigaBrain-WBC-0.5，一种行为世界模型（BWM），使用因果Transformer联合预测下一动作、下一状态和潜在行为命令分布，并通过自动地形标注管线恢复3D接触几何，部署时利用预测分布在线检测并纠正不合理命令。

✨ **主要贡献**：首次将行为世界模型用于人形机器人全身控制，在四类测试场景中均取得最高成功率（地形交互81.3%、不合理指令83.1%、跌倒恢复99.3%），且模型可从Unitree G1迁移至Maker L01机器人。

# PolygMap: A Perceptive Locomotion Framework for Humanoid Robot Stair Climbing

- arXiv: https://arxiv.org/abs/2510.12346v2
- arXiv ID: 2510.12346

---

🔍 **核心问题**：解决人形机器人在未知环境中精准攀爬楼梯的感知与运动规划问题，弥补现有双足机器人仅适用于平坦地面行走的局限。

🛠 **方法**：提出PolyMap框架，通过多传感器融合（LiDAR、RGB-D相机和IMU）实时构建多边形楼梯平面语义地图，并基于这些平面段进行落脚点规划，在NVIDIA Orin上实现20-30Hz的全身运动规划输出。

✨ **主要贡献**：首次将多边形平面语义地图与落脚点规划结合，实现人形机器人对楼梯的实时感知与稳健攀爬，室内外真实场景实验验证了该方法的高效性和鲁棒性。

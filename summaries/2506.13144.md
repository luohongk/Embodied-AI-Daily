# EnhanceGraph: A Continuously Enhanced Graph-based Index for High-dimensional Approximate Nearest Neighbor Search

- arXiv: https://arxiv.org/abs/2506.13144v3
- arXiv ID: 2506.13144

---

🔍 **核心问题**：现有基于图的近似最近邻搜索索引是静态的，导致索引生命周期中产生的大量搜索日志和构建日志未被充分利用，限制了搜索精度的进一步提升。

🛠 **方法**：提出EnhanceGraph框架，将搜索日志和构建日志整合为一种新颖的“共轭图”（conjugate graph）结构——搜索日志用于存储从局部最优到全局最优的边以增强路由，构建日志用于存储从近邻图中剪枝掉的边以增强k近邻检索。

✨ **主要贡献**：在多个公开及真实工业数据集上显著提升搜索精度（召回率最高从41.74%提升至93.42%）且不牺牲搜索效率，算法已集成到蚂蚁集团开源向量库VSAG中。

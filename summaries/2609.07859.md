# M3-Tele: A Unified Multimodal Teleoperational Framework for Compliant Whole-Body Mobile Manipulation

- arXiv: https://arxiv.org/abs/2609.07859v1
- arXiv ID: 2609.07859

---

🔍 **核心问题**：现有遥操作框架未充分结合多模态感知与全身协调控制，导致接触丰富任务中的演示采集效率和质量不足，影响下游策略学习。

🛠 **方法**：提出统一的M3-Tele框架，整合视觉、触觉、力觉和本体感觉，并设计全身柔顺控制器以支持稳定的物理交互。

✨ **主要贡献**：显著提升接触丰富遥操作性能，力跟踪误差从4.132N降至0.346N，接触丢失事件从每次2.46次降至0.02次，触觉变形误差降低65%；用户研究验证了系统可靠性，Diffusion Policy实验证明联合触觉与力觉感知的价值。

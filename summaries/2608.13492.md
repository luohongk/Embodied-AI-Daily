# AlayaWorld: Interactive Long-Horizon World Modeling - Full Technical Report (v1.1)

- arXiv: https://arxiv.org/abs/2608.13492v1
- arXiv ID: 2608.13492

---

🔍 **核心问题**：提升长时程交互式世界模型的性能，特别是解决条件信号与生成内容在潜在表示和时间结构上不一致的问题。

🛠 **方法**：采用流式3D点缓存渲染器替代深度扭曲空间记忆，并将视觉条件统一编码到因果VAE潜在空间，同时引入运动感知潜在条件、硬记忆丢弃等六项改进。

✨ **主要贡献**：通过重新设计条件表示与集成方式，使条件信号与生成内容在潜在表示和时间结构上高度对齐，显著增强了模型在长时程交互场景中的一致性和可控性。

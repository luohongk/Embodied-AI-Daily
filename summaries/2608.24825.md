# A Dual-Dimensional LLM Framework for Automated Item Incidental Content Similarity Analysis in Large-Scale Assessments

- arXiv: https://arxiv.org/abs/2608.24825v1
- arXiv ID: 2608.24825

---

🔍 **核心问题**：大规模测评中自动生成题目导致“无关内容冗余”（如措辞或情境框架重复），传统相似度指标（如BLEU、余弦相似度）难以同时捕捉结构和语义层面的冗余。

🛠 **方法**：提出基于大语言模型（LLM）的双维度自动化题目相似性分析框架（AISA），通过结构化分解和语义相关性两个维度量化题目相似性，并在计算机化自适应测试（CAT）中引入该相似度作为选题约束。

✨ **主要贡献**：心理测量验证表明LLM指标比传统文本指标更贴近“无关局部依赖”且题目参数分组更一致；CAT模拟显示其能提升估计稳定性、降低偏差且效率损失小，优于传统指标，支持题库管理、内容感知组卷和体验敏感的自适应测试。

# Chain-of-Visual-Thought: Teaching VLMs to See and Think Better with Continuous Visual Tokens

- arXiv: https://arxiv.org/abs/2511.19418v3
- arXiv ID: 2511.19418

---

🔍 **核心问题**：现有视觉语言模型（VLMs）在语言推理上表现优异，但缺乏对密集视觉信息（如空间关系、几何结构）的感知能力，导致在需要精细视觉理解的场景中性能受限。

🛠 **方法**：提出Chain-of-Visual-Thought（COVT）框架，通过约20个连续视觉token（紧凑的潜在表示）编码2D外观、3D几何、空间布局和边缘结构等互补感知信息。训练时，VLM自回归预测这些视觉token以重建密集监督信号（如深度、分割、边缘、DINO特征）；推理时直接在连续视觉token空间中进行思考，并可选择解码为可解释的密集预测。

✨ **主要贡献**：在超过10个多样化感知基准（如CV-Bench、MMVP、RealWorldQA等）上，将COVT集成到Qwen2.5-VL和LLaVA等强VLM中，性能稳定提升3%–16%，证明紧凑的连续视觉思维能显著增强多模态模型的精确性、接地性和可解释性。

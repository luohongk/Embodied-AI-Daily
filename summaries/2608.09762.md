# Efficient Real-World Online Reinforcement Learning for Robot Manipulation via Centralized Training and Critic Decomposition

- arXiv: https://arxiv.org/abs/2608.09762v1
- arXiv ID: 2608.09762

---

🔍 **核心问题**：现有真实世界在线强化学习方法在机器人操作任务中受限于较小的随机化范围，且多智能体并行训练时面临非平稳性问题，导致样本效率低、策略性能有限。

🛠 **方法**：提出统一框架，结合集中训练与分散执行（CTDE）和混合奖励架构（HRA），让多个actor共享一个集中式多头critic，并将critic分解为任务头与抓取头，分别对应稀疏任务奖励和基于势能的抓取奖励，同时重新设计critic与actor目标以利用分解的Q值并处理离散抓取策略的类别分布。

✨ **主要贡献**：在多种真实与仿真任务（如网球/香蕉抓取放置、锅复位、积木重排）中，将随机化范围扩大至先前工作的5-25倍，显著提升样本效率与成功率（如网球任务从60%提至80%，香蕉任务从60%提至90%，积木重排从25%提至95%），并成功完成基线方法无法解决的任务。

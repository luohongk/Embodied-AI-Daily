# Payload Swing Estimation and Damping Without Payload Parameters for Multirotor UAVs

- arXiv: https://arxiv.org/abs/2608.18625v1
- arXiv ID: 2608.18625

---

🔍 **核心问题**：多旋翼无人机吊挂载荷运输时会产生周期性摆动扰动，影响飞行跟踪精度并带来失稳风险，而现有防摆方法依赖额外传感器或需精确已知缆绳长度与载荷质量，限制了实际部署。

🛠 **方法**：仅利用机载IMU和油门指令，通过扩展卡尔曼滤波器将未知摆频作为状态估计周期性扰动，并设计主动阻尼控制器，在姿态环中加入修正角以耗散摆动能。

✨ **主要贡献**：无需任何载荷参数即可实现摆动估计与抑制，飞行实验验证了在缆绳长度和质量变化范围内均具有鲁棒阻尼效果，显著提升了现场适用性。

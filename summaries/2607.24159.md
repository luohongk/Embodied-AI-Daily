# DeVA: Decoupled Video-Action Model with physical guidance for robot policy learning

- arXiv: https://arxiv.org/abs/2607.24159v1
- arXiv ID: 2607.24159

---

🔍 **核心问题**：现有视觉-语言-动作模型主要依赖静态预训练，缺乏对物理动态和时间因果关系的监督，导致机器人策略学习效率低、泛化能力不足。

🛠 **方法**：提出DeVA模型，采用解耦的视频与动作专家架构，通过多层级特征传递实现信息交换，并引入物理显著性引导（如可操作性与深度信息）来监督中间视频特征和动作流。

✨ **主要贡献**：在有限数据下实现强性能，比统一架构收敛更快，且物理引导显著提升策略学习效果，在仿真和真实场景中均验证有效性。

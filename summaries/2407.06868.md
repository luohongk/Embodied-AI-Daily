# DRL-AdaPart: DRL-Driven Adaptive STAR-RIS Partitioning for Fair and Efficient Resource Utilization

- arXiv: https://arxiv.org/abs/2407.06868v3
- arXiv ID: 2407.06868

---

🔍 **核心问题**：如何在STAR-RIS辅助通信系统中实现公平且高速的数据传输，同时高效利用STAR-RIS元件资源，避免不必要的元件激活。

🛠 **方法**：引入子表面分配变量决定每个用户分配的STAR-RIS元件数量，联合优化STAR-RIS相移与子表面分配变量，采用定制化深度强化学习（DRL）算法，并加入惩罚项以智能停用不需要的STAR-RIS元件。

✨ **主要贡献**：提出DRL驱动的自适应STAR-RIS分区方法，在静态和移动场景下均能实现公平高速的数据速率，且分别最多可停用27%和21%的STAR-RIS元件而不影响性能，显著提升资源利用效率。

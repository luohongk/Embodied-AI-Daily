# An Initial Introduction to Cooperative Multi-Agent Reinforcement Learning

- arXiv: https://arxiv.org/abs/2405.06161v6
- arXiv ID: 2405.06161

---

🔍 **核心问题**：如何在多个智能体共享同一联合奖励的合作场景下，进行有效的多智能体强化学习，并厘清集中式与去中心化训练/执行三类范式的区别与联系。

🛠 **方法**：按集中式训练与执行（CTE）、集中式训练去中心化执行（CTDE）、去中心化训练与执行（DTE）三类框架，系统介绍独立Q学习、策略梯度、值函数分解（VDN、QMIX、QPLEX）及集中式评论家（MADDPG、COMA、MAPPO）等方法。

✨ **主要贡献**：作为合作式MARL的入门性综述，清晰梳理了核心概念、代表性方法及其相互关系，澄清常见误解，并指出开放问题，为理解该领域提供简明指南。

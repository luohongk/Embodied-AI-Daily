# Hybrid Feedback Sampling for Sample-Efficient Model Predictive Control

- arXiv: https://arxiv.org/abs/2608.19443v1
- arXiv ID: 2608.19443

---

🔍 **核心问题**：采样型模型预测控制（MPC）在高维且开环不稳定的动态系统中，样本需求随预测时域指数增长，导致采样效率低下和数值不稳定。

🛠 **方法**：提出反馈采样MPC（FS-MPC），通过混合采样设计结合局部与全局搜索，利用优化后的反馈策略实现最优采样分布，并基于系统稳定性和计算预算动态平衡搜索范围。

✨ **主要贡献**：理论上证明FS-MPC比标准MPPI收敛更快、比纯反馈采样更优；在类人机器人操作和灵巧操作等接触丰富任务中，成功处理动态不稳定场景，并在真实机器人上验证了有效性。

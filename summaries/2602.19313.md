# TOPReward: Token Probabilities as Hidden Zero-Shot Rewards for Robotics

- arXiv: https://arxiv.org/abs/2602.19313v2
- arXiv ID: 2602.19313

---

🔍 **核心问题**：机器人学习需要密集、指令相关的反馈信号来区分任务进展，但现有方法依赖人工标注或任务特定训练，难以大规模获取。

🛠 **方法**：提出TOPReward，通过探测预训练视频-语言模型（VLM）的内部token概率，而非直接生成数值，来推断指令任务是否完成，从而得到无需训练的密集奖励信号。

✨ **主要贡献**：在包含130个任务和4种机器人平台的ManiRewardBench基准上，TOPReward显著优于现有无训练VLM奖励方法，与需训练的奖励模型基线性能相当，且支持成功检测和离线奖励加权行为克隆等下游应用。

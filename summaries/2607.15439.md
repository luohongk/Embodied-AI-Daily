# Do Coding Agents Need Executable World Models, Simplification, and Verification to Solve ARC-AGI-3?

- arXiv: https://arxiv.org/abs/2607.15439v2
- arXiv ID: 2607.15439

---

🔍 **核心问题**：探究在ARC-AGI-3任务中，可执行世界模型、简化提示和精确回放验证这三个机制各自对智能体性能的独立贡献。

🛠 **方法**：基于Codex构建四种变体（纯文本、灵活接口可执行、可执行+简化提示、固定接口+简化+验证），在25个公开游戏上使用gpt-5.4和gpt-5.5（高/极高推理强度）进行主实验，并用gpt-5.6-sol进行探索性对比。

✨ **主要贡献**：发现模型能力和推理强度提升带来的性能增益常超过变体间差异；可执行交付并非普遍有益（纯文本在gpt-5.5下优于灵活接口可执行）；完整验证变体在所有设置中排名第一但资源消耗大；在gpt-5.6-sol下，验证变体以约99%人类相对动作效率完成所有公开关卡，但纯文本变体在max设置下动作数比人类基线少41%，表明三个机制在最高能力下并非必需，结果仅反映公开集饱和。

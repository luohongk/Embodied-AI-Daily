# Unlocking Lossless Speedups in LLMs via Discrete Diffusion

- arXiv: https://arxiv.org/abs/2609.04010v1
- arXiv ID: 2609.04010

---

🔍 **核心问题**：大语言模型（LLMs）基于自回归（AR）结构逐token生成，导致推理速度慢，难以实现无损加速。

🛠 **方法**：提出扩散增强LLM（Uno），将模型参数分为AR权重（用标准NTP目标训练）和轻量扩散权重（并行生成多token），并通过扩散蒸馏阶段学习；引入Ψ-Spec采样器族，支持固定上下文长度下的无损加速与推理时扩展。

✨ **主要贡献**：无需独立草稿模型即可实现无损加速，吞吐量在各类batch size下优于领先的投机解码方法，较基础AR模型最高提速3倍；8B Uno模型在智能体工具使用、编码和长上下文推理基准上超越26B DiffusionGemma和Mercury 2，且可从零训练或增强现有开源模型。

# Autonomous Agricultural Tractor: Integrated Weed Detection and LiDAR Navigation for Precision Paddy Farming

- arXiv: https://arxiv.org/abs/2608.19004v1
- arXiv ID: 2608.19004

---

🔍 **核心问题**：稻田精准除草中，如何在GNSS信号退化时实现稳健的作物行导航，并实时区分水稻与形态多样的杂草，同时避免将水稻误判为杂草的不可逆损失。

🛠 **方法**：构建AgriNav自主拖拉机系统，集成四个ROS耦合模块：基于PyTorch的WeedDet水稻检测、轻量级CNN-FPN变体（1.68M参数）带非对称类别权重、硬编码置信度门控的倒置逻辑判别模块，以及融合GNSS/IMU/轮式里程计的6状态扩展卡尔曼滤波器（含三级中断桥接）。核心创新是四机制LiDAR-相机融合桥，利用导航LiDAR实现ROI约束、世界坐标投影、地面滤波和双向置信度融合，零额外硬件成本。

✨ **主要贡献**：系统级实现LiDAR与相机在导航和检测任务中的协同复用；仿真验证20秒GNSS中断下连续位置跟踪、作物行检测置信度全程>0.9，水稻检测置信度在0.32-0.95范围（涵盖稻田、航拍及洪后图像）；LiDAR ROI约束使检测推理区域缩减30-50%。

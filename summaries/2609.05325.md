# FIRE-LIVWO: Robust LiDAR-Inertial-Visual-Wheel Odometry via Failure-Immune mmWave Radar Enhancement

- arXiv: https://arxiv.org/abs/2609.05325v1
- arXiv ID: 2609.05325

---

🔍 **核心问题**：在结构复杂、退化严重的大型地下煤矿环境中，烟雾粉尘导致视觉信息丢失和LiDAR点云特征退化，而长直自相似走廊引发几何退化，造成里程计漂移，SLAM鲁棒性难以保证。

🛠 **方法**：提出FIRE-LIVWO框架，基于迭代误差状态卡尔曼滤波（IESKF）紧耦合4D毫米波雷达、LiDAR、视觉和轮式里程计；在统一VoxelMap中构建LiDAR-雷达点面残差和稀疏视觉光度残差，并利用多普勒速度约束、非完整约束（NHC）及在线杠杆臂补偿，结合几何与视觉可观测性分析实现退化检测和自适应融合模型切换。

✨ **主要贡献**：首次将4D毫米波雷达与LiDAR-惯性-视觉-轮式里程计紧耦合，通过在线可观测性量化动态调整模态权重，在真实地下煤矿实验中准确识别失效边界并实现可靠切换，平均定位误差仅5.677m，优于基线方法，且代码已开源。

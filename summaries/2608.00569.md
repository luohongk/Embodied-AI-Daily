# Latency-Tolerant Cloud-Edge Collaborative Vision-Language-Action Models via Emergent Representational Specialization

- arXiv: https://arxiv.org/abs/2608.00569v3
- arXiv ID: 2608.00569

---

🔍 **核心问题**：如何在网络延迟和抖动条件下，将十亿参数级VLA策略部署到移动机器人上，同时兼顾云端语义推理与边缘闭环控制的实时性。

🛠 **方法**：提出CloudEdgeVLA云边协同策略，将时序错位视为表示学习问题——云端VLA将延迟观测编码为缓变任务特征，轻量边缘头结合最新云端特征与当前局部视觉；训练时将当前帧与随机延迟帧配对同一动作目标，驱动云边表示自发专业化。

✨ **主要贡献**：在四个LIBERO套件中，40步均匀延迟下仍保持63.8–78.0%成功率（对比VLASH最高仅6.4%、单路径基线最高3.0%），并通过去除控制循环中的阻塞同步，为云端模型可扩展、边缘轻量响应的VLA部署提供了实用路径。

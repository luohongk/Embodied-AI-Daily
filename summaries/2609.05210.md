# BLASt3R: Bundle Adjustment of Any Image Set with Multi-View Matching and Monocular Priors

- arXiv: https://arxiv.org/abs/2609.05210v1
- arXiv ID: 2609.05210

---

🔍 **核心问题**：现有混合式运动恢复结构（SfM）系统虽结合了前馈重建的鲁棒性与传统光束法平差（BA）的精度，但密集视图匹配成本高昂，难以满足在线视觉SLAM（VSLAM）的实时性需求。

🛠 **方法**：提出一种正则化BA框架，利用快速多视图匹配器进行初始化，并引入单目先验作为正则项，统一支持在线VSLAM与离线无序图像集重建，且所有任务共享相同超参数。

✨ **主要贡献**：在VSLAM和离线重建任务上均优于传统、前馈及混合基线，取得更优的精度-速度权衡；尤其其无标定VSLAM方法超越了所有先前需标定的方法。

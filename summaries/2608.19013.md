# Harness Continual Learning: Continual Adaptation Beyond Model Parameters

- arXiv: https://arxiv.org/abs/2608.19013v1
- arXiv ID: 2608.19013

---

🔍 **核心问题**：传统持续学习聚焦于模型参数更新，但现代智能体通过提示、记忆、工具等“外部装备”（harness）适应环境，装备更新可能导致已学行为遗忘。本文提出装备持续学习（HCL）范式，解决在冻结基础模型下如何持续改进外部状态而不丢失旧能力的问题。

🛠 **方法**：定义HCL框架，包含四个执行组件（任务接口、经验记忆、能力图谱、自适应路由），并引入“受保护的装备演化”机制——持续优化器从执行反馈中生成候选装备，持续评估器在提交前检查当前改进、历史保留和有效性，实现更新生成与状态提交的分离。

✨ **主要贡献**：在文本推理、多模态感知和开放世界交互任务上验证了能力积累与失败恢复，相对基线提升超10%；消融实验量化了装备级遗忘，并证明可通过调节稳定性-可塑性权衡显式控制遗忘程度。

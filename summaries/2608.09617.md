# Bayesian Symbolic Regression with Entropic Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.09617v1
- arXiv ID: 2608.09617

---

🔍 **核心问题**：符号回归中，现有方法通常只寻找单一最优表达式，无法量化表达式的不确定性，且难以融入先验知识。

🛠 **方法**：提出ERRLESS，利用最大熵强化学习训练一个神经策略，逐步构建表达式的抽象语法树，从而从后验分布中采样表达式。

✨ **主要贡献**：在Feynman基准上取得竞争性结果，生成简短可解释的表达式；后验预测均值相比SMC基线获得更高R²，展示了贝叶斯视角在符号回归中的优势。

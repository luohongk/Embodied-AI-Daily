# Towards an Automated Test of LLM Security Knowledge

- arXiv: https://arxiv.org/abs/2607.18496v3
- arXiv ID: 2607.18496

---

🔍 **核心问题**：当前评估大语言模型（LLM）在安全领域的知识水平主要依赖人工构建挑战问题或基准测试，耗时且需要专业知识，缺乏自动化方法。

🛠 **方法**：提出一种半自动化评估方法，利用消费者保护机构（CPA）的权威信息，通过检测LLM对安全主题（如身份盗窃、诈骗）回答的不稳定性来识别知识缺口，并在Gemini和GPT两个模型家族上进行了验证。

✨ **主要贡献**：首次引入基于CPA信息的自动化测试框架，能够有效区分LLM是否具备足够知识准确识别文本中的安全主题，减少了人工评估的依赖。

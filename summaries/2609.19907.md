# GS-PI: An Optimization-Decoupled Appearance Decomposition Approach for Generating PBR Gaussian Assets

- arXiv: https://arxiv.org/abs/2609.19907v1
- arXiv ID: 2609.19907

---

🔍 **核心问题**：Gaussian Splatting 将光照与几何烘焙纠缠在一起，无法直接接入 PBR 渲染管线；现有逆渲染方法通过联合优化解耦材质，但目标相互竞争，导致严重歧义和残余光照伪影。

🛠 **方法**：提出 GS-PI 优化解耦框架，将 PBR 材质生成建模为 3D 点云上的几何条件扩散过程，通过多尺度跨视角条件机制（全局语义先验、源锚定光度线索、绝对空间视角方向条件）预测 PBR 属性，再经可微光栅化蒸馏回 Gaussian 模型，得到可重光照的 PBR-GS 资产。

✨ **主要贡献**：在 3D 域直接操作天然保证多视角一致性，避免 2D 扩散的像素对应问题；有效防止高光烘焙进本征颜色；性能超越近期逆渲染基线，且无需代理网格，用学习式扩散加短程蒸馏替代逐场景联合优化。

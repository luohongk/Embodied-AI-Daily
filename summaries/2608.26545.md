# Memory Anchors for Continual Robot Learning

- arXiv: https://arxiv.org/abs/2608.26545v1
- arXiv ID: 2608.26545

---

🔍 **核心问题**：机器人在持续学习新任务时，容易遗忘已学行为（灾难性遗忘），尤其是在新旧任务需要冲突动作的情况下。

🛠 **方法**：提出“记忆锚点”（Memory Anchors）概念，即在新任务观测表征与旧任务表征重叠但动作冲突的区域中，识别少量关键旧经验；通过优先回放这些锚点数据，而非随机采样，来防止旧知识被覆盖。

✨ **主要贡献**：实验表明，仅排除10%的记忆锚点会导致LIBERO基准上遗忘率增加4.5倍以上；而将记忆锚点加入回放缓冲区可减少63%的高冲突任务遗忘，并在真实机器人上成功实现两个任务序列的持续学习。

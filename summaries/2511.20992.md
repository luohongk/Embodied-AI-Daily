# Dataset Poisoning Attacks on Behavioral Cloning Policies

- arXiv: https://arxiv.org/abs/2511.20992v2
- arXiv ID: 2511.20992

---

🔍 **核心问题**：研究行为克隆（BC）策略在训练过程中对数据集投毒攻击的脆弱性，特别是清洁标签后门攻击的影响。

🛠 **方法**：通过在专家演示数据集中注入视觉触发器（如特定图案）污染数据，训练后门策略；并引入基于熵的测试时触发攻击，在关键状态激活后门以最大程度降低策略性能。

✨ **主要贡献**：首次系统分析清洁标签后门攻击对BC策略的有效性，发现即使极小比例（如1%）的投毒数据也能使策略在测试时被后门触发显著降级，而任务表现仍接近基线，揭示了BC策略的隐蔽安全风险。

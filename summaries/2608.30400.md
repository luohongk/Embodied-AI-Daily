# Real-Time Scene-Adaptive Tone Mapping for High-Dynamic Range Object Detection

- arXiv: https://arxiv.org/abs/2608.30400v1
- arXiv ID: 2608.30400

---

🔍 **核心问题**：高动态范围（HDR）图像在输入为低动态范围（LDR）训练的目标检测网络时，因极端动态范围导致性能显著下降，需解决HDR RAW输入与检测网络LDR sRGB需求之间的适配问题。

🛠 **方法**：提出一种场景自适应色调映射方法，包含神经光度校准以正则化动态范围，以及缩放不变局部色调映射模型以保留细节，并与下游任务端到端联合优化，支持从LDR sRGB到HDR RAW的低成本迁移微调。

✨ **主要贡献**：在自动驾驶HDR场景中优于传统色调映射和先进AI-ISP方法，并在NVIDIA Jetson平台上实现4K高比特深度HDR输入的实时处理，同时支持高效性能迁移。

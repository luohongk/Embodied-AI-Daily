# SearchArt: Training Long-Horizon Search Agent with Scalable Synthetic and Verified Task

- arXiv: https://arxiv.org/abs/2607.24850v2
- arXiv ID: 2607.24850

---

🔍 **核心问题**：训练长时程搜索智能体面临任务数据规模不足、中间推理与工具使用难以评估和纠正的挑战。

🛠 **方法**：提出SearchArt框架，通过验证驱动的任务合成（从网页文档和证据图生成多样化的搜索问答对及轨迹）和多阶段后训练（监督微调+强化学习策略优化）来训练搜索智能体。

✨ **主要贡献**：设计了联合评估问答一致性、轨迹质量和证据相关性的验证管线，确保数据可靠性；仅用27B参数的模型在BrowseComp-ZH、BrowseComp和Deepresearch-bench上分别取得74.39、70.06和52.55分，匹配或超越前沿闭源智能体，展现了自适应搜索规划和长程复杂推理能力。

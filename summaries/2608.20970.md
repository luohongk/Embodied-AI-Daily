# Deep Learning Models Also Recall Features

- arXiv: https://arxiv.org/abs/2608.20970v1
- arXiv ID: 2608.20970

---

🔍 **核心问题**：本文探讨深度学习模型中的“特征回忆”（feature recall）机制，即模型如何从权重中检索存储的信息，而不仅仅是传统理解的“特征组合”。

🛠 **方法**：作者提出将线性投影视为一种按输入激活缩放的信息检索操作，并论证该机制适用于多种架构，同时探讨了如何在机制层面识别此类操作。

✨ **主要贡献**：首次系统性地定义“特征回忆”概念，将其与“特征组合”范式区分开来，为哲学理解和机械可解释性研究提供了新的概念工具和实证方向。

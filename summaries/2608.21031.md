# PhysCaP: Grounding Code-as-Policy Agent with Physics-Informed Exploration

- arXiv: https://arxiv.org/abs/2608.21031v1
- arXiv ID: 2608.21031

---

🔍 **核心问题**：现有视觉-语言-动作策略在机器人操作中依赖被动观察，无法推断对操作至关重要的潜在物理属性（如质量、刚度），导致在物理属性隐藏的任务中表现不佳。

🛠 **方法**：PhysCaP在代码即策略框架中引入物理信息驱动的探索层，通过无训练的物理属性提取模块从机器人本体感觉估计物体质量与刚度，并采用双智能体设计——Planner决定探索时机与停止条件，Prioritizer过滤不合理交互并按启发式优先级排序，实现高效目标探索。

✨ **主要贡献**：在真实桌面操作任务（隐藏物体搜索、空罐检测、成熟牛油果识别）和LIBERO模拟任务中，PhysCaP相比被动和朴素交互基线，以更少交互和更短执行时间达到相当性能，消融实验验证了物理属性提取模块的有效性。

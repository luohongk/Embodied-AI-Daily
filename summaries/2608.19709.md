# RFWM: Physics-Guided World Model for Dynamic Wireless Radiance Field Generation

- arXiv: https://arxiv.org/abs/2608.19709v1
- arXiv ID: 2608.19709

---

🔍 **核心问题**：现有基于学习的射频辐射场建模方法难以泛化到动态和未见过的环境，无法从稀疏测量中准确生成时空射频场。

🛠 **方法**：提出RFWM，一种物理引导的射频世界模型，采用两阶段训练策略——第一阶段将预训练视觉扩散骨干适配到射频轨迹，并利用Friis引导先验提供粗略衰减指导；第二阶段从零训练ControlNet并微调射频适配骨干，同时使用六个物理引导正则化器确保传播一致性，最后通过跨高度头一次性生成查询高度的射频轨迹。

✨ **主要贡献**：构建了包含115个环境、7,715条序列（平均33帧）的动态射频场生成基准；实验表明，RFWM在分布内和分布外设置下分别比现有最优方法降低MSE约7 dB和3 dB，显著提升了动态和未知环境下的射频场生成性能。

# Using VLM Reasoning to Constrain Task and Motion Planning

- arXiv: https://arxiv.org/abs/2510.25548v3
- arXiv ID: 2510.25548

---

🔍 **核心问题**：任务与运动规划（TAMP）中，高层任务规划常因抽象层的“向下精化”失败而导致规划效率低下，需要反复重规划。

🛠 **方法**：提出VIZ-COAST方法，利用预训练视觉语言模型（VLM）的常识空间推理能力，在规划前从图像和领域描述中提取约束，预先剪除不可行的任务计划。

✨ **主要贡献**：在三个具有挑战性的TAMP领域上，该方法显著缩短规划时间，部分场景完全消除向下精化失败，并能泛化到领域内多样实例，优于仅在失败后添加约束的既有方法。

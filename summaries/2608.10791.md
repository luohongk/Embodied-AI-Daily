# Dual Stress: Runtime Safety Monitoring for Safety-Constrained MPC Navigation

- arXiv: https://arxiv.org/abs/2608.10791v1
- arXiv ID: 2608.10791

---

🔍 **核心问题**：传统自动驾驶导航的安全监控仅依赖几何量（如间距、碰撞时间），忽略了模型预测控制器（MPC）在安全约束优化中产生的对偶信息（KKT乘子），导致对潜在碰撞的预警能力不足。

🛠 **方法**：提出“对偶应力”（Dual Stress）信号，即对MPC优化中每个障碍物对应的KKT乘子进行时间加权求和，作为补充几何监控的运行时风险指标，并在物理仿真器的预注册交叉场景中与15种几何检测器对比。

✨ **主要贡献**：对偶应力信号能额外标记出几何检测器漏报的85次碰撞（而几何检测器仅额外标记18次），两者结合可预警75%的可制动碰撞，而单独几何检测器仅预警不到一半，显著提升安全监控的互补性和有效性。

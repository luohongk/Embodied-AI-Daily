# ReWorld: An Interactive World Model with Long-Horizon Memory

- arXiv: https://arxiv.org/abs/2608.23565v1
- arXiv ID: 2608.23565

---

🔍 **核心问题**：交互式世界模型需同时满足用户动作控制（短时域）、长期记忆（长时域）和实时生成，但控制与记忆在结构上存在冲突。

🛠 **方法**：提出ReWorld，训练时用混合逐头注意力窗口（多数头关注近期，少数全局头关注全历史）并配合随机头路由和随机块丢弃；推理时用固定预算的KV缓存和姿态索引地标库检索最近地标，并通过度量尺度对齐的数据引擎统一多源数据，用LoRA适配器蒸馏压缩采样至4步。

✨ **主要贡献**：在动作跟随、长期回忆和视频质量三轴协议上，ReWorld在6个最新模型中取得最佳控制精度（旋转误差11.95°）和生成质量；在64秒往返轨迹中，固定12块缓存仍能重建起始视图，而滑动窗口和全KV注意力均失效。

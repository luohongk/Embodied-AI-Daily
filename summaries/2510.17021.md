# Forgetting to Forget: Attention Sink as A Gateway for Backdooring LLM Unlearning

- arXiv: https://arxiv.org/abs/2510.17021v2
- arXiv ID: 2510.17021

---

🔍 **核心问题**：本文探讨大语言模型（LLM）的“遗忘”（unlearning）过程是否可能被植入后门，即在正常条件下模型看似成功遗忘，但一旦触发隐藏触发器，就会恢复被遗忘的知识。

🛠 **方法**：作者提出一种后门攻击框架，通过将触发器放置在“注意力汇聚”（attention sink）位置（即浅层输入token持续吸引不成比例注意力的现象），并调整其注意力值来强化后门训练，从而在遗忘过程中嵌入隐蔽触发器。

✨ **主要贡献**：首次系统研究“后门遗忘”攻击，揭示注意力汇聚与后门有效性之间的强关联；实验证明，基于注意力汇聚引导的后门遗忘能在触发器出现时恢复遗忘知识，而在无触发器时与正常遗忘模型表现无异，攻击隐蔽性强且难以察觉。

# ReflectFact: Self-Reflective Agents for Improving Comprehension and Reasoning in Multi-Hop Fact Verification

- arXiv: https://arxiv.org/abs/2608.12877v1
- arXiv ID: 2608.12877

---

🔍 **核心问题**：多跳事实验证中，现有智能体方法缺乏全局验证目标意识，且参数化知识与证据冲突时易导致推理偏差，影响验证准确性。

🛠 **方法**：提出ReflectFact框架，包含显式推理路径规划、证据漂移验证和推理反思验证三个关键任务，通过自我反思机制校准证据偏差并修正推理缺陷。

✨ **主要贡献**：在HOVER和EX-FEVER数据集上分别超越最强基线3.32%和2.78%，达到最先进性能，有效改善了现有方法的理解与推理缺陷。

# Training Skills Like Parameters via Self-Supervised Semantic Diffusion

- arXiv: https://arxiv.org/abs/2607.27557v1
- arXiv ID: 2607.27557

---

🔍 **核心问题**：闭源大模型在高度专业化、开放式领域（如创意编剧）中表现不足，且现有后训练方法需要权重访问和大量计算，而智能体持续学习依赖昂贵的人工标注或不可靠的LLM评判反馈。

🛠 **方法**：提出一种无监督的自进化智能体框架，受扩散模型“破坏-重建”范式启发，利用现有高质量人类作品构造自监督信号，通过对比智能体重建结果与人类原作计算损失，更新外部文本技能库而非模型权重。

✨ **主要贡献**：在短剧编剧任务上验证了该方法，使智能体能自主提取和泛化技能，显著提升领域生成能力；自对比反思范式为智能体无外部监督地学习复杂人类作品提供了可扩展路径。

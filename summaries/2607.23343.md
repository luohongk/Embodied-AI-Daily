# Patient-Agnostic Synthetic Pretraining for Efficient Patient-Specific Intraoperative 2D/3D Registration

- arXiv: https://arxiv.org/abs/2607.23343v1
- arXiv ID: 2607.23343

---

🔍 **核心问题**：术中2D/3D配准通常需要为每位患者从头训练专用模型，计算成本高，限制了实际临床部署。

🛠 **方法**：提出基于患者无关的合成预训练与球面相似性学习的框架，先在多CT合成DRR上预训练学习可迁移的位姿敏感表征，再通过无分割的域随机化策略适应新患者，最后结合球面相似性学习与可微Levenberg-Marquardt优化进行精细配准。

✨ **主要贡献**：患者无关的合成预训练显著降低了患者特定配准的训练成本，同时保持高精度，并在多个解剖数据集上验证了适应效率与配准精度之间的良好平衡。

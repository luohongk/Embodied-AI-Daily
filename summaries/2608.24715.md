# Deep Learning Super Resolution for Satellite Cloud Mask Downscaling

- arXiv: https://arxiv.org/abs/2608.24715v1
- arXiv ID: 2608.24715

---

🔍 **核心问题**：解决卫星云观测中空间与时间分辨率难以兼得的矛盾，实现对地球静止卫星（SEVIRI）云掩膜产品的高精度空间降尺度（4倍增强）。

🛠 **方法**：提出两种深度学习超分辨率模型——基于CNN的SpatialCNN和基于GAN的SpatialGAN，并构建跨传感器云掩膜数据集SEVMOD-CM（通过MODIS与SEVIRI时空匹配生成），训练模型从SEVIRI光谱及云掩膜产品预测对应MODIS云掩膜。

✨ **主要贡献**：首次将超分辨率技术应用于静止卫星云掩膜降尺度，实验证明两种模型均优于标准双三次插值，为大气监测、天气预报、灾害风险降低、太阳能预测及气候研究提供高分辨率云数据支持，并公开了新的跨传感器数据集。

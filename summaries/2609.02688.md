# From Proxy Learning to Driving Decisions: A Transfer-Based Framework for Evaluating Future-Aware Autonomous Driving Planners

- arXiv: https://arxiv.org/abs/2609.02688v1
- arXiv ID: 2609.02688

---

🔍 **核心问题**：现有未来感知自动驾驶规划器常以代理目标或受限子集的改进直接宣称规划性能提升，但缺乏对提议排序、轨迹选择、全尺度效用及关键驾驶组件的验证，导致结论不可靠。

🛠 **方法**：提出代理到决策迁移（PDT）框架，包含决策迁移分解模块（通过分数边际、切换条件效用和支持-选择遗憾定位价值损失）与可靠性约束验证模块（要求精确配对、最小有效效应、尺度扩展确认、安全非补偿、序列可比性和家族级鲁棒性）。

✨ **主要贡献**：在NAVSIM-v1上揭示组件BCE下降但选中PDM几乎不变，且候选改进在扩展数据上不显著；432个配置无一通过鲁棒性门控，系统定位了决策迁移失败或不确定的证据层级，为未来感知规划器的可靠评估提供了严格方法论。

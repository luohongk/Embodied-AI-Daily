# TruncGradGS: Improved 3D Gaussian Splatting via Truncated Gradient Updates

- arXiv: https://arxiv.org/abs/2609.03534v1
- arXiv ID: 2609.03534

---

🔍 **核心问题**：3D高斯溅射（3D Gaussian Splatting）在优化过程中存在梯度消失现象，即远离高斯原语的像素对其属性更新的梯度贡献极小，导致场景重建质量不佳。

🛠 **方法**：提出一种分段截断梯度（piecewise truncated gradient）公式，通过截断梯度更新来缓解梯度消失，增强优化稳定性，并降低对初始化质量的敏感性。

✨ **主要贡献**：在随机和COLMAP初始化下均一致提升静态与动态3D高斯溅射的性能；同时指出当前动态场景基准的局限，并引入一个基于合成3D场景的新动态数据集用于更可靠的评估。

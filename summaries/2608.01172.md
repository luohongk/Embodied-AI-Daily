# Complete Motion Planning using Workspace-Fibered Decomposition for nR-Planar Manipulator

- arXiv: https://arxiv.org/abs/2608.01172v1
- arXiv ID: 2608.01172

---

🔍 **核心问题**：针对在杂乱环境中作业的nR平面冗余机械臂，如何高效进行运动规划，避免直接构建高维配置空间障碍物几何。

🛠 **方法**：提出基于工作空间纤维分解的框架，通过增量构建低维非冗余子链的障碍约束可达工作空间，并利用雅可比行列式连续性约束递归提升冗余方向纤维，生成降维规划流形。

✨ **主要贡献**：证明了最小非冗余子链的可达工作空间可精确刻画起始配置连通分量内的可行性，支持早期不可行检测；实验表明该方法在保持碰撞自由连通结构的同时，显著降低碰撞检测复杂度。

# Toward Blockage-Resilient 6G-V2X Connectivity: Semi-Distributed Bandit with Dynamic Arm Set for mmWave HetNets

- arXiv: https://arxiv.org/abs/2608.04852v1
- arXiv ID: 2608.04852

---

🔍 **核心问题**：解决6G车联网（V2X）中毫米波异构网络因动态阻塞和信道快速变化导致的用户关联不稳定问题，传统多臂老虎机（MAB）框架的静态奖励假设在此场景下失效。

🛠 **方法**：提出全分布式阻塞感知非平稳动态老虎机算法（BAND）及其半分布式扩展（S-BAND），将阻塞预测融入变化检测机制以抑制误报，并设计动态基站集合管理方案；S-BAND通过车辆周期性上传本地知识至宏基站进行聚类聚合，引入轨迹对齐知识（TAK）区域和知识继承保真度（KIF）指标。

✨ **主要贡献**：在真实城市拓扑仿真中，BAND和S-BAND相比集中式MAB基线分别降低34.9%和59.4%的遗憾值，且在10%-50%阻塞率下性能优势稳定；TAK区域在两种保真度准则下均优于传统K-means聚类方案。

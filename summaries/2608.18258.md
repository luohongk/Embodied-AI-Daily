# VERAGMIL: Virtual Environment for Scooping Granular Foods with Imitation Learning Models

- arXiv: https://arxiv.org/abs/2608.18258v1
- arXiv ID: 2608.18258

---

🔍 **核心问题**：机器人辅助喂食系统在处理颗粒状食物（如米饭、豆类）时面临动态物理特性带来的操控挑战，且高质量人类演示数据的获取困难。

🛠 **方法**：提出VERAGMIL框架，结合高保真模拟器与直观的虚拟现实（VR）界面来记录演示，并支持多种模仿学习方法（BC、BC-RNN、BCQ），在颗粒舀取和运输任务中训练模型，并与3D空间鼠标演示及人类专家基线对比。

✨ **主要贡献**：验证了VR演示数据显著优于3D空间鼠标数据，其中BCQ模型综合表现最佳，尤其在减少食物洒落方面接近人类水平；框架代码已开源，为颗粒状食物操控的RAF系统训练提供了有效方案。

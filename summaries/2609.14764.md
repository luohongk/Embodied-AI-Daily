# CCMAN: Cognitive Instability-Aware Cross-Modal Attention Network for Interpretable Temporal Biomarkers of Verbal Fluency Speech

- arXiv: https://arxiv.org/abs/2609.14764v1
- arXiv ID: 2609.14764

---

🔍 **核心问题**：如何从言语流畅性任务的语音中早期、可解释地检测认知衰退，并克服现有方法忽略语音时间动态、仅做整段录音特征聚合的局限。

🛠 **方法**：提出认知不稳定感知跨模态注意力网络（CCMAN），先在多个记忆探测任务上预训练任务无关的认知语音表征，再在语义与音素流畅性任务上微调，融合语义、声学和语言学信息，采用双向跨注意力、门控多模态融合与Transformer时序建模。

✨ **主要贡献**：在843名参与者、165.44小时语音数据上，二分类与多分类Macro-F1分别达0.81/0.59（语义）和0.77/0.53（音素），优于静态与时序基线；发现语义漂移方差、停顿方差及停顿时长渐进增长是可解释的生物标志物，并在独立PROCESS-2基准上最高提升9% Macro-F1，验证了泛化性。

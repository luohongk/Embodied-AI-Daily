# RegCL: Compact Continual SAM Adaptation for Visual Grounding in Multi-Sensorial Media

- arXiv: https://arxiv.org/abs/2507.12297v2
- arXiv ID: 2507.12297

---

🔍 **核心问题**：多感官媒体系统（如AR/VR、远程操作、具身AI）中的视觉定位模块需要适应不断变化的感知环境和应用领域，但SAM模型在医学图像、伪装场景等专门领域性能下降，现有持续学习方法依赖重放数据或增加领域专属模块，难以紧凑部署。

🛠 **方法**：提出RegCL，一种无重放的持续适应框架，通过增量模型合并将多领域分割知识整合到单一SAM适配器中。具体地，合并LoRA风格的轻量级适配模块（AugModules），优化合并模型与领域专属适配器之间的预测一致性，同时保留紧凑的历史特征统计信息。

✨ **主要贡献**：在五个异构分割数据集上验证了RegCL在领域增量学习下能同时保持旧知识（保留）和适应新领域，性能优于其他无重放持续学习与模型合并基线。该框架可作为演化中多感官媒体管线的紧凑视觉适应组件，代码已开源。

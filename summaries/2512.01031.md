# VLASH: Real-Time VLAs via Future-State-Aware Asynchronous Inference

- arXiv: https://arxiv.org/abs/2512.01031v2
- arXiv ID: 2512.01031

---

🔍 **核心问题**：现有视觉-语言-动作模型（VLA）在机器人任务中采用同步推理，导致动作停顿和反应延迟，无法适应动态实时任务。异步推理虽能实现连续控制，但预测与执行时间错位会引发动作不稳定，现有方法要么降低精度，要么增加运行时开销。

🛠 **方法**：提出VLASH方法，通过利用前一个动作块滚动机器人状态，预测未来执行时刻的状态，从而弥合预测与执行之间的时间差。该方法无需改变模型架构或增加额外运行时开销。

✨ **主要贡献**：相比同步推理，VLASH将反应延迟降低最多11.8倍，并在精度上持续优于所有异步基线方法。结合动作量化后，任务完成速度提升1.5-2.0倍且精度损失极小。它使π₀.₅等先进VLA模型能完成打乒乓球、打地鼠等需要快速反应和高精度的任务，而传统同步推理无法胜任。

# Valerant: An Automatic Navigable Game Map Generator via Action-Conditioned World Model Exploration

- arXiv: https://arxiv.org/abs/2609.09418v1
- arXiv ID: 2609.09418

---

🔍 **核心问题**：现有面向游戏的世界动作模型（WAM）主要在2D视觉空间运行，无法生成持久化的3D几何结构；而3D游戏需要显式几何来支持移动与交互，且游戏世界没有像自动驾驶/机器人那样的外部物理环境作为支撑。

🛠 **方法**：提出免训练的 Valerant 框架，将预训练的动作条件世界模型与基于SLAM的空间重建及探索驱动的动作选择相结合，通过预测性视觉推演逐步将单张图像转化为持久化的3D游戏地图。

✨ **主要贡献**：把基于WAM的交互从2D视觉模拟扩展到3D空间，实现从单图自动生成可导航的3D游戏地图，为减少3D游戏地图制作的人工成本提供了新途径。

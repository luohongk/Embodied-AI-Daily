# HiTac-WAM: A Hierarchical Tactile World Action Model for Contact-Rich Robot Manipulation

- arXiv: https://arxiv.org/abs/2608.19574v1
- arXiv ID: 2608.19574

---

🔍 **核心问题**：现有触觉感知的世界动作模型未能建模触觉状态之间的物理层级依赖关系，导致接触丰富的机器人操作任务中预测与规划性能受限。

🛠 **方法**：提出HiTac-WAM，一种层级触觉世界动作模型，将未来触觉预测分解为接触状态、3D形变场和滑移风险三个层级，并通过有向注意力掩码使触觉查询关注视频-动作上下文，同时利用预测与观测差异触发重规划。

✨ **主要贡献**：层级分解使3D形变误差降低17.6%、滑移AUPRC提升60.4%；在芯片抓取、黑板擦除和USB插入任务中，层级预测引导的选择将真实机器人成功率从31.1%提升至61.1%，完整系统达到72.2%。

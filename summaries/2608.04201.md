# Unscented KalmanNet: a hybrid deep learning filter with calibrated posterior covariance for nonlinear state estimation

- arXiv: https://arxiv.org/abs/2608.04201v1
- arXiv ID: 2608.04201

---

🔍 **核心问题**：非线性状态估计中，传统无迹卡尔曼滤波（UKF）在噪声统计未知、时变或模型失配时，估计精度和协方差校准会显著退化。

🛠 **方法**：提出Unscented KalmanNet（UKN），在UKF的显式sigma点协方差递推基础上，引入两个学习组件——NoiseNet预测有界乘性噪声协方差修正，GainNet对解析增益施加有界残差修正，并用校准感知的联合训练目标优化精度与校准。

✨ **主要贡献**：UKN在三个合成系统和UZH-FPV真实飞行数据上均取得最低状态估计误差，相比UKF在合成案例中RMSE降低26.4%-49.7%，在11次飞行交叉验证中位置和速度RMSE分别降低22.4%和34.3%，且协方差校准（NEES和覆盖率）最接近理想值，折叠间变异性最小。

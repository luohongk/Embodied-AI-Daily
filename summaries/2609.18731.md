# Which LLM is Best for Translating Natural Language Goals to PDDL

- arXiv: https://arxiv.org/abs/2609.18731v1
- arXiv ID: 2609.18731

---

🔍 **核心问题**：如何让非专家用自然语言表达的目标可靠地转换为PDDL形式化规划目标，从而降低自动规划的使用门槛。

🛠 **方法**：设计了一套精心优化的提示模板，并对六种前沿LLM在真实游戏测试场景下进行正确性、速度和错误倾向的系统评测。

✨ **主要贡献**：所有模型正确率均超92%，其中Gemini 2.5 Flash准确率最高（96%）且误报最少，GPT-4.1响应最快；同时揭示了语言歧义和领域表示局限仍是主要失败来源。

# Marionette: Predicting World States, Rendering Geometry, Painting Appearance

- arXiv: https://arxiv.org/abs/2608.14530v1
- arXiv ID: 2608.14530

---

🔍 **核心问题**：交互式游戏世界模型在长时程预测中，因隐式维护姿态、几何和遮挡等结构化属性，导致误差累积、一致性和可控性脆弱。

🛠 **方法**：提出Marionette模型，将世界状态显式建模为276维3D状态（含骨架、轨迹、旋转），用零参数渲染器计算几何与遮挡，再通过视频扩散模型合成外观。

✨ **主要贡献**：状态预测可直接控制（动作干预改变关节误差31%），长时程行为可在状态层修复（穿透减少66%、角色距离保持合理），且外观合成质量与真实姿态相当（FVD 831 vs 799）。

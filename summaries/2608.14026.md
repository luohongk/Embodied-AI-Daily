# MMDynOpt-Agent: Dynamic Optimization for Multimodal Large Language Model Reasoning via Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.14026v2
- arXiv ID: 2608.14026

---

🔍 **核心问题**：多模态大语言模型（MLLMs）在复杂推理任务中难以有效将视觉线索和问题语义转化为推理条件，导致推理性能受限。

🛠 **方法**：提出MMDynOpt-Agent，将多模态推理的动态优化建模为马尔可夫决策过程，通过端到端强化学习训练一个轻量级多模态智能体作为决策策略，与目标MLLM环境交互，利用多轮动态优化提示自适应引导推理；并设计结合格式合规、答案正确性和预算意识的奖励机制，平衡推理准确性与效率。

✨ **主要贡献**：该方法具有可迁移性和泛化性，可用一个目标MLLM训练后迁移至其他模型推理；在15个公开数据集上取得强性能，优于基线方法。

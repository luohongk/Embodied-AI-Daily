# Cortex: Compact Behavior Cloning for Quake with Frozen Visual Features

- arXiv: https://arxiv.org/abs/2607.22739v1
- arXiv ID: 2607.22739

---

🔍 **核心问题**：研究在视觉丰富的第一人称游戏中，仅使用简单的行为克隆策略（不依赖强化学习或显式记忆）能达到何种表现水平。

🛠 **方法**：采用紧凑的Transformer策略（Cortex），包含6层Transformer和1098万可训练参数，使用冻结的DINOv3视觉编码器，在公开的Pixels2Play数据集的Quake子集上训练，输入为四帧窗口的键盘鼠标动作。

✨ **主要贡献**：Cortex虽未完成关卡，但每局都能到达关键区域，多数局有击杀记录；相比同条件下的P2P-150M和NitroGen模型表现更深；消融实验表明密集视觉令牌可提升战斗和生存能力，同时揭示了协变量偏移问题，为后续针对性数据修正提供了方向。

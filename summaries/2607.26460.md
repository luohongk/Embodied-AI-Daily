# RLMM-Flow: A Flow-based Mobile Manipulation Framework with Latent-Space Reinforcement Learning

- arXiv: https://arxiv.org/abs/2607.26460v1
- arXiv ID: 2607.26460

---

🔍 **核心问题**：移动操作机器人需要生成满足多约束条件的全身动作序列，但仅靠模仿学习无法超越专家演示数据的质量上限。  
🛠 **方法**：提出RLMM-Flow框架，先通过流策略（flow policy）从专家演示中学习多模态运动先验，再冻结该策略并用潜在空间强化学习（latent-space RL）优化初始噪声，结合粗到细的潜在引导策略稳定高维优化。  
✨ **主要贡献**：在移动操作运动规划基准上，相比纯模仿流策略和现有RL后训练方法，显著提升了任务成功率、避障能力和轨迹质量，同时保持了流模型的高效推理速度。

# Learning to Use Tools: Reinforcement Learning for Tool-Integrated Mathematical Reasoning

- arXiv: https://arxiv.org/abs/2608.28447v1
- arXiv ID: 2608.28447

---

🔍 **核心问题**：大型语言模型在数学推理任务中常因计算错误导致失败，本文研究如何通过集成计算器工具提升推理准确性。

🛠 **方法**：构建监督微调数据集教会模型使用计算器工具，随后应用多种在线强化学习方法（RLOO、RLOO++、GRPO、DAPO），以最终答案可自动验证的奖励进行训练。

✨ **主要贡献**：工具集成使SFT和RL基线均提升约10个百分点；Tool-DAPO方法最优，将pass@1从35.8%提升至66.0%；实验证明RL能促使模型更有效地使用工具，即使仅提供最终答案奖励。

# PROBE: Manipulation-Grounded Visual Question Answering with VLM Agents

- arXiv: https://arxiv.org/abs/2608.17129v1
- arXiv ID: 2608.17129

---

🔍 **核心问题**：本文解决机器人在杂乱真实环境中回答物理遮挡问题（如“我的药还在柜子里吗？”）时，需要操作物体才能获取视觉信息，而现有VLM仅能处理静态场景推理的局限。

🛠 **方法**：提出Manipulation-Grounded VQA（MG-VQA）框架，构建高保真仿真器PROBE-Sim生成150个杂乱桌面任务基准PROBE-Bench，并设计PROBE-Agent微调方案，通过蒸馏教师模型成功轨迹到小型开源模型，结合混合数据策略训练。

✨ **主要贡献**：首次形式化“操作-推理”耦合的VQA任务；实验表明所有前沿VLM的智能体工具方法比纯感知基线平均提升8.0%；微调后的PROBE-Agent比现成智能体基线平均提升11.5%，且对未见物体和任务具有泛化性，并成功实现仿真到真实环境的迁移部署。

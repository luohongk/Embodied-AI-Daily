# SiNMULI: Novel Signed Network Approach for Malicious URL Identification

- arXiv: https://arxiv.org/abs/2608.19190v1
- arXiv ID: 2608.19190

---

🔍 **核心问题**：传统机器学习与深度学习在恶意URL识别中依赖静态数据分析，难以应对不断演变的恶意网站，且缺乏可解释性和抗对抗性。

🛠 **方法**：提出SiNMULI框架，将恶意URL识别建模为基于符号网络的二分类问题，利用URL的反向链接构建符号网络，结合社会平衡理论传播边符号，并通过51%多数规则对未标记域名进行分类。

✨ **主要贡献**：在真实数据集上达到99.89%的准确率、99.62%的精确率和99.80%的F1分数，优于传统ML和深度学习基线；同时具备高可解释性、抗对抗混淆能力，且不依赖训练数据，是轻量级、可扩展的网络安全方案。

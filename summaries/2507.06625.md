# Q-Guided Stein Variational Model Predictive Control via RL-informed Policy Prior

- arXiv: https://arxiv.org/abs/2507.06625v4
- arXiv ID: 2507.06625

---

🔍 **核心问题**：传统模型预测控制（MPC）依赖精确动力学模型和手工设计的代价函数，而现有学习型MPC方法（如可微MPC或CEM/MPPI）易陷入单一解（模式坍缩），难以在轨迹优化中保留多样化的可行方案。

🛠 **方法**：提出Q-SVMPC，将学习型MPC建模为轨迹级后验推断，利用强化学习中的软Q值作为引导信号，结合基于RL的策略先验，通过Stein变分梯度下降（SVGD）迭代细化轨迹粒子，从而在保持多样性的同时优化轨迹分布。

✨ **主要贡献**：在导航、机器人操作及真实水果采摘任务中，相比MPC、无模型RL及现有学习型MPC基线，Q-SVMPC展现出更高的学习效率、更强的最终性能与训练稳定性，并显式保留了多模态解，避免了模式坍缩问题。

# SEBA: Sample-Efficient Black-Box Attacks on Visual Reinforcement Learning

- arXiv: https://arxiv.org/abs/2511.09681v2
- arXiv ID: 2511.09681

---

🔍 **核心问题**：现有黑盒攻击方法在图像连续控制任务中因动作空间大、环境查询次数多而效率低下，视觉强化学习智能体的脆弱性尚未被充分探索。

🛠 **方法**：提出SEBA框架，整合影子Q模型（估计对抗条件下的累积奖励）、生成对抗网络（生成视觉不可察觉的扰动）和世界模型（模拟环境动态以减少真实查询），并通过两阶段迭代训练交替优化影子模型与生成器。

✨ **主要贡献**：在MuJoCo和Atari基准上，SEBA显著降低累积奖励、保持视觉保真度，并大幅减少环境交互次数，优于现有黑盒与白盒方法，实现了高效且强力的黑盒攻击。

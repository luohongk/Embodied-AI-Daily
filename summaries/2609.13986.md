# A Low-Latency Interactive System for Real-Time Video Understanding Based on VLMs

- arXiv: https://arxiv.org/abs/2609.13986v1
- arXiv ID: 2609.13986

---

🔍 **核心问题**：现有视频理解研究多聚焦模型能力，忽视了可部署的低延迟实时交互系统，本文旨在解决实时视频VLM应用的端到端低延迟交互问题。

🛠 **方法**：提出统一的边云协同系统，支持手机、智能眼镜、PC等轻量客户端发布视频与语音，服务端提供共享ASR/TTS、会话编排、后端适配与响应交付，并集成六种代表性视频VLM后端进行多维度评测。

✨ **主要贡献**：在合适的后端选择与WebRTC路径下，系统实现约0.9–1.0秒首帧VLM文本输出和1.3–1.5秒首个非静音TTS音频，同时揭示了后端适配成本及实时交互行为的差异。

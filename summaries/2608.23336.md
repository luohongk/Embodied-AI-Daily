# Can Coding Agents Build Robust Baselines? A Skill-Based Approach for Automating the Medical Imaging Model-Development Pipeline

- arXiv: https://arxiv.org/abs/2608.23336v1
- arXiv ID: 2608.23336

---

🔍 **核心问题**：医学影像深度学习基线模型的开发高度依赖人工迭代（文献调研、编码、实验、调优），现有自动化方法仅优化单一环节（如架构搜索或超参调优），无法覆盖完整开发流程。

🛠 **方法**：提出一种“智能体AI科学家”工作流，结合文献引导推理、自动代码生成和假设驱动实验，端到端自动化构建医学影像基线模型，无需针对任务重新设计。

✨ **主要贡献**：在4个公开基准（分割、分类、检测）上验证，均稳定提升验证性能并取得领先排名（如PUMA双赛道第6名、MILK10k第31名），且MIDOG25上展现跨扫描仪/肿瘤类型/物种的强泛化能力，证明技能化、文献引导的智能体工作流能大幅降低医学影像基线开发的人工成本。

# Habitat-GS: A High-Fidelity Navigation Simulator with Dynamic Gaussian Splatting

- arXiv: https://arxiv.org/abs/2604.12626v2
- arXiv ID: 2604.12626

---

🔍 **核心问题**：现有具身AI导航模拟器主要依赖网格渲染，逼真资产制作成本高，且动态人类建模受限于网格表示，导致智能体难以泛化到真实人类场景。

🛠 **方法**：基于Habitat-Sim扩展，集成3D高斯泼溅（3DGS）场景渲染器和可驱动的高斯化身（Gaussian Avatar），实现实时逼真渲染、可扩展的3DGS资产导入，并让化身同时充当视觉实体和导航障碍物。

✨ **主要贡献**：提出Habitat-GS模拟器，实验证明基于3DGS场景训练的智能体具有更强的跨域泛化能力，高斯化身能有效支持人类感知导航，且系统具备良好的可扩展性。

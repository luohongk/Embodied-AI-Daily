# ForgeryVCR: Visual-Centric Reasoning via Efficient Forensic Tools in MLLMs for Image Forgery Detection and Localization

- arXiv: https://arxiv.org/abs/2602.14098v2
- arXiv ID: 2602.14098

---

🔍 **核心问题**：现有基于多模态大语言模型（MLLM）的图像伪造检测与定位方法依赖文本中心的思维链（CoT），难以用语言描述细微的像素级篡改痕迹，导致幻觉问题。

🛠 **方法**：提出ForgeryVCR框架，引入取证工具箱将不可见的篡改痕迹转化为显式视觉中间表示，并通过“策略性工具学习”后训练范式（包括增益驱动的SFT轨迹构建和基于工具效用的强化学习优化），使模型自主调用多视角推理路径（如局部放大、压缩历史、噪声残差和频域分析）。

✨ **主要贡献**：在检测与定位任务上达到SOTA性能，显著提升泛化性和鲁棒性，且工具调用冗余度低；代码已开源。

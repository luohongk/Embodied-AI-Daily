# PlayTrain: An Efficient Reinforcement Learning Framework for LLM-Generated Adaptable JavaScript Games

- arXiv: https://arxiv.org/abs/2609.09059v1
- arXiv ID: 2609.09059

---

🔍 **核心问题**：传统视频游戏环境（VGEs）的开发或修改需要大量手工编码，过程繁琐且效率低，限制了强化学习（RL）研究的灵活性和可扩展性。

🛠 **方法**：提出PlayTrain框架，利用大语言模型（LLMs）从极简人类提示中生成JavaScript游戏，并构建高效流水线，使任何JS游戏能在标准gym环境中运行，支持RL智能体训练。

✨ **主要贡献**：实现端到端像素级智能体训练，速度超1M决策/秒（单GPU节点）；支持克隆Atari/ProcGen游戏及快速修改游戏逻辑、测试集或动态；将VGE开发简化为单一JS文件，由LLM生成和迭代，为RL研究开辟新方向。

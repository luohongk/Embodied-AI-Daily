# Parallel Branch Model Predictive Control on GPUs

- arXiv: https://arxiv.org/abs/2506.13624v2
- arXiv ID: 2506.13624

---

🔍 **核心问题**：解决大规模轨迹规划问题中分支模型预测控制（MPC）的计算效率瓶颈，尤其是在树形结构约束下的实时求解需求。

🛠 **方法**：提出一种基于GPU的求解器，采用多次打靶（multiple-shooting）公式化系统动力学，并结合增广拉格朗日方法处理一般阶段约束；同时开发两个利用树稀疏结构的定制内层LQR求解器，以提供不同并行度。

✨ **主要贡献**：在两类挑战性轨迹规划问题上验证了约束处理能力，并证明与高性能CPU求解器相比，该方法在大规模问题上具有显著性能优势，且支持简单热启动。

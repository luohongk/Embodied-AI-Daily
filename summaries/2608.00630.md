# Relative Parameter Importance in Task-Agnostic Replay-Free Continual Learning

- arXiv: https://arxiv.org/abs/2608.00630v1
- arXiv ID: 2608.00630

---

🔍 **核心问题**：在无任务标识且无法访问旧任务数据的离线持续学习场景中，如何平衡稳定性与可塑性，同时实现知识迁移。

🛠 **方法**：提出一种新的度量——相对参数重要性，衡量每个参数对当前和过去任务的相对重要性。高相对重要性的参数被强正则化以维持旧任务稳定性，低相对重要性的参数可自由更新，且允许高过去任务重要性但低相对重要性的参数被更新，从而支持反向知识迁移。

✨ **主要贡献**：在类增量与域增量文本分类任务上，该方法优于现有持续学习技术，并展示了向文本生成任务扩展的潜力。代码已开源。

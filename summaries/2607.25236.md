# VisualPatchWorld: Code World Models as Latent Structured Representations for Planning

- arXiv: https://arxiv.org/abs/2607.25236v1
- arXiv ID: 2607.25236

---

🔍 **核心问题**：如何构建一种既可从数据中学习、又具备可解释性和可编辑性的世界模型，用于机器人规划任务。

🛠 **方法**：提出VisualPatchWorld（VPW），通过主动探测选择定性动力学形式，再根据状态-动作轨迹拟合自由参数，最终将世界动力学表示为可执行的代码程序，并结合图像场景图提供实时状态。

✨ **主要贡献**：VPW在规划任务中达到69.0%的平均成功率，比最强代码基线高出23.5个百分点；在导航和抓取控制中接近真实物理引擎性能，并通过检查候选计划弥补接触推动任务的差距，为自动构建可规划代码世界模型提供了实用路径。

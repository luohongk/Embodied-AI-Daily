# PhiZero: A World Model Built Around Physical Language

- arXiv: https://arxiv.org/abs/2607.28624v1
- arXiv ID: 2607.28624

---

🔍 **核心问题**：现有物理世界模型直接在像素空间预测未来视频，导致世界动态隐含在高维视觉预测器中，缺乏显式的物理推理能力。

🛠 **方法**：提出PhiZero，从野外视频中通过自监督学习“物理语言”（一种紧凑的离散世界状态转移表示），采用“先推理后渲染”范式，先以物理语言序列推理未来演化，再将其渲染为视频。

✨ **主要贡献**：首次将物理语言用于显式世界建模，在生成与理解基准上验证了物理一致性；并展示了其在交互式建模、细粒度动作条件模拟和零样本运动迁移方面的潜力。

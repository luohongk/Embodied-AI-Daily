# DuaDeep-SeqAffinity: Dual-Branch Deep Learning for Tri-Stream Sequence-Based Antibody--Antigen Affinity Prediction

- arXiv: https://arxiv.org/abs/2512.22007v2
- arXiv ID: 2512.22007

---

🔍 **核心问题**：传统抗体-抗原亲和力预测依赖三维结构，成本高且数据稀缺，难以高通量应用。

🛠 **方法**：提出DuaDeep-SeqAffinity，仅用氨基酸序列，将抗原与抗体重链、轻链作为三条独立流，分别用冻结的ESM-2嵌入，并行经过Transformer和CNN双分支后晚期融合，以保留CDR局部信号。

✨ **主要贡献**：在AbRank基准上取得Pearson 0.683、R² 0.460、排序AUC 0.895，显著优于单分支消融模型；注意力与梯度分析显示模型聚焦CDR环和表位残基，可作为无结构依赖的高通量抗体筛选工具。

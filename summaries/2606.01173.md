# Bridging Multimodal Fusion and Expert Routing via Spectral Reliability Descriptors for Robust Object Detection

- arXiv: https://arxiv.org/abs/2606.01173v2
- arXiv ID: 2606.01173

---

🔍 **核心问题**：RGB-infrared（RGB-红外）目标检测中，跨模态融合产生的统计信息通常被丢弃，导致下游模块无法判断当前融合是否可靠，尤其在退化场景下性能下降。

🛠 **方法**：提出一种无参数的7维“光谱可靠性描述符”（提取频带能量、振幅比、相位一致性和跨模态相关性），并将其同时用于两个模块：光谱可靠性融合（SRF）通过门控机制将光谱残差与保守空间基结合，以及可靠性条件专家路由（RCER）将描述符与内容特征结合以引导稀疏专家选择。

✨ **主要贡献**：在DroneVehicle数据集上，六种合成退化下平均保留率提升至95.0%（对比内容-only MoE的92.0%和拼接法的87.9%），模态缺失时增益最大；自然昼夜划分下mAP50提升+5.2/+5.3。消融实验表明，描述符条件路由比专家架构本身带来更大的边际增益，证明将融合可靠性作为显式信号能同时改善自适应融合和条件计算。

# EvalSafetyGap: A Hybrid Survey and Conceptual Framework for LLM Evaluation-Safety Failures

- arXiv: https://arxiv.org/abs/2606.30219v4
- arXiv ID: 2606.30219

---

🔍 **核心问题**：大型语言模型（LLM）的评估指标（如基准分数、奖励信号、安全指标）可能表面提升，但实际反映的能力与对齐属性仍不确定，导致评估与安全之间存在“测量差距”。

🛠 **方法**：通过系统综述373项研究（2018-2026年），构建八流证据分类法，并基于此提出EvalSafetyGap概念框架，采用Goodhart启发的“不稳定性分解”和“对齐三难困境”形式化代理-目标差异问题。

✨ **主要贡献**：首次统一基准有效性研究与对齐失败研究为共享的代理-目标发散问题，提出能力、行为鲁棒性与治理披露应作为独立证据层报告，并给出动态基准、威胁模型预指定等未来研究议程。

# Sparse by Command: Task-Conditional Compute Skipping for Multi-Task Inference Accelerators

- arXiv: https://arxiv.org/abs/2607.22038v1
- arXiv ID: 2607.22038

---

🔍 **核心问题**：多任务推理模型在执行不同任务时，会进行相同的计算，导致大量与任务无关的操作浪费能量和计算周期。

🛠 **方法**：提出一种软硬件协同设计方法，通过轻量级门控网络根据任务输入预测每块的二进制执行掩码，在硬件层面跳过无关计算块，并设计支持掩码跳过的指令集架构和加速器。

✨ **主要贡献**：在保持驾驶质量的前提下，将计算量降低66-76%，设备端延迟减少51-59%（从9.12ms降至3.74-4.44ms），每次推理能耗从263mJ降至108-128mJ。

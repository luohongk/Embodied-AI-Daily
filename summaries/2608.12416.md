# RoboSynChallenge: Mastering Real-World Dexterity via Generalizing Synthesized Manipulation Skills

- arXiv: https://arxiv.org/abs/2608.12416v1
- arXiv ID: 2608.12416

---

🔍 **核心问题**：解决机器人操作泛化能力不足的问题，主要受限于真实世界数据稀缺且多样性不足。

🛠 **方法**：提出RoboSynChallenge统一基准，结合大规模合成数据生成与标准化真实世界评估，并提供了基于Transformer、扩散模型、视觉-语言-动作及世界动作模型的基线实现。

✨ **主要贡献**：构建了涵盖多任务、多环境、多难度级别的评测框架，鼓励利用合成状态-动作数据训练通用策略，并在未见过的真实环境中进行严格验证，推动数据高效、可泛化的操作智能发展。

# LLMs as Feature Engineers for Text-and-Tabular Prediction

- arXiv: https://arxiv.org/abs/2609.21894v1
- arXiv ID: 2609.21894

---

🔍 **核心问题**：如何从非结构化文本中自动提取可解释、受模式约束的分类特征，以提升表格预测模型的性能。

🛠 **方法**：提出迭代框架，由生成器LLM提出语义定义、提取器LLM生成特征、下游表格模型评估性能，并将模型错误（如AUC排序反转）转化为自然语言反馈来引导LLM优化搜索。

✨ **主要贡献**：错误驱动的循环使特征发现速度提升最高达3倍；生成特征与TF-IDF和稠密嵌入结合时严格优于任何子集，并在SHAP重要性排名中占主导，提供完全透明的语义审计轨迹。

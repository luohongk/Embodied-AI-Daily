# World Action Models in Real Time: An Empirical Study of Smooth Execution via Asynchronous Deployment

- arXiv: https://arxiv.org/abs/2608.01880v1
- arXiv ID: 2608.01880

---

🔍 **核心问题**：World Action Models因迭代去噪产生高推理延迟，导致机器人执行中出现停顿、动作过时和不连续，影响实时控制的流畅性。

🛠 **方法**：在10 Hz双臂机器人上系统比较六种异步部署策略（同步执行、纯异步切换、事后动作混合、去噪时混合、推理时速度引导、前缀条件生成），结合离线轨迹分析与在线动态操作、精密放置和长时任务实验。

✨ **主要贡献**：发现观测、预测与执行命令间的精确时间对齐是流畅控制的基本前提，对齐误差无法仅靠混合修正；前缀条件生成通过训练中学习一致的动作延续，在任务性能、执行速度和轨迹平滑度上取得最佳平衡，为高延迟World Action Models的实时部署提供了实用指导。

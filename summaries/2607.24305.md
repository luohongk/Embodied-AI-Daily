# Domain-Decomposition Neural Surrogates for Scalable Decentralized Ensemble Kalman Filter Based Parameter Identification in High-Dimensional Stochastic PDEs

- arXiv: https://arxiv.org/abs/2607.24305v1
- arXiv ID: 2607.24305

---

🔍 **核心问题**：在高维随机偏微分方程的参数识别中，传统集合卡尔曼滤波（EnKF）需要大量样本进行预测，导致计算成本过高。

🛠 **方法**：提出基于神经网络（NN）的替代模型，并引入增广拉格朗日乘子域分解法（DDM），将全局问题分解为局部子问题，独立优化局部NN模型后再进行全局通信耦合；同时采用分布式去中心化EnKF，各局部估计器利用本地信息更新参数，相邻子域间通信重建一致全局估计。

✨ **主要贡献**：显著减少NN参数数量并提高局部近似精度，在三维材料参数识别问题中，该方法能以较低计算成本获得与EnKF和MCMC相当的参数估计结果，尤其优于MCMC的计算效率。

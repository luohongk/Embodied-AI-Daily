# Tools Are Not Islands: Set-Level Tool Retrieval for LLM Agents via Query-Conditioned Hyperedge Prediction

- arXiv: https://arxiv.org/abs/2607.25718v2
- arXiv ID: 2607.25718

---

🔍 **核心问题**：现有工具检索方法孤立评估每个工具或顺序组合工具集，无法整体评估候选工具集的联合效用，导致LLM代理在调用外部工具时效率低下。

🛠 **方法**：提出HYSET方法，将工具检索建模为基于查询条件的超边预测问题，在工具共调用超图上通过基数特定的交互捕捉工具兼容性，并将工具集作为评分单元。

✨ **主要贡献**：首次将工具集作为整体评分单元，支持零样本/少样本迁移，在ToolBench上工具检索和端到端任务成功率均超越现有最优方法。

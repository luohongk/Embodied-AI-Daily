# Solving In-Table Prediction Problems by Deep Neural Networks with Performance Evaluation Using Synthetic Data

- arXiv: https://arxiv.org/abs/2609.01262v1
- arXiv ID: 2609.01262

---

🔍 **核心问题**：本文研究“表内预测”（In-Table Prediction, ITP）问题，即利用深度神经网络基于表中已知列预测任意选定列的数值，而非传统监督学习中的固定目标特征。

🛠 **方法**：采用自监督学习策略，随机掩蔽部分列作为预测目标；提出一种新型神经网络层以同时嵌入连续数值和缺失值；基于预定义列关系生成合成数据，并评估MLP、ResNet和Transformer三种架构的性能。

✨ **主要贡献**：首次系统探讨ITP的三种应用场景；在合成数据下发现基于注意力机制的Transformer在训练样本充足且嵌入长度较大时优于其他网络；强调该结论限于小规模列数的受控条件，属于初步探索。

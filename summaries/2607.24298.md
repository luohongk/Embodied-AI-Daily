# UMI3D: Robust 3D Generation on Unconstrained Multi-Image Inputs via Simultaneous Focus Cross-Attention Routing

- arXiv: https://arxiv.org/abs/2607.24298v1
- arXiv ID: 2607.24298

---

🔍 **核心问题**：现有单图像3D生成模型在处理非约束多图像输入时，因缺乏跨注意力机制中每个3D体素应信任哪张图像的决策原则，导致几何扭曲、纹理过平滑和颜色混乱等问题。

🛠 **方法**：提出UMI3D框架，核心是“同步聚焦跨注意力”（SFC-Attn），在去噪步骤中同时激活所有条件图像，但允许每个体素仅聚焦于最能解释它的单张图像；并设计无需外部匹配或分割的“体素参考分数”（VRS）来度量体素-图像亲和性，实现路由。

✨ **主要贡献**：无需训练、即插即用，显著提升单图像3D生成框架在多图像场景下的性能，在多种任务中验证了鲁棒性和有效性。

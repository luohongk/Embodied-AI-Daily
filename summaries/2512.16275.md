# GFLAN: Generative Functional Layouts

- arXiv: https://arxiv.org/abs/2512.16275v2
- arXiv ID: 2512.16275

---

🔍 **核心问题**：解决自动楼层平面图生成中拓扑关系优先于几何实现、功能约束传播与动线模式涌现等建筑推理难题，实现统一的计算框架。

🛠 **方法**：提出GFLAN生成框架，将平面图合成分解为拓扑规划（阶段A：双编码器卷积网络顺序分配房间质心）和几何实现（阶段B：Transformer增强图神经网络联合回归房间边界）两阶段。

✨ **主要贡献**：通过显式分解拓扑与几何任务，突破端到端生成方法局限，实现从单一外部边界和入口位置出发的结构化布局生成。

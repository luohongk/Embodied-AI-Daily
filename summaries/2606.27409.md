# Delayed Verification Destabilizes Multi-Agent LLM Belief: Instability Thresholds and Optimal Corrector Placement

- arXiv: https://arxiv.org/abs/2606.27409v2
- arXiv ID: 2606.27409

---

🔍 **核心问题**：多智能体LLM系统中验证存在延迟，延迟期间虚假信息会在智能体网络中传播，论文研究这种延迟验证何时会导致系统信念不稳定。

🛠 **方法**：将过程建模为带接地校正节点的图上的延迟共识，利用接地拉普拉斯谱分解推导验证剂量的闭式稳定性阈值，并构建超模放置目标与贪心(1-1/e)近似算法来分配校正器预算。

✨ **主要贡献**：揭示了校正过强或延迟过久会使共识转为振荡，最不稳定情形出现在通信与验证延迟相等时（延迟为2时阈值为黄金分割倒数），并在五个开源模型上验证了剂量-延迟振荡；同时发现接地事实问答因真值成为吸收边界而消除该效应，表明不稳定仅特定于带符号信念任务。

# ReSplat: Learning Recurrent Gaussian Splatting

- arXiv: https://arxiv.org/abs/2510.08575v4
- arXiv ID: 2510.08575

---

🔍 **核心问题**：现有前馈高斯泼溅模型依赖单次前向推理，性能受限，且生成的高斯数量多、计算开销大。

🛠 **方法**：提出ReSplat，一种前馈循环高斯泼溅模型，利用渲染误差作为反馈信号迭代更新3D高斯，无需显式计算梯度；同时引入紧凑重建模型在16倍下采样空间初始化，减少高斯数量。

✨ **主要贡献**：在多种视图数（2-32）、分辨率（256×256至540×960）和数据集（DL3DV、RealEstate10K、ACID）上达到最先进性能，同时显著减少高斯数量并提升渲染速度，且对未见数据分布具有良好泛化性。

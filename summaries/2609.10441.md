# ConvMem: Convolutional Memory for Long-Context Reasoning

- arXiv: https://arxiv.org/abs/2609.10441v1
- arXiv ID: 2609.10441

---

🔍 **核心问题**：大语言模型受限于固定上下文长度，难以处理超长文本；现有顺序式方法（如MemAgent）虽能扩展有效上下文，但存在高延迟、需昂贵强化学习训练且易过拟合的问题。

🛠 **方法**：提出ConvMem——一种免训练、高度可并行的框架，将长上下文推理重构为分层卷积：把针对特定查询提示的LLM视为卷积核，分层摘要文本片段，并引入可配置步长、跳跃连接和多核卷积来增强证据捕获与语义分解。

✨ **主要贡献**：将线性推理链变为对数级树形结构，缓解误差累积并实现文本片段与推理线程的大规模并行；在RULER-HotpotQA和RULER-2WikiMultiHopQA上超越免训练基线，且避免了RL训练模型在分布外任务上的过拟合风险。

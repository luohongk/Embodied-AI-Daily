# Automated ACL Footprint Identification Using 3D Deep Learning

- arXiv: https://arxiv.org/abs/2608.18012v1
- arXiv ID: 2608.18012

---

🔍 **核心问题**：ACL重建手术中股骨隧道定位不准是导致手术失败的主要原因，现有AI研究多集中于ACL分割和撕裂分类，缺乏对ACL股骨足迹中心的自动识别方法。

🛠 **方法**：开发了两种3D深度学习模型——基于3D股骨网格的图卷积神经网络几何模型，以及基于3D MR图像的标志点增强识别模型，使用公开数据库中4883个右膝和3087个左膝图像集进行训练和测试。

✨ **主要贡献**：两种模型均表现优异，其中基于图像的方法平均误差为2.1mm，优于基于模型的方法（2.8mm），证明3D深度学习可有效实现ACL足迹定位，有望提升ACL重建手术的准确性。

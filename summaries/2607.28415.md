# QQWorld: Quantile-Quantile Matching for World Model Regularization

- arXiv: https://arxiv.org/abs/2607.28415v1
- arXiv ID: 2607.28415

---

🔍 **核心问题**：潜空间世界模型（如LeWorldModel）在正则化时使用Epps-Pulley目标，但其纠正梯度在尾部样本上迅速消失，导致潜在分布出现重尾偏差，影响规划性能。

🛠 **方法**：提出QQWorld，用分位数-分位数匹配目标替代EP，将投影后的潜在样本与秩匹配的高斯分位数直接对齐，从而在尾部保持有效梯度；并引入跨批次QQ，利用先前批次的分离样本扩大有效排序池，同时权衡偏差与方差。

✨ **主要贡献**：在四个控制环境中，QQWorld显著提升了LeWM的平均规划成功率，同时实现更好的高斯对齐和更薄的潜在分布尾部，验证了其在分布正则化上的有效性。

# Missing Bridges: Composition-Aware Active Imitation Learning

- arXiv: https://arxiv.org/abs/2609.18004v1
- arXiv ID: 2609.18004

---

🔍 **核心问题**：在结构化多任务域中，任务数量随起始-目标组合呈组合式增长，而现有主动模仿学习方法仅按对专家策略的信息增益选择请求，忽视了可复用组合行为的价值。

🛠 **方法**：提出 AALT（自适应潜在拓扑智能体），将已有演示组织为潜在枢纽状态拓扑，识别能一次性解锁大量任务的高价值“桥梁演示”并向专家查询，推理时在拓扑上规划并以扩散策略条件化每次枢纽转移。

✨ **主要贡献**：证明该目标与任务可达性的信息增益形式相关；在 72 任务的 UR5e 仿真取物域中，仅用 3 个演示（5 次转移）即从 42/72 提升至 72/72 全部成功，而最强基线用 20 个演示（98 次转移）仅达 88.6%。

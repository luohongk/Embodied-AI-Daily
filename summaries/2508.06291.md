# VLEM: Real-Time 3D Vision-Language Embedding Mapping

- arXiv: https://arxiv.org/abs/2508.06291v2
- arXiv ID: 2508.06291

---

🔍 **核心问题**：如何在仅依赖原始RGB-D流、无需真值位姿的条件下，将2D视觉-语言嵌入实时集成到全局一致、度量精确的3D表示中，实现机器人对场景的语义理解与自然语言查询。

🛠 **方法**：提出VLEM框架，将来自不同后端的像素对齐2D视觉-语言嵌入融合进统一的3D度量地图，支持实时运行并克服计算与内存约束。

✨ **主要贡献**：相比ConceptFusion、Open-Fusion和RayFronts，VLEM在开放集分割上表现更优且表示更紧凑，并成功应用于实时机器人操作与移动建图任务。

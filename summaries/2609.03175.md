# Real-Time Shape Control of Multi-Segment Soft Robotic Arms Using Koopman Operators with Global and Local Observables

- arXiv: https://arxiv.org/abs/2609.03175v1
- arXiv ID: 2609.03175

---

🔍 **核心问题**：多段软体机械臂的形状控制因高维非线性和段间耦合而极具挑战，仅依赖全局形状误差作为控制目标难以实现高精度控制。

🛠 **方法**：提出一种基于Koopman算子的模型预测控制框架，融合全局与局部可观测量，实现对多段软体机械臂的实时形状控制。

✨ **主要贡献**：数值实验验证了控制器可扩展至10段独立驱动机械臂；物理实验实现了3段和5段机械臂的实时形状控制（末端速度达0.6 m/s），具备无需重训练的鲁棒跟踪能力（可承受400 g负载和7 N扰动），并展示了在受限空间中的巡检应用潜力。

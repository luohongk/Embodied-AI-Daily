# WAM-OPD: On-Policy Distillation for World Action Models

- arXiv: https://arxiv.org/abs/2608.22364v1
- arXiv ID: 2608.22364

---

🔍 **核心问题**：世界动作模型（WAM）在蒸馏过程中，加速后的学生模型可能丧失任务能力，并在遇到离线数据覆盖不足的状态时表现不佳。本文研究能否通过在线策略蒸馏（OPD）修复学生模型，而无需依赖稀疏奖励的强化学习。

🛠 **方法**：提出WAM-OPD，一种部署一致的训练后优化方案。学生模型在环境中行动并决定历史分布，冻结的教师模型为学生历史生成连贯的视频和动作目标，学生动作分支在自身生成的视频计划下训练，并通过联合视频与动作损失更新共享骨干中的轻量适配器，辅以动作流匹配正则化。

✨ **主要贡献**：在RoboTwin 2.0的两个任务上，Flash-WAM的成功率从0.0%提升至58.3%（HANDOVER MIC），从16.7%提升至33.3%（PUT OBJECT CABINET）。结果表明，对学生诱导历史进行密集教师监督是视频优先WAM的有效后训练接口，但结果仅为初步能力验证，不证明广泛或均匀的泛化能力。

# ExpBoN: Exponential-Noise Best-of-$n$ for Efficient Test-Time LLM Alignment

- arXiv: https://arxiv.org/abs/2609.21899v1
- arXiv ID: 2609.21899

---

🔍 **核心问题**：Best-of-$n$（BoN）采样是一种简单有效的推理时对齐方法，但硬最大化只能对奖励与分布偏移之间的权衡进行粗糙控制，需要更平滑且理论性质更优的软BoN方法。

🛠 **方法**：提出ExpBoN，一种基于指数噪声"report-noisy-max"机制的软BoN方法，具有精确的有限-$n$分解，并将其集成到引导投机推理（GSI）框架中形成ExpGSI，用于高效的奖励引导LLM对齐。

✨ **主要贡献**：证明了ExpBoN在全变差距离、期望奖励和双向KL散度上均具有指数级快速收敛，并给出了收敛性与遗憾行为的完整理论分析；ExpGSI在MATH500、MMLU-STEM和Minerva Math上保持相当精度的同时，将Qwen2.5-Math的计算量减少14%–39%，Qwen3在$n=16$时最多减少45%。

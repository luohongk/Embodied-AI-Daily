# Contact-Aware Incremental Model Predictive Control for an Underactuated Aerial Manipulator

- arXiv: https://arxiv.org/abs/2609.11661v1
- arXiv ID: 2609.11661

---

🔍 **核心问题**：如何在欠驱动空中机械臂平台上实现鲁棒的接触感知控制，完成空中书写等需要精确末端位姿与接触力跟踪的任务。

🛠 **方法**：结合非线性模型预测控制（NMPC）实现小参考穿透深度下的末端位置与法向力精确跟踪，并采用全身增量非线性动态逆（INDI）应对接触过程中的摩擦与气动扰动。

✨ **主要贡献**：在标准欠驱动四旋翼配简单刚性单连杆臂的平台上，无需全驱动平台、复杂机械臂或专用力/力矩传感器，即实现了五自由度末端位姿与接触力的鲁棒同步跟踪，并通过仿真与真实实验（含斜面、多参考力、不同摩擦及风扰）验证。

# A Visuo-Tactile Data Collection System with Haptic Feedback for Coarse-to-Fine Imitation Learning

- arXiv: https://arxiv.org/abs/2605.08757v2
- arXiv ID: 2605.08757

---

🔍 **核心问题**：传统遥操作数据采集系统将操作员与接触力隔离，难以演示精细力调节，导致模仿学习缺乏接触丰富的演示数据。

🛠 **方法**：提出一种包含直接驱动夹爪（保留自然触觉反馈）、视觉传感器、定制触觉阵列和手柄按钮的系统，操作员可实时标注任务关键区域，融合手内力感知与时间标注生成多模态数据集。

✨ **主要贡献**：设计了支持粗到细模仿学习的触觉-视觉数据采集系统，通过自然触觉反馈和实时时间标注，生成结构化的接触丰富演示，为高质量操作策略开发提供关键数据支持。

# LoDA: A Level of Detection Aware Method and a Multimodal Sensing Benchmark for Object Level Change Detection

- arXiv: https://arxiv.org/abs/2608.05356v1
- arXiv ID: 2608.05356

---

🔍 **核心问题**：针对多时相城市LiDAR点云中物体级变化检测缺乏明确检测限和一致物体级标签的问题，提出一种端到端的物体级3D变化检测方法。

🛠 **方法**：构建了集成检测限感知配准、基于几何代理的规则化语义与实例分割，以及高度、体积和表面法向位移线索的流水线，将位姿不确定性传播到空间变化的检测限中，并抑制误检。

✨ **主要贡献**：提出了LoDA基准（含Subiaco区多模态车辆LiDAR地图及物体级标注），在自建基准上达到95.0%准确率、90.8%宏F1和83.0%宏IoU，超过最强基线8.7 IoU点；在公开Urb3DCD-V2上mAcc和mIoUch分别提升1.36和3.18点。

# AI Control Scientist: LLM-driven Agentic System for Automated Control Design

- arXiv: https://arxiv.org/abs/2608.26780v1
- arXiv ID: 2608.26780

---

🔍 **核心问题**：传统控制系统设计依赖专家知识和大量手动参数调整，效率低且难以扩展，难以满足现代工业（如化工温控、航空发动机控制）的自动化需求。

🛠 **方法**：提出AI Control Scientist（AICS），一个由大语言模型驱动的智能体系统，包含三个协作模块：任务建模智能体（将语言需求转化为工程约束）、控制器设计智能体（生成控制器结构和可执行代码）、参数调优智能体（基于闭环性能标准优化参数）。

✨ **主要贡献**：首次实现从自然语言需求到优化控制器的全自动生成，在多种代表性控制系统的设计成功率和优化效率上均优于现有自动化基线，有望将控制系统设计从人工驱动转变为智能体驱动，并推广至模型预测控制等高级系统。

# SkillForge: Evolving Verifiable Skills for Reinforcement Learning Agents

- arXiv: https://arxiv.org/abs/2608.24747v1
- arXiv ID: 2608.24747

---

🔍 **核心问题**：现有基于强化学习的LLM智能体在训练后缺乏跨回合的可复用知识积累，且技能库只增不改，无法验证已存技能是否仍然有效。

🛠 **方法**：提出SkillForge框架，通过显式技能调用使强化学习同时优化环境动作和技能选择，并引入基于证据的技能验证与多路径技能归纳机制，实现技能的持续进化与质量维护。

✨ **主要贡献**：在ALFWorld、WebShop和AppWorld三个基准上，SkillForge一致优于SkillRL，验证了持续验证与精炼技能能有效训练更强的LLM智能体。

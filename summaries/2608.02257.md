# Learning Panorama-Aware VLA for Mobile Manipulation with Whole-Body Teleoperation

- arXiv: https://arxiv.org/abs/2608.02257v1
- arXiv ID: 2608.02257

---

🔍 **核心问题**：移动操作机器人面临两个挑战——数据层面缺乏高质量全身演示数据，模型层面现有VLA策略依赖局部相机视野，难以实现全局空间理解。

🛠 **方法**：开发了全身遥操作系统，通过单一VR接口协调控制轮式双臂机器人，采集5.5小时多模态演示数据；提出PanoVLA策略，基于Mixture-of-Transformers架构，通过全景编码与融合模块将全景观测、语言指令和机器人状态有效整合以生成动作。

✨ **主要贡献**：在四项真实世界移动操作任务中，PanoVLA平均阶段完成率达91.3%，端到端成功率达73.4%，显著优于局部视野基线，证明全景空间上下文能提升移动机器人的空间理解与闭环操作性能。

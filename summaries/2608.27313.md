# A Finite Sample Analysis for Quantile Temporal Difference Learning in Distributional Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.27313v1
- arXiv ID: 2608.27313

---

🔍 **核心问题**：本文旨在为分布式强化学习中的分位数时序差分（QTD）算法提供全局有限样本保证，解决其收敛速率和样本复杂度缺乏严格理论分析的问题。

🛠 **方法**：通过分离两种稳定性机制进行分析——利用奖励累积分布函数的序单调性和分布Bellman算子的$W_\infty$压缩性进行全局比较论证，将任意初始化的迭代拉入局部邻域；随后在邻域内线性化QTD均值场，利用其Jacobian矩阵（非奇异$M$-矩阵）和正半群进行方差敏感的鞅分析。

✨ **主要贡献**：首次建立了QTD的全局有限样本界，证明在步长$\alpha_t=c(t+1)^{-a}$（$a\in(1/2,1)$）下，最后迭代的波动阶为$\widetilde O(T^{-a/2}/\sqrt{1-\gamma})$，且不依赖分位数数量；同时清晰区分了局部随机波动与全局样本复杂度，指出最坏情况下瞬态和预热时间依赖于最小Bellman目标密度（阶为$m^{-1}$）。

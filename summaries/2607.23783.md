# $N_0$-TWAM: Scaling Tactile-Native World-Action Model for Contact-Rich Manipulation

- arXiv: https://arxiv.org/abs/2607.23783v1
- arXiv ID: 2607.23783

---

🔍 **核心问题**：解决接触密集型操作任务中，机器人缺乏对触觉与视觉联合预测能力的问题，难以实现精细操作。

🛠 **方法**：提出触觉原生世界-动作模型 $N_0$-TWAM，采用统一力触觉表示NeoForce构建物理接触信号，并引入触觉接触事件进行任务阶段划分，同时使用非对称混合Transformer架构（全宽专家用于视频预测，轻量专家用于动作和触觉预测）提升实时效率。

✨ **主要贡献**：首次大规模预训练触觉世界-动作模型（覆盖6种机器人形态、450个任务），在真实与仿真基准上验证了其预测视觉、触觉和动作的能力，证明了数据规模扩展对精确触觉与动作预测的益处，为开放接触密集型任务的精细操作奠定基础。

# VLM- and LLM-Driven Multi-Agent System for PET Image Denoising

- arXiv: https://arxiv.org/abs/2608.13791v1
- arXiv ID: 2608.13791

---

🔍 **核心问题**：PET成像存在空间分辨率低和信噪比低的问题，现有深度学习去噪方法在实际应用中需要多个专用模型和专家干预，缺乏自动化决策能力。

🛠 **方法**：提出一种由视觉语言模型（VLM）和大型语言模型（LLM）驱动的多智能体PET去噪框架，动态评估图像质量和病灶状态，自主选择最优去噪模型与参数，并支持带回滚机制的闭环反馈。

✨ **主要贡献**：在Siemens Biograph Vision Quadra PET/CT数据上（1/20和1/50低剂量），完整框架在PSNR和SSIM上均优于UNet、GAN和DDPM基线，验证了闭环多智能体框架自适应调整去噪策略的可行性。

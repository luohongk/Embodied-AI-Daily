# MobileDreamer: Generative Sketch World Model for GUI Agent

- arXiv: https://arxiv.org/abs/2601.04035v2
- arXiv ID: 2601.04035

---

🔍 **核心问题**：现有移动GUI智能体多为反应式，仅依赖当前屏幕决策，在长时程任务中表现受限，缺乏对未来状态的空间感知预测能力。

🛠 **方法**：提出MobileDreamer框架，包含文本草图世界模型（将图像转化为任务相关草图并采用序不变学习保留空间信息）和基于世界模型预测的滚动想象策略，用于优化GUI智能体的动作选择。

✨ **主要贡献**：在Android World上取得SOTA性能，任务成功率提升5.25%；世界模型评估验证了文本草图建模能准确预测关键GUI元素，为移动GUI智能体提供了高效的前瞻决策能力。

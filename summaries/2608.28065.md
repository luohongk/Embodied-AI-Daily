# Learning to Allocate Incentives for Incentivized Advertising via Offline Model-Based Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.28065v1
- arXiv ID: 2608.28065

---

🔍 **核心问题**：在激励广告中，平台需在广告展示前承诺奖励以促使用户点击，但需平衡前期激励与后期广告收入，同时考虑延迟收益、成本敏感性和跨期影响，现有研究缺乏针对该场景的决策算法。

🛠 **方法**：将激励分配建模为马尔可夫决策过程（MDP），提出离线模型强化学习框架，学习用户反馈和广告收入的世界模型，并采用保守策略优化；另设计独立反事实评分器，基于留出日志评估策略，无需在线曝光即可预选策略。

✨ **主要贡献**：首次系统解决激励广告的序贯分配问题；在工业数据和在线A/B测试中验证框架有效性，离线评分器提供稳定信号；部署路径显示MB-IQL较TD3+BC提升人均净利润7.96%，而退化为IQL则降低6.56%（均p<0.0001）。

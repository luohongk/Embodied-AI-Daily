# MemVLN: Episodic and Procedural Memory for Vision-and-Language Navigation

- arXiv: https://arxiv.org/abs/2607.23504v1
- arXiv ID: 2607.23504

---

🔍 **核心问题**：在连续环境下的视觉语言导航任务中，现有基于视频的方法难以同时兼顾长程视觉历史的一致性维护与低延迟动作执行。

🛠 **方法**：提出MemVLN框架，采用视觉编码器处理连续观测，结合大语言模型（LLM）理解指令并生成动作；核心是引入金字塔分辨率的**情景记忆**管理机制，聚焦当前感知并压缩长期历史，同时设计**程序记忆**通过原子级中层动作词汇表加速动作生成，避免自回归解码延迟。

✨ **主要贡献**：在VLN-CE任务上，MemVLN-4B在R2R和RxR数据集上分别比基线Qwen3-VL-4B提升5.8%和9.7%的成功率，推理速度提升7倍（达14 FPS），实现实时推理效率与最先进性能。

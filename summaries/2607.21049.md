# GuidedAttention: Interpretable and Correctable Visual Attention for OOD-Robust Robot Manipulation via Imitation Learning

- arXiv: https://arxiv.org/abs/2607.21049v1
- arXiv ID: 2607.21049

---

🔍 **核心问题**：端到端视觉运动策略缺乏可解释性，人类难以理解或纠正模型的视觉注意力，导致在分布外（OOD）场景下性能下降。

🛠 **方法**：提出GuidedAttention框架，通过从图像中预测任务相关的注意力关键点作为显式中间表示，并以此条件化扩散动作策略；用户可在初始化时检查并修正关键点，修正后的注意力由跟踪模块自动传播至整个执行过程。

✨ **主要贡献**：首次将可解释且可纠正的视觉注意力引入模仿学习，显著提升机器人操作性能，尤其在位置和外观分布外条件下表现鲁棒，仿真与真实实验均验证有效性。

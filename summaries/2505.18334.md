# CoopReflect: Towards Natural Language Communication for Cooperative Autonomous Driving via Multi-Agent Learning

- arXiv: https://arxiv.org/abs/2505.18334v2
- arXiv ID: 2505.18334

---

🔍 **核心问题**：如何通过自然语言实现车辆间（V2V）通信，使自动驾驶车辆不仅能相互协作，还能与人类驾驶员协同，从而提升行车安全与交通效率。

🛠 **方法**：提出多智能体学习框架CoopReflect，基于大语言模型（LLM）构建驾驶智能体，通过试错和多智能体复盘（debriefing）学习生成自然语言消息与高层决策，并在新仿真环境TalkingVehiclesGym中训练与测试。

✨ **主要贡献**：CoopReflect生成的通信消息比现有基线更有意义且更易被人类理解，显著增强协作能力；通过将场景特定知识蒸馏为统一语言模型策略，实现跨场景泛化并大幅降低决策延迟。

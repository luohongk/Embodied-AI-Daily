# REFORGE: A Method for Benchmarking LLMs' Reverse Engineering Capabilities in Decompiled Binary Function Naming

- arXiv: https://arxiv.org/abs/2607.07738v2
- arXiv ID: 2607.07738

---

🔍 **核心问题**：现有基准测试在评估大语言模型（LLM）逆向工程能力时，忽略了编译器优化导致的二进制与源代码对齐不可靠问题，导致评估结果存在偏差。

🛠 **方法**：提出Reforge流程，通过编译、DWARF与语法提取、对齐、反编译构建函数级真实标签，并设计八门置信漏斗与三层分级机制来量化对齐不确定性。

✨ **主要贡献**：证明优化级别下高置信度对齐率从87.2%降至65.9%，揭示幸存者偏差会夸大性能衰减；通过7个LLM的函数命名评估验证了不确定性感知基准测试的有效性。

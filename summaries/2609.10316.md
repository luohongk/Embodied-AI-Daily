# Ensembling LLMs for AI-Augmented Cybersecurity Software Requirements Generation

- arXiv: https://arxiv.org/abs/2609.10316v1
- arXiv ID: 2609.10316

---

🔍 **核心问题**：如何将网络安全标准中的高层控制项可靠地转化为具体的系统需求，克服单一LLM输出不稳定、遗漏有效防护措施且产生幻觉的问题。

🛠 **方法**：提出生成后集成（post-generation ensembling）策略，用信息检索中的数据融合算子聚合多次随机运行结果，包括Uniform融合（奖励跨运行一致性）和Naive-Bayes融合（按估计可靠性加权每次运行）。

✨ **主要贡献**：在10个ISO/IEC 27002:2022控制项、12种配置共24次运行上验证，融合方法将有效需求排在幻觉之前，PR-AUC和ROC-AUC分别达0.864和0.869，显著超越最佳单一配置（提升0.142和0.118），且增益在92%以上的自助采样中保持稳定，仅用非前沿模型即可实现更广覆盖和更优审查队列。

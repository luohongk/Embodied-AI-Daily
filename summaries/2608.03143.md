# From Routes to Steps: Separating Semantic Progress from Local Execution in Vision-and-Language Navigation

- arXiv: https://arxiv.org/abs/2608.03143v1
- arXiv ID: 2608.03143

---

🔍 **核心问题**：视觉语言导航（VLN）中，现有方法仅通过下一步动作预测来监督智能体，导致语义进度跟踪错误与局部执行错误难以区分，智能体在偏离路线后无法纠正进度状态。

🛠 **方法**：提出Route2Step框架，将语义进度跟踪与动作生成解耦。指令分析模块（M_IA）从全局指令和视觉历史预测当前进度状态，动作生成模块（M_AG）基于该状态生成局部动作块；通过E-SPA步骤对齐程序自动关联子指令与演示片段，无需人工时间标注即可监督进度状态。

✨ **主要贡献**：在R2R-CE上，SR从48.1%提升至55.3%，SPL从43.3%提升至48.2%，仅需190K状态级纠正样本和11.5K直接动作监督样本；在真实室内外环境中验证了实用性。

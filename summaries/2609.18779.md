# CERA-MoA: Co-Evolving Routing Mechanisms with Continually Learning LLM Agents

- arXiv: https://arxiv.org/abs/2609.18779v1
- arXiv ID: 2609.18779

---

🔍 **核心问题**：现有 Mixture-of-Agents（MoA）范式将查询路由与智能体微调割裂处理，导致路由策略无法适应智能体能力的动态演化，智能体也难以实现数据驱动的协同专业化。

🛠 **方法**：提出 CERA-MoA 迭代式强化学习框架，让动态路由器与独立智能体策略协同演化；设计基于中间层隐状态的预测性熟悉度估计器（避免完整 rollout 开销），并据此采用累积阈值自适应路由机制动态激活最小智能体子集，同时按能力主动分配针对性训练样本。

✨ **主要贡献**：实现路由与智能体能力的共同演化，在任务性能与效率间取得平衡，并促进智能体能力分化；在多个领域实验中超越当前最优的静态智能体路由与固定工作流微调基线。

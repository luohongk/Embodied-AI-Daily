# Kernel-SDF: An Open-Source Library for Real-Time Signed Distance Function Estimation using Kernel Regression

- arXiv: https://arxiv.org/abs/2603.29227v2
- arXiv ID: 2603.29227

---

🔍 **核心问题**：现有实时符号距离函数（SDF）估计方法在流式传感器数据处理中存在局限性，如体素方法分辨率固定且缺乏不确定性量化，神经网络训练耗时，高斯过程方法可扩展性差、符号估计不准且不确定性校准困难。

🛠 **方法**：提出开源库Kernel-SDF，采用核回归前端学习连续占据场，再通过高斯回归后端利用前端表面边界样本估计精确SDF，实现实时、带校准不确定性的SDF计算。

✨ **主要贡献**：在保持实时性能的同时，提供比现有方法更精确的SDF、梯度、不确定性和网格构建，适用于需要可靠不确定性感知几何的机器人任务。

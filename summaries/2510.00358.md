# DiSA-IQL: Offline Reinforcement Learning for Robust Soft Robot Control under Distribution Shifts

- arXiv: https://arxiv.org/abs/2510.00358v2
- arXiv ID: 2510.00358

---

🔍 **核心问题**：软体蛇形机器人因高度非线性动力学难以控制，在线强化学习训练成本高且有风险，而离线强化学习面临分布偏移问题，导致对未见场景的泛化能力下降。

🛠 **方法**：提出DiSA-IQL（分布偏移感知的隐式Q学习），在IQL基础上引入鲁棒性调制，通过惩罚不可靠的状态-动作对来缓解分布偏移。

✨ **主要贡献**：在目标到达任务中，DiSA-IQL在分布内和分布外评估下均优于基线模型（BC、CQL、原始IQL），实现了更高的成功率、更平滑的轨迹和更强的鲁棒性。

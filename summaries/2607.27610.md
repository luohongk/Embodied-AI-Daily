# Kalman Meets Curriculum: Efficient Dynamic Prompt Selection for Adaptive RL Finetuning

- arXiv: https://arxiv.org/abs/2607.27610v1
- arXiv ID: 2607.27610

---

🔍 **核心问题**：在强化学习微调大语言模型时，如何高效选择难度适中的提示（prompt），以适配当前策略的动态变化，避免静态难度预测在非平稳训练中的失效。

🛠 **方法**：提出KGPS方法，将提示选择重构为动态状态估计问题，用线性高斯状态空间模型建模提示的潜在成功率，并通过卡尔曼滤波器维护难度后验分布，结合策略更新幅度耦合过程噪声，最终按后验期望训练效用选择提示。

✨ **主要贡献**：KGPS无需额外rollout即可自适应策略漂移，在数学、规划和几何推理基准及多种RL算法上，显著提升最终准确率和rollout效率；例如在DeepSeek-R1-Distill-7B上，相比DS减少83%的rollout，同时平均性能提升0.12分，达到在线提示选择方法的最优水平。

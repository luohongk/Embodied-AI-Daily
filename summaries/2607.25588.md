# System-Aware Adaptive CSI Feedback via RL-Guided Autoencoder Switching in Multi-User MIMO System

- arXiv: https://arxiv.org/abs/2607.25588v1
- arXiv ID: 2607.25588

---

🔍 **核心问题**：在大规模多输入多输出（mMIMO）系统中，传统的固定压缩比信道状态信息（CSI）反馈方案无法适应非平稳信道环境，导致重建精度与信令开销之间的权衡效率低下。

🛠 **方法**：提出一种基于强化学习（RL）的自适应CSI反馈框架，通过RL智能体在预训练的多速率自编码器（AE）池中，为每个用户动态选择最优压缩比，并引入系统感知的奖励函数，综合考虑频谱效率、反馈开销和计算成本。

✨ **主要贡献**：相比固定压缩方案和自适应基线，该方法在动态无线条件下将CSI反馈成本降低53.4%以上，平均下行和速率提升53.64%，归一化均方误差（NMSE）降低22.38%，实现了更高效的速率-精度-反馈权衡。

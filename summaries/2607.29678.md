# TokTier: Exact Stateful Tokenization for Agentic LLM Serving

- arXiv: https://arxiv.org/abs/2607.29678v1
- arXiv ID: 2607.29678

---

🔍 **核心问题**：LLM服务系统在缓存提示词KV状态时，前端仍会对完整请求文本重复进行分词，导致编码智能体场景下长对话续写时延迟显著，分词耗时最高占首token时间的64%。

🛠 **方法**：提出TokTier有状态分词服务，对会话续写仅重分词追加点附近的小窗口，并通过稳定边界检查确认后拼接，失败则扩大窗口或回退全量分词；对无复用前缀的请求，将GPT家族正则预分词分解为局部规则，在GPU上执行精确预分词与BPE，并用影子验证器抽样复核线上流量。

✨ **主要贡献**：在17种分词器、12.4TB语料和9.3万+智能体步骤上实现零分歧；增量修复100K至3M字符仅需0.5-1.1ms，比HF快437倍，比最强缓存基线快2.1倍；GPU全量分词1M字符仅0.87ms；集成vLLM后中位首token时间降低16-34%，P99降低23%，在50ms P99目标下用4个修复核+1块GPU支撑1821请求/秒，远超16核无状态前端的40请求/秒上限。

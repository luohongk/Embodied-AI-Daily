# StreamTTT: Reconciling Real-Time Perception and Long-Term Memory in Streaming VLMs

- arXiv: https://arxiv.org/abs/2608.13416v1
- arXiv ID: 2608.13416

---

🔍 **核心问题**：流式视觉语言模型（VLMs）在实时感知与长期记忆之间存在权衡，缩短上下文虽能提升当前场景感知，却损害了长程回忆能力。

🛠 **方法**：提出StreamTTT，将长程历史写入在线更新的快速权重（fast weights）中，使其脱离注意力上下文，同时保留短滑动键值缓存用于近期证据，从而缓解注意力稀释；模型在离线长视频问答和新构建的实时问答语料上联合训练。

✨ **主要贡献**：在OVO-Bench上，StreamTTT-4B相比SimpleStream-4B在实时感知上提升1.4点，在回溯推理上提升3.7点；在StreamingBench的RTVU子集上，与更大的SimpleStream-8B表现相当，实现了实时感知与长期记忆的有效调和。

# ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents

- arXiv: https://arxiv.org/abs/2609.17523v1
- arXiv ID: 2609.17523

---

🔍 **核心问题**：如何让科研AI智能体在服务研究者的日常工作中持续自我改进，实现与科研共同演化的“发现智能”。

🛠 **方法**：提出“递归中的递归自我改进”范式，将执行框架演化与模型强化学习耦合——内层递归在模型固定下改进框架，外层递归在改进后的框架下训练模型，二者相互促进。

✨ **主要贡献**：发布交互式科研工作台ScienceBuddy，将研究者的请求、反馈和执行证据转化为持续学习的任务与评估标准，并在四类科学任务上验证了交互、框架优化与模型学习的有效性。

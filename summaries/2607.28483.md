# Towards Real-Time PixOOD: Efficient Anomaly Segmentation for Autonomous Vehicles

- arXiv: https://arxiv.org/abs/2607.28483v1
- arXiv ID: 2607.28483

---

🔍 **核心问题**：实时异常分割对自动驾驶系统安全至关重要，但现有高精度方法计算开销大，难以在嵌入式设备上部署。

🛠 **方法**：重新设计PixOOD的Neyman-Pearson评分阶段，并通过TensorRT硬件优化编译整个流程，适配桌面与嵌入式平台。

✨ **主要贡献**：在RTX 4060上达到182 FPS，在Jetson AGX Orin上达到75 FPS，分别比原方法快20倍和18倍，证明高效异常分割可实际部署于自动驾驶和铁路场景。

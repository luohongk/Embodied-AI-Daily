# When Memory Lies: An Empirical Study of Spatial Memory Staleness in VLM Agents

- arXiv: https://arxiv.org/abs/2608.04574v1
- arXiv ID: 2608.04574

---

🔍 **核心问题**：研究VLM智能体在环境变化后，其空间记忆过期（stale）与当前观察冲突时，能否察觉矛盾并避免安全相关的错误决策。

🛠 **方法**：基于动态FrozenLake测试平台，设计“过期检测”与“下游导航”两个任务，对3个闭源和3个开源VLM模型进行文本与图像输入测试（共1,800次检测、12,000次导航回合），并引入“读取时审计”过滤器对比有无审计的效果。

✨ **主要贡献**：发现三个关键结果——文本可解性不等于视觉接地（视觉F1从0.887到0.067差异巨大）；无审计地信任过期记忆会显著增加安全风险（GPT-4o下死亡次数翻倍）；审计虽能降低文本模式风险，但无法完全消除差距，且视觉审计不可靠时过滤无稳定收益。这揭示了空间记忆过期是安全失效模式，并指出视觉接地与冲突下的动作选择是核心开放挑战。

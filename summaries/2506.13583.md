# Can you see how I learn? Human observers' inferences about Reinforcement Learning agents' learning processes

- arXiv: https://arxiv.org/abs/2506.13583v2
- arXiv ID: 2506.13583

---

🔍 **核心问题**：人类观察者如何理解和推断强化学习（RL）智能体的学习过程，以及哪些因素影响这种理解，从而为可解释的RL系统设计提供依据。

🛠 **方法**：采用自下而上的两阶段实验设计。首先通过探索性访谈研究（N=9）识别人类解释的核心主题，然后设计基于观察的范式，在两项任务（导航/操作）和两种RL算法（表格/函数逼近）上进行确认性研究（N=34），分析816份响应以验证和细化主题框架。

✨ **主要贡献**：识别出人类理解RL智能体学习的四个核心主题（目标、知识、决策制定、学习机制），验证了观察范式的可靠性，并揭示了这些主题随时间演变及其相互关系，为设计可解释的RL系统和提升人机交互透明度提供了以人为中心的实证见解。

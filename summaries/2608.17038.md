# Terrain-Aware Local Path Planning with Global DEM Data Integration for Autonomous UGV Navigation

- arXiv: https://arxiv.org/abs/2608.17038v1
- arXiv ID: 2608.17038

---

🔍 **核心问题**：解决无人地面车辆（UGV）在复杂户外地形中导航时，全局地图与实时传感器反馈脱节的问题，提升路径规划的安全性与适应性。

🛠 **方法**：提出混合框架，先利用低分辨率数字高程模型（DEM）数据通过A*算法计算全局路径，再结合实时LiDAR障碍物检测与地形分析进行局部路径自适应修正。

✨ **主要贡献**：在Gazebo仿真中，相比基线方法，障碍物规避率提升至95%，平均遭遇坡度从8°降至2.7°，显著增强了路径效率、地形可通行性及实时适应能力。

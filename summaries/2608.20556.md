# Logic-VLA: A Temporal Logic Conditioned Vision-Language-Action Model

- arXiv: https://arxiv.org/abs/2608.20556v1
- arXiv ID: 2608.20556

---

🔍 **核心问题**：现有视觉-语言-动作（VLA）模型只能遵循自然语言指令，但无法精确满足安全关键或时空约束等正式要求。

🛠 **方法**：提出Logic-VLA，在推理时输入信号时序逻辑（STL）规范，通过语法图编码器学习时序语义，并采用两阶段策略：STL条件监督微调加轨迹级偏好优化（基于流匹配的Identity偏好优化）。

✨ **主要贡献**：在四旋翼导航仿真中，Logic-VLA将STL满足率提升24.8-40.7个百分点，同时名义任务成功率仅下降最多1.8个百分点，且能泛化到训练中未见过的STL公式，实现单一策略适应多种正式要求。

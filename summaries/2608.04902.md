# Visual Representation Matters: Exploiting Temporal Differences in Video-to-Audio Generation

- arXiv: https://arxiv.org/abs/2608.04902v1
- arXiv ID: 2608.04902

---

🔍 **核心问题**：视频到音频生成（V2A）需要利用连续帧中的时间线索，但现有方法依赖额外网络或强先验，未能充分挖掘视觉表征中的时间差异信息。

🛠 **方法**：提出TD-V2A框架，将时间差异（TD）作为V2A区别于图像到音频生成的关键表征，在帧级和特征级探索TD的最佳利用方式，并设计层级连续学习策略与退火时间差异引导方法，分别用于扩散训练和采样过程。

✨ **主要贡献**：实验表明，仅通过有效利用TD即可显著提升端到端V2A生成质量，甚至超越对比式音视频预训练等专用表征方法，且无需额外网络或复杂监督。

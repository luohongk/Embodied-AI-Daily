# Hybrid System Planning using a Mixed-Integer ADMM Heuristic and Hybrid Zonotopes

- arXiv: https://arxiv.org/abs/2602.17574v2
- arXiv ID: 2602.17574

---

🔍 **核心问题**：混合系统（如自动驾驶中的行为与运动规划）的嵌入式优化规划因混合整数规划计算量大且对数值形式敏感而难以实现。

🛠 **方法**：提出将混合zonotope（一种高级集合表示）与新的ADMM混合整数规划启发式算法相结合，用于混合系统的运动规划框架，并扩展了分段仿射（PWA）系统的可达性分析。

✨ **主要贡献**：所提集合构造方法在内存复杂度和凸松弛紧致性上优于现有技术；ADMM启发式算法利用混合zonotope结构，在收敛速度上超越现有最先进混合整数规划启发式；并在自动驾驶的联合行为与运动规划场景中进行了嵌入式硬件实验验证。

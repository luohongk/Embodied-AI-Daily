# User Feedback Provides a Unique Signal that LLMs Can not Detect

- arXiv: https://arxiv.org/abs/2609.02859v1
- arXiv ID: 2609.02859

---

🔍 **核心问题**：现有研究认为用户反馈对大型语言模型（LLM）的改进效果不佳，本文质疑这一观点，并指出问题源于当前评估范式的系统性偏差。

🛠 **方法**：构建具有明确真实标签的合成数据与自然场景数据，对比模型在有无用户反馈条件下的修订结果，并分析LLM评判者对修订输出的偏好。

✨ **主要贡献**：证明用户反馈是高度有效的改进信号——反馈驱动的修订能显著更精准地解决目标问题；同时揭示评估偏差根源：当模型仅凭反馈修正错误时，LLM评判者常误判，反而偏好较差的基线输出。

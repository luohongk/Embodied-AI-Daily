# Concept-Grounded Reasoning with Prompt-Driven Localization for Interpretable Structured Report Generation

- arXiv: https://arxiv.org/abs/2609.15334v1
- arXiv ID: 2609.15334

---

🔍 **核心问题**：现有医学报告生成系统多采用端到端多模态融合，未建模临床定义的中间属性，导致可解释性和临床依据不足。

🛠 **方法**：提出CORAL框架，利用提示驱动的医学分割模型定位病灶，通过概念瓶颈模块预测多类临床属性，并将概念文本令牌与掩码调制的视觉特征结合于MLLM中，实现结构化报告生成与诊断预测。

✨ **主要贡献**：在BUS-CoT和IU X-ray数据集上，CORAL在诊断准确性、概念一致性和报告质量上均优于强通用及医学MLLM，表明概念驱动的推理能更好地对齐临床决策过程。

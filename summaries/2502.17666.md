# Yes, Q-learning Helps Offline In-Context RL

- arXiv: https://arxiv.org/abs/2502.17666v5
- arXiv ID: 2502.17666

---

🔍 **核心问题**：现有离线上下文强化学习（ICRL）方法主要依赖监督学习目标，在离线RL场景中表现受限，本文探讨如何将RL目标整合进ICRL框架以提升性能。

🛠 **方法**：在ICRL框架中引入RL优化目标（如价值学习），并测试加入保守性（conservatism）对价值学习的影响，在超过150个GridWorld和MuJoCo数据集及XLand-MiniGrid环境中进行实验。

✨ **主要贡献**：相比广泛使用的算法蒸馏（AD），RL目标平均提升约30%性能，在XLand-MiniGrid中性能翻倍；加入保守性在几乎所有设置下带来额外提升，强调了ICRL学习目标与RL奖励最大化目标对齐的重要性。

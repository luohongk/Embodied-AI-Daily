# DFM-VLA: Iterative Action Refinement for Robot Manipulation via Discrete Flow Matching

- arXiv: https://arxiv.org/abs/2603.26320v4
- arXiv ID: 2603.26320

---

🔍 **核心问题**：现有VLA模型在机器人操作中采用离散token解码动作时，一旦生成token便固定不变，导致早期token错误无法在后续迭代中修正，限制了动作预测精度。

🛠 **方法**：提出DFM-VLA，基于离散流匹配（Discrete Flow Matching）构建token级概率速度场，在多次迭代中动态更新完整动作序列；同时设计度量对齐动作分词器（MAAT）和两阶段解码策略，并探索辅助速度头与嵌入引导两种速度场构建方式。

✨ **主要贡献**：首次将离散流匹配引入VLA动作解码，实现动作token的迭代精炼；在CALVIN、LIBERO、LIBERO-Plus及真实机器人任务上验证了有效性，显著提升操作精度。

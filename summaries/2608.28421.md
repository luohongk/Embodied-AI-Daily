# Program Learning with Verifiable Rewards: Symbolic Backpropagation for Post-Training LLMs

- arXiv: https://arxiv.org/abs/2608.28421v1
- arXiv ID: 2608.28421

---

🔍 **核心问题**：现有LLM后训练（如监督微调和强化学习）将推理能力隐式嵌入模型权重中，无法逐步检查、验证或迁移，且中间步骤难以获得细粒度监督。

🛠 **方法**：提出PLVR（Program Learning with Verifiable Rewards），通过“符号反向传播”学习显式程序——将推理过程分解为确定性原语和神经原语的组合，利用类型推断在程序层间反向传播奖励，实现逐步骤的稠密验证。

✨ **主要贡献**：在LiveCodeBench v6和Tau2Bench上，30B模型用PLVR比同预算RL平均高27.8分，比大10倍的前沿模型高13.6分；仅需100个示例即可适配新任务，无需新微调数据；消融实验证明优势来自反向传播机制而非类型系统，并开源了符号反向传播库和一致性检查器。

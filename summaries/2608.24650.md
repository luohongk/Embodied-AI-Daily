# Simthesizer: An Agent-Driven Simulation Framework for LLM Serving Systems

- arXiv: https://arxiv.org/abs/2608.24650v1
- arXiv ID: 2608.24650

---

🔍 **核心问题**：现有LLM服务系统模拟器开发速度跟不上真实系统演进，新机制（如代理工作流、分离式服务）需要大量侵入式重写，导致模拟器与部署系统之间存在发展鸿沟。

🛠 **方法**：提出Borg框架，采用可组合的模拟器基础设施，将完整服务流程（含控制决策）统一表示为动态图；通过Synthesizer agent（受约束的编码代理）将自然语言功能请求自动转化为模拟器扩展，并附带保真度验证。

✨ **主要贡献**：实现代理驱动的模拟器自主开发，扩展代码基于vLLM真实系统的平均吞吐误差仅2.51%（现有模拟器为6.03%）；在相同负载下，模拟速度比LLMServingSim2.0和Vidur分别快284.96倍和23.19倍。

# Multimodal Surface EMG Hand Gesture Recognition Using Query-Based Transformers for Prosthetic Control

- arXiv: https://arxiv.org/abs/2607.22779v1
- arXiv ID: 2607.22779

---

🔍 **核心问题**：现有基于表面肌电信号的手势识别模型在增加手势数量时性能下降，且难以有效融合多模态生理信号（如惯性数据）以提升识别精度。

🛠 **方法**：提出EMG-CrossFormer，一种端到端的混合卷积-Transformer架构，通过级联交叉注意力融合层整合多个单模态编码器的特征，并利用可学习的手势查询解码融合表示。

✨ **主要贡献**：仅使用表面肌电信号时，在四个NinaPro数据集上达到72.33%-79.16%的平均准确率；融合惯性信号后性能提升至80.40%-92.79%，证明了联合局部-全局特征建模与多模态融合对复杂手势识别的显著价值。

# PaCoNet: Deep Data Extraction for Parallel Coordinates

- arXiv: https://arxiv.org/abs/2608.06030v1
- arXiv ID: 2608.06030

---

🔍 **核心问题**：从平行坐标图（parallel coordinates plots）中自动提取数据，这是高维数据可视化中尚未被充分研究的领域。

🛠 **方法**：提出首个针对平行坐标图的深度学习模型PaCoNet，能够提取线条坐标并还原单个数据样本，同时构建了大规模平行坐标数据集用于训练和测试。

✨ **主要贡献**：首次实现平行坐标图的自动化数据提取与分析，显著优于未适配的基线方法，为复杂可视化分析奠定基础，并公开代码、模型和数据生成脚本。

# RouteBridge: Reliability-Routed Bidirectional Distillation Between Neural Radiance Fields and 3D Gaussian Splatting

- arXiv: https://arxiv.org/abs/2609.09606v1
- arXiv ID: 2609.09606

---

🔍 **核心问题**：现有 NeRF 与 3DGS 之间的跨表示蒸馏通常固定单一表示作为全场景教师，导致局部重建误差被传播放大。

🛠 **方法**：提出 RouteBridge 双向蒸馏框架，通过结合光度残差与表示特有几何证据的可靠性估计器，为每条光线自适应选择监督方向（NeRF→3DGS、3DGS→NeRF 或弃权），并借助与渲染器无关的接口传递颜色、不透明度和归一化深度。

✨ **主要贡献**：在 mip-NeRF 360 上，NeRF 与 3DGS 导出分别达 28.56 和 28.77 dB，3DGS 导出较 3DGS 提升 1.56 dB、较 NeRF-GS 提升 0.45 dB，LPIPS 降至 0.207；消融实验表明自适应路由与几何光线目标均有贡献。

# C$^2$Path: Class-Conditional Pathway Decoupling for Vision-Language Incremental Object Detection

- arXiv: https://arxiv.org/abs/2608.21937v1
- arXiv ID: 2608.21937

---

🔍 **核心问题**：增量目标检测（IOD）中，共享参数更新导致类别边界模糊，混合特征编码造成类别表示纠缠，阻碍模型持续学习新类别而不遗忘旧知识。

🛠 **方法**：提出C$^2$Path框架，通过类别条件路径解耦，利用类别专家库和类别条件解耦模块，动态生成路由信号组合ClassLoRA适配器，为不同类别构建独立可更新的计算路径。

✨ **主要贡献**：在COCO 2017多个增量学习设置下，C$^2$Path持续优于现有方法，实现类别间参数隔离更新与特征分离注入，为视觉语言检测器的类别持续扩展提供高效可扩展方案。

# Whole-Body MRI Classification via Prompt-Based Clinical Conditioning

- arXiv: https://arxiv.org/abs/2608.30824v1
- arXiv ID: 2608.30824

---

🔍 **核心问题**：全身MRI（WB-MRI）与临床变量结合可提升系统性疾病诊断，但临床数据常不完整或缺失，传统多模态融合方法难以处理。

🛠 **方法**：提出TACTIC框架，将临床属性编码为提示（prompt）条件化视觉特征学习，支持任意数量的表格输入，无需插补或固定输入结构即可自然处理缺失数据。

✨ **主要贡献**：在糖尿病、COPD、乳腺癌、前列腺癌和转移诊断等五项任务中，TACTIC在临床信息可用时持续优于仅图像基线，且在表格输入不完整时仍保持强预测能力，验证了提示式模型的灵活性和有效性。

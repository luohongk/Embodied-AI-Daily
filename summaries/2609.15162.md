# LieSpline-DP: Lie-Group B-Spline Diffusion Policy for Smooth Robot Manipulation

- arXiv: https://arxiv.org/abs/2609.15162v1
- arXiv ID: 2609.15162

---

🔍 **核心问题**：Diffusion Policy 在机器人操作中生成的轨迹不连续、不平滑，现有样条方法既无法保证跨动作块的 C² 连续性，也未考虑 SE(3) 的群结构。

🛠 **方法**：提出 LieSpline-DP，直接在 SE(3) 上生成末端执行器轨迹的 Lie 群 B 样条扩散策略，通过共享相邻规划的边界控制位姿来耦合连续计划，确保整条轨迹的 C² 连续性。

✨ **主要贡献**：在三个真实机器人任务中实现更低的轨迹抖动和更高的成功率；在涉及液体和柔性物体的任务中优势显著，倒水和挂钩任务成功率达 100%，而 DP 基线仅为 10% 和 30%。

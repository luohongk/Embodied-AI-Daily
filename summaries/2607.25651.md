# Demystifying Deep Learning Compiler Frontend Bugs: An LLM-Aided Empirical Study

- arXiv: https://arxiv.org/abs/2607.25651v1
- arXiv ID: 2607.25651

---

🔍 **核心问题**：深度学习编译器前端（如TorchDynamo）在将程序转换为图中间表示时引入的缺陷（fBug）严重但缺乏系统性研究，现有工作多关注底层API或视编译器为整体。

🛠 **方法**：采用领域知识增强的大语言模型辅助方法，对PyTorch 2默认前端TorchDynamo中的123个fBug进行实证分析，构建包含7个根因类别和15个子类别的分类体系。

✨ **主要贡献**：首次系统分类fBug根因，提供可操作的开发与测试建议；利用LLM生成根因感知的测试用例，发现23个新fBug（15个已确认），验证了方法在检测和加固编译器前端缺陷上的有效性。

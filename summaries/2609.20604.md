# Semantic SLAM in Precision Agriculture using Bayesian Inference

- arXiv: https://arxiv.org/abs/2609.20604v1
- arXiv ID: 2609.20604

---

🔍 **核心问题**：如何在精准农业场景中，让自主机器人在不单纯依赖GPS的情况下，实现实时语义建图与定位，并同时完成作物相关任务。

🛠 **方法**：将基于贝叶斯推断的物体及其语义属性概率建图，与基于$g^2o$的图优化SLAM相结合，并使用YOLOv8n从深度相机观测中提取物体与语义信息。

✨ **主要贡献**：提出并验证了一个面向精准农业的实时语义世界建模框架，在Gazebo仿真和Spot机器人室内实验中成功实现了至少400株植物的实时建图与定位。

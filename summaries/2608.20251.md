# Video2DoorTraversal: Push Door Traversal via Simulated Door Twins

- arXiv: https://arxiv.org/abs/2608.20251v1
- arXiv ID: 2608.20251

---

🔍 **核心问题**：解决轮腿移动机器人在真实环境中完成推门穿越这一长时程定位操作任务，尤其是门体结构多样且难以获取精确模型的问题。

🛠 **方法**：提出Video2DoorTraversal框架，通过单段RGB视频重建实例对齐、可动且仿真就绪的“门孪生”模型，结合仿真内循环生成可执行演示，并训练双深度策略网络ArticuACT以协调基座、机械臂和夹爪控制。

✨ **主要贡献**：实现96.57%的平均成功率于五扇真实门，对未见相似门零样本成功率80.95%，平均完成时间约13秒，且所有感知与推理均机载运行，展示了高效的实到仿到实迁移能力。

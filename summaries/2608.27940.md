# A Deep Learning-Based Stacking Ensemble Framework for Turbofan Engine Remaining Useful Life Prediction

- arXiv: https://arxiv.org/abs/2608.27940v1
- arXiv ID: 2608.27940

---

🔍 **核心问题**：针对涡扇发动机剩余使用寿命（RUL）预测精度不足的问题，提出一种集成学习框架以提升预测性能。

🛠 **方法**：构建两级堆叠集成框架，融合LSTM、CNN、CNN-LSTM和CNN-GRU四种异构深度学习基学习器，通过XGBoost元学习器整合其折叠外预测结果。

✨ **主要贡献**：在NASA C-MAPSS的FD001和FD003子集上，RMSE分别降至9.989和8.613，较最优基线TCAT降低10.2%和21.8%，并通过特征相关性、残差诊断和收敛曲线验证了模型鲁棒性。

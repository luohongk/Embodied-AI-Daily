# Human-Level Text-to-SQL via Reinforcement Learning on Verified Data, Without Pipeline Engineering

- arXiv: https://arxiv.org/abs/2603.20004v4
- arXiv ID: 2603.20004

---

🔍 **核心问题**：解决Text-to-SQL任务中，传统多阶段LLM流水线方法性能受限，且与人类专家水平存在显著差距的问题。

🛠 **方法**：采用基于验证数据的强化学习（RLVR）微调LLM，并开发了多轮专家驱动的数据验证流程，同时提出ReViSQL-BIRD奖励塑形方法，结合结果奖励与SQL等价性验证，并利用过程奖励激励外部知识使用。

✨ **主要贡献**：构建了BIRD-Platinum数据集（修正61%实例错误），使Qwen3-235B在多个基准上提升11-16%；ReViSQL-BIRD-K2.6首次在Arcwise-Plat上达到人类水平准确率（92.96%），超越顶尖开源系统10-22%。

# RoboTok: An Internet-Scale Data Engine for Human Demonstration Retrieval and Dexterous Manipulation Learning

- arXiv: https://arxiv.org/abs/2609.03199v1
- arXiv ID: 2609.03199

---

🔍 **核心问题**：机器人学习需要大量多样化的演示数据，但真实机器人数据采集成本高且难以覆盖长尾任务，亟需从互联网视频中高效获取可用的操作演示。

🛠 **方法**：RoboTok构建了一个互联网规模的数据引擎，从查询视频中提取3D手部轨迹，并在估计的演员中心参考系中学习潜在运动空间，以实现跨视角、场景和遮挡的操作行为比较与高效检索。

✨ **主要贡献**：提出手部姿态轨迹感知的检索方法，显著提升操作演示的相关性和下游机器人策略成功率，使网络视频成为可扩展且持续增长的机器人学习监督源。

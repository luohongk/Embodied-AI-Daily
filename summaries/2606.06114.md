# ANCHOR: An External LLM-Driven Supervisory Module Facilitating Healthy Evolution in Self-Evolving Systems

- arXiv: https://arxiv.org/abs/2606.06114v3
- arXiv ID: 2606.06114

---

🔍 **核心问题**：自演化智能体依赖自我对弈和自我生成的学习信号，其内部任务与验证信号难以覆盖阶段级错误，导致能力退化和安全漂移不断累积。

🛠 **方法**：提出 ANCHOR——一个基于外部 LLM 的监督框架，在自演化的多个阶段提供评估反馈，并将审核后的信号聚合为上下文供后续步骤使用；将其集成到两个代表性开源自演化智能体框架中，在编程、数学推理和安全任务上评估。

✨ **主要贡献**：ANCHOR 在保持核心能力稳定的同时显著提升安全性能；分析表明基于执行结果的监督尤为有效，且监督频率增加存在收益递减，验证了外部 LLM 监督是构建更安全、稳定、可控自演化智能体的实用途径。

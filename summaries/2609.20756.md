# OPTED: On-Policy Fine-Tuning for End-to-End Driving using a Render-Free Teacher

- arXiv: https://arxiv.org/abs/2609.20756v1
- arXiv ID: 2609.20756

---

🔍 **核心问题**：端到端自动驾驶策略经开环行为克隆预训练后，闭环部署时误差累积会使车辆偏离训练分布，带来安全隐患，而闭环后训练又依赖昂贵的传感器级仿真。

🛠 **方法**：提出 OPTED，将强化学习与端到端策略后训练解耦——先用 RL 在向量化输入（HD 地图与边界框）上训练一个特权教师模型，再由该教师为预训练学生模型提供闭环后训练监督，无需渲染传感器仿真。

✨ **主要贡献**：在 AlpaSim 中基于真实驾驶日志的 3DGS 神经重建对 TransFuser 和 VaVAM 微调，驾驶分数分别提升 1.6 倍和 9.5 倍；相比直接 RL 后训练，以约三个数量级的更少仿真交互达到同等闭环性能，且更贴近人类先验。

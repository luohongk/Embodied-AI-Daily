# Meshless Domain Randomization via Explicit Parameter Perturbation of 3D Gaussian Splatting

- arXiv: https://arxiv.org/abs/2607.22890v1
- arXiv ID: 2607.22890

---

🔍 **核心问题**：传统域随机化（DR）依赖多边形网格渲染，难以处理昆虫标本等复杂有机物体的纹理提取与渲染。

🛠 **方法**：提出无网格DR框架，在3D高斯泼溅（3DGS）参数空间上操作，通过光度扰动（调制球谐系数）和程序化扰动（用3D空间噪声替换原始纹理）两条独立管线合成随机化训练数据集，并利用光栅化引擎将扰动辐射场合成到随机背景上。

✨ **主要贡献**：首次实现基于3DGS参数扰动的无网格域随机化，为复杂几何体提供无需网格的鲁棒数据集生成替代方案。

# QUASAR: A Quantum-Classical Neural Network for SAR Satellite Physical-Layer Authentication

- arXiv: https://arxiv.org/abs/2608.20240v1
- arXiv ID: 2608.20240

---

🔍 **核心问题**：X波段SAR卫星（8-12 GHz）缺乏鲁棒的物理层认证（PLA），现有基于射频指纹的方案局限于6 GHz以下频段，且经典深度学习无法充分捕捉IQ相位非线性特征，导致认证性能不足。

🛠 **方法**：提出QUASAR，一种量子-经典混合架构，将CNN频谱图编码器与变分量子电路（VQC）融合，用于X波段SAR信号的物理层认证，并在三种对抗场景（重放、伪造IQ注入、星载欺骗）下进行测试。

✨ **主要贡献**：首次将量子增强技术应用于卫星物理层认证；数据效率显著提升（仅需10%训练数据即可匹配经典基线精度）；在相同数据预算下分类精度优于经典方法；三种对抗场景下分别拒绝89.7%、94.1%和81.3%的欺骗传输，为物理层认证开辟了新研究方向。

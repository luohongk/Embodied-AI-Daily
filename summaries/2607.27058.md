# Object Detection for Autonomous Driving in Chinese Rural Scenes: An Experimental Study on Real-Synthetic Data Mixing and Model Evaluation

- arXiv: https://arxiv.org/abs/2607.27058v1
- arXiv ID: 2607.27058

---

🔍 **核心问题**：解决自动驾驶模型在中国农村复杂交通场景中因数据稀缺和泛化能力不足导致的检测困难。

🛠 **方法**：构建一个结合河南尉氏县真实图像与虚幻引擎生成参数化虚拟场景的混合数据集，定义14类农村特有目标（如电动三轮车、低速车、路边摊），并在统一训练协议下评估13种主流检测器在不同真实/虚拟数据比例下的性能。

✨ **主要贡献**：实验表明，适度混合虚拟数据（1:0.5比例）可有效提升检测性能，YOLO11m达到最高mAP@0.5（0.758）；但过高比例（1:1）会引入域偏移抵消增益；同时揭示了模型对长尾非标准目标（如摊位、栏杆）的感知瓶颈，为农村自动驾驶的模型选择与数据策略提供实证依据。

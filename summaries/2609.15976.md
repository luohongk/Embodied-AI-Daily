# MessyMem: Learning-from-Doing Memory for Mobile Manipulation

- arXiv: https://arxiv.org/abs/2609.15976v1
- arXiv ID: 2609.15976

---

🔍 **核心问题**：移动操作机器人在多次、多房间的部署中，往往把每个任务都当作全新任务，无法积累和复用交互中获得的知识（如柜子被锁、物体藏在抽屉里）。

🛠 **方法**：提出 MessyMem 持久记忆系统，维护一个空间锚定的 3D 场景图（记录物体与位置），并通过交互学习到的属性和结果对其进行增强，同时关联视觉观测以支持细粒度回忆。

✨ **主要贡献**：在跨越 3 小时以上的 25 个连续仿真任务中达到 80.0% 的任务进度，分别超越最强消融版本 14.8 个百分点、最强外部基线 28.9 个百分点，并能从数千个关键帧和超过一小时前的历史中检索相关证据。

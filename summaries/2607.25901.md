# RecoReward: Recommender-Guided Multimodal Description Generation for Recommendation

- arXiv: https://arxiv.org/abs/2607.25901v1
- arXiv ID: 2607.25901

---

🔍 **核心问题**：多模态大语言模型生成商品描述时，无法利用下游用户信号决定应强调哪些语义，而现有用户条件方法需在推理时依赖用户信息，导致生成过程与用户绑定。

🛠 **方法**：提出RecoReward，在训练阶段通过行为衍生的奖励信号（如推荐器亲和度分数RAS）进行强化学习，对比历史活跃用户与非目标用户的偏好，使模型学习生成单一共享描述，推理时无需用户输入。

✨ **主要贡献**：RecoReward-9B在离线基准上超越Qwen3.5-9B等所有对比模型，在线A/B测试也显示性能提升，实现了仅依赖内容推理即可生成有益于下游推荐的商品特征。

# REVOLVE: An Automated Closed-Loop Framework for Evolving Robot Manipulation with Minimal Human Intervention

- arXiv: https://arxiv.org/abs/2609.14633v1
- arXiv ID: 2609.14633

---

🔍 **核心问题**：真实世界机器人操作策略的部署仍高度依赖人工进行失败评估、纠正和环境重置，且模型难以从失败与纠正经验中持续学习。

🛠 **方法**：提出 REVOLVE 自动化闭环框架，集成数据采集、策略训练部署、失败恢复与持续学习；其 ARC 架构自动重置环境并纠正策略失败，DLE 机制通过真实交互与失败-纠正数据反馈持续优化策略和智能体判断。

✨ **主要贡献**：在四项真实操作任务中，经五次迭代后策略平均成功率提升 18.5%、智能体判断准确率提升 8.5%，同时将数据采集和部署测试的人工投入分别减少 94.4% 和 95.1%，实现了极少人工干预下策略与监督模型的持续进化。

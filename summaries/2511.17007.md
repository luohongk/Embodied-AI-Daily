# Self-Localizing MIMO Beam Mapping for Intelligent Open RAN with Continuously Evolving Channel Memory

- arXiv: https://arxiv.org/abs/2511.17007v2
- arXiv ID: 2511.17007

---

🔍 **核心问题**：面向6G开放智能无线接入网（Open RAN），如何在缺乏位置标签和完整CSI的情况下，高效构建可复用且准确的无线信道知识。

🛠 **方法**：提出自定位MIMO波束映射框架，利用波束域RSS作为紧凑输入，通过双尺度特征提取器捕获角度依赖与样本相关性，结合混合时序编码器推断物理锚点，并构建物理结构的无线地图嵌入，由扩散解码器重建全CSI。

✨ **主要贡献**：在稀疏测量下物理锚点恢复精度提升超30%，NLOS波束跟踪信道容量增益较卡尔曼滤波基线提升超20%，且无线地图嵌入可持续更新复用，无需重复全CSI采集。

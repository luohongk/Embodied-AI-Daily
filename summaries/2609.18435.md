# WetRobo: A Reproducible Robot Kit for Coding Agents in Biological Laboratories

- arXiv: https://arxiv.org/abs/2609.18435v1
- arXiv ID: 2609.18435

---

🔍 **核心问题**：如何让湿实验室的普通研究人员无需遥操作或训练神经网络，就能将机器人任务可靠地迁移到不同实验室环境中。

🛠 **方法**：构建 WetRobo 机器人套件（含机械臂、实验室设备、控制代码、遥操作演示和 AGENTS.md 技能文件），由编码智能体观察本地环境并自主编写、执行程序，必要时调用外部工具进行适配。

✨ **主要贡献**：在真实实验室中成功完成掀培养皿盖、开试剂瓶盖、开培养箱门三项任务；编码智能体在两个实验室均完成开盖任务，而基于 Lab X 微调的 VLA 模型无法迁移到 Lab Y，证明"分发套件+编码智能体本地适配"是替代逐实验室训练策略的可行路径。

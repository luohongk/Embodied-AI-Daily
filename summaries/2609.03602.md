# SV-WAM: An Efficient Surround-View World-Action Model for End-to-End Autonomous Driving

- arXiv: https://arxiv.org/abs/2609.03602v1
- arXiv ID: 2609.03602

---

🔍 **核心问题**：现有端到端自动驾驶世界模型多采用单前视摄像头输入，限制了变道、汇入和转弯等安全关键场景的空间感知范围；而多视角视频生成推理开销大，难以高效部署。

🛠 **方法**：提出SV-WAM，一种环视世界-动作模型，保留六摄像头全景输入，将未来视频预测作为共享生成模型中的稠密训练监督而非推理输出，并引入动作中心因果掩码与可微可行驶区域合规正则化。

✨ **主要贡献**：在NAVSIMv2闭环与nuScenes开环基准上达到最先进规划性能，推理时丢弃视频分支实现低延迟动作规划，并具备竞争力的零样本迁移能力。

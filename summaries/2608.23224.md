# Think Only When Needed: Prompt-Authority Control for Selective Slow-Path Intervention in Vision-Language-Action Manipulation

- arXiv: https://arxiv.org/abs/2608.23224v1
- arXiv ID: 2608.23224

---

🔍 **核心问题**：在视觉-语言-动作（VLA）操作任务中，检索增强的文本提示一旦被加入执行，会因“提示形式崩溃”导致成功率大幅下降（如从92.47%降至3.00%），即使添加的是有意义或长度匹配的无意义文本也会失败。

🛠 **方法**：提出TOWN-VLA（Think Only When Needed），一种提示权限控制接口，将候选生成与修改策略输入的权限分离。通过固定兼容性规则授权规范紧凑指令，否则恢复原始Base提示，确保提示形式不被破坏。

✨ **主要贡献**：在900条审计路线中，所有路线均遵守契约（525条恢复Base，375条授权提示保留任务签名）；在LIBERO-Plus评估中成功率从69.5%提升至73.1%（+362个回合），在物理PiPER机械臂上从52.7%提升至78.7%（p=3.16×10⁻⁶），证明冻结控制器可强制执行提示权限，且无需oracle的准入校准是下一步部署目标。

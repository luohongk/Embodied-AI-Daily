# Incremental Pooled LLM Evaluation for Cost-Effective Retrieval Model Selection

- arXiv: https://arxiv.org/abs/2609.02745v1
- arXiv ID: 2609.02745

---

🔍 **核心问题**：在生产环境的RAG系统中，选择检索模型需要可靠且可重复的对比评估，但大规模获取相关性标注成本高昂，且新模型不断加入时重复评估难以持续。

🛠 **方法**：提出“增量池化LLM评估”——用LLM对当前候选系统检索结果的并集进行统一评判，当新系统加入时，仅对新贡献的文档进行评判并扩充池，已有评判结果被复用，从而对所有系统进行公平对比。

✨ **主要贡献**：在4个基准（含11种稠密/稀疏/混合检索系统）上验证了该方法与金标准排序高度相关，97%的系统对顺序在考虑qrels不确定性后保持一致；在实际金融新闻QA系统中，文档重叠带来65–80%的评判复用，评估成本降低最多4.9倍，为部署系统的增量模型选择提供了经济高效的实用流程。

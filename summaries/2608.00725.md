# SelfWAM: A Self-Grounded Unified World Action Model for Fast Robot Control

- arXiv: https://arxiv.org/abs/2608.00725v1
- arXiv ID: 2608.00725

---

🔍 **核心问题**：现有世界动作模型（WAM）在预测未来观测时，仅依赖任务提示和观测上下文，容易捕获通用任务进展，而非所执行动作的具体后果，导致未来预测对动作不够敏感。

🛠 **方法**：提出SelfWAM，一种基于模态专用混合Transformer（MoT）架构的自接地统一世界动作模型，联合预测动作、动作条件下的未来RGB帧和机器人自遮挡掩码；训练时让未来视觉查询关注干净的动作副本，并使用提示特定的自掩码目标强化动作相关视觉变化。

✨ **主要贡献**：通过干净动作条件与未来自掩码监督，使未来预测更直接反映动作对机器人可见运动及场景的影响；在RoboTwin 2.0和真实操作任务上，SelfWAM生成更动作敏感的未来预测，保持快速策略推理，并提升策略性能。

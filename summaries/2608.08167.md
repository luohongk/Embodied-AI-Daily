# Wiener Representation Filtering for VLM Hallucination Suppression

- arXiv: https://arxiv.org/abs/2608.08167v1
- arXiv ID: 2608.08167

---

🔍 **核心问题**：视觉语言模型（VLM）在开放式描述和视觉问答中常产生对象幻觉，即描述图像中不存在的对象、属性或关系。

🛠 **方法**：提出一种无需训练、事后编辑表示空间的技术。该方法在语言骨干的隐藏状态上，利用配对数据离线估计协方差，推导出Wiener型最优滤波器，并通过特征分解实现逐模式衰减，最终将校正直接吸收进模型现有权重中，推理时无需额外计算。

✨ **主要贡献**：在LLaVA-1.5、MiniGPT-4、Gemma3和mPLUG-Owl2上，于CHAIR、POPE和MME基准上一致降低对象幻觉，同时保持描述流畅性和响应质量；并进一步在TempCompass视频基准和离散扩散语言模型上验证了方法的通用性，表明其可推广至时序视频推理和多步去噪场景。

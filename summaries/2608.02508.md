# RoMeRL: Balancing Feedback Coverage and the Memory-Reward Trap in Self-Evolving Agent Memory via Reduced-Order Utility States

- arXiv: https://arxiv.org/abs/2608.02508v1
- arXiv ID: 2608.02508

---

🔍 **核心问题**：自进化LLM代理的记忆系统面临两个耦合挑战——轨迹索引效用随交互历史增长导致反馈分散，以及轨迹级奖励共同分配给共同检索的记忆导致无关经验收到误导性更新（记忆-奖励陷阱）。

🛠 **方法**：提出降阶记忆强化学习（RoMeRL），用固定维度的每任务记忆状态（按结果极性和记忆动态分解）替代增长的轨迹索引效用空间，通过固定语义坐标集合并更新/替换内容来集中反馈。

✨ **主要贡献**：理论上证明降阶参数化增加每个效用坐标的平均反馈，并刻画错误坐标的稳态占用；实验上在ALFWorld和LifelongAgentBench中，任务性能提升，Cold-Q比率降低80.0%，反馈密度提高约6.0倍，记忆大小减少84.4%，LLM调用减少21.1%。

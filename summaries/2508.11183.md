# Versatile Video Representation via Feed-Forward 2D Gaussian Splatting Tokenization

- arXiv: https://arxiv.org/abs/2508.11183v2
- arXiv ID: 2508.11183

---

🔍 **核心问题**：现有视频表示方法基于固定网格和分块tokenization，空间上对低信息区域过度编码，时间上难以区分静态与动态内容，导致表示效率与泛化性不足。

🛠 **方法**：提出高斯视频变换器（GVT），采用前馈式2D高斯泼溅（2DGS）tokenization方案，通过时空高斯嵌入（STGE）机制生成2D高斯，并利用高斯集划分（GSP）策略将高斯分为静态集和动态集，分别建模跨帧共享内容与逐帧动态内容。

✨ **主要贡献**：在视频重建、动作识别、压缩和生成四项任务上验证了GVT的有效性，重建与压缩性能达到SOTA，动作识别精度提升，生成性能与基线MAGVIT-v2相当，且无需逐视频优化，具备良好泛化性。

# When Unlearning Fails: Reliable Data Deletion under Post-Training in Agent Networks

- arXiv: https://arxiv.org/abs/2607.28829v1
- arXiv ID: 2607.28829

---

🔍 **核心问题**：在自改进联邦智能体网络中，数据删除请求后，已删除数据仍通过影响后续轨迹保留“影响回声”，导致传统遗忘方法失效，行为泄露持续存在。

🛠 **方法**：提出MUTE方法，通过服务器轻量账本估计下游影响，执行遗忘-保留更新清除当前残留，对高影响保留轨迹进行隔离或降权，并在上行带宽预算下审计后续行为以安排额外擦除。

✨ **主要贡献**：在LIBERO基准和物理Jetson边缘测试台上验证，MUTE在保持任务效用的同时显著降低行为泄露和影响再生，通信开销远低于全量重训练，支持多种删除粒度和两个视觉-语言-动作骨干网络。

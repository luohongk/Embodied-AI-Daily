# 5G ISAC-Based UAV Detection and 3-D Tracking Using Uplink Sounding Reference Signals on an End-to-End O-RAN Simulation Testbed

- arXiv: https://arxiv.org/abs/2608.05826v1
- arXiv ID: 2608.05826

---

🔍 **核心问题**：利用5G蜂窝基础设施实现低空无人机（UAV）的探测与三维跟踪，同时不干扰现有通信服务。

🛠 **方法**：构建了一个基于开源组件（OpenAirInterface、FlexRIC、Sionna RT）的端到端O-RAN仿真测试平台，将NR上行探测参考信号（SRS）复用为被动雷达波形，在gNB内完成物理层感知，并通过自定义E2服务模型将检测结果传递给扩展卡尔曼滤波器（EKF）跟踪xApp，无需修改NR标准或增加专用感知波形。

✨ **主要贡献**：通过两种独立方式（平面接收阵列提供垂直孔径、第二发射机提供距离分集）解决了单基地对下高度不可观测的问题，实测结果与离线射线追踪仿真一致，高度估计RMSE达1.8米；在10 Mbps上行通信负载下仍保持检测覆盖，验证了ISAC系统的可行性与鲁棒性。

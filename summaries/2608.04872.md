# A-SR: Self-Evolving Agentic LLMs for Symbolic Regression via Hierarchical Coordination

- arXiv: https://arxiv.org/abs/2608.04872v2
- arXiv ID: 2608.04872

---

🔍 **核心问题**：现有基于LLM的符号回归方法将异构搜索失败压缩为单一标量和统一提示，导致搜索效率低、难以适应多样化的失败模式。

🛠 **方法**：提出A-SR，一个自进化智能体框架，将控制单元从表达式编辑转为角色条件证据视图。通过协调协议路由、在线评估器-奖励角色策略和状态路由过程记忆，将评估反馈（可靠性、生产力）按角色分发至不同智能体，并在运行内自适应搜索、跨运行蒸馏轨迹到开源LLM。

✨ **主要贡献**：在LLM-SRBench的四个科学领域上，A-SR将Acc@0.01从25.79%提升至48.30%（Llama3.1-8B），A-SR-LoRA将Qwen3-4B结果从24.58%提升至38.29%；在四个真实科学发现任务中，8项指标中7项取得最佳归一化均方误差。

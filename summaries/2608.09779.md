# KGCaRe: Explainable Complex Conditional Question Answering using Automatic Knowledge Graph Construction and Context Retrieval with LLMs

- arXiv: https://arxiv.org/abs/2608.09779v1
- arXiv ID: 2608.09779

---

🔍 **核心问题**：解决大语言模型（LLMs）和检索增强生成（RAG）在领域特定复杂条件问答中表现不佳的问题。

🛠 **方法**：提出KGCaRe混合方法，结合神经检索与符号推理——从文档中通过多提示策略自动构建知识图谱（KG）存入图数据库，同时将文档嵌入向量库；利用LLM进行迭代图遍历提取相关三元组，并融合语义检索的文本片段，输入定制提示生成带解释的答案。

✨ **主要贡献**：在多个LLM（Mistral、Mixtral、GPT-3.5、GPT-4o）和两个复杂条件QA数据集上，KGCaRe一致优于现有基线（如Vanilla RAG、Think-on-Graph等），并公开了完整软件流水线。

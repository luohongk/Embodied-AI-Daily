# A Multi-Modal Perception Pipeline for Object Detection and Tracking in Autonomous Racing

- arXiv: https://arxiv.org/abs/2609.08338v1
- arXiv ID: 2609.08338

---

🔍 **核心问题**：在自动驾驶赛车高速、强振动、小安全边际等恶劣条件下，实现鲁棒的多目标检测与跟踪。

🛠 **方法**：提出一种多模态后期融合感知流水线，融合摄像头、LiDAR和RADAR的独立检测结果，并采用专用多目标跟踪框架，显式补偿检测延迟，并嵌入车辆动力学与赛道布局先验知识。

✨ **主要贡献**：在真实世界多种关键场景（含城市驾驶边缘案例）中验证了系统的有效性，证明其能提供及时、鲁棒的状态估计，支持安全自适应的规划决策。

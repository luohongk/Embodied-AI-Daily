# Learning CNN Filters via Generalized Stein's Method

- arXiv: https://arxiv.org/abs/2609.02875v1
- arXiv ID: 2609.02875

---

🔍 **核心问题**：从统计学角度估计卷积神经网络（CNN）中的卷积滤波器，避免依赖传统梯度下降训练。

🛠 **方法**：将CNN建模为矩阵输入的广义指数模型，利用广义一阶Stein公式，提出基于奇异值分解（SVD）的滤波器估计方法。

✨ **主要贡献**：理论上证明估计达到最优收敛率（与已知链接函数的广义线性模型相当），实验上优于Adam等流行深度学习算法，并扩展至非线性降维与表示学习。

# From Static Bibliometrics to Dynamic Knowledge Graphs: An LLM-Powered Framework for Modernizing Science, Technology, and Innovation (STI) Analytics

- arXiv: https://arxiv.org/abs/2607.21327v1
- arXiv ID: 2607.21327

---

🔍 **核心问题**：传统文献计量指标（如引用次数、h指数）存在时间滞后、语义浅薄，且无法捕捉当代知识生态系统的非线性动态变化。

🛠 **方法**：提出一个五层混合框架，整合开放学术数据、动态版本化知识图谱、受约束的大语言模型语义增强、多层验证管道及分析层，将LLM严格用于生成临时候选增强，仅通过结构、证据、比较和专家选择性验证后才纳入分析。

✨ **主要贡献**：将验证作为语义灵活性与认知纪律之间的中介原则，使STI分析在语义丰富性和时间响应性上超越静态文献计量，同时保持科学研究的证据标准，并讨论了可重复性、偏差和可审计性等治理问题。

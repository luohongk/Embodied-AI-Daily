# TEMPO: Learning Temporal Context for Dynamic Robot Manipulation

- arXiv: https://arxiv.org/abs/2609.16864v1
- arXiv ID: 2609.16864

---

🔍 **核心问题**：现有视觉-语言-动作（VLA）模型因仅依赖单帧观测，在动态操作任务中存在运动模糊（无法预测物体未来状态）和状态混叠（相似视觉对应不同动作）两大表征缺陷，且该瓶颈与模型规模、推理延迟无关。

🛠 **方法**：提出 TEMPO，在冻结的预训练 VLA 主干上额外引入两种时序输入——从冻结视频基础模型提取的运动摘要（解决运动模糊）和紧凑的本体感受历史（解决状态混叠），无需修改主干，训练与部署开销极小。

✨ **主要贡献**：在四项动态操作任务中显著提升性能（如瓶子交接成功率从 44% 提升至 74%），是唯一解决状态混叠的方法；通过探针与消融实验验证两种时序信号各自独立对应其缺陷，并发布 TEMPO-Bench 基准（超 5 万标注帧）。

# AI Can Learn Scientific Taste

- arXiv: https://arxiv.org/abs/2603.14473v3
- arXiv ID: 2603.14473

---

🔍 **核心问题**：探索AI能否学习“科学品味”——即判断和提出具有长期科学影响力研究想法的能力，以减少对资深人类专家的依赖。

🛠 **方法**：提出“社区反馈强化学习”（RLCF）框架，包含两个组件：Scientific Judge通过社区反馈（如引用量）学习评判研究想法，Scientific Thinker则学习提出高潜力研究想法。

✨ **主要贡献**：实验表明Scientific Judge在预测论文影响力上优于强LLM基线，且判断能力可泛化至未来年份、其他社区指标及未见领域；Scientific Thinker提出的研究想法比基线具有更高潜在影响力，证明AI可学习科学品味，为加速科学发现迈出重要一步。

# Action abstractions for amortized sampling

- arXiv: https://arxiv.org/abs/2410.15184v2
- arXiv ID: 2410.15184

---

🔍 **核心问题**：在强化学习和生成流网络（GFlowNets）中，长序列采样导致信用分配和探索困难，尤其在熵寻求方法中难以发现多样化的高奖励状态。

🛠 **方法**：提出在策略优化过程中迭代提取高奖励轨迹中频繁出现的动作子序列，并将其“分块”为单一高层动作加入动作空间，实现动作抽象。

✨ **主要贡献**：在合成和真实环境中显著提升样本效率，尤其在困难探索问题上；抽象动作具有可解释性，能捕捉奖励景观的潜在结构，是首个在摊销顺序采样中展示层次规划的工作。

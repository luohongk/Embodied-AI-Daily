# AdaHAT: Adaptive Hard Attention to the Task in Task-Incremental Learning

- arXiv: https://arxiv.org/abs/2608.01252v1
- arXiv ID: 2608.01252

---

🔍 **核心问题**：任务增量学习中，神经网络在学习新任务时容易灾难性遗忘，且基于架构的方法在长任务序列中会因大量参数变为静态而面临网络容量问题。

🛠 **方法**：提出自适应硬注意力机制（AdaHAT），通过考虑参数对先前任务的重要性和当前网络容量，允许对静态参数进行自适应更新，并基于此构建新网络架构。

✨ **主要贡献**：AdaHAT在多个数据集上优于HAT等基线，尤其在长任务序列中平均性能更佳，有效平衡了网络的稳定性与可塑性，缓解了容量问题。

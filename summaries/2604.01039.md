# Evaluation and Hardening of LLM System Instructions Against Extraction via Encoding Attacks

- arXiv: https://arxiv.org/abs/2604.01039v3
- arXiv ID: 2604.01039

---

🔍 **核心问题**：针对LLM系统指令泄露风险，现有防御仅依赖拒绝式指令，但攻击者可通过编码或结构化输出任务绕过防护，导致敏感信息泄露。

🛠 **方法**：提出自动化评估框架，将提取请求重构为编码或结构化输出任务，测试7种主流模型和46条系统指令的保密性；并提出基于思维链推理模型的一次性指令重塑缓解策略。

✨ **主要贡献**：发现结构化序列化攻击成功率超0.7，证明现有拒绝机制失效；提出的指令重塑方法无需重训练即可显著降低攻击成功率，为系统指令防护提供低成本有效方案。

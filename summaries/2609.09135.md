# Entropy-Regularized Rank-Masked Policy Optimization for Test-Time Reinforcement Learning in Code Generation

- arXiv: https://arxiv.org/abs/2609.09135v1
- arXiv ID: 2609.09135

---

🔍 **核心问题**：现有测试时强化学习（TTRL）依赖答案级自投票生成奖励，但代码生成中程序无法按表面形式比较，导致缺乏可用的训练信号。

🛠 **方法**：提出探针驱动的TTRL，从问题陈述构造无输出探针输入并执行候选程序，基于行为一致性定义探针共识奖励（PCR）；进一步提出熵正则化排名掩码策略优化（ERPO），通过排名掩码将低PCR转为保守负更新，并用熵上限控制策略漂移。

✨ **主要贡献**：首次将TTRL有效应用于代码生成，ERPO在编码基准上显著提升pass@1和pass@k，在域内适应和零样本迁移中均表现优异，且能缓解奖励黑客问题。

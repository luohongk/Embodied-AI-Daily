# Self-supervised In-context Operator Learning for Stochastic Mean-Field Control

- arXiv: https://arxiv.org/abs/2608.18282v1
- arXiv ID: 2608.18282

---

🔍 **核心问题**：现有方法每次只能求解一个随机平均场控制（MFC）问题实例，任务变化时需重新优化，缺乏能跨任务泛化的统一求解框架。

🛠 **方法**：将随机MFC建模为算子学习问题，提出NFIST（Normalizing Flow Invertible Solution Transformer），结合概率流ODE与基于可逆归一化流的Transformer，通过上下文学习（in-context learning）用任务提示（分布参数或粒子云）条件化传输映射，并以自监督方式直接最小化随机控制目标进行端到端训练。

✨ **主要贡献**：首次实现无网格、自监督的随机MFC神经算子，支持单次前向传播零样本泛化到未见任务；通过精确逆与解析对数行列式实现闭式得分评估（每粒子O(d)成本）；理论上证明了算子学习与逐任务优化的一致性；在随机最优控制、薛定谔桥、系统性风险控制和避障路径规划等实验中显著降低计算成本并验证泛化能力。

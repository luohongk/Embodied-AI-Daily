# SurgVIL: Scaling Surgical Robot Imitation Learning with Open-source Surgical Videos

- arXiv: https://arxiv.org/abs/2608.16058v1
- arXiv ID: 2608.16058

---

🔍 **核心问题**：手术机器人模仿学习面临数据稀缺问题——真实组织环境中的同步视频与机器人动作数据难以获取，而研究平台上的仿真数据虽含准确动作标签但缺乏视觉多样性。

🛠 **方法**：提出SurgVIL框架，将带运动标签的仿真机器人演示与开源手术视频（无运动标签）结合，通过估计近似运动学作为弱监督信号，用于策略学习。

✨ **主要贡献**：在da Vinci机器人两项任务（针拾取和胆囊切除切割）上，基于ACT、π₀和GR00T-H骨干网络，加入手术视频显著提升了模型对真实组织和分布外场景的泛化能力，为从仿真训练扩展到通用手术策略提供了可扩展路径。

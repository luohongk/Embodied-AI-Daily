# V-FiLLM: Verified Financial LLM Reasoning Benchmark

- arXiv: https://arxiv.org/abs/2608.11047v1
- arXiv ID: 2608.11047

---

🔍 **核心问题**：现有基准在STEM领域评估LLM已较成熟，但结构化数据上的金融推理评估仍缺乏，且人工标注成本高、难以规模化。

🛠 **方法**：提出V-FiLLM框架，从真实表格生成可执行计算树，通过符号化求值获得正确答案，再渲染为自然语言问题，完全脱离人工标注和模型生成误差，并支持四个难度维度（推理深度、表达式广度、金融概念复杂度、上下文规模）的独立控制。

✨ **主要贡献**：实验发现推理深度增加时准确率最高下降51%，对抗性数值扰动下下降47个百分点，揭示金融表格推理的脆弱性；轻量LoRA微调在验证链式推理轨迹上，将留出集准确率从81.1%提升至85.6%，并在FinQA上超越基线5个百分点，证明低成本适配是提升金融组合推理的有效方向。

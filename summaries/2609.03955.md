# Two-Stage Reinforcement Learning for Sound and Adversarial Test Generation in Code LLMs

- arXiv: https://arxiv.org/abs/2609.03955v1
- arXiv ID: 2609.03955

---

🔍 **核心问题**：代码大语言模型（LLMs）在生成代码时，高质量测试用例稀缺，因为测试用例需同时具备正确性（sound）和判别性（discriminative），这限制了模型通过可执行反馈进行强化学习的效果。

🛠 **方法**：提出两阶段强化学习框架TCS（Test Cases Scaling）。第一阶段生成与参考解一致的测试，第二阶段将缓冲区限制在当前失败模式上，学习生成反例测试，并采用滚动策略对齐的缓冲区进行训练。

✨ **主要贡献**：在TACO和LiveCodeBench基准上，TCS显著提升了pass@1和基于生成测试的推理时答案选择性能，且学到的测试生成器还能有效筛选其他LLM的输出。

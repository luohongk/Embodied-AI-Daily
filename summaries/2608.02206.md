# CLEAR: Conflict-aware Learning via Evidence-guided Adaptive Routing for Unified Sparse-View 3D Gaussian Super-Resolution

- arXiv: https://arxiv.org/abs/2608.02206v1
- arXiv ID: 2608.02206

---

🔍 **核心问题**：稀疏视角3D高斯泼溅超分辨率任务中，现有两阶段方法（先低分辨率重建再高分辨率细化）导致误差累积和几何信息丢失，且缺乏统一框架。

🛠 **方法**：提出CLEAR，首个统一单阶段框架，联合优化真实低分辨率观测与外部高分辨率先验；采用高斯级冲突感知优化策略（以LR梯度为锚，仅对严重HR冲突做证据条件软修正），并引入证据引导的Patch-to-Gaussian路由机制选择性传递高频梯度和致密化，辅以共享高斯dropout和分离的中间训练锚定增强鲁棒性。

✨ **主要贡献**：在合成和真实世界4倍超分基准上达到最先进渲染质量和几何保真度，首次实现稀疏视角3D高斯超分辨率的单阶段统一处理，有效缓解梯度冲突并恢复高频细节。

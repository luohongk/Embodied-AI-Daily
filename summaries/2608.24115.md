# PonderPounce: A Pretrained MLLM as an Episode Context Engine for Robot Control

- arXiv: https://arxiv.org/abs/2608.24115v1
- arXiv ID: 2608.24115

---

🔍 **核心问题**：现有视觉-语言-动作（VLA）模型虽具备多模态大语言模型（MLLM）的上下文推理能力，但未将其用作机器人控制的长期记忆，导致在部分可观测环境下策略性能受限。

🛠 **方法**：提出PonderPounce框架，将MLLM（Ponder，System2）的原生因果上下文作为机器人记忆，异步生成连续认知token供动作模型（Pounce，System1）使用；两者端到端联合训练，无需专用记忆模块或桥接预训练，并通过优化服务实现低延迟推理。

✨ **主要贡献**：在RoboMME基准上，9B模型达60.83%（0.8B为50.04%），远超FrameSamp+Modul（44.51%）和当前观测基线（17.93%）；9倍数据下达75.54%。在RoboCasa-DC上，仅用动作监督即达12.5%，优于最强演示条件基线（11.6%），且认知状态替换为学习空状态时性能降至8.6%，验证了记忆机制的有效性。

# ChainSplat: A Physics-Inspired Screw-Theoretic Model for Learning Deformable Linear Object Dynamics from Multi-View RGB Videos

- arXiv: https://arxiv.org/abs/2608.28570v1
- arXiv ID: 2608.28570

---

🔍 **核心问题**：从多视角RGB视频中学习可变形线性物体（如电缆、绳索）的3D几何、外观、运动学与动力学，以支持机器人精准操控，同时克服现有方法依赖深度输入、状态表示高维且计算昂贵的问题。

🛠 **方法**：提出ChainSplat框架，将DLO建模为通过转动关节连接的刚性连杆开放链，采用螺旋理论（screw theory）获得解析模型和紧凑状态表示，并与高斯泼溅（Gaussian splatting）结合，联合学习动力学、几何和外观，并支持任意状态的高保真RGB渲染。

✨ **主要贡献**：在真实实验中，ChainSplat在动力学预测、3D几何重建和RGB渲染上达到最先进性能，并实现实时状态与力估计，以及基于模型的轨迹优化，验证了其在真实机器人操控中的实用性。

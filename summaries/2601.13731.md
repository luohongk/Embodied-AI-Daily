# Breaking the Data Barrier in Learning Symbolic Computation: A Case Study on Variable Ordering Suggestion for Cylindrical Algebraic Decomposition

- arXiv: https://arxiv.org/abs/2601.13731v2
- arXiv ID: 2601.13731

---

🔍 **核心问题**：在符号计算中，圆柱代数分解（CAD）的效率高度依赖变量排序，但现有监督学习方法因难以获取大量标注数据而无法超越基于专家经验的启发式方法。

🛠 **方法**：设计一系列紧密关联的任务以轻松获取大量标注数据，利用这些数据预训练Transformer模型，再在CAD排序数据集上进行微调。

✨ **主要贡献**：实验表明，新模型预测的变量排序平均显著优于最佳启发式方法，突破了数据获取瓶颈，提升了符号计算效率。

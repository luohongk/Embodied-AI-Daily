# CLARE: Scalable Class-Incremental Continual Learning via a Sparsity-Based Framework

- arXiv: https://arxiv.org/abs/2609.17026v1
- arXiv ID: 2609.17026

---

🔍 **核心问题**：持续学习在长任务序列上顺序训练时，因任务间干扰和可塑性丧失而出现可扩展性瓶颈，导致性能下降。

🛠 **方法**：提出CLARE框架，分两阶段进行——先通过稀疏化目标识别任务关键的稀疏参数掩码，再仅对掩码选中的参数进行掩码约束微调，实现共享适配器空间中的任务累积。

✨ **主要贡献**：提出稀疏驱动的两阶段适配器机制，在减少任务间破坏性干扰的同时提升可扩展性；在Omnibenchmark-1k上学习100个任务后，最终准确率大幅超越强基线，分别比EASE提升4.64%和13.34%。

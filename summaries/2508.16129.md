# Bridging the Gap in Ophthalmic AI: MM-Retinal-Reason Dataset and OphthaReason Model toward Dynamic Multimodal Reasoning

- arXiv: https://arxiv.org/abs/2508.16129v3
- arXiv ID: 2508.16129

---

🔍 **核心问题**：现有眼科多模态大模型仅能进行基于视觉特征匹配的浅层推理，无法模拟真实临床中整合病史、主诉与影像数据的复杂推理过程。

🛠 **方法**：构建首个涵盖基础与复杂推理任务的眼科多模态数据集MM-Retinal-Reason，并提出眼科专用推理模型OphthaReason，其核心采用不确定性感知动态思维（UADT）方法，通过熵估计样本级不确定性并利用形状优势机制动态调节推理深度。

✨ **主要贡献**：在基础与复杂推理任务上均达到最优性能，相比通用/医学/强化学习医学/眼科多模态大模型分别提升至少24.92%、15.00%、21.20%和17.66%。

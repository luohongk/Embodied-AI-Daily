# Training a Conditioned Video Game Agent on a VLM Annotated Dataset

- arXiv: https://arxiv.org/abs/2608.05954v1
- arXiv ID: 2608.05954

---

🔍 **核心问题**：传统强化学习在视频游戏训练中依赖游戏引擎获取奖励，且奖励设计需反复试错，稀疏奖励难以解释，导致训练困难。

🛠 **方法**：使用视觉语言模型（VLMs）对视频游戏数据集进行自动标注，提取人类定义的奖励信号，并利用离线强化学习训练一个条件化智能体，使其能根据目标回报调整行为。

✨ **主要贡献**：提出一种无需游戏引擎的奖励获取方式，通过VLM标注实现离线RL训练，初步实验验证了可行性，并指出了早期实验中的难点与局限。

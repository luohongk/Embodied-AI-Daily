# Privacy Leakage via Output Label Space and Differentially Private Continual Learning

- arXiv: https://arxiv.org/abs/2411.04680v6
- arXiv ID: 2411.04680

---

🔍 **核心问题**：论文指出分类模型的输出标签空间可能成为隐私侧信道，导致即使模型训练满足差分隐私（DP），攻击者仍能通过标签空间泄露敏感信息，尤其在持续学习（CL）中标签空间动态变化时风险加剧。

🛠 **方法**：作者形式化了持续学习场景下的差分隐私定义，并提出两种消除侧信道的方法：一是对敏感数据中的标签应用最优DP机制进行发布，二是使用大型公共标签空间；同时通过适配预训练模型来评估这些方法的权衡。

✨ **主要贡献**：首次识别并形式化输出标签空间作为隐私侧信道，提出针对性的防御方法；实验表明在Split-CIFAR-100和Split-ImageNet-R上，所提方法在更强的隐私模型下比现有工作获得更高的模型精度。

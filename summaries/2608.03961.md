# Interpretable Adaptive Sampling for LLM Test-Time Scaling

- arXiv: https://arxiv.org/abs/2608.03961v1
- arXiv ID: 2608.03961

---

🔍 **核心问题**：LLM测试时扩展中，固定采样预算对简单和困难提示分配相同计算量，且缺乏可解释性，无法说明为何某提示获得特定采样数。

🛠 **方法**：提出自适应测试时扩展，使用轻量级模糊控制器，将提示复杂度和模型置信度等可解释信号映射为每查询采样预算，简单或高置信度提示分配少样本，困难或低置信度提示分配多样本。

✨ **主要贡献**：在公平对齐协议下，模糊自适应控制优于多种标准基线，接近全预算控制性能，同时减少平均采样数，使推理计算可检查且更高效。

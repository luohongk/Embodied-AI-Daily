# Macro-Action Topological Navigation under Noisy Localization using Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.23055v1
- arXiv ID: 2608.23055

---

🔍 **核心问题**：在大型逼真3D环境中，仅依赖原始像素和相机自身进行定位的强化学习智能体，如何在无真实位姿信息下完成多目标顺序导航任务。

🛠 **方法**：提出基于物体中心的拓扑控制器，用ORB特征库提供粗略位姿测量，结合最小扩展卡尔曼滤波器（EKF）融合运动模型，替代真实位姿估计；智能体利用局部一致的位姿跟随短边并视觉锁定目标，无需完整SLAM。

✨ **主要贡献**：首次证明纯强化学习可在逼真Habitat模拟器中仅凭视觉和局部一致位姿完成长距离导航，且位姿漂移不影响任务，更贴近生物导航机制，显著降低模型复杂度。

# TONAV: Task-Oriented Navigation and Action-Velocity Chunk Learning for Articulated Object Quadrupedal Mobile Manipulation

- arXiv: https://arxiv.org/abs/2608.22296v1
- arXiv ID: 2608.22296

---

🔍 **核心问题**：四足移动操作中，导航与操作之间存在“可达性-可操作性”差距，且跟踪滞后、运动抖动和接触不稳定限制了连续交互。

🛠 **方法**：提出TONAV统一框架，包含位置-速度耦合遥操作采集演示、基于视觉语言推理的任务导向导航（将高层指令分解为子目标并自适应调整基座），以及动作-速度块学习（联合建模关节位置及其时间变化，在速度监督下实现平滑稳定操作）。

✨ **主要贡献**：在多种铰接物体任务上，TONAV显著提高了任务导向导航和完整移动操作的成功率，有效弥合了导航-操作差距并改善了连续接触交互的稳定性。

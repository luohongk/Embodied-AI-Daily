# NormLift: From Lifted Features To Semantic Reliability In 3D Gaussian Splatting

- arXiv: https://arxiv.org/abs/2609.18898v1
- arXiv ID: 2609.18898

---

🔍 **核心问题**：现有将2D语义特征提升到3D高斯的方法多从渲染角度解释，将其视为可线性组合的欧氏变量，但这与下游任务中每个高斯在余弦嵌入空间被独立查询的实际用法不符。

🛠 **方法**：从3D视角重新审视特征提升，将每个高斯的语义分配建模为CLIP单位球面上的余弦对齐问题，推导出L2归一化语义反投影特征为闭式解，并据此将范数分解为视图内与视图间一致性，以特征幅值作为语义可靠性信号，结合多视图支持度校准，引导模式投票式精炼（避免线性平均以保持CLIP特征有效性）。

✨ **主要贡献**：提出NormLift这一无需训练的高效框架，从理论上为标准的特征提升规则提供了新的解释，并利用特征范数作为语义可靠性指标指导精炼，在开放词汇3D语义分割任务上取得强劲性能。

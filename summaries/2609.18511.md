# Learning from Distributed Eyes: Leveraging Collaborative Perception for Automated Model Adaptation

- arXiv: https://arxiv.org/abs/2609.18511v1
- arXiv ID: 2609.18511

---

🔍 **核心问题**：自动驾驶感知模型因域偏移难以泛化到新环境，而仅依赖自车数据的无监督自适应方法伪标签质量差，导致模型适应效果不佳。

🛠 **方法**：提出LDE框架，将协同感知（CP）转化为高质量监督信号用于模型自适应；设计了面向自适应的特征共享机制（选择性传输关键信息）、FoV过滤方法（剔除视角不匹配的标签）以及课程学习策略（渐进式利用伪标签）。

✨ **主要贡献**：有效解决了协同感知中通信瓶颈、视角差异和标签不可靠三大挑战，在3D目标检测任务上持续优于预训练模型和现有最先进的无监督自适应方法。

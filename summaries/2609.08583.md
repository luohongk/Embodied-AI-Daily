# Estimating Semantic Ambiguity via Gaussian Context Distributions for VLM-Driven Traversability Analysis

- arXiv: https://arxiv.org/abs/2609.08583v1
- arXiv ID: 2609.08583

---

🔍 **核心问题**：解决视觉语言模型（VLM）在非结构化环境导航中因语义歧义（如冲突预测）导致的危险决策问题。

🛠 **方法**：提出基于高斯上下文分布（GCD）的遍历性估计管线，利用概念锚定将开放词汇VLM预测映射到连续物理遍历性尺度，并基于分布统计特性生成稠密遍历性图和不确定性图。

✨ **主要贡献**：在真实GOOSE数据集上验证了不确定性度量与视觉伪影、混合地形重叠等歧义源的相关性，在保持竞争力的同时提供统计不确定性估计，提升复杂户外环境下的自主导航安全性。

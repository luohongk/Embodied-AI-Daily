# ValueFormer: A Causal Transformer Value Function with Stage-Aware Labels for Semi-Autonomous Vision-Language-Action Policies

- arXiv: https://arxiv.org/abs/2608.02958v1
- arXiv ID: 2608.02958

---

🔍 **核心问题**：行为克隆训练的视觉-语言-动作（VLA）策略在失败时无法从动作流中察觉异常，因为模仿学习缺乏进度信号，而强化学习因真实机器人成本高且变形食物难以仿真而不实用。

🛠 **方法**：提出ValueFormer，一个基于冻结DINOv3骨干的紧凑因果Transformer，单次前向输出两个逐帧信号——平滑的蒙特卡洛价值（用于优势估计）和尖锐的二元价值（用于在线错误检测）；失败片段采用阶段感知的成功-衰减回报标签，错误检测从错误区间而非单一失败时刻监督。

✨ **主要贡献**：在真实双臂三明治组装任务（1427个片段）中，评论家派生的逐帧训练权重将任务完成率从70%提升至85%（n=20噪声范围内）；批处理bf16编码器将实时服务成本降低3-5倍，使评论家与策略在单GPU上以2Hz并行运行。

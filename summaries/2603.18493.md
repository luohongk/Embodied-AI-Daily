# FILT3R: Latent State Adaptive Kalman Filter for Streaming 3D Reconstruction

- arXiv: https://arxiv.org/abs/2603.18493v2
- arXiv ID: 2603.18493

---

🔍 **核心问题**：流式3D重建中，循环状态更新规则（激进覆盖或保守更新）会导致遗忘历史信息或无法跟踪新证据，且在训练时间范围外变得不稳定。

🛠 **方法**：提出FILT3R，一种无需训练的潜在滤波层，将循环状态更新视为token空间中的随机状态估计。它维护每个token的方差，计算卡尔曼增益以自适应平衡记忆保留与新观测，并通过EMA归一化的时间漂移在线估计过程噪声。

✨ **主要贡献**：FILT3R提供可解释的即插即用更新规则，泛化覆盖和门控策略为特例。实验表明，在稳定区域增益随证据积累而收缩，在真实场景变化时增益上升，从而在深度、姿态和3D重建任务中显著提升长时稳定性，优于现有方法。

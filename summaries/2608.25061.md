# DataKernelBench: Can LLMs Optimize Database Queries on GPUs?

- arXiv: https://arxiv.org/abs/2608.25061v2
- arXiv ID: 2608.25061

---

🔍 **核心问题**：现有LLM内核基准测试聚焦于机器学习算子，未覆盖数据库查询中不规则、异构且数据移动密集的内核优化，导致LLM在数据库场景下的性能优化能力缺乏评估。

🛠 **方法**：提出DataKernelBench，将SQL转换为PyTorch TorchPlan程序，并让LLM通过执行引导修复（execution-guided repair）优化核心张量片段或完整查询的CUDA/Triton实现；对超GPU内存数据，扩展TorchPlan以支持Dask-cuDF按需分区加载。

✨ **主要贡献**：在TPC-H SF10（H100）上，最强全查询CUDA配置较TorchPlan基线实现2.11×加速且全通过率；在SF100（四块H100）上实现2.54×加速。发现高性能实现常用内核融合与执行策略变更，强模型更受益于全查询特化，且工作负载上下文比硬件上下文更重要。

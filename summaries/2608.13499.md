# OpScale: Operator-level Provisioning and Autoscaling for LLM Serving

- arXiv: https://arxiv.org/abs/2608.13499v1
- arXiv ID: 2608.13499

---

🔍 **核心问题**：在云GPU集群上服务大语言模型时，如何在满足严格用户SLO（如首字延迟）的同时实现成本效率，现有以整个模型为单位的粗粒度扩缩容常导致SLO违规或GPU利用率低下。

🛠 **方法**：提出OpScale，一种算子级（operator-level）的编排框架，包括性能剖析、资源供给、放置和运行时服务，以算子为弹性伸缩单元，并设计策略应对细粒度带来的高复杂度和空间爆炸问题。

✨ **主要贡献**：通过实验证明，OpScale在生产负载下（最多40块A100和24块GB200）相比现有方法，可减少最多36.3%的GPU使用和28%的功耗，或在固定成本下提升44%的吞吐量，同时满足SLO要求。

# Scientific Graphics Program Synthesis via Dual Self-Consistency Reinforcement Learning

- arXiv: https://arxiv.org/abs/2604.06079v2
- arXiv ID: 2604.06079

---

🔍 **核心问题**：科学图形程序合成中，多模态大语言模型生成TikZ代码时面临数据质量不足（图像-代码对缺乏严格可执行性和视觉对齐）以及评估标准缺失（缺乏结构和视觉保真度基准）两大挑战。

🛠 **方法**：提出闭环框架，包含执行中心数据引擎构建的SciTikZ-230K高质量数据集、多维度评估基准SciTikZ-Bench，以及创新的双自一致性强化学习优化范式（利用往返验证惩罚退化代码并增强整体自一致性）。

✨ **主要贡献**：构建了覆盖11个科学领域的大规模数据集和综合评估基准，提出双自一致性强化学习方法，训练出的SciTikZer-8B模型在性能上超越Gemini-2.5-Pro和Qwen3-VL-235B等专有及超大模型，达到当前最优水平。

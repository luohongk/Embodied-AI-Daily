# Automatic Model Card Generation Using an LLM

- arXiv: https://arxiv.org/abs/2608.24807v1
- arXiv ID: 2608.24807

---

🔍 **核心问题**：现有模型卡片缺乏统一结构，且许多模型没有模型卡片，导致模型比较和解读困难。

🛠 **方法**：提出两种基于大语言模型（LLM）的方法——MCTidy用于将现有模型卡片重组为标准模板，MCGenie用于直接从模型仓库数据生成模型卡片。

✨ **主要贡献**：在48个Hugging Face模型上验证，MCTidy实现高信息保留率和准确章节分配，幻觉极少且运行稳定；MCGenie生成的卡片语义相似度均值约0.9，超半数完全正确，生成质量依赖配套资源（尤其论文）。实验证明LLM方法可规模化生成标准化模型文档。

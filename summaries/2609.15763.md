# Sylvas: Synergistic Learning Value based Device Scheduling in Federated Continual Learning

- arXiv: https://arxiv.org/abs/2609.15763v1
- arXiv ID: 2609.15763

---

🔍 **核心问题**：在联邦持续学习（FCL）中，时空数据分布动态变化且标签稀缺，如何量化各边缘设备对全局学习的贡献，并在资源约束下调度最有价值的设备实现及时模型更新。

🛠 **方法**：提出Sylvas框架，从分布价值（时空分布视角衡量设备数据对全局模型的贡献）和标签价值（伪标签数据的数量与可靠性权衡）两个维度评估学习价值，融合为协同学习价值指标，据此在通信与计算资源约束下调度高价值设备。

✨ **主要贡献**：实现了时空分布动态下的及时模型自适应，并能有效利用无标签数据，为无线边缘FCL场景下的设备调度提供了协同学习价值驱动的解决方案。

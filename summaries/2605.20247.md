# CP-MoE: Consistency-Preserving Mixture-of-Experts for Continual Learning

- arXiv: https://arxiv.org/abs/2605.20247v2
- arXiv ID: 2605.20247

---

🔍 **核心问题**：解决大语言模型和视觉-语言模型在持续学习中因任务更新导致灾难性遗忘，以及现有MoE方法在知识隔离与参数覆盖之间的权衡问题。

🛠 **方法**：提出CP-MoE框架，引入“瞬态专家”捕获早期任务特定更新，并设计一致性保持路由偏置（利用瞬态专家与稳定专家的表示相似性引导路由选择）和瞬态专家引导的正则化机制（在参数合并时保护重要历史参数）。

✨ **主要贡献**：在SuperNI和VQA v2基准上验证，CP-MoE显著减少参数干扰和遗忘，同时保持跨任务知识迁移，达到最先进性能，并在多模态视觉推理任务中持续优于强MoE基线。

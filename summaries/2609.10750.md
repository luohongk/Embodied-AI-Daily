# When Synthetic Data Hurts: On Catastrophic Forgetting in Skill Retrieval for LLM Agents

- arXiv: https://arxiv.org/abs/2609.10750v1
- arXiv ID: 2609.10750

---

🔍 **核心问题**：LLM智能体需从大规模技能库中检索技能，但在真实监督数据稀缺、依赖合成数据微调时，会出现对真实及分布外（OOD）数据的灾难性遗忘。

🛠 **方法**：构建覆盖34,396个技能的生产级技能路由器，并借鉴持续学习思想，评估嵌入锚点正则、LwF、EWC和L2初始化等遗忘缓解微调方法。

✨ **主要贡献**：揭示了合成数据微调虽提升分布内检索却导致灾难性遗忘的问题，并证明上述方法既能保持OOD技能检索性能，又将0.6B Qwen检索器/重排器的合成分布内检索提升13.98%，为稀缺多正样本监督提供了实用基准与稳健微调方案。

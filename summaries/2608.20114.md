# DECOWAM: Decoupled Whole-Body World-Action Model for Legged Mobile Manipulation

- arXiv: https://arxiv.org/abs/2608.20114v1
- arXiv ID: 2608.20114

---

🔍 **核心问题**：现有世界-动作模型主要针对固定基座平台，未显式区分移动操作中相机自身运动与基座/手臂动作，导致在腿式移动操作场景下视觉预测和动作控制效果不佳。

🛠 **方法**：提出DECOWAM，一种解耦的全身世界-动作模型，通过专用条件接口分离基座与手臂动作，采用冻结FastWAM骨干加残差适配器、从特权观测蒸馏的动作等价未来瓶颈、对抗分离的基座/手臂潜变量，以及基座速度条件化视频预测。

✨ **主要贡献**：引入ARMDOG真实机器人数据集，在固定回放协议下相比FastWAM将动作MSE降低21.7%（仅需25.95M可训练参数），在79次闭环实验中取得最佳全身协调性和基座位移鲁棒性，任务完成率与最强基线相当，证明具身感知因子分解可支持参数高效的联合视觉预测与全身控制。

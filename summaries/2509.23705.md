# MDCPP: Multi-Robot Dynamic Coverage Path Planning for Workload Adaptation

- arXiv: https://arxiv.org/abs/2509.23705v2
- arXiv ID: 2509.23705

---

🔍 **核心问题**：传统多机器人覆盖路径规划假设机器人匀速运动，仅平衡几何面积或路径长度，但在实际任务中机器人速度会因感知或交互任务而空间变化，导致相同面积产生显著不同的完成时间。

🛠 **方法**：提出MDCPP框架，利用高斯混合模型从部分观测中学习工作量分布，预测每个栅格的服务时间，并通过分布式容量约束分配反复重新划分未覆盖区域，实现动态负载均衡。

✨ **主要贡献**：证明了分配轮次的有限终止性和成对局部最优性，给出了服务时间makespan的误差界及完全覆盖的充分条件；600次仿真表明在强异质性场景下预测价值显著，优于非预测性方法；三台UGV实验验证了实际定位、驱动和无线控制下的路线执行与速度自适应能力。

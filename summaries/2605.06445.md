# Constraint Decay: The Fragility of LLM Agents in Backend Code Generation

- arXiv: https://arxiv.org/abs/2605.06445v2
- arXiv ID: 2605.06445

---

🔍 **核心问题**：LLM智能体在宽松规范下代码生成表现良好，但生产级软件要求严格遵循架构模式、数据库、ORM等结构性约束，现有基准忽视了这些非功能性需求，导致功能正确但结构随意的方案被过度奖励。

🛠 **方法**：通过固定统一的API契约，设计80个全新生成任务和20个功能实现任务，覆盖八种Web框架，采用端到端行为测试与静态验证器双重评估，系统隔离并测量结构复杂度对智能体表现的影响。

✨ **主要贡献**：揭示了“约束衰减”现象——随结构要求累积，智能体断言通过率平均下降27.28分；发现框架敏感性差异（如Flask表现优于FastAPI/Django），并定位数据层缺陷（查询组合错误、ORM运行时违规）为主要根因，表明同时满足功能与结构需求仍是编码智能体的关键开放挑战。

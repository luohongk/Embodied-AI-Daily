# SkillComposer: Learning Reusable Skills for Natural-Language Robot Programming

- arXiv: https://arxiv.org/abs/2608.14944v1
- arXiv ID: 2608.14944

---

🔍 **核心问题**：自然语言编程机器人在处理复杂多步任务时，难以分解高层指令、生成代码，且无法复用已有解决方案。

🛠 **方法**：提出SkillComposer系统，采用“生成-测试”架构，由大语言模型迭代生成并修正机器人程序，执行成功后通过在线库学习算法将重复函数序列压缩为可复用的宏技能。

✨ **主要贡献**：通过消融实验和12人用户研究证明，评估者引导生成与技能抽象显著提升任务成功率、可用性，并降低用户编程负担，适用于操作与机器人照护任务。

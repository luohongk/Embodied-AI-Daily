# Blind Dexterity: Whole-Body Humanoid Manipulation via Pure Proprioception

- arXiv: https://arxiv.org/abs/2608.29487v1
- arXiv ID: 2608.29487

---

🔍 **核心问题**：探索仅依赖机器人本体感知（关节编码器）而非视觉、力觉或触觉传感器，能否实现全身灵巧操作与交互感知。

🛠 **方法**：在Unitree G1人形机器人上训练纯本体感知策略，利用关节编码器在柔顺接触中的动态读数作为“全身触觉通道”，并配合独立训练的任务特定状态估计器来解码物体状态。

✨ **主要贡献**：证明了仅凭关节编码器和柔顺驱动即可完成推扰恢复行走、足球拦截、提箱、滑板安装等多样任务，且状态估计误差在有效接触后快速下降，为低成本全身灵巧操作提供了实用基础。

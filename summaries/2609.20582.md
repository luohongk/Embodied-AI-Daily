# V2-STRep: VLM-Grounded Structured Task Representations for Reusable Robot Skills Acquired from Generated Videos

- arXiv: https://arxiv.org/abs/2609.20582v1
- arXiv ID: 2609.20582

---

🔍 **核心问题**：如何从生成视频中提取可复用的机器人技能，避免为每个任务单独录制演示，并解决生成运动仅捕获单一场景特定实现、任务结构与约束隐式的问题。

🛠 **方法**：提出零样本框架 V2-STRep，利用 VLM 提供的 2D 图像线索结合 RGB-D 观测提升到 3D，构建结构化任务表示（运动阶段、参考、约束及点/法向/轴/平面/6D位姿等几何目标），并通过几何规则迁移运动与任务约束轨迹优化完成抓取选择与运动规划。

✨ **主要贡献**：实现生成视频运动到可复用机器人技能的转换，支持跨场景迁移与指令变更下的技能复用而无需重新生成视频；在六项真实操作任务中执行成功率优于基线，并验证了可靠的跨场景迁移与部署指令适应能力。

# $\mathcal{P}^3$: Toward Versatile Embodied Agents

- arXiv: https://arxiv.org/abs/2508.07033v3
- arXiv ID: 2508.07033

---

🔍 **核心问题**：具身智能体在动态环境感知、开放工具访问和复杂多任务规划方面存在三大瓶颈，现有方法依赖工具反馈导致实时性差、误差累积且多任务调度不足。

🛠 **方法**：提出统一框架 \(\mathcal{P}^3\)，集成实时感知与动态调度，主动从环境提取任务相关信息，无需反馈即可接入工具，并基于任务紧急性和依赖关系动态调整执行顺序。

✨ **主要贡献**：构建Active Task Perception (ATP)基准以量化VLM的主动场景理解能力，实验验证多种VLM可检测并提议主动任务，真实机器人实验证明该方法能弥合基准与部署差距，实现可迁移的通用具身智能体。

# Knowing When to Stop: Adaptive Action Chunking via Internal Cross-Attention Dynamics in VLAs

- arXiv: https://arxiv.org/abs/2609.00908v1
- arXiv ID: 2609.00908

---

🔍 **核心问题**：现代视觉-语言-动作（VLA）模型中的固定动作分块执行策略在效率与准确性之间存在权衡——短分块需频繁推理且易振荡，长分块则可能与新观察状态失配。

🛠 **方法**：提出一种基于动作专家内部交叉注意力动态的自适应分块机制，通过检测注意力熵持续升高至平台期（对应预测误差增大）来在线截断执行，无需额外训练，仅利用策略已计算的注意力权重。

✨ **主要贡献**：在π₀.₅和X-VLA上，于RoboTwin 2.0、LIBERO及三项真实操作任务中，相比固定分块和自适应基线，该方法显著提升平均任务成功率，同时保持高效闭环控制，验证了交叉注意力动态可作为VLA自适应执行的实用内部信号。

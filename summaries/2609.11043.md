# LTLDiff: Finite Linear Temporal Logic-Guided Data Generation and Diffusion Policies for Multi-agent Robotic Manipulation

- arXiv: https://arxiv.org/abs/2609.11043v1
- arXiv ID: 2609.11043

---

🔍 **核心问题**：多智能体机器人操作任务中，扩散策略存在不同步、动作顺序错误和协调失败等问题，难以满足任务级的时间、逻辑和安全约束。

🛠 **方法**：提出LTLDiff框架，利用大语言模型从自然语言指令中学习有限线性时序逻辑（LTLf）规范，并通过抽象语法树表示将其嵌入为条件向量，同时指导数据收集和扩散策略训练。

✨ **主要贡献**：实现了逻辑引导的演示数据生成与扩散策略学习的结合，在多智能体操作任务中显著提升了任务成功率，验证了LTLDiff在协调多智能体操作中的有效性。

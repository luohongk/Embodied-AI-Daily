# Calibrate Before Reason: Robust Visual Token Reduction against Semantic Drift in VLMs

- arXiv: https://arxiv.org/abs/2607.27700v1
- arXiv ID: 2607.27700

---

🔍 **核心问题**：大视觉语言模型（VLMs）因视觉token序列过长导致推理开销巨大，而现有token缩减方法在压缩时可能丢弃或扭曲关键视觉信息，引发语义漂移，损害模型理解能力。

🛠 **方法**：提出CaRe框架，遵循“先校准再推理”原则，包含两个互补模块：1）扰动鲁棒校准锚定，在多方向扰动下识别模型侧影响稳定的锚点；2）置信门控token校准，从未选token中提取可靠信号注入锚点，无需训练即可保持语义保真。

✨ **主要贡献**：CaRe在多种VLM架构和基准上优于现有token缩减方法，剪除94.4%视觉token时仍保留96.4%的原始全token性能，端到端推理速度提升最高达2.30倍。

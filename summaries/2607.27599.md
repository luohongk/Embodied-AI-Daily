# World Action Planner: Generalizable Decision-Making with Action-Conditioned World Models

- arXiv: https://arxiv.org/abs/2607.27599v1
- arXiv ID: 2607.27599

---

🔍 **核心问题**：解决机器人决策系统在多样化场景和任务中泛化能力不足的问题，现有模仿学习策略难以适应新环境和新任务。

🛠 **方法**：提出World Action Planner系统，结合视觉语言模型（VLM）的推理能力与多任务姿态-图像条件世界模型的物理基础，通过初始动作规划、优化与搜索迭代细化，并基于世界模型想象滚动进行推理。

✨ **主要贡献**：在组合任务、新布局和零样本泛化场景中显著优于现有端到端策略模型（如VLA和WAM），展示了更强的泛化性能和决策质量。

# Chain-SLAM: Globally Consistent Backend for Multi-Session LiDAR SLAM via Chained Loop Closure

- arXiv: https://arxiv.org/abs/2609.12221v1
- arXiv ID: 2609.12221

---

🔍 **核心问题**：大规模多会话LiDAR SLAM中，如何在长时间、大空间跨度下保持全局一致性，实现多会话地图的在线对齐与复用。

🛠 **方法**：提出链式回环闭合机制，通过邻接图将几何约束跨会话关键帧传播，结合GNSS邻近地点识别初始化对齐，并在统一因子图中对新旧轨迹进行联合优化。

✨ **主要贡献**：实现了无需动态物体移除、跨平台鲁棒且超参数调优极简的多会话SLAM后端，在大规模数据集上提升了轨迹精度并实现了稳健的多会话集成，同时开源了代码。

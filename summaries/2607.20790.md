# Ocular Verification for Virtual Reality

- arXiv: https://arxiv.org/abs/2607.20790v1
- arXiv ID: 2607.20790

---

🔍 **核心问题**：针对虚拟现实头戴设备中非约束性采集（如离轴注视、不均匀光照、镜面反射）导致的虹膜识别性能下降问题，评估现有ISO/IEC质量指标的适用性并探索改进方案。

🛠 **方法**：在VRBiom数据集上分析ISO/IEC 29794-6虹膜质量指标的局限性；利用生成模型处理数据特异性挑战（如光照校正、反射消除）；分别进行单模态（虹膜、眼周）识别与多模态分数级融合（虹膜+眼周）。

✨ **主要贡献**：发现部分质量指标（如边缘充分性）在VR数据中失效；图像预处理主要提升眼周识别性能；多模态融合相比单模态虹膜识别将等错误率降低约11%。

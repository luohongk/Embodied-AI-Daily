# Rich-Media Re-Ranker: A User Satisfaction-Driven LLM Re-ranking Framework for Rich-Media Search

- arXiv: https://arxiv.org/abs/2602.05408v3
- arXiv ID: 2602.05408

---

🔍 **核心问题**：现有搜索重排序方法在提升用户满意度方面存在不足，主要因为对用户多面意图建模不充分，且忽略了视觉感知等丰富侧信息。

🛠 **方法**：提出Rich-Media Re-Ranker框架，包含Query Planner将会话内查询分解为互补子查询以覆盖潜在意图，并整合基于VLM的视觉内容评估信号，结合多面重排序原则（如相关性、信息增益、新颖性、封面视觉呈现），由LLM进行整体评估，并通过多任务强化学习增强场景适应性。

✨ **主要贡献**：首次将视觉感知信号与LLM重排序结合，实现多维度细粒度用户满意度建模；框架已部署于大规模工业搜索系统，显著提升了在线用户参与率和满意度指标。

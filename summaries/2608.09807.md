# WRAP: Wasserstein-Robust Adaptive Plug-in for Robot Localization

- arXiv: https://arxiv.org/abs/2608.09807v1
- arXiv ID: 2608.09807

---

🔍 **核心问题**：机器人定位在传感条件变化时，会出现有偏误差和协方差校准不准的问题，导致扩展卡尔曼滤波（EKF）和误差状态卡尔曼滤波（ESKF）性能下降。

🛠 **方法**：提出WRAP，一个与适配器无关的Wasserstein鲁棒插件。它通过因果模块提供时变的过程/测量统计量，并用均值保持的Wasserstein局部更新计算最不利协方差和鲁棒增益，同时保持传播模型、残差和回缩不变。

✨ **主要贡献**：在18个UWB-IMU序列上，WRAP将3D位置RMSE相对名义ESKF降低27.4%（仅适配器为19.8%），优于各向同性消融（19.5%）；GNSS-INS实验表明均值适配贡献主要精度提升，DR提升一致性并缓解过紧协方差；鲁棒求解在Jetson Orin Nano上仅需0.05ms（UWB）和2.92ms（GNSS）。

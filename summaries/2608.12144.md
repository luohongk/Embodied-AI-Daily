# ADEPT: A Unified Framework for Deep Learning Test Adequacy

- arXiv: https://arxiv.org/abs/2608.12144v1
- arXiv ID: 2608.12144

---

🔍 **核心问题**：深度学习测试充分性度量指标（如神经元覆盖、特征覆盖等）多以独立原型发布，安装、预处理、执行流程差异大，难以复现、比较和实际应用。

🛠 **方法**：提出统一框架ADEPT，集成多种代表性充分性技术（如神经元覆盖、惊喜充分性、输入分布覆盖、边界覆盖及突变评分），提供模板化指标接口、YAML配置管理、预处理缓存复用和结构化结果报告，并统一执行流程。

✨ **主要贡献**：简化了充分性指标的复现与应用，降低使用门槛，支持扩展新指标，适用于研究与工程实践，避免重复实现或配置不同原型的繁琐工作。

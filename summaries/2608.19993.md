# Optimal Skill Selection for LLM Agents with Provable Bicriteria Guarantees

- arXiv: https://arxiv.org/abs/2608.19993v1
- arXiv ID: 2608.19993

---

🔍 **核心问题**：LLM智能体在有限上下文窗口中加载技能文档时，如何选择最优技能集以最大化任务性能并最小化token成本，现有方法缺乏质量保证和成本意识。

🛠 **方法**：将技能选择建模为带硬token预算的优化问题（最大化单调子模收益减去上下文惩罚），提出多项式时间算法Best Prefix Selection (BPS)，并证明其双准则$(1-1/e,1)$近似保证。

✨ **主要贡献**：首次为技能选择提供理论性能保证（收益系数在多项式时间内最优）；在BigCodeBench变体上，BPS以比最强基线少28%的token达到0.73任务成功率，远超其他方法（0.20–0.52）。

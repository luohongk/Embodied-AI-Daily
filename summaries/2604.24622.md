# CF-VLA: Efficient Coarse-to-Fine Action Generation for Vision-Language-Action Policies

- arXiv: https://arxiv.org/abs/2604.24622v3
- arXiv ID: 2604.24622

---

🔍 **核心问题**：基于流的视觉-语言-动作（VLA）策略虽具强表达力，但需多步推理从高斯噪声恢复动作结构，导致实时约束下效率与质量难以兼顾。

🛠 **方法**：提出CF-VLA，采用粗到精两阶段生成框架——粗阶段学习条件后验将高斯噪声转化为动作感知的初始化，精阶段以固定时间步进行局部细化修正残差；训练时先学受控粗预测器，再联合优化。

✨ **主要贡献**：在低NFE（函数评估次数）下显著提升效率-性能前沿，如NFE=2时全面超越现有方法，部分指标匹敌或超越NFE=10的π₀.₅基线；动作采样延迟降低75.4%，真实机器人成功率83.0%，优于MIP 19.5点、π₀.₅ 4.0点。

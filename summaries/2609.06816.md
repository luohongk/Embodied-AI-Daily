# Unsound Search with Policy and Value Networks in Legends of Code and Magic

- arXiv: https://arxiv.org/abs/2609.06816v1
- arXiv ID: 2609.06816

---

🔍 **核心问题**：在集换式卡牌游戏《Legends of Code and Magic》（LoCM）中，传统观点认为基于枚举信念状态的不完美信息搜索因状态空间过大（2^101）而不可行，本文旨在验证理论上“不健全”（unsound）的完美信息蒙特卡洛搜索在该游戏中是否有效。

🛠 **方法**：通过模仿学习亚军策略NeteaseOPD构建策略与价值前馈网络，在战斗阶段对从对手牌组先验分布（基于亚军选牌）采样的世界进行搜索，并与无搜索的冠军智能体ByteRL对比。

✨ **主要贡献**：在严格配置下，搜索智能体以51.35%胜率（95% CI [50.37, 52.33]）击败ByteRL；无搜索时仅26.8%，搜索带来+24.6%提升。此外，该智能体在对抗已发布的最佳响应攻击时，比ByteRL更具鲁棒性，证明不健全搜索在不完美信息游戏中可产生更强且更抗攻击的智能体。

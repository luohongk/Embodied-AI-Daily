# SAGP: Semantic Affordance-Guided Grasp Planning via Coarse-Zone VLM Reasoning

- arXiv: https://arxiv.org/abs/2607.29374v1
- arXiv ID: 2607.29374

---

🔍 **核心问题**：传统基于几何的抓取规划虽然能保证物理有效性，但忽略了功能语义，常生成如抓杯沿、刀锋等实际不合适的抓取姿态，导致下游任务失败。

🛠 **方法**：提出SAGP，一种无需训练的流水线，通过粗区域抽象层将点云划分为空间区域（顶部、中部、底部、侧面、突起），利用预训练VLM进行零样本区域抓取质量评估，并与几何、可达性和任务对齐信号融合，重新排序抓取候选。

✨ **主要贡献**：在YCB物体和PyBullet仿真中验证，SAGP在保持几何规划高成功率的同时显著提升抓取的功能适切性，尤其对非对称、带柄物体效果突出，为VLM推理与几何抓取规划提供了无需精细分割的有效桥梁。

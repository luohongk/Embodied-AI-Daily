# Topology-enhanced machine learning for speech signal processing

- arXiv: https://arxiv.org/abs/2311.15210v2
- arXiv ID: 2311.15210

---

🔍 **核心问题**：现有深度学习语音信号处理模型多为黑箱结构，缺乏可解释性，且难以有效捕捉时间序列中内在的复杂结构信息。

🛠 **方法**：提出透明方法 TopCap，利用拓扑方法提取时间序列中的拓扑特征，生成能探测更精细信息（如振动）的描述符，并将其与神经网络相结合。

✨ **主要贡献**：TopCap 在清浊辅音分类中达到与神经网络相当的准确率，且将其特征融入神经网络后，在抗噪鲁棒性、准确率、稳定性、损失函数收敛性和可解释性方面均优于现有最先进方法。

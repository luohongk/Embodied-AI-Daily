# GLAM: Efficient Continual Learning at Scale via Grouped LoRA Adapter Merging

- arXiv: https://arxiv.org/abs/2509.13211v4
- arXiv ID: 2509.13211

---

🔍 **核心问题**：解决大规模预训练模型在长任务序列中持续学习时，如何高效添加新知识并避免灾难性遗忘，同时保持计算和参数开销可控。

🛠 **方法**：提出GLAM框架，基于LoRA适配器合并。每个任务训练一个轻量低秩适配器并附带重要性标量，随后对适配器进行剪枝、重缩放和顺序分组，实现结构化知识复用并限制参数增长；推理时将全部分组合并为单一模块，保证计算成本恒定。

✨ **主要贡献**：在多达50个任务的视觉基准上取得最高准确率，相比最优基线，仅用其16–19%的可训练参数，训练时间减少约63–74%，展示了高效且可扩展的持续学习能力，并公开源代码。

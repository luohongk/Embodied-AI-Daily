# MoMo: Dial Motion Mode in Robot Manipulation with Spatiotemporal Action Tokenization

- arXiv: https://arxiv.org/abs/2607.26315v1
- arXiv ID: 2607.26315

---

🔍 **核心问题**：机器人操作任务中，如何让机器人不仅准确完成任务，还能根据任务、物体和交互场景灵活调整动作的执行方式（如速度、动态程度等），并将这种执行层面的变化作为可复用的行为因素。

🛠 **方法**：提出MoMo框架，采用两阶段模仿学习：先通过时空动作分词器将动作序列离散化，再使用行为克隆Transformer，以任务和连续的运动模式条件作为输入，学习生成不同风格的动作。

✨ **主要贡献**：在6个真实机器人操作任务中，通过调整运动模式条件可产生稳定、动态及中间态的行为，且人类可区分；在仅用一种模式演示的任务上，MoMo能迁移到未见过的模式并保持任务成功率，证明了任务-模式组合的泛化能力，表明运动模式可作为跨任务复用的控制因素。

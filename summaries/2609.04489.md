# Towards Understanding Pause Token Fine-Tuning Dynamics: A Mode Retention Perspective

- arXiv: https://arxiv.org/abs/2609.04489v1
- arXiv ID: 2609.04489

---

🔍 **核心问题**：现有研究主要从计算表达能力角度解释暂停令牌（pause token）对LLM推理的提升，但对其在微调过程中的训练动态缺乏深入理解。

🛠 **方法**：通过两个受控实验揭示暂停令牌的训练不对称性，提出“掩码边界暂停”（MBP）训练规则——在推理步骤边界插入暂停令牌并掩码其损失，并在1B-8B的Qwen和Llama模型上验证。

✨ **主要贡献**：发现暂停令牌能显著减少对已学分布的覆盖（模式保留），并促使边界令牌编码更多下游信息（非近视压缩）；MBP在数学和代码推理上分别提升最高6点和2.5点，且不损害通用语言能力，并可将收益扩展到GRPO，将暂停令牌重新定义为训练动态干预而非仅推理计算工具。

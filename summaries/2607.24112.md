# Scaling GUI Agents with Visual State Transitions

- arXiv: https://arxiv.org/abs/2607.24112v1
- arXiv ID: 2607.24112

---

🔍 **核心问题**：如何提升GUI智能体在桌面和移动场景中的任务执行能力，解决现有模型对视觉状态变化理解不足的问题。

🛠 **方法**：提出状态转换预训练（STP），在统一多模态模型上联合优化逆动力学（从状态变化预测动作）和前向动力学（从当前状态和动作预测下一状态），从而学习动作相关的视觉表示和GUI动态世界模型。

✨ **主要贡献**：STP预训练后的模型在AgentNetBench、AndroidControl和GUIOdyssey等基准测试中，性能一致优于仅通过轨迹微调的基线模型；联合动力学优化比单目标训练更稳定，且下游性能随转换数据量增加而持续提升。

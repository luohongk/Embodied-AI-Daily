# STAR: A Spatial-Topology Aware Routing Framework for Generalizable 3D Scene Understanding

- arXiv: https://arxiv.org/abs/2608.11699v1
- arXiv ID: 2608.11699

---

🔍 **核心问题**：现有3D场景理解模型难以统一处理不同传感器模态间的拓扑差异，传统基于特征的MoE路由器在语义一致性与几何异质性并存时，难以有效分配专家。

🛠 **方法**：提出STAR框架，包含多属性自监督预训练分支（覆盖拓扑与纹理变化）和域感知专家分支，后者由域空间引导路由（DSR）和熵控动态分配（EDA）两个机制组成，分别捕捉局部拓扑变化和根据路由不确定性调整激活专家数。

✨ **主要贡献**：STAR在ScanNet上达到80.1% mIoU，在S3DIS上达到77.2% mIoU，均优于强基线，验证了跨域表示学习与自适应专家分配结合的有效性。

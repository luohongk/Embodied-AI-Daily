# Machine Learning-Based Cyber Defense for Cloud Infrastructure: An Adaptive Deep Q-Network Architecture for Intelligent Intrusion Detection and Automated Threat Mitigation

- arXiv: https://arxiv.org/abs/2608.12190v1
- arXiv ID: 2608.12190

---

🔍 **核心问题**：针对云环境中日益复杂的网络攻击，需要一种能够实时检测并自主响应的动态安全防御方案。

🛠 **方法**：提出基于强化学习的动态防御框架，采用深度Q网络（DQN）训练防御策略，使用CICIDS2017数据集建模、UNSW-NB15数据集进行外部验证，并包含数据预处理、特征工程和自适应策略学习。

✨ **主要贡献**：DQN模型在准确率（99.72%）、精确率（99.68%）、召回率（99.65%）、F1分数（99.66%）和ROC-AUC（0.999）上均优于决策树、SVM、随机森林、XGBoost和MLP等基线模型，误报率仅0.31%，检测延迟15ms，攻击缓解率达99.54%，展示了强化学习在云环境自主网络安全中的强大潜力。

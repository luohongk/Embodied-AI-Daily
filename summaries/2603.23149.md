# Describe-Then-Act: Proactive Agent Steering via Distilled Language-Action World Models

- arXiv: https://arxiv.org/abs/2603.23149v2
- arXiv ID: 2603.23149

---

🔍 **核心问题**：安全关键型智能体在部署时需要预判动作后果，但现有基于视觉仿真的世界模型延迟过高（每步数秒），难以满足实时性要求。

🛠 **方法**：提出DILLO（DIstiLLed Language-ActiOn World Model），通过跨模态蒸馏训练——用特权视觉语言模型（VLM）标注离线轨迹，让潜在状态条件的大语言模型（LLM）学习预测语义结果，实现纯文本推理路径，完全绕过视觉生成。

✨ **主要贡献**：将范式从“先模拟后行动”转为“先描述后行动”，推理速度比基线快14倍；在MetaWorld和LIBERO基准上，能生成高保真下一状态描述并有效引导策略，任务成功率平均提升9.3个百分点（最高15个百分点）。

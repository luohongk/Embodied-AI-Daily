# Rethinking 3D Noise: Learning 3D-Aware Video Priors via Optimization-Free Morphological Perturbations

- arXiv: https://arxiv.org/abs/2609.03657v1
- arXiv ID: 2609.03657

---

🔍 **核心问题**：神经辐射场（NeRF）和3D高斯泼溅（3DGS）等3D场景表示在稀疏视角设置下会产生严重伪影，现有修复方法依赖成对的有损/干净渲染数据，且需针对每个场景进行昂贵的重建。

🛠 **方法**：提出3D形态扰动（3D Morphological Perturbations）作为免优化的正则化器，将每个高斯视为类似2D像素的基本单元，在其形态参数空间（尺度、旋转、剪枝）上施加扰动，无需逐场景优化即可保持跨视角的空间一致性。

✨ **主要贡献**：该方法消除了数据集构建中的逐场景3DGS优化循环，使模型学到比稀疏视角基线更强的几何先验；在140亿参数视频模型上，相比最先进的图像到图像3D伪影修复器，平均深度误差降低12.5%，并在4项机器人操作任务中的3项上提升策略成功率最高达8.0%。

# NeurRAFT: Robot Motion Planning via Anchor-Level Flow Matching with Clearance-Aware Preference Tuning

- arXiv: https://arxiv.org/abs/2608.24026v1
- arXiv ID: 2608.24026

---

🔍 **核心问题**：现有端到端神经运动规划器在杂乱环境中生成无碰撞轨迹时，因建模密集路径点而浪费计算资源，且模仿学习无法区分安全与近碰撞轨迹，导致测试时仍出现碰撞行为。

🛠 **方法**：提出NeurRAFT框架，采用锚点级流匹配（anchor-level flow matching）生成紧凑锚点，并用雅可比加权损失训练；推理时通过两步积分和三次样条插值恢复全分辨率轨迹。此外，引入基于障碍物间隙感知的Direct Preference Optimization（DPO）直接调整预训练规划器的分布，使其偏向更安全的轨迹，无需增加推理开销。

✨ **主要贡献**：在多个基准上显著优于现有最先进规划器，并在真实Franka机器人上实现零样本迁移，即使在噪声和部分遮挡深度观测下也能稳定工作。关键创新在于锚点级表示与间隙感知偏好调优的结合，有效提升碰撞避免能力且不牺牲推理效率。

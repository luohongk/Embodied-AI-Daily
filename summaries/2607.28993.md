# ST-WAM: Semantic-Temporal World Action Model for Robust Manipulation under Visual Distribution Shifts

- arXiv: https://arxiv.org/abs/2607.28993v1
- arXiv ID: 2607.28993

---

🔍 **核心问题**：世界动作模型（WAMs）在视觉分布偏移下，因依赖像素级未来生成监督，容易将动作相关状态变化与任务无关视觉内容纠缠，导致鲁棒性下降，出现“训练分布幻觉”现象。

🛠 **方法**：提出语义-时间世界动作模型（ST-WAM），使用DINOv3作为共享语义表示进行未来预测和历史检索，同时保留细粒度VAE动态；通过双空间未来专家（DSFE）联合预测VAE潜变量和DINO特征，并利用当前锚定意图检索（CAIR）从近期DINO历史中提取任务相关证据。

✨ **主要贡献**：ST-WAM在LIBERO上达98.7%、RoboTwin 2.0上达92.8%；相比Fast-WAM，零样本LIBERO-Plus性能提升21.3个百分点，真实世界视觉偏移下成功率从25.8%翻倍至61.5%，证明语义-时间建模有效补充像素生成动态，无需额外预训练或任务标注。

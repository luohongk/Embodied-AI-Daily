# ChainVLA: Chaining Vision-Language-Action Queries through a Unified Execution State for Long-Horizon Manipulation

- arXiv: https://arxiv.org/abs/2608.02326v1
- arXiv ID: 2608.02326

---

🔍 **核心问题**：长时程操作中，视觉-语言-动作（VLA）模型在跨查询（cross-query）时无法有效衔接任务进度与运动连续性，导致重复规划时丢失上下文信息。

🛠 **方法**：提出ChainVLA（1.2B参数），通过联合且可修正的“执行状态”串联连续查询。该状态由两部分组成：**Progress Context**（循环工作状态+稀疏事件记忆，携带观测推导的任务进度）和**Motion Tail**（将上一预测未执行的运动延续注入状态构建与动作生成），共同条件化解码器，在最新观测下重新生成动作序列。

✨ **主要贡献**：在RMBench上达到62.8%平均成功率，在四个LIBERO套件上达98.8%；消融实验显示，移除Motion Tail或Progress Context后RMBench成功率分别降至11.2%和3.0%，表明运动连续性对保持观测流（进而推断任务进度）至关重要。

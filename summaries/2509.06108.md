# Using Reinforcement Learning to Optimize the Global and Local Crossing Number

- arXiv: https://arxiv.org/abs/2509.06108v3
- arXiv ID: 2509.06108

---

🔍 **核心问题**：如何利用强化学习优化图绘制的全局与局部交叉数，以提升图的可读性。  
🛠 **方法**：将图绘制问题建模为单人游戏，智能体通过观察顶点的局部几何与结构上下文，选择移动方向以最小化总交叉数或每条边的最大交叉数。  
✨ **主要贡献**：在最小化局部交叉数方面，该方法与现有启发式方法相比具有竞争力且常更优，但在全局交叉数优化上未超越当前最优方法。

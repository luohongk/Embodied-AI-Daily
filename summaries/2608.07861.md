# How Much Does It Cost to Answer My Question? Benchmarking Cloud VLM-based VQA Systems

- arXiv: https://arxiv.org/abs/2608.07861v1
- arXiv ID: 2608.07861

---

🔍 **核心问题**：云视觉语言模型（VLM）驱动的移动视觉问答（VQA）系统中，客户端图像预处理策略对成本、质量和延迟的影响尚未被系统研究。

🛠 **方法**：提出VQABench基准，将客户端输入预处理作为受控变量，在3个VQA数据集、4个商业VLM（来自3个提供商）上评估12种预处理技术，共调用95,168次API。

✨ **主要贡献**：首次系统量化了预处理对云VLM VQA系统的影响，发现预处理并非普遍有益——其效果依赖目标模型、API范式、提供商计费规则和任务形式，不当选择会同时增加成本/延迟并降低准确率，为实际部署提供了指导性见解。

# Artifact detection and localization in single-channel mobile EEG for sleep research using deep learning and attention mechanisms

- arXiv: https://arxiv.org/abs/2504.08469v3
- arXiv ID: 2504.08469

---

🔍 **核心问题**：针对单通道移动脑电（EEG）在睡眠研究中伪迹检测与定位困难的问题，现有方法在可穿戴设备场景下应用受限。

🛠 **方法**：提出一种结合卷积块注意力模块的卷积神经网络（CNN-CBAM），利用注意力图实现睡眠EEG中伪迹的检测与定位，并与6种其他机器学习/信号处理方法进行对比。

✨ **主要贡献**：在72条家庭监测EEG记录上训练、26条独立记录上测试，CNN-CBAM取得最优性能（AUC 0.88，灵敏度0.81，特异度0.86）；在最优注意力阈值0.66下，伪迹定位灵敏度0.61、特异度0.63，证明了可穿戴睡眠EEG中自动化伪迹检测与定位的可行性。

# DWBench: Holistic Evaluation of Watermark for Dataset Copyright Auditing

- arXiv: https://arxiv.org/abs/2602.13541v2
- arXiv ID: 2602.13541

---

🔍 **核心问题**：深度学习大规模数据集的版权保护需求日益迫切，但现有数据集水印方法缺乏统一评估标准，导致无法公平比较和判断其实际可用性。

🛠 **方法**：从实现和验证两个维度梳理现有方法，构建统一基准与开源工具包 DWBench，在分类和生成任务中对25种代表性方法进行标准化评估，涵盖鲁棒性扰动、多水印共存和多用户干扰等场景，并采用 TPR@5%FPR 和验证成功率（VSR）作为统一指标。

✨ **主要贡献**：揭示了标准单水印评估往往高估实际可审计性——孤立验证可靠的方法在低水印样本比例下性能下降，且在复杂多用户、多水印场景中所有权证据模糊，为提升水印可靠性与实用性提供了统一评估基础。

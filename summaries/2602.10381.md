# Deep learning approaches show promise for predicting childhood malnutrition: A comparative study with traditional machine learning methods using survey data

- arXiv: https://arxiv.org/abs/2602.10381v2
- arXiv ID: 2602.10381

---

🔍 **核心问题**：解决尼泊尔等资源匮乏地区儿童营养不良筛查效率低、传统方法难以覆盖偏远地区的问题。  
🛠 **方法**：基于2019年尼泊尔多指标聚类调查数据，系统比较了16种机器学习与深度学习算法（如TabNet、梯度提升模型等），并构建综合营养不良指标（整合发育迟缓、消瘦和体重不足）。  
✨ **主要贡献**：首次在尼泊尔应用深度学习预测儿童营养不良，发现TabNet因注意力机制表现最优；识别出母亲教育水平、家庭财富指数和儿童年龄为关键预测因子，为低资源地区提供了可扩展的筛查框架。

# Assembling the CREW: A Collaborative Multi-agent Reinforcement Learning Framework for Automated Related Work Generation

- arXiv: https://arxiv.org/abs/2609.15721v1
- arXiv ID: 2609.15721

---

🔍 **核心问题**：现有基于多智能体大语言模型的自动相关工作生成方法依赖预定义的静态工作流，各智能体分工固定，难以自适应地协作综合复杂科学文献。

🛠 **方法**：提出CREW框架，让多个LLM智能体摆脱启发式流水线，通过独立近端策略优化（IPPO）学习策略，自主选择检索、分发、撰写、批判等动作，实现动态协作。

✨ **主要贡献**：在标准RWG基准上显著提升生成质量，同时大幅降低token开销，验证了多智能体强化学习驱动的自适应协作优于静态工作流方法。

# Diffusion Based Unpaired Data Learning for Inverse Problems

- arXiv: https://arxiv.org/abs/2609.01370v1
- arXiv ID: 2609.01370

---

🔍 **核心问题**：解决逆问题求解中配对数据难以获取，而仅有非配对数据时深度学习模型训练困难的问题。

🛠 **方法**：提出LUD-DIF，一种基于扩散模型的非配对数据学习方法。从联合分布的证据下界（ELBO）出发，在弱耦合假设下将其解耦为两个独立的扩散过程，并从变分推断角度推导损失函数，同时定量分析假设引入的误差界，并给出超参数选择的理论启发式规则。

✨ **主要贡献**：首次为基于扩散模型的非配对逆问题求解提供了变分推断的理论支撑；在多个图像逆问题任务上验证了LUD-DIF的优异性能与泛化能力，显著提升了非配对场景下的数据利用率。

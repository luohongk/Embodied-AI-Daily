# When Classes Evolve: A Benchmark and Framework for Stage-Aware Class-Incremental Learning

- arXiv: https://arxiv.org/abs/2602.00573v2
- arXiv ID: 2602.00573

---

🔍 **核心问题**：传统类增量学习（CIL）假设类别形态静态不变，但现实中同一语义类别可能经历显著形态演化（如幼虫变蝴蝶），导致模型需同时应对类别区分与类内形态变化，现有方法无法有效处理此问题。

🛠 **方法**：提出Stage-Aware CIL（Stage-CIL）范式，并构建10域两阶段基准Stage-Bench；同时提出STAGE基线，通过固定大小记忆池解耦语义身份与演化动态，实现从早期形态预测后期形态的阶段感知学习。

✨ **主要贡献**：首次系统形式化并评估类别演化下的增量学习问题；实验证明传统CIL方法在此场景下不足，而STAGE显著优于强基线，展示了显式演化建模的潜力。

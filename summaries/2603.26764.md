# Low-Dose CT for Stroke Diagnosis: A Dual-Pipeline Deep Learning Framework for Portable Neuroimaging

- arXiv: https://arxiv.org/abs/2603.26764v2
- arXiv ID: 2603.26764

---

🔍 **核心问题**：便携式CT在低剂量扫描下产生噪声，影响图像质量及自动化卒中分类的准确性，需评估去噪预处理对分类性能的实际影响。

🛠 **方法**：采用双流水线框架，对比“直接分类”与“残差U-Net去噪后固定分类器分类”两种路径，在5种光子计数缩放因子（1/5/10/20/40）下模拟泊松噪声，使用809张切片（242阳性、567阴性）进行测试。

✨ **主要贡献**：直接分类在缩放因子20时达到最高ROC-AUC（0.937），而去噪后分类性能随噪声降低而下降（0.842→0.655）；重建质量（PSNR/SSIM）持续提升，但并未转化为分类精度的改善，仅在最低光子计数下略有帮助。此外，固定0.5阈值下两路径灵敏度均差，且患者级分析受限于测试集全阳性构成，无法评估AUC和特异性。

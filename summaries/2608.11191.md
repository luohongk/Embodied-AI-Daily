# Test-Time Self-Evolving GUI Visual Grounding via Reflection-Guided On-Policy Self-Distillation

- arXiv: https://arxiv.org/abs/2608.11191v1
- arXiv ID: 2608.11191

---

🔍 **核心问题**：GUI视觉定位模型在部署后参数固定，无法适应未见过的界面，且现有测试时强化学习方法无法对失败的探索进行反思。

🛠 **方法**：提出测试时自进化框架，构建“探索-评估-反思-内化”闭环。采用MLLM反射器评估预测结果并生成推理反思，通过反思引导的在线策略自蒸馏将高层推理转化为密集token级监督，并设计对比校准防止错误自回归前缀污染监督信号。

✨ **主要贡献**：首次将在线策略自蒸馏成功应用于GUI视觉定位的测试时自适应，在六个基准上平均提升7.4%准确率，填补了部署后自适应空白，完善了GUI代理的自进化能力。

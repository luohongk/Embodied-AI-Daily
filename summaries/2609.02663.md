# Characterizing Text Branch Sensitivity in Medical Vision-Language Segmentation via Evidence Decoupling

- arXiv: https://arxiv.org/abs/2609.02663v1
- arXiv ID: 2609.02663

---

🔍 **核心问题**：探究医学视觉-语言分割模型中，文本信息对像素级预测的实际贡献程度，以及模型对文本输入的敏感性。

🛠 **方法**：提出基于证据深度学习与深度监督的“证据解耦解码器”（EDD），将图像证据与文本调制证据在解码过程中分离，用于内部表征分析，并系统比较多种融合策略。

✨ **主要贡献**：发现不同数据集对文本扰动的敏感性差异显著（如BUSI/BTMRI强依赖文本，ISIC/Kvasir-SEG弱依赖），文本主要通过全局语义调制而非空间定位影响预测，且驱动敏感性的语义成分因数据集而异，为多模态分割模型设计提供了实证指导。

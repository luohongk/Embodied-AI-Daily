# SAM3-O2D2: Zero-Shot Object Out-of-Distribution Detection by Object Class Prompting of the SAM3-Image Model

- arXiv: https://arxiv.org/abs/2609.08281v1
- arXiv ID: 2609.08281

---

🔍 **核心问题**：解决目标检测器在真实场景中对未见过的物体过度自信的问题，实现零样本的分布外（OOD）物体检测。

🛠 **方法**：利用SAM3图像基础模型，仅用检测器预测的类别作为提示，比较检测器与SAM3的预测结果——若SAM3在对应位置未检测到提示的物体，则判定为OOD。

✨ **主要贡献**：提出SAM3-O2D2方法，在Pascal-VOC和BDD100K（ID）及MS-COCO和OpenImages（OOD）数据集上，AuROC和FPR95指标均显著超越现有零样本SOTA方法，且推理无需昂贵的扩散过程。

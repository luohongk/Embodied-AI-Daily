# LagrangeGS: Non-Conservative Lagrangian System on Dynamic 3D Gaussian Splatting

- arXiv: https://arxiv.org/abs/2608.22773v1
- arXiv ID: 2608.22773

---

🔍 **核心问题**：现有动态3D高斯泼溅（3DGS）的物理感知扩展仅拟合视觉形变的向量场，不满足拉格朗日力学，导致轨迹物理不一致、缺乏时间可逆性以及长期外推时几何塌陷。

🛠 **方法**：提出LagrangeGS，将动态3DGS建模为非保守拉格朗日系统，通过将速度-海森矩阵近似为单位矩阵来解耦数百万高斯粒子的动力学，并限制非保守力显式时间无关以实现可逆积分，同时引入局部刚性对齐正则化轨迹。

✨ **主要贡献**：在动态场景基准上验证了LagrangeGS支持稳定长期外推、一致的时间反演以及无需重训练的反事实物理编辑，从根本上解决了物理一致性、可逆性和几何稳定性三大问题。

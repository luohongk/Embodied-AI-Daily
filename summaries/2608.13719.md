# Coverage Aware Active Evaluation for Failure Discovery with Paired Systems

- arXiv: https://arxiv.org/abs/2608.13719v1
- arXiv ID: 2608.13719

---

🔍 **核心问题**：在有限测试预算下，如何有效发现自主系统在真实世界中罕见且多样化的严重故障，同时克服代理系统（如模拟器或低保真系统）与目标系统之间的差异。

🛠 **方法**：提出一种自适应故障发现方法，结合代理评估与有限的目标系统测试结果，利用控制变量启发的残差建模修正代理故障信号，并采用支持感知的互信息目标函数，在偏好现实可行区域的同时扩展故障模式的覆盖范围。

✨ **主要贡献**：在自动驾驶、操作和四足速度跟踪任务中，该方法发现的故障数量是随机采样和主动学习基线的2倍，且能发现其他方法遗漏的严重和多样化故障。

# One Adapter, Many Tasks: Task-Conditioned Feature Transformations for Continual Learning

- arXiv: https://arxiv.org/abs/2608.31096v1
- arXiv ID: 2608.31096

---

🔍 **核心问题**：类增量学习（CIL）中，现有基于预训练模型的方法存在参数/计算效率低（任务特定适配器）或推理时表示干扰（LoRA合并方法）的问题。

🛠 **方法**：提出FACET框架，使用单一共享适配器，通过动态任务条件特征变换将特征分布建模为重叠减少的任务特定混合分布，并引入无回放的任务条件特征一致性损失来缓解灾难性遗忘。

✨ **主要贡献**：在仅用一个适配器的情况下，FACET在长任务序列（如200个任务）和标准短序列（如20个任务）上均取得最优性能，同时显著减少可训练参数和计算量（GFLOPs），兼具高效性与可扩展性。

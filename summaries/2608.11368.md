# PAIR: Pairwise-Aware Inclusion Reweighting for Adaptive Rollout Allocation in RLVR

- arXiv: https://arxiv.org/abs/2608.11368v2
- arXiv ID: 2608.11368

---

🔍 **核心问题**：RLVR（可验证奖励强化学习）中，现有自适应分配器按点级难度或效用分配计算预算，但忽略了组内成对对比的统计结构，导致自适应选择产生偏差。

🛠 **方法**：提出PAIR（成对感知包含重加权），将短前缀视为顶点、成对梯度项视为对比图边，用前缀预测器估计正确性和剩余token成本，通过凸优化选择续写概率，并对每条边按其联合包含概率的倒数加权，实现无偏估计。

✨ **主要贡献**：在Qwen3-1.7B/4B上，PAIR相比最强点级分配器平均准确率提升+1.2和+1.4，同时比完整组GRPO减少51%和52%的生成token；审计实验证明未加权的自适应选择有偏，而PAIR的成对包含校正能在匹配后缀成本下恢复完整成对目标。

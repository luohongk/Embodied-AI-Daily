# When RL Meets Adaptive Speculative Training: A Unified Training-Serving System

- arXiv: https://arxiv.org/abs/2602.06932v5
- arXiv ID: 2602.06932

---

🔍 **核心问题**：现有投机解码将推测器训练与服务分离，导致部署延迟、收益反馈滞后以及领域漂移时推测器失效。

🛠 **方法**：提出Aurora系统，将在线推测器学习重构为异步强化学习问题，利用接受token为正反馈、拒绝token为隐式负反馈，并集成SGLang推理服务器与异步训练服务器，支持热更新。

✨ **主要贡献**：实现day-0部署，新模型可直接服务并快速适应流量；在MiniMax M2.1 229B和Qwen3-Coder-Next 80B上获得1.5倍初始加速，在分布偏移下比静态推测器额外提升1.25倍速度。

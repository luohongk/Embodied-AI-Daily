# EMFE: A lightweight, explainable machine learning framework for malaria cell classification

- arXiv: https://arxiv.org/abs/2608.24793v1
- arXiv ID: 2608.24793

---

🔍 **核心问题**：针对疟疾细胞分类中深度学习模型计算开销大、可解释性差且缺乏患者级严格验证的问题，提出一种轻量级、可解释的替代方案。

🛠 **方法**：提出EMFE框架，仅用5个特征，通过Gray World颜色归一化、自适应绿色通道阈值分割、形态学斑点检测结合经典机器学习分类器（随机森林、梯度提升、SVM），并在患者分组嵌套交叉验证下评估。

✨ **主要贡献**：优化后的随机森林在NIH数据集上达到94.6%的池化准确率（95% CI [93.6, 95.7]），经40患者留出测试（94.3%）和置换检验（p<0.001）验证；消融实验量化各特征贡献，与重训练的DenseNet121等深度模型对比展示精度-效率权衡，并明确表征了三种失败模式和可解释性分析。

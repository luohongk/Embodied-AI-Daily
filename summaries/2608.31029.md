# Driving on Memory

- arXiv: https://arxiv.org/abs/2608.31029v1
- arXiv ID: 2608.31029

---

🔍 **核心问题**：探究端到端自动驾驶模型在NAVSIM等基准测试中的高分是否真正源于对当前动态交通场景的实时反应，而非仅依赖静态场景记忆。

🛠 **方法**：移除模型的摄像头输入，替换为同一地点先前驾驶时检索到的记忆（包含道路布局等静态信息，但不含当前交通状态），在NAVSIM、Bench2Drive和RealEngine基准上对比性能。

✨ **主要贡献**：发现仅凭记忆在NAVSIM上即可达到甚至超越领先端到端方法的性能，表明该基准的高分无需对当前交通做出反应，需谨慎解读；而Bench2Drive和RealEngine上记忆导致显著性能下降，凸显了基准间的差异。

# MoPET: Parameter-Efficient Mixture-of-Experts for Unified Medical Image Classification

- arXiv: https://arxiv.org/abs/2607.29462v1
- arXiv ID: 2607.29462

---

🔍 **核心问题**：针对医学图像分类中不同诊断任务需单独训练适配器、且合并为单一网络时易发生负迁移的问题，提出一种统一且高效的参数微调方案。

🛠 **方法**：提出MoPET，一种基于混合专家（MoE）的方法，在冻结的基础模型上注入多个低秩PEFT专家，并通过学习到的稀疏路由器为每个输入选择少量专家，从而在共享跨数据集能力的同时限制梯度冲突。

✨ **主要贡献**：在MedMNIST基准上验证了PEFT优于全量微调（平均准确率从86.50%提升至88.97%）；单个MoPET模型可整合四个异质数据集，平均准确率超过最佳独立适配器（93.46% vs 92.83%）；并证明联合训练辅助数据可提升数据受限目标的准确率（从81.58%提升至83.58%）。

# Class Incremental Continual Learning with Self-Organizing Maps and Synthetic Replay

- arXiv: https://arxiv.org/abs/2508.21240v2
- arXiv ID: 2508.21240

---

🔍 **核心问题**：解决类增量持续学习中的灾难性遗忘问题，特别是在不存储原始数据样本的情况下实现高效回放。

🛠 **方法**：提出基于自组织映射（SOM）的生成式持续学习框架，扩展SOM以存储每个单元的分布统计量（均值、方差、协方差），用于生成合成样本进行回放；对高维输入，SOM在编码器-解码器的潜空间上运行，对低维输入则独立运行。

✨ **主要贡献**：实现了无示例、固定容量统计记忆的回放机制，无需存储原始数据；在CIFAR-10和CIFAR-100单类增量任务上分别比最先进的无预训练方法提升近10%和7%，并首次提供TinyImageNet单类增量基线结果；方法可可视化学习过程，训练后还可作为生成模型使用。

# Aging of Prompt Engineering Techniques Across LLM Versions

- arXiv: https://arxiv.org/abs/2608.24641v1
- arXiv ID: 2608.24641

---

🔍 **核心问题**：随着大语言模型（LLM）的快速迭代，提示工程技术（如零样本、少样本、思维链等）的有效性是否随模型版本变化而“老化”，以及这种变化是否具有跨模型家族的普遍性。

🛠 **方法**：对Khojah等人（2025）的研究进行部分复现，在6个指令微调模型（分属GPT、Qwen、Mistral三个家族，各含新旧两代）上，评估5种提示技术（Zero-Shot、Few-Shot、CoT、CCoT、PoT），使用CodePromptEval数据集的218个Python函数，通过pass@k功能正确性指标进行19,620次生成测试。

✨ **主要贡献**：发现提示工程“老化”具有模型家族特异性——GPT新模型对结构化提示的边际收益递减甚至为负，Qwen新模型仍显著受益于少样本和CCoT，Mistral则表现混合（CCoT持续有效，CoT和PoT收益减弱）。这表明提示策略需按模型家族和代际自适应调整，而非直接迁移，为未来开发模型感知的自适应提示方法提供了依据。

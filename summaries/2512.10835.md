# UBCL: A Reinforcement Learning Framework for Controllable and Diverse Player Behaviors

- arXiv: https://arxiv.org/abs/2512.10835v2
- arXiv ID: 2512.10835

---

🔍 **核心问题**：如何在无需人类玩家数据的前提下，实现可控且多样化的玩家行为生成，解决现有方法依赖大规模轨迹数据、需为不同玩家类型分别训练模型、缺乏可解释行为参数与策略间直接映射等问题。

🛠 **方法**：在N维连续空间中定义玩家行为，均匀采样目标行为向量，训练时智能体同时接收当前与目标行为向量，奖励基于两者归一化距离的缩减，采用单一PPO多智能体策略学习动作对行为统计的影响。

✨ **主要贡献**：提出UBCL框架，无需重训练即可复现新玩法风格，在自定义Unity多人游戏中实现显著高于胜率基线的行为多样性，并能可靠匹配指定行为向量，可应用于自动化测试、游戏平衡、类人行为模拟及在线游戏掉线玩家替换。

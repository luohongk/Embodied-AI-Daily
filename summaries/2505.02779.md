# Unsupervised Deep Learning-based Keypoint Localization Estimating Descriptor Matching Performance

- arXiv: https://arxiv.org/abs/2505.02779v2
- arXiv ID: 2505.02779

---

🔍 **核心问题**：视网膜图像配准（特别是彩色眼底图像）依赖标注数据，而医学领域标注数据稀缺，现有方法受限于此。

🛠 **方法**：提出全无监督配准流程，先学习无需关键点或标签的任意位置描述子，再训练一个无标签关键点检测器，通过直接估计描述子匹配性能来定位关键点，完全反转传统“检测器驱动描述子”的思路。

✨ **主要贡献**：在四个独立数据集上验证，无监督描述子优于监督方法，无监督检测器显著优于现有无监督方法；完整配准流程性能接近顶尖监督方法且无需任何标签，并可直接迁移至其他领域和模态。

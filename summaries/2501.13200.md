# SRMT: Shared Memory for Multi-agent Lifelong Pathfinding

- arXiv: https://arxiv.org/abs/2501.13200v2
- arXiv ID: 2501.13200

---

🔍 **核心问题**：解决多智能体强化学习（MARL）中分散式协调的挑战，特别是在部分可观测环境下智能体间信息共享受限、现有通信协议依赖领域或资源约束、集中式训练难以扩展至大规模智能体群体的问题。

🛠 **方法**：提出共享循环记忆Transformer（SRMT），通过一个全局记忆工作空间，让智能体广播其学习的循环工作记忆状态，并查询其他智能体的记忆表示以交换信息，实现无约束通信，同时保持分散式训练和执行。

✨ **主要贡献**：在部分可观测多智能体路径规划（PO-MAPF）任务上验证了SRMT的有效性，在稀疏奖励甚至无奖励引导下仍能涌现协调行为；在需协商的Bottleneck任务中优于通信和记忆增强基线，并泛化至训练中未见的长走廊；在POGEMA地图上随智能体数量和地图规模扩展，性能媲美最新MARL、混合及规划方法，且无需领域特定启发式。

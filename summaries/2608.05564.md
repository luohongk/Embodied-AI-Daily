# ESVR: 3D Ellipsoid-based Sparse Volume Rendering via Structure-aware Primitive Learning and Per-primitive Ray Sampling

- arXiv: https://arxiv.org/abs/2608.05564v1
- arXiv ID: 2608.05564

---

🔍 **核心问题**：大规模稀疏体数据的高效表示与渲染，现有方法依赖DVR图像学习导致信息损失，且难以支持灵活的传递函数交互控制。

🛠 **方法**：提出ESVR框架，直接学习三维体数据，采用有界椭球体基元、结构感知基元学习与互补剪枝、逐基元光线采样，并结合分块优化与幽灵椭球提供边界上下文。

✨ **主要贡献**：实现高达四个数量级的压缩率，实时渲染速度达43-223 FPS，同时保持有竞争力的重建质量，支持交互式传递函数映射。

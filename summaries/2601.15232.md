# When Agents Fail: A Comprehensive Study of Bugs in LLM Agents with Automated Labeling

- arXiv: https://arxiv.org/abs/2601.15232v3
- arXiv ID: 2601.15232

---

🔍 **核心问题**：LLM智能体（LLM Agent）在开发过程中频繁出现故障，但缺乏对其缺陷类型的系统性理解，导致调试困难且成本高昂。

🛠 **方法**：收集并分析了来自Stack Overflow、GitHub和Hugging Face论坛的1,268个与LLM智能体相关的缺陷帖子和代码片段，覆盖7种主流框架及自定义实现；同时构建了一个名为BugReAct的ReAct智能体，配备外部工具来自动检测和标注缺陷特征。

✨ **主要贡献**：首次全面揭示了LLM智能体软件中缺陷的类型、根本原因和影响，并验证了自动化缺陷标注的可行性——BugReAct（基于Gemini 2.5 Flash）在标注缺陷特征上表现优异，平均每个帖子/代码片段的成本仅0.01美元。

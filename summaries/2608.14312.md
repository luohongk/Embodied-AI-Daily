# Envs-FORGE: Frontier-Optimized Reward-Grounded Environment Synthesis for Agent RL

- arXiv: https://arxiv.org/abs/2608.14312v1
- arXiv ID: 2608.14312

---

🔍 **核心问题**：强化学习（RL）训练终端智能体时，现有固定提示策略（如few-shot、Self-Instruct等）对所有种子任务采用相同生成方式，无法根据当前策略的学习状态动态调整任务难度，导致训练环境缺乏可靠奖励和有效难度。

🛠 **方法**：提出Envs-FORGE，一种基于验证器奖励的提示策略。它估计每个种子的通过率，围绕目标学习前沿评估六个投影方向动作，并通过混合整数线性规划（MILP）为每个种子选择最优生成动作，同步重写指令、测试、Docker环境等，仅将金标准验证通过的环境用于RL训练。

✨ **主要贡献**：在Qwen 3.5 35B上，Pass@1较基线提升9.2个百分点（tb-core，40.0%→49.2%）和6.4个百分点（tb-2.0，23.0%→29.4%），超过最强固定基线2.4和2.1个百分点；SWE-bench Verified达77.1%（基线73.4%）；在4B–35B模型上均提升6.8–9.2个百分点，且所有方法生成相同数量（100个）验证环境，消耗相近token，保证公平对比。

# Achieving Olympiad-Level Geometry Large Language Model Agent via Complexity Boosting Reinforcement Learning

- arXiv: https://arxiv.org/abs/2512.10534v4
- arXiv ID: 2512.10534

---

🔍 **核心问题**：解决几何问题中LLM智能体在辅助构造方面启发式能力弱、依赖大规模数据与搜索的问题，实现竞赛级几何推理。

🛠 **方法**：提出InternGeometry智能体，通过迭代提出命题与辅助构造、符号引擎验证及反馈反思来引导推理，并引入动态记忆机制支持多轮交互；同时设计复杂度递增强化学习（CBRL）分阶段提升训练难度。

✨ **主要贡献**：仅用13K训练样本（约为AlphaGeometry 2数据的0.004%）即解决2000-2024年IMO几何题50道中的44道，超过金牌平均分（40.9），并能提出人类解答中未出现的新颖辅助构造，展示了LLM智能体在专家级几何任务上的潜力。

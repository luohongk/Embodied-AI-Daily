# Ladders in Chaos: When, How, (and Perhaps Why) Does Test-Time Scaling Improve LLM Machine Translation

- arXiv: https://arxiv.org/abs/2608.28496v1
- arXiv ID: 2608.28496

---

🔍 **核心问题**：探究测试时扩展（test-time scaling）如何影响大语言模型（LLM）的机器翻译质量，特别是顺序采样与并行采样两种范式的差异及其机制。

🛠 **方法**：对比顺序采样（sequential sampling）与并行采样（i.i.d. sampling with reranking）在翻译任务中的表现，结合人工多维分析（流畅性、自然度、准确性）和消融实验（控制上下文、采样温度）来揭示其作用机制。

✨ **主要贡献**：发现顺序采样在较小采样预算下能达到更高性能上限，生成更多样且有效的候选；人工分析表明顺序采样显著提升流畅性和自然度，但大预算下可能损害准确性；机制上，部分归因于模型访问更大目标侧上下文的能力，且该方法对温度鲁棒但对上下文构建敏感。

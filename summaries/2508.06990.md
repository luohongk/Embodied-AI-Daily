# Imaginative World Modeling with Scene Graphs for Embodied Agent Navigation

- arXiv: https://arxiv.org/abs/2508.06990v2
- arXiv ID: 2508.06990

---

🔍 **核心问题**：解决具身智能体在未知环境中进行语义导航时，因仅依赖历史观测而难以高效定位目标的问题。

🛠 **方法**：提出SGImagineNav框架，利用分层场景图作为符号世界模型，结合大型视觉语言模型预测并探索环境未知区域，并采用自适应导航策略在语义捷径与未知区域探索间动态切换。

✨ **主要贡献**：首次将“想象力”场景图用于主动环境建模，在HM3D和HSSD基准上将成功率提升至65.4%和66.8%，并在真实场景中验证了跨楼层、跨房间导航能力，代码已开源。

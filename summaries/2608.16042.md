# TR-GS: High-Fidelity Sparse-View CT Volumetric Rendering via t-Distribution Gaussian Splatting and Ray-Confidence Modeling

- arXiv: https://arxiv.org/abs/2608.16042v1
- arXiv ID: 2608.16042

---

🔍 **核心问题**：稀疏视角CT重建中，有限观测数据导致结构伪影和重建不确定性，影响高保真三维医学可视化。

🛠 **方法**：提出TR-GS框架，用可投影的Student's t分布高斯原语替代标准高斯原语，并引入射线置信度模型动态调节自由度，结合置信度引导的三维小波正则化平衡细节保留与噪声抑制。

✨ **主要贡献**：在合成和真实数据集上，TR-GS在多数评估场景中优于代表性基线，其余场景保持竞争力，为XR可视化和交互式临床渲染等下游医学应用提供支持。

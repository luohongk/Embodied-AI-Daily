# CARO: Contact-Agnostic Residual Observation for Zero-Shot Robust Quadruped Locomotion

- arXiv: https://arxiv.org/abs/2608.24217v1
- arXiv ID: 2608.24217

---

🔍 **核心问题**：四足机器人在面对分布外扰动（如负载变化、质心偏移、地形突变）时，现有策略缺乏零样本鲁棒性，且依赖昂贵的传感器或复杂的状态估计。

🛠 **方法**：提出CARO框架，将固定基座欧拉-拉格朗日模型嵌入强化学习控制环，利用扰动观测器提取动力学失配信号，构造无需力传感器、接触估计或视觉测量的扭矩级残差观测，供策略在线自适应。

✨ **主要贡献**：在无专门扰动课程或额外监督下，CARO显著提升仿真与真实世界中的零样本鲁棒性，涵盖非分布负载、质心偏移、地形变化、动态突变及高台着陆等挑战性场景。

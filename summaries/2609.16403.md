# Implementing a White-Box Undetectable Backdoor for Random Fourier Features

- arXiv: https://arxiv.org/abs/2609.16403v1
- arXiv ID: 2609.16403

---

🔍 **核心问题**：Goldwasser 等人提出的基于 CLWE 问题的 RFF 白盒不可检测后门仅有理论构造，缺乏参考实现，其能否用普通科学计算工具实现尚不明确。

🛠 **方法**：仅用 numpy 和 scipy 端到端实现该白盒 CLWE-RFF 后门，给出两种 $GP_d(b_k)$ 分布采样器（拒绝采样代理与基于齐次 CLWE 密度的精确闭式采样器），并进行权重空间与函数黑盒的统计不可区分性测试。

✨ **主要贡献**：验证了该后门在 commodity 工具下可实际实现，在多种稀疏比 $ρ$ 下未发现后门模型与干净模型的可检测差异，并报告了实现中需自行推导的部分及未复现的格硬度归约。

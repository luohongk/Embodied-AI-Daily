# Differentiable Jitter Correction using Deep Learning-based Image Quality Metric for Phase-Contrast Micro-CT

- arXiv: https://arxiv.org/abs/2608.27034v1
- arXiv ID: 2608.27034

---

🔍 **核心问题**：解决X射线相衬显微CT中因样本运动导致的逐投影刚性抖动伪影，且无需无运动参考的预扫描数据。

🛠 **方法**：提出全可微的抖动校正流程，结合基于梯度的自动对焦策略（适配平行束几何），用紧凑3D CNN预测视觉信息保真度（VIF）分数作为无参考图像质量指标，并引入仅作用于背景的空间选择性总变分惩罚以抑制优化中产生的虚假高频结构。

✨ **主要贡献**：在模拟和实验数据上验证了该方法能可靠恢复因抖动丢失的精细结构细节，并在不同同步辐射线站采集的形态差异显著的生物样本上展示了良好的泛化能力。

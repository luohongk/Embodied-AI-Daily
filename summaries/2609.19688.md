# LYRIC: Language-Driven Physics-Based Character Control for Contact-Rich Whole-Body Object Interaction

- arXiv: https://arxiv.org/abs/2609.19688v1
- arXiv ID: 2609.19688

---

🔍 **核心问题**：如何让模拟角色仅凭自由形式的语言指令和稀疏的终端物体目标，完成接触丰富的全身-物体交互动作，而无需预先指定全身运动学参考。

🛠 **方法**：提出 LYRIC——一种基于生成式流匹配的控制器，将控制分解为任务级规划器（预测短时域物体与人形根轨迹）和动作生成器（闭环求解全身运动与接触）；先用几何条件交互奖励和松弛参考跟踪训练单一跟踪策略，再通过行为克隆冻结规划器并对动作生成器进行策略后调优。

✨ **主要贡献**：在 OMOMO 数据集上统一策略达到 76.5% 成功率，留出集上达 90.3%（优于最强基线 74.2%），并支持测试时物体路点引导和零样本迁移到新物体形状，实现自然鲁棒的接触丰富交互。

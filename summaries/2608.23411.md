# STONIC: A Layered Measurement Contract for LLM Value Profiling

- arXiv: https://arxiv.org/abs/2608.23411v1
- arXiv ID: 2608.23411

---

🔍 **核心问题**：验证LLM在不同评估方式（问卷评分、成对选择、生成文本推断）下是否表现出稳定一致的价值偏好，即是否存在跨接口的“价值同一性”。

🛠 **方法**：提出分层测量契约STONIC，在5,144个情境中系统比较四种测量方式（独立评分、冲突选择、自发回答、自答vs替代选择），并利用FULCRA和DeBERTa进行语义审计，辅以隐藏状态分析。

✨ **主要贡献**：发现模型在评分与冲突选择间保持行为连续性（10/17配置），且强烈偏好自身先前答案（中位效应0.790），但不同接口间不存在评分者无关的稳定价值身份；FULCRA与人类标注一致性最高，隐藏状态比提示词更清晰编码决策结果。

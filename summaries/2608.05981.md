# Temporal Bridges for Spatial Resolution: Enhancing Climate Data Super-Resolution with Bidirectional Alignment

- arXiv: https://arxiv.org/abs/2608.05981v1
- arXiv ID: 2608.05981

---

🔍 **核心问题**：气候数据超分辨率（SR）任务中，现有深度学习方法仅利用单帧空间信息，忽略了时间帧间的相关性，且气候数据的随机性和噪声使光流等传统时间对齐方法失效。

🛠 **方法**：提出一种时间增强框架，包含三个模块：配对潜在映射（Paired Latent Mapping）统一潜在空间以实现空间对齐和降噪；双向时间对齐（Bidirectional Temporal Alignment）通过前向和后向网络捕捉连续潜在帧的时间相关性；时间增强超分辨率（Temporal Enhanced Super-resolution）优化整体框架以完成气候数据SR。

✨ **主要贡献**：首次为气候数据SR设计双向时间对齐框架，有效利用隐式时间相关性提升空间分辨率；在大规模真实数据集上验证了框架的优越性能，优于现有单帧SR方法。

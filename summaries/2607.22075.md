# FSE: Continual Learning for Named Entity Recognition by Fast-Slow Experts

- arXiv: https://arxiv.org/abs/2607.22075v1
- arXiv ID: 2607.22075

---

🔍 **核心问题**：解决命名实体识别（NER）在持续学习场景中的灾难性遗忘问题，并提升跨任务共享信息的利用效率。  
🛠 **方法**：提出Fast-Slow Experts（FSE）模型，包含共享的快速专家（学习token级链接过滤无效片段）和任务特定的慢速专家（对剩余候选片段进行分类），并引入长度衰减负采样策略缓解片段不平衡。  
✨ **主要贡献**：在OntoNotes和FewNERD数据集上达到持续学习NER的最优性能，验证了各模块的有效性、更快的收敛速度以及双专家的预期功能。

# Real-Time Nonlinear MPC via Sequential Quadratic Programming with Structure-Exploiting ADMM and Interior-Point Methods for Underactuated Double-Pendulum Swing-Up

- arXiv: https://arxiv.org/abs/2608.09272v1
- arXiv ID: 2608.09272

---

🔍 **核心问题**：针对欠驱动双摆系统的摆起与稳定控制问题，在无模型参数先验且交互时间受限的远程硬件环境下，实现全局控制策略。

🛠 **方法**：采用基于序列二次规划（SQP）的实时非线性模型预测控制（MPC），通过结构利用的ADMM和内点法求解优化子问题。

✨ **主要贡献**：提出一种SQP-MPC控制器，在CloudPendulum硬件上实现可靠的摆起与稳定性能，并展现出对扰动的鲁棒性，适用于“AI Olympics”竞赛场景。

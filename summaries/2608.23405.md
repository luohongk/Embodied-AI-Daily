# MomADv2: Reliable Temporal Memory for End-to-End Autonomous Driving

- arXiv: https://arxiv.org/abs/2608.23405v1
- arXiv ID: 2608.23405

---

🔍 **核心问题**：现有端到端自动驾驶方法依赖时序记忆进行长时程规划，但当驾驶指令变化时，历史记忆可能失效并误导决策，导致规划不一致和碰撞风险。

🛠 **方法**：提出MomADv2框架，包含两个核心模块：1) 选择性状态空间规划记忆查询模块，通过时序连续性和指令一致性过滤历史查询，并利用状态空间机制建模规划意图演化；2) 流匹配轨迹残差精炼器，学习从规划输出到专家轨迹的连续残差修正场，实现细粒度轨迹优化。

✨ **主要贡献**：在闭环NAVSIM、Bench2Drive和开环nuScenes上验证，相比MomAD在6秒规划下平均碰撞率降低15.6%，显著提升长时程规划的连续性和可靠性。

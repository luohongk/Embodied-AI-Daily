# Where to Look Matters: Learning Influential Views for VLM-based 3D Visual Grounding

- arXiv: https://arxiv.org/abs/2609.04741v1
- arXiv ID: 2609.04741

---

🔍 **核心问题**：现有基于VLM的零样本3D视觉定位方法在选择相机视角时依赖启发式规则，往往只关注物体可见性而忽略视角对定位任务的实际帮助，导致定位精度受限。

🛠 **方法**：提出IVSGround框架，训练一个轻量级视角选择器，通过两阶段拒绝采样从推理VLM的反馈中生成监督信号，学习为每个候选物体挑选具有判别性证据的视角，再由冻结的推理VLM进行对比式定位。

✨ **主要贡献**：在ScanRefer和NR3D数据集上，IVSGround显著提升了零样本3D视觉定位的准确率，验证了“选择哪里看”对定位效果的关键作用，并开源了项目代码。

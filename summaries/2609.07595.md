# Same Problem, Different Field: Cross-Domain Solution Import via Domain-Stripped Computational Fingerprints

- arXiv: https://arxiv.org/abs/2609.07595v1
- arXiv ID: 2609.07595

---

🔍 **核心问题**：不同领域常以不同名称解决同一计算问题（如卡尔曼滤波、贝叶斯预测、数据同化），现有基于主题和引用的科学嵌入无法识别这种跨领域共性，阻碍了解决方案的跨域复用。

🛠 **方法**：提出“领域剥离的计算指纹”，将每篇论文蒸馏为去领域和方法名的自由文本机制骨架加受控计算方面，并定义可调、可选的方面距离，用于跨领域检索相似问题对。

✨ **主要贡献**：在109篇论文基准上，骨架将跨域检索平均精度从0.222提升至0.513，完整指纹达0.557；四个科学嵌入器均低于纯TF-IDF基线，证明表示比嵌入器更重要。人工验证中，开放标准求解器成功复现了定制临床给药引擎的输出，证明解决方案导入可行。

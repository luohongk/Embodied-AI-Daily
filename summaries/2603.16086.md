# Towards the Vision-Sound-Language-Action Paradigm: The HEAR Framework for Sound-Centric Manipulation

- arXiv: https://arxiv.org/abs/2603.16086v2
- arXiv ID: 2603.16086

---

🔍 **核心问题**：现有VLA模型将声音视为静态预执行提示或仅关注人类语音，无法在任务执行中利用转瞬即逝的环境声学信息进行实时状态验证，且动作分块的开环执行造成"盲执行区间"，导致关键声音事件丢失。

🛠 **方法**：提出VSLA（视觉-声音-语言-动作）连续控制范式，并实例化为HEAR框架，包含四个组件：流式Historizer（维护因果音频上下文）、Envisioner（基于全模态基础模型进行多感官推理）、Advancer（音频世界模型，预测近未来音频编码）、以及流匹配Realizer策略（生成平滑动作块）。

✨ **主要贡献**：构建了OpenX-Sound预训练数据集和首个严格因果时序规则的以声音为中心的操作基准HEAR-Bench；实验表明鲁棒的以声音为中心的操作需要因果持续性和显式时序学习，为具身智能体的多感官基础模型提供了实用路径。

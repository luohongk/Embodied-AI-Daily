# Do You Really Need to Pretrain Q-Functions for Online RL Fine-Tuning?

- arXiv: https://arxiv.org/abs/2607.27203v1
- arXiv ID: 2607.27203

---

🔍 **核心问题**：在基于价值的强化学习中，基于预训练策略进行在线微调时，是否真的需要对Q函数进行预训练？传统观点认为需要，但最新研究表明随机初始化的Q函数也能取得良好效果。

🛠 **方法**：提出基于策略集成的初始化方法（IPE），通过训练多个多样化策略并利用其联合轨迹数据，在在线强化学习中引导Q函数的学习。

✨ **主要贡献**：发现Q函数预训练与在线微调之间存在根本性不匹配——预训练学习的Q函数针对的是预训练策略本身，而非在线微调收敛的目标，且这种差距无法通过离线价值最大化消除。IPE方法在连续控制基准测试中，相比朴素Q函数预训练，平均提升1.26倍的微调性能。

# Cross-Regional Grapevine Cold Hardiness Prediction via Learned Multimodal Latent Representations

- arXiv: https://arxiv.org/abs/2608.31097v1
- arXiv ID: 2608.31097

---

🔍 **核心问题**：现有葡萄藤耐寒性预测模型高度依赖本地数据，难以迁移到新区域或新品种，尤其在数据稀缺地区表现不佳。

🛠 **方法**：提出一种多模态潜表征学习框架，通过可学习的区域嵌入捕捉区域差异，并利用品种与种植区的文本描述（零样本）或少量历史观测（少样本）推断新区域嵌入，实现跨区域预测。

✨ **主要贡献**：在北美六个区域数据集上，该方法显著优于现有最优耐寒性预测模型，大幅提升了对数据稀缺区域的迁移预测精度，为跨区域耐寒性预测提供了可行方案。

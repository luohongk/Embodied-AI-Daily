# Noise-Robust Quantum State Characterization for Remote State Preparation with Deep Learning

- arXiv: https://arxiv.org/abs/2609.20523v1
- arXiv ID: 2609.20523

---

🔍 **核心问题**：在复杂噪声环境下，远程态制备（RSP）实验中量子态的目标态难以被准确估计与表征。

🛠 **方法**：提出基于Transformer的量子态表征模型（TQSC），从含噪测量数据中重建光子偏振的纯态与混合态，并利用注意力机制揭示测量观测量之间的物理关联。

✨ **主要贡献**：在复杂散射与动态高斯噪声下实现超过99.999%的平均估计-目标保真度，并在MNIST图像传输任务中将解码误码率从50.34%降至零，展现了优异的鲁棒性与泛化能力。

# Show-Harness: Just a VLM Agent Can Play Robots

- arXiv: https://arxiv.org/abs/2609.10522v1
- arXiv ID: 2609.10522

---

🔍 **核心问题**：如何将基础视觉语言模型（VLM）的广泛世界知识有效转化为机器人控制能力，避免昂贵的具身专属预训练。

🛠 **方法**：提出 Show-Harness 具身框架，通过离散语义动作单元构建紧凑的语义接口，让 VLM 直接推理高层意图，再由具身解释器确定性地将其映射为本地机器人动作；并开发 GUMI 接口支持基于 GUI 的演示采集。

✨ **主要贡献**：实现了闭源前沿 VLM 的零样本机器人控制和小型开源 VLM 仅需数 GPU 小时微调的低成本部署，实验表明其在任务、具身和环境上泛化性强，优于代表性智能体与 VLA 范式。

# Physics-Informed Deep Learning Model for Cross-Modality Super-Resolution in Fluorescence Microscopy

- arXiv: https://arxiv.org/abs/2607.21190v1
- arXiv ID: 2607.21190

---

🔍 **核心问题**：解决跨模态荧光显微镜超分辨率重建中，纯数据驱动模型生成的图像与光学成像物理规律不一致的问题。

🛠 **方法**：提出一种物理信息生成对抗网络，将显微镜特定的点扩散函数信息融入训练目标，实现共聚焦到STED图像的跨模态转换。

✨ **主要贡献**：PSF引导模型在结构保真度、局部偏差和频域分析上优于非PSF基线方法，证明光学先验能提升生成模型的物理合理性与结构准确性。

# DaViNCi: A Dataset Towards Outdoor Vision-and-Language Navigation with Continuous Actions and Dynamic Elements

- arXiv: https://arxiv.org/abs/2608.11901v1
- arXiv ID: 2608.11901

---

🔍 **核心问题**：现有户外视觉语言导航（VLN）数据集依赖固定离散拓扑图，无法反映真实户外环境的连续性和动态性，阻碍了智能体从仿真到现实的迁移。

🛠 **方法**：提出DaViNCi数据集，首个同时引入连续动作和动态元素的户外VLN数据集，包含6个地图、共6,933条轨迹，智能体需在连续动作空间中导航并应对不可预测的动态障碍。

✨ **主要贡献**：实验表明，在离散环境中DaViNCi的成功率比以往数据集下降超10%，连续环境下下降更显著，验证了其挑战性；同时明确了动作粒度与动态元素对导航性能的影响，推动户外VLN向更真实场景发展。

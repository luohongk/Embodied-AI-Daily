# Multimodal Domain Generalization for Depression Detection: An Attention-Based BiLSTM Network with Domain-Adversarial Training

- arXiv: https://arxiv.org/abs/2607.22794v1
- arXiv ID: 2607.22794

---

🔍 **核心问题**：解决抑郁症检测中因说话人差异导致的域偏移问题，提升模型在不同患者间的泛化能力。

🛠 **方法**：提出首个结合域泛化的多模态抑郁症检测框架，采用双向长短期记忆网络（BiLSTM）融合音频与文本模态，通过注意力机制实现模态内与跨模态交互，并利用梯度反转层（DANN）进行域对抗训练，抑制说话人特异性特征。

✨ **主要贡献**：在Androids-Corpus数据集上达到93.2%准确率和94.2% F1分数，超越现有基准；域泛化模块带来2.5%准确率和3.3% F1分数提升；消融实验验证了多模态融合、深度架构与域泛化的协同作用。

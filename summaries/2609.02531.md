# Spatially Aware World Action Model via Geometric Latent Diffusion

- arXiv: https://arxiv.org/abs/2609.02531v1
- arXiv ID: 2609.02531

---

🔍 **核心问题**：现有世界动作模型（WAM）仅基于RGB观测进行预测，未利用3D几何信息，限制了其在机器人策略学习中的表现。

🛠 **方法**：提出SA-WAM，通过非线性编码将无界深度信号映射到冻结VAE分词器的有界输入域，复用预训练视频扩散模型，实现联合动作、RGB和深度预测，无需针对3D进行微调。

✨ **主要贡献**：在RoboCasa和LIBERO-Plus基准上达到SOTA，同时提升未来状态预测质量；在真实UR5机械臂评估中优于强基线，尤其在随机环境中表现突出，并揭示了世界模型预测质量与任务成功率的关联。

# World Model Control by Trajectory Reachability Metrics

- arXiv: https://arxiv.org/abs/2605.22164v2
- arXiv ID: 2605.22164

---

🔍 **核心问题**：潜在世界模型在控制任务中，仅依赖终端潜在距离排序候选动作时表现不佳，导致控制器决策质量低下。

🛠 **方法**：提出轨迹可达性度量（TRM），从记录轨迹中训练一个轻量级成对时间代价函数，用于对候选动作序列的预测终点与目标进行排序，并引入选择审计（SASC）和行空间干预分析其作用机制。

✨ **主要贡献**：TRM在TwoRoom任务中将成功率从7.0%提升至96.7%（对照组保持0.0%），并将PLDM从32.7%提升至84.0%；在TopoNav任务中验证了排序修复与闭环控制的关联；发现XY行空间虽仅贡献<1%的终端潜在MSE，却承载了大部分控制信息；通过覆盖率和边界测试明确了方法适用范围与局限。

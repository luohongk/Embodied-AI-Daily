# Online Gate-Driven Flow Control in Resin Transfer Moulding Using a Neural-Network Surrogate

- arXiv: https://arxiv.org/abs/2608.29521v1
- arXiv ID: 2608.29521

---

🔍 **核心问题**：在树脂传递模塑成型过程中，因“竞速效应”导致树脂流动前沿不均匀，可能提前到达排气口而形成干斑缺陷，需在填充完成前确保纤维预成型体完全饱和。

🛠 **方法**：提出联合估计与控制策略，利用填充过程中的压力传感器数据，通过迭代扩展卡尔曼滤波估计未知的竞速强度，并同时优化辅助注入口压力；用神经网络代理模型替代昂贵的有限元-控制体积模型，并采用贝叶斯近似误差框架补偿代理模型与原模型的差异。

✨ **主要贡献**：证明了流动前沿几何仅取决于时间平均的注入口压力，使代理模型训练可行；在分叉几何上验证了该方法能显著减少填充结束时的未填充节点数，但改善程度强烈依赖于辅助注入口的位置和数量。

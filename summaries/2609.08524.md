# Layer Selection in VLMs for Zero-Shot OOD Detection via Multi-Resolution Entropy Estimation

- arXiv: https://arxiv.org/abs/2609.08524v1
- arXiv ID: 2609.08524

---

🔍 **核心问题**：在医学影像的零样本OOD检测中，现有方法几乎只使用VLM的最后一层嵌入，但中间层也能提供互补的OOD信号，且最优层深度因图像模态而异，因此需要一种稳健的层选择方法。

🛠 **方法**：提出一种多分辨率熵估计策略，通过聚合多个离散化尺度下的直方图统计量来评估各中间层的OOD判别能力，从而选择最优层组合，替代对分箱选择敏感的单分辨率熵估计。

✨ **主要贡献**：在MIDOG和OASIS两个医学OOD基准上，覆盖不同模态、多种偏移类型和不同VLM骨干，该方法一致优于现有最先进方法，且性能更稳定（单分辨率方法可导致AUROC波动高达19.3%），提供了一种轻量且稳健的零样本OOD检测方案。

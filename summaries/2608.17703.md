# Dijkstra as an Oracle for Online Stochastic Shortest Path Navigation with Provable Guarantees

- arXiv: https://arxiv.org/abs/2608.17703v1
- arXiv ID: 2608.17703

---

🔍 **核心问题**：移动机器人在未知地图遍历成本和随机执行环境下，如何高效且安全地完成随机最短路径导航，同时避免精确求解带来的高计算开销。

🛠 **方法**：提出DORA（Dijkstra Oracle Reduced-cost Algorithm）在线学习算法，利用Dijkstra作为精确规划引擎，在比文献中因果性条件更弱的“约简成本非负”条件下工作；每次迭代固定调用最短路径预言机，不估计转移核，并通过对数生存权重控制动态障碍物接触概率。

✨ **主要贡献**：理论上证明Dijkstra在弱条件下可精确求解随机最短路径；实验表明DORA在网格导航、定向钻井和无人机监控等基准任务中，性能与已知真实转移核的乐观值迭代相当，但规划计算量减少4.5至19.3倍，学习期间接触率降低17倍，且能严格满足跨两个数量级的接触预算。

# Quality-Aware Multimodal Fusion Reveals Implicit Identity in Valence-Arousal Features

- arXiv: https://arxiv.org/abs/2607.21347v1
- arXiv ID: 2607.21347

---

🔍 **核心问题**：传统人脸识别依赖静态外观特征，在表情变化、遮挡或光照不佳的非受控环境下性能下降，需要挖掘音视频动态表达中隐含的身份信息。

🛠 **方法**：提出质量感知自适应融合（QAAF）方法，通过可学习的软门控和质量相关丢弃机制，动态估计每个样本、每种模态的可靠性并调整其贡献，以多模态效价-唤醒（VA）估计作为预训练任务来学习鲁棒表征。

✨ **主要贡献**：在Aff-wild2上VA估计的CCC达0.472，优于基线；缺失单模态时性能仅下降7.5-34.4%；VA训练特征在AFEW-VA和YTF上超越其他软生物特征方法，与ArcFace融合后EER进一步降低，纠正了68.2%的误接受。

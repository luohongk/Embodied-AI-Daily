# MMaDA-VLA: Large Diffusion Vision-Language-Action Model with Unified Multi-Modal Instruction and Generation

- arXiv: https://arxiv.org/abs/2603.25406v3
- arXiv ID: 2603.25406

---

🔍 **核心问题**：现有VLA模型采用层级或自回归架构，存在结构复杂、长程误差累积以及需要辅助模块建模环境动态的问题。

🛠 **方法**：提出MMaDA-VLA，一个原生预训练的离散扩散VLA模型，通过共享离散token空间联合去噪未来目标观测与动作块，无需辅助世界模型即可将动作与预测视觉结果对齐，实现并行、无顺序依赖的细化。

✨ **主要贡献**：在LIBERO上平均成功率98.0%，在CALVIN上平均成功序列长度4.78，并在真实场景中表现优异，验证了统一多模态理解与生成的有效性。

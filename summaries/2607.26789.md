# CheckVLA: Execution-Time Verification with Action-Conditioned World Model for Long-Horizon Mobile Manipulation

- arXiv: https://arxiv.org/abs/2607.26789v1
- arXiv ID: 2607.26789

---

🔍 **核心问题**：VLA策略在执行长程移动操作时，通过开环动作块（action chunks）一次性发出多个动作，但执行中若发生意外偏差，剩余动作会持续传播错误，而提交时的策略置信度无法响应事后偏差，且仅基于观测的异常评分缺乏动作条件参考，难以区分预期变化与意外变化。

🛠 **方法**：提出CheckVLA，使用单独训练并冻结的动作条件世界模型（action-conditioned world model）进行执行验证。通过共形校准的风险阈值控制首次不必要干预的概率，当超出阈值时调整重写后缀对原动作块的保留程度，并采用延迟感知的硬前缀限制替换为可执行动作，同时利用事件驱动关键帧库保留先前进展证据。

✨ **主要贡献**：在RoboCasa365上，CheckVLA在相同训练方案和调用预算下平均成功率达36.1%，优于周期性重规划的27.6%（+8.5点）。在5%的误报目标下，动作条件验证的及时召回率达77.9%，远超仅观测控制的48.6%和动作打乱控制的37.9%，证明动作条件验证能在分块执行中恢复反馈，同时保持修复与推理延迟的一致性。

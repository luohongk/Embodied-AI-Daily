# GS-VLA: Plug-and-Play Viewpoint Canonicalization for Frozen VLA Policies via Gaussian Splatting

- arXiv: https://arxiv.org/abs/2608.19066v1
- arXiv ID: 2608.19066

---

🔍 **核心问题**：视觉-语言-动作（VLA）策略在部署时对相机视角变化极其敏感，即使微小的相机位移也会导致成功率大幅下降（如LIBERO基准上从约90%降至约10%），而现有微调或数据增强方法计算成本高且存在灾难性遗忘风险。

🛠 **方法**：提出GS-VLA，一个轻量级即插即用框架，在冻结的VLA策略前添加一个仅4M参数的3D高斯泼溅（3D Gaussian Splatting）视角规范化模块，将视角偏移问题重构为局部新视角合成任务，在局部性假设下实现场景无关的遮挡补全。

✨ **主要贡献**：首次直接利用3D高斯新视角合成进行VLA观测空间适配；无需修改策略权重即可在策略架构、未见任务套件和扰动尺度三个正交维度上显著恢复因视角偏移导致的性能损失，验证了轻量视觉模块的有效性。

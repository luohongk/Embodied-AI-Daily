# DSCD-Nav: Dual-Stance Cooperative Debate for Object Navigation

- arXiv: https://arxiv.org/abs/2601.21409v3
- arXiv ID: 2601.21409

---

🔍 **核心问题**：现有导航系统在决策层使用单次评分，导致长距离任务中过度自信的错误和冗余探索，影响部分可观测环境下的行动可靠性。

🛠 **方法**：提出DSCD-Nav，通过构建任务-场景理解（TSU）和安全-信息平衡（SIB）两种立场进行合作辩论，并引入导航共识仲裁（NCA）代理，基于证据交叉验证和轻量微探测来优化决策。

✨ **主要贡献**：在HM3Dv1、HM3Dv2和MP3D数据集上，该方法一致提升了导航成功率和路径效率，同时减少了探索冗余。

# Goal-Oriented Semantic Communication for ISAC-Enabled Robotic Obstacle Avoidance

- arXiv: https://arxiv.org/abs/2603.02291v2
- arXiv ID: 2603.02291

---

🔍 **核心问题**：针对ISAC使能的无人机避障任务，解决基站持续传输感知与控制指令信号导致的高通信开销问题。

🛠 **方法**：提出目标导向语义通信（GOSC）框架，采用卡尔曼滤波融合感知预测、基于马氏距离的动态窗口法（MD-DWA）生成精确控制信号，并利用有效性感知深度Q网络（E-DQN）依据信息价值（VoI）决定信号传输。

✨ **主要贡献**：在保持100%任务成功率的同时，将感知与控制信号传输次数减少92.4%，传输时隙减少85.5%，显著提升通信效率。

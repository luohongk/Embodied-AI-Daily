# SENTINEL-RL: Offloading Topological Reasoning from LLM Agents in the Security Operations Center

- arXiv: https://arxiv.org/abs/2609.04159v1
- arXiv ID: 2609.04159

---

🔍 **核心问题**：解决LLM智能体在SOC（安全运营中心）中因上下文窗口有限无法处理大规模认证图、且自由文本生成无法保证拓扑一致性，导致自主分析不可靠的问题。

🛠 **方法**：提出Sentinel-RL架构，将拓扑推理与语义推理解耦——用异构图注意力编码器将实时认证子图压缩为固定维度状态，PPO策略将该状态映射到受限调查动作集，LLM仅负责将策略建议转化为分析师可读的叙述，并由评论家（critic）把关。

✨ **主要贡献**：在LANL和Quartz数据集上验证，实现24M边图加载提速24倍（14.2分钟）、告警触发延迟≤2.5秒、PPO训练收敛（精确率0.91/召回率0.87）、完整检测-调查-推荐-人工审批周期中位数6.3秒；另贡献了热节点死锁规避、锚节点共置部署模式及企业就绪性分析。

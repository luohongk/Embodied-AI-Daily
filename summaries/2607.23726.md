# Hierarchical Soft Actor-Critic for Sparse-Reward Long-Horizon Reinforcement Learning

- arXiv: https://arxiv.org/abs/2607.23726v1
- arXiv ID: 2607.23726

---

🔍 **核心问题**：解决稀疏奖励和长周期任务中强化学习面临的探索困难，尤其是延迟奖励与连续控制带来的挑战。  
🛠 **方法**：提出双层分层强化学习框架，高层负责战略规划，低层采用连续控制的软演员-评论家算法，并引入熵正则化策略优化。  
✨ **主要贡献**：在SAR-2数据集上，HRL-SAC相比平面SAC基线在成功率、覆盖效率和收敛性上均表现更优，验证了分层熵正则化策略在长周期稀疏奖励任务中的有效性。

# DreamTrajectory: Trajectory-Guided Action Generation with World Model Alignment for Mobile Manipulation

- arXiv: https://arxiv.org/abs/2608.01381v1
- arXiv ID: 2608.01381

---

🔍 **核心问题**：移动操作机器人在大动作空间中难以精准协调基座与机械臂运动，且开环执行动作块会导致计划运动与实际运动之间的误差累积。

🛠 **方法**：提出DreamTrajectory框架，包含两个组件——(1) 联合预测意图级末端执行器轨迹和全身动作块，以轨迹显式引导动作生成；(2) 轻量级轨迹世界模型预测候选动作块引发的轨迹，并通过测试时“搜索-预测-评分”流程选择与计划轨迹最对齐的动作。

✨ **主要贡献**：在MS-HAB基准上，轨迹引导将平均成功率从32.3%提升至47.5%，测试时细化进一步提至54.8%，在接触丰富的铰接物体任务上提升最大；在三个真实世界移动操作任务上分别达到63.3%、81.7%和90.0%的成功率。

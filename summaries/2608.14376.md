# CoRun: Padding is Simple and Efficient for Deterministic LLM Inference

- arXiv: https://arxiv.org/abs/2608.14376v1
- arXiv ID: 2608.14376

---

🔍 **核心问题**：大语言模型推理在固定采样参数和随机种子下仍存在输出不一致性，主要源于批处理中动态输入形状导致的GPU执行非确定性，影响模型评估和强化学习等下游任务。

🛠 **方法**：提出CoRun系统，利用“位置不变性”而非“批不变性”，通过隔离预填充（prefill）和固定形状的批处理解码（decode）两阶段调度，结合CUDA图实现高效确定性推理。

✨ **主要贡献**：相比批不变内核方法，CoRun在保证确定性的同时提升吞吐量15-324%，平均降低首token延迟51.8%和每token输出延迟48.6%，并在Qwen和DeepSeek等多样架构上验证有效性。

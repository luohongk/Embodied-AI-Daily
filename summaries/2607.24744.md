# Data Pyramid for Embodied Manipulation

- arXiv: https://arxiv.org/abs/2607.24744v1
- arXiv ID: 2607.24744

---

🔍 **核心问题**：如何有效整合多种数据源，以解决具身智能体在机器人操作任务中缺乏大规模、高质量训练数据的问题。

🛠 **方法**：提出“数据金字塔”框架，将具身数据生态分为五类互补来源（真实机器人数据、UMI风格数据、自我中心/外部视角数据、仿真数据、通用视觉语言数据），并分析它们在预训练中的选择、对齐与混合策略。

✨ **主要贡献**：系统化梳理了具身数据源的特性与权衡，揭示了不同数据组合对感知、推理、规划、动作生成等能力的影响，并指出了未来六大关键挑战（如触觉数据集、失败恢复数据、跨本体动作对齐等），为下一代具身系统设计奠定基础。

# SVR: Self-Verifying Refinement via Joint Verdict-Confidence Reinforcement Learning for Adaptive Test-Time Compute

- arXiv: https://arxiv.org/abs/2607.28457v1
- arXiv ID: 2607.28457

---

🔍 **核心问题**：大语言模型推理时，固定计算预算在简单问题上浪费资源，而基于验证器的自适应推理依赖外部反馈，缺乏内部自适应控制机制。

🛠 **方法**：提出SVR框架，一种无外部验证器的多轮强化学习方法。模型每轮同时输出解答、离散正确性判定和置信度分数，仅当判定为“正确”且置信度超阈值时保留答案，否则基于自身验证继续细化。训练采用GRPO，奖励函数兼顾解答正确性、校准感知的自我验证和“可停止”状态，自适应停止仅在推理时激活。

✨ **主要贡献**：在7个数学推理基准上（Qwen3.5-2B），SVR以平均2.99轮推理达到0.563宏平均准确率，超越标准GRPO、强多轮基线和固定预算的oracle引导基线，且推理轮数远少于固定10轮方案，证明学习到的自我验证可作为有效的内部计算分配信号。

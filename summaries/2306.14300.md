# Screening Autism Spectrum Disorder in children using Deep Learning Approach : Evaluating the classification model of YOLOv26s by comparing with other models

- arXiv: https://arxiv.org/abs/2306.14300v2
- arXiv ID: 2306.14300

---

🔍 **核心问题**：利用儿童面部图像自动筛查自闭症谱系障碍（ASD），以支持早期干预。

🛠 **方法**：采用最新深度学习模型YOLOv26s，将其从目标检测任务迁移至图像分类任务，并与多个其他模型进行性能对比。

✨ **主要贡献**：YOLOv26s在ASD分类中达到92.86%的准确率和0.9291的F1分数，验证了深度学习模型在自闭症筛查中的有效性，并首次证明YOLOv26s可用于该分类问题。

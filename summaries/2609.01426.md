# Semantic-Guided Multimodal Preprocessing for Vision Transformer-Based Clear Cell Renal Cell Carcinoma Grading

- arXiv: https://arxiv.org/abs/2609.01426v1
- arXiv ID: 2609.01426

---

🔍 **核心问题**：现有透明细胞肾细胞癌（CCRCC）分级方法要么直接分析病理图像块，要么仅关注细胞核级分类，未能将两者有效结合以支持最终肿瘤分级。

🛠 **方法**：提出一种语义引导的多模态预处理方法，将预训练模型生成的细胞核分类图与RGB组织病理图像融合，通过通道拼接和乘法调制（含优化叠加）输入Vision Transformer（ViT）进行分级，同时保留RGB纹理特征。

✨ **主要贡献**：语义引导增强达到0.916的平衡准确率，显著优于RGB-only基线（0.707）和先前最大投票聚合方法（0.427）；敏感性分析显示即使在模拟扰动下仍保持21个百分点的优势，且各类别召回率均衡（0.93/0.91/0.91），证明该方法能有效利用现有不完美核分类器的诊断潜力，桥接细粒度核分析与粗粒度ViT分类。

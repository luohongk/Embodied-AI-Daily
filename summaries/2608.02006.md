# ASTRA: Asynchronous Spatio-Temporal Reconstruction via Trajectory Alignment

- arXiv: https://arxiv.org/abs/2608.02006v1
- arXiv ID: 2608.02006

---

🔍 **核心问题**：动态3D场景重建在严格同步多相机输入下表现优异，但实际中相机时间异步会导致运动模糊和几何伪影，现有方法依赖光度监督在较大时间偏移和复杂运动下难以提供有效的对齐信号。

🛠 **方法**：提出ASTRA框架，引入2D运动轨迹作为显式、与纹理无关的监督信号，通过将重建3D点的投影运动与观测2D轨迹对齐，联合优化时间偏移和动态3D表示，并采用动态与确定性掩码抑制不可靠轨迹约束。

✨ **主要贡献**：在多种动态高斯泼溅骨干上验证，ASTRA在高达25帧偏移的严重异步下仍保持高频细节和强鲁棒性，PSNR提升约1.4 dB，时间偏移MAE降低54.0%，同步成功率提升近4倍。

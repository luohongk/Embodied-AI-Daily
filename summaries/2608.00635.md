# FlowPilot: Real-Time World-Action Modeling for Agile UAV Navigation

- arXiv: https://arxiv.org/abs/2608.00635v1
- arXiv ID: 2608.00635

---

🔍 **核心问题**：面向敏捷无人机导航，解决传统“建图-规划”管线计算开销大、端到端策略缺乏场景预测能力的问题，实现基于深度相机的实时机载导航。

🛠 **方法**：提出FlowPilot，一种紧凑的世界-动作联合模型，采用流匹配（flow matching）同时去噪未来深度观测与可执行轨迹；通过双流混合Transformer（mixture-of-transformers）共享注意力耦合视频与动作专家，并以7次Bernstein多项式参数化动作，保证C²连续轨迹。模型在仿真（高吞吐、照片级）与真实数据构成的三级深度金字塔上训练。

✨ **主要贡献**：在闭环仿真中，FlowPilot在杂乱环境及8m/s指令速度下优于学习与优化基线；在真实四旋翼上，完整感知-动作管线在Jetson Orin NX上运行时间<18ms，仅靠机载传感与计算即可在室内及森林杂乱环境中达到5.5m/s速度。

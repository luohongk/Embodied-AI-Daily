# TANGO-VIO: Triangulation-Aware Navigation with Guaranteed Feature-Observability for Visual-Inertial Odometry

- arXiv: https://arxiv.org/abs/2608.02079v1
- arXiv ID: 2608.02079

---

🔍 **核心问题**：视觉惯性里程计（VIO）中，当相机发生纯旋转或平移量过小时，特征三角化会因视差不足而病态化，导致状态估计精度下降，而现有研究缺乏主动维护特征可观测性的导航策略。

🛠 **方法**：提出TANGO-VIO框架，将特征级堆叠承载矩阵的对数行列式度量嵌入控制障碍函数（CBF），通过名义方向加权的最小偏差速度修正，强制保证聚合三角化信息度量下界，从而在几何意义上确保特征可观测性。

✨ **主要贡献**：首次将三角化感知的可观测性保证融入VIO导航控制，通过软件在环仿真和真实飞行实验验证，在低视差运动下显著改善三角化条件，且飞行响应与仿真高度一致，证明了安全滤波器的实际可行性。

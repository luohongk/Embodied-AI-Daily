# Global monitoring of methane point sources using deep learning on hyperspectral radiance measurements from EMIT

- arXiv: https://arxiv.org/abs/2604.10094v2
- arXiv ID: 2604.10094

---

🔍 **核心问题**：解决现有基于星载成像光谱仪的甲烷点源监测依赖人工识别、检测限高且难以规模化的问题。  
🛠 **方法**：提出端到端视觉变换器框架MAPL-EMIT，利用EMIT仪器全辐射光谱联合反演场景内所有像素的甲烷增强，结合空间上下文与光谱信息，并基于360万物理合成羽流数据训练。  
✨ **主要贡献**：相比传统匹配滤波方法，显著降低检测限并提升弱羽流识别能力；在真实数据中捕获84%已知羽流复合体，且发现约1.5倍于人工分析的疑似羽流；通过光谱拟合评分与噪声估计有效控制误报，实现全球设施级甲烷排放的高通量快速监测。

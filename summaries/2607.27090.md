# InferScale: GPU-Native KV Injection for Personalized LLM Serving

- arXiv: https://arxiv.org/abs/2607.27090v1
- arXiv ID: 2607.27090

---

🔍 **核心问题**：大语言模型在服务中需重复预填充用户共享的个性化上下文（如记忆或对话历史），导致首令牌延迟（TTFT）随检索量增长而显著增加。

🛠 **方法**：提出InferScale系统，通过GPU原生KV注入替代重复预填充——预计算每个记忆事实的KV表示并缓存，在服务时直接注入vLLM的分页缓存；引入分块RoPE（Chunked RoPE）处理动态位置编码，以及上下文窗口编码（Context-Window Encoding）缓解独立编码缺失的跨事实上下文。

✨ **主要贡献**：在检索预算为50时，TTFT降低72-79%（3.6-4.8倍），吞吐量提升3.7-4.5倍，准确率仅略低于Mem0（60.3% vs 63.3%），且无需修改引擎或微调模型，实现延迟与检索上下文大小的解耦。

# Enabling Scalable Kinesthetic Teaching via Observer-based Hand-guiding with Active Support

- arXiv: https://arxiv.org/abs/2608.10847v1
- arXiv ID: 2608.10847

---

🔍 **核心问题**：传统机器人手把手示教（kinesthetic teaching）在长时间操作中会导致操作者疲劳，降低演示质量，且现有方法缺乏主动辅助或依赖昂贵硬件（如腕部力传感器）和任务先验知识。

🛠 **方法**：提出RHOAS方案，利用基于模型的力矩估计（无需额外硬件），结合内部关节力矩传感和冗余机器人运动学，在操作者交互频带内主动支持其意图运动，并抑制未建模弹性效应、测量噪声、奇异点附近估计误差及重力补偿误差。

✨ **主要贡献**：在KUKA LWR iiwa上开展16人用户研究，证明该方法显著降低物理努力，提升精确和敏捷任务的可操作性，并获得用户明确偏好，为可扩展的示教学习提供了低成本、高鲁棒性的主动引导方案。

# An Efficient Metric for Data Quality Measurement in Imitation Learning

- arXiv: https://arxiv.org/abs/2605.01544v2
- arXiv ID: 2605.01544

---

🔍 **核心问题**：模仿学习中的机器人策略在部署时面临分布外场景，而用户演示数据质量差（含过多修正动作、振荡等），现有数据筛选方法需策略回滚，计算成本高，难以实际部署。

🛠 **方法**：提出基于演示轨迹功率谱密度（PSD）的自动化数据质量排序指标，无需策略学习、环境交互或专家标注，直接计算轨迹的PSD值，低值代表平滑高质量，高值代表杂乱低质量。

✨ **主要贡献**：在基准数据集和养老院老年人用户研究中验证，PSD筛选的数据微调策略相比未筛选基线和两种竞争排序方法，获得更高任务成功率与更平滑的执行轨迹，且计算高效，适合现场数据整理。

# Effective Game-Theoretic Motion Planning via Nested Search

- arXiv: https://arxiv.org/abs/2511.08001v3
- arXiv ID: 2511.08001

---

🔍 **核心问题**：现有博弈论运动规划方法在一般动力学系统中难以高效计算纳什均衡，优化方法受限于简化模型和局部最优，而枚举方法因显式遍历所有轨迹而扩展性差。

🛠 **方法**：提出Game-Theoretic Nested Search (GTNS)，通过外层搜索所有智能体的动作空间，并在低维空间内进行内层搜索以丢弃违反纳什均衡约束（无单方面偏离）的轨迹，从而高效计算一般动态系统中的纳什均衡。

✨ **主要贡献**：GTNS具有可扩展性和可证明正确性，支持通过用户指定的全局目标显式选择均衡，适用于自动驾驶和赛车等复杂场景，在普通硬件上数秒内即可求解。

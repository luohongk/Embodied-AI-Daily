# Post-Training Language Models for Gold-Medal Performance in Coding Competitions

- arXiv: https://arxiv.org/abs/2609.02849v1
- arXiv ID: 2609.02849

---

🔍 **核心问题**：提升大语言模型在顶级编程竞赛（如IOI）中的表现，使其达到甚至超越人类金牌选手水平。

🛠 **方法**：构建端到端专用化流水线，包括大规模题目筛选（22,000道）、合成推理轨迹、监督微调（SFT）和强化学习（RL）；并引入GenCorrect测试时计算策略，通过迭代生成、评估和修正多样化解决方案来提升性能。

✨ **主要贡献**：在IOI 2025上，Nano-CC经后训练后得分从130提升至291，结合GenCorrect达468分，超过金牌线438.3；Ultra-CC达502分。在IOI 2026前瞻性评估中，专用系统在人类同等约束下得分535.4/600，超过金牌线（361.12）和最高人类得分（498.27），成为首个在IOI题目集上超越人类冠军的AI系统。

# Learning From How Humans Correct

- arXiv: https://arxiv.org/abs/2102.00225v21
- arXiv ID: 2102.00225

---

🔍 **核心问题**：在工业级NLP应用中，人工标注数据存在噪声，影响模型性能，需要有效识别并利用人工修正信息提升分类准确率。

🛠 **方法**：提出一种简单方法先识别噪声数据并人工重新标注，同时收集修正信息；随后设计新方法将人工修正信息注入深度学习模型，使模型学习人类的修正模式。

✨ **主要贡献**：在自建文本分类数据集上，该方法将测试集准确率从91.7%（已修正数据训练）提升至92.5%，且基线从83.3%提升至91.7%，人工评估准确率超过97%。

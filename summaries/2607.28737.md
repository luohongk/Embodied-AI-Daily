# Mirror Learning

- arXiv: https://arxiv.org/abs/2607.28737v1
- arXiv ID: 2607.28737

---

🔍 **核心问题**：解决模仿学习过度依赖第一人称密集对齐数据、无法利用第三人称被动观察信号的问题。

🛠 **方法**：提出“镜像学习”框架，结合微调的视频扩散模型学习视角变换，将第三人称演示转换为第一人称视角，再通过逆动力学模型推断学习者控制空间中的动作轨迹，生成“镜像数据”用于策略训练。

✨ **主要贡献**：首次证明仅用第三人称观察生成的镜像数据即可训练有效策略，且与第一人称行为克隆数据混合可进一步提升性能，为减少遥操作数据采集提供了一种可扩展、安全的替代方案。

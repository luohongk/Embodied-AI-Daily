# Optimization of time-consuming experimental conditions using pseudo-experimental data guided by adaptive polynomial regression

- arXiv: https://arxiv.org/abs/2607.22238v1
- arXiv ID: 2607.22238

---

🔍 **核心问题**：在实验成本高、耗时长且数据有限的场景下，传统贝叶斯优化收敛缓慢，而现有生成伪实验数据的方法因数据量不足导致质量低下。

🛠 **方法**：提出PolyBO方法，通过自适应多项式回归模型生成高质量伪实验数据，并与真实实验数据结合更新贝叶斯优化的代理模型，从而高效指导后续实验。

✨ **主要贡献**：在合成基准函数上优化时间中位数减少42%，在真实材料成分优化问题中优化时间中位数减少96%，显著提升了有限实验数据下的优化效率。

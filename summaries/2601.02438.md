# Focus on What Matters: Fisher-Guided Adaptive Multimodal Fusion for Vulnerability Detection

- arXiv: https://arxiv.org/abs/2601.02438v4
- arXiv ID: 2601.02438

---

🔍 **核心问题**：现有漏洞检测的多模态方法默认引入额外模态必然带来信息增益，但预训练模型已隐含编码大量结构信息，导致模态重叠、图编码器特征提取能力不足，朴素融合反而稀释有效判别信号。

🛠 **方法**：提出任务条件互补融合策略，利用Fisher信息量化任务相关性，将跨模态交互从全谱匹配转为任务敏感子空间内的选择性融合，并设计TaCCS-DFA框架，结合在线低秩Fisher子空间估计与自适应门控机制实现高效融合。

✨ **主要贡献**：理论证明该策略在同向扰动假设下显著收紧输出误差上界；在BigVul、Devign、ReVeal基准上F1最高提升6.3分，推理延迟仅增加3.4%，且保持低校准误差。

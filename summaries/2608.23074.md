# Grounding Isn't Knowing: Do VLMs Need Object Localization for Spatial Reasoning?

- arXiv: https://arxiv.org/abs/2608.23074v1
- arXiv ID: 2608.23074

---

🔍 **核心问题**：探究视觉语言模型（VLMs）在空间推理中是否必须依赖精确的目标定位，还是可以通过全局布局线索绕过显式定位。

🛠 **方法**：对LLaVA-1.5和Qwen2.5-VL两个模型家族，采用token消融、分层探针、注意力头敲除和因果中介分析等机制可解释性工具，系统分析空间关系预测的内部处理流程。

✨ **主要贡献**：发现空间关系预测遵循“定位到推理”的分阶段过程，目标对齐token提供粗略锚点而非精确边界框；位置信息在关系决策前即可解码，且少量注意力头同时中介定位与推理的因果效应；两个任务共享早期定位处理但最终依赖部分不同的专门通路，证明“知道目标在哪”不等于“知道目标如何关联”。

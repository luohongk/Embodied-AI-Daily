# HAM-VLN: Harnessing Hierarchical Agentic Memory for Zero-Shot Vision-and-Language Navigation

- arXiv: https://arxiv.org/abs/2607.29600v1
- arXiv ID: 2607.29600

---

🔍 **核心问题**：解决零样本视觉-语言导航（VLN）中，长时程导航因图像流或稠密地图导致记忆和推理瓶颈不断增长的问题。

🛠 **方法**：提出HAM-VLN，一种决策耦合的智能体记忆系统，构建基于深度的持久世界图。在每次动作决策的同一模型调用中，同时记录语义和反思信息（如房间类型、物体、导航进度、失败笔记），近期航点保留在有限窗口内，旧历史通过相关性、时效性和显著性评分检索，并辅以一跳拓扑扩展，无需额外LLM调用。

✨ **主要贡献**：在多个VLN基准上显著提升导航性能（VLN-CE R2R上SR达61.0%，RxR上52.7%，HM3D-v2 ObjectNav上79.7%），同时将上下文长度减少超过65%，且完全无需训练。

# Large Language Models (LLMs) for Telecom Root Cause Analysis (RCA): A Structured Reasoning Framework for Evidence-Grounded Diagnosis

- arXiv: https://arxiv.org/abs/2609.02805v1
- arXiv ID: 2609.02805

---

🔍 **核心问题**：电信网络中5G/6G网络的根因分析（RCA）因跨层依赖复杂而困难，直接使用大语言模型（LLM）会导致幻觉、推理不稳定和与结构化网络证据对齐不佳的问题。

🛠 **方法**：提出一个结构化推理框架，将异构网络遥测数据组织为规范上下文，在诊断过程中强制执行决策路径推理，最终生成基于证据的解释，以可靠识别故障。

✨ **主要贡献**：在TeleLogs和TelecomTS两个5G RCA数据集上，该框架相比基线方法持续提升了诊断准确性和决策一致性，强调了结构化推理设计对实际LLM-based RCA系统的重要性。

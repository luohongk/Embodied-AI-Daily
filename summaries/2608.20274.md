# Break It Down, Pass It On: Cross-Task Skill Transfer in LLM Agents

- arXiv: https://arxiv.org/abs/2608.20274v1
- arXiv ID: 2608.20274

---

🔍 **核心问题**：探究LLM智能体在不同任务间技能迁移的可靠性，即技能归纳方式如何影响其跨任务迁移效果。

🛠 **方法**：对比任务级与子任务级技能归纳、文本与代码技能格式两种维度，并引入技能效用评分（结合特异性和抽象性）预测迁移成功率。

✨ **主要贡献**：发现子任务级技能和文本格式技能迁移效果更好，且技能效用评分无需任务执行即可有效预测迁移表现，可作为技能记忆的实用诊断工具。

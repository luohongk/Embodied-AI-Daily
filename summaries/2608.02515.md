# LiveMem: Maintaining Memory State Continuity in Long-Running LLM Inference

- arXiv: https://arxiv.org/abs/2608.02515v1
- arXiv ID: 2608.02515

---

🔍 **核心问题**：长期运行的LLM在上下文窗口有限的情况下，无法在上下文切换时保持跨生命周期的持久记忆状态，导致历史信息丢失。

🛠 **方法**：提出LiveMem，一种内在记忆方法，为预训练全注意力LLM增加一个独立于活动上下文的固定容量记忆状态，同时主注意力路径保留有界KV窗口，并通过记忆导向的后训练和状态感知服务实现记忆的持续维护。

✨ **主要贡献**：在LongMemEval等基准上取得领先性能，即使支持证据已从当前上下文移除，仍能基于记忆状态正确回答问题，验证了记忆状态可作为持续LLM推理中独立且互补的抽象。

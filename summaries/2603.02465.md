# Toward Generalizable Deep Learning Based Peatland Fire Detection via Walsh Hadamard Transform and Domain Adaptation

- arXiv: https://arxiv.org/abs/2603.02465v2
- arXiv ID: 2603.02465

---

🔍 **核心问题**：传统野火检测模型难以有效识别泥炭地火灾（具有阴燃、低火焰强度、持续烟雾和地下燃烧等独特特征），且现有方法在数据有限条件下泛化能力不足。

🛠 **方法**：提出基于Walsh-Hadamard变换增强的ResNet-50（WHT-ResNet-50）框架，通过结构重参数化降低推理成本，并采用迁移学习实现野火到泥炭地火灾的域适应，结合混合域训练策略构建统一检测器。

✨ **主要贡献**：在有限数据下显著提升泥炭地火灾检测性能，WHT-ResNet-50以更少参数取得更高准确率和F1分数；重参数化模型在保持精度的同时降低推理开销；视频评估实现100%事件检出率和低误报率，提供准确高效的实用解决方案。

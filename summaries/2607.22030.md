# Impedance Control of Ship-Borne Manipulators via Optimization-based Task-Space Inverse Dynamics

- arXiv: https://arxiv.org/abs/2607.22030v1
- arXiv ID: 2607.22030

---

🔍 **核心问题**：船载机械臂在海洋环境中受随机波浪引起的基座运动干扰，导致轨迹跟踪精度下降，并增加接触操作的安全风险。

🛠 **方法**：提出基于优化的任务空间逆动力学（TSID）控制框架，通过二次规划求解，显式补偿基座运动的动态耦合；同时设计误差状态卡尔曼滤波器（ESKF），融合惯性测量与末端执行器位姿反馈，实现精确的前馈补偿。

✨ **主要贡献**：在7自由度机械臂与6自由度Stewart平台实验中，末端位置跟踪误差较最优基线降低25.7%以上；在基座运动下实现1毫米间隙的动态销孔插入，成功率提升且平均接触力降低45%，验证了精准且柔顺的接触操作能力。

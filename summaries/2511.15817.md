# A Causal Perspective on Measuring, Explaining and Mitigating Smells in LLM-Generated Code

- arXiv: https://arxiv.org/abs/2511.15817v7
- arXiv ID: 2511.15817

---

🔍 **核心问题**：本文旨在系统性地测量、解释和缓解大语言模型（LLM）生成代码中的代码异味（即影响可读性、可维护性或设计完整性的不良编码模式），并探究这些异味如何及何时在生成代码中出现。

🛠 **方法**：基于概率指标“倾向性异味评分”（PSC）作为因果分析工具，评估生成策略、模型大小、模型架构和提示词设计对代码结构质量的影响，并通过用户研究验证PSC在辅助开发者评估代码质量中的实用性。

✨ **主要贡献**：发现提示词设计和架构选择对异味倾向起决定性作用，提出缓解异味的实用策略；同时证明PSC能有效帮助开发者理解模型行为并评估代码质量，为LLM代码评估与部署中的质量感知集成奠定基础。

# Fashion-3DLR: A Controllable 3D Garment Generation Using Pairwise Fashion Elements for Intelligent Design

- arXiv: https://arxiv.org/abs/2607.23189v1
- arXiv ID: 2607.23189

---

🔍 **核心问题**：现有3D服装生成技术难以处理不同设计元素（如草图、纹理）在三维表示中的语义耦合关系，导致生成多样且高质量的3D服装资产存在挑战。

🛠 **方法**：提出Fashion-3DLR框架，通过服装特征融合扩散变换器（GFF-DiT）将2D设计元素集成到潜在空间，再利用整流流变换器生成几何潜在表示，最终解码为3D高斯或网格等多种3D服装形式。

✨ **主要贡献**：首次实现基于成对时尚元素的可控3D服装生成，支持物理仿真和虚拟试穿，性能超越现有最优方法，为智能设计提供通用工具。

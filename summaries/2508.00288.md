# UAV-ON: A Benchmark for Open-World Object Goal Navigation with Aerial Agents

- arXiv: https://arxiv.org/abs/2508.00288v5
- arXiv ID: 2508.00288

---

🔍 **核心问题**：现有空中导航研究多依赖语言指令（如VLN），缺乏在开放世界中基于高层语义目标（如“找到红色汽车”）自主导航的能力，且缺乏大规模、高保真度的基准测试环境。

🛠 **方法**：提出UAV-ON基准，包含14个基于虚幻引擎的高保真环境（城市、自然、混合场景），定义1270个带实例级语义描述（类别、尺寸、视觉特征）的目标物体，并实现模块化策略AOA（Aerial ObjectNav Agent），结合指令语义与自我中心观测进行长时程目标导向探索。

✨ **主要贡献**：首次为空中智能体建立开放世界物体目标导航基准，揭示现有方法在语义目标推理与空中导航复合挑战中的不足，推动基于语义目标的无人机自主性研究。

# Spectral Pre-Filtering for Context-Adaptive Sensor Fusion: A Four-Role FFT-GDCB Integration for High-Stakes Decision Systems

- arXiv: https://arxiv.org/abs/2608.22023v1
- arXiv ID: 2608.22023

---

🔍 **核心问题**：当传感器信号或数据流含有周期性结构（如机械旋转谐波、发动机振动、需求周期等）时，上下文自适应卡尔曼滤波器的噪声协方差回归会被污染，导致模型拟合的是结构模式而非真实状态不确定性。

🛠 **方法**：提出一种四角色FFT预滤波器，以$O(N\log N)$计算成本实现：白化有色噪声、清洁创新残差防止协方差污染、生成频谱上下文特征供下游bandit使用、对输入特征向量去季节化。该方法作为预处理层集成到GDCB家族中。

✨ **主要贡献**：单次FFT调用同时服务四个下游消费者，计算开销不足传感器融合或定价流水线预算的0.1%，且为即插即用方案。在六个独立领域（火箭降落、自动驾驶跟踪、短租定价、临床给药、航空票价分配、广告竞价校准）均通过预注册的PROVES评估协议验证。

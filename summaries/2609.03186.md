# Improving Clinical Target Volume Segmentation Accuracy using Anatomical Priors and Active Learning for the AGITG TOPGEAR Clinical Trial

- arXiv: https://arxiv.org/abs/2609.03186v1
- arXiv ID: 2609.03186

---

🔍 **核心问题**：在胃癌临床试验（AGITG TOPGEAR）中，临床靶区（CTV）分割因解剖结构复杂且标注数据有限，导致自动化轮廓质量保证（QA）模型训练困难，需提升分割精度。

🛠 **方法**：采用nnU-Net模型，利用TotalSegmentator生成周围器官的解剖先验图作为额外输入通道，并结合主动学习策略（基于模型不确定性和分割性能迭代选择训练病例），通过五折交叉验证集成不确定性评估。

✨ **主要贡献**：解剖先验将平均Dice相似系数（DSC）从0.84提升至0.86；主动学习同样达到0.86，且两者结合效果最佳（DSC=0.87）。不确定性指标与DSC相关，可用于识别次优预测并指导训练数据扩展，为放疗临床试验中的自动化轮廓QA提供了有效集成方案。

# Learning Spatiotemporal Decision Priors for Efficient Path Planning under Partial Observability

- arXiv: https://arxiv.org/abs/2607.22166v1
- arXiv ID: 2607.22166

---

🔍 **核心问题**：在部分可观测环境下，智能体仅依赖局部观测进行长程路径规划时，传统方法缺乏利用历史轨迹经验引导搜索的机制，导致冗余节点扩展和局部短视行为。

🛠 **方法**：提出ImiPath框架，通过构建局部时空观测表示（编码环境空间与轨迹时序信息），并设计时空注意力策略网络（STAPNet）从中提取可复用的决策先验，将其作为方向性引导集成到异构规划器中，以偏向局部有前景的搜索区域。

✨ **主要贡献**：在局部可观测条件下显著减少冗余节点扩展、提升搜索效率，同时保持路径质量；通过磁控微机器人平台的物理实验验证了框架的适应性与实际部署潜力。

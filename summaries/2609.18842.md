# Infinite-Parameter LLMs: Generating and Adapting Weights from Live Data

- arXiv: https://arxiv.org/abs/2609.18842v1
- arXiv ID: 2609.18842

---

🔍 **核心问题**：传统大模型权重在训练后冻结，无法从部署时的实时交互数据（如用户提供的事实或纠正）中学习，这些知识只能放入提示中，每次请求后即被丢弃。

🛠 **方法**：受MoE启发提出"无限参数LLM"，用紧凑的超网络将运行时数据转化为共享基础网络的低秩调制，并维护对生成器隐码的贝叶斯信念并在线更新，使有效权重随会话演进动态重导出。

✨ **主要贡献**：实现存储占用固定但可编译权重"无限"的架构，将运行时知识存入权重而非提示，从而摊销计算、释放上下文窗口、跨轮次持久化，并可能比上下文学习泛化更好；同时提出了针对性的评估协议。

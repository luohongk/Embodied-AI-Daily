# Indexing Long Documents for LLM-Based Analysis

- arXiv: https://arxiv.org/abs/2608.21237v1
- arXiv ID: 2608.21237

---

🔍 **核心问题**：针对长文档（如临床记录、法律合同、科学论文）的LLM分析，直接输入全文效率低、成本高且易产生幻觉，且无法跨问题复用计算。

🛠 **方法**：提出一种基于索引的分层纯文本结构，类似B+树，文档被组织为从根（通用摘要）到叶（具体内容）的页面，但内容存在于每一层，导航依据页面摘要间的相关性而非键值比较，索引结构由LLM自动发现。

✨ **主要贡献**：在NarrativeQA数据集上，该索引达到与最强基线DocETL相当的准确率，同时问答成本降低40%，展示了索引化文档分析的高效性和可复用性。

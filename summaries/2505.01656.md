# WaveInst: A Frequency-Domain Enhanced Network for Fine-Grained Thin Tree Trunk Extraction in Forest Scenes

- arXiv: https://arxiv.org/abs/2505.01656v2
- arXiv ID: 2505.01656

---

🔍 **核心问题**：解决森林场景中细树干提取难题，包括重叠树干被误识别为单根、树干与背景对比度低导致分割困难，以及幼树数据有限且树干粗细差异大限制模型性能。

🛠 **方法**：提出WaveInst实例分割网络，核心是频域特征补偿分支，包含离散小波变换块和高频增强块，分别进行高低频分解与多方向高频聚合、多路径高频细化；再通过自适应门控融合模块将空间域卷积特征与频域表示有效集成，增强解码器的细粒度细节表征。

✨ **主要贡献**：在公开数据集（SynthTree43k、CaneTree100、UrbanStreet）和自建PoplarDataset上验证有效性；在PoplarDataset上成熟树mAP达53.1、幼树达29.1，幼树提取性能超越现有最优方法6.6个百分点，证明其在细树干提取中的优越性。

# Modalities Should Talk to Each Other: Dual-Stream Multimodal Learning for Long-Horizon Influenza Forecasting

- arXiv: https://arxiv.org/abs/2608.23373v1
- arXiv ID: 2608.23373

---

🔍 **核心问题**：面向长期流感样疾病（ILI）预测，如何有效融合数值流行病学信号与噪声大、结构松散且滞后的文本信息（如新闻标题），以提升12周超前预测的准确性。

🛠 **方法**：提出双流注意力（DSA）框架，分别用Transformer数值编码器和领域自适应标题编码器处理两种模态，通过双向跨模态注意力（CMA）机制让文本与数值相互条件化，再接入因果时序模型进行预测。

✨ **主要贡献**：在Time-MMD数据集上，DSA的测试MSE（0.416）显著优于iTransformer、TaTS和GPT4MTS（分别降低54.95%、37.29%、67.23%），在100%的bootstrap抽样中排名第一，且最差窗口误差更低；外部地理数据集上同样排名第一。消融实验证明双向注意力优于单向，且性能不依赖文本编码器选择或微调；扰动分析表明CMA在文本→数值方向的功能性更强。

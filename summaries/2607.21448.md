# GrainGS: Gradient-Decoupled Gaussian Splatting for Efficient Dynamic Novel View Synthesis

- arXiv: https://arxiv.org/abs/2607.21448v1
- arXiv ID: 2607.21448

---

🔍 **核心问题**：现有动态3D高斯泼溅方法在细粒度运动建模、结构稳定性和紧凑表示之间难以平衡，存在冗余生长或运动抑制的问题。

🛠 **方法**：提出GrainGS框架，结合层级锚点骨架与逐高斯变形，通过静态预热阶段建立规范表示，利用停止梯度操作分离变形梯度，并引入规范-残差外观分解建模光度变化。

✨ **主要贡献**：在合成单目和真实多视图基准上，达到36.98 dB平均峰值信噪比、435.6帧/秒渲染速度和4.67 MB存储，实现了高质量重建、实时渲染与紧凑存储的统一。

# Adaptive Graph-of-Islands Evolution for Automatic Feature Engineering with LLMs

- arXiv: https://arxiv.org/abs/2607.23286v2
- arXiv ID: 2607.23286

---

🔍 **核心问题**：自动特征工程（AutoFE）在表格数据中需要从庞大的程序空间中寻找有效变换，但现有方法受限于固定算子库、静态提示缺乏搜索经验，以及进化算法中固定的迁移策略无法适应任务特定需求。

🛠 **方法**：提出TOPOFE框架，将AutoFE建模为图结构的多岛屿进化程序搜索。变换空间被划分为语义族，每个岛屿通过LLM引导的变异和交叉独立探索，并利用提示适应记忆积累反馈；同时动态学习有向拓扑图，通过自适应饱和检测触发跨岛迁移，实现LLM介导的混合合成。

✨ **主要贡献**：在29个表格数据集上，TOPOFE在分类和回归任务中优于多数最先进方法，生成的特征集冗余更低、覆盖更广；学习到的拓扑图具有任务特定的迁移结构，且发现的特征程序在不同预测器和LLM骨干间可靠迁移，证明改进源于结构化搜索与自适应协调，而非骨干生成能力。

# Fast Weight Attention for Continual Learning

- arXiv: https://arxiv.org/abs/2608.27763v1
- arXiv ID: 2608.27763

---

🔍 **核心问题**：在持续学习（continual learning）场景中，如何将不断扩展的上下文压缩为固定大小的循环状态，同时保持高效的状态更新与学习能力。

🛠 **方法**：提出“快速权重注意力”（Fast Weight Attention）框架，将循环状态转换视为在线学习规则，并针对前缀预测目标推导了归一化一阶更新（如NLMS回归和负内积目标），实现了Falcon系列变体（Falcon-1/2/3及其A版本），并提供了循环、掩码并行和分块并行三种计算形式。

✨ **主要贡献**：首次系统分离了循环序列模型中的时间对齐、可塑性、遗忘和有界重放四个维度；Falcon变体在语言建模上表现有竞争力，并在变长数字加法任务上显著改善长度外推能力；同时提出了数值稳定的正衰减重归一化方法。

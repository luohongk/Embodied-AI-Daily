# AllocBench: Measuring Online Tool Allocation Capability in LLM Agents

- arXiv: https://arxiv.org/abs/2607.23332v2
- arXiv ID: 2607.23332

---

🔍 **核心问题**：评估LLM智能体在固定预算下是否具备“在线工具分配”能力，即创建少量高复用工具而非大量一次性工具，并检验该能力能否从抽象任务迁移到代码构建任务。

🛠 **方法**：构建配对基准测试（AllocBench），包含抽象文本任务和代码构建任务，测试多个前沿模型（Claude Haiku/Opus、GPT-5.4-mini、GPT-5.6 Sol）及一个策略训练的Qwen模型，通过逐步消融实验定位失败模式。

✨ **主要贡献**：发现所有模型在抽象任务中表现接近最优，但均无法将能力迁移到代码任务；识别出各模型的具体失败模式（如GPT-5.6 Sol仅在完整构建时崩溃）；Qwen模型可泛化抽象分配能力但无法改善代码分配，证明在线工具分配是前沿模型的能力边界。

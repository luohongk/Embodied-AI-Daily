# FinTrace: Holistic Trajectory-Level Evaluation of LLM Tool Calling for Long-Horizon Financial Tasks

- arXiv: https://arxiv.org/abs/2604.10015v3
- arXiv ID: 2604.10015

---

🔍 **核心问题**：现有金融工具调用基准局限于有限场景，且依赖调用级指标，无法评估长周期金融任务中LLM的轨迹级推理质量。

🛠 **方法**：构建FinTrace基准，包含800条专家标注轨迹、34类真实金融任务，采用基于rubric的九项指标（动作正确性、执行效率、过程质量、输出质量）评估；并构建FinTrace-Training轨迹级偏好数据集，通过监督微调+直接偏好优化（DPO）训练Qwen-3-8B/32B。

✨ **主要贡献**：揭示前沿模型工具选择能力强但信息利用和最终答案质量薄弱；首次提供金融工具调用的轨迹级偏好数据集，DPO能有效抑制失败模式，但轨迹级改进尚未完全传导至最终输出质量。

# STAG-VIO: Stabilized Prompt-to-Geometry Interface for Robust Dynamic Visual--Inertial Odometry

- arXiv: https://arxiv.org/abs/2411.19289v4
- arXiv ID: 2411.19289

---

🔍 **核心问题**：动态视觉惯性里程计（VIO）在动态场景中易受运动干扰，现有语义辅助方法受限于类别分割器且对遮挡鲁棒性差，而基于提示的分割模型因提示不稳定导致掩码闪烁，破坏几何估计稳定性。

🛠 **方法**：提出STAG-VIO框架，将动态鲁棒性建模为感知到几何的接口稳定问题。采用不确定性自适应多目标跟踪生成时间连贯的框提示，驱动轻量级基础分割器，并通过几何导向形态学细化建立保守安全边界，最后用约束预算感知的特征重分配策略保留静态测量。

✨ **主要贡献**：在VIODE和OpenLORIS-Scene数据集上超越现有最优方法，消融实验表明提示稳定化是最关键组件，可将轨迹误差降低高达83%。

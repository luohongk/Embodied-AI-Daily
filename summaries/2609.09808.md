# GTA-2: A Multi-VLM Framework for Synthesizing Robot Manipulation Skills via Grounded Task Axes

- arXiv: https://arxiv.org/abs/2609.09808v1
- arXiv ID: 2609.09808

---

🔍 **核心问题**：机器人操作任务的行为/技能分解往往依赖预定义或通用技能，导致粒度过粗，无法体现执行所需的几何、控制和场景相关决策。

🛠 **方法**：提出 GTA-2 模块化多 VLM 框架，将技能表示为包含任务关键点与轴、控制器组合及场景参数的语义子任务，由四个专用 VLM 智能体分别负责任务分解、抽象技能构建、控制器参数分配和基于 RGB-D 的视觉特征接地。

✨ **主要贡献**：实现无需任务演示、策略训练或微调的零样本技能生成，并保持中间决策显式以支持针对性人工反馈；在 14 个真实机器人任务上平均零样本成功率达 73.9%（超最强基线 31.4 个百分点），经针对性优化后提升至 90.7%。

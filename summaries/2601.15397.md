# Beyond Prompting: Efficient and Robust Contextual Biasing for Speech LLMs via Logit-Space Integration (LOGIC)

- arXiv: https://arxiv.org/abs/2601.15397v3
- arXiv ID: 2601.15397

---

🔍 **核心问题**：现有 Speech LLM 因静态训练知识难以识别联系人名、歌单、专业术语等新实体，而提示方法受限于上下文窗口、推理延迟和"中间迷失"问题，生成式纠错（GEC）则易产生"过度纠正"和幻觉。

🛠 **方法**：提出 LOGIC 框架，直接在解码层（logit 空间）进行上下文偏置，将上下文注入与输入处理解耦，实现相对于提示长度的恒定时间复杂度。

✨ **主要贡献**：在 Phi-4-MM 模型、11 个多语言场景下，实体词错误率（Entity WER）平均相对降低 9%，误报率仅增加 0.30%，兼顾高效性与鲁棒性。

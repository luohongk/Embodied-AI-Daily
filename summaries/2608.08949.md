# EndoMD-SLAM: Endoscopic Gaussian Splatting SLAM under Optical Degradation with Memory and Static-Transient Decomposition

- arXiv: https://arxiv.org/abs/2608.08949v1
- arXiv ID: 2608.08949

---

🔍 **核心问题**：内窥镜手术中，光学退化（如移动碎屑、水冲洗）破坏多视角光度一致性，导致现有高斯溅射SLAM系统出现跟踪漂移和地图不可逆损坏。

🛠 **方法**：提出EndoMD-SLAM框架，包含两个关键机制：跟踪侧采用记忆驱动的门控机制，检测不可靠观测并暂停地图更新，利用历史关键帧进行漂移感知重定位；建图侧通过自监督静态-瞬态分解，将视觉污染物隔离到独立的瞬态场中，避免其与持久解剖地图结构纠缠。

✨ **主要贡献**：构建了基于结肠镜视频的退化聚焦基准数据集；实验表明，在严重光学退化下，标准基线方法失效，而EndoMD-SLAM保持几何完整性，绝对轨迹误差降低91%，渲染保真度提升9.9 dB PSNR。

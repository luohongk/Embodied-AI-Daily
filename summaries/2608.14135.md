# AgilePE: Autonomous UAV Pursuit-Evasion via Self-Play Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.14135v1
- arXiv ID: 2608.14135

---

🔍 **核心问题**：解决无人机在自主追逃任务中，因高维空中交互和对手行为动态变化而难以实现快速敏捷决策的问题。

🛠 **方法**：提出AgilePE系统，采用自博弈强化学习，将机载状态直接映射为集体推力和机体角速度指令，实现端到端敏捷控制；训练中使用优先虚拟自博弈和多样化对手池，并构建硬件对齐的仿真管线以支持零样本迁移。

✨ **主要贡献**：实现了无需任务微调的零样本真实无人机部署，在仿真和实机中均涌现出快速闪避、侧翼包抄等复杂追逃策略，验证了系统在真实双机交互中的有效性。

# SCAR-GS: Spatial Context Attention for Residuals in Progressive Gaussian Splatting

- arXiv: https://arxiv.org/abs/2601.04348v2
- arXiv ID: 2601.04348

---

🔍 **核心问题**：3D高斯泼溅（3D Gaussian Splatting）模型在中等和大型场景中存储需求过高，限制了其在云服务和流媒体传输中的部署。

🛠 **方法**：提出一种渐进式编解码器，用残差向量量化（Residual Vector Quantization）替代传统标量量化来压缩高斯特征，并引入基于多分辨率哈希网格的自回归熵模型，以预测每个传输索引的条件概率，实现高效压缩。

✨ **主要贡献**：创新性地结合残差向量量化与空间上下文注意力，显著提升率失真性能，使粗粒度和细化层的压缩效率更高，同时保持实时高保真渲染质量。

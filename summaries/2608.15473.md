# Q-First: Most of Attention Needs Only the Query in Disaggregated LLM Decoding

- arXiv: https://arxiv.org/abs/2608.15473v2
- arXiv ID: 2608.15473

---

🔍 **核心问题**：在分离式LLM解码架构中，注意力计算和前馈网络存在顺序依赖，导致KV缓存扫描端和计算端无法并行工作，造成硬件闲置。

🛠 **方法**：提出“Q-First”协议，将注意力子层与前馈子层交换顺序，使KV缓存扫描仅需查询（query）即可提前执行，键值对作为缓存写入无需等待，从而实现两端并发运行。

✨ **主要贡献**：在无需新算子、新形状或新硬件的情况下，端到端验证相对误差仅3.2×10⁻³；实验表明将查询提前一个前馈层读取对训练影响极小（差异小于随机种子间的波动），但进一步提前到网络输入则显著增加损失（+0.0974），确定了查询可提前读取的边界。

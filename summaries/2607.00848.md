# MetaHOPE: A Metaphor-Oriented Evaluation Framework for Analysing MT and LLM Translation Errors

- arXiv: https://arxiv.org/abs/2607.00848v2
- arXiv ID: 2607.00848

---

🔍 **核心问题**：针对机器翻译（MT）和大语言模型（LLM）在隐喻翻译中因语义复杂、依赖上下文及文化嵌入导致的错误，缺乏有效的错误严重性感知评估框架。

🛠 **方法**：提出MetaHOPE框架，基于错误严重性对隐喻翻译进行人工标注；选取GoogleMT、GPT5.4和Hunyuan-7b三种系统，使用VUAMC和PSUCMC语料库进行英汉双向翻译实验，并构建人工后编辑的双语平行语料作为参考。

✨ **主要贡献**：首次提出面向隐喻翻译的错误严重性感知标注框架MetaHOPE，创建了双语平行隐喻语料资源，并通过分析当前最优自动翻译模型的错误，为隐喻翻译研究提供了新工具与数据支持。

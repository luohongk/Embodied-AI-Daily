# FAMPWQ: Fisher Information-based Adaptive Mixed Precision Weight Quantization for Effective LLM Inference

- arXiv: https://arxiv.org/abs/2608.24945v2
- arXiv ID: 2608.24945

---

🔍 **核心问题**：大语言模型（LLM）在资源受限设备上部署时，传统量化方法因均匀位宽或简单敏感性评估导致性能严重下降。

🛠 **方法**：提出FAMPWQ方法，采用Fisher信息度量层间量化敏感性，并利用强化学习分配器生成自适应混合精度位宽策略。

✨ **主要贡献**：在7个模型和5个基准上显著优于7种基线方法，困惑度（PPL）最多降低3.39，准确率最高提升6.87%，LLM-as-a-judge胜率最高达76%。

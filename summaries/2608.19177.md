# Image-Guided Pavement Defect Recognition in GPR Data with novel 3D Deep Learning Architecture

- arXiv: https://arxiv.org/abs/2608.19177v1
- arXiv ID: 2608.19177

---

🔍 **核心问题**：解决探地雷达（GPR）在路面自动检测中面临的两个关键挑战——标注真实世界3D GPR数据稀缺，以及缺乏针对3D GPR数据特性设计的深度学习模型。

🛠 **方法**：提出一种经济高效的数据准备流程，将正射RGB影像与3D GPR扫描对齐，利用路面表面图像作为参考，将表面可见缺陷的标签迁移至对应GPR段，实现大规模自动标注；同时设计一种新型3D CNN架构，融合残差连接、混合卷积核尺寸以及深度和通道注意力机制，用于缺陷分类。

✨ **主要贡献**：构建了真实高速公路路段的标注3D GPR数据集，并提出专用3D深度学习框架；实验表明该网络在补丁和裂缝缺陷的二元分类任务中优于基线模型，消融研究验证了各架构组件的有效性，为实际数据集生成和自动化检测提供了可扩展方案。

# BioVLN: A Simulation Platform for Visual Language Navigation in Biomedical Laboratories

- arXiv: https://arxiv.org/abs/2607.26914v1
- arXiv ID: 2607.26914

---

🔍 **核心问题**：现有具身导航平台针对家庭环境设计，将目标视为物体中心或任意附近位置，无法满足生物医学实验室中仪器需从操作侧接近并保持安全距离的导航需求。

🛠 **方法**：提出BioVLN仿真平台，为每个仪器定义物理本体、周围安全区域和操作区域三个区域，并统一应用于场景生成、目标放置、导航评估和安全分析，支持程序化场景生成与手动设计环境。

✨ **主要贡献**：构建了47个场景和1667个导航任务，实验表明几何探索方法成功率达74.4–87.5%，而在操作区域内采样多个有效位置可将成功率提升至83.3–92.5%，并减少不安全接近。

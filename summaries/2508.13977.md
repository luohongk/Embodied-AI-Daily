# ROVR-Open-Dataset: A Large-Scale Depth Dataset for Autonomous Driving

- arXiv: https://arxiv.org/abs/2508.13977v4
- arXiv ID: 2508.13977

---

🔍 **核心问题**：现有自动驾驶深度数据集（如KITTI、nuScenes、DDAD）受限于昂贵的多激光雷达采集设备，导致数据多样性和可扩展性不足，且基准性能已接近饱和。

🛠 **方法**：构建ROVR数据集，采用轻量化采集流程，包含20万帧高分辨率图像，覆盖高速公路、乡村、城市场景，跨越昼夜及恶劣天气，采集自北美、欧洲和亚洲，并公开标定、同步、预处理及隐私保护流程。

✨ **主要贡献**：发布了大规模、多样化且低成本可复现的深度数据集，通过密度消融验证稀疏但统计充分的真值可支持稳健训练，并识别出当前架构共有的三种失败模式——光度崩溃、几何混淆和距离饱和。

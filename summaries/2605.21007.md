# LiteViLNet: Lightweight Vision-LiDAR Fusion Network for Efficient Road Segmentation

- arXiv: https://arxiv.org/abs/2605.21007v3
- arXiv ID: 2605.21007

---

🔍 **核心问题**：在边缘计算约束下，如何高效融合RGB外观与几何（深度）信息，实现自动驾驶与移动机器人的道路分割。

🛠 **方法**：提出LiteViLNet轻量双流网络，采用MobileNetV3 RGB编码器与仅0.12M参数的深度可分离几何编码器，通过多尺度融合模块（模态增强、全局查询跨模态交互、自适应门控）及深度大核桥接扩大上下文，解码器为U-Net风格且仅训练时使用深监督。

✨ **主要贡献**：在KITTI Road达97.23% MaxF，ORFD测试集达96.74% F-score与93.68% IoU；Jetson Orin NX上PyTorch FP16达22.18 FPS、TensorRT FP16达68.73 FPS，并在三种异构机器人平台上验证了可移植性。

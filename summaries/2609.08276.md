# Online Signature Verification Using Augmented Path Signature and T-Mamba

- arXiv: https://arxiv.org/abs/2609.08276v1
- arXiv ID: 2609.08276

---

🔍 **核心问题**：在线签名验证（OSV）中，现有深度学习方法难以提取高判别性特征并建模长距离依赖关系，导致验证精度受限。

🛠 **方法**：提出将增强路径签名（APS）描述符与T-Mamba模型结合的框架。APS通过时间和基点增强及滑动窗口路径签名捕捉几何结构和非线性通道交互；T-Mamba混合两个时间卷积网络（TCN）块与时间扫描Mamba，同时学习局部时序模式和全局长距离依赖。

✨ **主要贡献**：在MCYT-100、SVC-2004 Task 2和DeepSignDB三个公开基准上取得最优等错误率（EER），尤其在训练数据有限时表现突出，验证了方法的有效性和鲁棒性，并公开代码。

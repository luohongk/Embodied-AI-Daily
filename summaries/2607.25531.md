# Multi-Scale Structural Features for Continual, Comprehensible Visual Recognition in a Developmental Learning Framework

- arXiv: https://arxiv.org/abs/2607.25531v1
- arXiv ID: 2607.25531

---

🔍 **核心问题**：解决传统机器学习在持续学习中难以保留先前知识、缺乏可解释内部结构的问题，尤其是在视觉识别任务中特征表达能力不足导致准确率受限。

🛠 **方法**：提出一种多尺度结构特征表示，编码边缘、轮廓及其空间关系，并整合到无梯度、基于局部变异与选择的发育学习框架中，同时改进学习动态和模型预测读出机制。

✨ **主要贡献**：在类增量MNIST基准上显著提升识别准确率，匹配或超越基于回放和正则化的基线方法，且无需存储历史数据；关键优势在于学习过程中能完整保留早期所学类别，避免破坏性适应，并保持模型结构的人类可解释性。

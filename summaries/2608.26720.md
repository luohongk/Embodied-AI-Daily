# Parameter Efficient Continual Learning for Sparse Event-Based Transformers

- arXiv: https://arxiv.org/abs/2608.26720v1
- arXiv ID: 2608.26720

---

🔍 **核心问题**：针对稀疏事件驱动视觉Transformer在持续学习场景中能力不足的问题，提出一种参数高效且能量受限的持续学习方案。

🛠 **方法**：提出sLoTh框架，冻结骨干网络，仅更新可扩展的低秩注意力模块（seLoRA）和共享神经元阈值，参数更新量小于1%，无需回放缓冲区。

✨ **主要贡献**：在CIFAR-100、Tiny-ImageNet、ImageNet-100和ImageNet-R上（最多100个任务）实现无回放类增量学习与在线持续学习，性能具竞争力，且能耗比传统密集视觉Transformer降低约6.5倍。

# HINT: Human-Intent Inception for Long-Horizon Robot Manipulation

- arXiv: https://arxiv.org/abs/2609.02653v1
- arXiv ID: 2609.02653

---

🔍 **核心问题**：长时程机器人操作中，视觉信息容易主导语义意图，导致动作偏离人类目标，尤其在密集视觉输入和稀疏语言指令下难以实现高层级智能行为。

🛠 **方法**：提出HINT框架，模仿人类操作原理——仅在操作模式转换时触发语义推理以解析当前子任务和目标，其余时间通过多视角锚定与视觉追踪维持意图，并通过图像空间语义高亮和注意力先验注入两种视觉接口将追踪意图传递给动作策略，无需增加基础模型可训练参数。

✨ **主要贡献**：在三个长时程任务及分布外变体上显著提升意图理解、任务进度和端到端成功率，适用于两种基础策略，同时保持低延迟控制。

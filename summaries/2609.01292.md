# Relational Task Generation Language: A Declarative Specification Framework for Relational Deep Learning

- arXiv: https://arxiv.org/abs/2609.01292v1
- arXiv ID: 2609.01292

---

🔍 **核心问题**：关系深度学习（RDL）中预测任务的手动定义过程繁琐且易导致数据泄漏，缺乏标准化、声明式的任务规范方法。

🛠 **方法**：提出关系任务生成语言（RTGL），一种开源声明式语言，通过抽象底层SQL细节来简化RDL任务定义，并支持多样化的任务形式与目标类型。

✨ **主要贡献**：重建现有RDL基准任务并揭示其因手工SQL定义导致的不一致性；验证了RTGL的鲁棒性、易用性及其与现有RDL框架的无缝集成，为社区提供了便捷的任务定义工具。

# On-Device Inference versus Wireless Streaming: Energy-Efficient Multi-Modal Deep Learning for Wearable Cardiovascular Patches

- arXiv: https://arxiv.org/abs/2510.18668v4
- arXiv ID: 2510.18668

---

🔍 **核心问题**：可穿戴心血管贴片在资源受限条件下，需权衡本地设备推理与无线传输至云端处理的能耗效率。

🛠 **方法**：提出一种端到端多模态卷积神经网络，采用早期融合直接处理心电图和心音图信号，并部署8位整数量化模型至集成神经处理单元的微控制器，同时对比蓝牙低功耗传输能耗。

✨ **主要贡献**：浮点模型准确率达0.975，参数与计算量降低约三个数量级；神经处理单元推理能耗仅为CPU推理的七分之一，且本地推理比连续原始数据流传输更节能，证明边缘设备智能推理是持续心血管监测的更优方案。

# Agile-WAM: An Agile Tactile World Action Model for Contact-Rich Robot Control

- arXiv: https://arxiv.org/abs/2609.20761v1
- arXiv ID: 2609.20761

---

🔍 **核心问题**：现有触觉世界动作模型（WAM）依赖大规模预训练生成骨干网络来建模富接触物理动态，导致推理效率低、部署不灵活，难以满足高频精确的机器人控制需求。

🛠 **方法**：提出 Agile-WAM，将视觉与触觉观测编码到共享隐空间，通过直接“视觉-触觉到动作”的流匹配过程联合生成动作块及未来视觉/触觉隐表示；并引入多时间尺度多模态预测——视觉隐表示在较大时间偏移下监督，触觉隐表示预测下一帧，以捕捉接触瞬间的突变动态。

✨ **主要贡献**：在9个仿真和5个真实富接触操作任务中表现优异，真实实验整体成功率相对提升29.4%，推理延迟仅11.9 ms，证明无需大型生成骨干也能实现敏捷、高频的多模态世界动作模型控制。

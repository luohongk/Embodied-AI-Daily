# Retrofitting Code Using LLMs to Support Exceptional Behavior

- arXiv: https://arxiv.org/abs/2609.10397v1
- arXiv ID: 2609.10397

---

🔍 **核心问题**：如何为已有代码自动补全异常相关代码（ERC，包括throw语句、守卫条件及try/catch块），使给定的异常行为测试（EBT）能够通过，从而免除开发者手动编写ERC的繁琐工作。

🛠 **方法**：提出EXCODER工具，将静态与动态程序分析相结合，提取上下文信息并注入大语言模型（LLM），通过上下文工程辅助LLM完成ERC的自动生成。

✨ **主要贡献**：首次提出"为现有代码改装ERC"的新任务并构建了来自75个Java项目的304个方法基准；EXCODER结合Qwen 2.5 Coder 32b在开发者测试集上达到85.92%的pass@1（较基线提升12.56个百分点），同时通过人工检查揭示了工具的局限性并指明未来方向。

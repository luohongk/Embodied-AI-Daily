# Pre-training Visual Dexterity in Simulation

- arXiv: https://arxiv.org/abs/2608.15917v1
- arXiv ID: 2608.15917

---

🔍 **核心问题**：多指灵巧手的机器人策略训练缺乏大规模数据，因为真实遥操作成本高，而人类手部视频存在姿态估计和重定向损失。

🛠 **方法**：提出模拟预训练框架（SPD），在VR环境中让操作员操控虚拟物体，收集75小时多任务灵巧操作数据，用于预训练因果Transformer，再在真实56自由度双臂灵巧系统上用1-2小时物理演示进行微调。

✨ **主要贡献**：首次证明模拟遥操作数据可作为真实灵巧操作的有效预训练来源，显著优于从零训练的行为克隆策略；并通过消融实验验证了历史状态条件化和短动作块对反应式控制的重要性。

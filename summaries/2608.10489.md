# When Vision Becomes Text: Visual Token Pruning via Cross-Modal Residual Guidance in VLMs

- arXiv: https://arxiv.org/abs/2608.10489v1
- arXiv ID: 2608.10489

---

🔍 **核心问题**：视觉语言模型（VLM）中大量视觉token导致推理成本过高，现有剪枝方法仅基于局部相似性引导，未考虑整个推理过程中的跨模态信息吸收现象。

🛠 **方法**：提出跨模态残差（CMR）引导机制，通过Tikhonov正则化最小二乘将视觉token投影到文本子空间，利用重建残差量化文本无法解释的视觉信息；结合CMR、文本注意力相关性和残差空间多样性，提出无需训练的SIEVE剪枝方法。

✨ **主要贡献**：首次从几何视角量化文本对视觉信息的吸收（CMA），并据此设计高效剪枝方案。在LLaVA-NeXT-7B上仅保留11.1%视觉token即可保持97.5%性能，实现3.62倍预填充加速、2.49倍端到端加速和6.02倍KV缓存缩减。

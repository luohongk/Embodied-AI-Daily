# Le Critique: Privileged Value Functions for LLM Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.16739v1
- arXiv ID: 2608.16739

---

🔍 **核心问题**：LLM强化学习中，GRPO等组相对方法仅提供序列级信用分配且受慢速样本拖累，而传统价值函数方法因工程复杂和实际效果不佳未被广泛采用。

🛠 **方法**：提出两种互补策略——特权价值函数（PVF）注入任务相关的token级信号而不偏置策略目标；TETHER基线根据价值函数准确性自适应地在组相对基线与价值基线间插值。

✨ **主要贡献**：在多个推理任务上，两种策略均稳定优于标准价值函数基线，且与均值基线GRPO性能相当或更优，证明了价值函数RL的可行性和有效性。

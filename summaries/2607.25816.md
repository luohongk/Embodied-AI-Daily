# Speculate While You Reason: Teaching Agents to Predict Their Next Tool Call via Joint Agent-Speculator RL

- arXiv: https://arxiv.org/abs/2607.25816v1
- arXiv ID: 2607.25816

---

🔍 **核心问题**：大语言模型智能体在调用工具时需等待结果，导致大量时间延迟；现有投机模型（speculator）与智能体行为不一致，存在“投机-智能体差距”。

🛠 **方法**：提出“自投机智能体”（self-speculating agent），将智能体与投机模型统一为同一模型，通过联合智能体-投机强化学习（joint agent-speculator RL）交替更新，利用智能体自身轨迹生成投机目标。

✨ **主要贡献**：在搜索问答和对话式工具使用任务中，将下一工具调用预测的Hit@1从44.1提升至61.2（Qwen3-4B）和从48.9提升至66.3（Qwen3.5-4B），同时保持任务成功率不下降。

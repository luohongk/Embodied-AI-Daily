# EmbodiedSkills: A Unified Framework for Orchestrating, Training, and Deploying VLA Agents

- arXiv: https://arxiv.org/abs/2609.01281v1
- arXiv ID: 2609.01281

---

🔍 **核心问题**：解决视觉-语言-动作（VLA）模型在长时程机器人任务中仅预测动作、缺乏对执行有效性与结果验证的闭环保障问题。

🛠 **方法**：提出EmbodiedSkills统一框架，将每个技能决策视为“执行提案”，在执行前检查前提条件、执行后验证结果；通过固定的可执行技能接口连接高层技能选择、低层VLA执行与后动作验证，并记录结构化轨迹以支持组件监督与在线适应。

✨ **主要贡献**：在RoboTwin 2.0的50个任务上平均成功率达86.20%，在LIBERO四个套件上达97.40%；框架提供可训练、可检查的智能体层，支持低层VLA策略灵活替换，无需改动主循环。

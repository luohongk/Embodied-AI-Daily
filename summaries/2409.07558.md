# Unsupervised Point Cloud Registration with Self-Distillation

- arXiv: https://arxiv.org/abs/2409.07558v2
- arXiv ID: 2409.07558

---

🔍 **核心问题**：无监督刚性点云配准，避免依赖昂贵的真实位姿标注，提升训练可扩展性。

🛠 **方法**：采用自蒸馏框架，学生网络处理增强视图，教师网络包含可训练特征提取器和无学习鲁棒求解器（如RANSAC），通过最大化无监督内点率来优化一致性，无需手工特征或连续帧输入。

✨ **主要贡献**：简化训练流程，在3DMatch基准上超越现有无监督方法，并成功泛化到汽车雷达数据（传统特征失效场景），代码已开源。

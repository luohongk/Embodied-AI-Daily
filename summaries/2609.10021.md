# RoboDrop: Curating VLA Post-Training Data via Local Gradient Compatibility

- arXiv: https://arxiv.org/abs/2609.10021v1
- arXiv ID: 2609.10021

---

🔍 **核心问题**：VLA模型在新任务和新机器人本体上进行后训练时对数据质量高度敏感，而实际采集的机器人数据常含执行错误、传感器漂移、时间戳错位等异质噪声，人工检查成本高，现有清洗方法又只针对特定损坏类型。

🛠 **方法**：提出RoboDrop数据筛选框架，在单轮预热训练中在线计算每个候选样本的梯度与任务语义及视觉匹配验证样本梯度之间的局部梯度兼容性，作为其对后训练性能影响的代理指标，再按回合聚合分数并通过自动后处理规则生成过滤决策。

✨ **主要贡献**：在受控损坏、仿真次优演示和真实机器人数据上，RoboDrop比现有方法更准确地识别不可靠演示，用筛选后数据后训练得到的策略性能持续更强，真实机器人平均 rollout 成功率从35.0%提升至67.5%，确立了训练轨迹感知、上下文条件化的监督审计作为稳健VLA后训练的有效途径。

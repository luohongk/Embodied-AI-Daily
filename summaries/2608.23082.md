# A fast improved quasi-physical dynamic algorithm for efficient wireless coverage in convex polygonal regions

- arXiv: https://arxiv.org/abs/2608.23082v1
- arXiv ID: 2608.23082

---

🔍 **核心问题**：在凸多边形区域内高效部署无线节点以最大化覆盖面积，这是一个NP-hard的最优圆覆盖问题，现有方法在复杂多边形中常因初始化差、覆盖重叠和节点越界导致效率低下。

🛠 **方法**：提出改进的准物理动态算法（IQPD），包含结构保持初始化（通过缩放和仿射变换映射六角密排图案）、精炼虚拟力模型（引入摩擦和半径扩展机制减少重叠），以及边界环绕策略（利用法向和切向梯度将越界节点拉回区域内）。

✨ **主要贡献**：在多种凸多边形（含随机和真实场景）中，IQPD相比其他元启发式算法始终取得最高覆盖率与节点利用率，显著提升无线覆盖效率，且运行时间更短。

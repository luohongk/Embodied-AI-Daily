# Mobile Multi-Robot Navigation under Runtime Uncertainty via Koopman Operator Learning and Nonlinear Model Predictive Control

- arXiv: https://arxiv.org/abs/2609.14058v1
- arXiv ID: 2609.14058

---

🔍 **核心问题**：如何在存在运行时不确定性（如随机车轮打滑）且未知真实动力学模型的情况下，实现移动多机器人的闭环导航与编队控制。

🛠 **方法**：利用Koopman算子理论学习提升的双线性动力学模型，并将其嵌入非线性模型预测控制（NMPC）框架中，以预测受扰动和不确定性影响的仿射输入系统。

✨ **主要贡献**：提出了一种基于Koopman算子的NMPC框架，能够在障碍物环境中有效应对不同程度的车轮打滑，成功实现了多机器人目标到达与编队控制，并通过大量数值仿真验证了方法的有效性。

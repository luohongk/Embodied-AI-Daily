# Module Number Adaptive Visual Shape Control for Serial Modular Soft Robots

- arXiv: https://arxiv.org/abs/2608.29547v1
- arXiv ID: 2608.29547

---

🔍 **核心问题**：现有软体机器人视觉形状控制方法依赖固定结构，模块数量变化时需重新采集控制数据，缺乏可扩展性。

🛠 **方法**：提出模块数量自适应的视觉形状控制方法，仅用单模块训练数据，通过将整体相机图像分解为局部模块补丁，复用同一控制器控制1至5个模块的机器人；采用几何数据增强提升下游模块迁移性，并用轻量级掩膜重建网络恢复被移除的执行器通道。

✨ **主要贡献**：首次实现无需配置特定数据采集的模块数量自适应形状控制，在物理机器人上验证了跨模块数量、环境变化及负载条件下的控制有效性，证明单模块学习可扩展至多模块整体控制。

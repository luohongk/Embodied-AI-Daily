# FineVLA: Fine-Grained Instruction Alignment for Steerable Vision-Language-Action Policies

- arXiv: https://arxiv.org/abs/2605.27284v3
- arXiv ID: 2605.27284

---

🔍 **核心问题**：现有机器人数据集的指令通常只描述任务目标（如“拿起杯子”），缺乏执行细节（如用哪只手臂、接近方向、接触区域），限制了策略的可操控性和机器人视频理解能力。

🛠 **方法**：提出FineVLA框架，包括数据构建工具（整合10个开源数据集，生成47,159条细粒度轨迹）、细粒度基准（500视频、11,631原子事实）、机器人专用VLM标注器，以及混合细粒度和目标级指令训练的VLA策略。

✨ **主要贡献**：细粒度监督不牺牲目标级成功率（提升+1.4~+8.1点）；细粒度与原始指令互补，最佳混合比FG:Raw=1:2~1:1，在仿真和真实操作中分别达86.8%/82.5%和62.7（vs. 49.9原始）；细粒度监督显著提升可控性，在姿态、颜色和接近方向等维度上真实世界增益最大（+18~+23点）。

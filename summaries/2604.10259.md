# Real-Time Human Reconstruction and Animation using Feed-Forward Gaussian Splatting

- arXiv: https://arxiv.org/abs/2604.10259v2
- arXiv ID: 2604.10259

---

🔍 **核心问题**：从稀疏多视角RGB图像中实现高质量的人体3D重建与实时动画，同时避免依赖深度监督、固定视角或计算昂贵的交叉注意力机制。

🛠 **方法**：提出HumanGS框架，采用简单Transformer架构，通过几何反投影将SMPL-X顶点与多尺度图像特征显式关联，聚合多视角信息后由轻量MLP解码器生成与SMPL-X顶点对齐的3D高斯原语（一个约束高斯贴近表面，若干无约束高斯捕捉衣物等细节），并通过线性混合蒙皮和高斯光栅化实现高效动画。

✨ **主要贡献**：仅用THuman2.1的10K帧从头训练，重建质量达到或超越现有方法，重建速度比近期基于Transformer的方法快15倍以上，支持实时动画与交互应用。

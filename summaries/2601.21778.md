# Error Amplification Limits ANN-to-SNN Conversion in Continuous Control

- arXiv: https://arxiv.org/abs/2601.21778v3
- arXiv ID: 2601.21778

---

🔍 **核心问题**：在连续控制任务中，将训练好的人工神经网络（ANN）转换为脉冲神经网络（SNN）时，微小的动作近似误差会在决策步骤间产生时间相关性，导致状态分布偏移累积，严重降低性能。

🛠 **方法**：提出跨步残差电位初始化（CRPI），一种轻量级无梯度机制，通过在决策步骤间传递残留膜电位，抑制时间相关的误差累积。

✨ **主要贡献**：在连续控制基准（含向量和视觉观测）上验证了CRPI能有效恢复转换后的SNN性能，并揭示了连续控制是ANN-to-SNN转换中误差放大效应显著的关键挑战场景。

# Supporting Industrial Test-Failure Analysis with LLM-Based Systems: An Experience Report

- arXiv: https://arxiv.org/abs/2609.21843v1
- arXiv ID: 2609.21843

---

🔍 **核心问题**：如何利用工具增强的大语言模型（LLM）系统，辅助Westermo公司对夜间测试失败进行根因分析（RCA），以替代人工跨多源手动排查异构测试数据与日志的方式。

🛠 **方法**：实现了单智能体与编排式多智能体两种RCA工作流（均可访问测试元数据与日志），通过两个真实失败场景开展探索性工业案例研究，结合六位从业者的问卷与焦点小组评估，并对120次重复执行进行运行测量。

✨ **主要贡献**：发现两种配置在两个场景中均未呈现一致的感知质量优势；单智能体系统生成报告更快、成本更低，是更实用的基线，而多智能体架构的潜在收益仍需在更复杂场景中进一步评估。

# VeriScene: Reconstructing Crime Scenes from Legal Evidence via World-Model Agent

- arXiv: https://arxiv.org/abs/2609.08342v1
- arXiv ID: 2609.08342

---

🔍 **核心问题**：如何将多模态法律证据（如现场照片和证人陈述）融合，重建犯罪现场并动态重现犯罪过程，同时保证证据可追溯、动作物理合理，且能处理矛盾证词。

🛠 **方法**：提出VeriScene智能体，通过审计循环将证据迭代融合为带引用的叙事，利用世界模型进行探针推演验证假设动态并注入修正约束，最终从融合关键帧渲染重现视频。

✨ **主要贡献**：在25个犯罪场景基准上，VeriScene达到0.9014证据覆盖率和0.7217事实一致性，比端到端多模态LLM基线在事实一致性上提升20.35%、时间连贯性上提升34.88%，且跨4种LLM后端泛化，单场景成本仅1.82美元。

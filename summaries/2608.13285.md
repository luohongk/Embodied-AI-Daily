# EEG Decoding Using CNN and LSTM Network

- arXiv: https://arxiv.org/abs/2608.13285v1
- arXiv ID: 2608.13285

---

🔍 **核心问题**：运动想象脑机接口（MI-BCI）中，脑电信号（EEG）噪声大且与大脑活动关系复杂，导致可靠的MI-EEG解码困难。

🛠 **方法**：提出一种混合深度学习架构，结合卷积神经网络（CNN）和双向长短期记忆网络（bi-LSTM）。CNN从原始EEG中提取空间和时间特征，bi-LSTM建模特征间的时序依赖关系。

✨ **主要贡献**：在公开数据集和自采数据集上，该架构在二类和三类运动想象分类中均表现稳健，并展现出良好的跨被试（subject-independent）解码能力。

# Leveraging Image Generators to Address Data Scarcity: The Gen4Regen Dataset for Forest Regeneration Mapping

- arXiv: https://arxiv.org/abs/2605.05627v2
- arXiv ID: 2605.05627

---

🔍 **核心问题**：森林再生区域精细语义分割面临专家标注图像极度稀缺和类别严重不平衡的双重挑战，限制了深度学习模型的应用。

🛠 **方法**：利用大规模图像生成模型Nano Banana Pro，通过提示词同时生成高保真合成图像及其像素级对齐的语义掩码，并与真实数据（WilDReF-Q-V2数据集）联合训练。

✨ **主要贡献**：构建了包含2101对合成图像与掩码的Gen4Regen数据集，证明AI生成数据与真实数据高度互补，统一训练使F1分数提升超15个百分点，部分稀有类别提升超30个百分点，为标注稀缺领域提供了可扩展的数据生成框架。

# Model Predictive Control of Tensegrity Robots via Contact-Aware Graph Neural Dynamics Model

- arXiv: https://arxiv.org/abs/2609.08958v1
- arXiv ID: 2609.08958

---

🔍 **核心问题**：张拉整体机器人在复杂接触丰富地形中的建模与控制难题，尤其是非水平地形、障碍和自碰撞下的动力学预测与导航。

🛠 **方法**：提出一种基于接触感知图神经网络（GNN）动力学模型的模型预测路径积分（MPPI）控制器，并引入混合MPPI策略（结合转向运动原语）以提升机动性。

✨ **主要贡献**：扩展了GNN模型以支持可微接触检测，实现闭环数据采集与模型迭代优化；在MuJoCo五种导航任务中验证了该方法相比A*重规划和纯MPPI变体具有更高的预测精度与导航性能，展示了复杂接触环境下鲁棒导航能力。

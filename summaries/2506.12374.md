# AntiGrounding: Executable Robot Trajectories as Visual Prompts for VLM-Guided Manipulation

- arXiv: https://arxiv.org/abs/2506.12374v3
- arXiv ID: 2506.12374

---

🔍 **核心问题**：自然语言操作指令只指定任务目标，却不给出具体的机器人运动轨迹，如何让VLM在可执行轨迹层面进行选择与引导。

🛠 **方法**：提出AntiGrounding双几何-视觉轨迹接口，将每条经可行性筛选的短轨迹既作为显式运动计划，又渲染为VLM评估的视觉提示，通过多视角结构化VQA对安全性、任务对齐、效率和物理合理性打分并加权融合，指导后续轨迹提议，配合数字孪生验证后由真实机器人执行。

✨ **主要贡献**：在八项真实操作任务中实现71.25%总体成功率，显著优于pi0.5（50.00%）和PIVOT式基线（47.50%），并通过消融与评估器敏感性分析验证了轨迹评估、提议搜索、姿态控制等组件的有效性。

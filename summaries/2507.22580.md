# RePaCA: Leveraging Reasoning Large Language Models for Static Automated Patch Correctness Assessment

- arXiv: https://arxiv.org/abs/2507.22580v2
- arXiv ID: 2507.22580

---

🔍 **核心问题**：自动程序修复（APR）工具常生成满足测试但未修复根本缺陷的过拟合补丁，需静态评估补丁正确性（APCA）以识别此类补丁，但现有静态方法在可靠性、灵活性和可解释性上不足。

🛠 **方法**：提出RePaCA，利用擅长推理的大型语言模型（LLM），输入缺陷和修复代码片段，引导生成思维链（Chain of Thought）分析代码差异、推理补丁对根因的处理，并输出二分类（正确或过拟合）；通过组相对策略优化（GRPO）算法进行强化学习微调以增强推理能力。

✨ **主要贡献**：在Defects4J标准测试上达到83.1%准确率和84.8% F1分数，实现最先进性能；跨数据集训练时表现出更强泛化能力，优于现有领先技术；推理过程提升了补丁评估的可解释性，展示了微调推理LLM在静态APCA中的潜力。

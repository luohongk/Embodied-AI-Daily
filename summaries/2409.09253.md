# Unleash LLMs Potential for Sequential Recommendation by Coordinating Dual Dynamic Index Mechanism

- arXiv: https://arxiv.org/abs/2409.09253v2
- arXiv ID: 2409.09253

---

🔍 **核心问题**：现有基于LLM的序列推荐系统将索引生成与序列推荐分离，导致语义信息与协同信息融合不足，同时忽视用户相关信息，无法利用高阶用户-物品交互模式。

🛠 **方法**：提出端到端双动态（ED²）推荐器，采用双动态索引机制将索引生成与序列推荐统一到LLM骨干流水线中，并设计多粒度token调节器构建对齐监督，配合用户集合数据与新型指令微调任务捕捉高阶交互模式。

✨ **主要贡献**：首次在基于LLM的序列推荐中引入双动态索引机制，实现索引生成与推荐的一体化，并有效利用用户信息；在三个公开数据集上平均提升Hit-Rate 19.62%、NDCG 21.11%。

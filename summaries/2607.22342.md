# Beyond Binary Rooftop Mapping: A Four-Class Deep Learning Framework for Green Roof Potential Assessment from Open Swiss Geospatial Data

- arXiv: https://arxiv.org/abs/2607.22342v1
- arXiv ID: 2607.22342

---

🔍 **核心问题**：现有研究通常只单独识别现有绿色屋顶或具备绿化潜力的屋顶，缺乏同时评估两者的综合方法，难以全面支持城市热岛缓解等气候适应策略。

🛠 **方法**：基于Roofpedia框架，改进深度卷积神经网络，结合高分辨率航空影像和数字表面模型提取的屋顶坡度信息，利用瑞士公开数据集（SWISSIMAGE、swissSURFACE3D、swissTLM3D），将屋顶分为四类：现有绿色屋顶、适合安装绿色屋顶的屋顶、安装太阳能板的屋顶、不适合绿化的平屋顶。

✨ **主要贡献**：首次提出四类屋顶分类框架，同时识别现有绿色屋顶和绿化潜力屋顶，为城市规划者提供基于证据的绿色基础设施部署信息；完全开源，可迁移至全球其他城市。

# Model Predictive Control is almost Optimal for Heterogeneous Restless Multi-armed Bandits

- arXiv: https://arxiv.org/abs/2511.08097v2
- arXiv ID: 2511.08097

---

🔍 **核心问题**：针对异构无限时域多臂赌博机（RMAB）问题，其中各臂具有不同模型参数，传统方法难以处理这种异构性导致的收敛性分析困难。

🛠 **方法**：采用模型预测控制（MPC）策略，通过反复求解有限时域线性规划（LP）来生成无限时域策略，称为LP-update策略；并进一步提出分段有限时域策略（LP-update with recomputation）以显式关联计算时间与误差容忍度。

✨ **主要贡献**：在均匀遍历的温和假设下，证明了LP-update策略的次优性间隙为𝒪(√(1/N))；理论分析基于耗散性概念，可推广至弱耦合异构马尔可夫决策过程；实验表明即使有限时域τ很小（如5）算法仍高效，并揭示了LP-index策略等价于τ=1的特例。

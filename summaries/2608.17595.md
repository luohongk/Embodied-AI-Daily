# Modified Bryson-Frazier Smoothing and Hyperparameter Learning for Temporal Gaussian Process Regression

- arXiv: https://arxiv.org/abs/2608.17595v1
- arXiv ID: 2608.17595

---

🔍 **核心问题**：一维高斯过程回归中，RTS平滑器需对预测状态协方差矩阵求逆，可能因病态条件导致数值不稳定，且计算成本高。

🛠 **方法**：采用修正的Bryson-Frazier（MBF）平滑器替代RTS平滑器，在状态空间表示下进行高斯过程回归，并复用其中间量计算边际似然负对数的梯度，用于超参数学习。

✨ **主要贡献**：MBF平滑器在避免协方差矩阵求逆的同时，得到与RTS相同的后验分布，且计算和内存开销更低；同时实现超参数学习的梯度计算几乎零额外成本，为单维高斯过程回归提供了统一且数值稳健的推断与学习方案。

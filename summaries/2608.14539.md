# Decoding the Past: An Uncertainty-Aware Deep Learning Framework for Sex Attribution in Prehistoric Hand Stencils

- arXiv: https://arxiv.org/abs/2608.14539v1
- arXiv ID: 2608.14539

---

🔍 **核心问题**：解决旧石器时代手印模板性别归属难题，因缺乏真实标签、古今人群差异及图像退化带来的不确定性，传统形态测量方法难以有效区分性别。

🛠 **方法**：提出不确定性感知的深度学习框架，结合双图像处理、双轮廓提取、结构化剪影增强、模型架构多样性与集成决策聚合，使用EfficientNet-B3和MobileViT-S双集成网络，并融合UMAP+k-NN无监督映射与LayerCAM可解释性分析进行三角验证。

✨ **主要贡献**：在当代数据上准确率超88%，对史前手印可输出性别预测及内部一致性置信度，实现不确定性作为可量化考古推断指标，区分形态稳定与模糊案例，提升古代岩画解码的鲁棒性与可重复性。

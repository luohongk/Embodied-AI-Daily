# rMuscle: Robotic Muscle Memory for Efficient Vision-Language-Action Model Inference

- arXiv: https://arxiv.org/abs/2609.19104v1
- arXiv ID: 2609.19104

---

🔍 **核心问题**：VLA模型推理延迟影响机器人响应速度与动作流畅性，而现有推理框架未充分利用具身工作负载的特性（重复执行中的任务相似性）及各阶段瓶颈差异。

🛠 **方法**：提出rMuscle实时推理框架，通过双阶段"肌肉记忆"缓存利用跨执行相似性——Context Cache复用视觉token输出减少计算，Action Cache复用神经元激活模式减少权重访问，并结合在线缓存重计算、滑动窗口检索和跨去噪步掩码共享降低开销。

✨ **主要贡献**：在RTX 4090和Jetson Thor上于LIBERO、RoboTwin及物理操作任务中实现1.29–1.42倍加速，同时在真实机器人上保持原始成功率。

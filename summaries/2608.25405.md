# LAC: Linear and Angular Compliance for Humanoid Whole-body Control

- arXiv: https://arxiv.org/abs/2608.25405v1
- arXiv ID: 2608.25405

---

🔍 **核心问题**：现有仿人机器人全身控制器在物理交互中，要么将外力视为干扰而拒绝，要么仅对有限身体部位实现刚性或线性柔顺，缺乏对全身线性与角向柔顺的统一控制。

🛠 **方法**：提出LAC控制器，通过将全身柔顺响应合成为大规模增强数据集，在接触点施加力与力矩事件，利用虚拟导纳模型在指令刚度下生成柔顺运动；随后采用教师-学生强化学习训练单一策略，以跟踪外部力/力矩下的柔顺动作。

✨ **主要贡献**：在仿真与真实实验中，实现了上半身任意位置对外部力/力矩的全身柔顺响应，刚度指令在全程范围内可单调调节，并成功应用于遥操作移动操作任务，验证了方法的通用性与实用性。

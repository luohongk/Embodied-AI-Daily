# EvoCUA-1.5: Online Reinforcement Learning for Multi-turn Computer-Use Agents

- arXiv: https://arxiv.org/abs/2607.09773v2
- arXiv ID: 2607.09773

---

🔍 **核心问题**：多轮计算机使用智能体需在部分可观测的桌面环境中完成长时任务，但静态模仿学习无法覆盖真实交互的因果反馈循环，且在线强化学习面临多轮交互、稀疏奖励和慢环境反馈等挑战。

🛠 **方法**：提出EvoCUA-1.5，采用步骤级策略优化（STEPO）分解轨迹级优势，结合策略感知过滤与通过率校准、动态三自适应课程（DTAC）以及全异步RL基础设施（含陈旧性控制和小型分组批处理）。

✨ **主要贡献**：在OSWorld-Verified上达到63.2%成功率，超越同规模32B/35B开源基线，接近更大参数模型，为多轮计算机使用智能体的在线RL扩展提供了实用框架。

# StochSIPP: Safe Interval Path Planning in Stochastic Dynamic Environments

- arXiv: https://arxiv.org/abs/2608.00792v1
- arXiv ID: 2608.00792

---

🔍 **核心问题**：在随机动态环境中，如何在时间相关的障碍物状态不确定且仅能局部观测的情况下，规划出安全且高效的路径。

🛠 **方法**：提出StochSIPP，一种基于SIPP的精确应急规划器，通过生成在下次观测或目标处终止的认证安全宏动作，并利用有界AND/OR搜索在缓存的动作-观测图上为每个可达观测结果选择动作，同时采用乐观和鲁棒SIPP松弛提供上下界。

✨ **主要贡献**：在确定性安全区间、精确感知和按时执行条件下，策略可证明无碰撞；在概率独立且动作/结果生成完整时，能最小化期望到达时间。实验表明其优于保守固定路径规划器，可解决门控场景，但扩展性受同时观测的不确定状态数量限制。

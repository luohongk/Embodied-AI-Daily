# Continuous Cognitive Coverage for Autonomous Robots via Event-Dependent Cognitive Treatment and Learning

- arXiv: https://arxiv.org/abs/2609.04770v1
- arXiv ID: 2609.04770

---

🔍 **核心问题**：现有机器人认知处理多为任务驱动或固定推理，难以对持续遇到的事件提供差异化、连续性的认知覆盖。

🛠 **方法**：提出一种连续认知覆盖框架，为每个被认知接纳的事件依据其状态、上下文和历史分配事件依赖的认知处理（如描述、记忆、风险预测、规划、诊断、类比等），支持多认知过程的挂起、恢复与交错，并通过经验学习自动优化处理策略。

✨ **主要贡献**：实现了96.76%的结构化处理准确率、93.66%的自动处理率、92.64%的认知覆盖率（在突发延迟负载下），以及79.53%的持续学习联合准确率；新事件复用场景下自动处理率达100%。

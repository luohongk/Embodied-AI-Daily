# OPEN-1B: A Fully Auditable Training Run

- arXiv: https://arxiv.org/abs/2609.17380v1
- arXiv ID: 2609.17380

---

🔍 **核心问题**：现有开源语言模型因浮点运算的非结合性，即使公开权重、数据和配方，也无法跨硬件证明其训练过程的可复现性，从而无法排除隐藏数据、注入偏见或后门。

🛠 **方法**：通过对训练中非确定性来源（GPU核归约、数据并行集群的批次顺序、节点间/节点内集合通信）施加确定顺序，使分布式训练的每一步都能在单台商用硬件上按位精确重放，并采用多名独立审计者各验证部分步骤的集体验证方案覆盖整个训练过程。

✨ **主要贡献**：提出“完全可审计”这一新的模型透明层级，并发布 Open-1B 模型及其完整预训练数据集、所有中间检查点、训练代码库和审计工具，实现任意训练步骤的可复现与可验证。

# Ultrafast Sampling-based Kinodynamic Planning via Differential Flatness

- arXiv: https://arxiv.org/abs/2603.16059v3
- arXiv ID: 2603.16059

---

🔍 **核心问题**：解决高自由度机器人在动力学约束下的运动规划（kinodynamic planning）计算瓶颈问题，尤其是采样规划器中两点边值问题（BVP）求解或动力学传播带来的高耗时。

🛠 **方法**：提出FLASK框架，利用微分平坦性（differential flatness）将规划问题从原始状态空间转换到平坦输出空间，在该空间获得BVP的解析时间参数化解，再映射回状态空间生成闭式动力学可行轨迹，并结合SIMD并行化加速验证。

✨ **主要贡献**：实现微秒至毫秒级的超快规划，兼容任意采样规划器，具备概率完备性和渐近最优性保证，并在仿真和真实动态杂乱环境中验证了高效性与实用性。

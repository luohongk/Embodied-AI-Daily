# Validating LLM-Modernized Scientific Software Through Differential Fault Injection

- arXiv: https://arxiv.org/abs/2608.14527v1
- arXiv ID: 2608.14527

---

🔍 **核心问题**：现有LLM驱动的科学软件现代化验证仅关注正常执行，未检验现代化是否保留原始代码对故障、扰动和降精度的响应。

🛠 **方法**：提出差分故障注入验证方法，在GAMESS的共享自洽场驱动器中12个位置注入相同确定性故障，对比原始Fortran与LLM现代化实现的积分核行为。

✨ **主要贡献**：通过2200余次运行，验证了瞬态故障吸收成本与收缩模型一致（预测斜率0.74/1.49 vs 实测0.82/1.50），发现持久扰动使最终能量误差减半，并暴露了相位相关并行死锁和降精度下的假收敛；200对配对注入中原始与现代化核完全一致，且测量引导的同步修改与现代化组合在40对中全部匹配。

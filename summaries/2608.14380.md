# AgentRewind: Recoverable Execution for Long-Horizon LLM Agents

- arXiv: https://arxiv.org/abs/2608.14380v1
- arXiv ID: 2608.14380

---

🔍 **核心问题**：长时程LLM智能体在交互任务中，早期错误会通过上下文和环境状态传播，且难以通过后续动作逆转，现有方法缺乏错误发生后的恢复支持。

🛠 **方法**：提出AgentRewind运行时恢复框架，记录智能体上下文与受控环境的对齐检查点，使智能体可回退至先前状态并利用历史尝试信息继续执行；同时构建MettleBench基准，评估长时程工程任务中的完成度与部分进展。

✨ **主要贡献**：AgentRewind在多种任务、模型、执行策略和智能体框架下，显著提升了任务成功率和检查清单平均进展，优于对比基线；MettleBench为长时程恢复能力提供了标准化评估工具。

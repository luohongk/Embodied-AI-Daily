# Efficient Real-Time Adaptation of ROMs for Unsteady Flows Using Data Assimilation

- arXiv: https://arxiv.org/abs/2602.23188v2
- arXiv ID: 2602.23188

---

🔍 **核心问题**：针对参数化降阶模型（ROM）在非训练参数域（如不同雷诺数）下预测精度下降的问题，提出一种仅依赖稀疏观测数据的高效实时重训练策略。

🛠 **方法**：采用编码-处理-解码架构，结合变分自编码器（VAE）进行降维，用Transformer网络建模潜空间动力学；通过集成卡尔曼滤波同化稀疏数据，并仅重训练自编码器部分（而非整个模型）以适应新参数域。

✨ **主要贡献**：发现非样本外预测误差主要源于潜流形畸变而非动力学变化，因此仅需轻量级重训练自编码器即可达到与全量重训练相当的精度，大幅降低计算成本，支持实时适应和不确定性量化。

# Revisiting Topological Graphs for Macro Action based Closed-loop Reinforcement Learning of Vision Language Navigation in Continuous Environment

- arXiv: https://arxiv.org/abs/2609.03906v1
- arXiv ID: 2609.03906

---

🔍 **核心问题**：在连续环境视觉语言导航（VLN-CE）中，现有模仿学习方法因分布偏移和专家动作歧义而失效，而直接应用强化学习（RL）到微观动作空间则因奖励稀疏导致样本效率低下。

🛠 **方法**：将VLN-CE重构为分层马尔可夫决策过程（MDP），利用拓扑图抽象环境，使高层策略在宏观动作空间（前沿节点）上运行，并由免训练的低层控制器执行状态转移；同时提出动作感知价值头以支持基于图的PPO优化。

✨ **主要贡献**：显著压缩决策视野，使闭环RL在VLN-CE中可行且高效；在R2R-CE和RxR-CE基准上取得最先进性能（SOTA），验证了分层宏观动作RL架构的有效性。

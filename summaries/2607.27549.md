# Cross-Embodiment Transfer via Behavior-Aligned Representations

- arXiv: https://arxiv.org/abs/2607.27549v1
- arXiv ID: 2607.27549

---

🔍 **核心问题**：在机器人操作的大规模模仿学习中，如何有效实现跨本体（cross-embodiment）迁移，即利用不同机器人形态的数据训练策略，并泛化到新本体上。

🛠 **方法**：提出使用行为对齐表示（如物体边界框、语言动作、末端执行器轨迹）作为视觉-语言-动作（VLA）模型的中间表征，这些表示在不同本体间具有不变性且能预测机器人动作，从而统一跨本体数据。通过仿真基准测试比较不同表示及其集成方式。

✨ **主要贡献**：发现末端执行器轨迹对跨本体迁移特别有效；表示在更大先验数据集下更有用，并能利用无动作数据；在仿真到真实（sim-to-real）迁移中，预训练策略的任务完成进度提升28%。

# MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use

- arXiv: https://arxiv.org/abs/2608.20202v1
- arXiv ID: 2608.20202

---

🔍 **核心问题**：现有大语言模型记忆评测主要关注信息提取与检索的准确性，却忽略了已检索记忆对当前推理的负面影响。论文提出“记忆诱导认知陷阱”概念，即即使记忆记录正确且语义相关，也可能扭曲模型推理或信念，降低当前任务表现。

🛠 **方法**：构建MemTrapBench基准，覆盖两类认知陷阱——推理固化和信念扭曲；并提出AdaptiveMem，一种推理期轻量方法，通过指令引导LLM主动规避记忆陷阱。

✨ **主要贡献**：实验表明所有现有记忆策略在MemTrapBench上均不如无记忆设置，最强方法性能下降超10%；AdaptiveMem能有效缓解认知陷阱，同时在标准记忆基准上保持或提升性能，适用于多种记忆框架。

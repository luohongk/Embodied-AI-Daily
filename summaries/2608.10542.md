# Nonlinear Model Predictive Control via Sequential Convex Programming for Drone-to-Drone Docking

- arXiv: https://arxiv.org/abs/2608.10542v1
- arXiv ID: 2608.10542

---

🔍 **核心问题**：解决多旋翼无人机在目标受扰动运动下进行空中自主对接时，所面临的约束非线性轨迹优化难题。

🛠 **方法**：将对接任务建模为有限时域最优控制问题，采用基于降阶非线性模型并扩展扰动状态的方法，利用滚动时域内的序列凸规划（SCP）求解，并结合噪声测量下的状态估计进行轨迹执行验证。

✨ **主要贡献**：在MuJoCo高保真仿真中验证了该方法对静止和匀速目标的可靠对接，满足几何捕获约束；在锥半角低至10°时仍保持极小锥体违规和终端误差，且在风扰标准差达0.5时仍稳健运行，证明了SCP框架在估计不确定性下的扰动鲁棒性。

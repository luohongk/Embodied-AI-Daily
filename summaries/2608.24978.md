# MSR-IVA: Masked Structural Residual Independent Vector Analysis for State-Aware Fusion of Structural MRI and Dynamic Functional Network Connectivity

- arXiv: https://arxiv.org/abs/2608.24978v1
- arXiv ID: 2608.24978

---

🔍 **核心问题**：多模态融合中，当同一结构潜在表征与多个动态功能状态耦合时，现有IVA方法要么分别分解导致结构成分不相关，要么强制相同分解而抑制状态特异性关系，且未考虑部分受试者未表达所有动态状态的问题。

🛠 **方法**：提出MSR-IVA框架，将共享结构表征与状态特异性残差自适应相结合，并通过掩码机制处理状态表达不完整的情况，实现状态感知的结构MRI与动态功能网络连接融合。

✨ **主要贡献**：在ADNI队列上，MSR-IVA相比独立成对IVA基线将匹配源耦合提升6.5%，不匹配依赖降低15.7%；在表达两种状态的受试者中，跨状态结构源相关性达0.9177（无共享时仅0.2978），实现了受控的结构共享，既保持源对应性又允许状态特异性调整。

# ScienceIDE: Turning World's Scientific Codebase into Agent Learnable Environments

- arXiv: https://arxiv.org/abs/2609.19134v1
- arXiv ID: 2609.19134

---

🔍 **核心问题**：科学代码库蕴含数十年人类知识，但工具链碎片化、领域惯例隐式和验证标准特殊，导致这些知识难以转化为可靠的学习经验，即“科学经验瓶颈”。

🛠 **方法**：提出 ScienceIDE 基础设施，在专家定义的科学案例与验收标准指导下，让智能体将代码仓库转化为可执行环境，支持任务生成、执行与科学验证，并用于监督微调、强化学习和评估。

✨ **主要贡献**：基于验证过的交互轨迹训练出 PhAI-IDE-72B/9B/4B 模型系列，在科学代码修复及代码、推理、知识等通用基准上均有提升，证明科学经验可正向迁移至更广泛能力，为智能体学习与科学实践提供统一工作空间。

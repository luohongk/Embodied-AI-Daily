# IMPACT-VLA: Interaction-aware Multimodal Propagation Attribution via Counterfactual Trajectories for Vision-Language-Action Policies

- arXiv: https://arxiv.org/abs/2609.15005v1
- arXiv ID: 2609.15005

---

🔍 **核心问题**：现有归因方法只能衡量局部敏感度或时间聚合重要性，无法揭示VLA策略执行中各模态在不同阶段对任务成功的贡献，以及输入干预如何跨阶段传播。

🛠 **方法**：提出IMPACT-VLA，从成功参考轨迹的动作转换中划分行为阶段并与策略查询边界对齐，定义“阶段-模态块”为归因单元，通过闭环反事实重执行量化各块对最终任务成功的贡献，并分析跨阶段非加性交互与轨迹传播。

✨ **主要贡献**：在30个LIBERO任务（OpenVLA-OFT）中，25个任务（83.3%）出现主导模态转换；闭环归因比静态动作扰动更忠实识别任务关键信息；早期阶段输入替换使负交互对的后期块边际增益增大约3.3倍，且功能恢复可在无行为恢复时发生，揭示了多模态贡献在闭环执行中的条件耦合机制。

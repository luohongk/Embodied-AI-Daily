# Sampling-Based Coordination-Informed Multi-Objective Multi-Robot Reinforcement Learning

- arXiv: https://arxiv.org/abs/2606.30893v2
- arXiv ID: 2606.30893

---

🔍 **核心问题**：多机器人系统需同时优化多个相互冲突的目标并保持协调行为，但现有多智能体强化学习方法依赖固定或集中式协调，适应性差且不满足分布式约束。

🛠 **方法**：提出CIMORL框架，集成分布式权重预测机制、特权专家训练策略，并基于采样（树搜索CIMORL-TS和MPPI变体）利用训练时的全局信息，实现完全去中心化部署。

✨ **主要贡献**：在合作与对抗场景中，超体积指标提升21.2%，策略稳定性优于现有基线；Crazyflie无人机实验验证了部分可观测下资源分配和多攻多防场景的鲁棒性。

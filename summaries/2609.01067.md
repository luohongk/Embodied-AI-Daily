# World Model-Guided Reinforcement Learning via Counterfactual User Engagement Simulation

- arXiv: https://arxiv.org/abs/2609.01067v1
- arXiv ID: 2609.01067

---

🔍 **核心问题**：强化学习在用户中心智能体（如推荐系统）中面临在线反馈收集成本高、延迟大、风险高，且难以在相同用户状态下进行反事实比较的挑战。

🛠 **方法**：提出WMG-RL框架，利用冻结的用户模拟器（UEWM）在真实用户曝光前提供奖励监督。UEWM将推荐物品视为动作、用户反馈视为观测，从历史交互中推断用户特定动态，并并行预测多个候选物品的反馈，将其转化为密集奖励用于策略优化。

✨ **主要贡献**：UEWM能提供跨领域可靠且可迁移的奖励信号；WMG-RL使仅1.7B参数的学生策略在推荐任务上达到或超越更大规模LLM的性能，显著降低在线交互需求。

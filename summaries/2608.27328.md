# R2M-Bench: Evaluating Revisit Memory via Relative Consistency in Interactive Video World Models

- arXiv: https://arxiv.org/abs/2608.27328v1
- arXiv ID: 2608.27328

---

🔍 **核心问题**：现有视频世界模型评测中，首次访问与返回帧的高相似度可能仅源于场景变化小，而非模型真正记住了场景，导致绝对重访分数受渲染稳定性和重复内容干扰。

🛠 **方法**：提出R2M-Bench基准，通过同一条轨迹内的相对校准——将重访对与间隔匹配的非重访对（时间稳定性基线）及短程对（短期一致性）比较，计算MemoryGain和Normalized Memory Ratio。

✨ **主要贡献**：构建300个重访实例，覆盖外观、身份、几何和状态保持；在7个模型上验证Overall NMR与人类判断相关性ρ=0.547，且与运动速度相关性低（0.072 vs 0.207），有效消除慢动作捷径；DreamX-World-Memo表现最佳。

# Procedural Graphs: Self-Evolving Execution Structures for LLM Agents

- arXiv: https://arxiv.org/abs/2609.09153v1
- arXiv ID: 2609.09153

---

🔍 **核心问题**：解决LLM智能体在长程任务中因缺乏显式程序性知识而导致的规划失焦、工具调用顺序错误和重复无效操作等问题。

🛠 **方法**：提出Procedural Graph框架，将程序性知识组织为(procedure, relation, procedure)三元组图结构，通过定位活动节点并生成情境化引导来辅助决策，并利用LLM对比失败与成功轨迹实现图的自我进化。

✨ **主要贡献**：引入一种自演进的程序性知识表示方法，能从最小骨架开始构建超越手工设计的图结构，修复有缺陷的专家先验，并在多数据集、任务类型和LLM上稳定优于基于记忆的基线，无需人工干预即可持续提升性能。

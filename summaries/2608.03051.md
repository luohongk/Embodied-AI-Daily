# CUDA MPC: A GPU-Native Solver for Model Predictive Control

- arXiv: https://arxiv.org/abs/2608.03051v1
- arXiv ID: 2608.03051

---

🔍 **核心问题**：模型预测控制（MPC）依赖在线优化，在快速动态、高维模型或长预测时域下计算开销大，现有GPU实现因频繁内核启动和内存传输而效率低下。

🛠 **方法**：提出CUDA MPC框架，将并行时域ADMM分裂算法与融合CUDA内核结合，整个迭代求解在设备端完成；优化变量驻留于片上共享内存，并通过原子标志协议仅同步相邻时域块，减少主机干预和全局内存访问。

✨ **主要贡献**：在六个非线性机器人基准上，CUDA MPC在比CPU求解器长1-2个数量级的时域下保持实时性能；例如，0.1秒采样间隔内解决100步避障泊车问题，并成为唯一能实时协调10智能体集群的求解器（acados和CasADi无法求解）。相比张量框架实现，融合内核速度提升高达965倍。

# LLM Inference Under Bursty Workload Distribution: Modifying the WAIT Algorithm

- arXiv: https://arxiv.org/abs/2608.06135v1
- arXiv ID: 2608.06135

---

🔍 **核心问题**：现有LLM推理调度算法（如WAIT）假设请求到达符合恒定速率的泊松分布，无法应对真实世界中突发性、动态变化的流量模式，导致在突发负载下吞吐量下降。

🛠 **方法**：提出WAIT算法的轻量级扩展，通过在线估计请求到达间隔时间，动态适应时变的到达速率，无需预先知道流量特征；并利用基于马尔可夫调制泊松过程（MMPP）的合成工作负载进行仿真验证。

✨ **主要贡献**：在低到达率变化场景下，所提方法相比Sarathi-Serve、ORCA和vLLM实现了更高的吞吐量，同时保持相近的延迟，为突发性LLM推理负载提供了更鲁棒的调度方案。

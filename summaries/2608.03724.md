# Towards Reliable and Reproducible Fetal Brain Biometry: A Deep Learning Approach Using MRI

- arXiv: https://arxiv.org/abs/2608.03724v1
- arXiv ID: 2608.03724

---

🔍 **核心问题**：胎儿脑部生物测量是评估大脑发育、估算孕周和检测异常的关键手段，但传统手动测量耗时且易变，现有自动化方法缺乏可重复性和解剖学可解释性。

🛠 **方法**：提出一个全自动深度学习框架，基于3D超分辨率重建的胎儿脑MRI，通过四步流程联合估计线性测量值和对应解剖标志点。使用3D卷积神经网络从脑分割标签图回归标志点坐标，再通过测量特定的几何优化精修标志点并计算测量值。

✨ **主要贡献**：在两个公开胎儿MRI数据集（150个样本，孕周20-37周）上验证了五种关键生物测量指标，与现有唯一自动化流程相比，在多数测量上达到相当或更优精度，同时提供高效、可解释且可扩展的解决方案，便于临床集成。

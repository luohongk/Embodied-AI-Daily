# A Farewell to the Bias-Variance Tradeoff? An Overview of the Theory of Overparameterized Machine Learning

- arXiv: https://arxiv.org/abs/2109.02355v2
- arXiv ID: 2109.02355

---

🔍 **核心问题**：过参数化模型能完美插值含噪训练数据却仍具有良好泛化能力，这一现象挑战了传统的偏差-方差权衡理论，论文旨在系统梳理理解这一现象的理论框架。

🛠 **方法**：以统计信号处理视角，综述2018至2022年间关于过参数化线性回归及相关统计学习任务的基础理论分析，重点阐释双下降现象的精确解析刻画。

✨ **主要贡献**：系统概述了过参数化机器学习理论（TOPML）这一新兴子领域的基础发现，明确了其作为现代ML理论子领域的独特定位，并指出了未来开放的研究前沿。

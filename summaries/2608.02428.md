# DF$^3$: World Modeling via Decoder-Free Feature Forecasting in Autonomous Navigation

- arXiv: https://arxiv.org/abs/2608.02428v1
- arXiv ID: 2608.02428

---

🔍 **核心问题**：自动驾驶中从视频序列预测未来状态（世界建模）时，现有方法依赖像素级生成或重解码器，导致计算开销大且过度关注任务无关细节。

🛠 **方法**：提出DF³框架，在冻结的视觉基础模型末端注入可学习空间查询，直接在潜空间提取未来特征；通过轻量级Motion-Aware Context Fusion（MACF）机制融合粗粒度光流与细粒度潜空间互相关，并用任务查询直接生成下游输出，完全移除解码器。

✨ **主要贡献**：首次实现无解码器的纯潜空间世界建模，在公开基准和机器人模拟器零样本部署中达到与最先进方法相当的精度，同时显著提升计算效率和感知-控制集成灵活性。

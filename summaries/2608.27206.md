# PACE: A Unified Condense-and-Extract Paradigm for Fast VLM Inference

- arXiv: https://arxiv.org/abs/2608.27206v1
- arXiv ID: 2608.27206

---

🔍 **核心问题**：视觉语言模型（VLM）推理成本高，现有视觉token剪枝方法仅优化编码后阶段，且难以在严格token预算下同时保留全局上下文和细节信息。

🛠 **方法**：提出PACE框架，采用统一的“压缩-提取”范式。压缩阶段用自适应像素压缩器（APC）在编码前评估信息密度并降采样冗余输入；提取阶段用动态双注意力提取器（DDAE）融合编码器内部视觉信号和LLM语义信号，选择性保留关键视觉token。

✨ **主要贡献**：无需训练的推理加速框架，同时优化视觉编码器和LLM阶段。集成到Qwen2.5-VL-7B后，仅用10%视觉token即可保留93.8%性能，首token延迟（TTFT）提速3.1倍。

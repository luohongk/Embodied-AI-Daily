# GRAIN: Bridging Name and Narrative Shifts in Real-World Graph Reasoning through Invariance-Rewarded Agentic RL

- arXiv: https://arxiv.org/abs/2608.27142v1
- arXiv ID: 2608.27142

---

🔍 **核心问题**：大语言模型（LLM）在真实世界图推理任务中，面对节点标识符和任务表述的变化时表现脆弱，容易过拟合表面语言模式，而现有缓解方法（如多智能体系统）延迟过高。

🛠 **方法**：提出GRAIN，一个基于强化学习的单智能体框架，将推理建模为“语义解析+工具执行”流程，并通过结构不变性奖励（Structure Invariance Reward）验证提取的中间图与真实拓扑结构的一致性，迫使模型学习稳健的文本到结构映射。

✨ **主要贡献**：① 引入GRIT基准，用于评估模型对语言变化的敏感性；② GRAIN在准确率上比多智能体基线高16.45%，延迟降低约24%；③ 结构泛化能力强，将分布外（OOD）性能差距从15.77%减半至7.80%，并在超出训练分布的大规模图上保持鲁棒性。

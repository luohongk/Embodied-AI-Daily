# TrAct: Bridging Robot Control and Visual Prediction with Visual Tracks

- arXiv: https://arxiv.org/abs/2608.24101v1
- arXiv ID: 2608.24101

---

🔍 **核心问题**：机器人动作与图像空间视觉变化弱对齐，导致其作为世界模型条件信号时预测不准确，限制了机器人决策的泛化能力。

🛠 **方法**：提出TrAct框架，以视觉轨迹（visual tracks）作为控制与预测的中间接口，包含三个组件：VLAT模型联合预测候选动作与轨迹、TWM世界模型基于轨迹预测未来视觉结果、VLAC奖励模型评分并选择最优轨迹对应的动作执行。

✨ **主要贡献**：在LIBERO-INTEGRAL基准和真实Franka操作任务上，TrAct将成功率从27%提升至55%（仿真）和从49%提升至76%（真实），且TWM的视频预测质量一致优于动作条件世界模型，证明视觉轨迹是有效的共享接口。

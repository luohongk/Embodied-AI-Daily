# Learning-Aided Short Code Design for ISAC based on MIMO-OFDM

- arXiv: https://arxiv.org/abs/2609.09797v1
- arXiv ID: 2609.09797

---

🔍 **核心问题**：如何在短块传输下，为基于MIMO-OFDM的集成感知与通信（ISAC）系统设计编码波形，以灵活权衡通信可靠性与测距精度。

🛠 **方法**：采用基于Transformer的深度学习收发机，发射端将信息比特直接编码为ISAC波形，联合优化误码率（BER）与延迟修正克拉美-罗界（MCRB），接收端用对应Transformer恢复信息比特。

✨ **主要贡献**：揭示了通信导向与感知导向码字的极端结构，发现平衡的ISAC波形自然呈现两者的中间形态；数值结果表明该设计相比传统信道编码与调制方案可获得显著的权衡增益。

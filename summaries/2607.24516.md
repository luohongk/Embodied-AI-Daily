# DecoupleMix: Decoupled Ratio Search and Convex Allocation for Scalable VLM Data Recipes

- arXiv: https://arxiv.org/abs/2607.24516v1
- arXiv ID: 2607.24516

---

🔍 **核心问题**：当前视觉语言模型（VLM）的数据构建依赖启发式方法（如凭直觉设定跨领域比例、缺乏新数据准入标准），缺乏系统化、可复现的优化准则。

🛠 **方法**：提出DecoupleMix框架，将数据混合解耦为两个正交子问题——跨类别比例（通过单变量迭代搜索优化）和类别内组成（基于质量与难度评分，通过带多样性目标的约束凸优化选择数据）。

✨ **主要贡献**：实现数据收集的指导与可归因的验证实验，在80B额外多模态持续预训练数据上，VLM性能超越启发式基线，且小规模发现的最优比例可无缝迁移至大规模场景。

# Beyond Imitation: Self-Improving Robot Policies via Off-Policy Q-Planning

- arXiv: https://arxiv.org/abs/2608.21204v1
- arXiv ID: 2608.21204

---

🔍 **核心问题**：行为克隆（BC）策略无法自我改进，失败后需人工示范才能提升，而强化学习微调难以扩展到现代大规模机器人策略模型。

🛠 **方法**：提出Q-Planning，为大型视觉运动BC策略附加一个轻量级离策略Q函数。Q函数基于价值估计而非模仿动作，可同时从成功演示和部署回滚（含失败）中学习，推理时通过单步Q加权平均选择动作，在线自改进仅微调Q函数而冻结BC权重。

✨ **主要贡献**：在LIBERO和双机械臂RoboTwin基准上，十轮自改进将得分从93%提至99%（LIBERO-10）和83.8%提至91.4%（RoboTwin）；真实接触丰富双机械臂任务中，五轮迭代将堆杯成功率从40%提至90%、插钱包从25%提至80%，而仅用成功回滚的SFT停滞在55%和30%。在相同在线预算下，Q-Planning是唯一能稳定从失败中改进且无需训练辅助actor的方法（对比Best-of-N、filtered SFT、IBRL、DSRL、DAWR）。

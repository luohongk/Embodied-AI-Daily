# PACE: Phase-Aware Chunk Execution for Robot Policies with Action Chunking

- arXiv: https://arxiv.org/abs/2606.00537v2
- arXiv ID: 2606.00537

---

🔍 **核心问题**：机器人策略中动作分块（action chunking）的执行步长（execution horizon）对任务成功率有显著影响，但最优步长因任务而异且非单调变化，固定步长不可靠。

🛠 **方法**：提出PACE（Phase-Aware Chunk Execution），一种无需训练或访问策略内部结构的测试时执行方法，通过从预测的动作分块中在线识别低速过渡点作为候选重规划边界，动态调整执行步长。

✨ **主要贡献**：在50个RoboTwin2.0仿真任务中，平均成功率从57.8%提升至64.2%；在双臂ALOHA和单臂Franka真实机器人实验中，平均任务得分从60.7提升至77.7，平均成功率从50.7%提升至70.4%。PACE能自适应不同操作阶段的执行步长，在过渡阶段缩短执行、在连贯运动阶段保持较长执行。

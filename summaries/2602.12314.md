# LatentAM: Real-Time, Large-Scale Latent Gaussian Attention Mapping via Online Dictionary Learning

- arXiv: https://arxiv.org/abs/2602.12314v2
- arXiv ID: 2602.12314

---

🔍 **核心问题**：现有3D高斯泼溅（3DGS）映射框架在构建大规模开放词汇机器人感知的潜在特征图时，依赖模型特定的解码器蒸馏高维视觉语言模型（VLM）嵌入，导致模型不通用且需要预训练，难以实时扩展到长轨迹和大场景。

🛠 **方法**：提出在线字典学习框架LatentAM，将每个高斯基元关联一个紧凑查询向量，通过可学习字典的注意力机制近似VLM嵌入；字典从流式观测中高效初始化，并在信任域正则化下在线优化；同时采用基于体素哈希的地图管理策略，将优化限制在GPU上的活跃局部地图，全局地图存储于CPU以控制内存。

✨ **主要贡献**：LatentAM是模型无关且免预训练的即插即用方案，可在测试时适配不同VLM；在公共基准和大型自定义数据集上，特征重建保真度显著优于现有方法，并达到近实时速度（12-35 FPS），代码已开源。

# EvoTS-Agent: A Self-Evolving LLM Agent for Financial Time Series Change Point Detection

- arXiv: https://arxiv.org/abs/2608.17933v1
- arXiv ID: 2608.17933

---

🔍 **核心问题**：金融时间序列具有非平稳性和异质性，单一无监督算法无法在不同资产和市场状态下稳定检测变点，传统方法依赖专家人工选择模型和调参，缺乏可扩展性。

🛠 **方法**：提出EvoTS-Agent，一个基于验证反馈的自进化LLM智能体。它先进行探索性数据分析初始化候选模型，再通过三个算子（Revision利用当前最优解、Alternative Strategy在停滞时探索新方向、Recombination融合高绩效轨迹证据）迭代进化实验流程，并由验证反馈引导搜索。

✨ **主要贡献**：在四个基准数据集上，EvoTS-Agent持续优于现有基于LLM的智能体，且在所有评估的后端LLM上均达到100%的执行成功率，实现了无需人工干预的自主变点检测流程自适应优化。

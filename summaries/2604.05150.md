# Compiled AI: Deterministic Code Generation for LLM-Based Workflow Automation

- arXiv: https://arxiv.org/abs/2604.05150v2
- arXiv ID: 2604.05150

---

🔍 **核心问题**：解决大语言模型（LLM）在医疗等高风险企业工作流中因运行时推理带来的不可预测性、高成本和安全风险，需在保证可靠性与可审计性的同时提升效率。

🛠 **方法**：提出“编译式AI”范式，在编译阶段用LLM生成受限的确定性代码工件（嵌入验证模板），后续执行不再调用模型；构建四阶段生成-验证流水线，并设计系统架构与评估框架。

✨ **主要贡献**：在函数调用（BFCL）上实现96%任务完成且零执行token，约17次交易后成本持平，1000次时token消耗降低57倍；在文档智能（DocILE）上，Code Factory变体在关键字段提取上与直接LLM持平（80.0%），行项识别准确率最高（80.4%）；安全测试中提示注入检测准确率96.7%，静态代码分析零误报。

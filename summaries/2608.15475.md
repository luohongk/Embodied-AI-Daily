# Bit-Flip Attacks on Vision-Language-Action Models: Action-Decoding Architecture Shapes the Vulnerability

- arXiv: https://arxiv.org/abs/2608.15475v2
- arXiv ID: 2608.15475

---

🔍 **核心问题**：量化视觉-语言-动作（VLA）模型在部署时面临权重位翻转攻击（如Rowhammer）的安全威胁，本文首次系统研究此类攻击对不同动作解码架构的脆弱性差异。

🛠 **方法**：提出基于梯度选择的位翻转攻击方法，并设计固定方向流形逃逸损失函数以降低攻击预算；在四种模型变体（涵盖三种动作头）上评估攻击效果，并测试权重保护策略。

✨ **主要贡献**：发现少量梯度选定位翻转即可使闭环成功率降至0%，而随机翻转几乎无害；攻击预算高度依赖动作头类型（直接回归/令牌策略仅需1-5次翻转，流匹配需100-300次）；所提损失函数将π₀的攻击预算从~1000降至~100次翻转；保护少量关键权重（3.1%-5.3%）可显著提升鲁棒性；真实机器人实验验证了攻击有效性（0/20成功 vs 干净14/20）。

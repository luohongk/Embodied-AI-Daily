# InjecMEM: Memory Injection Attack on LLM Agent Memory Systems

- arXiv: https://arxiv.org/abs/2608.23471v1
- arXiv ID: 2608.23471

---

🔍 **核心问题**：LLM智能体的记忆系统可能引入新的安全漏洞，攻击者能否通过单次交互操纵后续生成结果。

🛠 **方法**：提出InjecMEM攻击范式，构造包含高召回主题锚点和对抗命令的注入文本，通过基于梯度的坐标搜索优化命令，使其在多种检索器和上下文条件下保持有效性。

✨ **主要贡献**：首次系统研究记忆系统注入攻击，证明单次交互即可定向劫持相关查询输出，且不影响无关查询，并提供了跨模型可迁移的攻击框架，强调记忆系统加固的必要性。

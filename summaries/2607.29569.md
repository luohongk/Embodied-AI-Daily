# Safe Vision Language Action Models via Barrier Enhanced Flow Matching

- arXiv: https://arxiv.org/abs/2607.29569v1
- arXiv ID: 2607.29569

---

🔍 **核心问题**：现有视觉-语言-动作（VLA）模型在生成机器人控制轨迹时缺乏形式化的安全保证，而外部安全过滤器可能破坏模型语义或增加计算负担。

🛠 **方法**：提出模块化推理框架，将Flow Matching生成模型与控制屏障函数（CBF）结合，在去噪过程中直接嵌入平滑的Log-Sum-Exponential聚合屏障，对整段动作块施加安全约束，无需额外数据集或重训练。

✨ **主要贡献**：证明了生成分布与目标分布间的2-Wasserstein距离有界；在两种机器人操作平台和2D导航基准上验证，该方法在不降低任务成功率的前提下实现可靠安全，且计算开销极小。

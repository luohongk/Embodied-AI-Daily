# Langevin dynamics along the zero set of real-analytic potentials

- arXiv: https://arxiv.org/abs/2608.09840v1
- arXiv ID: 2608.09840

---

🔍 **核心问题**：研究大参数β下，Langevin扩散在实解析势能函数零集上的极限动力学行为，并解释过参数化统计模型中随机梯度方法偏向奇异解（泛化性能好）的机制。

🛠 **方法**：将势能函数的零集按局部学习系数及其重数划分为不同维数的分层（strata），证明Langevin扩散对应的Dirichlet形式在特定意义下收敛到分层上的Dirichlet形式层级，从而推导出零集上的候选极限演化过程。

✨ **主要贡献**：首次严格推导了Langevin动力学在实解析势能零集上的极限演化，揭示该演化强烈偏向于更高维（更奇异）的分层，为Watanabe奇异学习理论中“奇异解泛化更好”的现象提供了动力学层面的理论解释。

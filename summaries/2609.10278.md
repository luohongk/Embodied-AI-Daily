# FreqFLD: Towards All-in-One Facial Landmark Detection via Frequency Modulation

- arXiv: https://arxiv.org/abs/2609.10278v1
- arXiv ID: 2609.10278

---

🔍 **核心问题**：现有面部关键点检测方法多基于空间域处理和数据集特定训练范式，忽略了该任务固有的几何驱动特性和对频率变化的敏感性，导致复杂场景下跨数据集泛化能力受限，难以构建统一（All-in-One）的检测模型。

🛠 **方法**：提出 FreqFLD 频率调制框架，包含三个核心组件——频率调制模块（FreqMoM）通过解耦和调制高低频分量显式引入频率先验；频率调制混合专家（FreqMoE）基于频率先验自适应选择专家以建模异构关键点模式；频率一致性路由损失（FreqCR）约束专家路由分配，促进多样化场景下的均衡专家利用。

✨ **主要贡献**：首次从频率调制视角实现 All-in-One 面部关键点检测，通过频率先验引导的专家混合与一致性路由机制，兼顾全局面部结构与局部关键点细节的平衡建模，在多个主流数据集上取得可比性能，并开源了代码。

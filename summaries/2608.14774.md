# p-Spin Glass Network Efficient Single-Batch Continual Learning

- arXiv: https://arxiv.org/abs/2608.14774v1
- arXiv ID: 2608.14774

---

🔍 **核心问题**：现代序列模型依赖大内存和大批量随机优化，限制了样本效率和持续学习能力。

🛠 **方法**：提出p-Spin Glass Network架构，通过原生三元量化压缩参数，并利用精确隐式梯度将激活内存严格限制为O(B·T·D)，同时支持单批次（微批次大小为1）的稳定训练。

✨ **主要贡献**：该网络在内存效率上压缩参数8倍，样本效率上仅用1/8的训练序列即可匹配Transformer基线的渐近性能，实现单批次稳定且单调收敛，并验证了该方法对离散子词和原始字节流等不同模态的时序信用分配均有效，为持续学习和边缘AI奠定基础。

# Adaptive-WAM: Quality-Guided Early-Exit Planning from Intermediate Video-Diffusion Features

- arXiv: https://arxiv.org/abs/2608.06008v1
- arXiv ID: 2608.06008

---

🔍 **核心问题**：大型视频扩散模型为自动驾驶提供丰富时空先验，但现有世界-动作模型在部署时仍需迭代生成未来视频，计算成本高昂。本文探讨执行视频扩散模型多少计算量即可做出可靠驾驶决策。

🛠 **方法**：提出Adaptive-WAM，基于Wan2.2-5B骨干的多出口规划器。在选定DiT块上附加轨迹扩散头，用轻量级轨迹质量评分器动态决定是否提前退出推理；若当前轨迹满足质量阈值则终止，否则从缓存隐藏状态继续到更深出口，避免视频合成所需的迭代去噪和VAE解码。

✨ **主要贡献**：在NAVSIM上自适应单轨迹规划器达90.8 PDMS，固定出口变体以64个提案达92.6 PDMS；NAVSIM v2上获89.9 EPDMS，为对比的前视视频世界模型规划器中最佳。无需目标域微调即可迁移至nuScenes（L2误差0.88m，碰撞率0.08%）。A100上自适应路由将延迟降至170ms，比固定全深度规划器低47%。

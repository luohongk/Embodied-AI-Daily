# LightSplat: Real-Time High-Fidelity 3D Gaussian SLAM with Loop Closure

- arXiv: https://arxiv.org/abs/2609.07274v1
- arXiv ID: 2609.07274

---

🔍 **核心问题**：现有基于3D高斯泼溅（3DGS）的SLAM系统在实时运行性能和地图适应性上不足，难以满足实际部署需求。

🛠 **方法**：提出LightSplat，一种混合表示的RGB-D SLAM框架，结合局部稀疏特征进行快速鲁棒跟踪，并通过双线程后端逐步构建稠密高斯子地图；同时利用特征加速的3DGS配准实现在线回环检测，并通过位姿图优化提升全局一致性。

✨ **主要贡献**：实现高质量3D高斯地图的在线重建，在多个数据集和真实机器人平台上达到接近最先进的重建质量，能适应实际相机运动，平均帧率保持8 FPS，为高保真3DGS在真实环境中的部署提供了高效稳健的基础。

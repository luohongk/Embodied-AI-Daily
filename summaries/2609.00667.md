# From Saliency to Discriminability: Rank-Preserving Visual Token Pruning for VLM Rerankers

- arXiv: https://arxiv.org/abs/2609.00667v1
- arXiv ID: 2609.00667

---

🔍 **核心问题**：视觉语言模型（VLM）作为列表式重排序器时需处理大量视觉token，现有剪枝方法依赖注意力显著性，但显著性常与排序贡献不一致，导致剪枝效果不佳。

🛠 **方法**：提出RaDiCal框架，利用归一化注意力熵判断显著性何时可信（Pearson r=0.87），将其与无注意力的排序判别先验融合，并从同一信任图谱中选择剪枝层，全程无需训练。

✨ **主要贡献**：在三个检索基准和多种VLM架构上，RaDiCal在20% token预算下匹配或超越Dense MRR@10（Flickr30K、MSCOCO），在FashionIQ上排名第一；10%保留率时性能损失仅1.2个百分点，同时减少39–45% FLOPs并实现1.28–1.45倍实测加速。

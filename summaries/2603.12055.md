# Continual Learning with Vision-Language Models via Semantic-Geometry Preservation

- arXiv: https://arxiv.org/abs/2603.12055v3
- arXiv ID: 2603.12055

---

🔍 **核心问题**：预训练视觉-语言模型（VLM）在持续学习中容易发生灾难性遗忘，且现有方法未显式保留跨模态语义几何结构，导致新任务监督引发几何扭曲。

🛠 **方法**：提出SeGP-CL框架，包含三部分：用双目标投影梯度下降（DPGD）构造对抗锚点以探测易漂移区域；通过锚点引导的跨模态几何蒸馏（ACGD）保持结构；用轻量文本语义几何正则化（TSGR）稳定文本参考系，并采用双路径推理融合跨模态与视觉线索。

✨ **主要贡献**：在五个持续学习基准上达到最先进性能，显著提升稳定性与前向迁移，同时更好地保留VLM的语义几何结构，代码已开源。

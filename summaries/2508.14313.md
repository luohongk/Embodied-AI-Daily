# AIRL-S: Unifying Reinforcement Learning and Search-Based Test-Time Scaling via Adversarial Inverse Reinforcement Learning

- arXiv: https://arxiv.org/abs/2508.14313v4
- arXiv ID: 2508.14313

---

🔍 **核心问题**：大语言模型在测试时扩展中，基于结果奖励的强化学习训练不稳定且样本效率低，而静态过程奖励模型依赖昂贵的人工标注且易受分布偏移导致的奖励攻击。

🛠 **方法**：提出AIRL-S框架，将对抗逆强化学习与组相对策略优化（GRPO）结合，从参考轨迹中直接推断稠密的逐步奖励模型，无需过程标签，并同时用作训练信号和搜索验证器。

✨ **主要贡献**：在数学、科学和代码生成的8个基准上，策略模型平均性能较基础模型提升9%，达到GPT-4o水平；并分析了AIRL与GRPO目标的互补性及学习到的PRM在生成器和搜索算法间的迁移性，建立了稳健且低成本的测试时计算扩展方法。

# Finding Vulnerabilities via LLM-Augmented Semantics-Aware Type-Checking

- arXiv: https://arxiv.org/abs/2608.14533v1
- arXiv ID: 2608.14533

---

🔍 **核心问题**：传统静态分析漏洞检测依赖专家手工编码的语法规则，难以捕捉代码深层语义（如变量和函数名的含义），在复杂软件系统中建模漏洞愈发困难。

🛠 **方法**：提出SETYPE语义感知类型系统，直接从源代码中基于符号和表达式的自然语言含义推导类型，类型推断和检查均由大语言模型（LLMs）执行，类型检查失败即视为潜在漏洞。

✨ **主要贡献**：原型工具PYSETYPE在Python Web应用上实现87%检测精度和88%准确率，发现15个潜在零日漏洞，其中9个获开发者确认，验证了语义感知方法在漏洞检测中的有效性。

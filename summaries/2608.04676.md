# SurgNarrator: A Generative Retrieval Framework for Surgical Video Understanding

- arXiv: https://arxiv.org/abs/2608.04676v1
- arXiv ID: 2608.04676

---

🔍 **核心问题**：手术视频理解需要在低延迟下实现复杂场景的语义识别，但现有方法难以兼顾推理能力与实时性，且手术场景中视觉相似但语义不同的事件增加了检索难度。

🛠 **方法**：提出SurgNarrator框架，构建手术专属词汇表定义临床语义检索空间，基于Qwen3-VL-Embedding-8B学习带时间感知的判别性表示，并在推理时采用层级化、过程感知的检索策略缩小搜索范围。

✨ **主要贡献**：在12个零样本基准上取得一致性能提升，相比生成式基线将输出阶段延迟降低两个数量级以上，实现了手术视频理解中速度与准确性的有效平衡。

# Learning What to Remember: Test-Time Training via Context Distillation

- arXiv: https://arxiv.org/abs/2608.01672v1
- arXiv ID: 2608.01672

---

🔍 **核心问题**：现有长上下文建模方法（如测试时训练TTT）只关注重建或在线适应目标，未考虑保留信息对未来预测的效用，导致记忆容量分配不优。

🛠 **方法**：提出测试时上下文蒸馏（TTCD）框架，用长窗口教师模型监督短窗口学生模型的快速权重，通过隐藏状态差异提供密集自监督信号，指导模型记忆对未来token预测关键的信息；并实现原位变体IP-TTCD，直接复用现有MLP参数作为快速权重。

✨ **主要贡献**：IP-TTCD在从头训练的长上下文语言建模任务上持续优于DeltaNet、Gated DeltaNet、滑动窗口注意力和TTT；同时支持预训练Transformer通过轻量架构增强在推理时持续适应，获得长上下文能力，为架构级持续学习迈出一步。

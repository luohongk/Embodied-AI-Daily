# MemLens: A Value-Aware Memory Management System with Interactive Analytics for LLM-based Agents

- arXiv: https://arxiv.org/abs/2607.25992v1
- arXiv ID: 2607.25992

---

🔍 **核心问题**：现有LLM智能体的记忆系统采用粗粒度、无价值感知的管理方式，导致冗余和低影响记录长期堆积，影响推理效率与个性化响应。

🛠 **方法**：提出MemLens系统，将记忆记录作为一等数据对象，通过Shapley式价值评估、价值感知存储和记忆辅助响应，并集成交互式分析仪表盘，支持记忆生命周期可视化与策略对比。

✨ **主要贡献**：实现了高效、可解释且个性化的长期记忆管理，通过端到端分析工具提升响应质量、降低检索延迟与令牌消耗，为LLM智能体提供价值驱动的记忆优化方案。

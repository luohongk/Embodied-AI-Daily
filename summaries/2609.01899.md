# TAPVid-MV: A Benchmark for Tracking Any Point in 3D Across Multiple Views

- arXiv: https://arxiv.org/abs/2609.01899v1
- arXiv ID: 2609.01899

---

🔍 **核心问题**：现有点跟踪基准仅针对单目视频或静态多相机系统，缺乏在相机运动下跨多个同步视图进行长期3D点跟踪的评测基准。

🛠 **方法**：构建TAPVid-MV基准，包含284个序列、1,142个标定相机流及109,769条点轨迹，覆盖室内外、机器人、驾驶等7个子集，利用传感器深度、LiDAR、SLAM、SfM、人体/物体网格及仿真获取轨迹，并全部经人工视觉验证。

✨ **主要贡献**：首个多视图3D点跟踪基准；评测30余种基线发现现有方法均未解决该任务，且多视图跟踪器未稳定优于单目方法；通过联合评估重建与跟踪，揭示几何恢复是3D点跟踪的主要瓶颈；发布注释支持2D/3D跟踪、轨迹预测及4D重建。

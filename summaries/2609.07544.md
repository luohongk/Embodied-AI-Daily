# Anti-Gravity Walking by a Flying Humanoid Robot via Thrust-Rate Input Whole-Body Model Predictive Control

- arXiv: https://arxiv.org/abs/2609.07544v1
- arXiv ID: 2609.07544

---

🔍 **核心问题**：飞行人形机器人在天花板等反重力环境中行走时，接触切换引起的动态结构突变会导致推力尖峰和控制不稳定。

🛠 **方法**：提出一种以推力变化率（thrust-rate）为控制输入的全身模型预测控制（MPC）框架，并引入足底法向接触力下界约束，在双支撑相平滑过渡该约束以保证自然支撑力。

✨ **主要贡献**：首次实现飞行人形机器人在反重力环境下的多接触全身MPC行走，并通过仿真和硬件实验验证；该方法保证推力连续性、保持优化问题稀疏结构以支持实时计算。

# Training-Free Action Correction for VLA Model Failures via Language Feedback

- arXiv: https://arxiv.org/abs/2608.29967v1
- arXiv ID: 2608.29967

---

🔍 **核心问题**：视觉-语言-动作（VLA）模型在部署时会出现系统性失败，本文研究这些失败能否在不重新训练的情况下通过语言反馈进行修正。

🛠 **方法**：提出CorrectVLA框架，将任务级自然语言修正转化为附加的动作幅度调整，不修改策略权重；人类提供一次统一修正，应用于所有rollout，无需逐次干预。

✨ **主要贡献**：在仿真和真实机器人实验中验证了该方法能恢复执行错位类失败（策略目标正确但动作幅度失准），并泛化到分布外任务；同时通过LIBERO-90失败模式分类，明确了可修正与不可修正的边界——当策略具备战略正确性时可修正，而语义理解根本缺失时则无效。

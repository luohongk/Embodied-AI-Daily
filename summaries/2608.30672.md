# HiRS-Agent: A Hierarchical Multi-Agent System for Reliable Long-Horizon Remote Sensing Task Solving

- arXiv: https://arxiv.org/abs/2608.30672v1
- arXiv ID: 2608.30672

---

🔍 **核心问题**：现有遥感任务智能体采用集中式决策框架，难以处理多阶段、相互依赖的长时序任务，导致执行不稳定、工具使用错误和错误跨阶段传播。

🛠 **方法**：提出HiRS-Agent，采用两层协作架构——Manager Layer负责动态路由、步骤验证、重规划和终止控制，Specialist Layer按遥感工作流组织领域工具并执行子任务推理与工具调用；结合两阶段监督微调和验证引导的分层强化学习优化协作与工具使用策略。

✨ **主要贡献**：在Earth-Agent Benchmark和ThinkGeo上显著提升长时序工具使用能力和最终任务正确率，验证了结构化多智能体协作对可靠遥感智能体的有效性，代码已开源。

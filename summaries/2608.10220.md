# Whole-Body Planning for Humanoids Navigating Confined Spaces via Self-Collision Avoidance References

- arXiv: https://arxiv.org/abs/2608.10220v1
- arXiv ID: 2608.10220

---

🔍 **核心问题**：人形机器人在高度受限环境中导航时，需同时避开密集环境障碍和复杂自碰撞约束，而传统轨迹优化器在狭窄空间内容易陷入局部最优，难以生成可行轨迹。

🛠 **方法**：提出三阶段全身规划框架，直接在运动学可达的刚体体积上进行路径规划，将可微碰撞避免与可达性约束结合，生成体积感知的引导轨迹，并用于训练残差强化学习策略以实现鲁棒在线执行。

✨ **主要贡献**：在Unitree G1人形机器人上，于三个超过NIST应急响应标准的测试场景中实现受限空间比（C_r<1.5）下的可行轨迹生成（12-18秒任务），优于标准基线方法；学习策略在物理仿真中通过广泛域随机化成功跟踪这些规划。

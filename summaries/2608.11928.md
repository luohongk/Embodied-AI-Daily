# Seed2GS: Camera-Free, Training-Free Object Extraction from 3D Gaussian Scenes via a Single Reference-View Grounding

- arXiv: https://arxiv.org/abs/2608.11928v1
- arXiv ID: 2608.11928

---

🔍 **核心问题**：从预构建的3D高斯泼溅（3DGS）场景中提取目标物体，现有方法要么需要逐场景训练（耗时数十分钟），要么依赖原始重建相机（预构建资产可能缺失），且精度有限。

🛠 **方法**：提出Seed2GS，将目标身份识别与3D覆盖分离。先用QD-SAM3从多个开放词汇候选掩码中选出可靠参考掩码，固定身份；再通过种子提升和可见性自适应虚拟轨道从新视角暴露物体，用跟踪传播种子而无需重复检测；最后仅用这些掩码监督每个高斯的一个临时前景logit，场景保持冻结。

✨ **主要贡献**：在无需原始相机和场景特定训练的情况下，达到最高报告精度——LERF-MASK上92.1% mIoU（比最强场景训练基线高3.7点，比最接近的无相机基线高7.6点），计算延迟仅9.3秒；3D-OVS上达95.7% mIoU。固定参考视图时仍保持91.1% mIoU，且用真实掩码替换预测种子仅提升0.72点，证明方法鲁棒性。

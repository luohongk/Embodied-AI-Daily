# EngiAI: Capability-Based Evaluation of Tool-Connected LLM Agents for Engineering Design

- arXiv: https://arxiv.org/abs/2605.19743v3
- arXiv ID: 2605.19743

---

🔍 **核心问题**：工程智能体系统日益增多，但任务、工具和成功标准各异，导致演示难以比较、失败难以诊断，缺乏统一的评估框架。

🛠 **方法**：提出基于能力的评估框架EngiAI，分别评估工作流执行、检索辅助参数选择、高性能计算编排和训练代码编写，使用执行轨迹和工程产物作为指标，并基于LangGraph实现，在Beams2D和Photonics2D问题上测试四种LLM后端。

✨ **主要贡献**：实验显示专有模型在工作流任务上完成率（96-97%）远高于开源模型（55-78%），检索能提升参数选择，且不同能力表现差异显著（如HPC编排中Gemini-3-Flash全通过而GPT-5-mini仅50-70%）。框架支持按能力分别评分，而非仅依赖端到端演示，有助于识别失败机制并结构化比较模型、架构和工具接口。

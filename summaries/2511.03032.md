# Leveraging Discrete Function Decomposability for Scientific Design

- arXiv: https://arxiv.org/abs/2511.03032v3
- arXiv ID: 2511.03032

---

🔍 **核心问题**：在科学设计中，针对离散对象（如蛋白质序列、电路组件）的属性优化，现有分布优化算法难以有效处理组合爆炸的搜索空间，且无法利用属性预测器中的可分解结构。

🛠 **方法**：提出一种新的分布优化算法——分解感知分布优化（DADO），通过结树（junction tree）定义设计变量间的可分解性，并采用软因子化的“搜索分布”（即学习生成模型）结合图消息传递机制，协调优化过程。

✨ **主要贡献**：首次将离散函数可分解性引入分布优化，显著提升搜索效率；DADO能自动利用属性预测器的因子化结构，在蛋白质设计等科学任务中实现更高效的优化，并具备理论上的可扩展性。

# ACE-Data-0: Human-Centric Ambient Capture as Embodied Data Engine

- arXiv: https://arxiv.org/abs/2607.28625v1
- arXiv ID: 2607.28625

---

🔍 **核心问题**：具身智能面临数据瓶颈，现有数据集在视角、模态或空间尺度上割裂，无法完整捕捉人类在真实环境中感知-动作闭环的协同演化过程。

🛠 **方法**：提出环境捕获引擎（ACE），将真实家庭环境改造为空间校准、时间同步的录制工作室，在桌面尺度（手-物操作）和房间尺度（全身运动与交互）同时记录第一视角与多视角视频、全身与手部运动、物体几何与6-DoF轨迹、音频及触觉信号，形成统一多感官数据流。

✨ **主要贡献**：构建ACE-Data-0数据集，含150小时、1700万帧视频、200个任务类别、50名参与者、75000个交互片段，覆盖原子操作到长时家庭活动链；提出从信号到场景组件再到交互的分层基准，揭示现有SOTA方法在接触、遮挡、自运动和长时域上的显著不足，为模仿学习、世界模型和VLA系统提供可扩展的同步演示基础。

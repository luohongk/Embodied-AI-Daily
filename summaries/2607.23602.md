# Action from Adjacent Set in Physical Space Outperforms the Best Prediction in World Models

- arXiv: https://arxiv.org/abs/2607.23602v2
- arXiv ID: 2607.23602

---

🔍 **核心问题**：在基于采样的潜在世界模型控制中，即使终端成本完美反映真实任务目标，残差预测误差也可能导致不可行动作序列获得异常低成本，且更大的候选池会增加这种“提议过度生成”风险，降低选择可行性。

🛠 **方法**：提出相邻集动作重建（ASAR）方法，在低成本候选中基于标准化早期动作前缀识别相邻集，通过局部加权聚合并锚定最小成本序列来重建完整动作序列，替代直接选择最小成本序列。

✨ **主要贡献**：实验表明，在Cube任务中，提议预算从72增至288时，最小潜在成本选择的可行性从0.375降至0.062；而Kernel ASAR在75个查询的Carry and Release任务中，相比匹配选择，在72/144/288提议下分别将事件完成成功率提升28.0/24.0/18.7个百分点（潜在成本）和18.7/20.0/17.3个百分点（轨迹可达性成本），并提供了有限提议池选择风险的理论分析。

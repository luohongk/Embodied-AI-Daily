# uScenes: A Multimodal RGB and 3D Sonar Dataset for Underwater Robot Perception

- arXiv: https://arxiv.org/abs/2608.27795v1
- arXiv ID: 2608.27795

---

🔍 **核心问题**：水下机器人感知中，光学相机在光照差和散射条件下不可靠，而2D前视声呐无法解析仰角，导致难以进行3D场景理解和精确目标检测。

🛠 **方法**：构建了一个多模态水下数据集uScenes，包含同步的3D多波束声呐点云和RGB图像，覆盖110个场景和95,834次同步观测，总计277.6分钟数据。

✨ **主要贡献**：提供了首个结合3D声呐点云与RGB图像的水下多模态数据集，为水下传感器融合、跨模态表示学习和3D场景理解奠定基础，并公开了代码和数据。

# ClawGym II: Exploring Black-Box RL on Agent Harness

- arXiv: https://arxiv.org/abs/2608.16798v1
- arXiv ID: 2608.16798

---

🔍 **核心问题**：现有智能体框架（agent harness）在长时程任务中表现优异，但通过复杂框架进行强化学习训练仍未被充分探索，面临训练不稳定、扩展性差等挑战。

🛠 **方法**：提出统一的黑盒强化学习框架，包括沙箱隔离的并发执行基础设施、在模型边界捕获调用的服务代理、将调用重构为前缀树以适配PPO和GRPO优化，并引入混合框架联合训练与训练-推理一致性保障。

✨ **主要贡献**：在ClawGym-Bench上通过OpenClaw和Claude Code分别提升Pass@1达9.98和14.81点，且在200-400步优化中保持稳定；在JobBench和OfficeQA等更难任务上也有持续增益，实现了跨异构执行系统的统一、稳定、可扩展的智能体优化。

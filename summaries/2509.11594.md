# GBPP: Grasp-Aware Base Placement Prediction for Robots via Two-Stage Learning

- arXiv: https://arxiv.org/abs/2509.11594v3
- arXiv ID: 2509.11594

---

🔍 **核心问题**：解决机器人抓取时如何快速选择最佳基座位置，避免传统任务与运动规划的高计算成本。

🛠 **方法**：提出两阶段学习框架——先用距离-可见性规则自动标注大量低成本数据，再用少量高保真仿真数据微调模型；采用PointNet++点云编码器与MLP对候选基座位姿进行评分。

✨ **主要贡献**：实现单张RGB-D图像驱动的实时基座位置预测，在仿真和真实移动机械臂上优于基于距离或几何的基线方法，且具备鲁棒退化能力，提供了一种数据高效、几何感知的基座放置实用方案。

# Streaming Multi-Agent Autoregressive Diffusion Model with World State Registers

- arXiv: https://arxiv.org/abs/2607.21594v1
- arXiv ID: 2607.21594

---

🔍 **核心问题**：现有自回归视频扩散模型在多智能体交互场景中难以维护跨智能体共享且随视角演化的世界状态，导致生成内容逻辑不一致。

🛠 **方法**：提出WorldWeaver（W²）流式多智能体视频扩散模型，通过引入跨智能体世界状态寄存器（可学习令牌）存储共享信息并动态更新，结合混合Transformer架构分离世界状态与视觉帧建模，并利用智能体状态、全局视角（如鸟瞰图）和场景文本作为监督信号。

✨ **主要贡献**：首次在双智能体Minecraft视频生成任务中验证显式世界状态建模可显著提升逻辑一致性与生成质量，并设计了可扩展的流式多视角生成框架。

# UniNav: A Unified World-Action Diffusion Model for Visual Navigation

- arXiv: https://arxiv.org/abs/2608.03244v1
- arXiv ID: 2608.03244

---

🔍 **核心问题**：图像目标视觉导航中，现有策略缺乏视觉预见能力，而世界模型虽能预测未来观测但需昂贵的规划回滚，难以兼顾预测与高效动作生成。

🛠 **方法**：提出UniNav，一个统一的世界-动作扩散模型，通过单一扩散过程在共享Transformer中联合去噪视觉token和轨迹token，并引入几何感知相机token增强空间定位，同时支持轨迹标注数据和纯视频数据训练。

✨ **主要贡献**：UniNav在多个导航基准上ATE指标全面超越最强基线；其变体UniNav-Fast通过单步推理实现0.1s低延迟且精度损失小，并开源代码。

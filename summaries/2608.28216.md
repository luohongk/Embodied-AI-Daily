# WALDO: One-Shot Exemplar-Conditioned Object Detection in Cluttered Scenes

- arXiv: https://arxiv.org/abs/2608.28216v1
- arXiv ID: 2608.28216

---

🔍 **核心问题**：如何在杂乱场景中仅凭单张参考图像和简短描述定位特定目标实例，并判断该实例是否存在，且无需依赖昂贵的大型视觉-语言模型。

🛠 **方法**：提出WALDO，一个仅含340万可训练参数的检测头，读取冻结的V-JEPA 2.1特征，联合预测目标定位与存在性；通过从实例标注合成训练片段（挖掘正例、构造排除目标但保留同类干扰物的负例），并报告了消除捷径（如裁剪尺寸泄露标签）的阴性对照。

✨ **主要贡献**：在35个杂乱场景上，WALDO的catalogue AP@50达0.461，优于Grounding DINO基线的0.306；替换骨干为DINOv3后性能显著下降，证明世界模型预训练目标优于输入分辨率；但实例级Success@1仅0.190（与类别随机基线持平），表明世界模型特征擅长定位与缺失检测，但不擅长实例身份区分。

# Physics-Constrained Deep Learning Model for Contactless Blood Pressure Monitoring from Triaxial Bodyseismography

- arXiv: https://arxiv.org/abs/2608.23562v1
- arXiv ID: 2608.23562

---

🔍 **核心问题**：传统BCG信号易受身体-床交互变化影响，导致血压监测模型泛化性和鲁棒性不足。

🛠 **方法**：提出Phy-BP框架，基于三轴体震信号（BSG），结合自适应质量控制算法筛选高质量信号段，并建立物理模型嵌入深度学习，约束三轴信号的内在耦合关系。

✨ **主要贡献**：在21名受试者162小时医院数据上验证，Phy-BP能动态过滤低质量测量，并通过跨轴物理一致性约束提升血压监测准确性，尤其在训练样本有限时表现突出。

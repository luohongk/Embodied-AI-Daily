# NanoBench: A Multi-Task Benchmark Dataset for Nano-Quadrotor System Identification, Control, and State Estimation

- arXiv: https://arxiv.org/abs/2603.09908v2
- arXiv ID: 2603.09908

---

🔍 **核心问题**：现有空中机器人基准数据集仅针对百克至千克级飞行器且只提供高层状态数据，无法支撑纳米级四旋翼（存在低雷诺数气动、空心杯电机非线性、算力严重受限等特性）的系统辨识、控制与状态估计研究。

🛠 **方法**：在商用 Crazyflie 2.1 纳米四旋翼（起飞重量27克）上，于 Vicon 动捕场地采集172段飞行记录，涵盖多频激励、三种速度下的几何轨迹跟踪和长时电池耗尽悬停；每段记录以100 Hz同步提供Vicon真值、原始IMU、机载EKF估计、PID控制器内部量及电机PWM指令，并以10 Hz提供电池遥测，通过陀螺仪相关在1 ms搜索网格上交叉对齐。

✨ **主要贡献**：首次公开在商用纳米级飞行平台上联合提供执行器指令、控制器内部量与估计器输出，并配以毫米级精度真值；同时定义了标准化评估协议、训练/测试划分及三个任务（非线性系统辨识、闭环控制器基准测试、机载状态估计评估）的开源基线。

# SIREN: Towards End-to-End Extreme-Weather Early Warning with Experience-Grounded LLM Agents

- arXiv: https://arxiv.org/abs/2607.24588v1
- arXiv ID: 2607.24588

---

🔍 **核心问题**：现有极端天气预警依赖专家流程，成本高、难以规模化，且现有LLM代理研究仅关注孤立科学任务，缺乏端到端预警链的自动化能力。

🛠 **方法**：提出SIREN框架，包含SIREN-Bench基准（600个问答实例覆盖19项任务及端到端预警链）和基于经验驱动的代理系统，通过检索、技能蒸馏和预测建模利用历史案例，整合异构天气证据与工具。

✨ **主要贡献**：揭示了现有天气代理框架的能力差距，并证明SIREN在独立预警流程和端到端预警链上均显著优于基线方法，实现了自动化、可扩展的极端天气早期预警。

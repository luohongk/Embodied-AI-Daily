# DRAFE: Domain-Robust Asymmetric Fusion of Heterogeneous Detection Transformers for Cross-City Fine-Grained Traffic Object Detection

- arXiv: https://arxiv.org/abs/2608.16632v1
- arXiv ID: 2608.16632

---

🔍 **核心问题**：解决跨城市细粒度交通目标检测中，模型在域泛化（跨城市场景）与细粒度车辆识别之间难以兼顾的问题。

🛠 **方法**：提出DRAFE框架，集成独立训练的LW-DETR和RF-DETR两个异构检测器。采用两阶段训练策略：先在多样公开数据集上通过伪标签扩展和人工标注精修预训练，再在目标数据集上微调；推理时结合锚点条件匹配、可靠性加权融合、一致性置信度重校准和互补假设恢复。

✨ **主要贡献**：构建了包含6,049张图像和203,619个标注的精选数据集；在AI City Challenge 2026 Track 6上取得0.4022 mAP，排名第6（共25队），比基线集成提升0.0553 mAP，验证了异构检测器融合对跨城市域泛化的有效性。

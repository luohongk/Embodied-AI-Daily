# Teaching is a Process: The TOSS Framework for Modeling Human Teaching Decisions in Human-Interactive Robot Learning

- arXiv: https://arxiv.org/abs/2608.21083v1
- arXiv ID: 2608.21083

---

🔍 **核心问题**：人类在教机器人学习时，其教学决策背后的内在逻辑是什么，以及如何使机器人更好地理解人类的教学意图。

🛠 **方法**：通过一项探索性自下而上的研究（N=34），让参与者观察两种不同的机器人强化学习场景，收集204条教学响应，并分析早期、中期和后期学习阶段的教学决策模式，最终提出TOSS框架。

✨ **主要贡献**：揭示了教学决策是由触发因素、目标、信号和策略组成的复杂网络，并提出了TOSS框架，将人机教学建模为机器人行为与人类教学动作之间的过程循环，为理解教学决策、模拟真实教学信号以及设计以人为中心的教学设置和新算法提供了理论基础和公开数据集。

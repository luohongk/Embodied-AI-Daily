# PointZero: 3D Point Track Completion for Learning Transferable 3D Dynamics

- arXiv: https://arxiv.org/abs/2609.19142v1
- arXiv ID: 2609.19142

---

🔍 **核心问题**：现有3D动力学世界模型依赖机器人动作标签训练，导致大量网络视频数据无法被利用，限制了模型的泛化能力。

🛠 **方法**：提出以3D点轨迹补全作为预训练目标——给定单帧RGB-D观测和稀疏部分3D轨迹，预测所有观测点的未来3D轨迹；构建了涵盖可变形、铰接和刚性物体的290万帧合成数据集，并训练了基于Transformer的PointZero模型。

✨ **主要贡献**：无需机器人动作标签即可学习丰富的3D动力学先验；在PGND 3D动力学基准上微调后超越基线，在6/7个仿真与真实机器人操作任务中达到或超越基线表现，并开源了数据集、模型权重和完整训练方案。

# OASIS: Occlusion-aware Single-image Hand Avatar Reconstruction via 3D Gaussian Splatting

- arXiv: https://arxiv.org/abs/2607.29633v1
- arXiv ID: 2607.29633

---

🔍 **核心问题**：单张图像下的3D手部化身重建面临严重自遮挡和复杂姿态变形，现有基于NeRF的方法计算昂贵且难以保留精细手部细节。

🛠 **方法**：提出OASIS框架，基于3D高斯泼溅（3DGS），通过几何对齐的视觉证据令牌和可见性条件点-图像注意力机制编码稀疏图像线索，并引入Feature-on-Mesh表示引导高斯变形，采用一次性适配方案从多身份数据学习共享先验再拟合目标图像。

✨ **主要贡献**：在挑战性姿态和真实场景下，OASIS在视觉保真度和效率上均优于现有基线，并展示出在文本生成化身和纹理编辑等下游任务中的强通用性。

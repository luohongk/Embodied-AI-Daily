# BenthicFlow: Generating Extensible Underwater Environments via Flow Matching

- arXiv: https://arxiv.org/abs/2608.23173v1
- arXiv ID: 2608.23173

---

🔍 **核心问题**：水下环境3D场景理解因高质量3D数据匮乏及地面训练模型难以泛化而面临挑战，现有生成方法需分块独立生成再拼接，且仅能展示单一调查点的异质景观。

🛠 **方法**：提出BenthicFlow，基于单一条件流匹配模型联合生成对齐的纹理和深度图，并采用MultiDiffusion启发的采样过程在生成轨迹中调和重叠窗口，无需独立拼接模型即可生成空间可扩展的RGBD马赛克，随后用表面对齐的高斯surfel将马赛克提升为显式3D底栖环境。

✨ **主要贡献**：首次实现无需拼接模型的统一框架，可生成跨地理调查点、保持站点特定外观且与目标分布高度一致的大规模连贯3D场景，代码和模型已开源。

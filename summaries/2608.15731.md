# Identifying Confusion Trends in Concept-based XAI for Multi-Label Classification

- arXiv: https://arxiv.org/abs/2608.15731v1
- arXiv ID: 2608.15731

---

🔍 **核心问题**：在医疗、自动驾驶等高风险领域，深度神经网络需具备可解释性，但现有概念可解释AI（CXAI）方法在多标签分类任务中的适用性和问题解决能力尚未充分评估。

🛠 **方法**：在MS-COCO数据集上选取20个标注最多的标签，训练VGG16和ResNet50模型，并应用CRP（概念相关传播）和CRAFT（概念递归激活分解）两种CXAI方法生成概念级解释，分析模型行为。

✨ **主要贡献**：发现CXAI能揭示DNN学习弱点、概念区分度越高则标签与概念混淆越少、环境概念暴露数据集偏差；证明CXAI有助于理解模型泛化能力并诊断数据偏差。

# In-Context VLA: Endowing Vision-Language-Action Models with Language via In-Context Post-Training and Agentic Tool Use

- arXiv: https://arxiv.org/abs/2608.05738v1
- arXiv ID: 2608.05738

---

🔍 **核心问题**：视觉-语言-动作（VLA）模型在机器人操作中普遍采用行为克隆训练，但直接注入自由形式的文本思维链（CoT）会降低底层控制性能，因为推理缺乏依据、延迟破坏闭环时序，且推理与动作令牌优化目标冲突，导致策略“叙述”而非“行动”。

🛠 **方法**：提出In-Context VLA框架，通过（i）上下文后训练——将感知证据作为结构化上下文注入，仅监督动作输出；（ii）智能体工具使用接口——策略主动查询开放词汇检测器、单目深度和视觉语言模型获取任务相关信息；数据引擎生成多样化、改写且基于证据的空间描述，使策略能理解未见过的语言。

✨ **主要贡献**：在RoboCasa-GR1、SimplerEnv、LIBERO仿真基准及8项真实机器人操作任务中，与匹配配置的CoT方法相比，该方法在性能和效率上均达到最先进（SOTA）结果，证明了“消费语言”而非“生成语言”对VLA更有效。

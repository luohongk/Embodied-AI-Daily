# Lightweight Machine Learning-Driven Monocular Sidewalk Path Extraction for Embedded Micromobility Navigation

- arXiv: https://arxiv.org/abs/2608.25178v1
- arXiv ID: 2608.25178

---

🔍 **核心问题**：在嵌入式微移动设备（如电动滑板车）上，如何在低功耗、地图稀疏的杂乱环境中，可靠且实时地从单目摄像头提取人行道路径。

🛠 **方法**：提出一个单目视觉管道，经过三次设计迭代（骨架图基线→距离变换走廊规划→轻量图像空间架构），采用半监督教师-学生框架（OneFormer Swin-L 生成伪标签训练 SegFormer-B0），并系统比较了五种路径规划方法在鸟瞰图（BEV）和图像空间中的表现。

✨ **主要贡献**：最终架构（图像空间中点规划为主、距离变换为备选、BEV仅用于可视化）在CPU上实现每帧<50 ms的端到端处理，分割IoU达0.946（11.7 ms/帧），路径规划速度比BEV方法快421倍，同时将时间不稳定性从1.46%降至0.33%，并揭示了单目BEV路径提取的脆弱性（99.3%帧无有效路径）。

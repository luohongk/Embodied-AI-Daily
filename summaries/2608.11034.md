# SCOUT: Symmetric Consensus Outlier Detection for Failure Localization in LLM Pre-Training

- arXiv: https://arxiv.org/abs/2608.11034v1
- arXiv ID: 2608.11034

---

🔍 **核心问题**：在大语言模型预训练中，同步机制会将单卡级别的停滞、降速和数值错误传播为整个任务的症状，导致故障根源难以定位；现有诊断手段（如进程内监控、事后日志、离线测试）无法在训练阻塞或终止后有效工作。

🛠 **方法**：提出SCOUT框架，基于“等价副本间严格多数共识”原则，通过对齐副本的进度、时间和数值证据，利用共识集合通信（C3）抽象识别与同伴不一致的秩；同时采用带外CPU观察器应对训练挂起，并通过原位回放复现慢节点和静默数据损坏（SDC），无需修改训练循环或框架源码。

✨ **主要贡献**：SCOUT统一了运行时故障定位流程，能实时识别协议偏差、验证检查点数值完整性以防SDC污染恢复，并兼容PyTorch、TorchTitan、Megatron-Core和DeepSpeed等主流框架，已开源。

# Query Rewriting for Complex Object Segmentation in 4D Gaussian Representations

- arXiv: https://arxiv.org/abs/2609.02664v1
- arXiv ID: 2609.02664

---

🔍 **核心问题**：4D高斯表示中的语言引导动态场景分割对冗长、叙事式查询高度敏感，导致时空定位和分割性能下降。

🛠 **方法**：提出一种无需训练的查询重写策略，将长描述性查询转化为简洁的关键词形式，逐步去除语言噪声并保留与目标对象相关的语义锚点。

✨ **主要贡献**：在HyperNeRF和Neu3D数据集上，将平均时间准确率从60.92%提升至92.21%，平均vIoU从20.08%提升至76.94%，且无需额外微调；消融实验表明短关键词查询能稳定视频特征相似性分布并更好对齐对象中心的高斯表示。

# AXIS: A Growable Community-Driven Data Engine for Scalable Robot Manipulation

- arXiv: https://arxiv.org/abs/2607.21588v1
- arXiv ID: 2607.21588

---

🔍 **核心问题**：现有机器人操作数据管道依赖专用硬件、固定任务或集中式运营，难以规模化扩展，导致策略学习缺乏多样性和高质量数据。

🛠 **方法**：提出AXIS数据引擎，支持浏览器远程操控以大规模收集演示，自动生成并验证新任务，通过成功检测、质量过滤、轨迹平滑及视觉/物理增强将社区数据转化为训练就绪格式，并采用任务快照与系统化留出协议评估策略。

✨ **主要贡献**：构建含207个任务和5万+轨迹的开放数据集；在统一评估套件下，基于AXIS持续预训练使π₀.₅成功率提升5.8%，优于RoboCasa365预训练模型37.3%，且随数据量增加呈现稳定扩展性，尤其在布局、传感器噪声和相机扰动场景下增益最大。

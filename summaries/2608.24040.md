# PinSieve: Production Selective VLM Serving and a Governed Memory Flywheel for Enterprise Content-Quality Triage

- arXiv: https://arxiv.org/abs/2608.24040v1
- arXiv ID: 2608.24040

---

🔍 **核心问题**：企业级AI代理在生产环境中需要可控、可观测且有状态，而非完全自主。本文针对大规模内容质量流水线中，轻量级上游模型无法解决的灰色地带样本，如何高效筛选并保持人工监管的问题。

🛠 **方法**：提出PinSieve系统，包含选择性VLM服务代理（仅处理灰色地带样本，输出标量路由分数并保留人工升级通道）、受控记忆飞轮（记录路由轨迹与审计采样）、数据整理代理（基于提议-验证循环，结合代表性、不确定性、时效性回放及护栏机制），以及推理审查代理（审计教师模型生成的推理并支持保留/修复/删除）。

✨ **主要贡献**：部署系统在灰色地带过滤非可操作项数量提升2.05倍，审查效率提高25.7%，运营成本降低16.2%，信号传递从次日变为当日；离线回放将平均FNR@50%从17.73%降至13.29%。该方案已迁移至多个内部信号，证明其跨任务可推广性。

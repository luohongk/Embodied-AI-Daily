# DSCH-Loss: A Dynamic Semantic Channel Objective for Deep Semantic Hashing

- arXiv: https://arxiv.org/abs/2607.24567v1
- arXiv ID: 2607.24567

---

🔍 **核心问题**：现有深度语义哈希方法中，基于固定宽度和汉明距离的语义通道损失函数会导致损失曲面不连续，增加优化难度。

🛠 **方法**：提出动态语义通道哈希（DSCH）损失函数，通过动态调整语义通道的大小和位置来避免损失曲面不连续性，并采用考虑平局的平均精度（tie-aware mAP）作为评估指标。

✨ **主要贡献**：在40项跨模态和模态内检索任务中，DSCH在35项上取得最优tie-aware mAP，相比次优方法提升高达1.75个百分点，且在不同模型架构和数据集上表现一致。

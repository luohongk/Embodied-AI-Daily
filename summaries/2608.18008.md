# Policy-Invariant Reward Shaping from LLM Feedback: A Framework for Hybrid RL Agents

- arXiv: https://arxiv.org/abs/2608.18008v1
- arXiv ID: 2608.18008

---

🔍 **核心问题**：现有将大语言模型（LLM）与强化学习结合的方法中，LLM生成的奖励信号缺乏理论保证，可能改变最优策略。

🛠 **方法**：将混合LLM规划器与RL控制器架构形式化为目标增强马尔可夫决策过程（Goal-Augmented MDP），并将LLM的逐状态进度分数作为有界势函数用于奖励塑形。

✨ **主要贡献**：证明当LLM分数作为势函数时，即使分数不准确，塑形项也能保持最优策略集不变，该保证强于通用LLM奖励方法；并在小型MDP上通过四种势配置（含对抗性放大20倍场景）验证了理论结果。

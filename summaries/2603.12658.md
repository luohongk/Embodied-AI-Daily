# Beyond Static Models: An Evolving Framework for Continual Learning in Large Language Models across Training Stages

- arXiv: https://arxiv.org/abs/2603.12658v2
- arXiv ID: 2603.12658

---

🔍 **核心问题**：解决大语言模型（LLMs）在静态预训练范式下无法动态适应新知识和顺序任务、且易发生灾难性遗忘的问题。

🛠 **方法**：提出一个围绕三个核心训练阶段（持续预训练、持续微调、持续对齐）的持续学习（CL）框架，并将方法细分为基于回放、正则化和架构三类，进一步按遗忘缓解机制进行子分类，同时比较传统CL方法在LLM中的适应性与改进。

✨ **主要贡献**：系统梳理了LLM持续学习的完整方法论，明确区分了LLM与机器学习在规模、参数效率和涌现能力上的差异，并总结了评估指标（如遗忘率、知识迁移效率）和新兴基准，最后指出知识无缝整合等关键开放问题与未来方向。

# StructureGS: Structure-aware Gaussian Splatting for Articulated Object Reconstruction

- arXiv: https://arxiv.org/abs/2607.26889v1
- arXiv ID: 2607.26889

---

🔍 **核心问题**：现有方法在重建具有多个可动部件的铰接物体时，难以解耦几何、外观与运动参数，导致部件分解模糊、边界不清晰及几何伪影。

🛠 **方法**：提出StructureGS框架，将结构感知引导融入3D高斯泼溅，通过部件有向包围盒施加空间连贯性与结构连接性约束，并设计结构感知损失函数注入显式结构约束。

✨ **主要贡献**：实现铰接物体重建的当前最优性能，生成部件几何清晰的高质量结果，有效解决了部件分解模糊与几何伪影问题。

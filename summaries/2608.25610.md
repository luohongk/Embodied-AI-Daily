# Advantage-Driven Explicit Memory for Social Navigation

- arXiv: https://arxiv.org/abs/2608.25610v1
- arXiv ID: 2608.25610

---

🔍 **核心问题**：传统社交导航策略将行为完全编码在神经网络参数中，导致对罕见高代价事件（如碰撞）的学习能力不足，且难以适应分布外（OOD）场景。

🛠 **方法**：提出一种带非参数显式记忆的导航智能体，利用RL优势信号索引关键历史步骤，并将显式记忆集成到循环PPO架构中，通过隐藏状态检索记忆以捕捉时空动态。

✨ **主要贡献**：显式记忆减轻了参数化策略的负担，支持部署时持续学习以提升OOD泛化能力；在仿真训练中结合真实数据部分缓解sim-to-real差距，实验证明对OOD社交行为具有鲁棒性。

# Reactive 3D Motion Planning for a Franka Arm via Star-World Workspace Reshaping

- arXiv: https://arxiv.org/abs/2607.25138v1
- arXiv ID: 2607.25138

---

🔍 **核心问题**：安全膨胀导致邻近障碍物重叠，破坏了基于调制的反应式规划器所需的“不相交障碍物”假设，影响三维机械臂的实时运动规划。

🛠 **方法**：采用Star-World工作空间重塑方法，将相交的膨胀障碍物聚类并替换为星形代理，结合基于动力系统的末端执行器控制器和零空间人工势场项，实现冗余机械臂的全身避障。

✨ **主要贡献**：在6个PyBullet场景中，重塑方法在5个场景中成功到达目标（基线为4个），解决了经典重叠墙壁案例，每次更新仅需0.68–8.70毫秒；但同时也增加了路径长度，在两种情况下产生近平衡态，并因过度合并而关闭了可通行通道。

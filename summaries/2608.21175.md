# SRL-MPC: Shape-Aware Reinforcement Learned Model Predictive Control

- arXiv: https://arxiv.org/abs/2608.21175v1
- arXiv ID: 2608.21175

---

🔍 **核心问题**：在异构人群和机器人编队中，实现安全且高效的形状感知导航，现有方法常因简化几何或假设同质机器人而难以应对密集场景。

🛠 **方法**：提出SRL-MPC，结合高阶控制屏障函数（HOCBF）与几何分离特征（GSFs）编码形状安全约束，并利用强化学习（RL）学习神经策略，实时调整MPC参数以适应周围人群几何。

✨ **主要贡献**：在保留MPC安全性与泛化能力的同时，引入RL的适应性与智能性；在随机人群和任意形状机器人编队实验中，显著优于基线方法，验证了有效性、可扩展性和鲁棒性。

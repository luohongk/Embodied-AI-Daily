# DynSSM: A Physics-Aware State-Space Memory Framework for Learning Vehicle Dynamics

- arXiv: https://arxiv.org/abs/2605.08489v2
- arXiv ID: 2605.08489

---

🔍 **核心问题**：高速自动驾驶赛车中，车辆动力学建模需兼顾精度与物理一致性，现有模型方法依赖简化假设，纯学习方法缺乏泛化与适应性。

🛠 **方法**：提出DynSSM框架，融合状态空间序列建模与循环编码器捕捉长短期动态，在物理约束范围内自适应调整轮胎与车辆参数，并引入残差校正补偿未建模动态。

✨ **主要贡献**：在仿真与真实Indy赛车上验证，相比SOTA，在未知赛道上的单步预测RMSE降低（纵向速度27.2%、横向速度73.9%、横摆角速度88.8%），闭环控制中单圈时间最多缩短13.2%，消融实验证实各组件对精度与鲁棒性的关键作用。

# Avatar: Toward Autonomous End-to-End Orchestration of Scientific Workflows using LLMs

- arXiv: https://arxiv.org/abs/2609.10509v1
- arXiv ID: 2609.10509

---

🔍 **核心问题**：科学工作流管理系统依赖固定的人工调优规则进行编排，LLM智能体虽有望实现更自主的编排，但在何处引入智能体推理、如何控制风险以及何时真正有效尚不明确。

🛠 **方法**：提出Avatar——一种基于actor的架构，包含编排器、执行器和溯源监控器三个角色，每个角色的决策策略可通过统一适配器验证的动作目录插拔切换（基于规则或LLM驱动），使传统与智能体控制在同一核心上运行，并在Academy框架上实现。

✨ **主要贡献**：规则模式能复现原生执行且单一核心可运行三种工作负载；LLM驱动的Avatar将计算浪费减少55%、GPU繁忙时间缩短40%，朝着能自主推理编排的工作流系统迈出一步。

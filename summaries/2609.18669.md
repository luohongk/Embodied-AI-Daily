# M$^3$P-R1: Reinforcement Learning for Large Language Model Guided Multi-Modal Motion Planning via MIP Code Generation

- arXiv: https://arxiv.org/abs/2609.18669v1
- arXiv ID: 2609.18669

---

🔍 **核心问题**：多模态运动规划（M³P）需同时处理连续运动与离散模式切换（如双足机器人先行走再抓取），纯离散或连续规划器均难以求解，而现有MIP建模方法依赖人工、难以泛化到非凸机器人任务。

🛠 **方法**：提出M³P-R1，通过强化学习微调大语言模型，使其生成可执行的MIP Python代码（变量、约束、目标），而非直接输出答案；以求解器结果作为奖励信号进行端到端训练。

✨ **主要贡献**：让LLM学会组合模态级离散化原语并合成跨模态耦合约束，生成可被求解器验证执行的MIP程序，为复杂M³P任务提供稳健、可验证的自动化建模方案。

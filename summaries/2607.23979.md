# Mutual Modality Trust with Lightweight Reconstruction Regularization for Fine-grained Tire Pattern Recognition

- arXiv: https://arxiv.org/abs/2607.23979v1
- arXiv ID: 2607.23979

---

🔍 **核心问题**：现有细粒度轮胎识别方法依赖单一视觉源，缺乏空间与频率特征的联合建模能力，且在有限标注数据下存在严重过拟合问题。

🛠 **方法**：提出轻量级细粒度轮胎识别方法，包含双分支独立推理（分别处理轮胎表面与胎面压痕）、基于互模态信任（M²T）的跨分支特征融合、频域分层引导模块（利用带通滤波器分解高低频特征），以及轻量级重建正则化（LR²）以增强特征稳定性。

✨ **主要贡献**：构建了包含299类14795对图像的MTire299多源数据集；通过双分支融合与频域调制显著提升识别性能；LR²正则化在有限标注下有效缓解过拟合，在两个公开数据集上验证了方法的优越性。

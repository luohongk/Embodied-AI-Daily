# Automated Numerical Stability Analysis of Deep Learning Operators

- arXiv: https://arxiv.org/abs/2607.25494v1
- arXiv ID: 2607.25494

---

🔍 **核心问题**：深度学习算子在使用有限精度算术时可能因精度不足或公式不当导致数值不稳定，影响训练和推理的可靠性。

🛠 **方法**：提出首个集成CESTAC方法的统一软件工具，通过单次计算验证数值稳定性，并自动检测不稳定来源，在训练和推理过程中持续监控。

✨ **主要贡献**：首次实现深度学习算子数值稳定性的自动化检测与监控，在多种任务中成功识别注入数值不稳定的算子，为开发数值稳定的计算内核提供了有效工具。

# Towards Reproducibility in Predictive Process Mining: SPICE -- A Deep Learning Library

- arXiv: https://arxiv.org/abs/2512.16715v3
- arXiv ID: 2512.16715

---

🔍 **核心问题**：预测性流程挖掘（PPM）中基于深度学习的现有方法缺乏可复现性、决策透明性，且难以整合新数据集和进行公平基准比较。

🛠 **方法**：提出SPICE，一个基于PyTorch的Python框架，重新实现了三种流行的PPM深度学习方法，并设计了统一且高度可配置的基础框架，支持可复现和稳健的模型对比。

✨ **主要贡献**：在11个数据集上，SPICE不仅复现了原始论文报告的指标，还提供了公平的对比指标，显著提升了PPM研究的可复现性和可比性。

# CoER: Defending against Adaptive Indirect Prompt Injection via Adversarial Co-Evolution and Refinement

- arXiv: https://arxiv.org/abs/2609.07529v2
- arXiv ID: 2609.07529

---

🔍 **核心问题**：语言模型智能体在工具调用时易受间接提示注入（IPI）攻击，且现有防御多针对固定攻击训练，难以应对能根据防御者行为自适应调整的攻击。

🛠 **方法**：将自适应IPI建模为一般和马尔可夫博弈，提出CoER框架——通过Co-PPO保留攻防双方历史策略作为对手种群进行双边强化学习，再用种群中的攻击者挑战教师智能体，仅用同时通过安全与任务完成验证的示范微调防御者。

✨ **主要贡献**：实现攻防协同演化与精炼，在七领域评测中将攻击成功率从38.5%降至0.2%，任务效用从63.2%提升至76.3%，并在外部基准上展现更强的抗攻击能力。

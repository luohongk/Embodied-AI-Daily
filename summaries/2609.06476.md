# One MLLM, One Call: Efficient Zero-Shot Vision-and-Language Navigation via Spatial-Aware Waypoints

- arXiv: https://arxiv.org/abs/2609.06476v1
- arXiv ID: 2609.06476

---

🔍 **核心问题**：解决连续环境中零样本视觉-语言导航（VLN-CE）任务中推理延迟高、计算开销大的问题，现有方法依赖预训练航点预测器或每步多次查询大型模型。

🛠 **方法**：提出O2C-Nav框架，每步仅调用一次多模态大模型（MLLM），通过无训练的航点生成器将历史感知的稀疏候选航点投影为RGB图像上的视觉标记，MLLM选择航点或生成目标框，再由快速行进法（FMM）规划器生成无碰撞路径。

✨ **主要贡献**：在R2R-CE和RxR-CE基准上超越现有零样本方法，显著降低视觉处理负载并提升实时部署潜力，代码已开源。

# SplitGaussian: Reconstructing Dynamic Scenes via Visual Geometry Decomposition

- arXiv: https://arxiv.org/abs/2508.04224v2
- arXiv ID: 2508.04224

---

🔍 **核心问题**：从单目视频重建动态3D场景时，现有基于高斯泼溅的方法将静态与动态元素耦合在共享表示中，导致运动泄漏、几何畸变和时间闪烁。

🛠 **方法**：提出SplitGaussian框架，显式将场景分解为静态和动态两个分支，仅动态分支随时间变形，静态分支保持背景几何不变，并支持视角与时间相关的外观细化。

✨ **主要贡献**：通过解耦运动与背景几何，显著提升时间一致性和重建保真度，加速收敛，并在渲染质量、几何稳定性和运动分离上超越现有最先进方法。

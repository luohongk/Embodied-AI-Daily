# Agentic Router: An Execution-Grounded Continual Learning Approach With Memory

- arXiv: https://arxiv.org/abs/2608.09184v1
- arXiv ID: 2608.09184

---

🔍 **核心问题**：现有LLM智能体在命令行网络操作中只关注命令生成或最终配置正确性，未利用执行反馈来同时提升候选动作覆盖率和动作选择质量。

🛠 **方法**：提出执行接地双路径后果感知智能体，提案路径将可复用操作经验抽象为可检索指导以提升可行动作覆盖率，选择路径通过会话级LoRA更新基于真实SSH反馈适应后果预测器，并采用效用与风险感知重排序选择最终动作。

✨ **主要贡献**：在SONiC多轮操作会话中，该方法显著提升可行动作覆盖率和top-1执行成功率，且两条适应路径提供互补增益，验证了执行接地持续学习的有效性。

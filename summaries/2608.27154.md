# ReViCo: Unveiling the Limitations of VLMs in Visual Text Understanding via Error Correction

- arXiv: https://arxiv.org/abs/2608.27154v1
- arXiv ID: 2608.27154

---

🔍 **核心问题**：现有视觉语言模型（VLMs）在理解图像中的文本方面仍存在显著不足，尤其是在需要结合视觉上下文进行深度文本理解的任务上。

🛠 **方法**：提出ReViCo基准，通过“视觉文本纠错”这一新任务评估模型，并采用两种范式——基于提示的策略和针对性的模型训练——来测试多种VLM的性能。

✨ **主要贡献**：揭示了当前最优VLM与人类在视觉文本理解上的巨大差距，并指出多数模型难以准确感知视觉文本，导致频繁纠错失败；ReViCo为开发更鲁棒、文本感知能力更强的VLM提供了新基准。

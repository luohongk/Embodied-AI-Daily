# TRACER: Balancing Stability-Plasticity-Cognitivity Trilemma for LLM Enhanced Continual Recommendation

- arXiv: https://arxiv.org/abs/2608.16075v1
- arXiv ID: 2608.16075

---

🔍 **核心问题**：持续推荐系统面临数据稀疏性挑战，引入大语言模型增强后产生稳定性-可塑性-认知性（SPC）三难困境，即通用语义先验与保留个性化历史偏好、适应个体兴趣变化之间存在冲突。

🛠 **方法**：提出TRACER框架，通过三个专门模块分别针对稳定性、可塑性和认知性进行协同优化，并设计机制防止任一模块主导，使语义知识辅助历史保留和兴趣适应而不干扰持续学习。

✨ **主要贡献**：首次系统定义SPC三难困境，提出平衡三者的整体解决方案；在五个真实数据集上验证有效性，相比最先进基线性能提升最高达14.38%，并开源代码。

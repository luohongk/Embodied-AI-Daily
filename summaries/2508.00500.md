# ProbGuard: Proactive Runtime Monitoring for LLM Agent Safety via Probabilistic Prediction

- arXiv: https://arxiv.org/abs/2508.00500v4
- arXiv ID: 2508.00500

---

🔍 **核心问题**：现有LLM智能体运行时监控框架（如AgentSpec）依赖反应式规则，只能在危险行为即将发生或已发生时检测违规，难以应对长时序依赖带来的安全风险。

🛠 **方法**：ProbGuard将智能体执行抽象为符号状态，从执行轨迹学习离散时间马尔可夫链（DTMC）建模行为动态；运行时从当前状态预测执行保持安全的概率，低于用户设定阈值时触发干预，并引入语义有效性约束和PAC风格样本复杂度分析。

✨ **主要贡献**：在自动驾驶和具身家庭智能体两个安全关键领域验证，可提前最多15.84秒（无假警报阈值）至38.66秒（更严格阈值）预测违规；在具身任务中，重新提示干预模式降低65.37%不安全行为且保留80.4%任务完成率，更严格的停止配置可降低93.60%不安全行为。

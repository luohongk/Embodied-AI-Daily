# AgentHPOBench: A Benchmark For Evaluating LLM Agents as Sequential Hyperparameter Optimizers

- arXiv: https://arxiv.org/abs/2607.29626v1
- arXiv ID: 2607.29626

---

🔍 **核心问题**：现有LLM智能体评估基准多聚焦于静态代码生成或最终答案正确性，无法直接衡量智能体能否解读实验证据并据此调整超参数，缺乏对顺序实验优化能力的评测。

🛠 **方法**：提出AgentHPOBench基准，包含7个研究类别、30个可执行的机器学习任务；每个任务从已验证的基线运行开始，智能体在每步观察累积配置、指标和日志后提出下一有效配置，采用统一协议评估12种智能体及传统HPO方法。

✨ **主要贡献**：首次系统评估LLM智能体作为顺序超参数优化器的能力，实验表明当前智能体具备跨领域的实验优化能力，但在持续迭代细化、复杂日志诊断和向参考性能稳定收敛方面仍存在明显局限。

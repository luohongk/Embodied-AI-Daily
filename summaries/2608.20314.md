# MidTool: Mid-training Data Synthesis for Agentic Tool Use

- arXiv: https://arxiv.org/abs/2608.20314v1
- arXiv ID: 2608.20314

---

🔍 **核心问题**：大型语言模型在通用工具使用（如调用API、MCP技能）方面的能力尚未得到充分研究，现有工作多聚焦于数学、科学或软件工程场景，缺乏针对通用工具使用的专门中训练（mid-training）方法。

🛠 **方法**：提出MidTool，一个用于智能体工具使用中训练的开放语料构建流水线，整合大规模网页、PDF和代码数据，并利用真实工具API、MCP技能和文档驱动工作流合成监督信号，训练模型识别工具可用性、从上下文中提取参数、组合调用流程并处理信息不完整的情况。

✨ **主要贡献**：在Qwen3-4B-Base和Qwen3-8B-Base上使用MidTool-Mix进行中训练，随后结合监督微调和强化学习，在BFCL、tau2-Bench和MCP Universe基准上持续优于基线，证明通用工具使用能力应通过专门的中训练来增强，而非完全依赖后训练。

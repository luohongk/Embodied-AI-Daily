# Cloud Workflow Scheduling Based on Graph Attention-Driven Hierarchical Reinforcement Learning

- arXiv: https://arxiv.org/abs/2609.14952v1
- arXiv ID: 2609.14952

---

🔍 **核心问题**：动态云工作流调度需在满足截止时间的同时平衡容器利用率与能耗，但任务执行速度随机、通信依赖放置位置，且任务与容器决策相互耦合，传统向量/矩阵状态难以充分刻画DAG依赖拓扑。

🛠 **方法**：为任务分配预测子截止时间以表征紧迫性，用多头图注意力网络（GAT）从动态DAG中提取依赖信息；将调度建模为事件驱动分层半马尔可夫决策过程（SMDP），由任务调度（TS）智能体和容器调度（CS）智能体分别用独立PPO交替训练。

✨ **主要贡献**：提出图注意力驱动的分层强化学习框架GA-HRL，在2018阿里巴巴集群数据上保持有竞争力的工作流成功率，并在成功率相当的情况下实现更高容器利用率和更低能耗；在最大速度波动下以小幅成功率换取显著能耗降低。

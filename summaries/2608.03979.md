# Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent

- arXiv: https://arxiv.org/abs/2608.03979v1
- arXiv ID: 2608.03979

---

🔍 **核心问题**：现有多模态智能体在处理连续视频流时存在两大瓶颈——模态偏差（智能体绕过视觉工具而依赖文本搜索）和参数知识泄漏（模型依赖内部记忆而非真实工具增强执行），导致视频深度研究任务表现不佳。

🛠 **方法**：提出Video-DeepResearch框架，采用解耦的感知-探索流水线，通过分阶段工具解锁强制在网页检索前进行跨帧视觉定位；训练上采用两阶段策略，先监督微调再使用GRPO强化学习，突破模仿学习上限。

✨ **主要贡献**：构建了包含200个复杂多跳VQA实例的Video-DR-Bench基准；提出的Video-DeepResearch-35B-A3B模型以64.0%平均准确率超越Claude-4.5-Sonnet（59.0%）5.0个百分点，显著优于GPT-5（52.5%）和Gemini 2.5 Pro（57.5%）；30B-A3B变体以59.3%的准确率在紧凑规模下达到与Claude-4.5-Sonnet相当的水平，验证了训练范式的有效性。

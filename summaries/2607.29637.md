# CodeShrink: Adaptive Visual Compression for Efficient Multimodal Code Understanding

- arXiv: https://arxiv.org/abs/2607.29637v1
- arXiv ID: 2607.29637

---

🔍 **核心问题**：多模态大语言模型（MLLMs）在代码理解任务中，将代码渲染为图像会引入大量冗余视觉token（如空白区域和与指令无关的代码），且固定压缩策略无法适应不同输入、任务和模型。

🛠 **方法**：提出CodeShrink框架，包含三个组件：空白消除渲染（用紧凑布局和显式结构标记替代空白依赖布局）、自适应压缩配置（用强化学习训练的轻量智能体预测每输入的最佳压缩设置）、主导token选择（联合分析指令和代码图像，在推理时剪除任务无关的视觉token）。

✨ **主要贡献**：在代码问答、克隆检测和代码补全任务上，CodeShrink减少高达71.2%的视觉token使用，同时匹配或超越未压缩的纯文本输入，并一致优于文本和视觉压缩基线，证明布局压缩、自适应配置和指令感知剪枝的组合能显著提升多模态代码理解的效率。

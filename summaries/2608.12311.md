# The Role Specialization Model (RSM): Coordinating LLM-Based Tools in Agentic Software Development - An Exploratory Case Study

- arXiv: https://arxiv.org/abs/2608.12311v1
- arXiv ID: 2608.12311

---

🔍 **核心问题**：如何协调多个具备不同能力的LLM工具，在真实软件开发流程中实现角色分工，并评估其效果与偏差。

🛠 **方法**：提出角色专业化模型（RSM），将Antigravity、Gemini CLI和Qwen Code三个LLM工具按角色分工，协同开发一个Python气候数据可视化桌面应用，并通过三个研究问题（协调方式、偏差原因、质量评估）进行探索性案例研究。

✨ **主要贡献**：验证了显式角色协调能有效组织开发流程并提升架构质量，同时揭示了需依赖协调策略、上下文管理和人工验证来应对偏差，并提供了基于ISO/IEC 25010的定性质量评估及提示词加固经验。

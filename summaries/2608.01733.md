# TWINS: A Tactile Wearable Isomorphic Arm Networked System for Contact-Rich Manipulation Learning

- arXiv: https://arxiv.org/abs/2608.01733v1
- arXiv ID: 2608.01733

---

🔍 **核心问题**：现有机器人系统主要聚焦于末端执行器操作，难以教授和执行涉及手臂、胸部等身体表面接触的操控任务。

🛠 **方法**：提出TWINS系统，包含操作员穿戴的双臂设备和同构机器人，两者具有相同关节配置和外部尺寸，并在胸部和手臂嵌入分布式触觉传感器以同步测量身体表面接触与关节运动。

✨ **主要贡献**：通过穿戴设备采集四种涉及身体表面接触的操控任务演示数据，训练模仿学习策略并部署于同构机器人，实验证明该系统实现了从演示、学习到执行的一体化流程，并利用身体表面触觉观测引导操控。

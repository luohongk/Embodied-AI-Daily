# Discovering Temporal Structure: An Overview of Hierarchical Reinforcement Learning

- arXiv: https://arxiv.org/abs/2506.14045v2
- arXiv ID: 2506.14045

---

🔍 **核心问题**：如何在复杂开放环境中让AI智能体高效地探索、规划和决策，以及如何定义和发现有意义的时序结构以支撑分层强化学习。

🛠 **方法**：从决策制定的基本挑战出发，系统梳理分层强化学习中时序结构发现的方法族，涵盖在线经验学习、离线数据集学习以及利用大语言模型（LLM）等途径。

✨ **主要贡献**：阐明了HRL在决策挑战中的优势及其对AI智能体性能权衡的影响，系统综述了时序结构发现的方法分类，并指出了该领域的挑战与最适合应用的研究方向。

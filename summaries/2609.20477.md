# Visual Sim-to-Real Learning for Robotic Insertion under Geometric Variations: Application to Rebar Installation

- arXiv: https://arxiv.org/abs/2609.20477v1
- arXiv ID: 2609.20477

---

🔍 **核心问题**：建筑工地上的钢筋插入任务重复且费力，且需在1.4毫米间隙下完成接触密集操作；由于结构件设计多样、加工公差各异，真实数据需随设计和批次变化反复采集，成本高昂。

🛠 **方法**：提出 RebarSim，一个完全在仿真中训练的视觉 sim-to-real 系统——先用强化学习在程序化生成的钢筋几何上训练基于特权状态的教师策略，再通过大规模域随机化蒸馏为直接从原始 RGB 和本体感知映射到动作的多视角学生策略。

✨ **主要贡献**：学生策略零样本迁移到真实世界，在真实工厂钢筋上取得 91.3% 的实机成功率；几何多样性与预训练均带来增益（学生策略在单设计专家自己的设计上超越该专家，预训练学生适应新设计所需蒸馏样本减少 4–6 倍），并证明外观随机化与 DAgger 混合策略对视觉 sim-to-real 迁移缺一不可。

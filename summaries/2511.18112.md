# EchoVLA: Robotic Vision-Language-Action Model with Synergistic Declarative Memory for Mobile Manipulation

- arXiv: https://arxiv.org/abs/2511.18112v3
- arXiv ID: 2511.18112

---

🔍 **核心问题**：现有视觉-语言-动作（VLA）模型主要局限于短时程、桌面级操作，缺乏移动操作所需的记忆与推理能力，难以在动态空间环境中协调导航与操作。

🛠 **方法**：提出EchoVLA，一种记忆增强的VLA模型，引入受人类大脑启发的协同声明式记忆，包括维护空间-语义地图的场景记忆和存储多模态任务经验的场景记忆，两者基于当前观测、任务历史与指令进行存储、更新和检索，并通过粗粒度与细粒度注意力融合，引导基座-机械臂扩散策略。同时提出MoMani自动基准，利用多模态大语言模型（MLLM）规划与反馈修正生成专家级轨迹。

✨ **主要贡献**：EchoVLA在仿真中于操作/导航任务上达到0.52成功率，移动操作任务上达0.31，分别比强基线π₀.₅提升+0.20和+0.11；此外，MoMani支持大规模训练，并辅以真实机器人演示，综合实验验证了模型在仿真与真实场景中的显著性能提升。

# 3DGSI-Assessor: A Large-Scale Dataset and An LMM-based Method for 3D Gaussian Splatting Image Quality Assessment

- arXiv: https://arxiv.org/abs/2608.03279v1
- arXiv ID: 2608.03279

---

🔍 **核心问题**：现有图像质量评估（IQA）指标无法准确捕捉3D高斯泼溅（3DGS）压缩带来的特有失真（如浮动伪影、表面散射），且只能给出单一总分，无法分别诊断几何与颜色属性的独立失真。

🛠 **方法**：构建大规模多维度IQA数据集3DGS-IEval-15K+（含15,200张图像、45,600个MOS分数，覆盖整体/几何/颜色三维度），并提出3DGSI-Assessor框架，基于大多模态模型（LMM）融合全局语义与维度特定局部特征，单次前向预测三个质量维度。

✨ **主要贡献**：首次提供针对压缩3DGS的多维度大规模评估数据集；提出的3DGSI-Assessor在3DGS-IEval-15K+上达到SOTA性能，并在其他NVS基准上展现良好泛化能力；数据集和代码将开源。

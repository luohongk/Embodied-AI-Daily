# Should I Use This Synthetic Dataset for Training? How to Test with Minimal Real Data

- arXiv: https://arxiv.org/abs/2608.27996v1
- arXiv ID: 2608.27996

---

🔍 **核心问题**：在数字孪生等生成合成数据用于增强真实训练数据时，如何以最少的真实测试样本判断合成数据是否真正提升模型在真实分布上的性能。

🛠 **方法**：提出自适应e过程符号翻转检验（aeSFT），一种双重自适应序贯检验方法，动态调整蒙特卡洛符号翻转次数和真实测试样本消耗量，支持任意时点的有效第一类错误控制。

✨ **主要贡献**：aeSFT在多个任务（合成数据分类、无线调度、无线地图预测）中，相比基于均值的序贯检验大幅减少真实测试样本需求，同时保持与固定样本符号翻转检验和配对t检验相当的检验功效，且误报率低于目标水平。

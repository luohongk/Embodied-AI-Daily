# Robot-Factored World Models via Robot Rendering

- arXiv: https://arxiv.org/abs/2607.22535v1
- arXiv ID: 2607.22535

---

🔍 **核心问题**：现有动作条件视频世界模型在机器人应用中，直接基于动作命令学习未来观测时，需要同时建模机器人自身运动实现和场景响应，导致学习负担重且可能泄露交互结果。

🛠 **方法**：提出“机器人因子世界模型”，将机器人特有的动作实现和渲染过程从模型中剥离：通过名义轨迹（经控制器和运动学处理后的中间信号）避免学习动作实现；利用URDF渲染机器人几何形状，并结合末端执行器深度与场景深度解决遮挡和深度模糊问题。

✨ **主要贡献**：构建了跨视角和机器人形态一致的视觉世界模型接口，在实验中优于向量条件基线，能泛化到未见机器人形态，并支持从人类演示视频生成机器人操作视频。

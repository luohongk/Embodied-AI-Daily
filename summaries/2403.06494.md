# An Efficient Solution to the 2D Visibility Problem in Cartesian Grid Maps and its Application in Heuristic Path Planning

- arXiv: https://arxiv.org/abs/2403.06494v2
- arXiv ID: 2403.06494

---

🔍 **核心问题**：解决二维笛卡尔网格地图中从源点到所有格点的可见性计算问题，传统射线投射算法计算量大且依赖障碍物复杂度。

🛠 **方法**：提出一种基于线性一阶双曲型偏微分方程的轻量级方法，采用熵满足的上迎风差分格式，在单次遍历中动态规划传播可见性，无需预处理，计算和内存复杂度均为O(n)，每格最多需十次算术运算。

✨ **主要贡献**：首次将可见性问题转化为PDE传输问题，实现比射线投射快数量级的全图可见性评估；并将可见性量作为启发式，开发了确定性、无局部极小值的路径规划器，附带开源实现。

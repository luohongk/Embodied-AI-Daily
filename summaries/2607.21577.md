# Synthetic data generation framework for quality control automation in gravure printing

- arXiv: https://arxiv.org/abs/2607.21577v1
- arXiv ID: 2607.21577

---

🔍 **核心问题**：凹版印刷质量控制依赖人工检测，效率低且成本高，而真实工业缺陷图像极度稀缺，难以训练深度学习模型实现自动化检测。

🛠 **方法**：提出一种合成数据生成框架，自动生成高保真印刷缺陷图像（如折痕、条纹、套印不准等），并输出对应的边界框和标注，用于训练目标检测模型RFDETR。

✨ **主要贡献**：生成了7533张合成图像，训练后的模型在真实工业样本上达到80.9%的平均精度（mAP），为零成本、快速部署的印刷缺陷自动检测提供了可行方案。

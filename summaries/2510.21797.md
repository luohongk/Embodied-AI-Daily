# Mitigating Sample-Level Imbalance via Probabilistic Separation for Adaptive Multimodal Fusion

- arXiv: https://arxiv.org/abs/2510.21797v4
- arXiv ID: 2510.21797

---

🔍 **核心问题**：多模态学习中存在模态不平衡问题，即强模态抑制弱模态，且现有方法未考虑样本级别的预测偏差，无法有效隔离低质量离群样本。

🛠 **方法**：提出一种样本级动态缓解框架，先引入“模态差距”指标量化单模态分支间的预测差异，并用高斯混合模型（GMM）建模其双峰分布，通过贝叶斯后验概率实现软分离；随后构建两阶段训练框架（预热+自适应），在自适应阶段用GMM引导的自适应损失动态调整优化优先级，对不平衡样本施加更强对齐惩罚，对平衡样本侧重多模态融合。

✨ **主要贡献**：实验表明该方法显著优于现有最先进基线；此外，利用GMM筛选的高质量平衡子集进行微调，可作为有效的数据净化策略。

# FlexWorm: Primitive-augmented Hybrid Contact-motion Planning for Suction-based Multi-segment Deformable Robots

- arXiv: https://arxiv.org/abs/2608.16853v1
- arXiv ID: 2608.16853

---

🔍 **核心问题**：针对多段吸附式软体机器人在复杂表面上的3D导航规划问题，现有方法依赖人工设计的步态和环境特定脚本，缺乏通用性。

🛠 **方法**：提出一个混合规划框架，包含块级逆运动学混合搜索（IKHS）和原语增强混合搜索（PaHS）。IKHS在可行吸附转换上进行最佳优先搜索，仅对自由块求解逆运动学；PaHS利用学习到的观测-原语嵌入快速检索已验证的运动片段，失败时回退到IKHS。

✨ **主要贡献**：框架在仿真中显著优于基线，PaHS在保持成功率的同时大幅减少规划时间；硬件实验验证了在气动软体机器人上的可执行性和在线恢复能力，且对具体驱动方式无依赖。

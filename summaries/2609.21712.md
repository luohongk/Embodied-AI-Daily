# ZYT-World: A Real-Time Controllable World Model for Closed-Loop Autonomous-Driving Simulation

- arXiv: https://arxiv.org/abs/2609.21712v1
- arXiv ID: 2609.21712

---

🔍 **核心问题**：面向自动驾驶闭环仿真的生成式世界模型在落地时面临三大挑战——原生分辨率下混合鱼眼-针孔相机阵列的忠实重建、因果逐步交互与长时稳定低延迟的兼顾，以及重访同一地点时的场景身份保持。

🛠 **方法**：提出统一架构 ZYT-World，原生生成4路视场角>180°的鱼眼视图和3路针孔视图；采用投影特定的 Plücker 适配器编码相机几何、自运动自适应层归一化实现全局运动控制、轻量像素对齐布局以实例级框/朝向/颜色条件化交通参与者；通过教师强制、因果一致性蒸馏、自 rollout 分布匹配蒸馏和 RigCritic 将40步双向教师模型压缩为单步逐潜变量流式生成器，并结合 TinyVAE、W8A8 量化与自研推理引擎降低解码与执行开销，另用跨轨迹配对训练插件式隐式记忆模块。

✨ **主要贡献**：单步模型在内部多视图测试集上保留教师模型90%以上的 PSNR/SSIM，FID/FVD/LPIPS 差距在11%以内，生成速度比40步双向教师快107.7倍，TinyVAE 解码比 Wan 快59.8倍，并验证了30秒长时 rollout 与跨轨迹重访的记忆行为。

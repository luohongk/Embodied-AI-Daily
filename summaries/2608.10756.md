# Embodied Multimodal Grounding for Open-Vocabulary Mobile Manipulation via Semantic 3D Gaussian Splatting

- arXiv: https://arxiv.org/abs/2608.10756v1
- arXiv ID: 2608.10756

---

🔍 **核心问题**：解决开放词汇移动操作中，语言指令、视觉观察、三维场景结构和动作可行性难以对齐的问题，尤其是在杂乱、遮挡和视角变化下的目标定位与操作鲁棒性。

🛠 **方法**：提出一种具身多模态接地框架，集成主动多视角语义3D高斯泼溅（Semantic-3DGS）、可达性感知的基座定位，以及基于扩散的视觉-语言-动作策略。语义3DGS作为共享接口，统一主动感知、语言条件3D定位、障碍感知推理、基座准备和动作模型语义条件化，且仅将3D语义线索注入动作专家模块的后期层以保留预训练先验。

✨ **主要贡献**：在50次真实机器人实验中，完整系统在长时程任务上达到60%成功率（优于PointVLA的40%和DexVLA的28%），在重度杂乱操作中达74%（优于单视图变体的52%和PointVLA的46%），并在75cm高度偏移下保持75%成功率，同时消除照片诱发的错误抓取，证明显式、可刷新的3D语义接地能显著提升杂乱、遮挡、视角变化和具身约束下的鲁棒性。

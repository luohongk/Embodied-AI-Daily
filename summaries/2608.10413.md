# DriveVLA-M0: Failure-Aware Memory Augmentation for Autonomous Driving

- arXiv: https://arxiv.org/abs/2608.10413v1
- arXiv ID: 2608.10413

---

🔍 **核心问题**：现有VLA自动驾驶模型缺乏利用历史失败案例和适应分布偏移的机制，导致在相似场景中反复出错。

🛠 **方法**：提出DriveVLA-M0，构建包含失败案例的潜在记忆池，设计解耦静态道路结构与动态智能体交互的检索模型，并在推理时通过轻量级LoRA测试时训练机制注入检索到的案例。

✨ **主要贡献**：在NAVSIMv1/v2基准上取得SOTA性能（Navtest 94.1 PDMS，Navhard 47.0 EPDMS），TTT反向传播仅需26.44ms；记忆扩展可无训练提升性能，代码已开源。

# Eventually Optimal and Scalable Multi-Agent Planning for Block Cave Mining

- arXiv: https://arxiv.org/abs/2609.07109v1
- arXiv ID: 2609.07109

---

🔍 **核心问题**：地下矿场中自动驾驶车队协调运输的优化与运动规划难题，具体为在满足放矿比例约束下最大化矿石吞吐量。

🛠 **方法**：提出SAMM算法，通过混合整数线性规划联合优化任务分配、调度与路径规划；并扩展出SAMMS变体，将问题分解为短周期子规划以提升可扩展性。

✨ **主要贡献**：首次形式化定义Block Cave Mining问题，SAMMS在工业场景中实现近最优吞吐量，并能高效扩展到更大车队和矿场布局。

# SmartMage: Dynamic Modality Orchestration for 3D Scene Understanding

- arXiv: https://arxiv.org/abs/2608.05137v1
- arXiv ID: 2608.05137

---

🔍 **核心问题**：现有3D场景理解的多模态大模型（MLLMs）依赖固定模态组合，忽略了不同查询对模态需求的差异性，导致引入无关模态的语义噪声并浪费计算资源。

🛠 **方法**：提出SmartMage统一框架，包含两个核心模块——SMART（语义引导的模态自适应路由）根据语义先验、文本-模态对齐和模态质量动态选择任务相关模态；MAGE（模态感知门控专家）利用模态先验指导专家激活，实现多模态推理的自适应专业化。

✨ **主要贡献**：在五个3D场景理解基准上达到最先进性能，并在RGB-only视频理解基准上取得竞争力结果；构建了细粒度语义分类的诊断基准ScanFacet，揭示了不同语义类型偏好的模态组合模式，验证了动态模态编排的有效性。

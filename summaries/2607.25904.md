# Interactive Reward Agent: GUI Task Evaluation via Environment-State Verification

- arXiv: https://arxiv.org/abs/2607.25904v1
- arXiv ID: 2607.25904

---

🔍 **核心问题**：解决GUI任务评估中仅依赖截图难以获取环境状态（如系统配置、文件数据等）导致判断不可靠的问题。  
🛠 **方法**：提出交互式奖励智能体（IRA），基于“先提出后验证”框架，通过调用系统工具、应用工具和GUI工具，从执行后的环境中交互式获取并验证证据。  
✨ **主要贡献**：构建了包含321个GUI任务轨迹的基准测试GUI-RewardBench，IRA在该基准上达到86.9%的准确率，并在强化学习中使OSWorld成功率提升至34.0%，证明其能提供有效奖励信号。

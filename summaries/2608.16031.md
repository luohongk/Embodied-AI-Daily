# AdROD: HyperNetwork-based Adversarially Robust Object Detection for Autonomous Driving

- arXiv: https://arxiv.org/abs/2608.16031v1
- arXiv ID: 2608.16031

---

🔍 **核心问题**：自动驾驶中基于摄像头的目标检测器易受物理对抗攻击影响，现有防御方法（如对抗训练、输入净化）对自适应攻击泛化能力不足。

🛠 **方法**：提出AdROD，一种嵌入式随机集成防御软件，采用低秩HyperNetwork（仅需标准1.6%参数）按帧生成多样检测器，并引入“功能多样性”机制（随机权重更新+输入空间变换），提供两种服务模式（AdROD-I连续保护、AdROD-II按需触发）。

✨ **主要贡献**：AdROD在合成基准、物理对抗补丁和OpenCDA协同仿真端到端安全测试中，优于五种基线防御，对自适应攻击泛化性更强，且能实时运行，在带对抗补丁的停车标志场景下安全停车。

# Deep learning based numerical approximation algorithms for stochastic partial differential equations

- arXiv: https://arxiv.org/abs/2012.01194v3
- arXiv ID: 2012.01194

---

🔍 **核心问题**：针对随机偏微分方程（SPDEs）难以高效求解的问题，提出一种基于深度学习的数值近似算法。

🛠 **方法**：利用神经网络在给定噪声过程实现下近似SPDE的解，并对模拟的噪声轨迹批量应用，从而获得解的统计分布，进而估计均值、方差等泛函。

✨ **主要贡献**：算法在加性/乘性噪声的随机热方程、随机Black-Scholes方程及非线性滤波中的Zakai方程上均表现准确，且运行时间短，可处理高达100维的空间问题。

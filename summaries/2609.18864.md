# ASLEval: Measuring Privacy Exposure Displacement in LLM Agent Sessions

- arXiv: https://arxiv.org/abs/2609.18864v1
- arXiv ID: 2609.18864

---

🔍 **核心问题**：现有对使用工具的LLM智能体的隐私评估通常只检查某个指定动作、最终回复或攻击者报告，这种局部代理会遗漏多步会话中其他位置的未授权暴露，且缺乏跨出口、报告和工具路径的统一真值标准。

🛠 **方法**：作者提出“隐私暴露位移”概念（局部评估代理与基于目标的会话暴露之间的不匹配），并构建ASLEval框架——预先注册隐藏目标集、测量所有声明的可见出口、保留内部轨迹用于诊断，在多种企业级环境和独立实现的运行时中进行验证。

✨ **主要贡献**：揭示了三种反复出现的模式：仅看预期出口会遗漏46.9%的暴露；攻击者自报既有遗漏又有高误报；模式对齐的内部证据通常在请求/探测层面先于可见暴露出现。研究呼吁基准应声明完整可见边界、以预设目标和授权为依据，并将隐私与任务效用一并报告。

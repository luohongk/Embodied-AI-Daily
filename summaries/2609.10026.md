# Beyond Contact Sensors: Deep learning with Pseudo-Labeling for remote Photoplethysmography

- arXiv: https://arxiv.org/abs/2609.10026v1
- arXiv ID: 2609.10026

---

🔍 **核心问题**：深度学习rPPG方法依赖视频与接触传感器标签精确同步的数据集，而这类数据采集成本高昂，能否用无监督信号处理方法生成的伪标签替代接触传感器标签来训练深度模型。

🛠 **方法**：使用无监督信号处理算法从视频中提取伪标签，用于训练深度学习rPPG模型，并在同步质量不同的数据集上进行系统的监督训练与伪标签训练的对比评估。

✨ **主要贡献**：发现同步不佳的数据集上伪标签训练优于监督训练；同步良好时两者在数据集内表现相当，跨数据集则监督训练更优，但剔除一个异常参与者后伪标签跨数据集性能显著提升，表明信号处理方法可生成有效训练信号，降低对昂贵标注数据的依赖。

# Beyond Instance Slots: Semantically Rich World Models for Physical Interaction Planning

- arXiv: https://arxiv.org/abs/2608.22294v2
- arXiv ID: 2608.22294

---

🔍 **核心问题**：现有世界模型在物理交互规划中仅预测未来观测或特征，无法明确回答候选动作是否产生任务一致的结果，且缺乏对任务中实体角色的语义化建模。

🛠 **方法**：提出语义丰富世界模型（SR-WM），围绕五个功能角色（夹爪、目标、目标状态、关系、阶段）构建任务条件化世界模型。利用视觉实体编码器从预训练patch特征提取软实体假设，通过角色绑定器映射到任务角色，并由动作条件动力学模型预测角色转移及细粒度语义（如接触、谓词建立、关系保持等）。

✨ **主要贡献**：将对象中心预测转化为语义接口，统一支撑多候选动作生成、阶段感知重排序和违规感知后缀重采样；在全部四个LIBERO仿真套件、跨套件迁移、感知诊断和动作敏感性分析中验证了有效性。

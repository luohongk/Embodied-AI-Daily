# Motion-Saliency Complementary Masked Modeling for Point Cloud Video Understanding

- arXiv: https://arxiv.org/abs/2608.30279v1
- arXiv ID: 2608.30279

---

🔍 **核心问题**：点云视频的自监督表示学习，旨在同时捕捉动态场景中的外观与运动信息，以提升3D动态场景理解能力。

🛠 **方法**：提出MoSaiC框架，包含三个组件：课程运动显著性掩码（CMSM）按课程策略优先掩码运动显著token；法向流运动建模（NFM）在so(3)李代数中监督每个token的局部刚性旋转；跨视图token一致性预测（CTCP）在token级别强制两个互补掩码视图的一致性。

✨ **主要贡献**：首次将运动显著性与互补掩码建模结合，在动作识别、时间动作分割和点级语义分割等多个下游任务上验证了有效性，显著提升了点云视频表示学习的性能。

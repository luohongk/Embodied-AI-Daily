# Function-Preserving Data Generation for Zero-Shot Real-to-Sim-to-Real Manipulation

- arXiv: https://arxiv.org/abs/2609.18293v1
- arXiv ID: 2609.18293

---

🔍 **核心问题**：接触密集型操作任务中，生成几何多样且物理有效的数据十分困难，传统形状增强方法会破坏任务关键接口，导致接触关系失效（如配合失配或穿模）。

🛠 **方法**：提出函数保持的Real-to-Sim-to-Real框架，通过约束引导的网格变形增强任务相关物体几何，同时物理一致地迁移任务位姿与碰撞代理，并在仿真中应用视觉域随机化。

✨ **主要贡献**：无需遥操作源轨迹即可从重建资产生成合成演示，实现零样本策略在未见物体几何和多样视觉条件下的鲁棒泛化，为接触密集型任务的规模化机器人学习提供了实用路径。

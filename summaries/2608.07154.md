# Representation Handoffs for OpenArm-Based Laboratory Mobile Manipulation

- arXiv: https://arxiv.org/abs/2608.07154v1
- arXiv ID: 2608.07154

---

🔍 **核心问题**：解决语言引导的实验室移动操作中，从指令和观测到安全动作的可靠对齐问题。

🛠 **方法**：构建基于OpenArm双臂的移动操作原型，集成移动底座、垂直滑轨、RGB-D感知、激光雷达建图、ROS2/MoveIt执行，并采用“表示交接”架构，将自然语言请求约束为技能调用，传感器观测映射为地图和物体位姿，运行时绑定编译为可执行运动目标。

✨ **主要贡献**：提出表示交接作为调试接口，通过干跑追踪和启动检查显式暴露部署障碍（如缺失标定、不完整物体资产、未完成的视觉接地），为语言、感知、规划和机器人安全集成提供了实用验证路径。

# QuARC-GS: Quantized Anchored Residual Coding for Compact Dynamic Scene Streaming with Gaussian Splatting

- arXiv: https://arxiv.org/abs/2608.18285v1
- arXiv ID: 2608.18285

---

🔍 **核心问题**：动态3D场景的在线自由视角视频流传输面临存储需求大和重建/渲染速度要求高的挑战，难以实现长视频的高效流式传输。

🛠 **方法**：提出QuARC-GS，一种量化感知的4D场景优化框架，采用单一规范帧加高度压缩的逐帧残差表示，结合量化感知锚点形变和变化门控致密化两种互补策略，分别处理运动、外观和点云增密。

✨ **主要贡献**：在保持重建质量和训练速度的同时，将每帧存储量相比最先进方法降低最多11倍，实现了超高压缩比的动态场景流式传输，并在多个公开数据集上验证了其有效性。

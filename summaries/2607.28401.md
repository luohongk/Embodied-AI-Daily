# Large scale cross-regional remote sensing flood monitoring framework for operative mapping and impact analysis

- arXiv: https://arxiv.org/abs/2607.28401v1
- arXiv ID: 2607.28401

---

🔍 **核心问题**：针对俄罗斯联邦等广阔且环境多样区域，现有遥感洪水监测算法泛化能力不足，且标注洪水数据稀缺、分布不均，难以实现大规模可靠监测与影响评估。

🛠 **方法**：构建了一个端到端多模态框架，融合SAR数据、多光谱影像和DEM及其衍生数据形成21通道输入；对比了监督学习的U-Net++模型与自监督AnySat架构（预训练+微调）两种水表检测策略，并依据俄紧急情况部官方方法估算洪水对城市的影响。

✨ **主要贡献**：自建覆盖七个俄罗斯地区的多模态数据集，证明在有限数据条件下监督学习更有效，而AnySat更具稳定性且适用于缺失模态场景；以2019年图伦洪水为例，预测结果与官方评估高度吻合（除物质损失外），展示了深度学习与多模态卫星数据集成在数据受限条件下实现可扩展、可靠洪水监测的潜力。

# Learning Stock Trading Policies via Barycenter-Based Adversarial Inverse Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.15770v1
- arXiv ID: 2608.15770

---

🔍 **核心问题**：强化学习在股票交易策略设计中面临奖励延迟与噪声、探索效率低以及难以施加显式风险约束等挑战。

🛠 **方法**：提出BRaG框架，利用性能加权的Wasserstein重心聚合多个异构专家策略，形成稳定的伪专家表示，通过对抗模仿学习预训练交易策略，再用真实市场奖励进行强化学习微调，并引入控制屏障函数约束动作执行以控制回撤。

✨ **主要贡献**：在美、英、印、台四个全球股票市场指数上，BRaG优于经典交易规则和近期深度强化学习方法，同时表现出更稳定的风险特征，有效解决了探索不稳定和风险约束问题。

# Rethinking Vacuity for OOD Detection in Evidential Deep Learning

- arXiv: https://arxiv.org/abs/2605.06382v2
- arXiv ID: 2605.06382

---

🔍 **核心问题**：论文指出在证据深度学习（EDL）中，基于空泛度（vacuity）的分布外（OOD）检测指标对类别数（K）的差异高度敏感，当ID与OOD的类别数不一致时，AUROC和AUPR结果会被人为扭曲，导致评估失真。

🛠 **方法**：通过理论分析和实证实验，系统比较了标准EDL和IB-EDL在类别数相差1时的OOD检测性能，并基于因果语言模型（如Llama3-8B）的多选题问答（MCQA）数据集进行验证，同时探讨了ID与OOD的明确定义问题。

✨ **主要贡献**：首次实证和理论证明了EDL微调大语言模型中，基于空泛度的OOD检测对类别数差异极其敏感（AUROC最大偏差0.427，AUPR最大偏差0.745），并揭示该偏差是评估伪影，可在模型预测不变的情况下人为抬高性能指标，为OOD评估的公平性提供了重要警示。

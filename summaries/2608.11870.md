# Enhancing Visual Domain Robustness in Behaviour Cloning via Saliency-Guided Augmentation

- arXiv: https://arxiv.org/abs/2608.11870v1
- arXiv ID: 2608.11870

---

🔍 **核心问题**：在视觉行为克隆中，传统图像增强方法（如随机裁剪、颜色抖动）在面对显著视觉域偏移（如阴影、干扰物、背景变化）时泛化能力不足，而叠加类增强方法可能破坏任务关键语义和时空关系。

🛠 **方法**：提出RoboSaGA，一种基于显著性引导的叠加增强方法，利用策略驱动的显著性图在像素级动态调整增强强度，对非关键区域进行强增强，同时保留任务关键信息，无需修改网络结构或增加额外训练目标。

✨ **主要贡献**：在仿真和真实环境中验证，RoboSaGA在保持域内性能的同时，显著提升了对视觉域偏移（包括干扰物、背景、光照和阴影变化）的鲁棒性，且易于集成到现有BC架构中。

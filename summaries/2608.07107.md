# MemWM: Memory-Augmented Text-Based World Model

- arXiv: https://arxiv.org/abs/2608.07107v2
- arXiv ID: 2608.07107

---

🔍 **核心问题**：文本世界模型在预测环境状态时，常遗漏任务关键事实、错误修改对象属性或应用错误转换规则，导致系统性预测错误。

🛠 **方法**：提出MemWM，一种记忆增强的文本世界模型，通过构建包含转换规则、状态缓存和难预测事实的“世界记忆”库，在想象下一状态时进行条件化；同时为策略模型提供检索到的任务级技能和逐步纠错指导。

✨ **主要贡献**：引入结构化状态保真度（SSF）评估事实保持，相比SFT训练，记忆增强使SSF最高提升206.3%；在ALFWorld、WebShop和ScienceWorld上，下游任务成功率相对提升最高达65.4%，且在不同记忆和动作预算下均表现稳健。

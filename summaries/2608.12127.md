# SCOPE-Router: Cost-Aware Open-Set VLM Routing for Execution-Oriented Tasks

- arXiv: https://arxiv.org/abs/2608.12127v1
- arXiv ID: 2608.12127

---

🔍 **核心问题**：现有视觉语言模型（VLM）路由研究局限于传统VQA评估，缺乏面向开放集场景的系统性校准优化，且训练目标因softmax归一化稀释多正样本信号且未考虑成本。

🛠 **方法**：提出SCOPE-Router双塔路由器，通过混合校准（随机/诊断/多样性采样）构建模型行为画像，使新模型无需重训练即可加入路由；并设计CRM+RCCR成本感知目标，通过逐对独立评分将成本偏好编码为连续相关目标，消除多正样本稀释并正则化查询空间。

✨ **主要贡献**：构建首个面向执行任务的VLM路由基准VLM-ExecRouterBench（覆盖代码、智能体、搜索域，含11个价格跨度近两个数量级的候选模型）；SCOPE-Router在三个基准上均取得最佳Rank Score，在OOD设置下超越第二名1.84分，双重OOD开放集评估下超越6.75分；CRM+RCCR应用于四种路由器时提升Rank Score 1.25–6.21分。

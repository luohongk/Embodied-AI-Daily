# ATLAS: Adaptive Topological Learning with Abstract Successors for Continual Learning

- arXiv: https://arxiv.org/abs/2608.04334v1
- arXiv ID: 2608.04334

---

🔍 **核心问题**：现有强化学习算法在非平稳环境中面临样本效率低和灾难性遗忘的挑战，难以快速适应环境变化。

🛠 **方法**：提出ATLAS框架，结合“当需增长”（GWR）网络与后继特征（Successor Features），将转移动态与奖励信号结构化解耦，实现自适应拓扑学习。

✨ **主要贡献**：ATLAS在空间导航任务中实现近即时目标适应，并展现正向迁移能力，显著优于常见在线/离线算法，在非平稳环境中兼具高样本效率与抗遗忘鲁棒性。

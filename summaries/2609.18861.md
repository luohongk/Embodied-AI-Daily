# PersonaPath: Towards Knowledge-Centric Personalized Learning Path Planning

- arXiv: https://arxiv.org/abs/2609.18861v1
- arXiv ID: 2609.18861

---

🔍 **核心问题**：传统自适应学习系统多采用以习题为中心（EC）的推荐方式，仅依赖题目级交互日志，难以针对不同学习者的目标与课程先修结构提供个性化路径规划。

🛠 **方法**：提出以知识为中心（KC）的学习路径规划任务，要求规划器综合学习者画像、掌握状态与先修知识结构，决定下一步应学习的教材、单元与概念；并构建 PersonaPath 基准，包含 2000 个细粒度学习者画像与覆盖 77 个学科、347 本教材、1751 个单元、4092 个概念的分层知识图谱。

✨ **主要贡献**：构建了面向知识中心个性化路径规划的新基准 PersonaPath，并评测代表性 LLM；结果显示最强模型在基础教育场景下最终通过率仅 29.5%，且主要瓶颈在于自适应性，无模型在个性化路径定制上超过 44.7%。

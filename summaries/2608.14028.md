# AdvDex: Learning Dexterous Manipulation from Human Demonstrations via Joint-Aligned Actions and Adversarial Learning

- arXiv: https://arxiv.org/abs/2608.14028v1
- arXiv ID: 2608.14028

---

🔍 **核心问题**：灵巧操作技能难以规模化，因为机器人演示数据采集昂贵，且不同执行器（人手、灵巧手、平行夹爪）的动作空间不一致，导致跨本体泛化困难。

🛠 **方法**：提出AdvDex框架，包含三个关键组件：1）OmniShare大规模多模态人手演示数据集（提供运动学监督和触觉测量）；2）联合对齐动作空间（JAAS），将手腕SE(3)位姿与15个手指关节统一为规范动作表示；3）域对抗学习，消除视觉表征中的本体特定信息。

✨ **主要贡献**：在手部动作预测和真实世界灵巧操作实验中，AdvDex相比基线持续提升，实现了有效的零样本人-机器人技能迁移、对未见物体和环境的泛化，以及数据高效的少样本适应。

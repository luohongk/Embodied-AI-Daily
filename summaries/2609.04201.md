# Scal3R: Learning Efficient Multi-Relative Pose Query for Scalable Online 3D Reconstruction

- arXiv: https://arxiv.org/abs/2609.04201v1
- arXiv ID: 2609.04201

---

🔍 **核心问题**：在线3D重建模型在长视频中表现不佳，因固定首帧锚点的位姿回归导致外推超出训练分布，漂移累积引发几何崩溃。

🛠 **方法**：提出Scal3R，将在线重建重构为多参考相对位姿查询，利用轻量级可学习token（约占参数1%）注入冻结骨干网络，通过非对称注意力查询多个历史关键帧的相对位姿，并结合带闭环的在线位姿图优化抑制长程漂移。

✨ **主要贡献**：在单GPU上8小时即可收敛，相比在线基线在KITTI上平均ATE降低超60%，并在Virtual KITTI、Sintel、TUM-Dynamic、ScanNet和7-Scenes上达到最先进性能。

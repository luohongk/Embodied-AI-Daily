# CLFTv2: Efficient Camera-LiDAR Fusion for Semantic Segmentation via Hierarchical Feature Pyramids

- arXiv: https://arxiv.org/abs/2609.09881v1
- arXiv ID: 2609.09881

---

🔍 **核心问题**：自动驾驶语义分割中，弱势道路使用者（VRU）因类别严重不平衡而难以可靠检测，同时现有融合方法计算开销大。

🛠 **方法**：提出CLFTv2，用基于Swin的多尺度编码器和轻量级FPN式残差解码器替代全局ViT注意力，在2D透视域中通过移位窗口注意力和逐尺度残差融合整合多尺度几何线索。

✨ **主要贡献**：在三个驾驶数据集上持续提升VRU召回率（ZOD上行人IoU从35.5%提升至44.9%，mIoU达53.5%；Waymo上mIoU达61.7%），且相比Swin版Mask2Former减少1.4倍GFLOPs、吞吐量提升2.2倍，证明层次化局部注意力融合是实时车载感知的高效可扩展方案。

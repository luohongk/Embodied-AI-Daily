# AccelMPC: High-Rate, Low-Power FPGA-Accelerated Model Predictive Control for Tiny Drones

- arXiv: https://arxiv.org/abs/2609.09380v1
- arXiv ID: 2609.09380

---

🔍 **核心问题**：微型无人机嵌入式边缘控制性能不足，现有缓存式MPC求解器计算需求过高，难以在资源受限的机器人上实现高控制频率。

🛠 **方法**：采用端到端协同设计，联合优化求解算法、数值表示、硬件映射与物理集成，将FPGA加速的ADMM-based MPC求解器与定制6g PCB结合，部署于35g Crazyflie无人机。

✨ **主要贡献**：实现1 kHz机载约束MPC（含动态障碍物），求解速度提升最高15.6倍，能量延迟积改善195.4倍，可扩展至超2万个优化变量及相当数量约束，并开源PCB设计、固件与FPGA求解器代码。

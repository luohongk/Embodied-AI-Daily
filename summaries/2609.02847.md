# RoGe: Novel View Synthesis via End-to-End Implicit Reconstruction and Generation

- arXiv: https://arxiv.org/abs/2609.02847v1
- arXiv ID: 2609.02847

---

🔍 **核心问题**：从稀疏视角合成新视图时，既要依赖观测视图的几何信息，又要生成未观测区域的合理内容，现有混合方法因使用有损的显式中间表示（如渲染图或3D点云）而累积误差，且重建与生成模块缺乏协同优化。

🛠 **方法**：提出RoGe框架，采用端到端联合训练的重建-生成架构——前馈重建模型构建隐式场景表示，直接以目标相机光线查询获得逐视图几何特征，并将其作为条件注入视频扩散模型，全程无显式3D中间体，使生成目标能反向优化几何条件。

✨ **主要贡献**：在DL3DV数据集上，RoGe在图像级指标和视频时间一致性上均优于重建、生成及混合基线；消融实验证明光线查询的隐式特征优于重建token和渲染RGB，且联合训练带来额外性能提升。

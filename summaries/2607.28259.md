# TopoFormer: Topology Meets Attention for Graph Learning

- arXiv: https://arxiv.org/abs/2607.28259v1
- arXiv ID: 2607.28259

---

🔍 **核心问题**：传统图神经网络难以捕捉多尺度拓扑结构，而持久同调方法计算成本高且难以并行化，限制了拓扑信息在图表示学习中的应用。

🛠 **方法**：提出Topoformer框架，其核心模块Topo-Scan通过节点或边过滤将图分解为有序的拓扑令牌序列，再交由Transformer处理生成图级嵌入，避免昂贵的图计算。

✨ **主要贡献**：Topo-Scan可并行化且与标准深度学习架构无缝集成，提供拓扑编码稳定性理论保证，在图分类和分子性质预测基准上达到或超越强基线，实现高效且可预测的计算性能。

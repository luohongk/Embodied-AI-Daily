# RMWorld: Task-Aware Radio World Models with Value-of-Information Guided Multi-Trial Learning for Multi-UAV Communication Control

- arXiv: https://arxiv.org/abs/2608.20126v1
- arXiv ID: 2608.20126

---

🔍 **核心问题**：多无人机通信控制中，无线信道模型（radio world model）的全局精度不足，导致在高需求走廊或关联边界处速率误差会反转控制决策，现有方法未针对任务风险进行校准。

🛠 **方法**：提出RMWorld框架，结合基于价值信息（value-of-information）的信道校准与可信度-多样性多试验选择；通过贝叶斯残差修正偏差传播公式，并利用任务门控的log-determinant目标选择反事实分支，辅以冲突投影和固定批次验证。

✨ **主要贡献**：推导了方差缩减恒等式，证明了后验任务风险等价性和子模贪心保证；在100组3GPP试验中达到0.949 bit/s/Hz任务加权RMSE，在30组DeepMIMO重载试验中中位积压降低0.967（相比Ensemble UCB，离线rollout增加37.5%）。

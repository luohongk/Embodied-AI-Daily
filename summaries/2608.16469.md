# Sterilizable Scene Graph Generation for Operating Rooms

- arXiv: https://arxiv.org/abs/2608.16469v1
- arXiv ID: 2608.16469

---

🔍 **核心问题**：手术视频场景图生成通常依赖大规模深度学习模型，难以在手术室（OR）中部署，受限于硬件体积、卫生要求、延迟和数据隐私。

🛠 **方法**：提出SG-NCA框架，基于神经细胞自动机（NCA），结合NCA多类分割进行目标检测与特征提取，并配以轻量级关系预测器，实现场景图生成。

✨ **主要贡献**：首次将NCA用于场景图生成，参数减少55倍，性能与现有基线相当；可在无风扇边缘设备上部署，并支持手术视频字幕等下游任务，适用于隐私保护且手术室就绪的术中理解。

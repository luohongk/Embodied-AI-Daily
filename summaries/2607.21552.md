# MIRROR: Learning from the Other View for Multi-Modal Reasoning

- arXiv: https://arxiv.org/abs/2607.21552v1
- arXiv ID: 2607.21552

---

🔍 **核心问题**：视觉-语言模型（VLM）在几何推理中，不同模态（文本、图像、图文结合）的表现不一致，标准多模态训练未能充分利用这种互补性。

🛠 **方法**：构建高质量配对多模态几何数据集ODA-Data，并提出MIRROR方法——通过强化学习，对每个问题评估所有模态的表现，选择最佳模态作为教师，用反向KL散度训练其他模态。

✨ **主要贡献**：MIRROR在几何推理基准上优于标准强化学习，显著提升了模型跨模态的准确性和一致性。

# FloAff-Kitchen: Bridging Navigation and Manipulation via Canonical and Progressive Floor Affordance Learning

- arXiv: https://arxiv.org/abs/2607.24207v1
- arXiv ID: 2607.24207

---

🔍 **核心问题**：移动操作机器人需要预测“地板可操作性”（Floor Affordance），以最大化下游操作任务的成功率，但现有方法因无关空间上下文和物体朝向导致表示模糊，且难以共享异构操作技能间的知识。

🛠 **方法**：提出统一框架，包括**规范地板可操作性表示（CFAR）**，通过保留与操作相关的局部几何结构并消除无关空间变化；以及**渐进式地板可操作性学习（PFAL）**，从基础操作任务学习可迁移先验，逐步适应异构下游技能。

✨ **主要贡献**：首次建立跨场景、多视角的FloAff-Kitchen基准，涵盖多种操作技能、场景布局和视角；实验表明该方法在三个基准设置中均优于强基线，消融研究验证了各组件的有效性。

# Gimbal-Based Human Tracking for Companion Robots Using Continual Learning

- arXiv: https://arxiv.org/abs/2608.21388v2
- arXiv ID: 2608.21388

---

🔍 **核心问题**：现有陪伴机器人的人体跟踪方法依赖可穿戴标签或固定视角相机，灵活性差，目标移出感知范围时容易跟踪失败。

🛠 **方法**：在移动机器人上集成云台相机，通过主动控制云台动态调整视角以保持目标在视野内；同时采用持续学习策略改进行人重识别（ReID），以适应长期跟踪中的外观和环境变化。

✨ **主要贡献**：显著提升了人体跟踪的稳定性与连续性，实现实时重识别，支持从走到跑的运动跟踪，并通过消除可穿戴标签需求提升了用户舒适度。

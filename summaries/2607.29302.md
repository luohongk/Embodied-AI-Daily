# BWM: A Low-Cost High-Fidelity World Simulator for Robot Learning

- arXiv: https://arxiv.org/abs/2607.29302v1
- arXiv ID: 2607.29302

---

🔍 **核心问题**：现有物理仿真器构建成本高且存在sim-to-real差距，视频生成器难以精确响应机器人细粒度动作，缺乏低成本、高保真的世界模拟器用于机器人学习。

🛠 **方法**：提出BWM（Boundless World Model），一种动作条件世界模型，结合初始环境引导、动态视觉历史和时序对齐的机器人动作条件，通过轨迹重放、重叠片段采样和初始观测增强构建训练数据，实现状态化自回归预测未来观测。

✨ **主要贡献**：BWM作为开源数据引擎和策略评估器，可增强模仿学习数据并支持闭环评估、风险预测和策略排序；在WorldArena基准和实体机器人上验证了高保真度和实用性，综合排名第一，并开源完整生态系统（模型、代码和接口）。

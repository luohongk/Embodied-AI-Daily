# Spectral-Aware Analytic Class-Incremental Learning for Long-Tailed Distributions

- arXiv: https://arxiv.org/abs/2607.22931v1
- arXiv ID: 2607.22931

---

🔍 **核心问题**：针对长尾分布下的类增量学习场景，现有解析持续学习方法因自相关矩阵病态导致尾部类别出现谱坍缩，无法有效区分尾部类别与噪声。

🛠 **方法**：提出几何-谱矫正框架，通过构造数据依赖的谱扰动矩阵，对各向异性谱滤波器选择性膨胀尾部类别的坍缩特征值，替代传统各向同性正则化。

✨ **主要贡献**：理论证明该方法能提升Gram矩阵的稳定秩，实验表明在长尾类增量学习中取得最优性能，同时保持解析方法的计算高效性。

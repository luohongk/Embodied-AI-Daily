# A Methodology for Selecting and Composing Runtime Architecture Patterns for Production LLM Agents

- arXiv: https://arxiv.org/abs/2605.20173v2
- arXiv ID: 2605.20173

---

🔍 **核心问题**：生产环境中的LLM代理将随机模型输出与确定性软件系统结合，但两者之间的边界未被作为一等架构对象对待，导致运行时可靠性难以保障。

🛠 **方法**：提出“随机-确定性边界”（SDB）作为核心架构原语，围绕协调、状态和控制三个关注点，设计六种运行时模式（如分层委派、散聚加Saga、事件驱动序列等），并给出五步模式选择方法论和故障诊断流程。

✨ **主要贡献**：首次将SDB定义为生产代理的负载支撑原语，提出“回放发散”故障模式，并通过可靠性分解论证模型方差降低后架构模式与SDB强度对长期可靠性的关键作用，附五个工作负载应用及一个可运行参考实现。

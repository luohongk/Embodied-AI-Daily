# Reasoning Without Inference Cost: Latent Semantic Scaffolding for Robot VLA Policies

- arXiv: https://arxiv.org/abs/2609.04893v1
- arXiv ID: 2609.04893

---

🔍 **核心问题**：VLA（视觉-语言-动作）模型通过模仿学习能预测动作，但缺乏因果推理能力，而现有引入推理的方法在推理时产生高昂计算成本，难以用于长时程任务。

🛠 **方法**：提出潜在语义脚手架（LSS），在人类演示预训练阶段添加辅助损失，通过小型投影头将VLA的动作token表示与物理推理文本的嵌入对齐，推理时丢弃投影头，不增加任何额外成本。关键设计是采用“密集LSS”，即每个动作token与其对应操作阶段的推理文本对齐，而非整段池化对齐。

✨ **主要贡献**：密集LSS在分布内任务和未见任务迁移上均取得最优性能，而池化对齐则过拟合训练任务；表征探针实验表明密集LSS使骨干网络各阶段的可分离性提升约两倍，验证了阶段局部对齐是核心机制。

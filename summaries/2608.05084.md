# Learning When to Stop: Prefix-Optimal Dynamic Diffusion Policies for Continuous Control

- arXiv: https://arxiv.org/abs/2608.05084v1
- arXiv ID: 2608.05084

---

🔍 **核心问题**：扩散策略在连续控制中因迭代去噪过程导致计算开销大，需在保持任务性能的同时减少去噪步数。

🛠 **方法**：提出Prefix-Optimal Generative Policies（POGP）框架，通过Bellman式递归学习每个中间去噪步骤的前缀价值函数，该函数既作为辅助训练目标提升中间输出质量，又作为测试时停止规则，在额外步骤无显著改进时提前终止去噪。

✨ **主要贡献**：在四个MuJoCo环境和12个基线对比中，POGP将所需去噪迭代次数减少约2.7倍，同时保持接近完整的任务性能；相比最先进的动态扩散基线，前缀训练还将最终任务性能提升约3.5%，表明监督中间去噪步骤不仅利于自适应早停，还能作为辅助目标改善策略学习。

# The Implications of Linguistic Illegibility for LLM Security

- arXiv: https://arxiv.org/abs/2609.02852v1
- arXiv ID: 2609.02852

---

🔍 **核心问题**：本文探讨了大型语言模型（LLM）的“语言不可读性”问题，即模型的外部语言输出或机制性提取的语言特征无法准确反映其内部真实计算，这导致依赖语言自报告的安全机制（如思维链监控、宪法自我批评、激活探针）存在根本性漏洞。

🛠 **方法**：作者提出，由于LLM内部计算本质上是激活空间上的数学运算，与自然语言之间存在有损转换，语言不可读性不可避免。为此，他们主张采用不依赖读取模型语言状态的隔离技术，重点推荐基于污点跟踪（taint tracking）的沙箱策略，并辅以稳健虚拟化、第三方审计等机制。

✨ **主要贡献**：首次系统定义了“语言不可读性”概念，论证了其对现有语言监控安全机制的局限；提出污点跟踪作为沙箱核心方案，可先验定义系统状态中不应受模型输出影响的部分；并综合多种隔离机制，为前沿模型的安全防护提供了超越语言监控的底层保障。

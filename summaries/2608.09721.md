# PET/CT Radiogenomic Mutation Prediction in Non-Small Cell Lung Cancer Using Multi-Label Learning

- arXiv: https://arxiv.org/abs/2608.09721v1
- arXiv ID: 2608.09721

---

🔍 **核心问题**：针对非小细胞肺癌（NSCLC），传统组织活检进行基因突变检测具有侵入性和局限性，本文探索能否利用PET/CT影像无创预测EGFR、TP53和KRAS三种基因突变，并评估多标签学习是否优于单基因分类。

🛠 **方法**：基于英国新型影像基因组学队列，采用深度学习模型对PET/CT影像进行放射基因组学分析，分别进行单基因分类和两两组合的多标签联合预测。

✨ **主要贡献**：首次系统研究多标签学习在PET/CT放射基因组突变预测中的应用。联合预测KRAS和TP53时，AUC分别从0.58提升至0.64（KRAS）和从0.69提升至0.71（TP53）；但EGFR/KRAS对仅EGFR获益，EGFR/TP53对无改善，表明多标签学习效果取决于具体基因组合，提示突变特异性建模策略可能更优。

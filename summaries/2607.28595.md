# Beacon: Knowing When and How to Perform Agentic Visual Reasoning

- arXiv: https://arxiv.org/abs/2607.28595v1
- arXiv ID: 2607.28595

---

🔍 **核心问题**：现有智能体视觉推理模型在工具使用上存在“模式适应性”不足和“工具效应”不佳的问题——模型难以判断何时真正需要工具，且工具带来的收益在简单问题上被引入的错误抵消。

🛠 **方法**：提出Beacon模型，在强化学习阶段引入“必要性感知自适应奖励”（Necessity-Aware Adaptive Reward）和“提示引导能力扩展机制”（Hint-Guided Capability Expansion），分别用于根据任务必要性自适应调用工具，并增强模型在最具挑战性问题上的工具使用能力。

✨ **主要贡献**：Beacon在多个基准上取得更强的整体性能，同时显著提升了模式适应性（更精准的工具调用时机）和工具效应（工具在困难问题上带来真实增益，且不损害简单问题的表现）。

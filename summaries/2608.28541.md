# An Enclosed Mode Is a Gauge Choice: Topology Relative to Reach in Certified Code World Models

- arXiv: https://arxiv.org/abs/2608.28541v1
- arXiv ID: 2608.28541

---

🔍 **核心问题**：论文探讨了在代码世界模型中，被采样门接受的模型在可达查询集上精确，但在不可达区域可能任意错误的问题，特别是环形冻结模式导致的拓扑误判及其代价。

🛠 **方法**：通过门商（gate quotient）形式化可达性与不可达性的边界，在最小环形仪器上证明极端案例，并用三种LLM模型家族合成实验，调节通道宽度γ观察错误模式变化，结合持续同调摘要和维度匹配的持久栅栏进行修复。

✨ **主要贡献**：提出“危险是相对于可达性的拓扑”原则，证明错误模式在不可达时不可证伪且无害、可达时有害；发现修复受参数和传感器限制，维度匹配的持久栅栏可将利用代价从0.999降至0.058，双自由度证书对称消除发明模式失败（1.769→0.029），并指出高维中壳层使误识别近乎必然但危险仍可完全利用。

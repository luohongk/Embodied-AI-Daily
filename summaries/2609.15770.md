# JEPLO: Joint-Embedding Predictive Learning for LiDAR-Based Legged Locomotion

- arXiv: https://arxiv.org/abs/2609.15770v1
- arXiv ID: 2609.15770

---

🔍 **核心问题**：现有腿足机器人感知运动多依赖RGB-D传感和显式建图，LiDAR方案探索不足，且在遮挡、稀疏和噪声等感知退化条件下鲁棒性差。

🛠 **方法**：提出JEPLO单阶段无建图学习框架，包含PE-JEPA世界模型（从原始LiDAR等本体/外部观测中学习预测性自我中心地形表征）和CJTS师生流水线（用深度强化学习训练由JEPA潜表征引导的运动策略）。

✨ **主要贡献**：实现仿真到现实的成功迁移，支持长楼梯、高箱等多样地形全向穿越，在感知退化条件下鲁棒性优于现有框架，并开源了实现、数据集与硬件设计。

# LT-Mem: Volatility-Aware Spatio-Temporal Memory for Lifelong Scene Understanding

- arXiv: https://arxiv.org/abs/2608.19059v1
- arXiv ID: 2608.19059

---

🔍 **核心问题**：长期运行的机器人在动态环境中进行场景理解时，会因覆盖历史信息或缺乏跨会话对象身份一致性，导致“时间性失忆”——无法回答如“绿色椅子在所有会话中出现在哪里”这类需要对象历史轨迹的问题。

🛠 **方法**：提出LT-Mem框架，结合多会话SLAM提供空间对齐的逐对象观测，并通过波动性感知策略（覆盖、保持、多假设）管理记忆演化，最终构建Live、Delta、Meta三部分记忆结构，同时保留当前状态与事件历史。

✨ **主要贡献**：引入LT-VQA数据集（含多会话记录、身份标注和时序问答），实验表明LT-Mem在所有指标上优于基线，且消耗的token数量少一个数量级；消融实验证实性能提升源于结构化记忆架构，而非LLM容量。

# UniMem: Unifying Multimodal Memory and Control for Vision-Language-Action Models

- arXiv: https://arxiv.org/abs/2608.22869v1
- arXiv ID: 2608.22869

---

🔍 **核心问题**：现有视觉-语言-动作（VLA）模型在处理需要记忆的非马尔可夫任务时表现不佳，而传统记忆方案依赖额外VLM导致训练流程割裂，固定间隔采样历史帧又会降低性能。

🛠 **方法**：提出UniMem框架，在单一骨干网络中统一高层多模态记忆与低层控制，包含事件分类器（触发记忆更新）、关键帧编码器（存储密集空间记忆）和关键帧缓存技术（减少推理开销）。

✨ **主要贡献**：在5个仿真和4个硬件任务上，UniMem显著优于固定间隔采样基线（仿真93.4% vs 68.2%）和分层基线（硬件80.0% vs 43.5%），同时推理更快、训练流程更简单，易于采用。

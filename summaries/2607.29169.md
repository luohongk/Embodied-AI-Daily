# ActFovea: Runtime Safeguarding for VLA Policies via Spatiotemporal Visual-Action Consistency

- arXiv: https://arxiv.org/abs/2607.29169v1
- arXiv ID: 2607.29169

---

🔍 **核心问题**：视觉-语言-动作（VLA）策略在机器人操作中易受运行时扰动影响，导致视觉观测、机器人状态与执行动作之间的时间对齐被破坏，引发任务失败。

🛠 **方法**：提出ActFovea，一种即插即用的守护框架，利用机器人运动学、本体感觉和近期动作构建动作条件化的中央凹区域，通过评估视觉运动与观测新鲜度是否与几何、本体感觉及动作转换一致来检测风险，并对可恢复扰动生成候选观测、验证动作块后恢复，否则触发有界安全失败。

✨ **主要贡献**：在多个LIBERO套件上对π₀策略的闭环评估中，ActFovea将局部视觉叠加下的成功率从49.3%提升至90.3%，弥合了93.7%的干净性能差距；在动作漂移和视觉延迟下分别提升7.0和9.8个百分点，同时保持干净任务性能；在冻结观测重放下所有试验均及时触发安全失败，无未保护失败，验证了时空视觉-动作一致性作为VLA策略运行时守护的有效基础。

# Bringing Value Models Back: Generative Critics for Value Modeling in LLM Reinforcement Learning

- arXiv: https://arxiv.org/abs/2604.10701v2
- arXiv ID: 2604.10701

---

🔍 **核心问题**：LLM强化学习中的信用分配问题——传统判别式价值模型难以可靠训练，且受限于单次预测范式，其表达能力不足以准确逼近价值函数。

🛠 **方法**：提出生成式演员-评论家（GenAC），用生成式评论家替代单次标量预测，通过思维链推理后再输出价值估计，并引入上下文条件化（In-Context Conditioning）使评论家在整个训练过程中与当前演员保持校准。

✨ **主要贡献**：GenAC提升了价值逼近、排序可靠性和分布外泛化能力，在下游RL任务中优于基于价值和无价值的基线，表明更强的价值建模是改进LLM强化学习信用分配的有前景方向。

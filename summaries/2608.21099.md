# A2DINOv3: Rethinking Multi-Modal Object Detection via Socialized Collaboration

- arXiv: https://arxiv.org/abs/2608.21099v1
- arXiv ID: 2608.21099

---

🔍 **核心问题**：多模态目标检测中，现有密集跨模态融合策略强制异质模态（如RGB与红外）无差别交互，导致冗余信息引入和预训练表征破坏，影响检测性能。

🛠 **方法**：提出A2DINOv3框架，采用多专家协作机制（Socialized Collaboration Protocol），将RGB和红外分支建模为独立专家，通过选择性、受限交互交换互补信息，并引入零初始化策略逐步激活跨模态协作，避免干扰并保留预训练知识。

✨ **主要贡献**：在四个多模态基准（GAIIC、FLIR、LLVIP、M3FD）上均取得最先进性能，验证了“社会化协作”思想在抑制模态干扰、平滑适应预训练模型方面的有效性，为多模态融合提供了新范式。

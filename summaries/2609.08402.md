# Towards Embodied Air-Ground Cooperative Object Search: Benchmark, Dataset and Agentic Method

- arXiv: https://arxiv.org/abs/2609.08402v1
- arXiv ID: 2609.08402

---

🔍 **核心问题**：本文研究城市环境中无人机与地面机器人协同的具身目标搜索任务（AGOS），即如何通过多视角视觉参考，让空中与地面机器人协作定位并验证指定目标车辆。

🛠 **方法**：提出了AGOS-Agent，一种无需训练、工具增强的智能体方法，通过“搜索-交接-验证”的协作协议，仅让视觉语言模型（VLM）负责场景理解与决策，从而简化复杂的动态协调过程。

✨ **主要贡献**：构建了首个AGOS专用基准AGOS-Bench及配套数据集AGOS-Dataset（含7.7k个跨难度场景），并在9种VLM上验证了AGOS-Agent的有效性——其中8种成功率提升、9种决策步骤减少，例如Gemini-3.6-Flash在困难子集上成功率从8.6%提升至55.7%。

# Lower Bounds for Private Graph Optimization Problems using Reconstruction Attacks

- arXiv: https://arxiv.org/abs/2609.10877v1
- arXiv ID: 2609.10877

---

🔍 **核心问题**：研究差分隐私下图优化问题（最小生成树、最小权完美匹配、层次聚类）在 $\ell_1$ 邻接关系下的误差下界，特别是近似 DP 能否降低误差。

🛠 **方法**：采用基于重构攻击（reconstruction attack）的技术，针对最坏情况图及具有扩展性质的稀疏图族推导下界，并推广到 Dasgupta 代价函数下的层次聚类问题。

✨ **主要贡献**：证明了 MST 和最小权完美匹配的紧误差下界 $Ω(n\log(m/n)/ε)$，改进了 Sealfon (PODS'16) 的 $Ω(n/ε)$ 结果；表明在 $\ell_1$ 邻接下近似 DP 无法降低 MST 误差（与 $\ell_\infty$ 邻接形成对比）；并给出层次聚类首个以平衡割最小权重为参数的近似 DP 下界。

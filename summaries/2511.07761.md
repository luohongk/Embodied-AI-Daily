# High-Altitude Balloon Station-Keeping with First Order Model Predictive Control

- arXiv: https://arxiv.org/abs/2511.07761v2
- arXiv ID: 2511.07761

---

🔍 **核心问题**：高空气球（HAB）在部分可观测风场中执行定点保持（station-keeping）时，因系统非线性、欠驱动且模型复杂，传统模型控制被认为不实用，而现有强化学习方法缺乏与模型基方法的公平对比。

🛠 **方法**：提出一阶模型预测控制（FOMPC），将气球动力学和风场建模为JAX中的可微函数，利用梯度优化进行在线轨迹规划，无需离线训练。

✨ **主要贡献**：FOMPC在时间半径内（TWR）指标上比最先进的强化学习策略提升24%，且对简化风场和动力学模型具有鲁棒性；尽管在线计算成本更高，但证明了模型基控制在定点保持中的有效性，挑战了“模型方法不实用”的假设。

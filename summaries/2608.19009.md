# Grading the Graders: Verification Autonomy Levels (L0-L5) for LLM Reasoning

- arXiv: https://arxiv.org/abs/2608.19009v1
- arXiv ID: 2608.19009

---

🔍 **核心问题**：现有文献中“验证级别”一词含义混乱，缺乏统一标准来评估LLM推理验证器的能力边界，尤其是验证的完整性与保证强度。

🛠 **方法**：提出验证自主级别（VAL）元标准，沿单一轴（验证规范的来源及结论保证）将验证方案分为L0-L5六级，并系统分析各领域验证器的能力上限。

✨ **主要贡献**：首次明确“完整性盲点”问题（替代/采样验证无法证明无遗漏），揭示形式化可验证属性与经验开放世界验证之间的根本二分法，并厘清粒度、概念层级、风险等维度与VAL的正交性，解决17篇论文中的概念混淆。

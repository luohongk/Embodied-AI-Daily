# DINO-VPT: Hierarchical Visual Prompt Tuning for Joint Physical-Digital Face Anti-Spoofing

- arXiv: https://arxiv.org/abs/2607.20900v1
- arXiv ID: 2607.20900

---

🔍 **核心问题**：现有统一人脸防伪（FAS）模型需同时检测物理和数字攻击，但依赖复杂的多模态融合和外部文本编码器，效率较低。

🛠 **方法**：提出轻量级纯视觉框架DINO-VPT，通过提示路由网络（PRN）动态注入基于输入特征的层次化视觉提示，无需多模态融合即可解耦不同伪造痕迹。

✨ **主要贡献**：在UniAttackData基准上，DINO-VPT以纯视觉架构超越基于视觉-语言模型（VLM）的最优方法，证明无需多模态监督即可实现统一FAS的顶尖性能。

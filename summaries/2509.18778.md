# VGGT-DP: Generalizable Robot Control via Vision Foundation Models

- arXiv: https://arxiv.org/abs/2509.18778v2
- arXiv ID: 2509.18778

---

🔍 **核心问题**：现有视觉模仿学习框架忽视视觉编码器的结构与容量，导致机器人在空间理解和泛化能力上受限，尤其在精确控制和长时程任务中表现不佳。

🛠 **方法**：提出VGGT-DP框架，采用预训练3D感知模型VGGT作为视觉编码器，结合本体感觉反馈设计“本体感觉引导的视觉学习策略”，并引入帧间令牌复用（FTR）机制减少推理延迟，同时应用随机令牌剪枝增强鲁棒性。

✨ **主要贡献**：在MetaWorld挑战性任务上，VGGT-DP显著优于DP和DP3等强基线，尤其在精度关键和长时程场景中表现突出，验证了几何先验与本体感觉融合对提升机器人控制泛化能力的有效性。

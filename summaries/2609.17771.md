# HINT-Plan: Human Intention-Aware Robot Task Planning in Context-Rich Environments using Vision Language Models

- arXiv: https://arxiv.org/abs/2609.17771v1
- arXiv ID: 2609.17771

---

🔍 **核心问题**：现有移动机器人的人类感知决策主要局限于低层运动规划中的避障，忽视了人类存在及高层行为对机器人任务规划带来的挑战。

🛠 **方法**：提出 HINT-Plan，利用视觉语言模型（VLM）从第三人称图像中预测人类高层意图，将其转化为目标状态，并结合分层场景图（SG）将环境拓扑与可操作知识转化为形式化规划语言，求解人机联合任务规划问题。

✨ **主要贡献**：在逼真仿真中实现 69.71% 的联合任务规划成功率，较基线最高提升 35.29%，同时减少功能冲突，验证了将推断的人类意图显式纳入多智能体形式化任务规划对主动式人类感知机器人决策的有效性。

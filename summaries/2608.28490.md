# LLM-Based Agents for Software and Systems Security: Approaches, Applications, and Assessment

- arXiv: https://arxiv.org/abs/2608.28490v1
- arXiv ID: 2608.28490

---

🔍 **核心问题**：系统梳理基于大语言模型（LLM）的智能体在软件与系统安全领域的构建、应用与评估现状，揭示该领域缺乏统一术语、风险差异大、评估协议不可比的问题。

🛠 **方法**：对2023–2026年间同行评审文献进行系统性综述，从技术方法（架构、感知、记忆、推理规划、行动空间、编排、自我改进）、应用场景（安全任务类型）和评估体系（数据集、结果/轨迹指标、安全措施、基线）三个维度分类分析。

✨ **主要贡献**：首次系统化整合该领域知识，指出当前智能体虽具备行动能力，但缺乏权限边界约束与行为可审计性；同时总结现有方法、应用和评估设计的局限与挑战，为未来研究指明方向。

# Stein Variational Uncertainty-Adaptive Model Predictive Control

- arXiv: https://arxiv.org/abs/2604.01034v3
- arXiv ID: 2604.01034

---

🔍 **核心问题**：针对具有潜在参数不确定性的非线性动态系统，解决传统鲁棒控制中保守性过强、牺牲标称性能的问题。

🛠 **方法**：提出Stein变分分布鲁棒模型预测控制，将最优控制与Stein变分推断结合，通过确定性粒子近似任务相关的不确定性分布，避免对不确定性模型施加参数限制，同时保持计算并行性。

✨ **主要贡献**：在单一决策理论框架下统一鲁棒控制与变分推断，通过聚焦对闭环性能影响最关键的参数敏感性来塑造控制律，在代表性控制问题上实现了比标称、集成和经典分布鲁棒基线更优的性能-鲁棒性权衡。

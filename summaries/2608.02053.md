# Protocol generalisation for brain tissue microstructure estimation via hypernetwork-controlled geometric deep learning

- arXiv: https://arxiv.org/abs/2608.02053v1
- arXiv ID: 2608.02053

---

🔍 **核心问题**：现有机器学习方法在脑组织微结构估计中缺乏对扩散MRI采集协议（尤其是b值）的泛化能力，且难以同时保证旋转等变性。

🛠 **方法**：提出一种基于超网络（hypernetwork）控制的球形卷积神经网络（SCNN），将b值作为显式输入嵌入网络，实现跨b值的协议泛化，同时保留SCNN固有的旋转等变性和b-vector泛化能力。

✨ **主要贡献**：首次在SCNN中引入b值依赖，实现同时跨b值和b-vector的泛化；在合成和真实数据上均显著降低RMSE和偏差，与常规NODDI拟合一致性更高，减少了对未知b值的重训练需求，提升了深度学习在临床dMRI参数估计中的实用性。

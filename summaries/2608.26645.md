# FLARE: A Failure-Aware Framework for Autonomous Correction and Recovery in Visual-Language Robotic Manipulation

- arXiv: https://arxiv.org/abs/2608.26645v1
- arXiv ID: 2608.26645

---

🔍 **核心问题**：视觉-语言-动作模型（VLA）在复杂长程机器人操作任务中泛化能力强，但依赖无失败的完美演示数据，导致无法从常见执行错误（如抓取失败、物体掉落、意外碰撞）中恢复。

🛠 **方法**：提出FLARE框架，采用“重试”（Retry）与“重置”（Reset）双机制。Retry通过在演示中注入扰动和桥接片段，解耦机器人位姿与环境状态，使策略自主处理执行偏差；Reset利用多模态大语言模型（MLLM）离线分析执行视频，自动识别分布外（OOD）状态，并针对性收集少量以物体为中心的“重置”技能库，训练策略将环境恢复至有效状态。推理时，在线MLLM监控器仲裁任务执行与重置技能的选择。

✨ **主要贡献**：在接触密集的挑战性操作任务上，FLARE显著提升了任务成功率与鲁棒性，首次将“重试-重置”范式系统性地引入VLA错误恢复，并实现了OOD失败状态的自动化识别与技能学习。

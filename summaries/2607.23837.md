# Latent-LoRA: Compact Latent-Space Adapters with Gradient-Free Routing for Continual Learning

- arXiv: https://arxiv.org/abs/2607.23837v1
- arXiv ID: 2607.23837

---

🔍 **核心问题**：解决大语言模型在顺序学习多个任务时出现的灾难性遗忘问题，现有LoRA方法要么需要任务身份信息，要么引入可训练门控模块导致自身易遗忘。

🛠 **方法**：提出Latent-LoRA，利用冻结LLM嵌入层的池化token嵌入拟合高斯混合模型实现无梯度路由，并通过SVD将任务参数约束在预训练权重的低维子空间内，施加正交正则化控制任务间干扰。

✨ **主要贡献**：无需重放、无需可训练路由模块，每任务参数更少；在五个模型规模和两个基准上实现接近零遗忘的最优性能。

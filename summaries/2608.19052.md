# Malformer: A Multi-Modal Malware Detector Using Transformers

- arXiv: https://arxiv.org/abs/2608.19052v1
- arXiv ID: 2608.19052

---

🔍 **核心问题**：传统基于单一表征（模态）的恶意软件检测系统难以识别新型威胁，且依赖反汇编等易失败步骤，导致检测泛化能力不足。

🛠 **方法**：提出Malformer，一种四模态（文本、图像、图、音频）融合的恶意软件检测模型，采用两个RoBERTa编码器处理文本与图数据、改进的Vision Transformer处理图像、WavLM处理音频，并通过自适应损失加权机制融合各模态特征。

✨ **主要贡献**：在201,549个样本数据集上达到98.3%准确率和0.9833的F1分数，比单模态和双模态检测器提升4.6-17.6个百分点，证明多模态融合能显著增强恶意软件检测的泛化性和鲁棒性。

# EMemBench: Interactive Benchmarking of Episodic Memory for VLM Agents

- arXiv: https://arxiv.org/abs/2601.16690v2
- arXiv ID: 2601.16690

---

🔍 **核心问题**：现有基准难以评估视觉语言模型（VLM）智能体的长期情景记忆能力，缺乏可扩展且可验证的评测方法。

🛠 **方法**：提出EMemBench，一种程序化基准生成器，通过交互式游戏（含纯文本和视觉环境）从环境轨迹自动生成问题，覆盖单/多跳回忆、归纳、时间、空间、逻辑和对抗性记忆技能，并基于游戏信号计算可验证的ground truth。

✨ **主要贡献**：实验表明现有强模型（含VLM）在EMemBench上远未饱和，归纳和空间推理是持续瓶颈，尤其在视觉场景中；持久记忆对文本游戏有提升，但对VLM智能体效果不稳定，揭示视觉情景记忆仍是开放挑战。此外，人类研究验证了基准的难度与可解释性。

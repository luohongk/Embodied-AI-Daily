# Nova: An End-to-End MLIR Compiler for Deep Learning

- arXiv: https://arxiv.org/abs/2608.00029v1
- arXiv ID: 2608.00029

---

🔍 **核心问题**：深度学习模型在硬件上的高效映射不足，现有框架（如PyTorch）缺乏全局图优化和细粒度硬件控制，导致计算性能和内存利用不理想。

🛠 **方法**：设计Nova，一个端到端JIT编译器，通过捕获eager执行并统一前向/反向传播为单一值语义方言，实现全图优化；利用Analytic Configurator基于算术强度确定性推导最优执行调度（零搜索时间），并结合结构哈希运行时直接从计算结构合成细粒度内核。

✨ **主要贡献**：在RTX 3060上，Nova在TF32矩阵乘法上匹配或略优于cuBLAS和XLA（相对误差<5e-4）；模型级吞吐量比PyTorch高10.6%、比XLA高4.4%；内存占用比PyTorch降低29%，成功在12GB GPU上训练1.44亿参数模型（17,900 tokens/s），而PyTorch在此场景下OOM失败。

# Deep Learning-Based Estimation of Ground Reaction Forces in Parkinsonian Gait Using an Optimized Set of IMU Data

- arXiv: https://arxiv.org/abs/2608.02408v1
- arXiv ID: 2608.02408

---

🔍 **核心问题**：帕金森病（PD）步态分析通常依赖实验室设备测量地面反作用力（GRFs），而现有可穿戴方案需佩戴多个传感器，且深度学习尚未被用于解决病理步态中GRF估计的挑战。

🛠 **方法**：提出一种混合CNN-BiLSTM深度学习框架，利用优化后的IMU传感器配置估计双侧垂直地面反作用力（vGRFs），分别对61名PD患者和65名健康对照（HC）的数据进行训练。

✨ **主要贡献**：首次将深度学习用于PD步态vGRF估计，实现高精度（受试者内$R^2$=0.98，受试者间HC为0.93、PD为0.91）；发现传感器配置显著影响精度，PD最优需4个IMU，但仅用2个IMU仍可稳健估计，为可穿戴步态分析系统提供了实用且可扩展的方案。

# ODEWorld: A Continuous Predictive Architecture via Physical-Time Flow

- arXiv: https://arxiv.org/abs/2607.27924v1
- arXiv ID: 2607.27924

---

🔍 **核心问题**：现有世界模型大多基于离散时间预测，难以高效捕捉物理世界中连续时空的动态变化，且常面临表征崩溃问题。

🛠 **方法**：提出物理时间流（PT-Flow），在结构化表征空间中用常微分方程（ODE）参数化序列数据的潜在动力学，并通过ODE求解器在压缩潜在空间中进行时间积分实现预测，构建了连续时间潜在世界模型ODEWorld。

✨ **主要贡献**：ODEWorld通过提取时变特征并强制ODE属性，解决了表征崩溃问题，支持任意时间分辨率、长时预测和反向预测，同时兼顾视觉重建质量与规划信息，在视频生成和机器人控制任务中均表现优异。

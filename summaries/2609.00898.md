# Vision-Language-Guided Pseudo-Labels for Unsupervised Domain Adaptation in Semantic Segmentation for Waste Sorting

- arXiv: https://arxiv.org/abs/2609.00898v1
- arXiv ID: 2609.00898

---

🔍 **核心问题**：在语义分割任务中，获取目标域标注成本高昂且难以规模化，尤其在工业垃圾分拣等实际场景中，如何实现无监督域适应（UDA）而不依赖任何目标域标注。

🛠 **方法**：提出一种跨模态伪标签生成流水线，基于SAM生成类别无关的区域提议，EVA-CLIP根据区域-文本相似度分配语义标签，并通过置信度过滤筛选可靠伪标签用于分割模型的自训练；可选扩展BLIP对模糊区域进行语言验证以提升伪标签质量。

✨ **主要贡献**：在合成到真实自动驾驶和实验室到工厂垃圾分拣两个域偏移任务上，该方法持续优于源域基线；实验表明伪标签质量（而非数量）是域适应自训练的决定性因素，且跨模态语言接地为部署关键场景提供了可靠的自动标注路径。

# QuASH: Using Natural-Language Heuristics to Query Visual-Language Robotic Maps

- arXiv: https://arxiv.org/abs/2510.14546v2
- arXiv ID: 2510.14546

---

🔍 **核心问题**：在视觉-语言模型构建的机器人地图中，如何根据自然语言查询准确判断环境中哪些部分与查询相关，从而实现高效的任务执行。

🛠 **方法**：利用查询词在嵌入空间中的同义词和反义词，应用启发式规则估计与查询相关的语言空间，并训练一个分类器将环境划分为匹配与非匹配区域。

✨ **主要贡献**：提出了一种与具体表示和编码器无关的查询技术，仅需少量训练即可显著提升地图和标准图像基准的查询能力，实验验证了其有效性和通用性。

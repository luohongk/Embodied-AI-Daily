# EgoGenesis: Egocentric World-Action Modeling with Online Anchored Projective Memory and Action-3D RoPE

- arXiv: https://arxiv.org/abs/2607.28243v1
- arXiv ID: 2607.28243

---

🔍 **核心问题**：第一人称（egocentric）视频数据稀缺，难以覆盖多样场景、物体、动作和本体，限制了具身智能体的世界-动作模型（WAM）泛化能力。

🛠 **方法**：提出EgoGenesis，基于预训练视频生成先验，引入两种几何感知条件机制——在线锚定投影记忆（OAPM）保留首帧3D场景锚点并周期性刷新近期状态，以及动作-3D旋转位置编码（A3D-RoPE）将末端执行器运动编码为相机感知的3D旋转坐标，注入骨架到视频的交叉注意力中。

✨ **主要贡献**：在长序列第一人称视频生成中显著提升视觉保真度、几何稳定性和动作对齐；用400条生成轨迹增强真实数据后，单臂任务真实机器人成功率从77%提升至84%，双臂任务从53%提升至70%，证明合成数据有效改善下游WAM泛化。

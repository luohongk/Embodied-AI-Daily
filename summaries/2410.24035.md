# A context-adaptive policy framework for robust and reactive robotic manipulation via uncertainty-aware imitation learning

- arXiv: https://arxiv.org/abs/2410.24035v2
- arXiv ID: 2410.24035

---

🔍 **核心问题**：现有基于动态系统的模仿学习方法虽能生成鲁棒的机器人操作策略，但缺乏对任务相关环境参数的灵活适应能力，难以应对动态变化的上下文信息。

🛠 **方法**：提出一种上下文自适应策略框架，通过模仿学习获取依赖机器人状态和低维任务参数的策略，并采用混合专家模型融合不确定性感知策略，以提升对分布外场景的鲁棒性和收敛性能。

✨ **主要贡献**：首次将任务参数化、鲁棒性与反应式操作结合，在LASA数据集和真实7自由度机器人上验证了该方法在力条件抓取、柔性物体操作及物体中心抓取中的有效性。

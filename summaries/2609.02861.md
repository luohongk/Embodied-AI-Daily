# Towards Trustworthy Autonomous Robots: An Explainable AI-Based Decision Framework

- arXiv: https://arxiv.org/abs/2609.02861v1
- arXiv ID: 2609.02861

---

🔍 **核心问题**：深度学习驱动的自主机器人在事故调查中缺乏可审计性，无法追溯系统做出特定决策的原因，难以满足高风险AI系统的透明性要求。

🛠 **方法**：提出TRACE决策框架，将决策过程组织为四个可审计层（语义感知、信念推理、动作合成、执行验证），通过文档化因果链将每个自主行动追溯到传感器证据，并兼容CNN、Transformer等学习型感知模块。

✨ **主要贡献**：在仓库机器人导航的500次模拟决策中，实现98.6%证据可追溯性、99.0%时间连续性和98.1%决策可重构性；相比LIME等事后解释方法，提供了决策级重构所需的工件结构，并满足欧盟AI法案对高风险系统的透明度要求。

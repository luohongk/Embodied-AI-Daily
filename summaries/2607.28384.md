# When Specifications Conflict: A Symmetry-Based Framework for Measuring LLM Preferences

- arXiv: https://arxiv.org/abs/2607.28384v1
- arXiv ID: 2607.28384

---

🔍 **核心问题**：大型语言模型（LLM）在面临多个相互冲突的信息源（如自然语言、形式语言等）时，如何解决这些冲突，以及模型偏好是否存在系统性规律。

🛠 **方法**：提出一个基于对称性设计的可控实验框架，通过构造显式冲突的规格说明，直接观察模型在竞争规格之间的选择，并系统比较四种表示类型（纯自然语言、形式语言、自然化形式语言、输入-输出示例）的偏好。

✨ **主要贡献**：在包含550个冲突实例、11个函数族的数学基准上，发现模型偏好呈系统性排序（形式语言≈自然化形式语言>纯自然语言>输入-输出示例），且示例效果依赖模型能力和函数族；框架还扩展到布尔代数、代码生成和临床领域的异构冲突，展示了其跨任务通用性。

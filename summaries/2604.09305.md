# VAGNet: Vision-based Accident Anticipation with Global Features

- arXiv: https://arxiv.org/abs/2604.09305v4
- arXiv ID: 2604.09305

---

🔍 **核心问题**：现有基于行车记录仪视频的事故预测方法依赖逐目标特征提取，计算开销大，难以满足实时性要求。

🛠 **方法**：提出VAGNet深度神经网络，利用视觉基础模型VideoMAE-V2提取交通场景全局特征，结合Transformer和图模块进行事故预测，无需显式目标级特征。

✨ **主要贡献**：在DAD、DoTA、DADA和Nexar四个基准数据集上，VAGNet在平均精度上优于现有方法，同时计算效率更高；在多数数据集上平均事故提前时间（mean time-to-accident）更高，其余数据集上性能相当。

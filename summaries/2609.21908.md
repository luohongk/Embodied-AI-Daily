# CommitFlow: Semantic Commitment Verification and Local Correction for Long-Horizon Robot Manipulation VLA Execution

- arXiv: https://arxiv.org/abs/2609.21908v1
- arXiv ID: 2609.21908

---

🔍 **核心问题**：长程机器人操作中，VLA策略可能在所需物理效果尚未建立时就推进到下一阶段，导致语义承诺与实际物理状态不匹配，局部偏差累积引发任务失败。

🛠 **方法**：提出CommitFlow闭环执行框架，在冻结基础策略的前提下集成三个组件——语义承诺监控器（SCM）检测阶段条件是否满足并阻止依赖动作、BoundaryFlow基于当前状态和基础动作生成局部修正、关系与增益校准（RGC）选择满足约束的最小修正强度。

✨ **主要贡献**：在RoboTwin 2.0的十项基准任务上平均成功率达75.9%，较基础策略pi0.5提升22.7%，且跨策略实验均取得一致增益，为实现可靠的长程机器人执行提供了有效方案。

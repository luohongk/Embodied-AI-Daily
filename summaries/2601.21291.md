# Gaussian Belief Propagation Network for Depth Completion

- arXiv: https://arxiv.org/abs/2601.21291v3
- arXiv ID: 2601.21291

---

🔍 **核心问题**：深度补全任务中，稀疏且不规则的深度输入在深度网络中难以有效处理，尤其在高稀疏度下性能受限。

🛠 **方法**：提出高斯置信传播网络（GBPN），将深度学习与概率图模型结合，由GMCN动态构建场景特定的马尔可夫随机场（含自适应非局部边），再通过增强的高斯置信传播（串并行消息传递）推断稠密深度分布。

✨ **主要贡献**：实现端到端深度补全，能捕捉长程空间依赖并有效传播稀疏测量信息，在NYUv2和KITTI上达到SOTA，且在不同稀疏度、稀疏模式和数据集上表现出优越的鲁棒性与泛化能力。

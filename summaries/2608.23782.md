# GAP-Prompt: Gated Adaptive Prompting for Efficient Continual Learning

- arXiv: https://arxiv.org/abs/2608.23782v1
- arXiv ID: 2608.23782

---

🔍 **核心问题**：持续学习中灾难性遗忘问题，现有基于提示的方法采用静态任务级策略，忽略了任务内样本的细粒度差异。

🛠 **方法**：提出GAP-Prompt，包含三个模块：实例条件门控（动态选择每个图像的提示注入层）、动态知识融合（实例感知地聚合当前与历史提示）、共享提示蒸馏（在早期共享层锚定基础知识以缓解遗忘）。

✨ **主要贡献**：在CIFAR-100、ImageNet-R和CUB-200上达到最先进性能，尤其在细粒度CUB-200上准确率达87.29%，接近联合训练上限（88.00%），显著优于现有方法。

# LaRec: Unleashing LLM-based Latent Reasoning for Generative Recommendation

- arXiv: https://arxiv.org/abs/2607.24617v1
- arXiv ID: 2607.24617

---

🔍 **核心问题**：现有基于大语言模型的推荐方法依赖显式思维链，导致推理文本冗长、响应效率低；而潜在推理面临监督信号稀疏和单一推理路径无法探索用户多样化兴趣的问题。

🛠 **方法**：提出LaRec框架，包含两个阶段：1）潜在预训练，通过步骤级对齐和过程方向对齐为潜在空间推理提供丰富监督信号；2）个性化强化学习微调，基于用户历史兴趣构建高斯混合分布，随机采样不同推理起点以探索多条潜在推理路径。

✨ **主要贡献**：在多个数据集上显著优于现有基线方法，同时保持高效推理，首次将潜在推理有效应用于生成式推荐，平衡了效率与推荐多样性。

# Temporal-Distance JEPA: Plan-Aware Representation Learning for Latent World Model Predictive Control

- arXiv: https://arxiv.org/abs/2607.25337v1
- arXiv ID: 2607.25337

---

🔍 **核心问题**：现有JEPA世界模型在规划时依赖嵌入空间的欧氏距离作为目标进度度量，但该度量是表征学习的副产品，未能从离线数据中挖掘出有向的时间进度成本，导致训练与规划之间存在差距。

🛠 **方法**：提出TD-JEPA，保留LeWM的编码器-预测器结构，从无奖励轨迹中挖掘有向时间成本：利用同轨迹步序作为正样本、跨轨迹对作为启发式负样本，并引入滚动一致性项匹配规划器视野，同时将挖掘的成本作为规划度量与表征学习信号。

✨ **主要贡献**：在锁定评估下，TD-JEPA在Two-Room任务中成功率提升至100.0%（LeWM为97.4%），在OGB-Cube上提升14.2个百分点，在Push-T任务中也有改进；消融实验验证了有向头、跨轨迹负样本和滚动一致性各自的有效性，缩小了JEPA世界模型训练与规划之间的差距。

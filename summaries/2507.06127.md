# PrefixAgent: An LLM-Powered Design Framework for Efficient Prefix Adder Optimization

- arXiv: https://arxiv.org/abs/2507.06127v2
- arXiv ID: 2507.06127

---

🔍 **核心问题**：前缀加法器设计空间随位宽指数增长，现有优化方法在性能、泛化性和可扩展性上存在局限。

🛠 **方法**：提出PrefixAgent框架，将优化问题分解为骨干合成和结构细化两个子任务，利用LLM通过函数调用迭代优化，并基于e-graph的重写与等式饱和能力生成大规模高质量训练数据，对LLM进行微调。

✨ **主要贡献**：首次将LLM与EDA反馈结合用于前缀加法器优化，显著缩小搜索空间；实验表明在几乎所有配置下合成面积均优于基线方法，且位宽越大优势越明显，并兼容商业EDA流程。

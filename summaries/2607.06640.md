# What a World Model Represents Is Three Questions

- arXiv: https://arxiv.org/abs/2607.06640v2
- arXiv ID: 2607.06640

---

🔍 **核心问题**：本文探讨世界模型如何通过不同训练路径（如重建、循环状态、时间滤波、任务监督）获取任务相关信息，并区分“信息是否可达”“是否被纳入潜在表示”“由哪条路径承载”这三个关键问题。

🛠 **方法**：在已知所需坐标的环境中，通过控制训练信号（如重建、预测、奖励/价值头）的数量和类型，测试潜在表示中方向的可达性、可接纳性及路径分配，并比较不同训练路径单独或组合时的效果。

✨ **主要贡献**：提出“可达性、接纳性、分配性”三问框架，证明训练信号的数量决定可安装的坐标数，且可达不等于接纳（如时序二阶矩在下一词预测中可能缺失），路径分配不随移除代价反转而改变，揭示了世界模型表示的本质机制。

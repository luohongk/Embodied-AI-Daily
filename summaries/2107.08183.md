# Hierarchical Reinforcement Learning with Optimal Level Synchronization Based on Flow-Based Deep Generative Model

- arXiv: https://arxiv.org/abs/2107.08183v2
- arXiv ID: 2107.08183

---

🔍 **核心问题**：在分层强化学习（HRL）中，高层策略训练面临非平稳性问题，现有离线策略校正方法采用间接概率方式，无法准确捕捉低层策略的当前能力，限制了训练效果。

🛠 **方法**：提出基于流式深度生成模型（FDGM）的HRL模型，利用FDGM的逆操作实现直接离线策略校正，使高层目标与低层策略的当前能力对齐，并克服了FDGM在HRL中的适用性限制。

✨ **主要贡献**：通过直接校正策略分布，提升了高层策略训练的有效性；在基准环境实验中，该模型性能优于现有方法。

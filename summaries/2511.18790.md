# RoguePrompt: Dual-Layer Ciphering for Self-Reconstruction to Circumvent LLM Moderation

- arXiv: https://arxiv.org/abs/2511.18790v3
- arXiv ID: 2511.18790

---

🔍 **核心问题**：现有越狱攻击多为单步变换，对当前先进大语言模型（LLM）的绕过效果不稳定，缺乏对多阶段提示变换攻击的理解。

🛠 **方法**：提出RoguePrompt自动化越狱流水线，采用双层提示变换（ROT-13和Vigenère嵌套编码）并附加自然语言解码指令，将禁止提示转换为看似无害的查询，在单次交互中诱导模型重建并执行原始意图。

✨ **主要贡献**：在黑盒威胁模型下，对313个真实被拒提示测试，平均实现93.93%的过滤绕过、79.02%的指令重建和70.18%的执行成功率，验证了分层编码的有效性，并强调需开发新型防御以检测自重建型越狱攻击。

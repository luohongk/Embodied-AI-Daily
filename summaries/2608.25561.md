# EgoArgus: Benchmarking VLMs as Situational Assistants for Modality-Grounded User Supports

- arXiv: https://arxiv.org/abs/2608.25561v1
- arXiv ID: 2608.25561

---

🔍 **核心问题**：现有具身智能基准测试主要孤立评估视觉理解能力，未检验视觉大模型（VLMs）在视觉信息与用户语言提示存在帮助、无关或冲突时，能否正确仲裁并决定何时介入。

🛠 **方法**：构建了EgoArgus，一个人工标注数据集，覆盖五种对话-视频日常场景，用于评估具身助手在理解与决策任务上的表现。

✨ **主要贡献**：实验表明当前VLMs作为可靠具身助手仍具挑战，需识别可信模态并判断干预时机；进一步分析发现现有模态偏差缓解方法效果有限，为部署VLMs作为日常助手提供了实践洞见。

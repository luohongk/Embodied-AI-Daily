# TASTE: Throughput-Aware Batch Size Tuning for On-Device Edge Learning

- arXiv: https://arxiv.org/abs/2609.07444v1
- arXiv ID: 2609.07444

---

🔍 **核心问题**：在资源受限的边缘设备上进行深度学习模型微调时，如何在不牺牲预测精度的前提下最大化训练吞吐量。

🛠 **方法**：提出一种基于贝叶斯优化的批量大小自动调整技术，结合梯度累积和线性学习率缩放，用于边缘设备上的模型训练。

✨ **主要贡献**：实验发现存在吞吐量上限，超过后增大批量无益；所提方法在Raspberry Pi 4等平台上实现高达2倍的训练吞吐量提升，且不损失精度；在持续学习场景中，最优批量大小能有效维持稳定性-可塑性平衡，缓解灾难性遗忘。

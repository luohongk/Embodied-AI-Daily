# DB-VIO: Dual-Branch Visual Inertial Odometry with Enhanced Visual-Inertial Representation

- arXiv: https://arxiv.org/abs/2607.22123v1
- arXiv ID: 2607.22123

---

🔍 **核心问题**：现有学习型视觉惯性里程计（VIO）方法使用统一的视觉-惯性表示和单一时序模型，难以捕捉旋转与平移的异质动态，且单目视觉缺乏几何结构、原始惯性编码隐含旋转运动学信息，导致旋转相关特征弱化。

🛠 **方法**：提出DB-VIO双分支框架，通过引入深度线索增强单目视觉感知，注入显式积分姿态先验强化旋转感知的惯性表示，并将位姿估计解耦为独立的旋转分支和平移分支，分别进行运动特定时序建模。

✨ **主要贡献**：在KITTI和EuRoC基准上分别提升基线20%和33%，尤其在EuRoC敏捷运动场景中旋转指标提升65.7%，验证了跨平台和运动场景的有效性与泛化性。

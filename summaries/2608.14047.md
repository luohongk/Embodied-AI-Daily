# Evolve Vision-Language-Action Model into an Agent with On-the-fly Tool-use

- arXiv: https://arxiv.org/abs/2608.14047v1
- arXiv ID: 2608.14047

---

🔍 **核心问题**：现有端到端视觉-语言-动作（VLA）模型在复杂真实场景中泛化能力差、数据依赖性强，且动作解空间过大导致训练效率低。

🛠 **方法**：提出ART（Agentic Robot with Tool-use）框架，通过工具注入机制，将VLA模型与现成的工具模块（如低层视觉、高层可负担性、具身增强）结合，将连续动作解空间分解为工具调用的离散决策，并设计长轨迹工具推理训练方案。

✨ **主要贡献**：仅用30K轨迹数据（远小于基线）即实现模拟与真实任务（如暗光下新视角抓取）成功率比主流基线高20%；验证了模块化工具利用带来的高效训练、轻量部署和可扩展性，为VLA系统在复杂场景中的实际部署提供了新路径。

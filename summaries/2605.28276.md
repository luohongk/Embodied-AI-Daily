# Commit to the Bit: Reactive Reinforcement Learning Done Right

- arXiv: https://arxiv.org/abs/2605.28276v2
- arXiv ID: 2605.28276

---

🔍 **核心问题**：在非马尔可夫环境中（如部分可观测或状态特征受限），如何学习最优反应式策略，而传统强化学习算法通常依赖马尔可夫假设。

🛠 **方法**：提出Committed Q-learning算法，该算法在进入某个特征时“承诺”单一动作，仅当观测特征变化时才重新采样动作，并引入准马尔可夫环境（quasi-Markov environments）进行理论分析。

✨ **主要贡献**：证明了在“rewire-robustness”假设下算法几乎必然收敛到最优反应式策略，该假设严格弱于先前工作所需的$q_\star$-可实现性条件，扩展了可应用场景。

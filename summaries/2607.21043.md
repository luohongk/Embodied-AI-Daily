# A Real-Time Generalized Nash Equilibrium Framework for Interaction-Aware Autonomous Driving in Mixed Traffic

- arXiv: https://arxiv.org/abs/2607.21043v1
- arXiv ID: 2607.21043

---

🔍 **核心问题**：解决自动驾驶车辆在混合交通中与人类驾驶员交互时，因策略相互依赖导致的复杂决策与安全约束问题。

🛠 **方法**：将驾驶交互建模为广义纳什均衡问题（GNEP），显式考虑共享安全与几何约束，并采用粒子群优化（PSO）求解器实现非凸问题的实时求解。

✨ **主要贡献**：在真实测试轨道上使用自动驾驶雷诺Zoé与人类驾驶员验证，系统能在50毫秒内收敛，生成舒适且类人的轨迹，有效处理关键场景。

# WCM: A World Critic Model for Vision-Language-Action Reinforcement Learning

- arXiv: https://arxiv.org/abs/2607.29613v1
- arXiv ID: 2607.29613

---

🔍 **核心问题**：现有VLA模型的强化学习后训练中，critic网络仅基于单帧观测或单帧VLM特征进行价值估计，无法处理机器人控制中的部分可观测性，导致价值估计不准确。

🛠 **方法**：提出World Critic Model（WCM），基于轻量级LeJEPA架构，联合预测未来潜在状态并估计价值，使critic表示显式学习时间动态而非仅回归标量回报，可无缝集成到on-policy和off-policy训练流程中。

✨ **主要贡献**：在149个任务、四个基准上达到SOTA性能，尤其在分布外场景下泛化能力显著提升；在7个真实世界操作任务中验证了稳定部署，兼容Pi0、Pi0.5和OpenVLA-OFT等主流VLA骨干网络。

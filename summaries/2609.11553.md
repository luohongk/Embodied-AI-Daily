# CAP: Continuously Adaptive Perception-Blind Humanoid Locomotion via Learned Denoising

- arXiv: https://arxiv.org/abs/2609.11553v1
- arXiv ID: 2609.11553

---

🔍 **核心问题**：人形机器人在复杂地形行走依赖前视外部感知，但真实部署中深度信号常部分或间歇性失效；现有方法要么假设深度干净，要么在感知与盲控子策略间硬切换，未能利用部分损坏深度中的可恢复信息。

🛠 **方法**：提出单阶段策略 CAP，用感知世界模型编码器（学习式去噪器）从损坏深度重建干净深度，并配以共激活的本体感受变分编码器提供无深度的身体状态；训练时结合深度噪声课程与世界模型特征 dropout，使策略暴露于全谱系感知质量。

✨ **主要贡献**：在仿真中深度良好时匹配或超越感知基线，感知恶化时比二值切换基线退化更平滑；在 Unitree G1 上的受控实验与室内外部署验证了间歇遮挡、真实传感器损坏及户外深度伪影下的感知鲁棒行走能力。

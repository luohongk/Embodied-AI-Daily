# Re$^3$Cap: Retrieval-Guided Refinement for Image Captioning Enhancement via Reinforcement Learning

- arXiv: https://arxiv.org/abs/2608.21305v1
- arXiv ID: 2608.21305

---

🔍 **核心问题**：现有强化学习（RL）在图像描述生成中难以鼓励大型视觉语言模型（LVLMs）探索新颖的推理策略，导致其性能与监督微调（SFT）存在差距。

🛠 **方法**：提出Re³Cap方法，利用多模态检索作为推理信号，通过两个组件——描述细化建议器（CRS）和质量评估器（CQA）——识别并修正图像描述中的幻觉和遗漏，无需额外标注。

✨ **主要贡献**：在COCO-LN500基准上，Re³Cap在关系推理任务上平均提升8.64%，性能超越GRPO，甚至可与监督微调相媲美，展示了检索引导在描述增强中的有效性。

# MA-DAR: Manifold-Aligned Dynamic Adaptive Routing for Continual Temporal Knowledge Graph Reasoning

- arXiv: https://arxiv.org/abs/2607.21949v1
- arXiv ID: 2607.21949

---

🔍 **核心问题**：解决持续时序知识图谱推理中，回放表示与当前表示直接融合导致的“范数支配”和“语义模糊”两种表示冲突问题。

🛠 **方法**：提出MA-DAR框架，先通过流形对齐将回放和当前表示映射到共享空间以缓解分布差异，再采用动态门控机制学习维度级融合权重，并引入极化正则化器抑制模糊门控决策。

✨ **主要贡献**：作为轻量级即插即用模块，在四个公开基准上持续提升代表性TKG编码器性能，并通过消融实验验证了流形对齐与动态自适应路由在缓解表示冲突、改善持续推理中的有效性。

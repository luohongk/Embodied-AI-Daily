# FixAnything: 3D-Consistent Rendering Refinement via Video Generative Priors

- arXiv: https://arxiv.org/abs/2608.23549v1
- arXiv ID: 2608.23549

---

🔍 **核心问题**：3D场景渲染（如3DGS、NeRF等）在输入视图稀疏或目标视角偏离时会产生伪影，现有修复方法针对特定表示定制，缺乏通用性。

🛠 **方法**：提出FixAnything，复用预训练视频生成模型，将渲染伪影修复视为视频到视频的转换，仅需轻量微调；通过二进制掩码保留高质量像素，并用相机位姿精度作为奖励信号进行直接偏好优化（DPO）以增强3D一致性。

✨ **主要贡献**：单一通用模型可修复多种3D表示的渲染伪影，无需重新设计架构，轻量微调即可显著提升质量，且易于适配未来更强的视频模型。

# StatePlay: State-Aware Game World Models for Mechanics-Consistent Generation

- arXiv: https://arxiv.org/abs/2607.26754v1
- arXiv ID: 2607.26754

---

🔍 **核心问题**：现有游戏世界模型仅关注像素级视觉真实性，忽略了游戏机制依赖的精确内部状态（如生命值、技能计时器），导致生成内容可能违反游戏规则。

🛠 **方法**：提出StatePlay模型，采用混合Transformer架构，分别处理视觉与状态信息，并通过跨模态交互使预测状态指导帧生成，同时为不同模态设计独立优化目标。

✨ **主要贡献**：状态预测的归一化L1距离低于0.06，相比无显式状态建模的方法，生成游戏序列的机制保真度提升18.6%，首次实现兼顾视觉真实性与规则一致性的游戏世界建模。

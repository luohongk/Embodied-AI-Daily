# Convergent Detour Hijacking: Task-Preserving Resource Amplification in Skill-Based LLM Agents

- arXiv: https://arxiv.org/abs/2608.12273v1
- arXiv ID: 2608.12273

---

🔍 **核心问题**：LLM智能体依赖第三方技能时，存在静态技能描述和指令体两个控制点，可被不可信发布者利用，将任务引导至不必要的昂贵路径，且现有研究未系统探讨这种端到端组合攻击。

🛠 **方法**：提出Convergent Detour Hijacking（CDH），一种纯文本、运行时无关的攻击，通过共享语义掩护，在技能选择阶段建立相关性，在规划阶段复用该理由制造看似合理的依赖，吸引攻击者控制的协调器技能，招募良性技能形成有界绕行，最终回到原路径保证任务完成。

✨ **主要贡献**：在多个LLM后端和491个任务上验证，DeepSeek-V4-Pro上协调器被选中率达80.02%，完成任务的运行中token消耗和端到端时间分别增加66.91%和92.45%，而任务完成率基本不变，证明正确结果不保证轨迹完整性和成本安全。

# Model Predictive Planner for UAV Navigation in Non-Convex Air Corridors

- arXiv: https://arxiv.org/abs/2607.24369v1
- arXiv ID: 2607.24369

---

🔍 **核心问题**：解决无人机在非凸城市空中走廊中导航时，因几何非凸性导致的局部极小值问题，并确保轨迹满足走廊约束与动态可行性。  
🛠 **方法**：提出基于混合整数跟踪模型预测控制的运动规划框架，将走廊可行性与动态一致性整合为单一优化问题，并嵌入基于最短路径的偏移成本与可行性约束。  
✨ **主要贡献**：无需依赖外部全局规划，即可生成动态有效且满足走廊约束的轨迹，仿真验证了其收敛到目标点的能力。

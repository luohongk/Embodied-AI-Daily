# DogLegs: Robust Proprioceptive State Estimation for Legged Robots Using Multiple Leg-Mounted IMUs

- arXiv: https://arxiv.org/abs/2503.04580v3
- arXiv ID: 2503.04580

---

🔍 **核心问题**：在激光雷达和相机等外部传感器可能失效的极端环境中，如何实现腿足机器人主躯干的鲁棒且精确的本体状态估计。

🛠 **方法**：提出DogLegs系统，融合躯干IMU、关节编码器和多个腿部IMU的数据，利用扩展卡尔曼滤波器（EKF）处理所有IMU帧的误差状态，并通过腿部IMU检测足底接触提供零速度更新，同时利用腿部运动学计算躯干与腿部IMU间的相对位置约束来修正主躯干状态。

✨ **主要贡献**：相比仅使用躯干IMU和关节编码器的传统腿式里程计方法，DogLegs在多种地形上显著提升了状态估计精度，并公开了代码和数据集以促进社区研究。

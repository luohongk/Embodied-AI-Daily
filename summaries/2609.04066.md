# Subspace Inference Enables Efficient Active Reward Learning from Preferences

- arXiv: https://arxiv.org/abs/2609.04066v1
- arXiv ID: 2609.04066

---

🔍 **核心问题**：从人类偏好中学习奖励模型（RLHF）时，现有方法样本效率低，且对大型神经网络奖励模型进行不确定性量化以支持主动学习非常困难。

🛠 **方法**：提出PreferenceEKF，将主动偏好学习建模为序贯贝叶斯滤波问题，利用扩展卡尔曼滤波器在低维参数子空间内进行推理，避免全参数空间的高成本后验推断，并高效采样网络参数以计算主动学习的采集函数。

✨ **主要贡献**：在D4RL和V-D4RL基准上，PreferenceEKF相比其他贝叶斯深度学习方法在样本效率、运行时间、可扩展性和校准性上更优，且学到的奖励模型能带来有竞争力的离线强化学习策略性能。

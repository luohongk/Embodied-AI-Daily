# Compositional SVG Generation via VLM-Driven Hierarchical Semantic Parsing

- arXiv: https://arxiv.org/abs/2609.14657v1
- arXiv ID: 2609.14657

---

🔍 **核心问题**：现有SVG生成方法多输出扁平、无语义的路径集合，编辑单个对象需手动识别其组成路径，缺乏结构化与可编辑性。

🛠 **方法**：提出VLM驱动的智能体框架，通过自顶向下分解、视觉定位和提示驱动的非模态遮挡恢复，递归地将视觉场景解析为语义与几何层级结构。

✨ **主要贡献**：构建了带人工标注语义组的Semantic SVG Benchmark及新指标（Semantic Recall/Precision、PERE），实验表明其原生预测结构在分组质量和可编辑性上超越现有扁平生成方法的上限，同时保持最优视觉保真度。

# Distill Skills into Weights, Not Prompts: Abstract Skills as Privileged Signals for On-Policy Self-Distillation

- arXiv: https://arxiv.org/abs/2608.09826v1
- arXiv ID: 2608.09826

---

🔍 **核心问题**：在可验证奖励的强化学习中，当采样组全部正确或全部错误时（占实验组的63.0%-68.0%），组间相对奖励信号失效，导致学习缺乏有效监督。

🛠 **方法**：提出SKALD（技能锚定潜在蒸馏）框架，采用同一Qwen3-Base模型的双上下文视图——仅问题学生模型和基于抽象技能卡（显式答案过滤）的教师模型。学生通过自身前缀训练，将技能优势迁移到共享参数中，测试时无需特权输入；同时使用退火指数倾斜目标缓解上下文分布不匹配，并通过经验门控仅在验证奖励估计教师优势为正时激活蒸馏。

✨ **主要贡献**：在五个保留数学基准上，SKALD在0.6B、1.7B和4B规模下分别比GRPO提升avg@8达+2.46、+4.85和+12.01。在1.7B规模下，仅零方差蒸馏即可恢复84.7%的完整增益，且SKALD比FLOP匹配的GRPO高+4.06，比上下文技能暴露高+3.77，证明抽象技能在组间相对奖励失效时提供了密集监督。

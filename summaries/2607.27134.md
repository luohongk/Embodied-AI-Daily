# Linguistic Monoculture in LLM-Assisted Language Use

- arXiv: https://arxiv.org/abs/2607.27134v1
- arXiv ID: 2607.27134

---

🔍 **核心问题**：研究大型语言模型（LLM）辅助语言使用时，可能导致语言形式趋同的“语言单一文化”现象，以及这种趋同对社会语言多样性的影响。

🛠 **方法**：构建一个数学框架，将作者和LLM表示为语言特征上的分布，通过重复互动共同演化，并分析三种交互机制（固定共享模型、递归更新共享模型、个性化模型）下的均衡与收敛速率。

✨ **主要贡献**：揭示了共享模型驱动语言趋同、递归反馈改变共同规范但不改变个体间差异、个性化模型可保留语言多样性；并证明个体理性趋同可能超过社会最优，产生负外部性和“单一文化代价”。

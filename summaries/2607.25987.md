# \textsc{IH-Benchmark}: A Conflict-Centered Benchmark for Instruction-Hierarchy Robustness in LLM Applications

- arXiv: https://arxiv.org/abs/2607.25987v1
- arXiv ID: 2607.25987

---

🔍 **核心问题**：现有基准测试仅部分评估LLM在冲突指令下的层级遵循能力，缺乏对系统-用户（S>U）和工具中介（U>T）两类冲突的全面覆盖。

🛠 **方法**：构建了基于44个约束族（涵盖通用、健康、金融、零售、编程领域）的冲突中心基准IH-Benchmark，采用谓词DSL与类别级LLM裁判结合的二元通过/失败协议进行统一评估。

✨ **主要贡献**：发现S>U遵循能力不能可靠预测U>T鲁棒性（部分模型在工具输出冲突时性能骤降）；揭示约束硬化效果因模型而异；指出最关键的失败往往是细微的（如注入免责声明或微小事实扭曲）而非明显危险行为。

# Diffusion-Guided Cooperative Policy Learning for Target Tracking Based on Underwater Mobile Agent Networks

- arXiv: https://arxiv.org/abs/2603.29426v2
- arXiv ID: 2603.29426

---

🔍 **核心问题**：针对水下多AUV协同目标跟踪中，多智能体策略非平稳性、探索经验质量不均导致的学习效率低下，以及动态水下扰动下随机探索与确定性执行之间的策略漂移问题。

🛠 **方法**：提出一种四层分层MARL架构（全局训练调度、多智能体协调、局部策略生成、实时动作执行），并基于此设计SDA-MARL算法，融合扩散生成分支与DDPG分支的双决策策略，结合监督样本选择机制和行为克隆损失。

✨ **主要贡献**：通过分离经验池减少训练干扰，利用高质量转移动作引导反向扩散以聚焦有效动作空间，并借助行为克隆对齐探索与执行，从而抑制策略漂移。在六自由度水下环境多配置实验中，SDA-MARL相比现有MARL方法收敛更快、跟踪精度更高、AUV间速度更一致且路径更短。

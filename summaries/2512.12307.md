# MRD: Using Physically Based Differentiable Rendering to Probe Vision Models for 3D Scene Understanding

- arXiv: https://arxiv.org/abs/2512.12307v5
- arXiv ID: 2512.12307

---

🔍 **核心问题**：如何揭示视觉模型对3D场景的隐式理解，即模型在2D输入下是否真正编码了物理场景属性（如形状、材质）。

🛠 **方法**：提出MRD（metamers rendered differentiably）方法，利用基于物理的可微渲染，搜索与原始场景物理属性不同但产生相同模型激活的3D场景参数（即模型“元音”），从而在物理约束下探测模型敏感性。

✨ **主要贡献**：首次将模型表征分析锚定于物理场景描述，可独立控制形状、材质和光照等属性进行探测；实验表明不同模型在几何和BRDF恢复上表现各异，能定性揭示模型对物理属性的敏感或不变性，为理解机器与人类视觉提供了新工具。

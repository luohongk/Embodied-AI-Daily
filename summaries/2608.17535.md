# GroupForward: Building Referable 3D Scenes via Instance-Grouped Feed-Forward Gaussian Splatting

- arXiv: https://arxiv.org/abs/2608.17535v1
- arXiv ID: 2608.17535

---

🔍 **核心问题**：现有前馈语义3D高斯泼溅方法缺乏显式实例区分，仅支持类别或短语级语义查询，无法完成复杂的3D指代分割与场景推理任务。

🛠 **方法**：提出GroupForward模型，从稀疏、无位姿、未标定的多视图图像中重建几何、外观、实例结构和语义；通过学习紧凑实例嵌入将高斯分组为跨视图一致的3D实例，并构建实例分组的3D场景图，结合视觉语言模型进行指代推理。

✨ **主要贡献**：将前馈语义3DGS从逐高斯语义特征渲染重构为实例级语义聚合与传播，并提出RSRF推理框架实现复杂3D指代分割；实验验证了实例分组重建与推理框架在语义重建和指代推理任务上的有效性。

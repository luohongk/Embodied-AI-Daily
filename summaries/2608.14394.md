# IRGNN: Efficient Invariant Radar Graph Neural Network for Radar Point Cloud Object Detection

- arXiv: https://arxiv.org/abs/2608.14394v1
- arXiv ID: 2608.14394

---

🔍 **核心问题**：解决自动驾驶中雷达点云稀疏、无序且信息量少，导致现有基于LiDAR的检测方法难以直接应用的问题。

🛠 **方法**：提出IRGNN，将雷达点云重构为具有平移和旋转不变性的图表示，采用改进的消息传递神经网络（含残差连接和虚拟节点层）增强局部特征传播与全局上下文建模，最后用任务特定头进行目标分类和边界框预测。

✨ **主要贡献**：在RadarScenes数据集上超越现有雷达检测方法，同时显著降低推理时的计算成本和内存占用，验证了高效雷达感知的实用潜力。

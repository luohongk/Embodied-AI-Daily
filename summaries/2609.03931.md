# Sparse auto-regressive modeling for scene generation from multi-view images

- arXiv: https://arxiv.org/abs/2609.03931v1
- arXiv ID: 2609.03931

---

🔍 **核心问题**：从稀疏、无约束的多视角图像生成完整3D场景，需在推理未见内容的同时保持计算可行性，现有前馈重建方法仅能处理可见内容，而3D生成模型受限于高计算成本和缺乏大规模3D监督。

🛠 **方法**：提出SPAR3S，一种稀疏体素对齐的3D潜在生成模型，仅表示占据体素，通过可微3D高斯泼溅从多视角图像学习稀疏潜在空间，并训练掩码自回归Transformer联合建模体素占用和潜在token值，以完成场景补全。

✨ **主要贡献**：无需真实3D数据监督即可实现条件场景补全，在合成室内场景中生成的新视角质量优于先前方法，并在RealEstate10k上验证了对真实数据的泛化能力。

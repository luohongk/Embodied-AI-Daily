# Architectural Design, Not Only Model Intelligence, Governs Multi-Agent LLM Performance

- arXiv: https://arxiv.org/abs/2602.03128v2
- arXiv ID: 2602.03128

---

🔍 **核心问题**：多智能体LLM框架的架构设计（编排、记忆、规划、通信等）对系统性能的影响长期缺乏标准化评估，现有基准仅孤立评测单个智能体能力。

🛠 **方法**：提出五维度架构分类法（编排、记忆、规划接口、专业化、通信拓扑），构建统一评测套件MAFBench，在固定底层LLM、仅改变架构设计的条件下对九种框架进行受控实证研究。

✨ **主要贡献**：提炼出六条基于证据的设计原则，证明架构设计而非仅模型智能决定性能——如编排单独可致延迟增加60倍以上、模式约束规划接口因格式失败致准确率下降达32点、通信拓扑不匹配使协调成功率从90%以上跌至30%以下，且无框架原生支持受控知识修订。

# Rethinking Critic Learning in PPO: Understanding and Mitigating Value Flattening

- arXiv: https://arxiv.org/abs/2609.18708v1
- arXiv ID: 2609.18708

---

🔍 **核心问题**：PPO 中用于估计状态价值的 critic 存在一种系统性失效模式——"价值平坦化"（Value Flattening），即中间状态的真实价值变化剧烈，而 critic 预测却趋于平坦，且该问题随状态空间增大而加剧。

🛠 **方法**：作者通过理论分析将价值平坦化归因于 critic 损失中的隐式方差惩罚以及时序相关状态的冗余更新，并提出 SP³O（稀疏近端策略优化），在每条回复中仅对少量彼此间隔较远的状态施加价值损失。

✨ **主要贡献**：识别并刻画了 PPO critic 学习中此前被忽视的价值平坦化失效模式，并证明仅监督三个稀疏状态即可缓解该问题，在 Qwen3-Base 上跨模型规模和评测集持续提升策略表现。

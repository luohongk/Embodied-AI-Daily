# Does Runtime Topology Context Improve LLM-Generated Kubernetes Security Patches?

- arXiv: https://arxiv.org/abs/2607.25995v1
- arXiv ID: 2607.25995

---

🔍 **核心问题**：现有LLM在生成Kubernetes安全补丁时，因忽略运行时服务调用拓扑，导致补丁可能破坏集群依赖关系，引发功能故障。

🛠 **方法**：提出KuTIE系统，通过整合Istio调用边、Trivy安全发现和工作负载的服务账户绑定，构建实时集群拓扑上下文，并以此条件化LLM的补丁生成。

✨ **主要贡献**：在包含31个可注入发现和7种依赖类的医疗集群上，拓扑上下文将拓扑相关补丁的正确率从11.1%提升至78.0%（Δ=0.669），且效果跨模型和六种依赖类一致，而拓扑无关的补丁无此提升（Δ=0.0），证明实时拓扑信息显著优于仅依赖扫描器的上下文。

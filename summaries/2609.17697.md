# Composite-Gradient Learning for Shared Control Authority Between Deep Reinforcement Learning and Model Predictive Control

- arXiv: https://arxiv.org/abs/2609.17697v1
- arXiv ID: 2609.17697

---

🔍 **核心问题**：在DRL与MPC共享控制权的框架中，常见方法将MPC视为环境的一部分，未能显式考虑MPC对控制的贡献及其与DRL智能体的交互，导致学习效果受限。

🛠 **方法**：提出复合梯度学习（CGL）方法，将DRL和MPC的控制输入表示为联合动作，并在训练更新DRL智能体时显式建模两者的交互，从而将MPC控制器整合进学习过程。

✨ **主要贡献**：在两种交互强度不同的多类高速公路交通网络上验证，CGL在弱交互下收益有限，但在强交互下的部分训练运行中学习到优于基线方法的控制策略，尽管平均控制性能提升幅度仍较为温和。

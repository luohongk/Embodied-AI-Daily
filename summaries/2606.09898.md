# TRAPS: Treatment-Assignment Prediction via Pathway-informed Stratification

- arXiv: https://arxiv.org/abs/2606.09898v2
- arXiv ID: 2606.09898

---

🔍 **核心问题**：现有基于通路信息的深度学习模型在癌症治疗预测中常被孤立评估，难以判断不同架构间的相对优劣。

🛠 **方法**：构建统一基准，比较BINN、GraphPath和PATH三种生物学信息架构，在5个TCGA癌症队列（2622例患者）上联合预测靶向治疗、放疗和6个月总生存期，采用重复分层交叉验证和配对bootstrap检验。

✨ **主要贡献**：在受控评估下，多数架构间差异不显著；但稀疏层次结构的BINN在乳腺癌生存预测上显著优于图模型（AUROC提升最高0.14，p≤0.01），且放疗预测整体较弱，表明短期生存是区分通路信息模型的最清晰指标。

# LaGSplat: Inferring Physics-Governed Interactive Simulation from Monocular Video Using Latent Lagrangian Gaussian Splatting

- arXiv: https://arxiv.org/abs/2608.16324v1
- arXiv ID: 2608.16324

---

🔍 **核心问题**：从单目视频中推断物体的物理交互动态，使模型能够对训练中未见过的外力做出合理响应。

🛠 **方法**：提出LaGSplat框架，将低维潜变量同时用作耗散拉格朗日方程的广义坐标和高斯泼溅解码器的条件变量，使图像空间施加的力能通过雅可比矩阵映射为潜空间广义力并进入运动方程。

✨ **主要贡献**：首次实现从单目视频推断可交互的物理驱动动态，支持对刚体和可变形物体施加任意大小和方向的外力并实时渲染响应；相比无约束预测器，该方法通过耗散欧拉-拉格朗日假设在泛化性和物理合理性之间取得平衡。

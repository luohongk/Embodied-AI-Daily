# Hybrid Artificial Potential Fields and Spatio-Temporal Transformers for Real-Time AUV Path Planning

- arXiv: https://arxiv.org/abs/2607.25056v1
- arXiv ID: 2607.25056

---

🔍 **核心问题**：解决自主水下航行器（AUV）在复杂非结构化环境中实现高效、安全且节能的实时路径规划问题。

🛠 **方法**：提出一种混合方法，结合人工势场（APF）与时空变换器（ST-Transformer），并与经典图搜索、采样、元启发式及学习型算法共13种方法进行对比评估。

✨ **主要贡献**：混合APF+ST-Transformer在路径最优性、碰撞避免和计算效率上表现均衡最优，平均路径长度943.15单位、碰撞率0.031、计算时间0.96秒，优于其他方法，推荐用于实时AUV导航。

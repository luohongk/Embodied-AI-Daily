# Phase-and-First-Arrival VLM Feedback for Sparse-Reward Reinforcement Learning in Surgical Manipulation

- arXiv: https://arxiv.org/abs/2609.07211v1
- arXiv ID: 2609.07211

---

🔍 **核心问题**：在稀疏奖励的强化学习中，手术操作等复杂多阶段任务失败时，机器人无法从部分成功的尝试中学习有效行为，且现有VLM反馈无法区分阶段进展及其时间点。

🛠 **方法**：提出“阶段与首次到达”反馈机制，对每条记录轨迹进行一次VLM查询，识别视觉上已验证的最远任务阶段及其首次到达时间，从而重用部分行为并定位奖励；并在SurgPhaseBench基准（含刚体与变形体任务）中验证。

✨ **主要贡献**：在5个模拟任务中平均成功率75.2%，优于基于CLIP的奖励（52.1%）；硬件实验中同一记录支持自主抓取与滑落恢复，证明轨迹级视觉监督能保留部分进展并提供稀疏奖励所需的时间信用。

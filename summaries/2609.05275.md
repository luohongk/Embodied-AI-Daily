# Don't Drop Dropout: Optimizing Layer Sparsity for Efficient LLM Training and Inference

- arXiv: https://arxiv.org/abs/2609.05275v1
- arXiv ID: 2609.05275

---

🔍 **核心问题**：层丢弃（layer dropout）在大规模LLM预训练中被普遍弃用，且缺乏对其负面影响（如精度下降）的系统性量化与缓解研究，本文旨在重新确立其在LLM训练中的价值。

🛠 **方法**：通过优化层分布、时间调度和优化器超参数，系统性地将层丢弃应用于LLM预训练，并利用其实现推理阶段的早期退出、中间层跳过及自推测解码等后训练优化。

✨ **主要贡献**：在相同训练FLOPs下，层丢弃可降低损失或节省高达25%的训练计算量；在推理阶段可实现最高1.5倍加速且精度损失可忽略。基于2400余次实验（模型规模271M至8.2B参数，数据量至160B tokens），验证了该方法在大规模训练中的可靠性。

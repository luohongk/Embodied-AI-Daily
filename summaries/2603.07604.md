# EmbedTalk: Talking Head Synthesis using Gaussian Embeddings

- arXiv: https://arxiv.org/abs/2603.07604v2
- arXiv ID: 2603.07604

---

🔍 **核心问题**：现有基于3D高斯泼溅（3DGS）的说话头合成方法使用三平面（tri-plane）编码高斯特征，受限于网格分辨率和3D到2D投影的近似误差，影响渲染质量和唇形同步精度。

🛠 **方法**：提出EmbedTalk，用逐高斯嵌入（per-Gaussian embeddings）替代三平面特征，直接编码语音驱动的面部形变，无需投影到低维子空间。

✨ **主要贡献**：在渲染质量、唇形同步和运动一致性上优于现有3DGS方法，并与最先进生成模型竞争；模型更紧凑，在笔记本GPU（RTX 2060）上实现60+ FPS实时渲染。

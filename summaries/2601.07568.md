# d3LLM: Ultra-Fast Diffusion LLM using Pseudo-Trajectory Distillation

- arXiv: https://arxiv.org/abs/2601.07568v3
- arXiv ID: 2601.07568

---

🔍 **核心问题**：扩散大语言模型（dLLMs）虽具备并行解码和随机顺序生成等优势，但面临精度与并行度之间的固有权衡，现有方法往往只侧重效率或精度之一。

🛠 **方法**：提出d3LLM，训练阶段引入伪轨迹蒸馏（pseudo-trajectory distillation）教模型在早期步骤自信解码哪些token以提升并行性；推理阶段采用基于熵的多块解码（entropy-based multi-block decoding）配合KV缓存刷新机制，在保持精度的同时实现高并行度。

✨ **主要贡献**：提出新评估指标AUP（Accuracy Under Parallelism）联合衡量精度与并行度；实验表明d3LLM相比vanilla LLaDA/Dream提速最高达10倍，相比自回归模型提速5倍且精度损失很小，代码已开源。

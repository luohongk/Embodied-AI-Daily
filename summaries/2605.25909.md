# Accelerated Spatio-Temporal Gaussian Rendering via Kinematic and Semantic Priors

- arXiv: https://arxiv.org/abs/2605.25909v2
- arXiv ID: 2605.25909

---

🔍 **核心问题**：动态3D场景重建中，现有4DGS方法无法同时兼顾物理一致性和语义理解，且缺乏高效的时间外推能力。

🛠 **方法**：提出统一的4DGS框架，结合运动学与语义先验，通过刚性体约束机制，仅预测每个语义对象的锚点高斯运动，其余高斯通过相对变换更新。

✨ **主要贡献**：首次实现物理一致且语义感知的4DGS，显著加速新视角合成，支持对象级外推和语义交互，优于无约束基线。

# AdaptVPR: Route-Aware Hard Positive Generation for Robust Visual Place Recognition

- arXiv: https://arxiv.org/abs/2609.04369v1
- arXiv ID: 2609.04369

---

🔍 **核心问题**：视觉地点识别（VPR）在光照、天气、季节变化及动态遮挡等域偏移下鲁棒性不足，主要原因是同一地点在训练数据中的外观多样性有限。

🛠 **方法**：提出AdaptVPR框架，利用视觉语言模型解析场景属性并评估编辑可行性，通过规则调度器按可编辑性和风险约束生成三条增强路线（全局外观、局部遮挡、双路线组合），并用基于几何一致性和外观多样性的VPR验证方案筛选生成样本，失败时进行有限提示修正和再生成。

✨ **主要贡献**：构建了含16万验证通过的合成同地难正样本的AdaptCities数据集，在多个VPR基线和视觉基础骨干上，标准基准一致提升，挑战性域偏移下R@1最高提升9.2%，代码与数据已开源。

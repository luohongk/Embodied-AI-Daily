# Preview-Based Relative-Motion Control of an Insertion Tool for Neural-Thread Placement in Pulsating Tissue

- arXiv: https://arxiv.org/abs/2608.08860v1
- arXiv ID: 2608.08860

---

🔍 **核心问题**：在心脏和呼吸脉动组织环境中，机器人神经线放置需要精确控制插入工具尖端相对于运动组织的相对位置，以补偿延迟和周期性运动干扰。

🛠 **方法**：提出一种基于预览的相对运动控制器，估计延迟周期表面运动并在短时域内预测，结合无偏移模型预测控制（MPC）调节相对位置，同时限制执行器力和横向相对速度；在3自由度下引入耦合预览和可行性恢复的八边形剪切约束。

✨ **主要贡献**：在MuJoCo仿真中，1自由度控制器实现12.0μm自由空间和1.9μm接触RMS相对放置误差，显著优于延迟反馈阻抗和实验室系PD控制；3自由度下横向剪切从1.34降至0.50 mm/s，且软八边形控制器在10μm RMS噪声下无违规完成所有测试，并提供了Lyapunov稳定性证书，但研究仅限仿真，需进一步验证柔性线和硬件条件。

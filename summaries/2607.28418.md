# WIDE: Boosting Adaptive LLM Inference via Token-level Dynamic Width Pruning

- arXiv: https://arxiv.org/abs/2607.28418v1
- arXiv ID: 2607.28418

---

🔍 **核心问题**：现有LLM剪枝方法在静态结构化剪枝下精度损失大，而动态剪枝方法多局限于粗粒度结构决策，难以在真实推理场景中实现高效加速。

🛠 **方法**：提出WIDE框架，实现端到端可微的token级动态宽度剪枝，允许每个token动态选择注意力头组和FFN通道组，并通过两阶段训练学习稀疏执行模式，同时采用剪枝-内核协同设计分解动态稀疏加速。

✨ **主要贡献**：在50%稀疏度下，相比最先进的动态深度剪枝，WIDE在仅校准设置下提升55.1%性能；在预填充和解码场景中分别实现最高1.98倍和4.95倍的核级加速，以及1.68倍和1.55倍的端到端加速，代码已开源。

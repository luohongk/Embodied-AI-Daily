# Bridging the Gap in ECG-Based Emotion Recognition: A Unified Evaluation of Deep Learning Models

- arXiv: https://arxiv.org/abs/2609.15055v2
- arXiv ID: 2609.15055

---

🔍 **核心问题**：基于心电信号（ECG）的情感识别研究中，预处理、训练和评估流程不一致，导致模型间难以直接比较，且现有研究多在单一数据集上验证，泛化能力存疑。

🛠 **方法**：提出两个开源框架——标准化基准工具包ARRC和跨数据集训练验证框架ARDT，将CUADS、ASCERTAIN、DREAMER三个公开数据集整合为统一数据集，并对三种主流深度学习模型和两种CNN基线进行超参数优化与10折交叉验证。

✨ **主要贡献**：建立了可复现的ECG情感识别基准，揭示了分类精度与模型复杂度之间的权衡关系，并通过公开全部源代码促进该领域研究的透明性和可比较性。

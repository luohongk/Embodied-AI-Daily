# Scalable Edge-assisted Fusion and Path Prediction for Connected Autonomous Vehicles

- arXiv: https://arxiv.org/abs/2609.04364v1
- arXiv ID: 2609.04364

---

🔍 **核心问题**：自动驾驶车辆（AV）的规划算法受限于车载传感器的视线遮挡，无法有效应对动态交通状况，而现有边缘融合方案按每辆AV独立处理，扩展性差且结果质量有限。

🛠 **方法**：提出Conductor系统，基于固定锚点（如路侧单元RSU）构建统一世界模型，并预测区域内AV的未来轨迹；通过遮挡感知选择器优先融合能检测RSU盲区物体的AV数据，并配合运行时控制器动态调整融合AV数量和轨迹预测量，以满足信息时效（AoI）预算。

✨ **主要贡献**：在最多31辆CAV的仿真场景下，Conductor的联合选择-控制机制能在严格AoI安全约束内运行，融合保真度接近理想Oracle方案，显著优于随机选择方法，兼顾了可扩展性与结果质量。

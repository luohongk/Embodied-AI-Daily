# Should We Type or Talk to LLM Agents? A Comprehensive Study of Voice and Keyboard Input Perturbations

- arXiv: https://arxiv.org/abs/2608.03970v1
- arXiv ID: 2608.03970

---

🔍 **核心问题**：研究人类通过键盘打字与语音输入向大语言模型（LLM）传递信息时，不同输入通道的扰动（如语音转录的不流畅、键盘拼写错误）如何影响模型性能。

🛠 **方法**：提出HIVE（Human Input-Variation Engine），包含语音转录扰动（如填充词、结构重组）和QWERTY键盘扰动（如拼写错误），并在多种指令微调模型上进行系统性评估。

✨ **主要贡献**：发现语音转录扰动显著降低所有测试模型的准确率，且主要源于转录结构而非填充词；键盘扰动影响较小，模型能容忍大量拼写错误；两者性能损失均与问题中关键token的破坏程度相关；语音扰动在需要推理或构造答案的任务中影响更大，而选择题无差异；轻量微调无法消除该影响，但思维链预算可几乎完全恢复键盘通道性能，对语音通道无效。

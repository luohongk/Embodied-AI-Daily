# Safeguarding LLM Agents from Misalignment through Provenance Analysis

- arXiv: https://arxiv.org/abs/2607.01236v2
- arXiv ID: 2607.01236

---

🔍 **核心问题**：LLM智能体在调用工具时可能偏离用户意图（即“错位”），现有基于LLM评判的运行时防护缺乏系统推理框架，判断不一致且难以审计。

🛠 **方法**：提出基于溯源分析（Provenance Analysis）的概念框架，将错位检测形式化为判断工具调用是否由上下文中的可追溯证据支持，并构建多阶段流水线ProvenanceGuard，在动作执行前分析三类错位并仅放行对齐动作。

✨ **主要贡献**：在AgentSafetyBench和WorkBench上、跨11个骨干LLM评估，相比LLM评判基线，错位轨迹错误率从44.3%降至2.1%（AgentSafetyBench）、32.4%降至18.7%（WorkBench），同时任务成功轨迹的不必要干预从31.2%降至13.0%，且对齐轨迹上无显著额外干预，证明结构化溯源推理是有效的防护基础。

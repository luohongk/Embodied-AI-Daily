# Can LLMs Reason Like Automated Theorem Provers for Rust Verification? VCoT-Bench: Evaluating via Verification Chain of Thought

- arXiv: https://arxiv.org/abs/2603.18334v2
- arXiv ID: 2603.18334

---

🔍 **核心问题**：现有评估仅以二元结果衡量LLM在Rust程序验证中的表现，无法判断模型是否真正理解验证所需的逻辑推理过程。

🛠 **方法**：提出VCoT-Lift框架，将底层求解器推理转化为高层、人类可读的验证步骤，并基于此构建包含1,988个任务的VCoT-Bench基准，从证明缺失鲁棒性、证明类型能力和证明位置敏感性三个维度评估模型。

✨ **主要贡献**：首次提供细粒度的验证链式推理基准，对十个先进LLM的评估显示其推理能力远不及自动定理证明器，揭示了当前模型在Rust验证中的严重脆弱性。

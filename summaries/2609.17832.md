# Adaptive-MHE : A Sampling-Based Adaptive MPC for Legged Loco-Manipulation via Moving Horizon Estimation

- arXiv: https://arxiv.org/abs/2609.17832v1
- arXiv ID: 2609.17832

---

🔍 **核心问题**：腿足机器人进行移动操作时，物体与地形参数（如质量、摩擦）通常未知，仿真与现实的参数失配导致sim-to-real差距，降低控制性能。

🛠 **方法**：提出Adaptive-MHE，一种基于移动 horizon 估计（MHE）的在线采样式系统辨识框架，通过大规模并行仿真轨迹匹配在线估计物理参数，并与采样式模型预测控制器耦合。

✨ **主要贡献**：实现了在线自适应参数估计，无需可微动力学假设，在仿真与硬件实验中持续优于基线，并达到使用真实参数的控制器性能水平。

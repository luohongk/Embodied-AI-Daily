# CoTinyVLA: Chain-of-Thought Distillation for a Sub-Billion-Parameter Vision-Language-Action Model

- arXiv: https://arxiv.org/abs/2607.25487v1
- arXiv ID: 2607.25487

---

🔍 **核心问题**：现有视觉-语言-动作模型（VLA）参数量高达3B-7B，远超嵌入式机器人内存预算，难以在资源受限场景下实现鲁棒操作。

🛠 **方法**：提出CoTinyVLA（0.9B参数），基于Qwen3.5-0.8B骨干网络，通过结构化监督替代模型扩增，包含三个组件：双视角时序输入（每步16帧历史+文本标记）、层级链式思维蒸馏（从35B教师模型蒸馏出情节级计划和片段级思考）、以及指令释义增强（40条基础指令扩展为800变体）。

✨ **主要贡献**：在LIBERO-Plus基准的七个扰动维度上，CoTinyVLA以0.9B参数全面超越最强7B基线（Spatial+4.7%、Object+2.8%、Goal+15.9%、Long+3.0%），尤其在最难“机器人初始状态”维度达73.6%（基线仅39.9%），且推理显存仅需2.25 GiB。消融实验证实各组件可分离优化，情节计划缺失会导致成功率下降40-45个百分点。

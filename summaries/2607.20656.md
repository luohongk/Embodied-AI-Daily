# Adaptive Multi-Horizon Reinforcement Learning

- arXiv: https://arxiv.org/abs/2607.20656v1
- arXiv ID: 2607.20656

---

🔍 **核心问题**：传统强化学习使用固定折扣因子平衡短期与长期回报，但无法适应动态环境中的任务变化，导致手动调参困难。

🛠 **方法**：提出自适应多时间范围强化学习框架，通过动态选择与组合多个时间范围，无需手动调整折扣因子即可适应奖励结构变化。

✨ **主要贡献**：在MiniGrid环境（含连续三个任务切换场景）中验证了该方法能自动识别有效折扣因子，提升参数效率与持续学习场景下的适应性。

# LiDARDraft: Generating LiDAR Point Cloud from Versatile Inputs

- arXiv: https://arxiv.org/abs/2512.20105v2
- arXiv ID: 2512.20105

---

🔍 **核心问题**：现有方法在生成逼真且可控的激光雷达点云时，难以平衡复杂点云分布与简单控制信号之间的矛盾，导致生成质量不高且控制灵活性不足。

🛠 **方法**：提出LiDARDraft，通过3D布局作为桥梁，将文本、图像等多样化输入统一转化为语义和深度控制信号，并采用基于距离图的ControlNet实现像素级对齐，从而引导激光雷达点云生成。

✨ **主要贡献**：首次实现从任意文本描述、图像或草图“从零开始”生成自动驾驶仿真环境，在可控点云生成中达到高质量与高灵活性的统一。

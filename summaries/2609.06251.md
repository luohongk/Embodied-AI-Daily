# MobileVLA-R1 2.0: RL-Enhanced Reasoning for Mobile Robot Control

- arXiv: https://arxiv.org/abs/2609.06251v1
- arXiv ID: 2609.06251

---

🔍 **核心问题**：移动机器人视觉-语言-动作（VLA）系统中，高层语义推理与低层运动控制之间存在鸿沟，导致长时程决策和精确动作生成困难。

🛠 **方法**：提出MobileVLA-R1 2.0框架，通过监督式思维链（CoT）对齐和强化学习学习多粒度具身推理，并设计推理条件动作解码器，将多模态推理映射为任务级动作目标，再由机器人控制器转换为具体指令。

✨ **主要贡献**：在VLN-CE、QUARD及Unitree Go2/G1真实机器人上验证，平均SR提升1.6点，G1移动操作全任务成功率较MobileVLA-R1提升10.0点，展现了跨平台的鲁棒长时程指令跟随与闭环执行能力。

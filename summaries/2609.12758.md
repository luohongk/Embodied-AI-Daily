# Curriculum-Based Adversarial Heterogeneous Agent Reinforcement Learning for Autonomous Quad-Copter Landing in Maritime Settings

- arXiv: https://arxiv.org/abs/2609.12758v1
- arXiv ID: 2609.12758

---

🔍 **核心问题**：海上环境中无人机回收受风湍流和甲板运动影响，传统着陆方法不可靠，需学习鲁棒的协同控制策略以实现船载机械臂的空中捕获。

🛠 **方法**：在NVIDIA Isaac Lab中，采用异构智能体近端策略优化（HAPPO）结合课程学习和对抗性风智能体（HARL-AC）训练控制策略，并与课程域随机化及单一海况基准进行对比。

✨ **主要贡献**：HARL-AC在分布内海况下成功率高达97.5%，在分布外海况（7/8/10）泛化更优，海况10下中位成功率提升16%、坠毁率降低14%，且策略行为更谨慎安全。

# Socially Consistent Multi-Robot Navigation Using Decoupled Planning and Trajectory Coordination

- arXiv: https://arxiv.org/abs/2607.20772v1
- arXiv ID: 2607.20772

---

🔍 **核心问题**：解决多机器人在人类环境中长期导航行为缺乏社会一致性和可预测性的问题，避免局部规划器因缺乏社会意识而产生低效、反应式的运动。

🛠 **方法**：提出一种部分去中心化框架，通过改进的A*规划器将宏观社会规范嵌入代价函数，并共享路径构建社会图以保持一致性；同时将多机器人轨迹协调问题建模为混合整数凸规划，高效计算无冲突轨迹。

✨ **主要贡献**：在路径规划阶段强制社会一致性，生成可预测且符合社会规范的机器人路径，简化了多机器人协调的复杂性，支持大规模车队和动态任务分配。

# SparkVLA: Stop-Aware Hierarchical VLA with Adaptive Action Chunking for Long-Horizon Manipulation

- arXiv: https://arxiv.org/abs/2608.16172v1
- arXiv ID: 2608.16172

---

🔍 **核心问题**：在分层视觉-语言-动作（VLA）系统中，子任务终止点与动作块执行长度这两个决策相互依赖，但现有方法孤立评估它们，导致长时程操作效率低下。

🛠 **方法**：提出SparkVLA，将两个决策统一为单一排序问题——停止选项与所有动作前缀长度在同一候选集中竞争，选择得分最高者；并引入锚点条件上下文编码模块和停止感知动作前缀选择头，分别优化视觉令牌剪枝与候选评分。

✨ **主要贡献**：在RoboCerebra基准上达到47.12%成功率，比官方分层基线高30.57%，比最强可复现方法高26.83%；真实机器人多步任务实验进一步验证了物理硬件上的有效性。

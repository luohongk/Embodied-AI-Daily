# Retrofit: Continual Learning with Controlled Forgetting for Binary Security Detection and Analysis

- arXiv: https://arxiv.org/abs/2511.11439v3
- arXiv ID: 2511.11439

---

🔍 **核心问题**：二进制安全分析中，深度学习模型在威胁演变和代码表示变化时性能下降，而现有持续学习方法依赖数据回放或不受约束的更新，在数据敏感的安全环境中效果受限。

🛠 **方法**：提出RETROFIT框架，通过无回顾的参数合并，将先前训练和最新微调的模型作为新旧知识教师；采用低秩稀疏子空间约束参数变化以近似正交性，并用置信度引导的仲裁机制动态聚合知识，实现受控遗忘。

✨ **主要贡献**：在恶意软件检测（时间漂移下）将保留分数从20.2%提升至38.6%，超过新数据上的oracle上限；在二进制摘要任务中，BLEU分数比先前迁移学习提升2倍以上，跨表示泛化能力超越所有基线。

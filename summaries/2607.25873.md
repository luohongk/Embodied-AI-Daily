# How Do LLMs Read Bug Reports? An Empirical Study of Attention in LLMs for Automated Program Repair

- arXiv: https://arxiv.org/abs/2607.25873v1
- arXiv ID: 2607.25873

---

🔍 **核心问题**：探究基于大语言模型的自动程序修复系统为何在相同上下文下对相似漏洞的修复效果不一致，以及模型注意力机制是否影响修复成功率。

🛠 **方法**：对SWE-bench Verified和Multi-SWE-bench中的319个真实Python和Java漏洞进行实证研究，分析模型注意力在漏洞报告各部分的分布差异，并对比成功与失败修复的注意力模式。

✨ **主要贡献**：首次实证发现成功修复时模型注意力分散于多个诊断组件（如漏洞描述、堆栈跟踪、测试用例），而失败修复常过度集中于元数据（如版本信息）；模型注意力与开发者关注的关键部分越对齐，修复成功率越高，揭示了注意力分配不当是LLM修复失败的关键因素。

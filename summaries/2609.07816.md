# Kalman Delta Networks: Uncertainty-aware Associative Memory

- arXiv: https://arxiv.org/abs/2609.07816v1
- arXiv ID: 2609.07816

---

🔍 **核心问题**：线性注意力模型在固定大小记忆更新时缺乏对记忆估计置信度的跟踪，导致写入强度无法根据累积证据自适应调整。

🛠 **方法**：将循环关联记忆重构为线性-高斯状态空间模型，引入卡尔曼滤波器作为最优递归估计器，提出Kalman Delta Networks（KDNs），通过传播记忆状态及其不确定性来计算卡尔曼增益，并设计了两种支持GPU并行扫描的近似方法（对角KDN和各向同性KDN）。

✨ **主要贡献**：首次将不确定性感知引入线性注意力记忆更新，Delta规则成为其特例；在750M和1.3B参数规模的预训练中，KDN变体持续优于最先进的线性注意力模型，在困惑度和下游任务平均准确率上均有提升。

# CNsEMD: An Expert-Annotated Multi-Field-Strength MRI Dataset and a Hyperspherical Manifold Network for Multimodal Cranial Nerve Parcellation

- arXiv: https://arxiv.org/abs/2609.07058v1
- arXiv ID: 2609.07058

---

🔍 **核心问题**：脑神经（CN）在MRI中体积小、对比度低、形态细长且路径复杂，导致精确分割极为困难；同时缺乏公开的专家标注数据集，限制了基于学习的CN分析方法的发展与公平比较。

🛠 **方法**：构建了CNsEMD数据集（202例受试者，涵盖3T/5T/7T MRI），并提出PHM-Net网络，通过超球面嵌入空间捕获跨模态角度关系，利用HCI模块在T1w与DEC特征间进行双向交互，结合PHOR保留扩散幅度并表征轴向方向，以及HPSH实现基于原型的分割。

✨ **主要贡献**：首次提供多场强、专家标注的CN分割基准数据集CNsEMD；PHM-Net在CNsEMD上优于现有方法，且其几何一致的超球面设计在不同MRI采集条件下均表现出鲁棒性，为多模态CN成像与分割提供了可复现的基准与解决方案。

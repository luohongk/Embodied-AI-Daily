# Conformal Cascade: Distribution-Free Accuracy Guarantees for Multi-Tier LLM Inference

- arXiv: https://arxiv.org/abs/2607.25018v2
- arXiv ID: 2607.25018

---

🔍 **核心问题**：大型语言模型（LLM）级联推理中，基于置信度阈值的路由规则因置信度校准不良而无法提供形式化的精度保证，且阈值需针对不同模型对和领域手动调整。

🛠 **方法**：提出**Conformal Cascade (CC)** 框架，使用共形预测的集合大小作为延迟规则——当校准集合坍缩为单一答案时接受小模型输出，否则延迟到大模型。通过逐层联合界提供无分布假设的有限样本精度保证，并推导期望成本与α及校准集接受率的显式关系。

✨ **主要贡献**：CC在18个多项选择基准、4种开源模型家族的两层级联上，多数情况下优于最强校准调优启发式方法，尤其在推理密集型任务上增益显著；在简单基准上以零精度损失将大部分查询路由至小模型，且无需训练、仅需黑盒API访问。

# Light-Loco-Parkour: Versatile Perceptive Whole-Body Locomotion via Multi-Skill Distillation

- arXiv: https://arxiv.org/abs/2608.02653v1
- arXiv ID: 2608.02653

---

🔍 **核心问题**：现有仿人机器人全身控制系统在复杂地形中运动能力不足，要么缺乏地形泛化能力，要么忽略手臂、躯干和膝盖的利用，难以像人类一样灵活穿越杂乱环境。

🛠 **方法**：提出Light-Loco-Parkour（LLP），一个端到端的感知全身运动系统，基于深度感知和速度指令，通过多技能蒸馏将RL训练的行走策略与物体交互式跑酷技能结合，并利用稀疏种子扩展生成地形配对参考，从奖励中学习自主技能切换。

✨ **主要贡献**：单一策略无需参考输入、技能标签或手工状态机即可自主决定行走、平衡、攀爬、下踏或跳跃，在仿真和真实实验中均展现高成功率，并零样本迁移至室内外硬件，实现户外自主全身运动。

# Riemann-1.0: An Embodied World Action Model for Physical AI

- arXiv: https://arxiv.org/abs/2608.27033v1
- arXiv ID: 2608.27033

---

🔍 **核心问题**：现有世界动作模型（WAM）在机器人策略执行与视觉世界模拟上分离，难以将大规模异构具身数据转化为通用、可执行的机器人操作能力。

🛠 **方法**：提出Riemann-1.0，一个全因果自回归世界动作模型，将多视角视觉、机器人状态和动作统一建模为因果序列；并设计渐进式具身预训练框架，统一学习人类视频、手持夹爪演示和异构机器人轨迹。

✨ **主要贡献**：单一模型同时支持在线策略执行与多具身视觉模拟，基于20万小时交互数据训练，在RoboTwin2.0（94.3%）、LIBERO（99.0%）和RoboCasa-365（62.6%）等基准上达到SOTA，真实长时程任务SR达85.0%，较最强开源基线提升15%。

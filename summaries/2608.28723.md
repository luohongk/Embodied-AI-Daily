# Vehicle Drift Emergence: Continuous Evolution from Grip Driving to the Handling Limit via Boundary Exploration Learning Model Predictive Control

- arXiv: https://arxiv.org/abs/2608.28723v1
- arXiv ID: 2608.28723

---

🔍 **核心问题**：本文解决自动驾驶车辆在极限操控下从抓地行驶到漂移状态的连续过渡问题，而非传统方法中显式设定漂移参考。

🛠 **方法**：提出边界探索学习模型预测控制（BE-LMPC），通过构建经验安全集和局部平移终端代价，在重复圈速最小化任务中迭代优化空间速度分配，逐步探索更大的侧偏角和横摆角范围。

✨ **主要贡献**：实验表明，在摩擦系数0.6时，圈速从第3圈的49.95秒降至第12圈的25.50秒，漂移首次出现在第11圈，达到16.5°侧偏角和0.894后轴利用率；而在0.8-1.2摩擦系数下无漂移发生。研究证明漂移是极限操控在性能需求接近轮胎能力时的条件性延续，而非独立预设的运动模式。

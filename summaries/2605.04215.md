# Predict-then-Diffuse: Adaptive Response Length for Compute-Budgeted Inference in Diffusion LLMs

- arXiv: https://arxiv.org/abs/2605.04215v3
- arXiv ID: 2605.04215

---

🔍 **核心问题**：扩散式大语言模型（D-LLM）在推理前需固定响应长度，导致计算浪费（长度过大）或输出截断需重算（长度过小），缺乏按查询自适应分配计算预算的能力。

🛠 **方法**：提出Predict-then-Diffuse框架，包含自适应响应长度预测器（AdaRLP），先根据输入查询估计最优响应长度，再以该长度运行D-LLM推理；同时引入数据驱动的安全机制，对预测长度进行小幅上调以防低估。

✨ **主要贡献**：该框架与模型无关，能显著降低计算开销（FLOP），避免填充token的浪费，同时保持输出质量，并在多个数据集上验证了对偏斜数据分布的鲁棒性。

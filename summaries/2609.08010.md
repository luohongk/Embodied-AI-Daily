# mjorbit: A Simulation Framework for Space Robotics

- arXiv: https://arxiv.org/abs/2609.08010v1
- arXiv ID: 2609.08010

---

🔍 **核心问题**：面向在轨服务、组装与制造等空间任务，缺乏高效、通用且支持接触的多体空间机器人仿真框架。

🛠 **方法**：基于MuJoCo引擎构建mjorbit框架，先对轨道传播与现有机器人仿真耦合方式进行实证对比，再添加航天器动力学、执行器与传感器，提供低延迟C++ CPU后端和高吞吐GPU后端，并统一于简洁Python API。

✨ **主要贡献**：提出通用、灵活且高性能的空间机器人仿真框架，并通过模型预测控制与强化学习在多个真实在轨案例中验证其有效性，代码已开源。

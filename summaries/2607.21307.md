# Scaling Up Formal Representation of Clinical Trial Protocols in Ensemble Logic Using LLMs: A Preliminary Study

- arXiv: https://arxiv.org/abs/2607.21307v1
- arXiv ID: 2607.21307

---

🔍 **核心问题**：临床实验协议依赖非结构化自由文本，阻碍了自动化推理、队列发现和试验模拟，尤其是动态资格标准和事件时间约束等关键时间表型难以被形式化表达。

🛠 **方法**：提出CT-TEL工作流，利用大语言模型（LLMs）将叙述性临床协议自动翻译为时间集成逻辑（TEL）公式，并通过反向翻译方法评估语义保留度。

✨ **主要贡献**：成功为23个真实临床试验生成逻辑模型，验证了LLMs将非正式协议映射为可计算逻辑的可行性，为“符号生物医学”范式下的可扩展临床试验模拟提供了初步证据。

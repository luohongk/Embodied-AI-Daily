# When Does On-Policy Interaction Help? Representational Tradeoffs in Value-Based Imitation Learning

- arXiv: https://arxiv.org/abs/2607.29617v1
- arXiv ID: 2607.29617

---

🔍 **核心问题**：在模仿学习中，当学习者无法完美表示专家策略时，交互式查询和值函数估计如何提升性能？具体而言，专家交互是否以及为何能降低学习者的表示能力要求。

🛠 **方法**：提出交互式在线模仿学习算法OVI，该算法利用专家沿学习者轨迹的交互查询，仅需学习者能表示专家的值函数（而非完整策略），并借助线性最大化预言机实现高效计算。

✨ **主要贡献**：理论上证明专家交互可放宽表示需求（只需值函数可实现性），并给出负结果说明无交互时离线算法必须依赖专家策略类的复杂度；实验表明OVI优于BC、DAgger及离线值基方法，尤其在学习者网络远不如专家表达力时增益最大。

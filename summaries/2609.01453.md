# Does Imitation Learning Preserve Temporal Robustness in Dexterous Manipulation? An Expert-Learner Comparison Across Task Execution Speeds

- arXiv: https://arxiv.org/abs/2609.01453v1
- arXiv ID: 2609.01453

---

🔍 **核心问题**：本文探讨模仿学习策略在灵巧操作任务中是否保留专家在不同执行速度下的时间鲁棒性，即任务成功率是否随速度变化而保持稳定。

🛠 **方法**：在接触密集的ParcelStow任务中，使用脚本化专家生成演示数据，训练基于Action Chunking with Transformers（ACT）的策略，并在相同初始条件和速度因子下对比专家与学习者的成功率及阶段级表现。

✨ **主要贡献**：发现名义速度下专家和ACT均达100%成功率，但在最大演示速度下专家成功率为84%，ACT仅为53%，且ACT的失败主要源于插入阶段错位；此外，所有无力闭合的抓取均无法完成任务，表明名义速度下的成功并不能保证跨速度的鲁棒性。

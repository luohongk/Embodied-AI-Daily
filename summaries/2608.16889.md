# Don't Drop the BATON: Long-Horizon Robot Manipulation via Agentic Subtask Exploration and Transition-aware Memory

- arXiv: https://arxiv.org/abs/2608.16889v1
- arXiv ID: 2608.16889

---

🔍 **核心问题**：长时程机器人操作任务中，多阶段技能链因误差累积和子任务间状态不兼容而失败，现有LLM代理方法探索成本随阶段数指数增长，且缺乏对子任务间转换状态的建模。

🛠 **方法**：提出BATON框架，将探索单元从整个任务分解为单个子任务（成本从T^K降为T*K），并引入转换感知记忆——包括验证器代理控制VLA调用时机、交接转换恢复入口状态、前瞻转换选择可继承的策略结果，全程无需更新参数。

✨ **主要贡献**：在RoboMemArena基准上，BATON将任务成功率提升11.6%，累计成功率提升14.9%，超越现有最先进方法，同时实现了失败归因到单一阶段和探索成本的线性增长。

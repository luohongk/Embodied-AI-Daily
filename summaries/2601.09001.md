# Entropy Sentinel: Probing Entropy Traces for LLM Monitoring

- arXiv: https://arxiv.org/abs/2601.09001v5
- arXiv ID: 2601.09001

---

🔍 **核心问题**：如何利用低成本、易获取的熵信号（如top-k logprobs）替代昂贵的评估方法，实时监测大语言模型（LLM）在领域层面的性能退化，并优先定位需干预的薄弱环节。

🛠 **方法**：将每个响应的输出熵分布压缩为紧凑向量，通过轻量级分类器预测实例质量，再聚合为领域级估计；在可验证任务（10个STEM基准、9种LLM）和主观任务（用户对话分类、LLM评分）上验证其有效性。

✨ **主要贡献**：发现熵信号在可验证任务中能近乎单调地追踪模型准确率，在主观任务中与LLM评分高度相关（相关系数最高达0.91），且能近乎完美检测最差类别，为低成本监控LLM性能提供了可靠代理方法。

# Air-Ground Collaborative Vision-and-Language Navigation via Shared Bird's-Eye Maps

- arXiv: https://arxiv.org/abs/2609.03483v1
- arXiv ID: 2609.03483

---

🔍 **核心问题**：空中-地面协同视觉语言导航（VLN）中，无人机（UAV）具备全局鸟瞰视角而无人车（UGV）仅有局部第一人称视角，但现有方法缺乏协同机制，导致协同性能甚至低于单智能体。

🛠 **方法**：提出AGC-VLN，首个免训练的空中-地面协同VLN基线。将导航分解为基于VLM的语义推理与确定性几何执行，通过共享鸟瞰图（UAV渲染UGV位姿与目标标记）实现协同；UGV利用该图规划道路跟随路径并闭环执行，UAV并行运行3D-SPF（SPF的空间搜索升级版）定位并飞向目标。

✨ **主要贡献**：在CARLA-Air的Town10HD场景100个闭环测试中，AGC-VLN联合成功率77.0%，较最弱单智能体（UAV，50.0%）提升27.0%，并超越最强单智能体基线（Travel UAV，53.0%）24.0个百分点，验证了全局视角与道路执行能力的互补性。

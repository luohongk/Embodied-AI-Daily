# FlipToSee: A Probabilistic Stable Placement Prior for Active Visual Exploration via Regrasping

- arXiv: https://arxiv.org/abs/2609.20078v1
- arXiv ID: 2609.20078

---

🔍 **核心问题**：桌面物体的主动视觉探索常需将未知物体重新定向到新的稳定支撑面，以暴露被遮挡的表面，但如何在不进行穷举物理搜索的情况下找到这些稳定放置姿态。

🛠 **方法**：提出 FlipToSee 概率框架，将放置姿态参数化为 $S^2$ 上的单位支撑法向量，用 von Mises–Fisher 混合密度网络建模其多模态条件分布，并从混合分量中确定性提取候选集，再用辅助头进行鲁棒性重排序。

✨ **主要贡献**：消除了 6-DoF 回归中平移与偏航带来的表示歧义，在仿真中实现分布内物体 98.4%、分布外形状 95.3%、零样本迁移到 YCB 家居物体 90.0% 的首次提议成功率，并在真实机器人上结合抓取与运动规划验证了探索性重抓取。

# FlashVLA: Streaming Action Decoding for Fast and Asynchronous VLA Inference

- arXiv: https://arxiv.org/abs/2608.27384v1
- arXiv ID: 2608.27384

---

🔍 **核心问题**：VLA模型在机器人操控中因推理延迟高和异步执行不稳定而受限，尤其是流匹配类模型需多步迭代解码动作，现有方法难以兼顾低延迟与时间一致的异步执行。

🛠 **方法**：提出FlashVLA框架，采用流式动作解码，维护包含多个不同噪声级别动作块的缓冲区，并通过块级因果注意力逐块解码，每步推理生成一个可执行动作块。

✨ **主要贡献**：块级自回归设计隐式保持动作连续性，无需额外未来状态条件即可实现平滑异步执行；在模拟和真实实验中，FlashVLA显著提升推理速度，单GPU上可达≥30Hz控制频率，同时保持强任务性能。

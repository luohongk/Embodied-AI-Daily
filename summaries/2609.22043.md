# An Interpretable Memory Decision Controller for LLM Agents Based on Three-Signal Complementarity: Decoupling Confidence and Consistency

- arXiv: https://arxiv.org/abs/2609.22043v1
- arXiv ID: 2609.22043

---

🔍 **核心问题**：现有LLM记忆系统只关注高效检索，忽视了“检索到的记忆是否可信”这一决策问题，导致在记忆冲突时RAG盲目注入记忆、放大幻觉。

🛠 **方法**：提出零参数的记忆决策层（MDL），置于检索与生成之间，通过基于QR正交子空间投影的三信号互补编码器（相关性、可靠性、任务风险）融合元工作记忆信号，生成可解释的决策表示，并显式解耦置信度与一致性，引入风险反转与显式弃权机制。

✨ **主要贡献**：在冲突记忆下将幻觉率降低约56.04%，高风险场景接近零幻觉；控制器完全白盒、纯几何运算、无需训练参数，每次决策仅约0.14毫秒，比前置嵌入检索快约50倍，比LLM自评估快四到五个数量级。

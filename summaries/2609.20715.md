# Don't Mask the Environment: Observation Supervision Changes How Agents Explore Under RL

- arXiv: https://arxiv.org/abs/2609.20715v1
- arXiv ID: 2609.20715

---

🔍 **核心问题**：标准SFT只对智能体生成的动作token计算损失，而将环境观测仅作为上下文，这是否是强化学习的最佳初始化方式。

🛠 **方法**：提出ActObs，在SFT阶段同时对轨迹中已有的观测token进行监督，让策略学习预测动作后果，且不增加数据、参数、序列长度或前向计算。

✨ **主要贡献**：在Qwen3-4B/8B上，ActObs经GRPO后在Terminal-Bench 2.0的pass@k全面优于仅动作监督，并跨域提升代码编辑表现；分析表明联合监督可防止动作与观测梯度正交化导致的单向特化，保留环境预测能力并利于下游探索。

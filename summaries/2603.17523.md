# Translation Invariance of Neural Operators for the FitzHugh-Nagumo Model

- arXiv: https://arxiv.org/abs/2603.17523v2
- arXiv ID: 2603.17523

---

🔍 **核心问题**：评估神经算子（NOs）能否捕捉FitzHugh-Nagumo模型的刚性时空动力学，并重点考察其在时空平移情形下的泛化能力。

🛠 **方法**：采用新颖训练策略——在固定时间、不同空间位置和强度下施加电流训练，测试时则将电流在时间和空间上平移，形成分布外场景；对七种NO架构（CNO、DeepONet及其变体、FNO、Tucker张量化FNO、局部神经算子）进行精度、效率与推理速度的基准测试。

✨ **主要贡献**：发现CNO对平移后的测试动力学泛化良好，而其他架构泛化能力差；训练集上各架构精度相当（FNO最高但计算成本大），DeepONet及其变体训练与推理效率更优，为平移动力学场景提供了全面基准。

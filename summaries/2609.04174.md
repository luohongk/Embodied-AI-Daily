# Zero-Shot Novel Depth Synthesis Using 3D Foundation Models Scene Representations

- arXiv: https://arxiv.org/abs/2609.04174v1
- arXiv ID: 2609.04174

---

🔍 **核心问题**：如何利用3D基础模型（3DFM）的内部表示，从单一视角推断场景中未见视角的深度信息，实现零样本的新视角深度合成。

🛠 **方法**：提出Z3D方法，基于VGGT等3DFM的预训练表示，通过潜在扩散模型（latent diffusion）在3DFM表示空间中生成未见视角的点图（pointmaps），从而解码隐藏表面并估计深度。

✨ **主要贡献**：首次证明3DFM内部表示可解码隐藏表面，并实现跨多个数据集的新视角深度预测，无需针对特定场景训练，展示了3DFM表示对3D场景的泛化能力。

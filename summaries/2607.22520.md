# The Regression Tax: Decomposing Why Skills Help and Hurt LLM Agents

- arXiv: https://arxiv.org/abs/2607.22520v1
- arXiv ID: 2607.22520

---

🔍 **核心问题**：揭示LLM智能体添加程序性技能后，不仅可能提升任务成功率，还会导致“回归”（技能使原本可完成的任务失败），而现有评估仅关注平均改进，忽略了这一代价。

🛠 **方法**：通过近6000次实验，对比有无技能智能体在办公自动化基准和模型栈上的表现，区分“回归”与“残余失败”，并分析回归的三种成因（技能描述渗透、接地位移、验证位移）。

✨ **主要贡献**：发现最佳技能主要因回归更少而非增益更多而胜出；识别出技能应避免的三种回归模式，并指出智能体可靠性更依赖接地与验证而非程序性技能选择。

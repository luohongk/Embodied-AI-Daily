# GameWAM: A World Action Model for Video Games

- arXiv: https://arxiv.org/abs/2608.26200v2
- arXiv ID: 2608.26200

---

🔍 **核心问题**：现有游戏智能体缺乏显式的世界动态建模，而交互式世界模型又无法作为任务策略，如何在视频游戏复杂动态与开放式交互下统一世界建模与动作决策尚待探索。

🛠 **方法**：提出GameWAM，通过并行视觉与动作生成过程（块因果条件+流匹配）联合生成未来视觉观测与可执行的键鼠轨迹，并采用模式预测、连续动作归一化及块循环控制实现长时程闭环交互。

✨ **主要贡献**：首个面向原生闭环游戏与GUI控制的World-Action Model，以更少原生动作实现有竞争力的任务成功率，并揭示了生成式控制中的低频动作源印记（LASI）失效模式。

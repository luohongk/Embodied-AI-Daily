# Temperature Scaling Attack Disrupting Model Confidence in Federated Learning

- arXiv: https://arxiv.org/abs/2602.06638v3
- arXiv ID: 2602.06638

---

🔍 **核心问题**：在联邦学习中，现有攻击主要针对模型精度或植入后门，而忽略了预测置信度校准这一关键安全维度。本文提出将置信度校准破坏作为独立攻击目标，解决模型在高风险场景下因过度自信或信心不足导致的风险控制失效问题。

🛠 **方法**：提出温度缩放攻击（TSA），在本地训练阶段注入温度缩放参数，并通过学习率-温度耦合机制控制更新尺度，使模型在保持预测精度和常见优化信号接近良性训练的同时，系统性偏移置信度输出。作者还提供了非独立同分布（non-IID）设置下的收敛性分析。

✨ **主要贡献**：首次将校准完整性确立为联邦学习的关键攻击面。实验表明TSA在CIFAR-100上使校准误差增加145%而精度变化小于2%，且能抵御鲁棒聚合和后处理校准防御。案例研究显示，在医疗和自动驾驶场景中，即使精度不变，TSA可导致高达7.2倍的漏检率增加和严重的置信度门控失效。

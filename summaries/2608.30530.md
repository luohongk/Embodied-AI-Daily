# WebWorld: The Browser as a World Model for Self-Improving Web Code

- arXiv: https://arxiv.org/abs/2608.30530v1
- arXiv ID: 2608.30530

---

🔍 **核心问题**：VLM驱动的网页代码自我修复存在结构性缺陷——提出修复的模型同时充当评判者，视觉合理性无法保证页面真实功能正确。

🛠 **方法**：提出WebWorld框架，将浏览器作为确定性可执行的世界模型，VLM生成批评后由规划器编译为类型化交互契约，浏览器重新执行候选代码并仅在目标进展与所有已验证能力保持时签发接受证书，认证转换累积为质量棘轮，仅此作为SFT导出依据。

✨ **主要贡献**：在匹配训练下，WebWorld-27B相比Raw-27B在HTMLBench-400提升5.3分、MiniAppBench-Val提升14.9分，达到Kimi-K2.6和GPT-5.4等强前沿系统水平；等规模消融证明浏览器认证机制是性能提升的关键，移除证书后9B模型提升几乎消失。

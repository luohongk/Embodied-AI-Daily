# WebCoach: Self-Evolving Web Agents with Cross-Session Memory Guidance

- arXiv: https://arxiv.org/abs/2511.12997v2
- arXiv ID: 2511.12997

---

🔍 **核心问题**：当前多模态大模型驱动的网页代理在跨会话任务中频繁出现重复错误，缺乏从历史经验中学习的能力，导致长期鲁棒性和样本效率低下。

🛠 **方法**：提出WebCoach框架，包含三个组件：WebCondenser（标准化导航日志）、外部记忆库（存储完整轨迹作为情景经验）、Coach（基于相似性和时效性检索经验，并通过运行时钩子注入任务建议），实现跨会话记忆的持久化与利用。

✨ **主要贡献**：WebCoach无需重新训练即可实现代理的自我进化，在WebVoyager基准测试中，使用38B模型将任务成功率从47%提升至61%，且小型模型搭配WebCoach可达到与GPT-4o代理相当的性能。

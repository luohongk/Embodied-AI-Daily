# What Makes Good Agentic Data? An ACE Lens on Data Generation for LLM Agents

- arXiv: https://arxiv.org/abs/2608.27260v1
- arXiv ID: 2608.27260

---

🔍 **核心问题**：LLM智能体依赖生成的交互数据来学习与环境互动，但现有研究领域分散、评估标准不一，缺乏统一的生成机制框架，且常混淆候选数据构建与验证选择。

🛠 **方法**：提出两层级框架——首先将智能体数据表示为因子化对象$(E,q,τ,v)$（环境、任务、交互、验证器），按生成范式的主锚点与依赖结构分类；其次通过ACE视角（准确性-复杂度-多样性）将数据生成形式化为约束分布设计，在准确性确定的可行支撑内，按学习者能力配置复杂度，并控制多样性覆盖与冗余。

✨ **主要贡献**：统一了智能体数据生成的描述与评估框架，揭示了领域向执行锚定准确性、学习者相对复杂度及超越表面变化的多样性转变趋势，并讨论了数据规模、来源、训练机制与自适应学习等扩展方向，强调核心挑战在于持续分配有效、信息丰富且非冗余的经验，而非简单增加数据量。

# Discriminative World Models for Web Agents

- arXiv: https://arxiv.org/abs/2609.02885v1
- arXiv ID: 2609.02885

---

🔍 **核心问题**：现有Web智能体的世界模型通过监督式下一状态预测训练，其生成的状态表示与下游排序器需求不一致，导致动作选择效果不佳。

🛠 **方法**：提出“预测状态匹配”训练目标，要求模型预测的状态表示能区分真实结果状态与替代动作产生的状态，并基于WebArena Go-Browse轨迹构建分支数据集进行训练。

✨ **主要贡献**：在预测状态匹配基准上优于监督式下一状态预测模型；在WebPRMBench上提升PRM式动作排序性能；在WebArena-Lite上通过测试时动作选择显著提高端到端任务成功率。

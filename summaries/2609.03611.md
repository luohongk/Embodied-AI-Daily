# FailBench: How Reliable are VLMs at Judging Robot Task Success?

- arXiv: https://arxiv.org/abs/2609.03611v1
- arXiv ID: 2609.03611

---

🔍 **核心问题**：现有视觉语言模型（VLM）在机器人任务成功判断上的基准缺乏跨域泛化证据，且对失败检测的可靠性评估不足。

🛠 **方法**：构建FailBench基准，包含来自14个公开来源（12个真实、2个模拟）的2,197次操作尝试，其中75%为自然发生的失败；评估13种基于VLM的检测器，并引入输入级干预（空间定位与裁剪相关区域）。

✨ **主要贡献**：最佳模型平均平衡准确率仅0.77；微调模型普遍逊于通用VLM；模型在依赖可观察物体运动的任务上接近饱和，但在接触密集型装配任务上退化至接近随机水平；错误分析揭示系统性的“成功偏向”偏差；空间裁剪干预无需额外训练即可将最佳检测器提升2.4个百分点。

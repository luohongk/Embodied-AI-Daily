# RayViT: Ray-Conditioned Visual Representations for Viewpoint-Robust Imitation Learning

- arXiv: https://arxiv.org/abs/2607.29622v1
- arXiv ID: 2607.29622

---

🔍 **核心问题**：视觉模仿学习中，RGB观测缺乏几何线索，导致策略在相机扰动下表现脆弱。

🛠 **方法**：提出RayViT架构，将相机几何编码为Plücker射线图，经patch化后作为密集位置嵌入注入预训练ViT，并通过门控交叉注意力生成几何感知的类别令牌，同时辅以余弦相似度损失增强鲁棒性。

✨ **主要贡献**：在RoboCasa多任务基准中，相机扰动下鲁棒性提升约13个百分点；真实机器人多任务成功率平均完成阶段数提升1.78，验证了方法的有效性与泛化性。

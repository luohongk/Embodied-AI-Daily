# SMG: Semantic Motion Graph for Monocular Dynamic Gaussian Splatting

- arXiv: https://arxiv.org/abs/2608.31023v1
- arXiv ID: 2608.31023

---

🔍 **核心问题**：从单目视频中建模动态场景时，现有动态高斯泼溅方法在遮挡或复杂运动下容易过拟合训练视角，缺乏可靠正则化信号导致重建质量下降。

🛠 **方法**：提出语义运动图（SMG），将高斯运动建模为低秩语义运动，利用场景中语义一致区域运动相似的先验，通过图节点驱动高斯运动，并用可靠节点引导不可靠节点的运动以降低不确定性。

✨ **主要贡献**：首次将语义一致性引入动态高斯泼溅，显著提升单目动态场景重建的鲁棒性；引入新的多视角数据集（ego-exo设置），并在多个真实世界基准上取得最先进性能。

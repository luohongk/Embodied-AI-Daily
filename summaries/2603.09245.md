# Bridging Object Detection and Segmentation with Polygon Detection Transformers

- arXiv: https://arxiv.org/abs/2603.09245v2
- arXiv ID: 2603.09245

---

🔍 **核心问题**：现有前景表示方法中，边界框过于粗糙无法准确表达物体形状，而掩码分割虽精确但对紧凑几何结构过度建模，需要一种兼顾效率与精度的中间表示。

🛠 **方法**：提出Poly-DETR，基于极坐标表示，让对象查询回归一个起始点和固定数量的径向距离，直接构建逼近轮廓的多边形；并设计了极坐标可变形注意力和位置感知训练方案来对齐特征采样与多边形监督。

✨ **主要贡献**：Poly-DETR在MS COCO上比现有极坐标方法提升4.7 mAP，且在遥感、医学影像和自动驾驶等高分辨率场景中展现出比掩码方法更强的可扩展性，并能自然扩展到基于基础模型先验的DETR变体。

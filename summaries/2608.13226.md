# CoverPrune: Coverage-Driven Token Pruning for 3D VLMs via Optimal Transport

- arXiv: https://arxiv.org/abs/2608.13226v1
- arXiv ID: 2608.13226

---

🔍 **核心问题**：3D视觉语言模型（3D VLMs）在推理时因视觉token数量庞大而产生严重计算瓶颈，现有基于多样性的token剪枝方法会丢弃代表性原型token，破坏多视角一致性和几何结构，影响空间推理能力。

🛠 **方法**：提出CoverPrune，一种无需训练的框架，将推理时token剪枝建模为最优传输（OT）问题；设计特征-空间-时间（FST）传输代价和目标容量，并采用空间引导的贪心选择（SGS）算法近似求解；另提出加速变体CoverPrune-Lite，利用空间结构化局部匹配降低开销。

✨ **主要贡献**：将剪枝范式从“最大化多样性”转向“保留视觉证据覆盖”，在多个3D空间推理基准上取得最先进的token效率，即使在极高剪枝预算下仍保持稳健推理性能，代码已开源。

# SHE: Trajectory-driven Safety Harness Evolution for LLM Agents

- arXiv: https://arxiv.org/abs/2608.09885v1
- arXiv ID: 2608.09885

---

🔍 **核心问题**：LLM智能体的安全性不仅依赖模型权重，还受限于固定的agent harness（管理上下文、工具、权限等），现有机制无法随新风险动态演化，且组件间功能耦合导致安全责任归属不清。

🛠 **方法**：提出Safety Harness Evolution (SHE)框架，将harness分解为系统提示、规则库、安全记忆和工具策略四个职责明确的组件，并引入基于轨迹归因的演化循环——从失败轨迹生成结构化诊断，学习各组件边界细化，再通过安全-效用验证选择演化后的harness。

✨ **主要贡献**：在Agent-SafetyBench上，SHE将攻击成功率（ASR）相比静态SafeHarness降低3.1倍，同时提升良性任务效用；演化后的harness在未见风险（AgentHarm基准）上表现泛化，且无需额外演化即可迁移至其他agent模型。

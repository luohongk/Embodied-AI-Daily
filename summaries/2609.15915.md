# Safe Meta-Reinforcement Learning via Information Space Reachability

- arXiv: https://arxiv.org/abs/2609.15915v1
- arXiv ID: 2609.15915

---

🔍 **核心问题**：元强化学习（meta-RL）虽能让智能体快速适应新任务，但其在现实应用中的安全性要求尚未被充分研究，如何在适应过程中保证安全是关键挑战。

🛠 **方法**：提出在“信息空间”（同时刻画物理状态与智能体对任务的信念）中推理安全性，引入安全价值函数衡量智能体无限期避开不安全区域的概率，并证明其满足自一致条件与贝尔曼方程，从而可被元RL学习；据此开发了结合安全过滤与约束策略优化的安全元RL算法。

✨ **主要贡献**：首次将安全性显式纳入元RL的适应过程，通过信息空间可达性建模使安全价值函数可学习，并在元RL基准上验证了方法的有效性。

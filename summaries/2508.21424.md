# Unsupervised Incremental Learning Using Confidence-Based Pseudo-Labels

- arXiv: https://arxiv.org/abs/2508.21424v3
- arXiv ID: 2508.21424

---

🔍 **核心问题**：解决现实场景中增量学习依赖人工标注数据的问题，即如何在无标签数据上实现类别增量学习。

🛠 **方法**：提出基于置信度伪标签的无监督增量学习方法（ICPL），用模型生成的伪标签替代人工标注，并通过置信度筛选将高质量伪标签集成到现有CIL方法中。

✨ **主要贡献**：在CIFAR100和ImageNet100上验证了方法的有效性，相比监督方法性能接近，且比最先进的class-iNCD方法最终准确率提升超过5%；同时证明了在细粒度数据集上的实用性和较低的计算复杂度。

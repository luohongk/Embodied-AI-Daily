# Beyond Benchmarks: Using VLMs to Reveal Systematic Classification Failures Under Real World Conditions

- arXiv: https://arxiv.org/abs/2609.11126v1
- arXiv ID: 2609.11126

---

🔍 **核心问题**：分类模型的验证与确认（V&V）目前依赖耗时的人工检查错误样本，本文探索能否用视觉语言模型（VLM）加速这一过程，尤其是在训练数据覆盖不足、场景多样性较低的国防领域。

🛠 **方法**：提出基于VLM的错误切片检测（ESD）方法，利用VLM将图像嵌入语义向量空间，进而对分类模型的系统性错误进行独立分组和标注，并在军事与非军事数据集上分别评估。

✨ **主要贡献**：证明该方法能在非军事数据集中识别具有实际意义的系统性扰动，在军事场景中也能按环境对图像聚类描述（但存在描述重叠）；结果表明VLM尚不足以实现全自动V&V，但有望在未来加速该流程。

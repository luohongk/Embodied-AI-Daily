# Mamba-CL: Optimizing Selective State Space Model in Null Space for Continual Learning

- arXiv: https://arxiv.org/abs/2411.15469v3
- arXiv ID: 2411.15469

---

🔍 **核心问题**：解决持续学习中模型在学习新任务时遗忘旧知识（灾难性遗忘）的问题。  
🛠 **方法**：基于Mamba状态空间模型，通过将参数更新约束在先前任务特征子空间的零空间中，实现跨任务输出一致性，并推导出四个关键时不变参数的全局约束条件。  
✨ **主要贡献**：首次将Mamba模型应用于持续学习，理论保证了遗忘抑制，在四个类增量基准上超越现有方法，代码已开源。

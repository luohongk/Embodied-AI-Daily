# Face-D(^2)CL: Multi-Domain Synergistic Representation with Dual Continual Learning for Facial DeepFake Detection

- arXiv: https://arxiv.org/abs/2604.08159v2
- arXiv ID: 2604.08159

---

🔍 **核心问题**：针对面部DeepFake检测中，模型在持续适应新伪造方法时面临特征表示能力不足和灾难性遗忘两大瓶颈。

🛠 **方法**：提出Face-D(²)CL框架，融合空间域与频域特征进行多域协同表示，并采用双持续学习机制（RF-EWC区分真实/伪造样本的参数重要性，D-OGC约束任务专家模块更新不干扰旧知识），无需历史数据回放。

✨ **主要贡献**：在稳定性和可塑性上均超越现有SOTA方法，平均检测错误率相对降低60.7%；在未见伪造域上，平均检测AUC比当前SOTA提升7.9%。

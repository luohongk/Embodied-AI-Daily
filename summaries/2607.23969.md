# LeapBot-WA: World-Anchor Action Models via Predictive Latent Alignments

- arXiv: https://arxiv.org/abs/2607.23969v1
- arXiv ID: 2607.23969

---

🔍 **核心问题**：现有世界动作模型依赖像素级视频生成，导致计算资源浪费于任务无关细节，且易受视觉干扰影响，限制了模型在机器人控制中的鲁棒性和可扩展性。

🛠 **方法**：提出LeapBot-WA，采用联合嵌入预测架构作为“世界锚点”，在潜在空间中实现预测性语义对齐；引入各向同性语义自编码器将非高斯预测特征映射为扩散友好流形；设计非对称混合变换器架构，训练时用锚点扩散变换器引导动作扩散变换器，推理时剪除重分支实现零开销执行。

✨ **主要贡献**：在LIBERO基准上达到预测模型最优性能，无需大规模轨迹预训练即可匹配顶级生成式WAM在RoboTwin 2.0上的表现；展现对未知环境的零样本鲁棒性及真实世界迁移能力，建立了高效鲁棒的潜在中心化机器人控制范式。

# GS$^{2}$CI: Robust Gaussian Splatting For Snapshot Compressive Imaging via Large Vision Model Priors

- arXiv: https://arxiv.org/abs/2608.13502v1
- arXiv ID: 2608.13502

---

🔍 **核心问题**：从单次快照压缩成像（SCI）测量中重建高质量3D场景，现有方法因信息丢失、视角多样性有限及联合优化3D表示与相机位姿的计算负担而表现不佳。

🛠 **方法**：提出结合3D高斯泼溅（3DGS）与大规模视觉基础模型（VFM）先验的框架，先用测量数据初始化3D VFM并进行SCI感知的高斯优化，再用2D VFM在合成视角提供伪监督细化外观，并引入SCI专用的稠密化策略OSGR（不透明度引导的分裂与增长调控）以稳定优化。

✨ **主要贡献**：在多个基准上取得最强综合性能，重建质量领先且对视角变化鲁棒，同时保持有竞争力的计算效率；OSGR策略有效缓解SCI监督模糊导致的优化不稳定问题。

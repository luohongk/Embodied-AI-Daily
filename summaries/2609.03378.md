# When Depth Hurts: Reliability-Aware Geometry Distillation for Depth-Free RGB-D Salient Object Detection

- arXiv: https://arxiv.org/abs/2609.03378v1
- arXiv ID: 2609.03378

---

🔍 **核心问题**：RGB-D显著目标检测中，传感器深度图常存在缺失、模糊或伪影，导致多模态融合反而降低检测精度，现有质量感知方法仍依赖有缺陷的深度模态。

🛠 **方法**：提出可靠性感知几何蒸馏框架，训练时用冻结的Depth Anything V2作为教师模型，将稠密相对几何、层次空间注意力和边界结构蒸馏到紧凑的边缘感知几何分支；通过池化双向交互对齐几何与外观，并用像素级可靠性估计器选择性注入与RGB表示兼容的几何信息，推理时完全移除教师模型，仅用RGB输入。

✨ **主要贡献**：在36项指标-数据集对比中取得26项最佳或并列最佳，ReDWeb-S上MAE相对降低13.4%；在DUTS-TR重训后，PASCAL-S上F-measure提升4.2%，证明蒸馏几何可跨传感器和数据集域迁移，且无需训练/推理时使用深度数据。

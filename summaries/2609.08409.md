# Coverage Path Planning for Redundant Manipulators using Generalized Spanning Trees

- arXiv: https://arxiv.org/abs/2609.08409v1
- arXiv ID: 2609.08409

---

🔍 **核心问题**：针对冗余机械臂的表面覆盖路径规划，解决因每个表面点存在多个逆运动学解而导致的配置选择困难及运动质量下降问题。

🛠 **方法**：提出离线与在线两种联合生成树覆盖算法。离线JSTC将问题建模为广义最小生成树，在每个网格单元采样多个IK解并选择最优配置；在线JSTC则通过增量扩展与回溯生成树，结合可行性和代价评估处理动态网格更新。

✨ **主要贡献**：离线JSTC相比现有方法显著降低计算时间、重配置次数和关节运动量；在线JSTC在动态场景中实现快速逐步行规划，扩展了经典STC方法至冗余机械臂领域。

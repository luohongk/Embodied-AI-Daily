# 4D Radar Perception Algorithms for Autonomous Driving: A Review

- arXiv: https://arxiv.org/abs/2609.19216v1
- arXiv ID: 2609.19216

---

🔍 **核心问题**：4D毫米波雷达感知算法近年快速发展，但缺乏按感知任务与算法演进组织的系统性综述。

🛠 **方法**：按感知任务演进组织文献，先介绍雷达基础、数据表示与质量增强方法，再依次综述目标级感知、运动与定位、局部与稠密空间感知、动态场景理解，并对比纯雷达学习、多模态融合与跨模态监督/知识蒸馏。

✨ **主要贡献**：系统梳理了高度、多普勒测量与雷达物理先验在各任务中的利用方式，总结了现有数据集的任务覆盖、输入数据、标注与评估协议，并指出从稀疏目标感知向动态空间理解转变的挑战与未来方向。

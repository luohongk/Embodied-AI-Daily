# Towards Unified World Models for Visual Navigation via Memory-Augmented Planning and Foresight

- arXiv: https://arxiv.org/abs/2510.08713v3
- arXiv ID: 2510.08713

---

🔍 **核心问题**：现有视觉导航系统将规划与世界模型分离，导致状态-动作不对齐，在动态或新场景中适应性差。

🛠 **方法**：提出UniWM，一个统一的多模态自回归世界模型，将第一人称视觉预测与规划集成于同一架构，并通过分层记忆机制融合短期感知与长期轨迹上下文。

✨ **主要贡献**：在四个基准及人形数据集上，导航成功率最高提升30%，轨迹误差显著降低，零样本泛化至未见数据集，并自然扩展到高维人形导航。

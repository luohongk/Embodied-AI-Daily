# An offline approach to fNIRS-guided reinforcement learning for robot behavior

- arXiv: https://arxiv.org/abs/2607.14393v2
- arXiv ID: 2607.14393

---

🔍 **核心问题**：探索能否利用功能性近红外光谱（fNIRS）采集的脑信号，在仿真环境中调节机器人强化学习（RL）过程，以替代或补充传统人工反馈。

🛠 **方法**：比较被动（观察）与主动（示范）交互任务下训练的智能体，并测试多种将神经信号融入RL算法的方式，重点采用参数增强（而非替换）策略，同时分析模型粒度和噪声对学习的影响。

✨ **主要贡献**：验证了该框架的有效性——神经信号在增强轨迹优先级和状态-动作Q目标时能提升学习效果；且框架能从离线数据中成功学习，为实时脑机接口（BCI）不可行或数据有限的场景提供了实用替代方案。

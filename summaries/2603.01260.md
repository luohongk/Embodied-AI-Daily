# MOSAIC: A Universal Agent-Level Interface for Cross-Paradigm Agent Mixing and Human-AI Collaboration

- arXiv: https://arxiv.org/abs/2603.01260v3
- arXiv ID: 2603.01260

---

🔍 **核心问题**：现有基础设施无法在同一环境中部署来自不同决策范式的智能体，导致无法在相同条件下进行公平的跨范式比较。

🛠 **方法**：MOSAIC 通过基于 IPC 的 worker 协议将各类框架封装为隔离子进程，并以 operator 抽象将 worker 映射为统一智能体槽位，同时提供手动与脚本两种确定性评估模式。

✨ **主要贡献**：实现了 RL 策略、LLM、VLM 与人类操作者在共享强化学习环境中的异构混合协作与可复现的跨范式对比，并开源了平台及文档。

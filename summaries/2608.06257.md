# MASS: Multiplayer World Models with Authoritative Shared State

- arXiv: https://arxiv.org/abs/2608.06257v1
- arXiv ID: 2608.06257

---

🔍 **核心问题**：现有视频世界模型在多智能体环境中将世界状态与视角相关的视觉潜在变量纠缠在一起，导致计算冗余、视角不一致和扩展性差。

🛠 **方法**：提出MASS框架，将世界动态与视角渲染解耦。一个学习的逻辑引擎从联合动作中推进全局权威类型化状态（无需手写转移函数），作为唯一循环记忆和同步参考；一个学习的渲染引擎从该共享状态按需生成任意相机的独立一致视图。

✨ **主要贡献**：在匹配的多玩家Snake基准上，相比最先进的多视角基线，MASS实现了更高的状态准确性和更低的跨视角不一致性，并能推进包含1024个并发玩家、10000个循环步骤的预测世界，证明显式权威状态建模是可扩展多智能体世界模拟的实用基础。

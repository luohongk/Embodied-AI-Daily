# Context Is King: How In-Context Specification Shapes the Geometry of Concepts

- arXiv: https://arxiv.org/abs/2607.24425v1
- arXiv ID: 2607.24425

---

🔍 **核心问题**：探究大语言模型中概念几何结构的决定因素，即模型实际使用的结构是由预训练存储的固定世界模型主导，还是由上下文指定规则动态决定。

🛠 **方法**：通过设计对比实验，在上下文中施加声明性规则（如循环或树形拓扑），测试模型对任意无意义标记的几何编码能力；利用表征相似性分析和激活修补技术，验证上下文指定结构是否被模型因果性地使用。

✨ **主要贡献**：发现上下文指定规则能覆盖预训练先验，主导模型实际使用的几何结构（表征相似性0.6-0.9 vs 近零），且该机制仅在较大模型（如Gemma-31B、Qwen-27B）中清晰体现，揭示了模型规模对上下文动态几何构建能力的关键作用。

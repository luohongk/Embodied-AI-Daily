# $ω$-0: A Latent Predictive World Action Model for Concurrent Humanoid Loco-Manipulation

- arXiv: https://arxiv.org/abs/2608.06375v1
- arXiv ID: 2608.06375

---

🔍 **核心问题**：现有类人机器人策略通常将移动与操作分离，难以实现家庭场景中需要同步协调的全身移动-操作（concurrent loco-manipulation）行为。

🛠 **方法**：提出 $ω$-0 模型，一种潜在预测式全身世界-动作模型，直接预测控制器兼容的动作潜变量，以轻量级未来观测嵌入作为预测目标，结合扩散模型生成全身动作，并支持多种视觉输入及基于控制器的仿真回放来对齐视觉-运动先验。

✨ **主要贡献**：构建了40+小时的真实家庭类人机器人数据集 $ω$-HOME，并在11项家庭任务上验证单一 $ω$-0 模型可生成平滑的边移动边操作行为，性能一致优于多种代表性模仿学习、VLA、类人机器人和世界-动作模型基线。

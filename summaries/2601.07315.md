# VLM-CAD: VLM-Optimized Collaborative Agent Design Workflow for Analog Circuit Sizing

- arXiv: https://arxiv.org/abs/2601.07315v5
- arXiv ID: 2601.07315

---

🔍 **核心问题**：视觉语言模型（VLM）在解读模拟电路原理图等密集结构化工程内容时存在空间盲区和逻辑幻觉，难以可靠地完成模拟电路尺寸设计任务。

🛠 **方法**：提出 VLM-CAD 协作智能体工作流，通过神经符号结构解析模块 Image2Net 将原始像素转化为显式拓扑图和结构化 JSON 表示，并采用可解释信赖域贝叶斯优化方法 ExTuRBO，利用智能体生成的语义种子热启动局部搜索，并用自动相关性判定提供灵敏度证据。

✨ **主要贡献**：在涵盖 6 种电路、4 个技术平台的 12 项尺寸设计任务上，实现严格 Pass@1 达 23.3%、宽松 Pass@1 达 91.7%，并为最终设计报告提供灵敏度证据，有效弥合了模态鸿沟并提升了工程决策的可靠性。

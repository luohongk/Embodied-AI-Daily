# When Should a World Model Move? Loss-Conditioned State Execution

- arXiv: https://arxiv.org/abs/2609.15801v1
- arXiv ID: 2609.15801

---

🔍 **核心问题**：世界模型是否应执行其预测更新，仅凭预测信息量或事件可预测性无法判断更新能否降低下游损失，需将“状态可移动性”与特定提案的收益区分开来。

🛠 **方法**：提出损失条件状态执行（loss-conditioned state execution），从预测分布构造损失特定的可行提案，在独立校准单元上评估其相对保持现状的分组有界损失增益，仅当同时下置信界为正时才执行提案。

✨ **主要贡献**：形式化了状态可移动性并证明被接受分组以高概率降低期望损失；在M4月度序列上仅对14.0%序列执行提案即取得0.588的有界损失（优于保持现状0.599和始终执行0.621），并在京东库存预测中揭示了事件可预测性与状态执行决策可能相悖。

# Environment Evolution for Terminal Agents

- arXiv: https://arxiv.org/abs/2609.04128v1
- arXiv ID: 2609.04128

---

🔍 **核心问题**：为终端智能体（terminal agents）训练提供持续有效、可验证且难度递增的环境，避免现有方法因依赖在线策略采样而导致的泛化不足和学习信号衰减问题。

🛠 **方法**：提出“环境进化”（environment evolution）框架，基于多轮学习目标推导三种影响难度的进化方向，通过循环工程的多智能体协作机制离线逐步提升环境难度，并在训练中按代际调度这些进化环境以提供连续学习信号。

✨ **主要贡献**：在Hy4 preview、Claude Opus 5和GPT-5.6 Sol上验证了该方法能稳定生成更难的环境；在Qwen3.6-27B和Qwen3.6-35B-A3B上通过简单长时程RL训练，分别将Terminal-Bench 2.1性能提升14.4和18.0个百分点，证明了其有效性与通用性。

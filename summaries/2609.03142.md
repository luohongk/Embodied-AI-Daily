# Sensing Which Modality Matters: Evidence-Gated Regularization for Robust VLA Policies

- arXiv: https://arxiv.org/abs/2609.03142v1
- arXiv ID: 2609.03142

---

🔍 **核心问题**：视觉-语言-动作（VLA）模型在有限且同质的机器人演示数据上训练时，容易学习到传感器间的虚假关联而非任务相关信号，导致对遮挡和干扰的鲁棒性差。

🛠 **方法**：提出证据门控正则化（EGR），通过逐帧、逐传感器估计任务相关性，对低证据传感器施加不变性约束，对高证据传感器施加单传感器充分性约束，训练时无推理开销。

✨ **主要贡献**：在BEHAVIOR-1K基准和两类真实机器人（双臂视觉、单臂视觉+触觉）上验证，EGR将仿真成功率在完整模态下提升31%，在无关传感器损坏时提升75%，在单传感器回退时提升120%；真实场景中双臂成功率从30%提升至85%，触觉设置从55%提升至70%。

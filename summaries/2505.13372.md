# Exploiting Symbolic Heuristics for the Synthesis of Domain-Specific Temporal Planning Guidance using Reinforcement Learning

- arXiv: https://arxiv.org/abs/2505.13372v2
- arXiv ID: 2505.13372

---

🔍 **核心问题**：在时间规划中，针对固定领域和给定训练问题（而非计划），如何利用强化学习合成启发式指导，以提升规划器性能，并解决训练过程中因无限状态MDP导致的回合截断问题。

🛠 **方法**：提出一个改进的学习与规划框架，在强化学习和规划阶段均利用符号启发式信息。具体包括：设计不同奖励模式以缓解回合截断影响；学习现有符号启发式的残差（即“修正值”）而非从零学习整个启发式；采用多队列规划方法，将学习到的启发式与符号启发式结合，平衡系统搜索与不完美的学习信息。

✨ **主要贡献**：形式化了多种奖励模式，提出残差学习策略和混合多队列规划方法，通过实验对比各方案优劣，显著提升了该学习与规划框架的性能，推进了该领域的最新水平。
